# 午夜机台 · 设计文档

> 这是游戏唯一的策划文档。**改设计 = 在同一次提交里改这份文档**：加减系统、改规则、改关键数值、加新元素，都要同步到这里（维护规则见文末）。数值的最终来源是代码；这里写规则、意图和关键数值。

## 1. 一句话

深夜的公寓里有一台午夜机台。投币后你在地下挖出一座基地，派领袖穿过传送门去异世界探险，把物资和图纸带回来，每 5 天守一次城——直到基地核心归零或传送门被打破。

**核心体验**：出征时“要不要再往前走一步”的贪心和风险；回到基地后“这次带回的东西怎么用”的规划；守城时“牺牲谁”的抉择。

## 2. 三层循环

| 层 | 在哪里 | 做什么 | 一次多长 |
|---|---|---|---|
| ~~房间~~（**已屏蔽**） | 午夜机台所在的房间 | 用代币买家具（永久加成）、选卡带、看成就 | — |
| 基地（局外） | 地下基地 | 按天推进：挖掘、建造、招募、升级、选世界出征、每 5 天守城 | 十几天到几十天 |
| 一次出征（局内） | 异世界地图 | 一站站往前走：战斗、夜市、奇遇；撤离或打败首领就带着收获回基地 | 7～17 站 |

一局结束的条件（任一）：
- **基地核心归零**：核心整局只有 3 点，领袖在出征中阵亡一次 -1；通关一个世界 +1（不超过 3）。
- **传送门被打破**：守城时传送门耐久打光。

**当前流程（2026-09-24 起）**：开场动画结束时镜头停在机台正面，机台屏幕上直接显示「开始游戏 / 继续」「玩法说明」「设置」（没有单独的标题页）；点开始游戏，镜头钻进屏幕 → 基地。基地是局外，出征是局内。一局结束时弹出结算（原因、坚持的天数、通关的世界数），可以「重新开始」或「回到标题」。基地右上角有「放弃」按钮：确认后清空这一局的所有进度（基地、领袖、建筑、物资、天数），从第 1 天重新开始；新手教学不会再出现，设置保留。
- **重新开始送序章奖励**（用户裁定 2026-09-24）：打过序章之后的每一局新游戏（放弃、结算后重新开始）都直接拿到序章结算给的东西——物资、碎片、经验球、领袖经验、找到的图纸（按玩家自己那次序章实际拿到的记在档案里；更早的档案按常见值：物资 +100、领袖经验 +100、1 张随机图纸）；序章教你盖的**酒馆已经建在主基地左边**，不用再盖。

房间系统（代币、家具、成就、卡带、月相、噩梦模式）目前**屏蔽**（`M.META_ROOM = false`，在 `src/mc-meta-a.js`）：家具和成就的加成全部不生效，下面 §4 的内容保留作为以后恢复时的设计。

## 4. 房间（局外成长，**已屏蔽**）

- **机台**：点它投币开始新的一局；有进行中的局时显示「继续 · 第 N 天」。
- **家具**（15 件，每件 1～3 级，花代币解锁 / 升级）：

| 家具（1 → 3 级） | 效果 |
|---|---|
| 水壶 → 咖啡机 → 多合一饮料机 | 每局前几天部队和领袖攻击 +10% → 前 7 天 +20%、部队生命 +10% |
| 旧冰箱 → 双门冰箱 → 冷库 | 初始物资 +150 → +250，带回物资 +25%，基地每天 +25 物资 |
| 存钱罐 → 保险箱 → 瑞士银行 | 把上一局的一部分物资 / 碎片带进下一局（15% → 50%，3 级还带最好的 1 件宝物） |
| 旧沙发 → 懒人沙发 → 按摩椅 | 初始领袖 +1 级 → +2 级，招募的领袖 +1 级，医疗回血 +50% |
| 攻略书 → 地图册 → 全知之书 | 出征视野 +1 → 整张地图可见 |
| 小苗 → 盆栽 → 世界树苗 | 每局多勘明 1～3 块特殊地格，3 级时主基地正下方必定是「灵脉」 |
| 收音机 → 唱片机 → 点唱机 | 事件好运 +10% → +15%，自带随机战旗，初始倍率 +0.2 |
| 挂钟 → 落地钟 → 时之沙 | 建造 -1 天 → -2 天，挖掘立刻完成 |
| 挂历 → 行事历 → 预言历 | 袭击间隔 5 天 → 6 → 7 天，守城武器伤害 +40% |
| 相框 → 照片墙 → 纪念碑 | 领袖阵亡多留经验球 → 宝物全部保住、多留碎片 |
| 猫碗 → 猫窝 → 黑猫 | 地图必出「招财猫」；每局 1～2 次把倒下的领袖叼回来（不死、不扣核心） |
| 卡带架 → 卡带柜 → 收藏墙 | 解锁开局卡带（2 → 4 种，3 级可同时插 2 盘） |
| 展柜 | 开启成就系统 |
| 月相窗 | 每局随机月相：满月好运、新月便宜、血月更难但图纸翻倍、代币 +30% |
| 那扇门 | 可选「噩梦模式」：敌人 +40%，代币 ×1.6 |

- **开局卡带**（4 种）：建筑师（+3 建筑图纸，至少 1 张奇观）、军火（+3 宝物图纸和 1 件稀有宝物）、招魂（+150 碎片、领袖上限 +1）、工兵（开局挖通 3 格、物资 +100）。
- **成就**（14 个，每个永久解锁一样局内的好处）：见附录 D。

## 5. 基地

### 5.1 天数

每出征一次，或点顶栏的「☾ 休整一天」，就过去 1 天。挖掘和建造按天推进，农场等建筑按天产出。每天会有一次换日动画。

### 5.2 挖掘与建造

- 基地在地下的网格里，**主基地**在第一排中间，连着地面的传送门。
- 只能挖**和已有房间相邻**的格子，花物资（基础 50）和天数：岩层 1 天；特殊地形叫「开垦」，按地形 1～3 天（见附录 B）。挖通后成为空房间。
- 在空房间里建造需要：**对应的建筑图纸**（列表里只出现你有图纸的建筑，×2 = 有 2 张）、物资、天数，史诗 / 传说建筑还要灵魂碎片（史诗 30、传说 60）。
- **电力**：大部分房间耗电，发电类产电；电力不足时不能再建耗电建筑。
- 建筑分 4 个品质，47 座，按**功能**分：仓库、电力、锻造、医疗、招募、训练、后勤、防御、运势、特殊；按**风格**分：蒸汽、魔法、自然、水域、玄幻、科幻、中世纪、卡通（主基地自成一类）。完整列表见附录 A。
- 奇观 = 稀有及以上的名胜建筑（埃菲尔铁塔、金字塔……），效果最强。

### 5.3 特殊地格

岩层里散布着 22 种特殊地格（特殊地形）。**和岩层混在一起的特殊地形就不是岩层**：
- 每种地形在基地里画成它自己的样子（地热的熔岩裂缝、晶簇、世界树根、龙骨……，`src/mc-terrain-art.js`），**不挂单独的图标**；鼠标放上去就显示它的详细信息（任何房间的效果、契合时的效果、开垦费用和天数）。
- 开垦天数和岩层不同，每种地形不一样：松软土层、陶土层、地下泉、风穴 1 天；化石层、古遗迹、琥珀层、灵脉、裂隙、英灵冢、时之沙、梦境裂隙、地热 2 天；晶簇、金脉、富矿脉、龙骨、大地之心、陨星坑、雷暴核心、世界树根、王座遗骸 3 天。
- 深层（第 4、5 排）的地脉在旁边挖通之前是「未勘明的地脉」：画成透着微光的岩层。
- 开垦后在上面建房间：**任何房间**都能拿到通用效果；建筑的**功能或风格「契合」**时，再拿一份更强的效果。房间地面留一道该地形的纹路。建造列表里「★」表示这里有地格加成。完整列表见附录 B。
- 建好之后，房间面板和悬浮说明只写**还在生效**的那部分，每条后面一个绿勾（「这个房间 +3 电力 ✔」），不再重复地格名字和规则；只在建造时起作用的地格（古遗迹）建成后直接消失。

### 5.4 房间标签

每个房间角上两个图标：左边**风格**，右边**功能**。地格和奇观用它们挑选「契合」的建筑。

## 6. 领袖

### 6.1 基本

- 领袖是出征的指挥官，也是守城的主力。上限 6 名；招募房间里可以**扩建**：每次花 200 / 400 / 600 / 800 物资，上限 +1（最多 +4）；吴哥窟另 +2。
- 招募：在招募建筑（招魂台、酒馆……）花 120 物资，品质随机：普通 55% / 稀有 30% / 史诗 12% / 传说 3%；巨石阵、灵脉、英灵冢等能保底。
- **招募演出（碎卡）**：抽出一张卡，卡背翻转飞到屏幕中央 → 蓄力（裂纹从中心蔓延，光色从普通一路升到它的真实品质，越好越震）→ 碎裂（碎片四散、白闪、冲击环、震屏）→ 露出真容（领袖像、职业图标、名字，品质色放射光）→ 飞进左下角的领袖栏。
- 品质影响属性（×1 / ×1.08 / ×1.18 / ×1.3）和天赋树深度。
- 6 种领袖职业（守夜人、赌徒寡妇、驱魔修女、屠宰场主、钟表匠、焚尸人），每种有自己的技能。
- **领袖没有个人名字**：职业就是名字，也代表技能——同一职业永远是同一个技能。每个职业有自己的职业图标。
- **基地领袖卡片**：头像；左上角职业图标；框底「Lv2」；边框颜色 = 品质；血条；右上角黄点 = 有没用的天赋点。不写名字。
- **生命不会自动回复**：营火、奇遇、医疗建筑、地下泉。
- **阵亡 = 永久死亡**：在出征中阵亡，基地核心 -1，带着的宝物丢失（保险库保住第 1 件），留下灵魂碎片；在守城中阵亡，核心不受影响，同样留下碎片。

### 6.2 领袖技能

每个职业**一个技能**（用户裁定 2026-09-24，原来的军团技能和个人技能合并成一个，界面上只显示一个图标、一个名字）。它有两种用法：场外指挥时玩家按空格释放，冷却按走过的站数算；领袖亲自上场后（以及守城时），它自己攒满、**范围里有敌人才放**，不弹横幅。

| 领袖 | 技能 | 场外按空格 | 亲自上场后（悬浮说明里的原话） |
|---|---|---|---|
| 守夜人 | 照夜 | 所有敌人停顿 | 怒气满后，用灯盾砸晕身边的敌人（240 以内有敌人才放） |
| 赌徒寡妇 | 梭哈 | 8 秒内每次击杀倍率 +1 | 能量满后，朝最肉的敌人掷出致命一牌（有敌人就放） |
| 驱魔修女 | 圣咏 | 全队回血 | 法力满后，治疗全队并灼伤身边的敌人（有友军低于 75% 生命，或 280 以内有 2 个敌人） |
| 屠宰场主 | 血祭 | 献祭生命最低的部队，倍率 +1 | 怒气满后，旋转攻击周围敌人（220 以内有敌人才放） |
| 钟表匠 | 倒带 | 部队攻速 +100%，6 秒 | 每 7 秒，让最近的敌人停摆（400 以内有敌人才放） |
| 焚尸人 | 火葬 | 点燃所有敌人 | 每 6 秒，点燃身边的敌人（280 以内有敌人才放） |

- 放不放的判定和技能实际打到的范围用同一套量法（`M.psReady`），不会出现“放了但一个都没打到”。守城时同理，按水平距离量。
- 领袖头像的悬浮说明：「Lv2 驱魔修女 / 血条 / 圣咏」，按住 Ctrl 展开成「全队回复 36% 生命（冷却 3 个节点）。上场后：法力满后，治疗全队并灼伤身边的敌人。」
- **技能按钮**（地图顶栏、战斗里的技能按钮）的悬浮说明直接给这句话，没有 Ctrl 这一层（用户裁定 2026-09-24）。

### 6.3 成长

- **经验球 → 升级**：在领袖详情里点「升级」，立刻升一级并播放升级仪式；从出征回来时如果升了级，也播放。每级 1 个天赋点。
- **天赋树**（三条路线）：杀伐（攻击、暴击、冷却、按职业加攻……）、坚忍（生命、护盾、保险柜、按职业加生命……）、运数（倍率、商店、碎片、物资、视野……）。每名领袖从每条路线随机抽 3～4 个。
- 天赋只写现在真的生效的东西（用户裁定 2026-09-24）：旧版的「【火】部队」「【兽】部队」「积分不足时」这类已经不存在的对象全部换成了**按职业**的天赋（射手、战士、法师、先锋、祭司），旧存档里的天赋自动换成对应的新天赋。
- **宝物**（13 种）：出征时带在身上。锻造建筑里用宝物图纸 + 120 物资打造，品质随机；精铸多花 40 碎片，至少史诗。宝物格数量随领袖和建筑增加（紫禁城、王座遗骸 +1）。

## 7. 出征

### 7.1 选世界

- **没有世界列表页。** 传送门平时是一座暗的石拱门，没有漩涡。点它 → 传送门打开（漩涡转起来），上方升起今天能去的世界**碑**（石碑造型，参考《暗黑地牢》的区域牌）。第 1～5 天每天 1 块，第 6 天起 2 块，第 12 天起 3 块；第二天换一批。
- 碑上只有两样东西：**危险度**（骷髅 + 低 / 中 / 高）和**特产图标**。悬浮碑看详情：世界名、危险度、每项特产的效果、「开局的仗约 N，首领约 B」「你出发时约 M」、主题敌人。
- **危险度**＝你出发时的战斗力（最强的领袖 + 3 支开局部队的平均值）÷ 这个世界开局几场仗的平均战斗力：≥ 1.6 低，≥ 1.15 中，否则高。首领的战斗力单独给出，那是这一趟要长到的目标。
- **特产**：物资 / 经验 / 积分倍率、支援道具、地脉结晶、宝物图纸、战后回血、高品质图纸、灵魂碎片，以及建筑图纸偏向的风格（风格图标）。
- **选中一块碑**：碑先抬起、砸进传送门、碎裂（冲击环 + 碎石 + 闪光 + 震屏），传送门随即展开这个世界的样子：雾中小镇起雾、精灵之森绿意盎然（藤蔓爬满门柱、萤火虫）、废弃游乐园旋转彩条和灯泡、沉没港口水波与气泡（水漫出门槛）、蒸汽铸造厂齿轮咬合和蒸汽、深夜医院鬼魂尖啸着飘出、星舰残骸星光跃迁、地狱血从门楣流下和火焰、地下赌场转盘和金币。然后弹出出征准备（选领袖和宝物）；关掉准备面板，碑重新升起。
- 10 个世界：旧公寓走廊（教学）、雾中小镇、精灵之森、废弃游乐园、沉没港口、蒸汽铸造厂、深夜医院、星舰残骸、地狱、地下赌场（最终之地）。
- 不想出征时，点顶栏「☾ 休整一天」直接过一天。

### 7.2 地图

- 横向推进的节点图，走过的节点不能回头；岔路用 ↑ ↓（或 W S）或点击选择。
- **视野**默认 2 步（能看清前方 2 步以内的节点）。会被这些改变：监听室 +2、风穴 +1、领袖天赋「鹰眼」+1、部分世界压低 1（雾中小镇起雾、深夜医院停电、地狱浓烟、地下赌场昏暗）、奇遇（许愿井打中井心附近：+1；落地镜失败：雾漫出来 −1）。最少 1 步。地图顶栏的眼睛图标显示当前视野，悬浮列出每一项来源。
- **战斗力一目了然**：每个看得见、还没打的战斗（普通、精英、首领、坚守、撤离）头上都有它的敌方战斗力，颜色按胜算：绿 = 我方 ÷ 敌方 ≥ 1.25（稳赢），黄 = 1～1.25（有风险），红 = 低于 1（很危险）。领袖小人头上是我方总战斗力，顶栏也有。悬浮战斗节点还会写「敌方战斗力 N · 我方 M · 稳赢 / 有风险 / 很危险」。每场战斗的敌人在第一次被看到时就定下来，显示的就是你要打的那一仗。
- 长度 4 档：短 7 站 / 中 10 / 长 13 / 极长 17，站数越多精英、首领、撤离点越多。
- 节点 11 种：起点、普通战、坚守战、精英战、首领、夜市、营火、宝箱、奇遇、招募旗、撤离点。
- **撤离点**：坚守一场后带着全部收获回基地。**首领**：打败即通关这个世界（核心 +1）。

### 7.3 部队

- 部队在战斗中自动作战，上限 10 支。来源：开局部队、夜市、招募旗、奇遇。
- 可用部队 140 种（普通 27 / 稀有 30 / 史诗 50 / 传说 33），敌人 49 种。
- **部队只显示三样东西**（用户裁定 2026-09-24）：名字 / 职业图标 + 职业、战斗力图标 + 战斗力 / 一句话（它的特性做什么）。不显示生命、攻击等数值，没有 Ctrl 详情。例：「巫毒信徒 / 战士 ★31 / 死亡时会对击杀者施加毒素。」
- 买部队只需要想两件事：**缺不缺这个职业**（前排扛伤、近战、远程、法术、治疗支援、赚钱），**这个职业里哪个战斗力最高、买得起**。这就是构筑策略。
- 职业（6 种）：先锋扛伤、战士近战、射手远程、法师法术、祭司支援、商人赚积分。战旗按职业加成。
- 每个单位有 1 个或多个**特性**（共 145 种），卡片上的一句话由前两个特性的短句拼成（`src/mc-awaken.js` 的特性表 `TR`，一条特性一句，不写数值）；没有特性的单位写它的职业用途。
- **部队没有额外的主动技能**。以前给每个职业加的招牌技能（冲锋盾击、旋风斩、箭雨……）已删除。单位只有自己的特性；特性本身就是攒法力释放的（治疗链、炮弹休克……），照旧按触发条件释放。
- **开战激活**：开战时，每个有特性的单位依次播放它的特性激活演出（光点聚向胸口 → 地面冲击环 + 光柱 + 火花 → 这一类特性的专属花样 → 特性图标从身上冲出、越过头顶再落定）。图标之后一直浮在头顶，特性生效时闪一下；亡语类单位死亡时，图标飞向击杀者炸开（巫毒信徒：身体里生出一个骷髅顶在头上，死时骷髅飞向凶手）。光环类还会连线到范围内的每个友军。共 27 类：亡语、毒、召唤、治疗、守护、反伤、迅捷、冰霜、火焰、雷电、金币、成长、潜行、冲锋、刀锋、奥术、狂怒、诅咒、复生，以及 8 种光环（治疗、守护、伤害、攻速、法力、冰霜、削弱、吸血）。每个单位属于哪一类见 `docs/effects.md` 的单位表。
- 种族仍然存在（决定外观、入场方式、世界的主题敌人），但不在卡片上显示，也不参与任何加成；宝玉兽的「玉石共鸣」改为按场上的商人数量算。

### 7.4 夜市、战旗、道具

- **夜市**：三个区——部队、战旗、道具，点击直接买；刷新花积分，越刷越贵；点自己的部队半价卖掉。
- **战旗**（11 面）：整支部队的常驻加成，本次出征一直生效。职业战旗只加对应职业；狂热、赏金、王冠加倍率；壁垒给护盾；血怒全体攻击。
- **支援道具**（5 种，最多 3 个）：闪电风暴、回魂烛、旧相框、招魂铃、骰盅。战斗中按 Q W E 由领袖放出，放的时候转盘决定这次的品质（至少是道具本身的品质）。
- 道具的悬浮说明：名字（颜色 = 品质，名字后面不写品质）+ 一句话；四档品质各自的效果（普通 / 稀有 / 史诗 / 传说）**按住 Ctrl 才显示**，平时最后一行是闪烁的「按住 Ctrl 显示详细信息」（用户裁定 2026-09-24）。

### 7.5 奇遇与小游戏

26 种奇遇，每种是一个几秒到十几秒的小游戏（弹珠台、抓娃娃、扫雷、合奏、转盘……），营火和招募旗也是小游戏。结果给积分、部队、生命、倍率、图纸等。

### 7.6 带回

撤离或通关后，本次的**物资、经验、碎片、图纸**带回基地；领袖阵亡则全部丢失。此外还可能带回**纪念品**（11 种），在基地生效：流浪领袖、矿工队、工匠、修门石、启示卷轴、淬火石、安神香、迷踪粉、引荐信、蓄能核心、行军包（见附录 E）。宝物和建筑不能直接带出，只能带图纸。

## 8. 战斗

- 敌我同时入场，顶部显示这一仗的名字（普通战 / 精英战 / 首领战 / 最终首领战 / 坚守战 / 撤离战，一个词，不再写「普通战 · 首领」）通告；双方站定、通告淡出后才开打。
- **开战激活**：见 §7.3——每个有特性的单位先亮出自己的特性图标。
- **法力特性按时机释放**：带法力特性的部队上场时法力已满（法力条边框闪烁），但不会一开场全放——每个特性有自己的**触发条件**，满足才放，放完重新攒。敌人从 0 开始攒法力，用同样的触发条件。触发条件分几类（`src/mc-skilltrigger.js`，每个单位的具体条件见 `docs/characters.csv` 和 `docs/effects.md` 的 U 表）：
  - 治疗类：有友军生命低于一定比例（治疗链 70%、颅骨炖汤 60%）；以血换血类还要求自己生命高于 50%。
  - 近身范围类（禁果）：身边有 3 个以上敌人。
  - 落点范围类（炮弹休克、铁之冰雹、剑雨、剑刃风暴）：射程内的目标附近有 2 个以上敌人扎堆。
  - 群体类（闪电打击）：攻击范围内有 3 个以上敌人。
  - 强化自己类（太阳耀斑、神盾、急速射击……）：敌人进入攻击范围；精神扭曲：攻击最高的友军开始交战。
  - 单体重击类（法力爆裂、小行星、能量涌动）：射程内的目标生命还多（≥ 40%）。
  - 召唤类：有敌人逼近到 600 以内；扣血召唤（次元裂隙）还要求自己生命够扣。
  - 所有“N 个以上敌人”的条件，在敌人总数少于 N 时按剩下的数算，不会因为敌人太少而永远不放。
- 领袖亲自上场后的技能：范围里有敌人才放，见 §6.2。
- **目标**：普通战消灭所有敌人；坚守战撑过倒计时。
- **积分 = 基础积分 × 倍率**：击杀得基础分；精英 +0.1、首领 +0.3 倍率，战旗 / 宝物 / 特性继续叠加。
- **领袖**站在左边的指挥位，不参战；部队全灭后亲自上场。**首领战例外**（用户裁定 2026-09-24）：领袖和部队一起开场就上，技能从一开始就是自动释放（所以首领战里没有空格技能）。
- 操作：空格 领袖技能，Q W E 道具，P 暂停，F 切换 1× / 2× / 3× 速度。

### 8.1 战斗力（用户裁定 2026-09-24，自己算、说得清）

- **一方的战斗力 = √(全体总生命 × 全体每秒总伤害)**，按战斗里真实生成的数值算：我方 = 所有部队（战旗、领袖天赋和宝物、本局加成都算进去，开局护盾算作额外生命）+ 领袖（按当前生命）；敌方 = 这一仗的全部敌人（按天数放大、精英 ×1.15、首领护甲 ×1.3）。
- 单个部队 / 领袖的战斗力用同一个公式：√(生命 × 每秒伤害)。所以整队的数和单位的数是一套尺子。
- **为什么是这个公式**：两队对打时，一方能扛多久看总生命，打多快看总秒伤，双方互相消耗，谁的“生命 × 秒伤”大谁赢（兰彻斯特平方律）。用 3000 场无画面模拟标定（`tools/sim-power.js`，随机阵容、领袖、世界、普通 / 精英 / 首领 / 坚守）：按「我方 ÷ 敌方」排序预测胜负的准确度（AUC）0.99。实测胜率：比值 ≥ 1.25 约 99%，1.1～1.25 约 90%，1.0～1.1 约 65%，0.9～1.0 约 55%，低于 0.8 基本输。
- 特性、技能、站位会让结果有出入（比如召唤、治疗、群伤），所以“黄色”区间要看阵容。
- 坚守 / 撤离战只要撑过倒计时，地图上显示的敌方战斗力按全部波次的 0.7 算。
- **首领按同一站的精英战标定**：中途首领 = 精英战 × 1.1，最终首领 = 精英战 × 1.3（只缩放首领本体）。以前地图前段的首领是周围战斗的三倍，是“总被首领打死”的另一个原因。
- **修掉的 bug**：卫队长「神盾」、奥法元帅「最终审判」的范围伤害读错了特性数值，打出 NaN，被打到的敌人生命变成 NaN、再也打不死，拖到 150 秒超时判负——“战斗力高却打不过首领”的主因。伤害和治疗现在拒绝非法数值。

## 9. 守城

- **用词**（用户裁定 2026-09-24）：基地被袭击、领袖在地面迎战这件事叫**守城**；「**防御**」只是房间的功能标签（弩炮室、兵马俑……）。以前混用的「防守」全部改掉：建筑说明写「守城时……」，地格的契合写「防御」。
- 每 5 天一次（挂历可延长到 6 / 7 天）。当天先打开**选将面板**：挑出守城的领袖（默认勾上普通 / 稀有），不能跳过。
- 守城时选中的领袖在地面作战，领袖技能自动释放；地下的**武器房间**向地面开火——射程随深度递减，每往下一层覆盖少一格。
- 守城阵亡的领袖永久死亡，留下灵魂碎片（这是清掉弱小领袖、换高端材料的主要途径），基地核心不受影响。
- 结束按表现评级：评分 = 55% 击杀比例 + 45% 传送门保有比例；S / A / B / C 对应奖励 ×1.6 / ×1.3 / ×1 / ×0.7，发物资、经验球和图纸。
- 传送门被打破 = 这一局结束。

## 11. 界面与文字规范

**原则：画面上常驻的字越少越好；玩家不关心的细节藏起来；任何一个设计元素都不能让人问“这是干什么的”。没有用处的元素就不该存在。**

### 11.1 三层信息

| 层 | 什么时候看得到 | 放什么 |
|---|---|---|
| 常驻 | 一直在屏幕上 | 名字、数字、图标、按钮；每条说明最多一句 |
| 详情 | **只有领袖和支援道具**：按住 **Ctrl**（或点右下角「ⓘ」常开） | 领袖技能的完整描述；道具四档品质的效果 |
| 说明 | 鼠标悬浮 / 初见说明卡 / 玩法说明（F1、右下角「？」、标题菜单） | 这个元素是什么、怎么用 |

- **除了领袖和支援道具，其他一律直接显示全部信息**（部队、建筑、地格、宝物、面板、技能按钮……），没有 Ctrl 这一层（用户裁定 2026-09-24）。部队本来就只有一句话，见 §7.3。
- 代码里：领袖的视图用 `this.D(常驻, 详情)`、模板用 `data-detail`；悬浮说明用 `ctrl: true` 标记；道具的悬浮说明用 `ctrlLines: true`（一句话常显，品质行只在 Ctrl 时显示）。其他地方不要用。
- **悬浮说明“图标为主”**（`src/mc-tipcompact.js`）：领袖的悬浮说明平时只显示标题和图标行，最后一行是蓝色闪烁的「按住 Ctrl 显示详细信息」，按住 Ctrl 才展开技能；其他悬浮说明图标行和文字一起显示。部队的悬浮说明 = 名字 / 职业、战斗力 / 一句话。悬浮说明可以提供 `briefTitle`（简版标题）、`brief`（图标行：图标 + 数字，或血条）和 `pic`（头像 / 物品图）。例：领袖 =「Lv2 驱魔修女」/ 血条 1864/1870 / 技能图标 + 名字 / 闪烁「按住 Ctrl 显示详细信息」/ 有天赋点时再闪烁一行「有 N 个天赋点可用」，按住 Ctrl 时技能展开成完整描述、Ctrl 那行消失，其余不变；部队 = 名字 / 职业图标 + 职业、战斗力 / 一句话；地格 = 地格图标 + 名字 / 契合的功能或风格图标。
- 夜市部队卡牌：头像、名字、职业图标 + 职业、战斗力、一句话、价格。面板里地格显示为「地格图标 + 名字 + 契合图标」+ 一行效果。
- Mac 上按住 Ctrl 点击会被系统当成右键，此时不触发“返回”。
- 费用、耗电、天数用图标 + 数字，不写“物资”“天”这类字。

### 11.1b 文案规则（用户裁定 2026-09-24）

例：房间角上的风格图标。**错**：「中世纪 / 建筑风格 / 建筑风格：地格和奇观写着契合某种风格的时候，风格对上的房间才有额外效果 / 这个房间：酒馆」。**对**：「[图标] 中世纪 / 该建筑具有**中世纪**风格」。

1. **只说眼前这一个东西在这里是什么、做什么**，一句话，关键词着色。
2. **不在单个说明里讲整个系统的规则**：规则写在初见说明卡和玩法说明里，只写一次。
3. **不写标题已经说了的类别**（「建筑风格」「宝物 ·」「特殊地格」），**不重复屏幕上已经有的东西**（标题、图标、按钮上的费用、芯片上的射程）。
4. **不写操作教学**（「点击……」「悬浮查看……」「按住……」）；交互自己说明自己。小游戏的操作提示除外。
5. **功能文字里不放氛围描写**（世界的背景描述、建筑的来历）。
6. **面板 = 这个东西的详细信息**，不先复述一遍悬浮说明。有专门操作的房间（招募、锻造、仓库）直接写操作本身：酒馆面板只有一个按钮「花 120 物资，招募领袖」。
7. 空状态一句话（「没有宝物」「没有建筑图纸，出征能拿到」）。

### 11.2 初见说明

- 每个设计元素在 `src/mc-guide.js` 的 `CONCEPTS` 里有一条：图标、名字、**一句话**、它在屏幕上的位置。
- 这个元素第一次出现在屏幕上时，旁边弹出一张说明卡（高亮框指向它）；点一下就知道了，每台设备只弹一次。战斗中的说明卡会暂停战斗。
- 所有说明卡都收在「玩法说明」里，随时能查。
- **新增任何元素（图标、标签、资源、按钮、数值）时，必须同时加 `CONCEPTS` 条目和悬浮说明**；说不清用途的元素不加。

### 11.4 操作

### 11.5 视觉：Pixel Juice（2026-09-24）

**硬边**：3px 墨色描边，无圆角，无模糊阴影 / 发光（发光改 3px 硬边光圈），渐变只用硬色带（画布用 `M.UI.lg / rg` 取 4–5 段）。投影一律实心：面板 12px、卡片 9px、按键正下 9px。字影 3px 墨；≥52px 的标题用 8 向墨描边 + 下 6px。动效一律 `steps()`。

**字号阶梯**（舞台 1920×1080 像素）：18 标签 · 20 次要注 · 22 说明 · 24 列表副字 · 26 正文 · 28 小标题 · 30 条目名 · 32–38 按键 · 40 面板标题 · 44–48 主按键 · 52–56 大数字 / 大标题 · 60–64 招牌 · 72 结算总数；演出大字可到 96–180。字体三层：
- 正文：Fusion Pixel 12px Proportional SC（OFL，jsDelivr/Fontsource 加载，离线回退 Noto Serif SC），不加粗。画布文字同样换成它。

- 机台数码 `<mc-num v="…">`：手绘 5×7 点阵数字（0–9 + − × = % . , : / k m v），墨描边 + 顶部高光 + 底部暗阶；数值变化时白闪一帧 + 放大回弹（4 步）。不支持的字符回退为 Silkscreen。

## 12. 存档与日志

- **玩法日志**（只有玩法数据，不含个人信息）：
  - Claude Artifact 版：自动上传到该 Artifact 的共享数据库（集合 `tele`）。

## 13. 维护规则
