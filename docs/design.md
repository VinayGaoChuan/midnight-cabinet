# 午夜机台 · 设计文档

> 这是游戏唯一的策划文档。**改设计 = 在同一次提交里改这份文档**：加减系统、改规则、改关键数值、加新元素，都要同步到这里（维护规则见文末）。数值的最终来源是代码；这里写规则、意图和关键数值。

## 1. 一句话

深夜的公寓里有一台午夜机台。投币后你在地下挖出一座基地，你的领袖（你的化身，只有一个）穿过主基地的传送门去异世界探险，把物资和图纸带回来，地下每建一座房间，地面上就升起一座建筑，城镇越来越繁荣；每 5 天守一次城——直到基地核心的三颗心用完，或者主基地被攻破。

**核心体验**：出征时“要不要再往前走一步”的贪心和风险；回到基地后“这次带回的东西怎么用”的规划；守城时“城墙和塔够不够”的准备。

## 2. 三层循环

| 层 | 在哪里 | 做什么 | 一次多长 |
|---|---|---|---|
| ~~房间~~（**已屏蔽**） | 午夜机台所在的房间 | 用代币买家具（永久加成）、选卡带、看成就 | — |
| 基地（局外） | 地下基地 | 按天推进（顶部时间轴）：挖掘、建造、选世界出征或休整一天、日程事件、每 5 天混沌来袭 | 十几天到几十天 |
| 一次出征（局内） | 异世界的一章 | 从这一章最近点亮的路标出发，一站站往前走：战斗、夜市、奇遇；打倒首领点亮路标，想走多远走多远，撤离或通关带着收获回基地 | 一整章 24～36 站（约 30～45 分钟），也可以打一两个首领就撤离 |

一局结束的条件（任一）：
- **基地核心的心用完**（用户裁定 2026-09-26，恢复）：核心整局 3 颗心；探索失败时献出一颗复活领袖（§6.1），通关一个场景补回一颗（不超过 3）；探索失败时已经没有心可献，这一局结束。
- **主基地被攻破**：守城时主基地耐久打光。

**当前流程（2026-09-24 起）**：开场动画（§10.3，2026-09-26 重做：雨夜外景 → 走廊 → 恶魔脸老虎机）结束时镜头停在老虎机屏幕上，机台屏幕上直接显示「开始游戏 / 继续」「玩法说明」「设置」（没有单独的标题页）；点开始游戏，镜头钻进屏幕 → 基地。基地是局外，出征是局内。一局结束时弹出结算（原因、坚持的天数、通关的世界数），可以「重新开始」或「回到标题」。基地右上角有「放弃」按钮：确认后清空这一局的所有进度（基地、领袖、建筑、物资、天数），从第 1 天重新开始；新手教学不会再出现，设置保留。
- **第一次输掉一局之后机台才展开**（用户裁定 2026-09-26：「机台物中的东西，只有第一次失败后，才会展开，否则没有意义，也会让每个玩家觉得太多，太复杂」）：从没输过的玩家看到的机台和以前一样；第一次核心碎了或主基地被攻破（「放弃」不算），倒下的领袖留下一张遗像，机台屏幕上多出「遗像墙」，之后每开新的一局先到「投币前」选领袖、卡带和遗像（§4）。
- **重新开始送序章奖励**（用户裁定 2026-09-24）：打过序章之后的每一局新游戏（放弃、结算后重新开始）都直接拿到序章结算给的东西——物资、碎片、经验球、领袖经验、找到的图纸（按玩家自己那次序章实际拿到的记在档案里；更早的档案按常见值：物资 +100、领袖经验 +100、1 张随机图纸）；序章教你盖的**酒馆已经建在主基地左边**，不用再盖。
- **新手引导暂时去掉**（用户裁定 2026-09-24：太乱，之后重新设计）：没有引导气泡、没有基地教学步骤、建筑建成后的提示也没有；初见说明卡不再自动弹出（「玩法说明」里仍能查到每一张）。序章还是第一次出征，只是不带提示；序章结束时酒馆直接建好（不再给酒馆图纸）。

房间系统（代币、家具、成就、卡带、月相、噩梦模式）目前**屏蔽**（`M.META_ROOM = false`，在 `src/mc-meta-a.js`）：家具和成就的加成全部不生效，下面 §4 的内容保留作为以后恢复时的设计。

## 4. 机台（第一次输掉一局后展开，`src/mc-legacy.js`）

以前设计的房间层（家具、月相、噩梦模式、旧成就）一直屏蔽，2026-09-26 换成下面这一层；家具的永久加成不做（加成太多太乱，还会让每一局越来越容易）。房间场景本身（开场的公寓和机台）照旧。

- **什么时候出现**：一局输掉之前什么都不出现；第一次输掉（核心碎了 / 主基地被攻破，「放弃」不算）后，结算面板写「机台屏幕上多了『遗像墙』」，机台屏幕上多一个「遗像墙」，开新的一局先到「投币前」。
- **遗像**（参考《邪恶铭刻》的死亡卡）：一局输掉时，倒下的领袖卡摊在桌上，从它学会的天赋里（最多列 5 个，层数高的在前）选一个刻进遗像，也可以不刻；没学过天赋就没有遗像。遗像挂在遗像墙上，最多 6 张，多了最旧的一张掉下来。开新的一局可以带一张：新领袖开局就有这个天赋（不占天赋树，按遗像上的层数算），和遗像同一职业再多 1 个天赋点；带走的遗像就用掉了。领袖的悬浮说明里写「遗像 天赋名：效果」。
- **投币前**：一块面板三行——领袖（已解锁的六选一，没解锁的写解锁条件）、卡带（插一盘或不插；没买的写价格，点一下用代币买下）、遗像（带一张或不带）；右下「投币」，镜头钻进机台屏幕开始新的一局。默认选中上一次的领袖和卡带。
- **领袖解锁**：守夜人、驱魔修女、焚尸人开局就有；玩过的职业一直开着；另外三个靠一件事：赌徒寡妇——FEVER 转出一次传说效果；屠宰场主——累计让 3 支部队进化；钟表匠——守住第 15 天的混沌来袭。2026-09-26 以前输过的玩家六个都开着。机台展开之前每局的领袖照旧随机。
- **卡带**（代币买一次，永久拥有；每局插一盘）：

| 卡带 | 效果 | 价格（代币） |
|---|---|---|
| 工兵 | 开局已挖通 3 个房间，物资 +100 | 120 |
| 建筑师 | 开局多 2 张稀有以上的建筑图纸 | 200 |
| 征兵 | 每次出征，多一支和开局第一支相同的部队（离进化只差一支） | 200 |
| 专精 | 每个场景的部队池只有 6 种（平时 8 种），更容易进化 | 300 |
| 军火 | 开局多一张工坊类建筑图纸和一张宝物图纸 | 300 |
| 赌徒 | FEVER 槽涨得快 20%，带回的物资少 20% | 300 |

- **代币**：每局结束按结算公式给（投币 20、每天 5、每通关一个世界 40、每个首领 15、每个精英 6、每守住一次混沌来袭 12、每座建筑 5、每张带回的图纸 4、每次奇遇 2；一局 15 天左右约 400～600），成就另给。
- **成就**（附录 D）：每个只给一次代币，达成时屏幕上方提示「成就 · 名字 · 代币 +N」；遗像墙上能看到全部成就和达成情况。机台展开前不计。

## 5. 基地

### 5.1 天数

每出征一次就过去 1 天；也可以点顶栏右边的「☾ 休整一天」不出征直接过一天（用户裁定 2026-09-25 加回来）。挖掘和建造按天推进，生产类建筑按天产出。

**时间轴**（用户裁定 2026-09-24 / 25，`src/mc-timeline.js`）：基地顶栏中间常驻一条时间轴（资源在顶栏左侧，右边是「休整一天」和「放弃」），10 个**圆形的日子节点**，节点之间隔一段距离、中间 3 个小圆点：当前这 5 天和下一个 5 天。每格写「今天 / 明天 / 第 N 天」，有事件的格子画事件图标、边框是事件颜色；过去的日子压暗、盖红「✕」；悬浮一格看事件名和一句话。
- **按 5 天推进**（用户裁定 2026-09-25）：时间轴不是每天滚。过一天（节奏照卡皮的「下一天」，2026-09-26）：今天那格白光一闪（0.25 秒）、盖「✕」→ 两天之间的 3 个小圆点一个一个点亮（每个一声）→ 金色的「今天」圈滑到下一个节点、回弹 → 新的今天白光一闪、跳一下（放大到 1.2 倍 0.15 秒，0.05 秒落回）；节点里平时写日子数字，有事件的画事件图标，下面只在今天 / 明天写字；这一天有事件时，屏幕中间打出事件名和一句话：事件名弹出（0 → 1.1 → 0.96 → 1.02 → 1，约 0.3 秒），下面铺一条事件颜色的底光、一明一暗地呼吸；混沌来袭改成从上面砸下来、略冲过头再站住、歪 4 度，同时红闪、警报、心跳。最后事件名缩到一半、0.2 秒飞回时间轴上的那一格，那一格白光一闪、再跳一下。
- **守完一次混沌来袭，整条往后推 5 天**，这是一场大演出，给下一段的期待感：时间轴放大、落到屏幕中间，屏幕压暗 → 过去的 5 天一格一格盖章掉落 → 整条向左滚 5 格（回弹）→ 新的 5 天一格一格弹进来，有事件的格子爆光 → 中间打出「新的五天」，下面红字写下一次混沌来袭是第几天，那一格一直跳 → 缩回顶栏。显示的这一段记在存档里（`m.tlWin`），所以重进游戏不会重演。
- **事件是来访者**（用户裁定 2026-09-26：「屏幕中间出现一个小画面，画面里面是个NPC造访我的城市的小动画……事件结果，要统一在事件结束后再触发……商店只能买一样东西」，`src/mc-visit.js`）：到了有事件的那天，屏幕中间开一扇像素小窗：夜里的城门，两边火把在跳，月亮、星星、石板路；来访者从城门的黑影里走出来，走到中间站定（商人推着车，占卜师面前浮着水晶球，瘟疫医生周围飘着绿烟，朝圣者捧着蜡烛）。小窗下面弹出这次的内容和选项，**只能选一个**；选的时候小窗一直在动。选完来访者当场做出反应——**高兴**（蹦起来、金币往上撒）、**失望**（头上一朵小雨云）、**施法**（施法动作、一圈星光）、**干活**（挥动工具、尘土）——头上一个气泡说一句话，然后转身走回城门、小窗收起。**小窗收起以后，选的东西才生效**：付钱、东西进仓库、下一次出征的祝福进「待生效」。演出时点小窗外面的暗处可以加速。

| 事件 | 来访者 | 选项 |
|---|---|---|
| 混沌来袭 | —— | 每 5 天一次（第 5、10、15…天），守完往后推 5 天；进入守城 |
| 流浪商人 | 推着车的商人 | 随机 3 件货只能买一件（用户裁定 2026-09-26「商人的物品应该是随机」）：从建筑图纸（普通 / 稀有收物资，史诗 / 传说收碎片）、宝物图纸（只在有工坊时）、眼下用得上的纪念品里按权重随机抽；或者不买 |
| 占卜师 | 摇着水晶球的占卜师 | 从 7 种祝福里随机给 3 种选一：部队攻击 +20%、带回的物资 +50%、视野 +2、每场战斗初始积分倍率 +0.5、领袖出发时回满生命、掉图纸的概率翻倍、FEVER 槽涨得快 30%（下一次出征生效） |
| 疫病 | 瘟疫医生 | 治疗（40 物资）；或者硬扛，领袖失去 30% 生命 |
| 丰收 | 天没亮就打鸣的公鸡 | 干活：所有挖掘和建造推进 1 天；撒一把米（30 物资）：推进 2 天 |
| 朝圣者 | 捧着蜡烛的朝圣者（有信仰值以后才会来） | 留他过夜：信仰值 +8；捐一笔香火（60 物资）：信仰值 +24 |

- **每 5 天有 2 个事件**（用户裁定 2026-09-25：旧版每天四成的随机太稀，常常一整段只有混沌来袭）：每一段 5 天里，除了混沌来袭那天，从剩下的日子里随机挑 2 天，各放一种不同的事件（按权重：流浪商人 5、占卜师 4、丰收 3、朝圣者 3（有信仰值才会排）、疫病 2；招募日随着单领袖一起删掉了，勘探队随着地形一起删掉了）。事件提前一段生成，存在存档里（`m.evs`），所以看到的就是会发生的。第 1 天不放事件。
- 旧存档（用户裁定 2026-09-25）：读档时按新规则把之后的日子重新排一次（`m.evV` 记版本），已经发生过的事件不动。

**待生效的效果**（用户裁定 2026-09-25，`src/mc-timeline.js` 的 `M.pendingFx`）：纪念品和事件留下的「下一次……」效果，在顶栏下面左侧排成一行，每个一格（图标 + 一句短话，悬浮看全句），用掉就消失：占卜师的祝福（下一次出征）、迷踪粉（下一次混沌来袭怪物 -30%）、战鼓（下次出征每场战斗开局 FEVER 槽 30%）、工匠（下一项工程少 2 天）。

**回到基地的顺序**（用户裁定 2026-09-24）：先结算（物资、碎片、图纸、信仰值飞进顶栏，纪念品生效）→ 领袖阵亡（撕卡，核心受损）→ 领袖升级（升级仪式，接着弹出天赋页，§6.3）→ 建筑建成（每座一次）→ 下一天（时间轴滚动）→ 这一天的来访者 → 如果这一天轮到混沌来袭，进入守城。一件放完再放下一件（`src/mc-home.js` 的队列，按游戏帧推进）；这段时间不能出征，**也点不动基地的其他地方**（用户裁定 2026-09-26：「动效播放的时候，是不能点击基地的其他地方的……很影响爽感节奏感」）：整个基地上面盖一层透明的锁（顶栏、时间轴、房间、领袖卡都点不到），点它只会让演出加速；要你回答的时候（来访者的选项、升级后的天赋页、守城选将）锁自己让开。收获飞进顶栏时，**数字跟着每个图标落地一点一点涨**（不是等全部飞完才变）；图纸一律飞进主基地（仓库）那个房间；任何飞行的图标都落在屏幕里（用户裁定 2026-09-25：以前守城后图纸会飞到屏幕下面去）。
- **演出别拖**（2026-09-27，机器人试玩量出来回家一趟基地要锁 20 秒左右、最长 40 多秒）：收获飞入 1.6 秒；建成的房间在同一拍里一个接一个亮（每个隔 0.26 秒，最多 1.9 秒，以前每个 1 秒）；升级仪式 3 秒（展开新天赋层再加 1.6 秒）；有事件的日子翻日历 2.3 秒，「新的五天」4.4 秒；扩张每格 0.11 秒、收尾 1.7 秒；来访者进出各快了约 0.4 秒；发展方向的光墙 2.7 秒。演出里点一下仍然 3 倍快进。

### 5.2 挖掘与建造

- **主基地在地面上**（用户裁定 2026-09-25）：一座带传送门的仓库大楼——中间的拱门就是传送门（点它选世界出征），两翼是仓库（点它看物资、图纸和宝物），怪物混沌来袭时攻打的就是它（主基地耐久）。地下还是网格里的功能房间；原来地下第一排中间的主基地房间变成「升降井」，连着地面的主基地，点它也能打开仓库；挖掘只能从它和已有房间旁边开始。基地平时的镜头把地面的主基地和整片地下都放进画面。
- **地面城镇**（用户裁定 2026-09-26 / 27，`src/mc-town.js`、`src/mc-townlook.js`）：地下每建一座建筑，地面就升起一座对应的建筑——建成那天它从地里拔起来（地面裂开、土块飞溅、晃着升起），在建的房间地面上是脚手架。所以地下建得越多，地面越繁荣。
  - **有景深、错落、连成一片**（用户裁定 2026-09-27：「现在的建筑样式好像是一个一个横向排列的，非常丑……要有景深，错落有致，满满的要越来越像一个整体」）：主基地后面是**三条街**，一条比一条靠后、越往后越小、越蒙在夜色里（基线 y −30 / −70 / −110，缩放 0.84 / 0.7 / 0.58）。每座民用建筑去「目前最短的那条街」接着排（高的奇观偏向后街），所以三排交错、天际线高低起伏；品质越高越靠近主基地，城市从主基地两翼后面一直绕出去。街上空着的地方由**市民的房子**补满（每条街都盖到最长那条的长度，繁荣度每升一级城市再往外长一点），街上摆着路灯、摊位、树之类的**街景**；地面铺成一整片街区，后面是城市的**天际线**。这些都随**发展方向**变（§5.3）。
  - **民用建筑是背景**（用户裁定 2026-09-27：「所有非战斗类建筑都是背景，不会被攻击，无法被点击」）：怪物从它们前面走过去，不打它们；悬浮、点击都没有反应（管它要点地下的房间）。
  - **战斗建筑在最前面**：城墙、守望古树、防御塔、兵营、防御罩站在主基地前面的两道战线上（y −6 / −22，前后错开，不平铺在地上）：防御罩和兵营挨着主基地，防御塔均匀铺满整个城市，最外面是城墙（两道城墙一前一后、叠一点），最坚固的在最外面。只有它们会挨打、会倒；它们能悬浮、点击，和点它的地下房间一样（防御塔会在地上画出射程）。

### 5.5 信仰值与宗教（用户裁定 2026-09-26，`src/mc-faith.js`、`src/mc-religion.js`）

「建造信仰类建筑会解锁，从此，常驻资源中就有信仰值了（他会有自己的用处），局内就可以通过某些方法收集信仰值，而如果不建这类建筑，就不会出现信仰值」。

- **宗教**（用户裁定 2026-09-26：「信仰值的设定需要再调整一下，没有人朝着打不过去玩的。我想信仰值可不可是升级宗教的资源，到了数量自动升级宗教，n选1，当前有几个宗教建筑，就能从每个信仰建筑中，随机抽取一个，该宗教的效果，构成n，（具体效果你自己设计），没有品质和等级之分，从池子中全随机」）：信仰值只用来升级宗教。以前的「出发前祈福」和「复活仪式用 30 信仰值代替一颗心」都删掉了。

### 5.6 首领建筑（用户裁定 2026-09-26，`src/mc-bossbld.js`）

「不一定非要是专属宝物，可以是boss的专属建筑，例如精灵女王雕像之类的」——这个游戏的掉落是图纸。每个区域的最终首领有一座自己的建筑，**图纸只从它身上掉**：每次打倒它，普通 10% / 噩梦 16% / 地狱 24%（今日修饰「老兵」翻倍），已经有了（建好、在建或图纸在仓库）就不再掉。这是反复刷同一个首领的理由。
- 每座属于一个大类，比同类的传说建筑略强；品质按传说算，建造要物资、天数和碎片，和别的建筑一样。
- **雕像**：地下房间的中间一座底座，上面立着这个首领的石像或铜像——就是它自己的像素形象（战斗里的那一帧）换成石头或青铜的色阶，头顶一束冷光（石像）或暖光（铜像）；地面城镇上也是一座底座上的同一尊像。

## 6. 领袖

### 6.1 基本

- **只有一个领袖**（用户裁定 2026-09-25，`src/mc-solo.js`）：它就是玩家的化身，出征的指挥官；守城时站在主基地屋顶指挥，不参战（用户裁定 2026-09-26）。**没有品质**，**等级上限 20**（领袖详情里写「Lv 5 / 20」）。每开一局新游戏，职业随机；第一次输掉一局以后改成在「投币前」从已解锁的职业里选（§4），还可以带一张遗像。没有招募、没有领袖上限（招魂台、酒馆、扩建、巨石阵保底、吴哥窟上限这些全部删掉或改成别的效果，见附录 A）。
- **出征失败 → 复活仪式**（用户裁定 2026-09-26，`src/mc-revive.js`）：这一趟的收获丢掉，只留下一半经验（2026-09-26：输了也往前走一点），带着的宝物不丢，照样过一天；回到基地后先演一场不能跳过、不用操作的复活：领袖的卡飞到屏幕中间，越绷越紧、心跳越来越快，撕成两半（「领袖倒下」）；守夜的主教从左边走进来，六根蜡烛一根根点亮，他举着法杖一句句念悼词（「长夜还没有结束，灯还亮着。」「机台记得每一个没有回来的人。」「以核心的一颗心，缝好你的名字。」「醒来吧，驱魔修女。」；这是最后一颗心时第三句是「这是核心的最后一颗心。」）；顶栏基地核心的一颗心离开，拖着红色的尾迹划一道弧飞进两半卡片中间，跳三下，红线把两半缝起来，缝口变成金色；白光一闪，大字「复活」，写着「基地核心 N / 3」，卡片带着一道金色的疤飞回领袖头像，**领袖满血**。
  - 核心里已经没有心时：悼词第三句是「……核心里，已经没有心了。」，顶栏的核心碎掉，两半卡片掉下去，接着基地爆炸，这一局结束。
  - 序章失败不扣核心、不演仪式。守城时领袖不参战，所以不会在守城里倒下。
- **开局建筑**：新的一局主基地旁边先有一间普通品质的医院（以前是酒馆），领袖每天自己回血。
- 属性：生命、攻击随等级涨（每级 +10% / +12%），天赋和宝物再加。
- 6 种领袖职业（守夜人、赌徒寡妇、驱魔修女、屠宰场主、钟表匠、焚尸人），每种有自己的技能。
- **领袖没有个人名字**：职业就是名字，也代表技能——同一职业永远是同一个技能。每个职业有自己的职业图标。
- **基地领袖卡片**：左上角角标「Lv2」；半身像；下面只写职业名；血条；右上角黄点 = 有没用的天赋点。左下角只有这一张，不再写「领袖 1 / 6」。
- **生命不会自动回复**：营火、奇遇、医疗建筑、地下泉。
- 旧存档（2026-09-25）：多名领袖只留等级最高的一名，品质去掉，天赋树按新的样子重长、点数全退；经验球全部变成它的经验；招魂台 / 酒馆变成医院，这两种图纸按 60 物资一张退掉。旧存档（2026-09-26）：基地核心补满 3 颗心；繁荣度按已经挖开的范围给到足够的级别，已经挖开的地块都不会变黑；主基地耐久按比例换算到新的基数。

### 6.3 成长

- **经验直接给领袖**（用户裁定 2026-09-25）：出征回来、守城结束、每天的训练类建筑，经验直接加给领袖，够了就升级并播放升级仪式；没有经验球，也没有「升级」按钮。每级 1 个天赋点，满级 20。
- **升级后直接选天赋**（用户裁定 2026-09-26：「英雄升级后，应该直接弹出升级选择技能的页面，如果解锁新技能了，那就播放解锁新技能的效果。如果玩家不想现在就选择天赋，可以点击取消，如果选择完了，没有天赋点了，或者没有可用天赋了，那也算取消，然后继续推进其他结算效果」，`src/mc-home.js`）：升级仪式放完（这一级展开了新的一层天赋时，仪式最后一段先演这一层一个一个弹出来），马上打开这名领袖的天赋页，基地压暗，左下一个「取消」。按住学天赋；点数花完或者没有能学的天赋，页面自己关上；点「取消」（或 ✕、Esc）就以后再学。页面开着的时候，后面的结算（建筑建成、换日、来访者……）都等着。从天赋页里自己点升级的，不再另外弹。
- **天赋树**（用户裁定 2026-09-25，参考《英雄无敌》的副技能，`src/mc-talent.js`）：每名领袖一棵**自己的随机树**，根是它的技能。
  - **分层**：第 1 层的格子只会随机到第 1 层天赋，第 2 层只会随机到第 2 层天赋……同一种天赋，层数越高数值越大（第 1～6 层 = 第 2 层数值的 ×0.7 / ×1 / ×1.35 / ×1.75 / ×2.2 / ×2.7），有的天赋只在高层出现（神秘术、狂怒、宝物大师、建筑学、招魂术、集结、统御……）。点一个天赋要先点它下面连着的那个。
  - **树的样子**：只有一个领袖以后，它总是长最高的那种树（6 层，19～23 个天赋）；下面是以前按品质分的形状：普通 3 层（每层 2～3 格，6～8 个天赋）、稀有 4 层（10～12 个）、史诗 5 层（14～18 个）、传说 6 层（19～23 个）。每层从上一层的格子里长出 0～2 个分支（根上最多 3 个），所以有的枝往上长、有的就停了。一棵树里不会有和父节点、子节点、兄弟节点重复的天赋。
  - **每三级一层**（2026-09-25，满级从 10 提到 20）：第 k 层在 Lv 3k−1 展开（Lv2、5、8、11、14、17）；还没展开的下一层只显示成一排「?」，左边写「LvN」。升级仪式最后一段专门演这一层：「第 N 层天赋」，这一层的天赋一个一个弹出来，下面写名字（颜色 = 作用范围）；之后第一次打开这名领袖的详情，新的一层也会弹出来。
  - **大小自动缩放**：树框里只画展开的层 + 下一层的「?」，层越少格子越大（最大 72），6 层时缩到 44；左边是层号，底下是颜色说明「领袖 部队 出征 基地」。格子小的时候不在每个格子下写「按住」，右下角统一写「按住发光的天赋学习」。
  - **作用范围**写在每一句里，颜色也不同：**领袖**（金，只作用于这名领袖本人）、**部队**（红，这名领袖出征时带的部队）、**出征**（青，这名领袖出征时的收获和地图）、**基地**（绿，这名领袖活着就每天生效，作用于整个基地或所有领袖）。例：「好体质：本领袖住院时，每天回复的生命 +50%。」（原来的「医院疗养速度 +50%」说不清是谁的，用户裁定 2026-09-25）。
  - **有的天赋改变打法**：考古学（掉图纸的概率 +x%）、集结（每有 1 支某职业部队，全体攻击 +x%，鼓励堆一个职业）、混编（每有一种职业，全体生命 +x%，鼓励混搭）、征兵术（开局多带某职业部队）、赏金（精英战、首领战积分 +x%，鼓励走精英）、货郎（卖部队的商店多摆几支）、热身（每场战斗开局 FEVER 槽已经有一截：层数越高越多）、寻宝术（宝箱积分 +x%）。每棵树至少有 1 个这类天赋和 1 个基地天赋（10 格以上的树各至少 2 个）。
  - 完整的天赋表见附录 E。旧存档：旧的三条路线整棵换成新树，学过的天赋点全部退回（用户裁定 2026-09-25）。
- **宝物条目写清作用对象**（用户裁定 2026-09-25，和天赋同一个问题）：「部队暴击率 +x%」「领袖每场战斗后回复 x% 生命」「打仗得到的物资 +x%」「领袖出征得到的经验 +x%」「奇遇出好结果的概率 +x%」……；「领袖技能冷却 -x%」换算成节点：约 7% 起少 1 个、约 40% 起少 2 个（旧版不到 17% 的条目实际不起作用）。
- **宝物**（13 种）：出征时带在身上。锻造建筑里用宝物图纸 + 120 物资打造，品质随机；精铸多花 40 碎片，至少史诗。宝物格数量随领袖和建筑增加（紫禁城、王座遗骸 +1）。

## 7. 出征

### 7.1 选世界

- **没有世界列表页。** 传送门平时是一座暗的石拱门，没有漩涡。点它 → 传送门打开（漩涡转起来），上方升起今天能去的世界**碑**（石碑造型，参考《暗黑地牢》的区域牌）。第一块是当前章节（难度低），后面是刷图碑（中、高），见下面的「碑」；第二天换一批修饰和刷图目标。
- 碑上有三样东西：**场景名**（最上面）、**难度**（骷髅 + 低 / 中 / 高）和**特产图标**。悬浮碑看详情：标题「世界 · 场景」，第一行是难度和它给什么（「难度中：物资 ×1.4、经验 ×1.3，图纸更常见、品质更好」），然后场景的故事、「场景 2 / 3 · 3 个首领」、每项特产的效果、「开局的仗约 N，首领约 B」「你出发时约 M」、主题敌人。
- **难度是碑自己带的**（用户裁定 2026-09-25，`src/mc-danger.js`）：以前的「危险度」是拿你的战斗力去比，玩家变强以后所有世界都显示「低」，而且低的世界照样掉高级图纸。现在每块碑固定一个难度，决定这一趟的敌人和收获：

| 难度 | 敌人等级 | 敌人强度 | 物资 | 经验 | 图纸掉率 | 图纸品质（普通 / 稀有 / 史诗 / 传说） |
|---|---|---|---|---|---|---|
| 低 | +0 | ×1 | ×1 | ×1 | ×1 | 82 / 15 / 2.6 / 0.4 |
| 中 | +0.6 | ×1.05 | ×1.4 | ×1.3 | ×1.3 | 55 / 32 / 11 / 2 |
| 高 | +1.2 | ×1.1 | ×1.9 | ×1.7 | ×1.7 | 28 / 38 / 25 / 9 |

- **章节、区域、路标**（用户裁定 2026-09-26：先是「世界分场景，每个场景一个最终首领」，然后「要做成暗黑破坏神 2 那种体验：从第一章打到最后一章，还愿意打不同难度，还愿意同一难度反复打」；`src/mc-scenes.js`）：
  - **一个世界 = 一章**，按顺序打：雾中小镇 → 精灵之森 → 废弃游乐园 → 沉没港口 → 蒸汽铸造厂 → 深夜医院 → 星舰残骸 → 地狱 → 地下赌场。上一章通关，下一章才出现。
  - 一章由几个**区域**首尾相连（精灵之森：德鲁伊 → 知识古树 → 精灵女王），每个区域有自己的故事；一个区域 = 一段路 + 小首领，再一段路 + 这个区域的**最终首领**（金库多一段）。20 个区域、20 个最终首领见附录 G。
  - **路标**：每打倒一个首领（小首领或最终首领），这一章就点亮一个路标，**马上记住**（这一趟后面输了也不丢）。下次再来这一章，从最近的路标出发：先到一家卖部队的店，手里多一笔按跳过的路程算的积分（`M.CHAPTER_GRANT` 0.33 × 跳过各站的敌人预算之和），组好部队接着往前走。**打过的内容不用再打**——这是解决中期重复的办法（2026-09-26 的模拟里，机器人把同一个场景的前半段反复打了七八次）。
  - **想走多远走多远**：一趟出征可以一口气打完整章，也可以打一两个首领就从撤离点走。**连战**：同一趟里每打倒一个首领，撤离或通关时带回的物资和经验 +15%——越往前走越值，但死在路上就全丢。
  - 打倒区域的最终首领：基地核心 +1、固定 1 张建筑图纸、按难度有概率掉它的**首领建筑图纸**（§5.6）。打倒一章最后的首领 = 这一章通关。
- **碑**：第一块碑永远是**当前章节**（从最近的路标出发）；通关过的章节会出现在后面的碑上，是**刷图碑**——从某个区域最终首领之前的路标出发，直奔它去（第 1 天 1 块碑，第 2～5 天最多 2 块，第 6 天起最多 3 块；一章都没通关时只有当前章节）。碑上写起点的区域名；悬浮看「第 N 章 · 世界 · 区域」、区域的故事、从第几个路标出发、这一章还剩几个首领、今日修饰。
- **今日修饰**（每块碑当天随机一个，让同一章每次走起来不一样）：浓雾（视野 -1、敌人生命和攻击 -8%）、血月（每段多一场精英战、图纸掉率 ×1.5）、丰收（物资 ×1.5）、授业（领袖经验 ×1.4）、悬赏（每场初始积分倍率 +0.3）、老兵（敌人 +10%、暗金宝物掉率翻倍）。
- **小首领有固定的名字**（用户裁定 2026-09-26：「每个小boss都要有个固定的名字，例如天马，虫王之类的，这样玩家在聊天的时候，能说自己打到哪个小boss了，而且小boss头顶要顶上自己的名字」）：每个区域一个（金库两个），外形和名字固定，见附录 G。名字写在它头顶（酒红底、金字的名牌），也写在屏幕顶上的首领血条上、地图的首领节点上（看得见时）；入场时直接顶着名牌落地，不再另打一行「首领 · …」。
- **敌人强度看你走到了故事的哪里，不看天数**（用户裁定 2026-09-26：「英雄的成长远不如每天敌人变强的速度」「哪天没打过去，后面就一直打不过了」）：章节等级 S = 世界难度（1 / 1.6 / 2 / 2.4 / 3 / 3.2 / 4 / 5 / 6，按章节顺序）+ 难度档（噩梦 +5、地狱 +10）；一章的第一站敌人等级 0.7 + 0.55 × S，最后一站 2.6 + 1.25 × S + 0.16 × 24（按标准章节长度算，长的章节只是爬得慢，所以后一章不会比前一章的结尾还弱；普通上限 14、噩梦 21、地狱 28），中间均匀爬升——从路标出发时，敌人从这一章那个位置的等级开始；敌人生命和攻击 ×（0.88 + 0.12 ×（S − 1））× 这一章的系数（`M.CHAPTER_EK`，§8.2）× 碑的强度 × 今日修饰。某天输了，第二天同一章同一个路标一样难，不会越拖越难。**只有混沌来袭**（守城，§9）还跟着天数长——那是催你往前走的钟。
- **特产**：物资 / 经验 / 积分倍率、FEVER 更快、宝物图纸、战后回血、高品质图纸、灵魂碎片，以及建筑图纸偏向的大类（§5.4）。
- **选完碑直接出发**（用户裁定 2026-09-25）：仓库里没有宝物就不弹出发面板，碑落进传送门就走；有宝物才弹，默认勾好上一次带的，可以改也可以直接点出发。
- **点别处先退出**（用户裁定 2026-09-25）：传送门开着的时候点领袖卡、房间或打开任何别的面板，传送门先自己关上，不会叠在一起卡住；选中的碑如果因为别的事没能打开世界，1.6 秒后自动放开。
- **选中一块碑**：碑先抬起、砸进传送门、碎裂（冲击环 + 碎石 + 闪光 + 震屏），传送门随即展开这个世界的样子：雾中小镇起雾、精灵之森绿意盎然（藤蔓爬满门柱、萤火虫）、废弃游乐园旋转彩条和灯泡、沉没港口水波与气泡（水漫出门槛）、蒸汽铸造厂齿轮咬合和蒸汽、深夜医院鬼魂尖啸着飘出、星舰残骸星光跃迁、地狱血从门楣流下和火焰、地下赌场转盘和金币。然后弹出出征准备（选领袖和宝物）；关掉准备面板，碑重新升起。

### 7.2 地图

- 横向推进的节点图，走过的节点不能回头；岔路用 ↑ ↓（或 W S）或点击选择。
- **视野**默认 2 步（能看清前方 2 步以内的节点）。会被这些改变：监听室 +2、风穴 +1、领袖天赋「侦察术」+1～3、部分世界压低 1（雾中小镇起雾、深夜医院停电、地狱浓烟、地下赌场昏暗）、奇遇（许愿井打中井心附近：+1；落地镜失败：雾漫出来 −1）。最少 1 步。地图顶栏的眼睛图标显示当前视野，悬浮列出每一项来源。
- **战斗力一目了然**：每个看得见、还没打的战斗（普通、精英、首领、坚守、撤离）头上都有它的敌方战斗力，颜色按胜算：绿 = 我方 ÷ 敌方 ≥ 1.25（稳赢），黄 = 1～1.25（有风险），红 = 低于 1（很危险）。领袖小人头上是我方总战斗力（徽章贴近模型头顶，一眼能看出是谁的）；领袖面板里也有我方战斗力和视野（不和收获放在一行）。悬浮战斗节点还会写「敌方战斗力 N · 我方 M · 稳赢 / 有风险 / 很危险」。每场战斗的敌人在第一次被看到时就定下来，显示的就是你要打的那一仗。
- **地图随机生成**（用户裁定 2026-09-24）：每一列有几个节点、怎么连、每个节点是什么，每次都随机；只有下面几条是固定的。
- 首领前一站的商店只卖部队（兵营、难民营、奴隶贩子、法师协会、猎人营地、佣兵团随机一种）。
- **长度由章节定**（用户裁定 2026-09-26）：一张地图就是一章（从出发的路标到这一章结束），由几**段**组成，每段 3 站随机节点 → 卖部队的店 → 首领；前一段是区域的小首领，后一段是区域的最终首领：
  - 一段 = 2～3 列随机节点 → **商店**（只卖部队）→ **首领**。首领前一站一定是卖部队的商店，不管走哪条路都会经过（整列只有这一个节点），给玩家花钱变强的机会。
  - 每段最多 2 个精英战（每列最多 1 个）；全图第一场一定是普通战。
  - **撤离点只出现在首领战后面**：打败一个不是最后的首领后，下一列有一个撤离点（在上方或下方的岔路），其他节点继续往前；走进撤离点坚守一场，带着全部收获回基地。撤离点后面没有路。
  - 打倒一章最后的首领 = 这一章通关（核心 +1）；最后一章通关 = 这个难度通关，开下一个难度（§7.7）。
- 节点 11 种：起点、普通战、坚守战、精英战、首领、夜市、营火、宝箱、奇遇、招募旗、撤离点。随机列里的出现权重：普通战 26、奇遇 16、坚守战 9、宝箱 9、营火 6、招募旗 6、夜市 4（生成后约三成普通战再换成奇遇）。
- 出发时的提示写「世界名 · 起点区域 · M 站」，地图顶栏也写「世界名 · 区域 · 第 N / M 站」。首领节点上直接写最终首领的名字。

### 7.3 部队

- **开战站位按职业**（用户裁定 2026-09-25）：先锋站最前，守护者 / 战士 / 圣骑士（简单防御）在它后面，然后刺客，再后面射手 / 法师，最后面牧师 / 祭司 / 召唤师 / 商人，塔类最后。
- 部队在战斗中自动作战，**不设上限**（用户裁定 2026-09-24），买得起多少就带多少；一列站不下 8 个就往后排成多列。来源：开局部队、夜市、招募旗、奇遇。
- **进化**（用户裁定 2026-09-26：「要三个相同的进化一次，这样变化还多，玩家总期待，下一次能进化成什么，一个单位最多进化5次。这个在教学模式中要有，并且进化的时候，要做伟大的进化效果，并且显示进化后的部队卡」，`src/mc-evo.js`）：队伍里凑齐三支同一种部队（进化次数不到 5 次的），立刻进化成一支新的部队。
  - **进化成什么**：从这个场景的部队池里抽，品质不低于原来的，同职业的机会是别的 3 倍、同种族 1.5 倍、高一档品质 1.6 倍——事先不知道，这是期待所在。进化出来的部队加进部队池，所以再凑两支同样的就能接着进化。
  - **不会亏**：新部队值三支原部队的 110%——它自己的价格不够时，生命和攻击按比例放大（战斗力、卖价也跟着变）；比原来三支加起来还贵时就是赚了。三支里最多次进化过的那支决定进化次数，新部队 +1，最多 5 次；满 5 次的不再参与进化。
  - **标记**：部队栏卡片下面每进化一次一颗金色菱形；战斗里进化过的部队每次大 6%（最多大 30%）。
  - **演出**（约 5.5 秒，点一下 3 倍快进）：屏幕压暗，三支部队从部队栏飞到屏幕中间、绕圈越转越快越转越近、背后光芒按品质一档档爬升 → 合成一团光，在旧样子和新样子的白色剪影之间越闪越快（品质升档时剪影上裂开品质色的裂纹）→ 白闪、冲击圈、碎光爆开，顶上「进化！」和「步卒 → 铁甲战士」→ 中间立起新部队的卡片（进化菱形、部队、名字、职业和战斗力、一句话），停一会儿后缩小飞进部队栏。演出时不能点别的（点击是快进）。
  - **序章里一定有一次**：序章开局带两支步卒，序章的夜市一定摆着第三支；三支步卒进化成铁甲战士。
- **部队池**（用户裁定 2026-09-26：「为了让一局游戏能够买到相同单位，所以每次进入一个场景的时候，先随机本次场景的部队池，所有商店都是从这个池子里随机的」）：每进入一个场景（区域）先抽这个场景的 8 种部队，所有商店、招募旗、奇遇给的部队都从里面来，同一种部队会反复出现。
  - 抽法：品质比例跟着这里商店的品质走，至少一种史诗；至少 3 种前排（先锋 / 守护者 / 战士 / 圣骑士）、2 种射手 / 刺客、2 种法师 / 牧师 / 祭司 / 召唤师，其中有一种便宜的先锋或守护者——所以每种店都有货。一趟出征的第一个场景把开局部队的种类放进去。
  - 走进下一个场景，保留队伍里正在养的种类（按数量和进化次数最多 4 种），其余重抽；屏幕上方提示「新的场景，部队池换了一批」。
  - 地图上小地图下面一排是这个场景的部队池（品质色边框，队伍里已有的种类下面有金色菱形，悬浮看部队）。

#### 7.5.1 小玩法演出（用户裁定 2026-09-25：局内玩法要有表演，调动获得感）

**原则**
1. **结果先定，演出后挑**：概率一点不改。结果在按下按钮那一刻就定了，演出只决定怎么把它端出来——「差一点」「听牌」「升格」都只在结果本来就是这样时才演。
2. **四拍**：预期 → 悬念 → 揭晓 → 回响。赢得越大，悬念拉得越长、回响越响；没中就一拍带过（≤ 0.4 秒）。
3. **舞台会跟着紧张**：听牌时舞台压暗、聚光灯罩住关键的那一格、镜头往里推 6%～10%、灯珠越跑越快、心跳一下比一下急；揭晓的一瞬间全部松开。
4. **每一次揭晓都要连到落点**：奖励从舞台飞进计数器，舞台上同时滚一个「+数字」，滚完计数器鼓一下。
5. 所有长演出都能点一下快进（§11.6），但不会跳过结果本身。

**中奖分四档**（`M.SHOW.win`）
| 档 | 例子 | 演出 |
|---|---|---|
| 1 小中 | 两颗樱桃、押中红黑、普通果子 | 「+数字」滚 0.4 秒、奖励飞出、一圈光 |
| 2 中 | 三连水果 / 铃铛、稀有部队、双倍返还 | 加一记炸光、灯珠快闪、「+数字」滚 0.8 秒 |
| 3 大赢 | 三个 BAR、史诗、骰子全胜 | 画面停一拍、白闪、光芒、金币喷泉、「大赢」章砸下、灯珠换色频闪 |
| 4 大奖 | 777、押金中了、传说、一次清空奖池 | 先黑场 0.2 秒 → 聚光 → 「大奖」逐字砸下 → 满屏金币雨和彩纸 → 计数器越滚越快、音调越来越高，约 2.5 秒 |

没中（`M.SHOW.lose`）：舞台灰一下 0.25 秒、一声轻响、灰字，马上可以再来。**差一点**（`near`）：落空但离大奖只差一格时，那一格在线外抖一下，打「差一点！」小章——同样一拍带过，不拖。

**悬念工具**（`M.SHOW`，文件 `src/mc-show.js`，每个小玩法共用）
- **听牌 reach**：压暗 + 聚光 + 推镜头 + 心跳 + 「听牌！」牌子；超级听牌（可能出大奖）换红金色、边框频闪、「超级听牌」。
- **慢动作 slowmo**：最后一段按 0.3～0.5 倍速（弹珠落进最后一排钉子、娃娃被吊到出口上方、骰子在棱上打转）。
- **一格一格挪 crawl**：转盘 / 滚轮最后几格一格一响、音调往上爬，最后一格停得最久。
- **滚轮的转和停**（照卡皮的老虎机，2026-09-26）：滚轮不是一路慢慢减速，而是拉杆后机箱往上跳两下、滚轮 0.15 秒起速后一直全速转（带拖影：图案竖着拉长、身后拖两道残影），到点正好转到结果那格时猛地停住，往前冲一点再往回弹（0.33 秒）。要再往上挪一格时先冲出去三分之一多、再慢慢挪到位、略过头一点再回来。
- **预兆 omen**：翻牌、砸蛋、开瓶、掀帘之前，东西先亮起它的品质色（白 → 蓝 → 紫 → 金），越好的亮得越久、抖得越厉害。
- **升格 promote**：预兆可以先亮低一档、再裂开升上去（白光一闪、裂纹、颜色跳一档）——只有真实结果更高时才会升，所以玩家一看到裂纹就知道「来了」。
- **连击 combo / 评级 grade**：手上功夫的玩法（温泉、拳馆、乐师、镜子、裁缝、许愿井、招财猫、墓碑）每一下成功都有「GOOD / GREAT / PERFECT」小章、音调逐级升高；连到 5 下进入**狂热**：舞台四边亮起、背景跟着节拍闪；结束时评级章（S / A / B / C）砸下，按评级走中奖四档。

|---|---|---|---|---|---|---|---|

### 7.6 带回

撤离或通关后，本次的**物资、经验、碎片、图纸、信仰值**带回基地；出征失败则这一趟的收获丢掉，只有一半经验留给领袖（领袖和宝物不丢）。此外还可能带回**纪念品**，在基地生效：矿工队、工匠、修门石、启示卷轴、淬火石、安神香、迷踪粉、补给箱、战鼓（见附录 E）。**只掉眼下用得上的**（用户 2026-09-26：「我从局内带回了淬火石，但是我却没有宝物」）：没有能挖的岩层就不掉矿工队、主基地满耐久不掉修门石、没有品质能升的宝物不掉淬火石、领袖没受伤不掉安神香；带回来时已经用不上的，换成物资。宝物和建筑不能直接带出，只能带图纸。
- **图纸从哪来**（用户裁定 2026-09-25：以前图纸掉得太多）：只有两个**固定**来源，各给 1 张随机建筑图纸——打倒一个区域的最终首领、守住一次混沌来袭。其余都是**小概率随机**，建筑图纸和宝物图纸各半（**没有工坊时全是建筑图纸**，§5.4）：普通 / 坚守战 3%、精英战 8%、中途首领 12%、宝箱 10%（撤离战不掉）；乘以难度的掉率（§7.1），再乘以晶簇（+20%）、领袖天赋「考古学」（+20%～100%）、幸运之星的「掉图纸的概率翻倍」、血月、蒸汽铸造厂（常掉宝物图纸，×2）。品质按这一趟的难度（守城按中）。奇遇里明确给图纸的结果照旧。
- **收获一件一件摆出来**（用户裁定 2026-09-24）：地图顶栏里，图纸、纪念品这类稀有收获每件单独一格（图标 + 名字，颜色 = 品质），和积分、物资、经验并排，放不下就换行，不做滚动区。战斗结算的奖励格、出征结束画面的奖励格也一样。
- 悬浮任何一件都告诉你**它有什么用**：建筑图纸 = 那座建筑的一句话（弩炮室图纸：「守城时向地面射击。」）；宝物图纸 = 打造出来的宝物前两条能力；纪念品 = 它的效果（启示卷轴：「带着它回来的领袖获得 1 个天赋点。」）。

- **每种建筑一座**（用户问 2026-09-27：「很多图纸都是重复的，例如医院，我手里有3张了，难道我可以建3个医院吗，效果叠加」）：只有**普通和稀有品质的战斗建筑**（城墙、防御塔、兵营、防御罩、守望古树）可以建很多座——一座城需要好几道墙和好几座塔；其余建筑、以及所有史诗 / 传说 / 首领建筑**每种只能建一座**。已经建好、正在建、仓库里有图纸、或者这一趟已经捡到过图纸的一座一座的建筑，不会再掉它的图纸（换成别的有用的图纸），商人也不卖；多出来的一张（旧存档、别的来路）当天换成物资（建造费的一半），日志里写「多余的医院图纸换成 N 物资」。
- **掉落怎么捋的**（2026-09-27，机器人跑 13 趟统计）：以前每打倒一个首领都必掉一个纪念品，13 趟带回 37 个纪念品、20 张建筑图纸，其中 9 个启示卷轴（白送天赋点）；首领建筑还会从普通图纸池里漏出来。现在：纪念品首领 40%、撤离点 35%、精英 15%、普通战 2%、宝箱 12%（一趟大约一个）；启示卷轴出现的机会降到原来的三分之一，颜色改成普通的米色（原来的金色看着像传说品质）；首领建筑只从它自己的首领身上掉。建筑图纸的品质照旧看难度档：低难度普通 82% / 稀有 15% / 史诗 2.6% / 传说 0.4%，越难越好。

## 8. 战斗

- 敌我同时入场，顶部显示这一仗的名字（普通战 / 精英战 / 首领战 / 最终首领战 / 坚守战 / 撤离战，一个词，不再写「普通战 · 首领」）通告；双方站定、通告淡出后才开打。
- **开战激活**：见 §7.3——每个有特性的单位先亮出自己的特性图标。
- **蓄力与警示圈**（用户裁定 2026-09-26，`src/mc-omen.js`）：我方、敌方、精英、首领，**所有单位放技能都先蓄力，地上亮出警示圈**：外圈是技能的范围（正好是会被打到的地方，所以是 r × r/1.2 的椭圆），里面的颜色从中心往外长，**填满的那一刻技能放出来**。敌人的圈是红色，我方的是技能自己的颜色；打别人的技能从施法者到落点有一条虚线（看得出谁在放、放向哪里），治疗 / 强化落在友军脚下。蓄力时间按品质：普通 0.45 秒、稀有 0.6、史诗 0.8、传说 1.0，精英 +0.2，首领另算（§8.3）——越强的单位蓄得越久、圈越大，看一眼就知道这一下有多重。自走棋里单位不会躲，也没法操作躲，所以蓄力不长，只是给人一个“要来了”的提示。技能打在标出来的那个目标上（蓄力时就锁定）。
- **精英**：精英头顶有一块琥珀色的「精英」牌，一眼分得清哪个是精英（用户裁定 2026-09-26）。
- **法力特性按时机释放**：带法力特性的部队上场时法力已满（法力条边框闪烁），但不会一开场全放——每个特性有自己的**触发条件**，满足才放，放完重新攒。敌人从 0 开始攒法力，用同样的触发条件。触发条件分几类（`src/mc-skilltrigger.js`，每个单位的具体条件见 `docs/characters.csv` 和 `docs/effects.md` 的 U 表）：
  - 治疗类：有友军生命低于一定比例（治疗链 70%、颅骨炖汤 60%）；以血换血类还要求自己生命高于 50%。
  - 近身范围类（禁果）：身边有 3 个以上敌人。
  - 落点范围类（炮弹休克、铁之冰雹、剑雨、剑刃风暴）：射程内的目标附近有 2 个以上敌人扎堆。
  - 群体类（闪电打击）：攻击范围内有 3 个以上敌人。
  - 强化自己类（太阳耀斑、神盾、急速射击……）：敌人进入攻击范围；精神扭曲：攻击最高的友军开始交战。
  - 单体重击类（法力爆裂、小行星、能量涌动）：射程内的目标生命还多（≥ 40%）。
  - 召唤类：有敌人逼近到 600 以内；扣血召唤（次元裂隙）还要求自己生命够扣。
  - 所有“N 个以上敌人”的条件，在敌人总数少于 N 时按剩下的数算，不会因为敌人太少而永远不放。
- **目标**：普通战消灭所有敌人；坚守战撑过倒计时。
- **积分 = 基础积分 × 积分倍率**：击杀得基础分；精英 +0.1、首领 +0.3 积分倍率，FEVER / 宝物 / 特性继续叠加。
- **领袖**站在左边的指挥位，不参战；部队全灭后亲自上场（撤离战一开始就和部队一起上，§6.2）。领袖和首领每出手一次，屏幕震一下（用户裁定 2026-09-26）。
- 操作：空格 领袖技能，P 暂停，F 切换 1× / 2× / 3× 速度。

### 8.0 击退与击飞（用户裁定 2026-09-26，参考《英雄之时》，`src/mc-knock.js`）

- **推多远 = 攻击者的力量 ×（这一下打掉对方最大生命的比例）^0.7 ÷ √对方的分量**。力量看体型和品质（领袖 2.2、首领 2.4），分量看体型、品质、是不是精英（精英更沉，召唤物更轻）。所以强打弱会把人打飞，弱打强几乎推不动——品质差和战斗力差自己就体现出来，不用另外的规则。
- 攻击方式：近战顺着出手的方向推；远程只推一点（×0.55）；技能 ×1.4、暴击 ×1.5、重击 ×1.2；爆炸从爆心往外推（×1.2）。持续伤害（燃烧等）不推。正在施法的单位只晃一下。
- **三种受击，三种样子**（用户裁定 2026-09-26：「击退，击飞，击倒，不同情况，应该用不同表现……击飞应该是击倒加飞起……部队死亡，直接翻跟头同时变白片，效果简直太差了」）：很小——只抖一下；**击退**——站着往后滑，身体顺着受力方向后仰，脚下扬尘，地上留一道擦痕，短暂硬直；**击倒**——短滑一下就被打翻、侧躺在地上，躺 0.6 秒左右再爬起来；**击飞** = 击倒加飞起：往后倒着飞起来（身体向后倒、不翻跟头），落地时躺平、弹一下、一圈尘土，躺一会儿再起身；在空中再挨打会被打得更高。三档都有顿帧、命中爆点和震屏，越重越长；**高两档品质的单位（或精英、首领）打低品质单位时**，命中处多一圈冲击波，震得更狠。
- **死亡**：身体原地倒下（被大招打死的会被抛飞、落地后躺平），闪一下红，冒出几点灵魂光点，然后分 4 档淡出。不翻跟头，也没有白色剪影。
- **朝向**：每个单位面朝自己正在打的目标（有 14 像素的死区，不来回抖），不再是我方永远朝右、敌方永远朝左；冲刺、出手的前冲也顺着朝向。
- 滑出去、飞出去的单位撞上自己人，会把对方也撞开（像保龄球）；撞到场地边上弹回来。
- **领袖和首领永远不会被击退**；它们每出手一次，屏幕震一下（首领更重）。
- 对数值的影响（`.ai/sim-kb.js`，普通 / 精英 / 首领各 400 场，开 / 关对照）：普通战时间 +12%，首领战 +20%；同一个战斗力比值下我方胜率高 5～15 个百分点（我方部队品质高、推得动敌人）。

### 8.1 战斗力（用户裁定 2026-09-24，自己算、说得清）

- **一方的战斗力 = √(全体总生命 × 全体每秒总伤害)**，按战斗里真实生成的数值算：我方 = 所有部队（领袖天赋和宝物、本局加成都算进去，开局护盾算作额外生命）+ 领袖（按当前生命）；敌方 = 这一仗的全部敌人（按天数放大、精英 ×1.15、首领护甲 ×1.3）。
- 单个部队 / 领袖的战斗力用同一个公式：√(生命 × 每秒伤害)。所以整队的数和单位的数是一套尺子。
- **为什么是这个公式**：两队对打时，一方能扛多久看总生命，打多快看总秒伤，双方互相消耗，谁的“生命 × 秒伤”大谁赢（兰彻斯特平方律）。用 3000 场无画面模拟标定（`tools/sim-power.js`，随机阵容、领袖、世界、普通 / 精英 / 首领 / 坚守）：按「我方 ÷ 敌方」排序预测胜负的准确度（AUC）0.96（2026-09-24 职业改版后重测 4000 场；有了前排，阵容搭配本身更重要了）。实测胜率：比值 ≥ 1.25 约 99%，1.1～1.25 约 94%，1.0～1.1 约 80%，0.9～1.0 约 74%，0.6～0.9 约 55%，低于 0.6 约 22%。
- 特性、技能、站位会让结果有出入（比如召唤、治疗、群伤），所以“黄色”区间要看阵容。
- 坚守 / 撤离战只要撑过倒计时，地图上显示的敌方战斗力按全部波次的 0.7 算。
- **首领战的显示系数**（用户裁定 2026-09-25：「两边战斗力一样，结果我碾压了」）：用 300 场无画面首领战和精英战对照标定（`.ai/sim-boss2.js`）。领袖首领战一开始就上场时，首领要乘 0.75 才和精英战同一个意思；现在首领战也是部队全灭后领袖才上场，首领按 1.05 显示——同一个比值在两种仗里胜率一样（1～1.15 都是七八成）。
- **单独的首领**（2026-09-26 起首领战只有首领一个）：用 `.ai/sim-boss3.js` 各 400 场重标——小首领带两招蓄力重击，按 **1.26** 倍显示；最终首领出手慢、部队能沿整条地形边缘打它，按 **0.92** 倍显示（`M.MB_SHOW` / `M.FB_SHOW`）。标完后两种首领和普通战同一个意思：显示 1～1.15 胜率 56～72%，1.15～1.35 胜率 83～92%，1.35 以上约 99%。最终首领一场 1～2 分钟（比值 1.35 以上约 1 分钟），时限 240 秒（别的仗 150 秒）。
- **首领按同一站的精英战标定**（只缩放首领本体）：第一段的小首领 = 精英战 × 0.75（这时玩家只在一个夜市买过兵）；之后的小首领 × 1.0，最终首领 × 1.15（2026-09-26 成长模拟后从 1.0 / 1.3 / 1.45 降下来——首领单独出场、显示改诚实之后，旧的倍数让机器人第 2～5 天就把三颗心输光）。以前地图前段的首领是周围战斗的三倍，是“总被首领打死”的另一个原因。

### 8.3 首领战（用户裁定 2026-09-26，`src/mc-bossfight.js`、`src/mc-titan.js`）

- **首领战只有首领一个**，没有别的敌人。场景中间的是**小首领**，场景尽头的是**最终首领**。
- **小首领**：一个巨大的敌人（比平时的首领再大 1.4 倍），会走会打，普通攻击每一下都震屏；另有两招蓄力重击，轮流用，每 6.5 秒左右一次，蓄力 1.1～1.2 秒，地上先亮红色警示：**重击**——目标脚下一个圈（半径 170），圈里的单位受 1.6 倍攻击的伤害并被击飞；**横扫**——面前一个扇形（半径 300），扇形里的单位受 1.2 倍伤害并被击飞。
- **最终首领**：
  - **地形**：战场右边是它的地形（岩浆、海水、树根、月池、坟坑……附录 G），谁都走不进去。它从地形里升起来（2.2 秒，地形翻涌），只露出上半身，站在原地不动；近战部队走到地形边上就能打到它，沿整条边都行。
  - **出手慢、每一下都重**：每一招先蓄力 1.3～1.55 秒，地上亮红色警示圈（里面的颜色填满就砸下来），蓄力动作和出手动作配着（举起双拳 → 砸地；手臂往后拉 → 横扫；双手举天 → 召唤）。每一击都震屏、顿帧。
  - **震击**：双拳砸在面前（落点选部队最密的一条线，半径 250 的圈）：圈里的单位受 0.6 倍攻击的伤害并被击飞；**不在圈里的其他单位被冲击波击倒**（倒地 0.6 秒，不掉血）。地面裂开，一圈冲击波扫过整个战场。
  - **扫臂**：一只手臂横扫面前一大片扇形（半径 820，左右各 62°，几乎整个前场）：扇形里的单位受 0.35 倍伤害，全部被击飞。
  - **第二阶段**：血量过半时它仰天怒吼（1.5 秒，红光、震屏、地形变亮），之后多一招**天降**：地图上一串 7 个红色警示圈从它面前一路排到我方后排，填满后按顺序一个接一个砸下（每个半径 118，0.45 倍伤害 + 击飞）。落下来的东西每个首领不同：深渊魔王是陨石，德鲁伊是地里钻出的荆棘，知识古树是果子，精灵女王是星光……（附录 G）。
  - 招式顺序：第一阶段震击、扫臂轮流；第二阶段震击、天降、扫臂、天降。每招之间歇 1.4 秒。
  - **形象**：20 个最终首领都用角色同一套 16-bit 像素引擎画（材质缓冲 → 两阶明暗 → 选择性描边 → 蓄力时的轮廓光），大小约是普通单位的 4 倍。一套骨架（躯干、头、两只按落点解出来的手臂、背后长的东西、近手拿的东西）按首领换装：角、翅膀、鹿角、王冠、树皮、面罩、船锚、铁锤……招式三招都一样，名字、第二阶段落下的东西、地形各是各的，不出戏（德鲁伊不会放火球）。
  - **死亡**：沉回自己的地形（2.4 秒，连串爆炸、白闪），战场多停一会儿让人看完。
  - 顶上一条大血条（名字 + 红条 + 金色的一半刻度，进入第二阶段后刻度变红）；小首领也有这条血条，没有刻度。
- **数值**：首领按同一站的精英战标定（§8.1），表里的生命 10000、攻击 330 只决定形状（血厚、出手重），再按场景整体缩放。
- **最终首领更凶、更短**（2026-09-27，机器人试玩：最终首领战中位 62 秒，三分之一超过 90 秒，最长 4 分钟，却几乎每次都赢）：强度从同一站精英战的 1.15 倍提到 1.25 倍，并且同样的强度里生命 ×0.45、攻击 ÷0.45（强度 = √(生命 × 伤害) 不变）——少挨一会儿，但每一下更疼。首领战模拟（`.ai/sim-boss3.js`）：强度比 1.35～1.7 的最终首领战平均 70 秒、胜率 93%，1.15～1.35 平均 91 秒、胜率 79%。

### 8.4 FEVER（用户裁定 2026-09-26，`src/mc-fever.js`）

「根据战场的表现，自动触发fever，fever的效果就是现在道具的效果，这样即保留了爽，也解决了玩家不舍得用的问题。而且fever，还有一种街机感，所以要做伟大的fever效果」。
- **FEVER 槽**（战斗底栏左边，五个字母 F E V E R，槽每满 20% 亮一个，下面一条进度条）：部队打出表现就涨——每一下命中（射手多、法师每个目标少一点）、暴击、前排（先锋 / 守护者）挨打、击杀（刺客、商人击杀更多，打死精英更多）、打掉首领的生命（每 10% 生命 +15）、治疗、召唤、祭司在场。槽不跨战斗。
- **build 就是部队的搭配**：职业每多一种，涨得快 7%（最多 +35%）；既有前排又有后排 +15%，缺一边 -15%。悬浮 FEVER 槽能看到这两项。仓储类建筑、天赋「热身」、纪念品「战鼓」、祝福能让槽开局就有一截或涨得更快。
- **满了自动爆发**，不用按：**战斗停住**（从这一刻到效果演完，战斗时间一动不动），白闪、震屏，屏幕四周亮起一圈跑马灯（五色灯泡追着转），F · E · V · E · R 五个大字一个一个砸下来（每个落地一圈光、一下震），接着街机滚轮转出这次的效果——闪电风暴、回魂烛、旧相框、摄魂铃（原来叫招魂铃，名字像召唤，其实是控制，2026-09-27 改名）、骰盅，各四档（普通 / 稀有 / 史诗 / 传说，附录 E）。转哪一种看战况：部队残血偏回魂烛，敌人多偏摄魂铃，部队快打光偏旧相框。
- **效果上台演**（用户裁定 2026-09-27：「fever触发的时候，战斗停止，结算效果的时候，全屏幕压暗，然后fever结算的效果自带光亮……把所有fever结算效果都整理一遍，都要有类似的伟大的表演」，`src/mc-feverstage.js`）：滚轮停下后整个屏幕（战场和底栏）压暗，顶上金字写出效果名和这一档做什么（「闪电风暴 / 8 道粗雷 + 冲击波」），效果在暗处自己发光地演——它碰到的单位从暗里亮出来，它带来的东西发着光飞过去：
  - 闪电风暴：一道道雷从屏幕顶上劈下来，被劈的敌人亮起、跳出伤害；稀有会连锁到旁边的敌人，史诗以上落地一圈冲击波，传说的紫雷把敌人劈晕。
  - 回魂烛：中间一支大蜡烛，一颗颗光点飞向每个我方部队，落下就亮起、跳出绿字；史诗以上套一圈金色护盾；传说让倒下的部队在光柱里站起来。
  - 旧相框：中间一个旧相框，召来的灰狼、恐狼、复仇之龙、骨龙发着光飞到我方开战时站的阵地上，落地一圈紫光，之后一直亮着到演完。
  - 摄魂铃：一口大铃摇起来，三圈声波扫出去，被扫到的敌人亮起，头上转星星（定住）或冒爱心（倒戈，敌人互相攻击 5 秒）。
  - 骰盅：底栏的积分倍率被照亮、金框一闪一闪；骰盅一摇，两颗骰子滚出来；每 +0.1 就是一枚发光的筹码飞进积分倍率，落下时倍率弹一下、数字跳 0.1（+0.2 / +0.3 / +0.5 / +0.8）。
  - 演完暗处退去，战斗继续，FEVER TIME 开始。转盘上写的就是会发生的（以前写的数字和实际不一致：骰盅写 +2.5 实际 +0.5，旧相框写召唤火小鬼实际召唤狼）。
- **FEVER TIME 8 秒**：部队攻速 +30%，身上冒金光，积分倍率 +0.2（两枚筹码飞进积分倍率）；屏幕顶上一排跳动的彩色 FEVER 字和一条往回缩的时间条，跑马灯一直转。结束后槽从 0 再涨。一场普通战大约一次，首领战两三次。

- 每 5 天一次，自动开始（不弹选将面板）。
- **地面城镇守城**（用户裁定 2026-09-26 / 27，`src/mc-siege.js`）：领袖站在主基地屋顶指挥，不参战、不放技能。怪物从城市两头外面进来，往主基地走，**只打战斗建筑**——城墙、守望古树、防御塔、兵营、防御罩；民用建筑是背景，怪物从它们前面走过去（§5.2）。碰到哪座战斗建筑先把它打掉，所以最外层的城墙先挨打；打到主基地就砸主基地（主基地耐久，基数 2400）。会射击的怪物走到离建筑 170 以内才开火（不然会站在塔的射程外面慢慢磨）。

- **强度与失败率**（用户裁定 2026-09-27：「局外塔防应该敌人的实力，应该足够强，跟玩家足够压力……局外的失败概率应该是50%，具体点相信你自己，你来定」）：目标是**一局下来大约一半的城会被攻破**，而且输给的是自己的选择（防御建得少、没加固），不是运气。怪物的数量按当天的预算来，生命和攻击再乘一条按天数的曲线 `M.RAID_CURVE`：第 5 天 ×4.4、第 10 天 ×1.7、第 15 天 ×2.1、第 20 天 ×3.0、第 30 天 ×3.6（中间按天数插值）。第 5 天乘得最多，是因为那时怪物的预算还很小、城里已经有 2 道墙和 1～3 座塔。

## 10. 画面与演出

- **手机上的画面**（2026-09-27，安卓玩家反馈「每次点击屏幕，全屏都蓝，而且特别卡」，在安卓模拟器里实测找到根因）：
  - **点击变蓝**：安卓 WebView 默认给被点的元素盖一层 40% 的蓝（`rgba(51,181,229,0.4)`），而基地、地图、战斗都是一整块全屏的可点画布，所以点哪儿整屏都蓝。页面全局关掉点击高亮（`-webkit-tap-highlight-color: transparent`）。
  - **卡**：每帧的 HD-2D 后期效果（景深模糊、泛光的亮度对比度加模糊、柔光调色、暗角：两次模糊加四次全屏混合）占了基地一帧的六成：基地 53 → 20 毫秒一帧（约 19 → 49 帧）、地图 33 → 22 毫秒，关掉它其他都不变。手机和平板（触屏设备）不做这层后期；任何设备开着它撑不住约 30 帧（最近 150 帧平均超过 33 毫秒），也自己关掉。电脑上照旧。
  - 用户裁定 2026-09-27「手机上就把景深模糊、泛光、调色、暗角这些类似的效果关掉」：触屏设备上同样不画场景灯光外面那圈柔光（基地、地图、战斗）、地图上的光柱、战斗里技能聚焦的暗角；基地的夜色光照留着（它是夜景本身，只占约 1 毫秒）。模拟器实测基地约 19 毫秒一帧，卡顿帧 6%（修之前 53 毫秒、22%）。
- **60 个单位同屏**（2026-09-27：「即使在电脑上，也特别卡」，电脑版 Chrome 采样找到的根因）：战场上技能名字弹出时，每一帧都按正在变化的字号重新生成字形、读回画布像素，大字的光晕也每帧重算；单位多、技能多时这些叠在一起。改成字形按原字号生成一次、缓存，弹出只是缩放；光晕按几档固定大小缓存。新像素角色的攻击 / 技能动作每个单位每帧重画一次，改成同一个动作最多每秒约 33 次（姿势本来就是每秒 12 帧）。60 个单位时主线程忙碌从约 55% 降到约 45%，12 秒里超过 33 毫秒的长帧从 18～30 次降到 4～6 次。
- 部队、敌人和领袖都是逐个设计的像素角色（程序绘制；2026-09-26 起替换原来的 16-bit 骨骼角色）：每个角色按自己的职业和特性单独设计外形，同类不重复；待机、移动、攻击、技能（蓄力 → 施放 → 收招）、受击、死亡六个状态都画，外加它自己的技能特效。源在 `pcd/`：共享引擎 `pcd/lib/pcd.js`、部件库、每个角色一个模块 `pcd/chars/<key>.js`，设定卡 `pcd/batch-*/<key>/design.md`，单个查看 `pcd/view.html?c=<key>`。`node tools/pcd-pack.mjs` 打包成 `src/mc-pcd.js`，`src/mc-pcd-game.js` 接进游戏。
- 战斗里的像素角色：身体按 12 帧 / 秒逐帧播放；攻击、技能、死亡、复活、领袖的场外技能由角色模块自己演，弹道和特效对准真实目标的距离，光环类的特效落在身边真实的友军身上；倒下时播放自己的死亡动画（被击飞的除外），播完才消失。技能在蓄力、施放时不会被普通攻击打断（伤害照常结算），收招时才让给下一次攻击；小首领的重击 / 横扫也用自己的蓄力 → 施放。1 个像素画成 4 个逻辑像素，体型 ≥ 1.6 倍的（首领）画成 8 个。

### 10.1 基地像素房间（用户裁定 2026-09-25：整个基地都是真像素画，房间要最 juicy、最惊艳，并为以后的 HD-2D 提前准备）

**做法**（`src/mc-pxroom.js` 引擎、`src/mc-pxroom-kit.js` 风格外壳 / 岩层 / 空房间、`src/mc-pxroom-a.js` 房间）：
- 房间按美术分辨率画：150×105 格，一格 = 2 个世界单位（和角色同一像素尺度），地面顶在第 90 行。不用渐变、不用抗锯齿、不用模糊光晕；房间外框是 2 格墨框 + 1 格斜面边，稀有及以上加品质色细线，史诗 / 传说有光点沿边框跑、传说四角闪。
- **颜色按材质色阶**：石、砖、木、铁、黄铜、铜、布、叶、土、水、瓷砖、科幻板、魔法石、火、灯光……每种 8–12 级，暗部统一收进角色色板的夜蓝（`pcd/lib/pcd.js` 同一组暗色），亮部偏暖，阴影偏蓝紫。
- **四个深度层**：墙（0）、靠墙（5）、中景（14）、前景（26，离眼睛最近的吊链、管子、煤桶）。每格记：材质、色阶位置、朝向（法线）、发光、深度。
- **每帧打光**：房间自己的灯（锻炉火、火把、吊灯、屏幕、水晶、补光灯……）把每一格沿自己的色阶往上 / 往下推，光圈是硬边色带，交界只有 1 格宽的网点；有颜色的灯让受光面带上灯的颜色（硬分 6 档，不抖网点）；金属、玻璃、水、瓷砖有高光。灯会闪（火焰、烛火、日光灯偶尔闪一下、脉冲），也会被动作点亮（铁匠一锤满屋一亮、安全阀喷汽警示灯一红、召魂时水晶一亮）。会动的灯（摆动的吊灯、上下的吊笼灯）用沿轨迹的几盏灯交替渐变。
- **会动的东西**每帧重画并同样受光：像素火焰（热量扩散元胞自动机）、齿轮 / 飞轮 / 叶轮、植物梢头摆动、心电图、水面、锦鲤，以及房间里的工人（约 26 格高的像素小人：铁匠抡锤、工人拧螺栓、护士巡房、召魂者举杖、农夫浇水、管理员拖地、搬运工搬箱）。
- **粒子**是单格像素，按寿命走色阶（白 → 本色 → 暗）：火星（上飘、会照亮周围的墙）、火花（飞溅、落地弹跳）、蒸汽 / 喷雾（网点透明）、气泡、水滴（落地溅开）、灵魂、符文、治疗十字、闪光。光柱是一束硬边分档的半透明光，同时照亮它经过的东西；水面光影是一片流动的光。
- **视差**：镜头左右移动时，前景层比中景、中景比墙多移动 1–2 格，地面按远近逐行错开，房间像一个小立体布景。
- **互动**：悬浮一个房间，灯亮一点、一粒光点沿边框跑；点房间，所有灯一闪、灯位冒闪光、房间弹一下；房间建成（或挖通），灯按顺序一盏一盏闪着亮起来、顶上落灰、最后房间弹一下再轻震。
- **空房间**：岩壁、矿道木架、一盏吊灯在绳上摆（光影跟着摆）、飞蛾绕灯、镐和木箱、角落蛛网。**岩层**：3 种像素岩层（岩带、圆石、裂纹、矿物闪点）。
- **地面上的主基地**（用户裁定 2026-09-25：全游戏最精致的一件，`src/mc-pxroom-base.js`）：一座夜里的仓库大楼，380×210 格、透明底，盖住整个地面主基地和通往地下的井口。两翼不一样：左翼是仓库（红砖下层、半卷起的铁皮卷帘门里透出暖光和货箱、木装卸台，木构上层有吊货门和伸出来的吊梁，吊着的麻袋定时放下吊起，屋顶三扇天窗、墙角爬满常春藤），右翼是账房（暖色石砌下层、两扇拱窗、带铁钉的正门和门灯、摇晃的金币招牌，上层有带小屋顶的凸窗和摆着花盆的铁栏阳台，屋顶老虎窗、风向鸡和铁烟囱）；屋顶是一片片交错的红瓦，半圆脊瓦、青苔、两处滑落的瓦；两边有落水管，上层出挑在下层墙上投下阴影；中间是石砌门楼，尖顶上一只发光的大钟，指针停在午夜前几分、分针每秒走一下；门楼的尖拱就是传送门：拱石上刻着随传送门光呼吸的青色符文，拱顶一颗青色宝石，拱门内沿发光，门里是一条有纵深的隧道：光环从亮的深处一圈圈往外推、两条旋臂转着（打开时转快、变亮、星点被吸进去，整座门楼被照青），门前湿石板的水洼里倒映着它。门前三级台阶、两只火盆（火星上飘、照亮台阶），门楼两侧飘着青色旗帜，屋檐下四盏灯笼在摆，广场两端各一盏路灯；一只黑猫每 26 秒沿仓库屋脊走过来坐下甩尾巴；有时凸窗后走过一个人影；搬运工把装卸台上的货扛到推车，账房先生不时拿着账本走出门口；飞蛾绕灯、萤火虫在门前石子广场上闪。传送门耐久低于 35%：拱石裂开、漩涡闪烁、一盏红色警示光一胀一缩、偶尔迸火花。悬浮门或两翼，灯亮一点。
- **地面与天空**：夜空是硬边色带；星星一闪一闪，还有一条暗淡的银河；月亮是一张有环形山和光晕的像素月；远山带月光照亮的山脊和雪顶，山脚有几点村庄灯火；近处是松林剪影；云慢慢飘；每十几秒划过一颗流星。远山、松林、云、星星随镜头有不同的视差。地面是草皮加土层，主基地两边铺着石子路；地下的土层是像素土纹。基地上空飘的光点也改成了像素点（一个亮格 + 十字形暗格光晕）。
- **施工和挖掘**（`src/mc-pxroom-jobs.js`）：正在建的房间是木脚手架：上层木匠抡锤、一锤火花一闪，下层工人锯木板、木屑飞，吊着的工作灯在摆（光跟着摆），顶上落灰，后面是要建的房间的虚影；正在挖的格子是一条随进度往里推的隧道：身后立起木支架，钻头顶着岩面转、火花和碎石飞溅，矿工抡镐，工作灯挂在掌子面。
- **画布尺寸**：房间是 150×105；别的东西可以声明自己的尺寸（`PXR.def(key, { size: [w, h], fy, clear: 1 })`，主基地就是 380×210 透明底），引擎画它之前切到它的尺寸和缓冲。
- **性能**：屏幕外的房间不画；缩小时房间隔几帧刷新一次（错开），每帧房间总共最多用 4 毫秒（`M.PXR.BUDGET`），超出的下一帧补，任何房间最多 0.2 秒刷新一次。
- **进度**（2026-09-26）：全部 48 种建筑、22 种特殊地形、未勘明的地脉、9 种风格外壳、岩层、空房间、施工 / 挖掘、地面主基地、夜空和地面全部是像素画（第一批 7 座手做定标准，其余 40 座 + 地形由工作流按同一标准制作，每座独立验收、返工，最后整套一致性检查；石墙 2026-09-26 补上：城墙底下的石料间，石匠凿石，方石从天花板的吊口一块块吊上地面的城墙，`src/mc-pxroom-c.js`）。室外奇观各有自己的天色（月夜、雾夜、黄昏、黎明、日出、极光），不互相重复。旧的矢量画法（`mc-rooms.js`、`mc-base.js` 的 `drawRoom`、`mc-terrain-art.js` 的地形图）只在像素版缺失时兜底。

**HD-2D 交接**：房间数据就是 HD-2D 需要的东西，不用重画。`M.PXR.export(key)` 给出每层四张图（颜色、法线、发光、深度）和灯（位置、半径、颜色、闪烁方式）、粒子发射器、光柱；`M.PXR.frame(key, t)` 给出这一刻的动画层（同格式）、粒子（位置 + 颜色）和每盏灯的亮度。三维里：墙层上半是立面、地面行平铺成地板（每行深 2 格），其余每层一张立在自己深度上的面片，灯变点光源，再加辉光和移轴景深。示例：`tools/hd2d-room.html?r=smithy`（启动开发服务器后打开，右下角是同一份数据的 2D 画面）。

**给美术的工具**：在游戏里加载 `tools/pxroom.js`，`__rooms(['smithy'], { scale: 5 })` 整数倍放大看一个房间（1–9 键点亮第几个房间、B 重放建成、H 切换悬浮），`__rooms()` 看全部像素房间。新房间照 `src/mc-pxroom-a.js` 的写法：`PXR.def(key, { amb, paint(S, sc), anim(D, t, rs, o) })`，先 `PXR.shell(S, sc, 风格)`，再按层画东西、`sc.light` / `sc.emit` / `sc.shaft` / `sc.field` 声明灯、粒子、光柱、光影，`anim` 里画会动的东西；房间的一句话描述写进 `M.ROOM_D`。

### 10.2 声音（2026-09-25 重做）

音效的实现是 `src/mc-audio.js`（就是 `M.Sfx`）。全部实时合成，没有音频文件。
- **同一个调**：有音高的音效（金币、升级、滴答、悬浮……）都取 F 大调五声音阶；「明天」和混沌来袭时换成 D 小调。叠在基地配乐上也不会打架。高频的声音（悬浮、滴答、数字滚动）在音阶里随机取音或逐级往上走，连起来像一小段旋律。
- **金币按数量走音阶**（用户裁定 2026-09-25）：连着来的金币一个比一个高，在五声音阶里一格格往上爬，停 0.7 秒再从低处开始；一次给很多时按数量连成一串上行音（数量越多串越长，最多 8 个音），积分到手按这次涨了多少算。金币串（大赢、大奖、结算总额、购买）也是沿音阶往上走的一串，不再是随机音高。
- **一个动机**：进基地、领袖上场的铜管都是同一个四音「回家」动机 C–F–G–A；它的小调版 A–D–E–F 留给「明天」。
- **卡在动画节拍上**：演出音效的每一声都对着动画里的时间点。可以点击快进的演出（升级、招募、换日、新的五天、撕卡、转盘、胜利横幅）不预先排好整段，而是在各自的 tick / draw 里按动画的 t 逐拍触发，快进时声音跟着一起加速。进战通告和结算卡片不能快进，开始时一次排好。
- **和声的爽点**：升级时战斗力滚动的那一秒压在属和弦上，数字停住变金的那一刻解决到主和弦；招募碎卡时光每爬一档品质响一声，一声比一声高。
- **按下反馈五档**：动效的 `juice(tier)` 调 `M.Sfx.cue('ui_' + tier)`，tap / back / no / good / big 各一种；另有 `ui_rush`（点击快进）。**一次点击一个声音**（用户裁定 2026-09-25：有的音效表达重复）：按下（tap）只有按键本身短短的一下，不带音高，这次点击做了什么由动作自己的声音来说；按下后 0.4 秒内动作里再调 click、按返回键关面板时的 panelClose 都不再响；悬浮声更轻，0.15 秒最多一次。
- **音效导演**（用户裁定 2026-09-25：要有一个导演控制一切，不能冲突、不能烦）：所有声音先经过 `mc-audio.js` 里的导演。
  - 每个音效属于一个类别：界面、命中、出手、技能、世界、演出、小游戏、环境。
  - **战斗里每一声都放**（用户裁定 2026-09-25：打击、被击打每一声都要出来才够爽）：出手、命中、弹道、暴击、击杀、技能、入场、召唤都放，不再按帧挑一个；同一帧挤了很多声时一起轻一点（按 √(4 / 声数) 压），同类声音越密越轻但最低只压到四成，不丢声。
  - **开战只有进战通告一个声音**：踩上战斗节点、开战时都不再放风声和重击；进战通告那 1.4 秒里，单位入场、开场的第一批技能和命中都不出声，只听得到号角。
  - 一批奖励飞进顶栏只响第一个落地的（卡片弹出时已经一张张响过）；地图上起步不出声，只有脚步声。
  - 同类声音在一小段时间里越密越轻，超过上限就丢。实测：原来战斗里每秒约 20 声（命中 7.7、出手 8、弹道 3.9），0.25 秒里最多挤 176 次命中请求。
  - 大演出（进战、胜利、结算、升级、招募、撕卡、混沌来袭、新的五天、大赢、大奖……）一响，接下来那一段就是「舞台」：战斗声压到三成，出手声压到两成，技能声压到一半。
  - 高频的声音（命中、弹道、脚步、悬浮、逐字跳……）在 3 个变体里轮换，不连续两次同一个。
  - 小游戏的每个事件各自限流，付钱和紧接着的动作声不会互相吞掉。
  - 奖励声同一帧（以及紧接着 0.35 秒内）只放分量最大的那个：大奖 > 大赢 > 号角 > 中 > 揭晓 > 小中 > 小游戏自己原来的「中了」> 升起 / 金币 / 倍率；重击只给大赢以上让路。所以旧调用和小玩法演出的新调用可以并存。
  - 按钮声、小游戏的动作声和奖励声不受发声数上限限制，演出进行时也能响。

## 11. 界面与文字规范

**原则：画面上常驻的字越少越好；玩家不关心的细节藏起来；任何一个设计元素都不能让人问“这是干什么的”。没有用处的元素就不该存在。**

### 11.1 三层信息

| 层 | 什么时候看得到 | 放什么 |
|---|---|---|
| 常驻 | 一直在屏幕上 | 名字、数字、图标、按钮；每条说明最多一句 |
| 说明 | 鼠标悬浮 / 初见说明卡 / 玩法说明（F1、右下角「？」、标题菜单） | 这个元素是什么、怎么用 |

- **游戏里没有「按住 Ctrl 显示详细信息」**（用户裁定 2026-09-24，全部删掉）：没有 Ctrl 键、没有右下角「ⓘ」开关、没有闪烁的提示行。每个东西只有一种说法，该给的信息直接给，不该给的（领袖上场后怎么打、道具四档效果、规则说明）就不给。
- 代码里：`this.D(常驻, 详情)` 永远返回常驻那一份，`data-detail` 的模板文字永远隐藏（旧代码留着但不生效）；悬浮说明的 `ctrl: true` 只表示「只显示标题和图标行」。
- **悬浮说明“图标为主”**（`src/mc-tipcompact.js`）：领袖的悬浮说明只显示标题和图标行（技能图标 + 名字，下面一句军团技能）；其他悬浮说明图标行和文字一起显示。部队的悬浮说明 = 名字 / 职业、战斗力 / 一句话。悬浮说明可以提供 `briefTitle`（简版标题）、`brief`（图标行：图标 + 数字，或血条）和 `pic`（头像 / 物品图）。例：领袖 =「Lv2 驱魔修女」/ 血条 1864/1870 / 技能图标 + 名字 + 一句军团技能 / 有天赋点时再闪烁一行「有 N 个天赋点可用」；部队 = 名字 / 职业图标 + 职业、战斗力 / 一句话；地格 = 地格图标 + 名字 / 契合的功能或风格图标。
- 夜市部队卡牌：头像、名字、职业图标 + 职业、战斗力、一句话、价格。
- 费用、天数用图标 + 数字，不写“物资”“天”这类字。

### 11.1b 文案规则（用户裁定 2026-09-24）

例：房间角上的风格图标。**错**：「中世纪 / 建筑风格 / 建筑风格：地格和奇观写着契合某种风格的时候，风格对上的房间才有额外效果 / 这个房间：酒馆」。**对**：「[图标] 中世纪 / 该建筑具有**中世纪**风格」。

1. **只说眼前这一个东西在这里是什么、做什么**，一句话，关键词着色。
2. **不在单个说明里讲整个系统的规则**：规则写在初见说明卡和玩法说明里，只写一次。
3. **不写标题已经说了的类别**（「建筑风格」「宝物 ·」「特殊地格」），**不重复屏幕上已经有的东西**（标题、图标、按钮上的费用、芯片上的射程）。
4. **不写操作教学**（「点击……」「悬浮查看……」「按住……」）；交互自己说明自己。小游戏的操作提示除外。
5. **功能文字里不放氛围描写**（世界的背景描述、建筑的来历）。
6. **面板 = 这个东西的详细信息**，不先复述一遍悬浮说明。有专门操作的房间（招募、锻造、仓库）直接写操作本身：酒馆面板只有一个按钮「花 120 物资，招募领袖」。
7. 空状态一句话（「没有宝物」「没有建筑图纸，出征能拿到」）。

### 11.2 初见说明

- 每个设计元素在 `src/mc-guide.js` 的 `CONCEPTS` 里有一条：图标、名字、**一句话**、它在屏幕上的位置。
- 说明卡**暂时不自动弹出**（新手引导去掉了，§2）；以前是元素第一次出现时在旁边弹出、每台设备一次。

### 11.4 操作

- 鼠标、键盘、手柄、触屏都能玩；看起来能点的东西都能点。

### 11.5 视觉：Pixel Juice（2026-09-24）

**动效一律平滑**（用户裁定 2026-09-24：界面风格保留，但一卡一卡的动效全部改掉）：画布动效用连续时间（不再按 8 / 12 / 15 / 24 帧取样；唯一例外是像素角色的身体动作，它们是逐帧画的，按 12 帧 / 秒播放，角色在场上的位移仍是连续的），透明度连续（不再分 4 档），关键帧之间缓动插值（弹出、砸下、回弹的数值和节奏不变），闪烁改成正弦呼吸，位置按 1 像素而不是 3 / 4 / 6 像素网格移动，字号连续缩放；CSS 的刷光、上下浮动、左右跳、呼吸、闪烁、逐字跳、跑马灯、扫描线、按钮按下回弹全部去掉 `steps()` 改成缓动。战斗通告、胜利、结算彩票条、换日、升级、阵亡卡、招募碎卡、技能名牌、宝箱、转盘都受益。只有战旗飘动是 8 帧贴图动画，保留逐帧。下文里「逐字跳」「几帧」一类的描述指动作本身，节奏已经平滑。

### 11.6 手感分档（2026-09-25）

用户裁定 2026-09-25：以前每次点击都放一样的一套（形变 + 碎块 + 火花 + 震屏 + 推开邻居），点多了又吵又卡。改成按玩家当下的心情分档：**爽点要突出，普通点击就是普通点击，负面的一下就过去**。一次反馈是一条连起来、分主次的链，不是各演各的。

| 档 | 什么时候 | 反馈 | 时长 |
|---|---|---|---|
| 普通 | 开面板、选东西、切页、暂停、变速 | 按下的东西缩一下；一声轻响。没有粒子、不震屏 | 0.12 秒 |
| 关闭 / 返回 / 取消 | ✕、返回、算了、离开、卖掉部队 | 更轻更快；面板立刻关，卖掉只飞回一枚金币 | 0.08 秒 |
| 被拒绝 | 积分 / 物资 / 碎片不够、失效键、技能用不了、条件不足 | 按下的东西左右摇头 + 低音；**缺的那样东西**（钱包、物资、碎片、队伍栏、道具栏）隔 0.06 秒红着抖一下；再弹一句提示。不震屏、不卡帧 | 0.18 秒 |
| 小爽点 | 买下普通 / 稀有的部队；开挖；普通 / 稀有建筑开工 | 挤压回弹 + 触点闪光 + 圈 + 火花；买到的东西飞进它的栏位 | 0.26 秒 + 飞行 |
| 大爽点 | 买下史诗 / 传说；奇观开工；招募、升级、点亮天赋、出征、宝箱、转盘、胜利 | 见下面的层次；招募、升级、宝箱、转盘、胜利是各自的全屏演出（`docs/effects.md` A 节） | 0.4 秒 + 飞行 |

**层次**（大爽点完整走一遍，小爽点只走前两层）：① 主体 0 秒——按下的东西挤压、亮一下（按下时的缩一下就是蓄力，成功时的弹开是释放）；② 近场 0–0.04 秒——触点闪光、光圈、火花；③ 场景 0.06–0.12 秒——冲击波和碎块、镜头轻震、周围的按钮按距离先后被推开；④ 落点——奖励沿弧线飞向它的计数器，落下时计数器鼓一下、数字滚上去。动作和它影响的东西要连起来：点亮天赋 → 领袖卡跟着鼓一下；开工 → 按键先弹，地格上的光和尘晚 0.1 秒。

**入场也分层**：右侧面板外框从右滑入（带一点过冲）→ 标题牌压下来 → 内容一行一行跟上；确认框外框弹出 → 标题牌 → 选项逐行；有插画的奇遇是黑边合拢 → 插画从左滑入 → 对话框升起 → 名牌压下 → 选项逐行。入场用 CSS 动画（元素插进页面时自己播），不靠每帧重画整页。

**卡帧**（打中时画面停一下）只给大爆点（`explode` 强度 ≥ 1.5：宝箱开箱、转盘定格、胜利、首领）；界面上的小爆点不停，停了就像卡住。

**负面演出更快**：领袖阵亡撕卡、核心受击整段按 1.5 倍速播；领袖受伤的震屏减半。

**点一下就快进**：长演出（回家那一串、招募碎卡、升级、转盘、胜利横幅、阵亡卡、核心受击）里点击任何地方，整段加速到 3 倍，1.2 秒内不再点就恢复原速；不会有点了没反应的时候。

**性能**：界面只在它显示的东西在动时才每帧重画（数字滚动、计数器鼓动、结算、转场、新手气泡）；特效粒子、闪光、横幅、转盘、宝箱、撕卡、招募卡都画在特效画布上，不重画整页；震屏直接写到舞台上；悬浮说明只在鼠标移动时跟着重画。悬停不放粒子、不加模糊滤镜。

代码：`src/mc-game-a.js` 的 `juice`（分档）、`pressTier`（按下时判断档位：模板里的 `data-j="back"`、失效键、关闭类文字）、`deny`（被拒绝）；`src/mc-recruit.js` 的 `hurry`（快进）；`src/mc-pj.js` 的 `[data-enter]` / `[data-enter-rows]`（分层入场）。

## 13. 维护规则

1. **改设计就改这份文档**，和代码放在同一次提交里。设计单文件：不另建新文档、不留旧版本。
2. 新增元素：同时补 `src/mc-guide.js` 的 `CONCEPTS`（初见说明）、悬浮说明、这份文档的对应章节和附录。
3. 改角色或技能：改 `pcd/chars/<key>.js`（按 pixel-character-design 的规范，设定卡一起改），再跑 `node tools/pcd-pack.mjs` 重新生成 `src/mc-pcd.js`；还在用 16-bit 骨骼的单位改 `src/mc-px16-cast.js` / `mc-px16-fx.js`，再跑 `node tools/gen-prompts.js` 重新生成 `docs/prompts/`。
4. 加减会动的东西（单位、技能、小游戏、建筑、FEVER 效果、音效、全屏演出）：跑 `node tools/gen-effects.js` 更新 `docs/effects.md` 的生成部分；新的全屏演出、基地 / 地图 / 战斗 / 界面动效要手动补进 `docs/effects.md` 对应小节；房间场景的文字描述写在 `src/mc-rooms.js` 的 `M.ROOM_D`。
4. 改界面文字：先看 §11 的预算；超预算的内容放进详情层或说明卡。
5. 自检：浏览器里加载 `tools/designcheck.js` 后运行 `__designCheck()`，它会列出游戏里存在、但这份文档没提到的建筑、地格、世界、节点、奇遇、领袖、战旗、道具、宝物、家具、说明卡。

6. **机器人试玩**（用户裁定 2026-09-27：「你来做机器人脚本，自己玩游戏，判断一下还有哪些是违反人类直觉，感受不好，违反玩家期待的，发现问题你就直修，修好了再跑」）：加载 `tools/bot.js` 和 `tools/uxbot.js`，运行 `await __ux(秒数)`。它像普通玩家一样玩，同时记下：屏幕上的坏字（NaN、undefined……）、超出框的文字、基地连续点不动的时间和原因（每一种演出各占多少秒）、被拒绝的操作、反复出现或太长的提示、有物资有图纸却空着的房间、太长的战斗（最终首领 120 秒、其他 90 秒）、叠在一起的弹窗、演出中弹出的说明卡、留在别的画面上的小游戏、守城失败和没有防御就守城、同一章连输。2026-09-27 第一轮找出并修掉了：回家一趟基地要锁 20～40 秒（§5.1 的演出时长）、物资到第 15 天攒到上万没处花（加入加固，调低后期物资）、最终首领战太长（§8.3）、守城僵持不结束（§9）、民用建筑被主基地挡住（§5.2）。

## 14. 多人玩法（设计稿 2026-09-27，尚未实现）

用户要求：「下一步我要做多人玩法，给我设计一下具体的多人玩法内容。多人玩法的实现技术是操作同步+确定性模拟，服务器用 steam 自带的转发消息的那套机制」。只在 Steam 版做（安卓的系统 WebView 版本不一，浮点和数学函数不能保证逐位一致，先不跨平台）。

### 14.1 四种玩法（按上线顺序）

**① 联防（2–4 人，先做）**：守城那天可以「求援」。
- 守城开始前 20 秒，顶栏多一个「求援」按钮：发给在线的 Steam 好友（富状态显示「第 N 天 · 混沌来袭」），也可以挂在公开列表里。朋友点进来就是**援军**，城是房主的，存档也只动房主的。
- 援军带来两样东西：**自己的领袖**（站在房主主基地屋顶，一场守城能放 1 次领袖技能，点地面选落点）和**借来的塔**（自己城里最强的 2 座防御塔的复制品，伤害 ×0.7，援军在房主战线的空位上点一下放下；复制品挨打会倒，但不会让房主的房间损毁）。
- 每多一名援军，怪物生命 +25%、数量 +15%：朋友来了能扛住原本扛不住的一波，但不会变成白送。
- 奖励：房主照常结算；每名援军拿房主奖励的一半物资、10 灵魂碎片和 1 张随机防御图纸，写进**援军自己的存档**；守住后两边都记一次「援军」（成就、Steam 统计）。
- 为什么先做：守城现在大约一半的城市会被攻破（§9），叫朋友来帮忙是最自然的社交理由；守城的模拟只有一个场景、输入很少（放塔、放技能），最适合先把操作同步跑通。

**② 双人出征（2 人，之后 3–4 人）**：两个领袖一起走一张地图。
- **开房**：房主选章节和难度（只能选两人都解锁过的章节）；各带自己的领袖（等级、天赋、宝物来自各自存档）。
- **地图**：每一段轮流带路（第一段房主，下一段对方……），带路的人决定走哪个节点；另一个人可以在节点上「标记」（小旗 + 一声）。事件、小游戏由带路的人做选择，收获两人都有。
- **战斗**：两支部队并排上场，各自的单位描一圈自己的颜色；前后排按两边合起来排。**各自的领袖技能各放一次**；两人的技能 2 秒内接连放出 = **合击**：两个技能效果都 +30%，屏幕上打出「合击！」。
- **FEVER 共用一条槽**：两支部队一起涨，职业种类按两边合起来算——两人各带不同的职业，FEVER 来得更快，这是双人的阵容配合。
- **夜市**：每人自己的积分、自己的一排货（按各自的种子随机）；买下的部队可以**送给队友**（点部队拖到队友头像上），卖出照常。
- **敌人**：两人时敌人生命 ×1.7、攻击 ×1.2，首领生命 ×1.9；之后三人 ×2.4 / ×1.35 / ×2.7。
- **有人倒下**：领袖阵亡的一方变成旁观，他的部队交给队友指挥到这场结束；每点一次屏幕「打气」，FEVER 槽 +1%（每场最多 +20%）；下一个营地节点复活，生命一半。
- **掉落各算各的**：图纸、首领建筑图纸、纪念品按每个人自己的种子掉，带回各自的基地；撤离、通关、失败对两人同时生效。

**③ 午夜擂台（2–8 人对战）**：只比部队搭配和领袖技能的时机，跟存档的强弱无关。
- 开局每人从 3 名领袖里选 1 名（统一 5 级、统一天赋），30 点生命。
- **每回合**：30 秒夜市（每人 50 积分 + 连胜 / 连败各多 10；5 张卡，刷新 5 积分；部队价格和出征时一样，同一种部队场上总数有限，买完别人就刷不到），然后和另一名玩家的部队打一场（对手每回合轮换）。战斗规则和出征完全一样（前后排、职业、FEVER），领袖技能自己按。
- 输的一方掉生命 = 2 + 对方活下来的部队数 + 回合数 ÷ 3；生命归零出局，最后站着的赢。
- 奖励只有名次积分（Steam 排行榜）和**外观**：机台皮肤、给自己地面城市用的装饰（广场雕像、彩旗、灯笼），让朋友来访时看得见，不给任何数值。

**④ 城市来访（2–8 人，社交）**：点好友列表里的「来访」，看对方的地面城市（只读，当时的样子，§5.2 / §5.3 的景深和发展方向都在），两边的领袖在街上走；可以留一份礼物（从自己仓库送 1 张建筑图纸），可以「点赞」（对方下一天繁荣度 +5%）。不需要操作同步：房主把存档快照发过来就行。

### 14.2 技术：操作同步 + 确定性模拟 + Steam 转发

- **联机层**：用 Electron 外壳里已经有的 steamworks.js：`matchmaking` 建房、找房、邀请（`createLobby` / `joinLobby` / `openInviteDialog`，收到邀请走 `GameLobbyJoinRequested` 回调）；数据走 `networking.sendP2PPacket`——Steam 先试直连，打不通就自动走 Valve 的中继，不用自己架服务器。只接受同一个房间里成员的会话（`P2PSessionRequest` 回调里核对）。
- **房间数据**（lobby data）：玩法、种子、房主的游戏版本号（`MC_BUILD`，版本不同不能进）、每个位置的领袖简要、准备状态。
- **星形转发**：所有人的操作先发给房主，房主把每一回合所有人的操作打成一包发回给所有人（可靠包）。人少（≤ 8）、只有一个时钟，房主掉线时由房间里的下一个人接着当房主（大家状态一样，只要接着从最后确认的回合往下打包）。
- **回合**：模拟固定 30 步 / 秒；3 步为一回合（0.1 秒）。操作标上「在第 T + 2 回合执行」（默认 0.2 秒延迟，按延迟在 1–4 回合之间自动调整）。某一回合的包没到，就等它，不往下算。操作都很小（放技能：落点 x；放塔：位置；买部队：卡片序号），一回合一包几十字节。
- **不是实时的环节不用回合**：地图选路、夜市、事件、小游戏选项都是「阶段操作」——谁点了什么就发一条，大家按收到的顺序执行，所有人都执行完才进下一阶段。只有战斗和守城按回合走。
- **确定性改造清单**（现在的代码不满足，要先改）：
  - 随机分两路：模拟里的随机要所有人一样，画面里的随机（粒子、震屏）各算各的。做法：每一步模拟开始前把 `Math.random` 换成同一种子的伪随机数（mulberry32，种子来自房间数据 + 回合号），这一步结束再换回来——这样现有代码里几百处 `Math.random`（全项目 68 个文件、402 处）不用一处处改；画面代码里的随机本来就不影响结果。
  - 模拟里不能读真实时间：`performance.now()` 在模拟里的用法都改成步数（现在 FEVER 的慢动作、转盘的时间点、扩张演出的看门狗、战斗 2 里 1 处，§8.4）；帧间隔 `dt` 一律换成固定的 1/30 秒。
  - 画面函数（`G.view` 和各种绘制）不许改模拟状态；有改的地方搬进模拟步。
  - 排序比较函数要全序（相同时按 id 分先后）；遍历用数组，不依赖 `Object.keys` 的数字 / 字符串混排。
  - 数学函数：`sin` / `cos` / `pow` / `exp` 在同一个 Electron（V8）版本里逐位一致；房间校验 `MC_BUILD`，所以 Steam 版里可以直接用。
- **对不上怎么办**：每 30 回合，每人把模拟状态（单位的位置和生命取整、随机数状态、回合号）算一个哈希发给房主；有人对不上，房主把完整状态发给他（可靠包，最多 1MB），他从这一回合重新开始；开发版同时把双方状态写进日志（`.ai/`），用来找出哪里不确定。
- **断线重连**：30 秒内回来，房主发完整状态和之后的回合包，他追上来；超过 30 秒，他的部队交给电脑（FEVER 满了就放技能），他的领袖不会死亡结算。
- **存档**：每个人的存档仍然只在自己的设备上。多人结果由模拟算出，每个客户端只把**属于自己的那一份**写进自己的存档（联防的援军、出征的掉落）。合作玩法不防作弊；擂台的排行榜只有外观，各自上报名次。

### 14.3 做的顺序

1. 确定性改造 + 回放测试：同一个种子和操作记录，跑两次必须逐步相同（机器人脚本自动对比，§13）。
2. 联机层：建房 / 邀请 / 回合包 / 哈希校验 / 重连，先用两个本机客户端互连测试。
3. 联防（最小可玩）→ 双人出征 → 午夜擂台 → 城市来访。每一步都先做「两个机器人客户端对打一小时，哈希全部对得上」再给人玩。

| 物资 | 挖岩层、建房间、打造宝物都花它。出征和守城带回来。 |
| 灵魂碎片 | 高端材料：建史诗 / 传说建筑、精铸宝物时要用。主要在守城时击杀怪物得到。 |
| 基地核心 | 三颗心：探索失败时献出一颗救回领袖，打倒区域最终首领补回一颗；心用完这一局就结束。 |
| 信仰值 | 建了信仰类建筑才会出现；攒够了宗教就升一级。 |
| 宗教 | 信仰值攒够，宗教自动升一级：每座信仰建筑给出一条教义，选一条。 |
| 来访者 | 日历上的事件是一位来访者：在城门口选一样，等他离开后才生效。流浪商人只卖一样东西。 |
| 繁荣度 | 造的建筑品质越高，繁荣度涨得越多；升一级，地块向外扩一圈。 |
| 发展方向 | 繁荣度每升一级，从两个方向里选一个，城市就朝那边长。 |
| 地面城镇 | 地下每建一座建筑，地面就升起一座：前排是会挨打的战斗建筑，后面是城市。 |
| 损毁 | 守城时被打塌的战斗建筑，修好之前不起作用；点它的房间修复。 |
| 未解锁的地块 | 黑色的地块还没解锁，繁荣度升级后才能挖。 |
| 建筑大类 | 建筑按用途分九类：生产、仓储、工坊、信仰、医疗、训练、防御、侦察、工程。房间右下角的图标就是它的大类。 |
| 工坊与宝物图纸 | 建了工坊类建筑，出征才会掉宝物图纸。 |
| 首领建筑 | 每个区域的最终首领有一座自己的建筑，图纸只从它身上掉；建好后立着它的石像或铜像。 |
| 挖掘 | 点和房间相邻的岩层，花物资和天数挖开，挖通才能建房间。 |
| 建筑图纸 | 列表里只有你有图纸的建筑，×2 就是有 2 张。图纸靠出征和守城拿。 |

**领袖**

| 元素 | 说明卡 |
|---|---|
| 领袖 | 你的化身：出征带队，守城时站在主基地屋顶指挥。点卡片看天赋；卡片上的黄点 = 有没用的天赋点。 |
| 宝物 | 出征时带在身上的装备，出征失败也不会丢。 |
| 天赋树 | 每名领袖一棵自己的树，每三级长出一层，越往上越强。 |
| 职业 | 头像左上角是领袖的职业。职业决定技能：同一职业，技能永远一样。 |
| 领袖技能 | 每个职业一个技能：在场外指挥时按空格放，每场战斗一开战就能用一次。 |
| 升级选天赋 | 领袖升级后直接打开天赋页，可以当场学，也可以取消以后再学。 |

**出征**

| 元素 | 说明卡 |
|---|---|
| 传送门 | 点它打开，上方升起今天能去的世界碑，点碑出征。 |
| 难度 | 碑上的低 / 中 / 高：越难收获越多，图纸越好。 |
| 世界特产 | 碑下方的图标：这个世界多给的东西。悬浮看详情。 |
| 地图节点 | 图标就是这一站的内容：战斗、夜市、营火、宝箱、奇遇……鼠标悬浮看详情。 |
| 领袖生命 | 不会自动回复：靠营火、奇遇，或者回基地后的医疗建筑。归零就探索失败，基地核心献出一颗心救回领袖。 |
| 积分 | 这一局的钱：打赢战斗得到，在夜市和奇遇里花。回基地就清零。 |
| 本次收获 | 物资、经验、图纸要撤离或通关才带得回基地；出征失败只留下一半经验。 |
| 部队 | 战斗里自动作战。在夜市买、招募旗领；三支相同的会进化。 |
| 进化 | 同一种部队凑齐三支就进化成一支新部队，最多进化 5 次。 |
| 部队池 | 每个场景只出几种部队，商店和招募都从里面来。 |
| 小地图 | 整条路线的缩略图。越往右越深，最右边是首领。 |
| 战斗力 | 敌人头上是它的战斗力，你头上是你的。颜色：绿稳赢，黄有风险，红很危险。 |
| GOGO 灯 | 水果机顶上的灯。拉杆时亮了，这一把一定中铃铛以上。 |
| 章节 | 每个世界是一章，按顺序打；一章分几个区域，每个区域的尽头是它的最终首领。 |
| 路标 | 打倒一个首领就点亮一个路标，下次可以直接从这里出发。 |
| 连战 | 同一趟里每打倒一个首领，撤离时带回的物资和经验就多 15%。 |
| 刷图 | 通关过的章节会出现在碑上，直接从某个最终首领前的路标出发，去刷它的专属建筑图纸。 |
| 神龛 | 有了信仰值以后，地图上会出现神龛，在那里祈祷能收集信仰值。 |
| 今日修饰 | 每块碑当天带一个修饰：浓雾、血月、丰收……悬浮碑可以看。 |
| 难度 | 全部章节通关后开噩梦，噩梦通关后开地狱：同样的章节，敌人更强，收获更好。 |
| 场景 | 每个世界分几个场景，按故事一个接一个；打倒场景尽头的首领才算通关。 |

**守城**

| 元素 | 说明卡 |
|---|---|
| 守城 | 怪物攻打主基地：城墙挡路，防御塔开火，兵营出兵，领袖在屋顶指挥。主基地被攻破这一局就结束。 |
| 防御塔 | 地下每建一座防御建筑，地面就升起一座，守城时它自己开火。 |
| 防御罩 | 罩住的建筑和主基地先由护罩挨打；护罩破了，过一会儿会恢复。 |
| 加固 | 用物资把一座战斗建筑加固，最多三级，守城时更结实、打得更疼。 |

**战斗**

| 元素 | 说明卡 |
|---|---|
| 战斗目标 | 普通战：消灭所有敌人；坚守战：撑过倒计时。 |
| 积分 = 基础 × 积分倍率 | 击杀得基础分；精英、首领、FEVER、宝物会加积分倍率。积分就是这一局的钱。 |
| FEVER | 部队越打越热，槽满了自动爆发一次随机效果，接着 8 秒部队攻速更快。职业越多、前后排齐全，涨得越快。 |
| 小首领 | 每个区域的小首领都有自己的名字，名字写在它头顶。 |
| 指挥位 | 领袖站在左边指挥；部队全灭后亲自上场，撤离战和部队一起上场。 |
| 领袖技能 | 按空格放。 |
| 特性 | 卡片上那一句话就是这支部队的本事。开战时它的图标从身上亮出来，停在头顶，生效时会闪。 |
| 警示圈 | 技能要落下的地方，里面填满就放出来；红色是敌人的。 |
| 精英 | 更强的敌人，打倒它积分倍率 +0.1。 |
| 最终首领 | 场景尽头的首领，站在自己的地形里；血条过半进入第二阶段。 |
