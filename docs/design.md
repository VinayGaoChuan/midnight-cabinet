# 午夜机台 · 设计文档

> 这是游戏唯一的策划文档。**改设计 = 在同一次提交里改这份文档**：加减系统、改规则、改关键数值、加新元素，都要同步到这里（维护规则见文末）。数值的最终来源是代码；这里写规则、意图和关键数值。

## 1. 一句话

深夜的公寓里有一台午夜机台。投币后你在地下挖出一座基地，你的领袖（你的化身，只有一个）穿过主基地的传送门去异世界探险，把物资和图纸带回来，地下每建一座房间，地面上就升起一座建筑，城镇越来越繁荣；每 5 天守一次城——直到基地核心的三颗心用完，或者主基地被攻破。

**核心体验**：出征时“要不要再往前走一步”的贪心和风险；回到基地后“这次带回的东西怎么用”的规划；守城时“城墙和塔够不够”的准备。

## 2. 三层循环

| 层 | 在哪里 | 做什么 | 一次多长 |
|---|---|---|---|
| ~~房间~~（**已屏蔽**） | 午夜机台所在的房间 | 用代币买家具（永久加成）、选卡带、看成就 | — |
| 基地（局外） | 地下基地 | 按天推进（顶部时间轴）：挖掘、建造、选世界出征或休整一天、日程事件、每 5 天混沌来袭 | 十几天到几十天 |
| 一次出征（局内） | 异世界地图的一个场景 | 一站站往前走：战斗、夜市、奇遇；打败场景尽头的最终首领，或打过小首领后从撤离点走，带着收获回基地 | 2～4 个首领，12～23 站 |

一局结束的条件（任一）：
- **基地核心的心用完**（用户裁定 2026-09-26，恢复）：核心整局 3 颗心；探索失败时献出一颗复活领袖（§6.1），通关一个场景补回一颗（不超过 3）；探索失败时已经没有心可献，这一局结束。
- **主基地被攻破**：守城时主基地耐久打光。

**当前流程（2026-09-24 起）**：开场动画结束时镜头停在机台正面，机台屏幕上直接显示「开始游戏 / 继续」「玩法说明」「设置」（没有单独的标题页）；点开始游戏，镜头钻进屏幕 → 基地。基地是局外，出征是局内。一局结束时弹出结算（原因、坚持的天数、通关的世界数），可以「重新开始」或「回到标题」。基地右上角有「放弃」按钮：确认后清空这一局的所有进度（基地、领袖、建筑、物资、天数），从第 1 天重新开始；新手教学不会再出现，设置保留。
- **重新开始送序章奖励**（用户裁定 2026-09-24）：打过序章之后的每一局新游戏（放弃、结算后重新开始）都直接拿到序章结算给的东西——物资、碎片、经验球、领袖经验、找到的图纸（按玩家自己那次序章实际拿到的记在档案里；更早的档案按常见值：物资 +100、领袖经验 +100、1 张随机图纸）；序章教你盖的**酒馆已经建在主基地左边**，不用再盖。
- **新手引导暂时去掉**（用户裁定 2026-09-24：太乱，之后重新设计）：没有引导气泡、没有基地教学步骤、建筑建成后的提示也没有；初见说明卡不再自动弹出（「玩法说明」里仍能查到每一张）。序章还是第一次出征，只是不带提示；序章结束时酒馆直接建好（不再给酒馆图纸）。

房间系统（代币、家具、成就、卡带、月相、噩梦模式）目前**屏蔽**（`M.META_ROOM = false`，在 `src/mc-meta-a.js`）：家具和成就的加成全部不生效，下面 §4 的内容保留作为以后恢复时的设计。

## 4. 房间（局外成长，**已屏蔽**）

- **机台**：点它投币开始新的一局；有进行中的局时显示「继续 · 第 N 天」。
- **家具**（15 件，每件 1～3 级，花代币解锁 / 升级）：

| 家具（1 → 3 级） | 效果 |
|---|---|
| 水壶 → 咖啡机 → 多合一饮料机 | 每局前几天部队和领袖攻击 +10% → 前 7 天 +20%、部队生命 +10% |
| 旧冰箱 → 双门冰箱 → 冷库 | 初始物资 +150 → +250，带回物资 +25%，基地每天 +25 物资 |
| 存钱罐 → 保险箱 → 瑞士银行 | 把上一局的一部分物资 / 碎片带进下一局（15% → 50%，3 级还带最好的 1 件宝物） |
| 旧沙发 → 懒人沙发 → 按摩椅 | 初始领袖 +1 级 → +2 级，招募的领袖 +1 级，医疗回血 +50% |
| 攻略书 → 地图册 → 全知之书 | 出征视野 +1 → 整张地图可见 |
| 小苗 → 盆栽 → 世界树苗 | 每局多勘明 1～3 块特殊地格，3 级时主基地正下方必定是「灵脉」 |
| 收音机 → 唱片机 → 点唱机 | 事件好运 +10% → +15%，自带随机战旗，初始积分倍率 +0.2 |
| 挂钟 → 落地钟 → 时之沙 | 建造 -1 天 → -2 天，挖掘立刻完成 |
| 挂历 → 行事历 → 预言历 | 混沌来袭间隔 5 天 → 6 → 7 天，守城武器伤害 +40% |
| 相框 → 照片墙 → 纪念碑 | 领袖阵亡多留经验球 → 宝物全部保住、多留碎片 |
| 猫碗 → 猫窝 → 黑猫 | 地图必出「招财猫」；每局 1～2 次把倒下的领袖叼回来（不死、不扣核心） |
| 卡带架 → 卡带柜 → 收藏墙 | 解锁开局卡带（2 → 4 种，3 级可同时插 2 盘） |
| 展柜 | 开启成就系统 |
| 月相窗 | 每局随机月相：满月好运、新月便宜、血月更难但图纸翻倍、代币 +30% |

- **开局卡带**（4 种）：建筑师（+3 建筑图纸，至少 1 张奇观）、军火（+3 宝物图纸和 1 件稀有宝物）、招魂（+150 碎片、领袖上限 +1）、工兵（开局挖通 3 格、物资 +100）。

## 5. 基地

### 5.1 天数

每出征一次就过去 1 天；也可以点顶栏右边的「☾ 休整一天」不出征直接过一天（用户裁定 2026-09-25 加回来）。挖掘和建造按天推进，生产类建筑按天产出。

**时间轴**（用户裁定 2026-09-24 / 25，`src/mc-timeline.js`）：基地顶栏中间常驻一条时间轴（资源在顶栏左侧，右边是「休整一天」和「放弃」），10 个**圆形的日子节点**，节点之间隔一段距离、中间 3 个小圆点：当前这 5 天和下一个 5 天。每格写「今天 / 明天 / 第 N 天」，有事件的格子画事件图标、边框是事件颜色；过去的日子压暗、盖红「✕」；悬浮一格看事件名和一句话。
- **按 5 天推进**（用户裁定 2026-09-25）：时间轴不是每天滚。过一天（节奏照卡皮的「下一天」，2026-09-26）：今天那格白光一闪（0.25 秒）、盖「✕」→ 两天之间的 3 个小圆点一个一个点亮（每个一声）→ 金色的「今天」圈滑到下一个节点、回弹 → 新的今天白光一闪、跳一下（放大到 1.2 倍 0.15 秒，0.05 秒落回）；节点里平时写日子数字，有事件的画事件图标，下面只在今天 / 明天写字；这一天有事件时，屏幕中间打出事件名和一句话：事件名弹出（0 → 1.1 → 0.96 → 1.02 → 1，约 0.3 秒），下面铺一条事件颜色的底光、一明一暗地呼吸；混沌来袭改成从上面砸下来、略冲过头再站住、歪 4 度，同时红闪、警报、心跳。最后事件名缩到一半、0.2 秒飞回时间轴上的那一格，那一格白光一闪、再跳一下。
- **守完一次混沌来袭，整条往后推 5 天**，这是一场大演出，给下一段的期待感：时间轴放大、落到屏幕中间，屏幕压暗 → 过去的 5 天一格一格盖章掉落 → 整条向左滚 5 格（回弹）→ 新的 5 天一格一格弹进来，有事件的格子爆光 → 中间打出「新的五天」，下面红字写下一次混沌来袭是第几天，那一格一直跳 → 缩回顶栏。显示的这一段记在存档里（`m.tlWin`），所以重进游戏不会重演。
- **事件**（每种一句话，参与方式简单，选择有区别）：

| 事件 | 一句话 | 怎么参与 |
|---|---|---|
| 混沌来袭 | 怪物攻打主基地，领袖出来守城。 | 每 5 天一次（第 5、10、15…天），守完往后推 5 天；进入守城选将 |
| 流浪商人 | 用物资、碎片或经验球，换随机的好东西。 | 弹出 3～4 件随机货：一张建筑图纸（普通 / 稀有收物资，史诗 / 传说收碎片）、一张宝物图纸（60 经验球）、一颗地脉结晶（80 经验球，买下后镜头飞到那一格看它变成特殊地形）、一名至少稀有的领袖（70 碎片）或一件纪念品（70 物资）；想买几件买几件 |
| 幸运之星 | 三选一：下一次出征的祝福。 | 从 7 种里随机给 3 种：部队攻击 +20%、带回的物资 +50%、视野 +2、开局多带 2 个支援道具、每场战斗初始积分倍率 +0.5、领袖出发时回满生命、掉图纸的概率翻倍 |
| 地脉涌动 | 一格岩层变成随机的特殊地形。 | 自动：镜头飞过去，地形亮相，说出它的效果 |
| 疫病 | 领袖们病倒了：花物资治疗，或者每人失去 30% 生命。 | 二选一：花 40 × 领袖数 物资，或者硬扛 |
| 丰收 | 所有挖掘和建造各推进 1 天。 | 自动 |

- **每 5 天有 2 个事件**（用户裁定 2026-09-25：旧版每天四成的随机太稀，常常一整段只有混沌来袭）：每一段 5 天里，除了混沌来袭那天，从剩下的日子里随机挑 2 天，各放一种不同的事件（按权重：流浪商人 5、幸运之星 4、丰收 3、招募日 / 地脉涌动 / 疫病 各 2）。事件提前一段生成，存在存档里（`m.evs`），所以看到的就是会发生的。第 1 天不放事件。
- 旧存档（用户裁定 2026-09-25）：读档时按新规则把之后的日子重新排一次（`m.evV` 记版本），已经发生过的事件不动。

**待生效的效果**（用户裁定 2026-09-25，`src/mc-timeline.js` 的 `M.pendingFx`）：纪念品和事件留下的「下一次……」效果，在顶栏下面左侧排成一行，每个一格（图标 + 一句短话，悬浮看全句），用掉就消失：幸运之星的祝福（下一次出征）、迷踪粉（下一次混沌来袭怪物 -30%）、引荐信 / 招募日（下一次招募免费）、行军包（下次出征多带道具）、工匠（下一项工程少 2 天）。

**回到基地的顺序**（用户裁定 2026-09-24）：先结算（物资、碎片、经验球、图纸飞进顶栏，地脉结晶落进岩层，纪念品生效）→ 领袖阵亡（撕卡，核心受损）→ 领袖升级（升级仪式）→ 建筑建成（每座一次）→ 下一天（时间轴滚动）→ 这一天的事件 → 如果这一天轮到混沌来袭，进入守城。一件放完再放下一件（`src/mc-home.js` 的队列，按游戏帧推进）；这段时间不能出征。收获飞进顶栏时，**数字跟着每个图标落地一点一点涨**（不是等全部飞完才变）；图纸一律飞进主基地（仓库）那个房间；任何飞行的图标都落在屏幕里（用户裁定 2026-09-25：以前守城后图纸会飞到屏幕下面去）。地脉结晶落进岩层也一样演：镜头飞到那一格，地形亮相，打出地形名和效果，再回来。

### 5.2 挖掘与建造

- **主基地在地面上**（用户裁定 2026-09-25）：一座带传送门的仓库大楼——中间的拱门就是传送门（点它选世界出征），两翼是仓库（点它看物资、图纸和宝物），怪物混沌来袭时攻打的就是它（主基地耐久）。地下还是网格里的功能房间；原来地下第一排中间的主基地房间变成「升降井」，连着地面的主基地，点它也能打开仓库；挖掘只能从它和已有房间旁边开始。基地平时的镜头把地面的主基地和整片地下都放进画面。
- **地面城镇**（用户裁定 2026-09-26，`src/mc-town.js`）：地下每建一座建筑，地面就升起一座对应的建筑——建成那天它从地里拔起来（地面裂开、土块飞溅、晃着升起），在建的房间地面上是脚手架。所以地下建得越多，地面越繁荣。
  - **自动布局**：主基地在中间，建筑按类别左右对半分，每一类轮流发到两边，两边一直对称、整齐（同样的房间永远排成同样的城镇）。后排是民用建筑（生产、后勤、医疗、锻造、训练、运势、特殊），品质越高越靠近主基地；前排里侧是兵营，然后是防御塔——每秒伤害最高的在最里面，均匀铺满整个城镇，最外面那座紧挨着城墙，所以城墙前面总在塔的射程里；城墙在最外层，多道城墙紧贴着叠在一起，最坚固的在最外面。新建筑升起时，别的建筑一起滑到新位置。平时镜头随城镇变宽自动拉远，两头都看得见。
  - **城里的人**：生产、后勤建筑的人走出去采集，背着袋子回来，在门口卸下；锻造、训练、运势建筑的人在自家门口干活（打铁、打木桩、祈祷）；其他人四处闲逛。每座建筑 1 人，奇观 2 人；城墙、兵营没有。混沌来袭一开始，所有人跑回自己的建筑里，防御塔的射手、炮手、法师这时出现在塔顶。领袖站在主基地屋顶，平时观望，守城时挥旗指挥。
  - 地面建筑可以悬浮、点击，和点它的地下房间一样（地下的房间同时被框出来）。
- **繁荣度与地块**（用户裁定 2026-09-26，`src/mc-rules26.js`、`src/mc-prosper.js`）：地下每座建成的建筑都增加繁荣度，品质越高加得越多（界面上只写「繁荣 LvN」和到下一级的进度条，不写具体数字；内部：普通 10、稀有 25、史诗 45、传说 70；Lv2 / Lv3 / Lv4 需要 40 / 120 / 260）。开局只解锁升降井周围一圈（5 格），每升一级向外解锁一圈，Lv4 解锁整片岩层。拆掉建筑繁荣度会降，但已经解锁的地块不会再锁上。
  - 没解锁的地块是**纯黑的**，看不到特殊地形，也不能挖；悬浮只写「繁荣度升到 LvN 解锁」。
  - **扩张演出**：升级那天，在建成的房间亮过之后、翻日历之前：一圈金色光波从升降井往外推到新一圈的边上；新一圈的黑块按离升降井由近到远，一格接一格裂出发光的缝、碎成黑色碎片飞走，露出下面的岩层；露出特殊地形的那一格亮起它的颜色和名字；最后横幅「繁荣度 LvN · 地块向外扩了一圈」。
- **损毁、修复与拆除**（用户裁定 2026-09-26）：守城时被打塌的地面建筑变成废墟，它的地下房间**不起作用**，直到修好——房间面板里「修复 · N 物资 · 1 天」（建造费的 40%，至少 30）。任何建筑都能拆（升降井除外）：「拆除 · 50 物资 · 1 天」，要点两次确认；拆除中的房间立刻停止生效，拆完图纸收回、地形保留，房间变回空房间，地面建筑沉回地下。
- 只能挖**和已有房间相邻**、**已经解锁**的格子，花物资和天数：岩层 50 物资、1 天；特殊地形叫「开垦」，按地形 1～3 天，价格 = 50 ×（1 + 开垦天数），即 100 / 150 / 200（用户裁定 2026-09-24：特殊地形更贵，挖不挖是个选择，不是必选）。还没勘明的地脉按岩层价。挖通后成为空房间。
- 点了「挖掘 / 开垦」或建造之后，面板自己关掉（用户裁定 2026-09-24）。
- **照明**：主基地、史诗 / 传说建筑照亮周围 2 格；普通 / 稀有建筑和空房间照亮周围 1 格。
- **建造列表和地形**（用户裁定 2026-09-25，`src/mc-buildui.js`）：空房间在特殊地形上时，契合这个地形的建筑排在最前面，名字后面一个闪烁的「★ 契合地格」；只有通用效果的不标（通用效果对谁都一样），列表下面也不再重复地形说明。悬浮一个建筑：建筑的一句话，下面写一次「地格「晶簇」」和它的两行——「✔ 任何房间：……」（总是绿）、「✔ / ✘ 契合「科幻」：……」（契合绿勾，不契合红叉），不再另外重复一遍生效的效果。
- **点还没开垦的地形**：除了开垦按钮，还列出你手上有图纸的所有建筑，排法和建造列表一样（契合的在前、闪烁），这样挖之前就知道这格值不值得开。
- 在空房间里建造需要：**对应的建筑图纸**（列表里只出现你有图纸的建筑，×2 = 有 2 张）、物资、天数，史诗 / 传说建筑还要灵魂碎片（史诗 30、传说 60）。
- **没有电力**（用户裁定 2026-09-24）：不再有电力限制和任何电力数字。原来的 4 座发电建筑改成「生产」类：蒸汽工坊（原发电机）每天 15 物资、马丘比丘每天 15 物资 + 20 经验球、鲁尔区每天 45 物资、埃菲尔铁塔每天 4 碎片 + 武器伤害 +30%。
- 建筑分 4 个品质，45 座（2026-09-26 加了石墙），按**功能**分：仓库、生产、锻造、医疗、招募、训练、后勤、防御、运势、特殊；按**风格**分：蒸汽、魔法、自然、水域、玄幻、科幻、中世纪、卡通（主基地自成一类）。完整列表见附录 A。
- 奇观 = 稀有及以上的名胜建筑（埃菲尔铁塔、金字塔……），效果最强。

### 5.3 特殊地格

岩层里散布着 22 种特殊地格（特殊地形）。**和岩层混在一起的特殊地形就不是岩层**：
- 每种地形在基地里画成它自己的样子（地热的熔岩裂缝、晶簇、世界树根、龙骨……，`src/mc-terrain-art.js`），**不挂单独的图标**；鼠标放上去就显示它的详细信息（任何房间的效果、契合时的效果、开垦费用和天数）。
- 开垦天数和岩层不同，每种地形不一样：松软土层、陶土层、地下泉、风穴 1 天；化石层、古遗迹、琥珀层、灵脉、裂隙、英灵冢、时之沙、梦境裂隙、地热 2 天；晶簇、金脉、富矿脉、龙骨、大地之心、陨星坑、雷暴核心、世界树根、王座遗骸 3 天。
- 地块没解锁之前全黑，看不到地形；一解锁就看得见（以前深层「未勘明的地脉」的规则取消，用户裁定 2026-09-26）。
- **地脉结晶**（出征带回、商人、灵脉事件）只改造已解锁的地块：先挑空房间，再挑岩层；都没有时改造一间已经建好的房间——优先选地形和建筑「契合」的，否则随机。
- 开垦后在上面建房间：**任何房间**都能拿到通用效果；建筑的**功能或风格「契合」**时，再拿一份更强的效果。房间地面留一道该地形的纹路。建造列表里只有契合的建筑带闪烁的「★ 契合地格」（§5.2）。完整列表见附录 B。
- 建好之后，房间面板只写**还在生效**的那部分，每条后面一个绿勾（「基地每天 +15 经验球 ✔」）；悬浮说明和建造时一样，地格的两行各自打勾 / 打叉，只写一次；只在建造时起作用的地格（古遗迹）建成后直接消失。

### 5.4 房间标签

每个房间角上两个图标：左边**风格**，右边**功能**。地格和奇观用它们挑选「契合」的建筑。

## 6. 领袖

### 6.1 基本

- **只有一个领袖**（用户裁定 2026-09-25，`src/mc-solo.js`）：它就是玩家的化身，出征的指挥官；守城时站在主基地屋顶指挥，不参战（用户裁定 2026-09-26）。**没有品质**，**等级上限 20**（领袖详情里写「Lv 5 / 20」）。每开一局新游戏，职业随机。没有招募、没有领袖上限（招魂台、酒馆、扩建、巨石阵保底、吴哥窟上限这些全部删掉或改成别的效果，见附录 A）。
- **出征失败 → 复活仪式**（用户裁定 2026-09-26，`src/mc-revive.js`）：这一趟的收获丢掉，只留下一半经验（2026-09-26：输了也往前走一点），带着的宝物不丢，照样过一天；回到基地后先演一场不能跳过、不用操作的复活：领袖的卡飞到屏幕中间，越绷越紧、心跳越来越快，撕成两半（「领袖倒下」）；守夜的主教从左边走进来，六根蜡烛一根根点亮，他举着法杖一句句念悼词（「长夜还没有结束，灯还亮着。」「机台记得每一个没有回来的人。」「以核心的一颗心，缝好你的名字。」「醒来吧，驱魔修女。」；这是最后一颗心时第三句是「这是核心的最后一颗心。」）；顶栏基地核心的一颗心离开，拖着红色的尾迹划一道弧飞进两半卡片中间，跳三下，红线把两半缝起来，缝口变成金色；白光一闪，大字「复活」，写着「基地核心 N / 3」，卡片带着一道金色的疤飞回领袖头像，**领袖满血**。
  - 核心里已经没有心时：悼词第三句是「……核心里，已经没有心了。」，顶栏的核心碎掉，两半卡片掉下去，接着基地爆炸，这一局结束。
  - 序章失败不扣核心、不演仪式。守城时领袖不参战，所以不会在守城里倒下。
- **开局建筑**：新的一局主基地旁边先有一间普通品质的医院（以前是酒馆），领袖每天自己回血。
- 属性：生命、攻击随等级涨（每级 +10% / +12%），天赋和宝物再加。
- 6 种领袖职业（守夜人、赌徒寡妇、驱魔修女、屠宰场主、钟表匠、焚尸人），每种有自己的技能。
- **领袖没有个人名字**：职业就是名字，也代表技能——同一职业永远是同一个技能。每个职业有自己的职业图标。
- **基地领袖卡片**：左上角角标「Lv2」；半身像；下面只写职业名；血条；右上角黄点 = 有没用的天赋点。左下角只有这一张，不再写「领袖 1 / 6」。
- **生命不会自动回复**：营火、奇遇、医疗建筑、地下泉。
- 旧存档（2026-09-25）：多名领袖只留等级最高的一名，品质去掉，天赋树按新的样子重长、点数全退；经验球全部变成它的经验；招魂台 / 酒馆变成医院，这两种图纸按 60 物资一张退掉。旧存档（2026-09-26）：基地核心补满 3 颗心；繁荣度按已经挖开的范围给到足够的级别，已经挖开的地块都不会变黑；主基地耐久按比例换算到新的基数。

### 6.2 领袖技能

每个职业**一个技能**，就是场外指挥时按空格放的**军团技能**，冷却按走过的站数算（用户裁定 2026-09-24 合并成一个名字；2026-09-26 删掉「领袖亲自上场后自己放」的那一半——领袖上场后只会普通攻击，技能照样可以按空格放）。

| 领袖 | 技能 | 按空格 |
|---|---|---|
| 守夜人 | 照夜 | 所有敌人停顿 |
| 赌徒寡妇 | 梭哈 | 8 秒内每次击杀积分倍率 +1 |
| 驱魔修女 | 圣咏 | 全队回血 |
| 屠宰场主 | 血祭 | 献祭生命最低的部队，积分倍率 +1 |
| 钟表匠 | 倒带 | 部队攻速 +100%，6 秒 |
| 焚尸人 | 火葬 | 点燃所有敌人 |

- **领袖上场后技能照样能按**（用户裁定 2026-09-25）：场外、场上都能按空格放（冷却和每场一次不变）。技能没有可作用的对象时直接变灰：血祭要献祭一支部队，场上没有部队时不能放（「没有能献祭的部队」）；圣咏、倒带都包括领袖自己。
- **领袖什么时候上场**（用户裁定 2026-09-25）：所有战斗（包括首领战）都是部队全灭后领袖才上场；只有**撤离战**领袖和部队一起上场，撤离战的怪物也多一些（每波 0.48 倍预算，别的坚守战 0.45；2026-09-26 从 0.62 降下来——打完首领的残兵撤离时死得比往前走还多）——在规定时间里没有全灭就撤离成功。
- **领袖倒下不一定输**（用户裁定 2026-09-25）：部队还有人站着，仗就继续打；只有领袖和部队都倒下才算输。打赢了领袖以 1 点生命爬起来。
- **守城时领袖不放技能**（用户裁定 2026-09-26）：它站在主基地屋顶指挥，是个摆设。
- 领袖头像的悬浮说明：「Lv2 驱魔修女 / 血条 / 圣咏：全队回复 36% 生命，冷却 3 个节点。」没有 Ctrl 这一层。技能按钮（地图顶栏、战斗里）、天赋树中心的悬浮说明也是这一句。

### 6.3 成长

- **经验直接给领袖**（用户裁定 2026-09-25）：出征回来、守城结束、每天的训练类建筑，经验直接加给领袖，够了就升级并播放升级仪式；没有经验球，也没有「升级」按钮。每级 1 个天赋点，满级 20。
- **天赋树**（用户裁定 2026-09-25，参考《英雄无敌》的副技能，`src/mc-talent.js`）：每名领袖一棵**自己的随机树**，根是它的技能。
  - **分层**：第 1 层的格子只会随机到第 1 层天赋，第 2 层只会随机到第 2 层天赋……同一种天赋，层数越高数值越大（第 1～6 层 = 第 2 层数值的 ×0.7 / ×1 / ×1.35 / ×1.75 / ×2.2 / ×2.7），有的天赋只在高层出现（神秘术、狂怒、宝物大师、建筑学、招魂术、集结、统御……）。点一个天赋要先点它下面连着的那个。
  - **树的样子**：只有一个领袖以后，它总是长最高的那种树（6 层，19～23 个天赋）；下面是以前按品质分的形状：普通 3 层（每层 2～3 格，6～8 个天赋）、稀有 4 层（10～12 个）、史诗 5 层（14～18 个）、传说 6 层（19～23 个）。每层从上一层的格子里长出 0～2 个分支（根上最多 3 个），所以有的枝往上长、有的就停了。一棵树里不会有和父节点、子节点、兄弟节点重复的天赋。
  - **每三级一层**（2026-09-25，满级从 10 提到 20）：第 k 层在 Lv 3k−1 展开（Lv2、5、8、11、14、17）；还没展开的下一层只显示成一排「?」，左边写「LvN」。升级仪式最后一段专门演这一层：「第 N 层天赋」，这一层的天赋一个一个弹出来，下面写名字（颜色 = 作用范围）；之后第一次打开这名领袖的详情，新的一层也会弹出来。
  - **大小自动缩放**：树框里只画展开的层 + 下一层的「?」，层越少格子越大（最大 72），6 层时缩到 44；左边是层号，底下是颜色说明「领袖 部队 出征 基地」。格子小的时候不在每个格子下写「按住」，右下角统一写「按住发光的天赋学习」。
  - **作用范围**写在每一句里，颜色也不同：**领袖**（金，只作用于这名领袖本人）、**部队**（红，这名领袖出征时带的部队）、**出征**（青，这名领袖出征时的收获和地图）、**基地**（绿，这名领袖活着就每天生效，作用于整个基地或所有领袖）。例：「好体质：本领袖住院时，每天回复的生命 +50%。」（原来的「医院疗养速度 +50%」说不清是谁的，用户裁定 2026-09-25）。
  - **有的天赋改变打法**：考古学（掉图纸的概率 +x%）、集结（每有 1 支某职业部队，全体攻击 +x%，鼓励堆一个职业）、混编（每有一种职业，全体生命 +x%，鼓励混搭）、征兵术（开局多带某职业部队）、赏金（精英战、首领战积分 +x%，鼓励走精英）、货郎（卖部队的商店多摆几支）、狩猎（打赢有概率捡支援道具）、寻宝术（宝箱积分 +x%）。每棵树至少有 1 个这类天赋和 1 个基地天赋（10 格以上的树各至少 2 个）。
  - 完整的天赋表见附录 E。旧存档：旧的三条路线整棵换成新树，学过的天赋点全部退回（用户裁定 2026-09-25）。
- **宝物条目写清作用对象**（用户裁定 2026-09-25，和天赋同一个问题）：「部队暴击率 +x%」「领袖每场战斗后回复 x% 生命」「打仗得到的物资 +x%」「领袖出征得到的经验 +x%」「奇遇出好结果的概率 +x%」……；「领袖技能冷却 -x%」换算成节点：约 7% 起少 1 个、约 40% 起少 2 个（旧版不到 17% 的条目实际不起作用）。
- **宝物**（13 种）：出征时带在身上。锻造建筑里用宝物图纸 + 120 物资打造，品质随机；精铸多花 40 碎片，至少史诗。宝物格数量随领袖和建筑增加（紫禁城、王座遗骸 +1）。

## 7. 出征

### 7.1 选世界

- **没有世界列表页。** 传送门平时是一座暗的石拱门，没有漩涡。点它 → 传送门打开（漩涡转起来），上方升起今天能去的世界**碑**（石碑造型，参考《暗黑地牢》的区域牌）。第 1 天 1 块（低），第 2～5 天 2 块（低、中），第 6 天起 3 块（低、中、高）；第二天换一批。
- 碑上有三样东西：**场景名**（最上面）、**难度**（骷髅 + 低 / 中 / 高）和**特产图标**。悬浮碑看详情：标题「世界 · 场景」，第一行是难度和它给什么（「难度中：物资 ×1.4、经验 ×1.3，图纸更常见、品质更好」），然后场景的故事、「场景 2 / 3 · 3 个首领」、每项特产的效果、「开局的仗约 N，首领约 B」「你出发时约 M」、主题敌人。
- **难度是碑自己带的**（用户裁定 2026-09-25，`src/mc-danger.js`）：以前的「危险度」是拿你的战斗力去比，玩家变强以后所有世界都显示「低」，而且低的世界照样掉高级图纸。现在每块碑固定一个难度，决定这一趟的敌人和收获：

| 难度 | 敌人等级 | 敌人强度 | 物资 | 经验 | 图纸掉率 | 图纸品质（普通 / 稀有 / 史诗 / 传说） |
|---|---|---|---|---|---|---|
| 低 | +0 | ×1 | ×1 | ×1 | ×1 | 82 / 15 / 2.6 / 0.4 |
| 中 | +0.6 | ×1.05 | ×1.4 | ×1.3 | ×1.3 | 55 / 32 / 11 / 2 |
| 高 | +1.2 | ×1.1 | ×1.9 | ×1.7 | ×1.7 | 28 / 38 / 25 / 9 |

- **世界 → 场景**（用户裁定 2026-09-26，`src/mc-scenes.js`）：每个世界分 2～3 个场景，每个场景有自己的故事，故事决定它有多长，所以**场景的长度是固定的**。每个场景的尽头是它自己的**最终首领**，场景就以它命名（精灵之森：德鲁伊 → 知识古树 → 精灵女王）；场景中间的首领是**小首领**。场景按故事顺序来：一个世界的碑总是通向它第一个还没通关的场景；打倒场景尽头的最终首领 = 这个场景通关（基地核心补一颗心），**最后一个场景通关才算世界通关**。全部通关的世界只在没别的可选时才出现，这时随机重打一个场景。20 个场景和最终首领见附录 G。

- **小地图在屏幕右上角**（用户裁定 2026-09-25）：和左上的领袖面板顶边对齐。
- 每个单位有 1 个或多个**特性**（共 145 种），卡片上的一句话由前两个特性的短句拼成（`src/mc-awaken.js` 的特性表 `TR`，一条特性一句，不写数值）；没有特性的单位写它的职业用途。

#### 7.5.1 小玩法演出（用户裁定 2026-09-25：局内玩法要有表演，调动获得感）

**原则**
1. **结果先定，演出后挑**：概率一点不改。结果在按下按钮那一刻就定了，演出只决定怎么把它端出来——「差一点」「听牌」「升格」都只在结果本来就是这样时才演。
2. **四拍**：预期 → 悬念 → 揭晓 → 回响。赢得越大，悬念拉得越长、回响越响；没中就一拍带过（≤ 0.4 秒）。
3. **舞台会跟着紧张**：听牌时舞台压暗、聚光灯罩住关键的那一格、镜头往里推 6%～10%、灯珠越跑越快、心跳一下比一下急；揭晓的一瞬间全部松开。
4. **每一次揭晓都要连到落点**：奖励从舞台飞进计数器，舞台上同时滚一个「+数字」，滚完计数器鼓一下。
5. 所有长演出都能点一下快进（§11.6），但不会跳过结果本身。

**中奖分四档**（`M.SHOW.win`）
| 档 | 例子 | 演出 |
|---|---|---|
| 1 小中 | 两颗樱桃、押中红黑、普通果子 | 「+数字」滚 0.4 秒、奖励飞出、一圈光 |
| 2 中 | 三连水果 / 铃铛、稀有部队、双倍返还 | 加一记炸光、灯珠快闪、「+数字」滚 0.8 秒 |
| 3 大赢 | 三个 BAR、史诗、骰子全胜 | 画面停一拍、白闪、光芒、金币喷泉、「大赢」章砸下、灯珠换色频闪 |
| 4 大奖 | 777、押金中了、传说、一次清空奖池 | 先黑场 0.2 秒 → 聚光 → 「大奖」逐字砸下 → 满屏金币雨和彩纸 → 计数器越滚越快、音调越来越高，约 2.5 秒 |

没中（`M.SHOW.lose`）：舞台灰一下 0.25 秒、一声轻响、灰字，马上可以再来。**差一点**（`near`）：落空但离大奖只差一格时，那一格在线外抖一下，打「差一点！」小章——同样一拍带过，不拖。

**悬念工具**（`M.SHOW`，文件 `src/mc-show.js`，每个小玩法共用）

### 7.6 带回

撤离或通关后，本次的**物资、经验、碎片、图纸**带回基地；出征失败则这一趟的收获丢掉，只有一半经验留给领袖（领袖和宝物不丢）。此外还可能带回**纪念品**（9 种），在基地生效：矿工队、工匠、修门石、启示卷轴、淬火石、安神香、迷踪粉、补给箱、行军包（见附录 E）。宝物和建筑不能直接带出，只能带图纸。
- **图纸从哪来**（用户裁定 2026-09-25：以前图纸掉得太多）：只有两个**固定**来源，各给 1 张随机建筑图纸——通关一个场景（打倒它的最终首领）、守住一次混沌来袭。其余都是**小概率随机**，建筑图纸和宝物图纸各半：普通 / 坚守战 3%、精英战 8%、中途首领 12%、宝箱 10%（撤离战不掉）；乘以难度的掉率（§7.1），再乘以晶簇（+20%）、领袖天赋「考古学」（+20%～100%）、幸运之星的「掉图纸的概率翻倍」、血月、蒸汽铸造厂（常掉宝物图纸，×2）。品质按这一趟的难度（守城按中）。奇遇里明确给图纸的结果照旧。
- **收获一件一件摆出来**（用户裁定 2026-09-24）：地图顶栏里，图纸、地脉结晶、纪念品这类稀有收获每件单独一格（图标 + 名字，颜色 = 品质），和积分、物资、经验并排，放不下就换行，不做滚动区。战斗结算的奖励格、出征结束画面的奖励格也一样。
- 悬浮任何一件都告诉你**它有什么用**：建筑图纸 = 那座建筑的一句话（弩炮室图纸：「守城时向地面射击。」）；宝物图纸 = 打造出来的宝物前两条能力；地脉结晶 = 它把一格变成什么地形、有什么效果；纪念品 = 它的效果（启示卷轴：「带着它回来的领袖获得 1 个天赋点。」）。

- **法力特性按时机释放**：带法力特性的部队上场时法力已满（法力条边框闪烁），但不会一开场全放——每个特性有自己的**触发条件**，满足才放，放完重新攒。敌人从 0 开始攒法力，用同样的触发条件。触发条件分几类（`src/mc-skilltrigger.js`，每个单位的具体条件见 `docs/characters.csv` 和 `docs/effects.md` 的 U 表）：
  - 治疗类：有友军生命低于一定比例（治疗链 70%、颅骨炖汤 60%）；以血换血类还要求自己生命高于 50%。
  - 近身范围类（禁果）：身边有 3 个以上敌人。
  - 落点范围类（炮弹休克、铁之冰雹、剑雨、剑刃风暴）：射程内的目标附近有 2 个以上敌人扎堆。
  - 群体类（闪电打击）：攻击范围内有 3 个以上敌人。
  - 强化自己类（太阳耀斑、神盾、急速射击……）：敌人进入攻击范围；精神扭曲：攻击最高的友军开始交战。
  - 单体重击类（法力爆裂、小行星、能量涌动）：射程内的目标生命还多（≥ 40%）。
  - 召唤类：有敌人逼近到 600 以内；扣血召唤（次元裂隙）还要求自己生命够扣。
  - 所有“N 个以上敌人”的条件，在敌人总数少于 N 时按剩下的数算，不会因为敌人太少而永远不放。
- **目标**：普通战消灭所有敌人；坚守战撑过倒计时。
- **积分 = 基础积分 × 积分倍率**：击杀得基础分；精英 +0.1、首领 +0.3 积分倍率，战旗 / 宝物 / 特性继续叠加。
- **领袖**站在左边的指挥位，不参战；部队全灭后亲自上场（撤离战一开始就和部队一起上，§6.2）。领袖和首领每出手一次，屏幕震一下（用户裁定 2026-09-26）。

### 8.0 击退与击飞（用户裁定 2026-09-26，参考《英雄之时》，`src/mc-knock.js`）

- **推多远 = 攻击者的力量 ×（这一下打掉对方最大生命的比例）^0.7 ÷ √对方的分量**。力量看体型和品质（领袖 2.2、首领 2.4），分量看体型、品质、是不是精英（精英更沉，召唤物更轻）。所以强打弱会把人打飞，弱打强几乎推不动——品质差和战斗力差自己就体现出来，不用另外的规则。
- 攻击方式：近战顺着出手的方向推；远程只推一点（×0.55）；技能 ×1.4、暴击 ×1.5、重击 ×1.2；爆炸从爆心往外推（×1.2）。持续伤害（燃烧等）不推。正在施法的单位只晃一下。
- 四档：很小——只抖一下；中等——往后滑，脚下扬尘、地上留一道擦痕，短暂硬直（0.06 + 力度 × 0.3 秒）；很大——**击飞**：往高处飞、横向落得不远（飞得高、落得近，避免被打出老远再走回来拖慢战斗），空中转体、身后三道残影，落地弹一下、一圈尘土，倒地 0.22 秒再爬起来；在空中再挨打会被打得更高（浮空连击）。**致命一击**：尸体被远远抛出去、转着落地、淡出——这一下纯看的，不影响战斗。
- 滑出去、飞出去的单位撞上自己人，会把对方也撞开（像保龄球）；撞到场地边上弹回来。
- **领袖和首领永远不会被击退**；它们每出手一次，屏幕震一下（首领更重）。
- 对数值的影响（`.ai/sim-kb.js`，普通 / 精英 / 首领各 400 场，开 / 关对照）：普通战时间 +12%，首领战 +20%；同一个战斗力比值下我方胜率高 5～15 个百分点（我方部队品质高、推得动敌人）。

### 8.1 战斗力（用户裁定 2026-09-24，自己算、说得清）

- **一方的战斗力 = √(全体总生命 × 全体每秒总伤害)**，按战斗里真实生成的数值算：我方 = 所有部队（战旗、领袖天赋和宝物、本局加成都算进去，开局护盾算作额外生命）+ 领袖（按当前生命）；敌方 = 这一仗的全部敌人（按天数放大、精英 ×1.15、首领护甲 ×1.3）。
- 单个部队 / 领袖的战斗力用同一个公式：√(生命 × 每秒伤害)。所以整队的数和单位的数是一套尺子。
- **为什么是这个公式**：两队对打时，一方能扛多久看总生命，打多快看总秒伤，双方互相消耗，谁的“生命 × 秒伤”大谁赢（兰彻斯特平方律）。用 3000 场无画面模拟标定（`tools/sim-power.js`，随机阵容、领袖、世界、普通 / 精英 / 首领 / 坚守）：按「我方 ÷ 敌方」排序预测胜负的准确度（AUC）0.96（2026-09-24 职业改版后重测 4000 场；有了前排，阵容搭配本身更重要了）。实测胜率：比值 ≥ 1.25 约 99%，1.1～1.25 约 94%，1.0～1.1 约 80%，0.9～1.0 约 74%，0.6～0.9 约 55%，低于 0.6 约 22%。
- 特性、技能、站位会让结果有出入（比如召唤、治疗、群伤），所以“黄色”区间要看阵容。
- 坚守 / 撤离战只要撑过倒计时，地图上显示的敌方战斗力按全部波次的 0.7 算。
- **首领战的显示系数**（用户裁定 2026-09-25：「两边战斗力一样，结果我碾压了」）：用 300 场无画面首领战和精英战对照标定（`.ai/sim-boss2.js`）。领袖首领战一开始就上场时，首领要乘 0.75 才和精英战同一个意思；现在首领战也是部队全灭后领袖才上场，首领按 1.05 显示——同一个比值在两种仗里胜率一样（1～1.15 都是七八成）。
- **单独的首领**（2026-09-26 起首领战只有首领一个）：用 `.ai/sim-boss3.js` 各 400 场重标——小首领带两招蓄力重击，按 **1.26** 倍显示；最终首领出手慢、部队能沿整条地形边缘打它，按 **0.92** 倍显示（`M.MB_SHOW` / `M.FB_SHOW`）。标完后两种首领和普通战同一个意思：显示 1～1.15 胜率 56～72%，1.15～1.35 胜率 83～92%，1.35 以上约 99%。最终首领一场 1～2 分钟（比值 1.35 以上约 1 分钟），时限 240 秒（别的仗 150 秒）。
- **首领按同一站的精英战标定**（只缩放首领本体）：第一段的小首领 = 精英战 × 0.75（这时玩家只在一个夜市买过兵）；之后的小首领 × 1.0，最终首领 × 1.15（2026-09-26 成长模拟后从 1.0 / 1.3 / 1.45 降下来——首领单独出场、显示改诚实之后，旧的倍数让机器人第 2～5 天就把三颗心输光）。以前地图前段的首领是周围战斗的三倍，是“总被首领打死”的另一个原因。

### 8.3 首领战（用户裁定 2026-09-26，`src/mc-bossfight.js`、`src/mc-titan.js`）

- **首领战只有首领一个**，没有别的敌人。场景中间的是**小首领**，场景尽头的是**最终首领**。
- **小首领**：一个巨大的敌人（比平时的首领再大 1.4 倍），会走会打，普通攻击每一下都震屏；另有两招蓄力重击，轮流用，每 6.5 秒左右一次，蓄力 1.1～1.2 秒，地上先亮红色警示：**重击**——目标脚下一个圈（半径 170），圈里的单位受 1.6 倍攻击的伤害并被击飞；**横扫**——面前一个扇形（半径 300），扇形里的单位受 1.2 倍伤害并被击飞。
- **最终首领**：
  - **地形**：战场右边是它的地形（岩浆、海水、树根、月池、坟坑……附录 G），谁都走不进去。它从地形里升起来（2.2 秒，地形翻涌），只露出上半身，站在原地不动；近战部队走到地形边上就能打到它，沿整条边都行。

  - **震击**：双拳砸在面前（落点选部队最密的一条线，半径 250 的圈）：圈里的单位受 0.6 倍攻击的伤害并被击飞；**不在圈里的其他单位被冲击波击倒**（倒地 0.6 秒，不掉血）。地面裂开，一圈冲击波扫过整个战场。
  - **扫臂**：一只手臂横扫面前一大片扇形（半径 820，左右各 62°，几乎整个前场）：扇形里的单位受 0.35 倍伤害，全部被击飞。

  - 招式顺序：第一阶段震击、扫臂轮流；第二阶段震击、天降、扫臂、天降。每招之间歇 1.4 秒。

  - **死亡**：沉回自己的地形（2.4 秒，连串爆炸、白闪），战场多停一会儿让人看完。

- **用词**（用户裁定 2026-09-24）：基地被混沌来袭、领袖在地面迎战这件事叫**守城**；「**防御**」只是房间的功能标签（弩炮室、兵马俑……）。以前混用的「防守」全部改掉：建筑说明写「守城时……」，地格的契合写「防御」。

### 10.1 基地像素房间（用户裁定 2026-09-25：整个基地都是真像素画，房间要最 juicy、最惊艳，并为以后的 HD-2D 提前准备）

**做法**（`src/mc-pxroom.js` 引擎、`src/mc-pxroom-kit.js` 风格外壳 / 岩层 / 空房间、`src/mc-pxroom-a.js` 房间）：
- 房间按美术分辨率画：150×105 格，一格 = 2 个世界单位（和角色同一像素尺度），地面顶在第 90 行。不用渐变、不用抗锯齿、不用模糊光晕；房间外框是 2 格墨框 + 1 格斜面边，稀有及以上加品质色细线，史诗 / 传说有光点沿边框跑、传说四角闪。
- **颜色按材质色阶**：石、砖、木、铁、黄铜、铜、布、叶、土、水、瓷砖、科幻板、魔法石、火、灯光……每种 8–12 级，暗部统一收进角色色板的夜蓝（`pcd/lib/pcd.js` 同一组暗色），亮部偏暖，阴影偏蓝紫。
- **四个深度层**：墙（0）、靠墙（5）、中景（14）、前景（26，离眼睛最近的吊链、管子、煤桶）。每格记：材质、色阶位置、朝向（法线）、发光、深度。
- **每帧打光**：房间自己的灯（锻炉火、火把、吊灯、屏幕、水晶、补光灯……）把每一格沿自己的色阶往上 / 往下推，光圈是硬边色带，交界只有 1 格宽的网点；有颜色的灯让受光面带上灯的颜色（硬分 6 档，不抖网点）；金属、玻璃、水、瓷砖有高光。灯会闪（火焰、烛火、日光灯偶尔闪一下、脉冲），也会被动作点亮（铁匠一锤满屋一亮、安全阀喷汽警示灯一红、召魂时水晶一亮）。会动的灯（摆动的吊灯、上下的吊笼灯）用沿轨迹的几盏灯交替渐变。
- **会动的东西**每帧重画并同样受光：像素火焰（热量扩散元胞自动机）、齿轮 / 飞轮 / 叶轮、植物梢头摆动、心电图、水面、锦鲤，以及房间里的工人（约 26 格高的像素小人：铁匠抡锤、工人拧螺栓、护士巡房、召魂者举杖、农夫浇水、管理员拖地、搬运工搬箱）。
- **粒子**是单格像素，按寿命走色阶（白 → 本色 → 暗）：火星（上飘、会照亮周围的墙）、火花（飞溅、落地弹跳）、蒸汽 / 喷雾（网点透明）、气泡、水滴（落地溅开）、灵魂、符文、治疗十字、闪光。光柱是一束硬边分档的半透明光，同时照亮它经过的东西；水面光影是一片流动的光。
- **视差**：镜头左右移动时，前景层比中景、中景比墙多移动 1–2 格，地面按远近逐行错开，房间像一个小立体布景。
- **互动**：悬浮一个房间，灯亮一点、一粒光点沿边框跑；点房间，所有灯一闪、灯位冒闪光、房间弹一下；房间建成（或挖通），灯按顺序一盏一盏闪着亮起来、顶上落灰、最后房间弹一下再轻震。
- **空房间**：岩壁、矿道木架、一盏吊灯在绳上摆（光影跟着摆）、飞蛾绕灯、镐和木箱、角落蛛网。**岩层**：3 种像素岩层（岩带、圆石、裂纹、矿物闪点）。
- **地面上的主基地**（用户裁定 2026-09-25：全游戏最精致的一件，`src/mc-pxroom-base.js`）：一座夜里的仓库大楼，380×210 格、透明底，盖住整个地面主基地和通往地下的井口。两翼不一样：左翼是仓库（红砖下层、半卷起的铁皮卷帘门里透出暖光和货箱、木装卸台，木构上层有吊货门和伸出来的吊梁，吊着的麻袋定时放下吊起，屋顶三扇天窗、墙角爬满常春藤），右翼是账房（暖色石砌下层、两扇拱窗、带铁钉的正门和门灯、摇晃的金币招牌，上层有带小屋顶的凸窗和摆着花盆的铁栏阳台，屋顶老虎窗、风向鸡和铁烟囱）；屋顶是一片片交错的红瓦，半圆脊瓦、青苔、两处滑落的瓦；两边有落水管，上层出挑在下层墙上投下阴影；中间是石砌门楼，尖顶上一只发光的大钟，指针停在午夜前几分、分针每秒走一下；门楼的尖拱就是传送门：拱石上刻着随传送门光呼吸的青色符文，拱顶一颗青色宝石，拱门内沿发光，门里是一条有纵深的隧道：光环从亮的深处一圈圈往外推、两条旋臂转着（打开时转快、变亮、星点被吸进去，整座门楼被照青），门前湿石板的水洼里倒映着它。门前三级台阶、两只火盆（火星上飘、照亮台阶），门楼两侧飘着青色旗帜，屋檐下四盏灯笼在摆，广场两端各一盏路灯；一只黑猫每 26 秒沿仓库屋脊走过来坐下甩尾巴；有时凸窗后走过一个人影；搬运工把装卸台上的货扛到推车，账房先生不时拿着账本走出门口；飞蛾绕灯、萤火虫在门前石子广场上闪。传送门耐久低于 35%：拱石裂开、漩涡闪烁、一盏红色警示光一胀一缩、偶尔迸火花。悬浮门或两翼，灯亮一点。
- **地面与天空**：夜空是硬边色带；星星一闪一闪，还有一条暗淡的银河；月亮是一张有环形山和光晕的像素月；远山带月光照亮的山脊和雪顶，山脚有几点村庄灯火；近处是松林剪影；云慢慢飘；每十几秒划过一颗流星。远山、松林、云、星星随镜头有不同的视差。地面是草皮加土层，主基地两边铺着石子路；地下的土层是像素土纹。基地上空飘的光点也改成了像素点（一个亮格 + 十字形暗格光晕）。
- **施工和挖掘**（`src/mc-pxroom-jobs.js`）：正在建的房间是木脚手架：上层木匠抡锤、一锤火花一闪，下层工人锯木板、木屑飞，吊着的工作灯在摆（光跟着摆），顶上落灰，后面是要建的房间的虚影；正在挖的格子是一条随进度往里推的隧道：身后立起木支架，钻头顶着岩面转、火花和碎石飞溅，矿工抡镐，工作灯挂在掌子面。
- **画布尺寸**：房间是 150×105；别的东西可以声明自己的尺寸（`PXR.def(key, { size: [w, h], fy, clear: 1 })`，主基地就是 380×210 透明底），引擎画它之前切到它的尺寸和缓冲。

**给美术的工具**：在游戏里加载 `tools/pxroom.js`，`__rooms(['smithy'], { scale: 5 })` 整数倍放大看一个房间（1–9 键点亮第几个房间、B 重放建成、H 切换悬浮），`__rooms()` 看全部像素房间。新房间照 `src/mc-pxroom-a.js` 的写法：`PXR.def(key, { amb, paint(S, sc), anim(D, t, rs, o) })`，先 `PXR.shell(S, sc, 风格)`，再按层画东西、`sc.light` / `sc.emit` / `sc.shaft` / `sc.field` 声明灯、粒子、光柱、光影，`anim` 里画会动的东西；房间的一句话描述写进 `M.ROOM_D`。

### 10.2 声音（2026-09-25 重做）

音效的实现是 `src/mc-audio.js`（就是 `M.Sfx`）。全部实时合成，没有音频文件。
- **同一个调**：有音高的音效（金币、升级、滴答、悬浮……）都取 F 大调五声音阶；「明天」和混沌来袭时换成 D 小调。叠在基地配乐上也不会打架。高频的声音（悬浮、滴答、数字滚动）在音阶里随机取音或逐级往上走，连起来像一小段旋律。
- **金币按数量走音阶**（用户裁定 2026-09-25）：连着来的金币一个比一个高，在五声音阶里一格格往上爬，停 0.7 秒再从低处开始；一次给很多时按数量连成一串上行音（数量越多串越长，最多 8 个音），积分到手按这次涨了多少算。金币串（大赢、大奖、结算总额、购买）也是沿音阶往上走的一串，不再是随机音高。
- **一个动机**：进基地、领袖上场的铜管都是同一个四音「回家」动机 C–F–G–A；它的小调版 A–D–E–F 留给「明天」。
- **卡在动画节拍上**：演出音效的每一声都对着动画里的时间点。可以点击快进的演出（升级、招募、换日、新的五天、撕卡、转盘、胜利横幅）不预先排好整段，而是在各自的 tick / draw 里按动画的 t 逐拍触发，快进时声音跟着一起加速。进战通告和结算卡片不能快进，开始时一次排好。
- **和声的爽点**：升级时战斗力滚动的那一秒压在属和弦上，数字停住变金的那一刻解决到主和弦；招募碎卡时光每爬一档品质响一声，一声比一声高。

## 11. 界面与文字规范

**原则：画面上常驻的字越少越好；玩家不关心的细节藏起来；任何一个设计元素都不能让人问“这是干什么的”。没有用处的元素就不该存在。**

### 11.1 三层信息

| 层 | 什么时候看得到 | 放什么 |
|---|---|---|
| 常驻 | 一直在屏幕上 | 名字、数字、图标、按钮；每条说明最多一句 |
| 说明 | 鼠标悬浮 / 初见说明卡 / 玩法说明（F1、右下角「？」、标题菜单） | 这个元素是什么、怎么用 |

- **游戏里没有「按住 Ctrl 显示详细信息」**（用户裁定 2026-09-24，全部删掉）：没有 Ctrl 键、没有右下角「ⓘ」开关、没有闪烁的提示行。每个东西只有一种说法，该给的信息直接给，不该给的（领袖上场后怎么打、道具四档效果、规则说明）就不给。
- 代码里：`this.D(常驻, 详情)` 永远返回常驻那一份，`data-detail` 的模板文字永远隐藏（旧代码留着但不生效）；悬浮说明的 `ctrl: true` 只表示「只显示标题和图标行」。
- **悬浮说明“图标为主”**（`src/mc-tipcompact.js`）：领袖的悬浮说明只显示标题和图标行（技能图标 + 名字，下面一句军团技能）；其他悬浮说明图标行和文字一起显示。部队的悬浮说明 = 名字 / 职业、战斗力 / 一句话。悬浮说明可以提供 `briefTitle`（简版标题）、`brief`（图标行：图标 + 数字，或血条）和 `pic`（头像 / 物品图）。例：领袖 =「Lv2 驱魔修女」/ 血条 1864/1870 / 技能图标 + 名字 + 一句军团技能 / 有天赋点时再闪烁一行「有 N 个天赋点可用」；部队 = 名字 / 职业图标 + 职业、战斗力 / 一句话；地格 = 地格图标 + 名字 / 契合的功能或风格图标。
- 夜市部队卡牌：头像、名字、职业图标 + 职业、战斗力、一句话、价格。面板里地格显示为「地格图标 + 名字 + 契合图标」+ 一行效果。
- 费用、天数用图标 + 数字，不写“物资”“天”这类字。

### 11.1b 文案规则（用户裁定 2026-09-24）

例：房间角上的风格图标。**错**：「中世纪 / 建筑风格 / 建筑风格：地格和奇观写着契合某种风格的时候，风格对上的房间才有额外效果 / 这个房间：酒馆」。**对**：「[图标] 中世纪 / 该建筑具有**中世纪**风格」。

1. **只说眼前这一个东西在这里是什么、做什么**，一句话，关键词着色。
2. **不在单个说明里讲整个系统的规则**：规则写在初见说明卡和玩法说明里，只写一次。
3. **不写标题已经说了的类别**（「建筑风格」「宝物 ·」「特殊地格」），**不重复屏幕上已经有的东西**（标题、图标、按钮上的费用、芯片上的射程）。
4. **不写操作教学**（「点击……」「悬浮查看……」「按住……」）；交互自己说明自己。小游戏的操作提示除外。
5. **功能文字里不放氛围描写**（世界的背景描述、建筑的来历）。
6. **面板 = 这个东西的详细信息**，不先复述一遍悬浮说明。有专门操作的房间（招募、锻造、仓库）直接写操作本身：酒馆面板只有一个按钮「花 120 物资，招募领袖」。
7. 空状态一句话（「没有宝物」「没有建筑图纸，出征能拿到」）。

### 11.2 初见说明

### 11.5 视觉：Pixel Juice（2026-09-24）

**动效一律平滑**（用户裁定 2026-09-24：界面风格保留，但一卡一卡的动效全部改掉）：画布动效用连续时间（不再按 8 / 12 / 15 / 24 帧取样；唯一例外是像素角色的身体动作，它们是逐帧画的，按 12 帧 / 秒播放，角色在场上的位移仍是连续的），透明度连续（不再分 4 档），关键帧之间缓动插值（弹出、砸下、回弹的数值和节奏不变），闪烁改成正弦呼吸，位置按 1 像素而不是 3 / 4 / 6 像素网格移动，字号连续缩放；CSS 的刷光、上下浮动、左右跳、呼吸、闪烁、逐字跳、跑马灯、扫描线、按钮按下回弹全部去掉 `steps()` 改成缓动。战斗通告、胜利、结算彩票条、换日、升级、阵亡卡、招募碎卡、技能名牌、宝箱、转盘都受益。只有战旗飘动是 8 帧贴图动画，保留逐帧。下文里「逐字跳」「几帧」一类的描述指动作本身，节奏已经平滑。

### 11.6 手感分档（2026-09-25）

用户裁定 2026-09-25：以前每次点击都放一样的一套（形变 + 碎块 + 火花 + 震屏 + 推开邻居），点多了又吵又卡。改成按玩家当下的心情分档：**爽点要突出，普通点击就是普通点击，负面的一下就过去**。一次反馈是一条连起来、分主次的链，不是各演各的。

| 档 | 什么时候 | 反馈 | 时长 |
|---|---|---|---|
| 普通 | 开面板、选东西、切页、暂停、变速 | 按下的东西缩一下；一声轻响。没有粒子、不震屏 | 0.12 秒 |
| 关闭 / 返回 / 取消 | ✕、返回、算了、离开、卖掉部队 | 更轻更快；面板立刻关，卖掉只飞回一枚金币 | 0.08 秒 |
| 被拒绝 | 积分 / 物资 / 碎片不够、队伍 / 道具栏满、失效键、技能用不了、条件不足 | 按下的东西左右摇头 + 低音；**缺的那样东西**（钱包、物资、碎片、队伍栏、道具栏）隔 0.06 秒红着抖一下；再弹一句提示。不震屏、不卡帧 | 0.18 秒 |
| 小爽点 | 买下普通 / 稀有的部队、道具、战旗；开挖；普通 / 稀有建筑开工 | 挤压回弹 + 触点闪光 + 圈 + 火花；买到的东西飞进它的栏位 | 0.26 秒 + 飞行 |
| 大爽点 | 买下史诗 / 传说；奇观开工；招募、升级、点亮天赋、出征、宝箱、转盘、胜利 | 见下面的层次；招募、升级、宝箱、转盘、胜利是各自的全屏演出（`docs/effects.md` A 节） | 0.4 秒 + 飞行 |

**层次**（大爽点完整走一遍，小爽点只走前两层）：① 主体 0 秒——按下的东西挤压、亮一下（按下时的缩一下就是蓄力，成功时的弹开是释放）；② 近场 0–0.04 秒——触点闪光、光圈、火花；③ 场景 0.06–0.12 秒——冲击波和碎块、镜头轻震、周围的按钮按距离先后被推开；④ 落点——奖励沿弧线飞向它的计数器，落下时计数器鼓一下、数字滚上去。动作和它影响的东西要连起来：点亮天赋 → 领袖卡跟着鼓一下；开工 → 按键先弹，地格上的光和尘晚 0.1 秒。

**入场也分层**：右侧面板外框从右滑入（带一点过冲）→ 标题牌压下来 → 内容一行一行跟上；确认框外框弹出 → 标题牌 → 选项逐行；有插画的奇遇是黑边合拢 → 插画从左滑入 → 对话框升起 → 名牌压下 → 选项逐行。入场用 CSS 动画（元素插进页面时自己播），不靠每帧重画整页。

**卡帧**（打中时画面停一下）只给大爆点（`explode` 强度 ≥ 1.5：宝箱开箱、转盘定格、胜利、首领）；界面上的小爆点不停，停了就像卡住。

**负面演出更快**：领袖阵亡撕卡、核心受击整段按 1.5 倍速播；领袖受伤的震屏减半。

**点一下就快进**：长演出（回家那一串、招募碎卡、升级、转盘、胜利横幅、阵亡卡、核心受击）里点击任何地方，整段加速到 3 倍，1.2 秒内不再点就恢复原速；不会有点了没反应的时候。

**性能**：界面只在它显示的东西在动时才每帧重画（数字滚动、计数器鼓动、结算、转场、新手气泡）；特效粒子、闪光、横幅、转盘、宝箱、撕卡、招募卡都画在特效画布上，不重画整页；震屏直接写到舞台上；悬浮说明只在鼠标移动时跟着重画。悬停不放粒子、不加模糊滤镜。

代码：`src/mc-game-a.js` 的 `juice`（分档）、`pressTier`（按下时判断档位：模板里的 `data-j="back"`、失效键、关闭类文字）、`deny`（被拒绝）；`src/mc-recruit.js` 的 `hurry`（快进）；`src/mc-pj.js` 的 `[data-enter]` / `[data-enter-rows]`（分层入场）。

- **启动时存档检测**：发现与当前版本不兼容的部分就单独清掉；整份不能用就播放撕碎存档的演出并删除，不影响重新开始。
- **玩法日志**（只有玩法数据，不含个人信息）：
  - Claude Artifact 版：自动上传到该 Artifact 的共享数据库（集合 `tele`）。
  - GitHub Pages 版：只存在玩家自己浏览器里（最多约 1.4 MB），不上传；玩家可以在「设置 → 数据采集」复制或下载后发给开发者。设置了 `localStorage['mc-tele-endpoint']` 时额外 POST 到那个地址。
  - Steam 版：运行日志写在电脑的用户数据目录 `logs/`（保留最近 10 次），不上传；测试版可一键导出到桌面。
- 分析：`python3 tools/tele_analyze.py`。

## 13. 维护规则

1. **改设计就改这份文档**，和代码放在同一次提交里。设计单文件：不另建新文档、不留旧版本。
2. 新增元素：同时补 `src/mc-guide.js` 的 `CONCEPTS`（初见说明）、悬浮说明、这份文档的对应章节和附录。
3. 改角色或技能：改 `pcd/chars/<key>.js`（按 pixel-character-design 的规范，设定卡一起改），再跑 `node tools/pcd-pack.mjs` 重新生成 `src/mc-pcd.js`；还在用 16-bit 骨骼的单位改 `src/mc-px16-cast.js` / `mc-px16-fx.js`，再跑 `node tools/gen-prompts.js` 重新生成 `docs/prompts/`。
4. 加减会动的东西（单位、技能、小游戏、建筑、道具、音效、全屏演出）：跑 `node tools/gen-effects.js` 更新 `docs/effects.md` 的生成部分；新的全屏演出、基地 / 地图 / 战斗 / 界面动效要手动补进 `docs/effects.md` 对应小节；房间场景的文字描述写在 `src/mc-rooms.js` 的 `M.ROOM_D`。
4. 改界面文字：先看 §11 的预算；超预算的内容放进详情层或说明卡。
5. 自检：浏览器里加载 `tools/designcheck.js` 后运行 `__designCheck()`，它会列出游戏里存在、但这份文档没提到的建筑、地格、世界、节点、奇遇、领袖、战旗、道具、宝物、家具、说明卡。

**战斗**

| 元素 | 说明卡 |
|---|---|
| 战斗目标 | 普通战：消灭所有敌人；坚守战：撑过倒计时。 |
| 积分 = 基础 × 积分倍率 | 击杀得基础分；精英、首领、战旗、宝物会加积分倍率。积分就是这一局的钱。 |
| 指挥位 | 领袖站在左边指挥；部队全灭后亲自上场，撤离战和部队一起上场。 |
| 领袖技能 | 按空格放。 |
| 特性 | 卡片上那一句话就是这支部队的本事。开战时它的图标从身上亮出来，停在头顶，生效时会闪。 |
| 警示圈 | 技能要落下的地方，里面填满就放出来；红色是敌人的。 |
| 精英 | 更强的敌人，打倒它积分倍率 +0.1。 |
| 最终首领 | 场景尽头的首领，站在自己的地形里；血条过半进入第二阶段。 |
