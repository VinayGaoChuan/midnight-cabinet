# 午夜机台 · 设计文档

> 这是游戏唯一的策划文档。**改设计 = 在同一次提交里改这份文档**：加减系统、改规则、改关键数值、加新元素，都要同步到这里（维护规则见文末）。数值的最终来源是代码；这里写规则、意图和关键数值。

## 1. 一句话

深夜的公寓里有一台午夜机台。投币后你在地下挖出一座基地，派领袖穿过传送门去异世界探险，把物资和图纸带回来，每 5 天守一次城——直到基地核心归零或传送门被打破。

**核心体验**：出征时“要不要再往前走一步”的贪心和风险；回到基地后“这次带回的东西怎么用”的规划；守城时“牺牲谁”的抉择。

## 2. 三层循环

| 层 | 在哪里 | 做什么 | 一次多长 |
|---|---|---|---|
| 房间（局外） | 午夜机台所在的房间 | 用代币买家具（永久加成）、选卡带、看成就，投币开始一局 | 一局之间 |
| 一局（基地） | 地下基地 | 按天推进：挖掘、建造、招募、升级、选世界出征、每 5 天守城 | 十几天到几十天 |
| 一次出征（局内） | 异世界地图 | 一站站往前走：战斗、夜市、奇遇；撤离或打败首领就带着收获回基地 | 7～17 站 |

一局结束的条件（任一）：
- **基地核心归零**：核心整局只有 3 点，领袖在出征中阵亡一次 -1；通关一个世界 +1（不超过 3）。
- **传送门被打破**：守城时传送门耐久打光。

一局结束后按表现结算**代币**（投币参与 20、每存活 1 天 5、每通关世界 40、每个首领 15、每个精英 6、每守住一次袭击 12、每座建筑 5、每张带回的图纸 4、每次奇遇 2……），回到房间。

## 3. 资源

| 资源 | 用在哪 | 从哪来 | 保存范围 |
|---|---|---|---|
| 代币 | 房间里买、升级家具 | 一局结束结算 | 永久（档案） |
| 物资 | 挖掘、建造、招募（120）、打造宝物（120） | 出征带回、守城奖励、后勤建筑、地格 | 一局 |
| 灵魂碎片 | 史诗 / 传说建筑、精铸宝物（+40） | **主要来自领袖阵亡**（出征或守城），灵脉等地格 | 一局 |
| 经验球 | 领袖升级（在领袖详情里点「升级」） | 出征带回、守城奖励、冥想室 / 少林寺、琥珀层 | 一局 |
| 电力 | 房间运转 | 发电类建筑、地热 / 晶簇地格、蓄能核心 | 一局 |
| 建筑图纸 / 宝物图纸 | 建造对应建筑 / 打造对应宝物（消耗 1 张） | 首领、精英、宝箱、守城评级、卡带 | 一局 |
| 积分 | 夜市买部队、战旗、道具；部分奇遇 | 战斗：基础积分 × 倍率 | 一次出征（回基地清零） |
| 基地核心 | 生命线 | 通关世界 +1 | 一局，上限 3 |
| 传送门耐久 | 守城的生命线 | 修门石、圣米歇尔山、陶土层 | 一局 |

## 4. 房间（局外成长）

- **机台**：点它投币开始新的一局；有进行中的局时显示「继续 · 第 N 天」。
- **家具**（15 件，每件 1～3 级，花代币解锁 / 升级）：

| 家具（1 → 3 级） | 效果 |
|---|---|
| 水壶 → 咖啡机 → 多合一饮料机 | 每局前几天部队和领袖攻击 +10% → 前 7 天 +20%、部队生命 +10% |
| 旧冰箱 → 双门冰箱 → 冷库 | 初始物资 +150 → +250，带回物资 +25%，基地每天 +25 物资 |
| 存钱罐 → 保险箱 → 瑞士银行 | 把上一局的一部分物资 / 碎片带进下一局（15% → 50%，3 级还带最好的 1 件宝物） |
| 旧沙发 → 懒人沙发 → 按摩椅 | 初始领袖 +1 级 → +2 级，招募的领袖 +1 级，医疗回血 +50% |
| 攻略书 → 地图册 → 全知之书 | 出征视野 +1 → 整张地图可见 |
| 小苗 → 盆栽 → 世界树苗 | 每局多勘明 1～3 块特殊地格，3 级时主基地正下方必定是「灵脉」 |
| 收音机 → 唱片机 → 点唱机 | 事件好运 +10% → +15%，自带随机战旗，初始倍率 +0.2 |
| 挂钟 → 落地钟 → 时之沙 | 建造 -1 天 → -2 天，挖掘立刻完成 |
| 挂历 → 行事历 → 预言历 | 袭击间隔 5 天 → 6 → 7 天，守城武器伤害 +40% |
| 相框 → 照片墙 → 纪念碑 | 领袖阵亡多留经验球 → 宝物全部保住、多留碎片 |
| 猫碗 → 猫窝 → 黑猫 | 地图必出「招财猫」；每局 1～2 次把倒下的领袖叼回来（不死、不扣核心） |
| 卡带架 → 卡带柜 → 收藏墙 | 解锁开局卡带（2 → 4 种，3 级可同时插 2 盘） |
| 展柜 | 开启成就系统 |
| 月相窗 | 每局随机月相：满月好运、新月便宜、血月更难但图纸翻倍、代币 +30% |
| 那扇门 | 可选「噩梦模式」：敌人 +40%，代币 ×1.6 |

- **开局卡带**（4 种）：建筑师（+3 建筑图纸，至少 1 张奇观）、军火（+3 宝物图纸和 1 件稀有宝物）、招魂（+150 碎片、领袖上限 +1）、工兵（开局挖通 3 格、物资 +100）。
- **成就**（14 个，每个永久解锁一样局内的好处）：见附录 D。

## 5. 基地

### 5.1 天数

每出征一次，或在传送门「休整一天」，就过去 1 天。挖掘和建造按天推进，农场等建筑按天产出。每天会有一次换日动画。

### 5.2 挖掘与建造

- 基地在地下的网格里，**主基地**在第一排中间，连着地面的传送门。
- 只能挖**和已有房间相邻**的岩层，花物资（基础 50）和天数；挖通后成为空房间。
- 在空房间里建造需要：**对应的建筑图纸**（列表里只出现你有图纸的建筑，×2 = 有 2 张）、物资、天数，史诗 / 传说建筑还要灵魂碎片（史诗 30、传说 60）。
- **电力**：大部分房间耗电，发电类产电；电力不足时不能再建耗电建筑。
- 建筑分 4 个品质，48 座，按**功能**分：仓库、电力、锻造、医疗、招募、训练、后勤、防御、运势、特殊；按**风格**分：蒸汽、魔法、自然、水域、玄幻、科幻、中世纪、卡通（主基地自成一类）。完整列表见附录 A。
- 奇观 = 稀有及以上的名胜建筑（埃菲尔铁塔、金字塔……），效果最强。

### 5.3 特殊地格

岩层里散布着 22 种特殊地格。挖开后在上面建房间：
- **任何房间**都能拿到地格的通用效果；
- 建筑的**功能或风格「契合」**这块地格时，再拿一份更强的效果。

地格在基地里显示为带光点的图标，悬浮可看效果；建造列表里「★」表示这里有地格加成。完整列表见附录 B。

### 5.4 房间标签

每个房间角上两个图标：左边**风格**，右边**功能**。地格和奇观用它们挑选「契合」的建筑。

## 6. 领袖

### 6.1 基本

- 领袖是出征的指挥官，也是守城的主力。上限 6 名（吴哥窟 +2，招魂卡带 +1）。
- 招募：在招募建筑（招魂台、酒馆……）花 120 物资，转盘决定品质：普通 55% / 稀有 30% / 史诗 12% / 传说 3%；巨石阵、灵脉、英灵冢等能保底。
- 品质影响属性（×1 / ×1.08 / ×1.18 / ×1.3）和天赋树深度。
- 6 种领袖职业（守夜人、赌徒寡妇、驱魔修女、屠宰场主、钟表匠、焚尸人），每种有自己的两项技能。
- **生命不会自动回复**：营火、奇遇、医疗建筑、地下泉。
- **阵亡 = 永久死亡**：在出征中阵亡，基地核心 -1，带着的宝物丢失（保险库保住第 1 件），留下灵魂碎片；在守城中阵亡，核心不受影响，同样留下碎片。

### 6.2 两项技能

| 领袖 | 军团技能（场外指挥时按空格） | 个人技能（亲自上场后自动 / 守城自动） |
|---|---|---|
| 守夜人 | 照夜：所有敌人停顿 | 灯盾猛击（怒气）：身边敌人 2.5 倍伤害 + 眩晕，自己得护盾 |
| 赌徒寡妇 | 梭哈：8 秒内每次击杀倍率 +1 | 致命一掷（能量）：朝生命最高的敌人 6 倍伤害 |
| 驱魔修女 | 圣咏：全队回血 | 圣光祷言（法力，约 8 秒）：全队回复 20% 生命并灼伤身边敌人 |
| 屠宰场主 | 血祭：献祭生命最低的部队，倍率 +1 | 剁骨旋风（怒气）：身边敌人 3 倍伤害，每砍中一个回 6% 生命 |
| 钟表匠 | 倒带：部队攻速 +100%，6 秒 | 停摆（每 7 秒）：最近 3 个敌人停摆 2.5 秒 |
| 焚尸人 | 火葬：点燃所有敌人 | 焚身（每 6 秒）：身边火浪并点燃 |

- **军团技能**：冷却按走过的站数算（地图上每站亮一格，全亮即可用）；领袖亲自上场后这场战斗里收起。
- **个人技能**：领袖上场时充满一次，之后按怒气（受伤、攻击）、能量（命中）、法力（时间）或秒数冷却攒满；攒满后等触发条件满足才自动放（见 §8）。

### 6.3 成长

- **经验球 → 升级**：在领袖详情里点「升级」，立刻升一级并播放升级仪式；从出征回来时如果升了级，也播放。每级 1 个天赋点。
- **天赋树**（三条路线，各 8 个天赋）：杀伐（攻击、暴击、冷却……）、坚忍（生命、护盾、保险柜……）、运数（倍率、商店、碎片、物资……）。
- **性格**（16 种，8 好 8 坏）：领袖自带的小加成 / 小毛病；坏性格可在疗养室花物资和天数消除。
- **宝物**（13 种）：出征时带在身上。锻造建筑里用宝物图纸 + 120 物资打造，品质随机；精铸多花 40 碎片，至少史诗。宝物格数量随领袖和建筑增加（紫禁城、王座遗骸 +1）。

## 7. 出征

### 7.1 选世界

- 点传送门打开世界列表。第 1～5 天每天只开 1 个世界，第 6 天起 2 个，第 12 天起 3 个；第二天换一批。
- 10 个世界：旧公寓走廊（教学）、雾中小镇、精灵之森、废弃游乐园、沉没港口、蒸汽铸造厂、深夜医院、星舰残骸、地狱、地下赌场（最终之地）。
- 每个世界有：**危险程度**（骷髅数，随天数上升）、**特产**（更容易带回的东西，如物资 ×1.6、图纸风格偏向）、主题敌人。
- 出发前选领袖和要带的宝物。

### 7.2 地图

- 横向推进的节点图，走过的节点不能回头；岔路用 ↑ ↓ 或点击选择。
- 长度 4 档：短 7 站 / 中 10 / 长 13 / 极长 17，站数越多精英、首领、撤离点越多。
- 节点 11 种：起点、普通战、坚守战、精英战、首领、夜市、营火、宝箱、奇遇、招募旗、撤离点。
- **撤离点**：坚守一场后带着全部收获回基地。**首领**：打败即通关这个世界（核心 +1）。

### 7.3 部队

- 部队在战斗中自动作战，上限 10 支。来源：开局部队、夜市、招募旗、奇遇。
- 可用部队 140 种（普通 27 / 稀有 30 / 史诗 50 / 传说 33），敌人 49 种。
- 每个单位有**种族**（13 种）和**职业**（6 种）两个标签，以及 1 个或多个**特性**（共 145 种）。
- 职业决定打法和招牌技能：先锋（冲锋盾击）、战士（旋风斩）、射手（箭雨）、法师（陨石 / 霜冻 / 闪电链）、祭司（圣光审判）、商人（金币风暴）；野兽用猛扑。
- 种族只是分类：战旗、特性、事件写到某个种族 / 职业时，带对应标签的单位才算数。

### 7.4 夜市、战旗、道具

- **夜市**：三个区——部队、战旗、道具，点击直接买；刷新花积分，越刷越贵；点自己的部队半价卖掉。
- **战旗**（11 面）：整支部队的常驻加成，本次出征一直生效。职业战旗只加对应职业；狂热、赏金、王冠加倍率；壁垒给护盾；血怒全体攻击。
- **支援道具**（5 种，最多 3 个）：闪电风暴、回魂烛、旧相框、招魂铃、骰盅。战斗中按 Q W E 由领袖放出，放的时候转盘决定这次的品质（至少是道具本身的品质）。

### 7.5 奇遇与小游戏

26 种奇遇，每种是一个几秒到十几秒的小游戏（弹珠台、抓娃娃、扫雷、合奏、转盘……），营火和招募旗也是小游戏。结果给积分、部队、生命、倍率、图纸等。

### 7.6 带回

撤离或通关后，本次的**物资、经验、碎片、图纸**带回基地；领袖阵亡则全部丢失。此外还可能带回**纪念品**（11 种），在基地生效：流浪领袖、矿工队、工匠、修门石、启示卷轴、淬火石、安神香、迷踪粉、引荐信、蓄能核心、行军包（见附录 E）。宝物和建筑不能直接带出，只能带图纸。

## 8. 战斗

- 敌我同时入场，顶部显示「普通战 / 精英战……」通告；双方站定、通告淡出后才开打。
- **技能按时机释放**：我方部队上场时技能已就绪（法力满，法力条边框闪烁），但不会一开场全放——每个技能有自己的**触发条件**，满足才放，放完重新攒；不满足就照常普攻、继续等。敌人从 0 开始攒法力，用同样的触发条件。触发条件分几类（`src/mc-skilltrigger.js`，每个单位的具体条件见 `docs/characters.csv` 和 `docs/effects.md` 的 U 表）：
  - 治疗类：有友军生命低于一定比例（治疗链 70%、圣光审判 80%、颅骨炖汤 60%）；以血换血类还要求自己生命高于 50%。
  - 近身范围类（旋风斩、禁果）：身边有 2～3 个以上敌人。
  - 落点范围类（箭雨、陨石、霜冻、炮弹、剑雨）：射程内的目标附近有 2 个以上敌人扎堆。
  - 群体类（闪电链、金币风暴）：攻击范围内有 2～3 个以上敌人。
  - 突进类（冲锋盾击 360、猛扑 320）：最近的敌人进入突进距离。
  - 强化自己类（太阳耀斑、神盾、急速射击……）：敌人进入攻击范围；精神扭曲：攻击最高的友军开始交战。
  - 单体重击类（法力爆裂、小行星、能量涌动）：射程内的目标生命还多（≥ 40%）。
  - 召唤类：有敌人逼近到 600 以内；扣血召唤（次元裂隙）还要求自己生命够扣。
  - 所有“N 个以上敌人”的条件，在敌人总数少于 N 时按剩下的数算，不会因为敌人太少而永远不放。
- 领袖个人技能同理：守夜人、焚尸人等身边有敌人才放；驱魔修女有友军生命低于 75% 或身边 2 个以上敌人才放；赌徒寡妇有敌人就放。
- **目标**：普通战消灭所有敌人；坚守战撑过倒计时。
- **积分 = 基础积分 × 倍率**：击杀得基础分；精英 +0.1、首领 +0.3 倍率，战旗 / 宝物 / 特性继续叠加。
- **领袖**站在左边的指挥位，不参战；部队全灭后亲自上场。
- 操作：空格 军团技能，Q W E 道具，P 暂停，F 切换 1× / 2× / 3× 速度。

## 9. 守城

- 每 5 天一次（挂历可延长到 6 / 7 天）。当天先打开**选将面板**：挑出守城的领袖（默认勾上普通 / 稀有），不能跳过。
- 守城时选中的领袖在地面作战，个人技能自动释放；地下的**武器房间**向地面开火——射程随深度递减，每往下一层覆盖少一格。
- 守城阵亡的领袖永久死亡，留下灵魂碎片（这是清掉弱小领袖、换高端材料的主要途径），基地核心不受影响。
- 结束按表现评级：评分 = 55% 击杀比例 + 45% 传送门保有比例；S / A / B / C 对应奖励 ×1.6 / ×1.3 / ×1 / ×0.7，发物资、经验球和图纸。
- 传送门被打破 = 这一局结束。

## 10. 画面与演出

- 全部角色和技能是 16-bit 像素动画（程序绘制）：固定调色板、两色明暗、选择性描边、蓄力 / 施法时 1px 轮廓光、池化粒子。规范和每个角色 / 技能的描述见 `docs/prompts/`（由 `node tools/gen-prompts.js` 从角色数据生成）。
- 角色一览：网址末尾加 `#gallery`。
- **全部表现效果的清单**（每个单位的主动技能、每个奇遇小游戏、领袖阵亡撕卡、进入战斗通告、升级仪式、换日、守城……共几百项，带编号和代码位置）见 [`effects.md`](effects.md)，给打磨表现的同学用。
- 重要时刻都有仪式感演出：升级、战力提升、换日、存档检测撕毁、核心受损、招募开卡。

## 11. 界面与文字规范

**原则：画面上常驻的字越少越好；玩家不关心的细节藏起来；任何一个设计元素都不能让人问“这是干什么的”。没有用处的元素就不该存在。**

### 11.1 三层信息

| 层 | 什么时候看得到 | 放什么 |
|---|---|---|
| 常驻 | 一直在屏幕上 | 名字、数字、图标、按钮；每条说明最多一句 |
| 详情 | 按住 **Shift**（或点右下角「ⓘ」常开） | 括号里的规则、操作提示、背景描述、完整的效果说明 |
| 说明 | 鼠标悬浮 / 初见说明卡 / 玩法说明（F1、右下角「？」、标题菜单） | 这个元素是什么、怎么用 |

- 代码里：视图用 `this.D(常驻, 详情)` / `this.D1(一段话)`（只留第一句）选择文字；模板里写死的说明加 `data-detail`。
- 费用、耗电、天数用图标 + 数字，不写“物资”“天”这类字。

### 11.2 初见说明

- 每个设计元素在 `src/mc-guide.js` 的 `CONCEPTS` 里有一条：图标、名字、**一句话**、它在屏幕上的位置。
- 这个元素第一次出现在屏幕上时，旁边弹出一张说明卡（高亮框指向它）；点一下就知道了，每台设备只弹一次。战斗中的说明卡会暂停战斗。
- 所有说明卡都收在「玩法说明」里，随时能查。
- **新增任何元素（图标、标签、资源、按钮、数值）时，必须同时加 `CONCEPTS` 条目和悬浮说明**；说不清用途的元素不加。

### 11.3 每屏文字预算（整屏常驻中文字数，含顶栏，不按 Shift）

| 界面 | 预算 | 当前（2026-09-24 实测） |

| 大地图 | ≤ 45 | 42（原 68） |
| 战斗 | ≤ 50 | 45（原 63） |
| 夜市 | ≤ 60 | 40（原 179，含新手提示） |
| 守城选将 | ≤ 110 | 104（原 205） |
| 出征准备 | ≤ 50 | 37（原 126） |
| 世界选择 | ≤ 50 | 37（原 84） |

| 奇遇 / 小游戏 | 规则一句 + 按钮 | 每个奇遇文案 ≤ 34 字 |

测量工具：`tools/textaudit.js`（浏览器里 `__textAudit('标签')`）。

### 11.4 操作

- 鼠标、键盘、手柄、触屏都能玩；看起来能点的东西都能点。
- 右键 = Esc（返回 / 关闭）。
- 按键可在「设置」里改。

## 12. 存档与日志

- **存档只在玩家自己的设备上**，不进 git：
  - 网页版：浏览器 localStorage，键 `midnight-cabinet-meta-v4`（这一局）、`midnight-cabinet-profile-v1`（档案：代币、家具、成就）、`midnight-cabinet-settings-v1`（设置）、`midnight-cabinet-guide-v1`（看过的说明卡）。
  - Steam 版：同样的数据镜像到电脑的用户数据目录 `save/save.json`（供 Steam 云存档同步）。
- **启动时存档检测**：发现与当前版本不兼容的部分就单独清掉；整份不能用就播放撕碎存档的演出并删除，不影响重新开始。
- **玩法日志**（只有玩法数据，不含个人信息）：
  - Claude Artifact 版：自动上传到该 Artifact 的共享数据库（集合 `tele`）。
  - GitHub Pages 版：只存在玩家自己浏览器里（最多约 1.4 MB），不上传；玩家可以在「设置 → 数据采集」复制或下载后发给开发者。设置了 `localStorage['mc-tele-endpoint']` 时额外 POST 到那个地址。
  - Steam 版：运行日志写在电脑的用户数据目录 `logs/`（保留最近 10 次），不上传；测试版可一键导出到桌面。
- 分析：`python3 tools/tele_analyze.py`。

## 13. 维护规则

1. **改设计就改这份文档**，和代码放在同一次提交里。设计单文件：不另建新文档、不留旧版本。
2. 新增元素：同时补 `src/mc-guide.js` 的 `CONCEPTS`（初见说明）、悬浮说明、这份文档的对应章节和附录。
3. 改角色或技能：改 `src/mc-px16-cast.js` / `mc-px16-fx.js`，再跑 `node tools/gen-prompts.js` 重新生成 `docs/prompts/`。
4. 加减会动的东西（单位、技能、小游戏、建筑、道具、音效、全屏演出）：跑 `node tools/gen-effects.js` 更新 `docs/effects.md` 的生成部分；新的全屏演出、基地 / 地图 / 战斗 / 界面动效要手动补进 `docs/effects.md` 对应小节；房间场景的文字描述写在 `src/mc-rooms.js` 的 `M.ROOM_D`。
4. 改界面文字：先看 §11 的预算；超预算的内容放进详情层或说明卡。
5. 自检：浏览器里加载 `tools/designcheck.js` 后运行 `__designCheck()`，它会列出游戏里存在、但这份文档没提到的建筑、地格、世界、节点、奇遇、领袖、战旗、道具、宝物、家具、说明卡。

**性格（16）**：好——冷静、贪婪之眼、铁皮、鼓舞、幸运儿、夜猫子、精打细算、嗜血；坏——恐慌、手抖、多疑、体弱、霉运、怯战、贪杯、厌世。

**领袖**

|---|---|
| 领袖 | 出征带队、守城作战。点卡片看天赋和升级；卡片上的黄点 = 有没用的天赋点。 |

**出征**

| 元素 | 说明卡 |
|---|---|
| 传送门 | 点它出征。每天只开几个世界，第二天换一批。被怪物打破，这一局结束。 |
| 危险程度 | 骷髅越多敌人越强；天数越往后，所有世界都更危险。 |
| 世界特产 | 这个世界更容易带回的东西，比如「物资 ×1.6」。 |
| 地图节点 | 图标就是这一站的内容：战斗、夜市、营火、宝箱、奇遇……鼠标悬浮看详情。 |

| 积分 | 这一局的钱：打赢战斗得到，在夜市和奇遇里花。回基地就清零。 |
| 本次收获 | 物资、经验、图纸要撤离或通关才带得回基地；领袖阵亡就全丢。 |
| 部队 | 战斗里自动作战。在夜市买、招募旗领，最多 10 支。 |
| 支援道具 | 战斗中按 Q W E 由领袖放出。用的时候转一下，决定这次的品质。 |
| 战旗 | 整支部队的常驻加成，比如「射手战旗」让所有射手更强。 |
| 小地图 | 整条路线的缩略图。越往右越深，最右边是首领。 |

**战斗**

| 元素 | 说明卡 |
