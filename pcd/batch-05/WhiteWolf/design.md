# 角色设定卡：白狼（WhiteWolf）

- 名称 / 身份：白狼，恶魔种的雪狼，先锋（防御型），稀有；升级线第一级（→ 雪狼王）。
- 一句话剪影：一只腿很长的灰白雪狼，一条巨大蓬松的雪尾高高卷过背像一面盾，肩上两丛冰棱。
  1. 巨蓬雪尾卷过背，像一面盾，尾尖挂冰晶（外轮廓；升级线保留，是「出人意料为防御型」的来源）
  2. 两侧肩胛各一丛冰晶棱刺，往上刺出 3–4 格像肩甲（外轮廓；升级线扩成冰川脊）
  3. 耳后一对后弯 2 格的冰晶小角（恶魔种族；升级线长成冰冠）
  4. 额头一枚冰蓝菱形晶斑（内部细节）
- 尺寸：待机约 35×27 格（含卷尾），缓冲 104×58；站位 HX 66。
- 体型档：高腿修长雪狼。len 13、chest 5、leg 8（长腿、身轻 → 闪避），胸前雪毛领加雪毛围兜（胸前轮廓厚 → 防御），背线平直。
- 材质色阶（色板下标）：
  - 身体 pale [8, 59, 60, 17]（band 2）
  - 雪毛领 / 围兜 / 吻部 / 腹线 [8, 60, 17, 21]；巨尾同色阶，band 2
  - 冰棱 / 冰角 sky [39, 40, 41, 23]；远侧冰棱 [39, 40, 40, 41]
  - 晶斑 [39, 40, 22, 21]；眼 [0, 0, 23, 23] 平涂冰蓝；发光体 glow [22, 22, 21, 21]
- 部件顺序（从后往前）：远侧腿 → 卷背巨尾（+ 尾尖冰晶）→ 远侧肩棱 → 躯干 + 颈 → 近侧腿 → 近侧肩棱 → 颈圈毛 + 雪毛围兜 → 头（+ 冰角、额心晶斑同部件）→（死亡）雪堆。
- 细节清单：canine 头（冰蓝眼、黑鼻、耳）、ruff 雪毛领、胸前参差的雪毛围兜、巨尾内侧每 3 节一道暗毛纹和亮毛纹、背上毛纹、爪垫、肩棱尖端亮、尾尖冰晶、额心晶斑（技能时变亮）。
- 攻击方式：近战「扫」。原地半转身，用结冰的巨尾水平横扫目标（尾 × 扫），同族狼里唯一不用嘴 / 爪的。
- 差异化：
  - 体型：高腿修长。黑剑低伏瘦长，暗牙金毛昂头，灰骨狼露骨，恐狼有肩峰和火鬃，头狼驮鼓、最壮；白狼通体雪白、腿最长、尾巴像盾。
  - 武器、握法、攻击：巨尾 × 转身横扫；同族其他狼用的是扑咬、爪拍、咬 + 擂鼓。
  - 待机个性：抖身甩掉背上的雪，雪屑四散；平时尾巴缓慢左右扫。
  - 步态：轻盈无声小跑，不扬尘，每步脚下闪 1 颗雪晶。
  - 死亡：侧倒，风雪斜吹过来一层层把身体埋进雪堆，雪堆再从上往下被吹散。
  - 主色：灰白 pale 雪毛，同族没有用这个色阶的。

# 特效设定卡

- 元素色阶：雪 · 冰灰蓝，自建 fxRamp 'snow'：21 白 → #eef4ff 雪白 → #bcd0ea 冰灰蓝 → #7a8cae 灰蓝 → #3a4462 深灰蓝（升级线共用）。
- 攻击：
  - 预兆：压低、举尾
  - 出手：半转身，尾巴甩平，轮廓光 1 档
  - 挥砍：雪色扫弧 fx.slash
  - 命中：impact 火花 + 雪屑，假人小摇
- 技能「寒冬之触」（冰霜光环，被动生效的样子）：
  - 蓄力：压低身体呼出白雾；脚下雪花点阵 fx.circle（扁）以自身为心一圈圈往外铺（4 圈，正反交替转）；雪粒绕肩棱汇聚；肩棱轮廓光 2 档，发光体闪。
  - 施放：挺身、雪尾炸开；雪色点阵护罩 fx.dome 从贴身扩成大环（自绘扩散点阵环，前后分层），雪粒顺环飘出；震屏 2 格 + 闪白。
  - 命中：大环扫过假人，罩上霜边 dummyFx（outline snow + slow 0.6）；头顶飘下冰屑，每 0.3 秒冒一颗冻伤小十字。
  - 收招：白雾渐散，轮廓光逐档熄灭。
- 受击：雪毛屑火花（自建 whiteWolfFur 色阶）+ 白色剪影 1 帧 + 击退 2 格；顺带表现敏捷之足：原位留下一道雪色残影（0.3 秒淡出）。
- 死亡：侧倒伸腿，尾尖冰晶弹落，风雪斜吹，雪一层层掩埋（4 层，最后堆成雪丘），雪丘从上往下消散；魂光雪色为主、夹一些 soul。
- 音色：踏雪的咯吱声 + 冰晶清脆的一声叮 + 长长的白雾呼气，重量 0.45。SFX { body beast, how topple, pal frost, style shield, w 0.45 }。
