# 先祖战士 AncestorWarrior

模块：`pcd/chars/AncestorWarrior.js`　查看：`pcd/view.html?c=AncestorWarrior`　截图 / 导出：`shots/`

## 角色设定卡

- **名称 / 身份**：先祖战士，恶魔族先锋（优质）。一个刚从浅坟里爬出来的先祖。
- **一句话剪影**：头戴骨白先祖面具、一对上弯长角；左手挎一面圆顶墓碑盾，右手半截锈断剑，背后一条锯齿破尸布。
- **尺寸**：待机 27×28 格（含角），脚底对齐地面线。体型档是矮壮沉底（`parts.rig` stocky + hunch 1）：头身比约 4.5，宽肩短腿，微弓背。
- **材质色阶**（[勾线, 暗, 基, 亮]）
  - 尸布 / 破麻衣 shroud：自建墓苔绿褐 `#10160f #26331f #3e5233 #627a4e`，band 2（面积最大）
  - 皮肤 skin：灰青恶魔皮 `#0e1216 #2a353c #46565e #6a7e84`
  - 面具 / 角 / 骨珠：bone；白辫：white；缠布：[20, 7, 6, 5]
  - 墓碑：stone，碑脚苔斑 moss；断剑：steel 刃 + leather 锈斑 + iron 护手
  - 坟土 dirt：[0, 20, 19, 32] band 2
  - 墓火 glow（发光体，flat）：grave 色阶 `#10302a #2a7462 #62d0a4 #d4f6e4`
- **部件顺序（从后往前）**：尸布披风 → 远侧白辫 → 后臂（赤膊）→ 腿（赤足缠布）→ 破麻衣躯干（锯齿下摆、胸口破口）→ 头 + 先祖骨面具（同一部件）→ 长角 → 近侧白辫 → 墓碑盾（后手）→ 断剑 → 前臂。
- **细节清单**
  - 面部：骨面具的眉骨与鼻梁前凸、2 格墓火眼孔（一明一灭）、牙排、颊纹
  - 发：两条白色长辫，每 2 行一道辫纹，辫梢骨珠，梢会摆
  - 服装：破麻衣锯齿下摆、胸口破口露出灰青皮、麻绳腰带；锯齿尸布披风
  - 盾：圆顶墓碑，碑面内框刻线、先祖纹（发光体，从下往上逐行点亮，5 档）、右上角裂纹、碑脚苔斑
  - 武器：断剑的铁柄头、缠布握把、护手、刃高光、锈斑、参差断口
- **攻击方式**：近战。撩——碑盾护胸，断剑从身后下方往前上方反撩，前冲 4 格。
- **差异化**
  - 体型档：矮壮沉底（同组恶魔近战里血骑士是英武、逃兵是缩肩骷髅、诅咒剑士是全身铁甲的标准体）
  - 识别特征：墓碑盾（外轮廓）、先祖面具 + 上弯长角（外轮廓）、锯齿尸布披风（外轮廓）、断剑、白辫骨珠
  - 武器 × 握法 × 攻击：单手断剑 + 墓碑盾，上撩（同族剑盾角色里唯一的上撩）
  - 待机个性：拄着碑盾低头默祷，辫梢摆动，眼孔墓火一明一灭、碑纹跟着亮一下
  - 步态：蹒跚拖步，接触帧身子一顿，断剑尖拖在地上留下 1 格土痕
  - 死亡方式：下陷入坟——仰倒后身下拱起土堆把身体埋掉，只剩墓碑立在土堆上，最后碑也化灰
  - 主色：墓苔绿褐尸布（同族没有用这个色相做主材质的）
- **升级线**：灵魂战士保留墓碑盾（长成碑形塔盾）、长角（长成后掠王角）、白辫、断剑（被魂火接成传说之剑）和 grave 色阶。

## 特效设定卡

- **元素色阶**：墓火 · 青绿，自建 fxRamp `grave`：21 白 → `#d4f6e4` 淡青白 → `#62d0a4` 墓火青绿 → `#2a7462` 暗青 → `#10302a` 墨青（升级线共用）；土块用 FXI.earth。
- **攻击「反撩」**：预兆——碑盾抬到胸前，断剑压到身后下方（1 帧）；出手——前冲 4 格、定格 1 帧，impact 色阶拖影弧从身后下方扫到前上方；命中——impact 外爆 10 颗 + 十字星芒，假人小摇。
- **技能「浅坟」**（特性被动生效的样子：死了很快从浅坟里爬出来，更快）
  - 蓄力 1.4 s：跪下，碑盾离手自己立成墓碑，身体下沉进土 6 格、身前拱起土包；四周地面冒出墓火粒子定点汇聚到坟上（K_SPIRAL_PT），碑纹从下往上逐行点亮；眼孔 / 碑纹 1、2 档逐帧闪；轮廓光 2 档；地面映光。
  - 施放 0.5 s：破土而出——蓄力粒子外爆、土块外爆 24 颗 + 带重力的土块、冲击环、墓碑十字星芒、两道地裂，震屏 2 格 + 天空闪白。
  - 命中：起身后两层青绿残影（copySprite + blitShape，表现「攻速 +50%」）+ 断剑一道青绿双层拖影弧快撩，墓火外爆 22 颗，假人大摇击退，震屏 1 格。
  - 收招 0.7 s：碑纹 / 眼孔 2→1→0，余烬从面具眼孔飘升。
- **受击**：enemy 敌弹来袭 → 白色剪影 1 帧 + 击退 2 格 + 眼孔熄灭 + 白辫、衣摆反甩；impact 火花；震屏 1 格。
- **死亡**：26 颗火花 + 震屏 2 格 + 闪白 → 踉跄 → 碑盾脱手立在身旁 → 仰倒（离地 3→1→0）→ 尘土 16 颗 → 身下土堆拱起、慢慢把身体和断剑埋掉 → 眼孔闪几次熄灭 → 只剩墓碑立在土堆上，自上而下消散，墓火 + 魂光上升。
- **音色**：碎土簌簌 + 石碑一记闷响 + 骨珠辫子的细碎骨铃，重量 0.6。SFX `{ body: 'flesh', how: 'collapse', pal: 'earth', style: 'nova', w: 0.6 }`；step 在步态接触帧，swing / hit 在出手帧，impact 在破土与残影快撩，fall 在倒地帧。
