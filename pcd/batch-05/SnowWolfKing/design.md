# 角色设定卡：雪狼王（SnowWolfKing）

- 名称 / 身份：雪狼王，白狼的最终形态，恶魔种先锋（防御型），神话。
- 一句话剪影：一只昂首站立的巨型纯白王狼，头顶 5 支冰棱王冠，背上一整排冰川脊，同款卷背巨尾更大，尾尖冻成冰棱。
  1. 冰棱王冠：白狼的冰晶小角长成 5 支，中间最高，高出头顶 7 格（外轮廓）
  2. 冰川脊：白狼的肩棱扩成一整排，从后颈排到臀，肩上最高（外轮廓）
  3. 卷背巨尾：比白狼更粗更长，尾尖冻成一簇 3 根下垂冰棱（外轮廓）
  4. 冰晶面纱：3 条细冰链从冠沿垂到额前，逐格亮暗交替，随步伐摆（名字「冰冻面纱」的来源）
  5. 身周常驻 4 颗慢飘的雪花（5 格小十字）
- 尺寸：待机约 42×35 格（含冠），缓冲 112×66；站位 HX 62。比头狼（约 34×26）高 6 格以上，是全部狼线里最大的。
- 体型档：巨型王狼。len 16、chest 6.5、rump 5、hump 1.5、leg 9、lw 3，颈长 6、颈角 1.2（昂首）；白狼的长腿和卷尾比例原样放大。
- 材质色阶（色板下标）：
  - 身体 white [7, 18, 17, 21]（band 2）
  - 颈圈毛 / 围兜 / 吻部 / 巨尾 [7, 17, 21, 21]
  - 冰冠、近侧肩棱、尾尖冰棱（frost 青蓝）[39, 23, 22, 21]；远侧冰川脊 [39, 40, 23, 22]
  - 面纱 sky [39, 40, 41, 23]；晶斑 [39, 40, 22, 21]
  - 眼 [0, 0, 22, 22] 冰青发光；点亮的冠尖 glow [22, 22, 21, 21]
- 部件顺序（从后往前）：远侧腿 → 卷背巨尾 → 尾尖冰棱簇 → 冰川脊（只露出背线以上）→ 躯干 + 颈 → 近侧腿 → 近侧肩棱 → 大颈圈毛 + 围兜 → 头（+ 面纱、额心晶斑同部件，免得分界线把脸压黑）→ 冰棱王冠。
- 细节清单：
  - 放大 canine 头（7.5·6·3.6）：冰青发光眼、鼻、耳
  - 大 ruff 颈圈毛与参差的胸前围兜
  - 巨尾毛纹；冰川脊高低错落（隔一根高 1 格）
  - 王冠 5 支，逐支可点亮；面纱 3 条冰链；额心晶斑
- 攻击方式：近战「砸」。抬起近侧前爪（人立式前抬）猛按下去（爪 × 按地砸）：爪下冒出一丛 3 根冰锥，冰浪沿地面冲到目标脚下再冒 2 根。
- 差异化：
  - 体型：巨型王狼，狼线最大。头狼驮鼓、狮鬃，恐狼有肩峰和火鬃，其余更小。
  - 武器、攻击：前爪 × 按地砸 + 冰锥。白狼是尾扫，恐狼是爪横拍，头狼是扑咬擂鼓。
  - 待机个性：昂首缓缓环顾，鼻息成白雾，冰面纱轻晃。
  - 步态：庄重踱步，接触帧身体顿挫 1 格，每步 4 颗雪尘；踏地音重。
  - 死亡：冻结碎裂。其他狼都是倒地，只有它是站着冻成冰雕、再碎掉。
  - 主色：纯白 white 长毛，冰冠 frost 青蓝。白狼是灰白 pale，同线拉开一档。

# 特效设定卡

- 元素色阶：雪 · 冰灰蓝（'snow'，同升级线：21 → #eef4ff → #bcd0ea → #7a8cae → #3a4462）+ 冰晶青蓝 FXI.frost（21 白 → 22 冰青 → 23 青 → 40 钢蓝 → 39 深蓝）。
- 攻击：
  - 预兆：前爪抬起、身体后仰（2 帧）
  - 出手 / 接触：前爪按地，震屏 1 格
  - 冰锥：爪下 3 根冰锥（自绘，2 帧长高 → 保持 → 从上往下抖动碎掉）+ fx.wave 冰浪推到假人 + 假人脚下 2 根冰锥
  - 命中：impact + frost 冰屑，假人大摇
- 技能「冰冻面纱」（更大更强的冰霜光环）：
  - 蓄力：仰天长嚎（抬头、张嘴、前身抬起），白雾往上喷；雪暴粒子从脚下大半径逆时针螺旋上升到冰冠（K_SPIRAL_PT，反向、压扁）；冰冠 5 支逐支点亮（每支一颗小星芒）；轮廓光 1 → 2 → 3 档；最后 0.5 秒毛领、面纱被风雪吹抖。
  - 施放：从天降下一道冰晶帘幕——10 根冰棱从左上斜落，一路覆盖到假人（自绘 7 格冰棱，落地碎冰屑、插地一瞬）；螺旋粒子外爆；一圈大冰环 ring + 雪色法阵 fx.circle；震屏 2 格 + 闪白。
  - 命中：假人整只冻结（dummyFx fill frost + outline frost + stun 1 + slow 0.4），脚下冒出 3 根冰锥，冰屑外爆 + 十字星芒，头顶持续飘冰屑。
  - 收招：冠尖逐支熄灭，白雾渐散。
- 受击：白毛屑火花（自建 snowKingFur）+ 白色剪影 1 帧 + 击退 2 格；敏捷之足：原位留下一道冰青残影（同一个体，招牌动作保留）。
- 死亡：
  - 受击踉跄，前腿一软
  - 整只冻成冰雕：烘焙后按亮度换成冰青单色，定格，冒寒气
  - 背上劈开一道折线裂纹
  - 碎成冰块（death chunks，chunk 5，frost）落地，震屏 + 冰屑
  - 冰块化开，魂光（frost / soul）上升
- 音色：暴风雪的呼号 + 冰川开裂的低沉咔嚓 + 一声长嚎，重量 0.95。SFX { body beast, how shatter, pal frost, style frost, w 0.95 }。
