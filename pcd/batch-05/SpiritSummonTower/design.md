# 角色设定卡 · 灵召塔 SpiritSummonTower

- 名称 / 身份：灵召塔，恶魔族召唤师（部队，稀有），一座会自己召唤的「灵魂之门」——固定建筑，本身不攻击。
- 一句话剪影：中空的半圆拱门 + 拱顶两肩各蹲一尊小石兽（左伏月豹、右坐看门犬）+ 门下悬浮的圆铁基座与绕行碎石。
- 尺寸：约 29×36 格（门体约 20 宽、30 高，含石兽与悬浮 1–2 格），稀有 28–32 档。脚底 = 基座下沿，离地悬浮；站位 HX 34（远程位）。
- 骨架：不用骨架，全部自画部件（`chars/SpiritSummonTower.js` 里标了「候选部件」：环绕碎石、漂浮圆基座、月白石拱门、旋转裂隙、拱心石、伏卧石兽）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 月白灰石 M_STONE = [8, 10, 18, 17]，band 2（拱门大块）；石兽 / 拱心石 band 1；后半圈碎石暗一级。
  - 基座 iron [0, 27, 28, 29]，band 1。
  - 裂隙 M_RIFT = [25, 24, 23, 22]、白芯 M_CORE = [23, 22, 21, 21]（发光体，平涂）。
  - 符文灯 / 石兽眼 / 基座符点 M_LAMP = [25, 24, 22, 21]（发光体，平涂，4 档：熄 / 暗 / 亮 / 炽）。
- 部件顺序（从后往前）：后半圈碎石 → 基座（含 5 个符点）→ 拱门（含 6 盏符文灯、裂纹）→ 裂隙 → 拱心石 → 月豹石兽 → 看门犬石兽 → 前半圈碎石。
- 细节清单：
  - 「脸」：两尊石兽各有 1 格魂光眼、尖耳 / 剪耳；月豹长尾卷起，看门犬方头、亮面鼻梁。
  - 砖石：门柱砌缝 2 道、拱石放射分块 4 道、挑檐托石、柱脚、拱心石凸出 2 格带魂光符。
  - 配件：门柱两侧 6 盏 2×2 符文灯（法力条）；基座顶面亮沿 + 正面 5 个符点随法力亮。
  - 发光体：裂隙漩涡（两条旋臂转动 + 白芯）5 态：一点 / 收缩 / 常态 / 张满门洞 / 脉动；熄灭态 = 缩成一点。
- 攻击方式：施法（仅表现，游戏里不攻击）——裂隙收缩 1 帧 → 脉动定格吐出一颗短程魂光弹（口光十字 2 帧）→ 余波 → 回待机。
- 差异化（同组 / 已通过的建筑：充能塔、火神塔、玉藤堡垒；同组召唤物：月豹、看门犬）：
  - 体型档：悬浮拱门档，中空门形轮廓；充能塔是瘦高树干、火神塔是梯形火山石堡，都是实心。
  - 识别特征：①拱顶两肩的月豹 / 看门犬石兽（改轮廓，就是它召唤的两只）②中空门洞里旋转的青蓝裂隙（发光体）③门柱 6 盏符文灯（法力条）④基座下绕行的 3 块碎石（改轮廓）。
  - 武器 + 握法 + 攻击类型：门内裂隙 × 施法（吐魂光弹），同族无重复。
  - 待机个性：漩涡慢转，6 盏符文灯依次「呼吸」，碎石绕基座转。
  - 步态：整座门离地 1–2 格悬浮平移，一起一伏，基座下拖魂光粒子，不落地（hover）。
  - 死亡方式：坍塌——拱顶先裂、裂隙缩成一点，门石一块块竖直落下堆成废墟（死亡套件 chunks，冲击点在头顶上方）。
  - 主色：月白灰石 + 魂光青蓝，和充能塔（树干）、火神塔（火山岩）拉开。

# 特效设定卡

- 元素色阶：灵门 · 魂光 FXI.soul：22 青 → 23 蓝 → 24 紫 → 25 深紫 → 3 暗；石屑 FXI.dust，受击火花 FXI.impact。
- 攻击「魂光弹」：
  - 预兆：裂隙收缩、符文灯暗一档 1 帧。
  - 出手：裂隙脉动定格，口光十字 2 帧，8 颗魂光小火花。
  - 弹道：白芯 + 青十字、尾端闪烁，150 格/秒，隔步拖尾。
  - 命中：12 颗魂光外爆 + 小十字星芒，假人小摇。
- 技能「次元裂隙：蓄满法力后召唤月豹和看门犬」：
  - 蓄力 1.4 s：6 盏符文灯每 0.2 s 点亮一盏（法力 16%/s 的可视化）；漩涡越转越快；魂光定点螺旋汇进裂隙；轮廓光 1 → 2 档；1.2 s 灯全亮时拱顶裂开、掉下 3 块门石（表现损失 400 生命）+ 扬尘 + 震屏 1 格，裂隙逐帧脉动。
  - 施放 0.5 s：裂隙张满整个门洞（亮面），汇聚粒子外爆 + 26 颗魂光 + 冲击环 + 十字星芒；震屏 2 格 + 天空闪白；一只月豹剪影、一只看门犬剪影（blitShape 单色 + 2 层残影）先后冲出门洞向前奔 10–26 格。
  - 命中：两只剪影落点各开一圈小召唤法阵（fx.circle soul，相反旋向）+ 魂光外爆 18 颗 + 十字星芒 + 小冲击环；看门犬落地震屏 1 格。
  - 收招 0.7 s：裂隙收回常态，符文灯一盏盏熄灭，裂纹合上，余光从裂隙飘升。
- 受击：enemy 敌弹来袭 → 白色剪影 1 帧 + 击退 2 格 + 裂隙收缩、石兽眼灭、碎石甩到后侧；impact 火花 16 颗 + 石屑 6 颗 + 震出的魂光 5 颗；震屏 1 格。
