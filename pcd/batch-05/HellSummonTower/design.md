# 角色设定卡 · 地狱召唤塔 HellSummonTower

- 名称 / 身份：地狱召唤塔，恶魔族召唤师（部队，神话），灵召塔进化成的「地狱之门」——固定建筑，本身不攻击，付出更多生命召唤更强的魔豹和邪犬。
- 一句话剪影：同一座拱门加高加厚成黑曜赤岩地狱门 + 拱顶两颗骷髅兽首各伸出一支外弯巨角（伸出门框 5 格）+ 门框外侧垂到地面堆开的粗锁链 + 底座下四只石爪足。
- 尺寸：约 40×43 格（门体 26–28 宽、40 高，巨角伸到 ±18），比灵召塔高 10 格，本组最大；神话 32–40 档（含角）。脚底 = 爪足落地，站位 HX 34。
- 骨架：不用骨架，全部自画部件（`chars/HellSummonTower.js` 里标了「候选部件」：石爪足、底座、地狱门、熔岩缝、熔血漩涡、拱心石、骷髅兽首 + 外弯巨角、粗锁链、火爪影）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 黑曜赤岩（自建 ramp）[#0c0606, #2a1212, #4a1e1a, #6e2e24]：门体 band 2；拱心石、近侧爪足 band 1；远侧爪足暗一级。
  - 兽首与颅灯 bone [8, 7, 6, 17]；巨角 [0, 55, 56, 13]（墨 → 暗酒红 → 血红 → 酒红尖）；锁链 iron [0, 27, 28, 29]（地上的链堆暗一级）。
  - 熔血漩涡 M_RIFT = [55, 56, 57, 58]、熔岩白芯 M_CORE = [45, 46, 47, 21]（发光体，平涂）。
  - 熔岩缝 / 颅灯火 / 兽首眼火 M_LAVA = fire [44, 45, 46, 47]（发光体，4 档：熄 / 暗 / 亮 / 炽）；火爪影 M_CLAW = [55, 45, 46, 47]（发光体）。
- 部件顺序（从后往前）：远侧两只爪足 → 外侧两根锁链（含地上链堆）→ 底座 → 近侧两只爪足 → 地狱门（含 6 颗颅灯、裂纹）→ 熔岩缝 → 熔血漩涡 → 拱心石 → 两颗兽首（每颗先角后颅）→ 门洞内沿两根锁链 → 火爪影。
- 细节清单：
  - 「脸」：魔豹颅（左，朝外）圆颅、短吻、1 格眼火 + 眼窝、两根下垂长獠牙；邪犬颅（右，朝外）长吻、一排牙、眼火 + 眼窝；每颗一支外弯上翘的巨角。
  - 砖石：拱石放射分块 5 道、门柱砌缝 2 道、伸出门框的挑檐（兽首座）、柱脚、底座正面砌缝、拱心尖石嵌血符。
  - 配件：6 颗骨白小颅灯（眼窝 = 火，头顶一簇火苗，法力条）；4 根粗锁链——外侧两根从挑檐外端垂到地面沿地面往外堆开，门洞内沿两根斜缠过拱肩再垂下、末端一只张开的镣铐；四只石爪足各三趾 + 骨白爪尖。
  - 发光体：熔血漩涡 5 态（一点 / 收缩 / 常态 / 张满门洞 / 脉动）+ 熔岩缝从门洞下沿淌到地面（3 档长度）；熄灭态 = 缩成一点。
- 攻击方式：施法（仅表现，游戏里不攻击）——爪影缩进门里、门体后引 1 帧 → 一只火爪影从门洞伸出 20 格向前虚抓定格（斩击弧 + 爪尖火光 2 帧），甩出三道弯爪痕飞向目标 → 爪影收回。
- 差异化（同组 / 已通过的建筑：灵召塔（上一级）、充能塔、火神塔、玉藤堡垒；同组召唤物：魔豹、邪犬）：
  - 体型档：巨型角门档，本组最大，底座长出四只爪足（会走），和灵召塔的悬浮门、火神塔的梯形石堡、充能塔的树干拉开。
  - 识别特征：①两支外弯巨角伸出门框 5 格（改轮廓）②外侧锁链垂地堆开（改轮廓）③四只石爪足（改轮廓）④骷髅兽首 + 6 颗颅灯 + 熔血漩涡（保留灵召塔的石兽、法力灯、裂隙，同一个个体进化）。
  - 武器 + 握法 + 攻击类型：门里伸出的火爪影 × 虚抓（爪），和灵召塔的「裂隙吐弹」区分。
  - 待机个性：漩涡慢转、颅灯逐颗忽闪、锁链咔啦颤（每 0.4 s 左右摆）、熔岩从门缝一滴滴落下；1.5–2.0 s 爪影从门里扒住门洞右沿、兽首眼火一亮。
  - 步态：四只石爪足蹒跚挪步——对角两只一组交替抬起 3 格，两个接触帧前后互换；经过帧门体抬 1 格并左右晃 1 格，锁链反向摆；每个接触帧 3 颗尘 + step。
  - 死亡方式：内爆——整座门被自己的裂隙吸进去，像素由外向内螺旋收向门心（外圈先被吸走、越往里转得越快），最后一点闪白熄灭，锁链脱落砸在地上堆开。
  - 主色：黑曜赤岩 + 熔血红 / 熔岩橙，和灵召塔的月白石 + 魂光青蓝完全相反的色相。

# 特效设定卡

- 元素色阶：地狱 · 熔血 FXI.blood：21 白 → 58 淡粉 → 57 红 → 56 暗红 → 55 酒红；熔岩点缀 FXI.fire（21 → 47 → 46 → 45 → 44）；锁链崩断的火星 FXI.steel；尘土 FXI.dust；受击火花 FXI.impact。
- 攻击「火爪虚抓」：
  - 预兆：裂隙收缩、爪影缩进门里、门体后引 1 格 1 帧。
  - 出手：火爪伸出门洞 20 格定格，熔血斩击弧 + 爪尖十字火光 2 帧 + 10 颗火星。
  - 弹道：三道并排的弯爪痕（白尖 → 淡粉 → 红 → 暗红），140 格/秒，隔步拖尾。
  - 命中：14 颗熔血外爆 + 一道斩击弧，假人小摇。
- 技能「超级裂隙：蓄满法力后召唤魔豹和邪犬」：
  - 蓄力 1.4 s：6 颗颅灯每 0.2 s 燃起一颗（法力 16%/s）；熔血漩涡越转越快，熔血定点螺旋汇进门心；0.5 / 0.7 / 0.9 / 1.1 s 四根锁链依次「崩」地绷断（钢色火星 10 颗 + 小十字 + 从拱上掉一块黑曜岩弹地 + 震屏 1 格，表现损失 1040 生命）；熔岩顺裂缝流下、越流越长，拱顶裂纹透出熔光；轮廓光 1 → 2 档（rimAll，外沿按距离打光）；1.1 s 起裂隙逐帧脉动、门体一顿一顿。
  - 施放 0.5 s：裂隙张满门洞；一道血红火柱从门洞自下而上冲天（第 1–2 帧长满，之后从下往上断开）；汇聚粒子外爆 + 30 颗熔血 + 冲击环 + 十字星芒；震屏 2 格 + 天空闪白；魔豹剪影（弓背、双触须、分叉双尾）与邪犬剪影（长腿、短角、拖断链）先后扑出门洞，带 2 层残影。
  - 命中：两只剪影落点各一道双向地裂（fx.crack blood 左右各 8 格）+ 一圈火环（ring fire）+ 16 颗熔血外爆 + 10 颗熔岩飞溅落地（带重力贴地走完色阶）+ 震屏 1 格。
  - 收招 0.7 s：裂隙收回常态，颅灯一颗颗熄灭，熔岩退回，0.5 s 断链重新垂下扣回门框。
- 受击：enemy 敌弹来袭 → 白色剪影 1 帧 + 击退 2 格 + 裂隙收缩、颅灯与兽首眼火暗下、锁链甩向前侧；impact 火花 18 颗 + 黑曜岩屑 6 颗 + 震出的熔血 6 颗；震屏 1 格。
- 死亡：来袭命中闪白 + 裂纹（火花 26 颗、震屏 2 格、天空闪白）→ 0.5 s 裂隙暴涨成脉动、满身熔岩裂纹、门体一顿一顿 → 0.65 s 锁链脱落竖直砸下、夜空压暗，门体像素螺旋收向门心（10 帧）并伴随熔血碎屑螺旋吸入 → 0.99 s 锁链落地沿地面堆开 + 尘土、fall → 1.45 s 门心最后一点闪白（小冲击环 + 14 颗熔血 + 震屏 2 格）后熄灭 → 魂光上升，地上的链堆 1.5 s 后抖动消散。
- 音色：锁链崩断的金属脆响 + 熔岩咕嘟 + 地底低吼，重量 1.0。SFX `{ body: 'stone', how: 'dissolve', pal: 'blood', style: 'summon', w: 1.0 }`；step 在爪足接触帧，swing（claw）+ shoot（fire）在出手帧，hit（magic）在爪痕命中，impact（blood）两只剪影各落地一次，fall 在锁链落地帧。
