# 角色设定卡 · 白牙 WhiteFang

- 名称 / 身份：白牙，恶魔族召唤师（部队，史诗），火猪进化成的白獠牙巨野猪；背着手里剑转轮发射架，花黄金给自爆步兵装上手里剑。
- 一句话剪影：前重后轻的楔形巨野猪 + 两根上弯白獠牙 + 背上高出背线的四臂手里剑转轮 + 红面罩飘带 + 挂小铁炸弹的导火索尾。
- 尺寸：约 44×30 格（含獠牙、转轮、尾；身体约 34×22），史诗，比火猪大一倍半。站位 HX 58（背负转轮远投，不前冲）。
- 骨架：parts-beast `B.quad`——head boar 放大（颅 8×7、吻 5、吻高 5、垂耳 droop 3、盘状鼻，自带獠牙关掉改自画）、len 13、chest 6 / rump 3.8、waist 0.35、hump 2.5（肩峰高耸的楔形）、leg 5、lw 3 粗腿、hoof 蹄、neckA 0.15 / headA 0.35 头低压向前、mane ridge 白鬃 3、tail none（导火索尾自画）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 铁灰鬃皮 body = iron [0, 27, 28, 29]，band 2；四肢 / 头 band 1；远侧腿暗一级。
  - 背脊长鬃 mane = white [7, 18, 17, 21]；吻部 muz [0, 28, 29, 30]；鼻盘 nose [0, 11, 12, 13]；蹄 claw [0, 0, 8, 27]；眼 eye [0, 0, 17, 21]（面罩眼缝里的白）。
  - 忍者面罩与飘带 mask = crimson [11, 12, 13, 26]，远侧飘带 [11, 12, 12, 13]。
  - 獠牙 tusk = white [7, 18, 17, 21]，远侧 [7, 18, 18, 17]；蓄力时牙尖映白热 hot（whitefire 色，平涂，不是光源）。
  - 转轮刃 blade [27, 28, 30, 31]；发射架 frame = iron；金轴心 hub = gold [20, 19, 14, 5]；轴心芯 core [#ff8a2a, #ffd060, #fff8d8, 21]（发光体，平涂 5 档）。
  - 导火索 fuse [0, 20, 19, 32]；小铁炸弹 bomb [0, 0, 27, 28]；引信火星 spark [#8a2a10, #ff8a2a, #ffd060, 21]（发光体）。
- 部件顺序（从后往前）：远侧两腿 → 导火索尾 + 炸弹 + 火星 → 背脊白鬃 → 躯干 + 颈 → 近侧两腿 → 发射架（鞍板 + 两根斜撑 + 立柱）→ 转轮（刃 + 金轴心 + 发光芯）→ 面罩飘带 → 远侧獠牙 → 头（+ 紧跟着画的面罩）→ 近侧獠牙 →（死亡时）脱落的转轮。
- 细节清单：
  - 脸：面罩横过眼睛 3 行红布（上下沿暗一级）+ 2 格白色眼缝、垂耳、盘状鼻 2 格、吻部浅一级；闭眼时眼缝合上。
  - 毛：背脊一排直立白长鬃（中段最长、随 P.mane 摆）、背上毛纹。
  - 配件：面罩后脑结 + 两条 6 / 5 格飘带（根部 2 格宽、尖端摆）；发射架鞍板贴着背线，斜撑和立柱把转轮顶起 8 格。
  - 武器：四臂风车转轮（三角刃，根 1.2 → 尖 5，刃尖高光；每档转 22.5°，4 个朝向）；金轴心 3×3 左上亮右下暗，芯 5 档（暗 / 亮 / 很亮 / 爆闪 / 熄灭）。
  - 獠牙：根 2 格粗、尖 1 格，从嘴角往前再往上卷，远侧那根错开 1 格暗一级。
  - 尾：2 格粗的弹簧导火索，末端坠一颗 3×3 小铁炸弹（左上高光），炸弹顶一格引信火星。

- 升级线（火猪 → 白牙）：头巾 → 面罩 + 更长飘带、嘴角小白獠牙 → 巨獠牙、导火索尾加粗并挂炸弹、口衔手里剑 → 背负手里剑转轮；圆桶小猪 → 楔形巨野猪；焰橙 → 铁灰 + 白（名字「白牙」），特效从 fire 升成更白更亮的白焰。
- 差异化（同组四足：看门犬、邪犬、魔豹、月豹、白狼、雪狼王；已通过：熊线、狼线、马、龙、攻城羊 SiegeRam、针刺者）：
  - 体型档：前重后轻楔形巨野猪档，约 34×26 身体；和攻城羊（奶油卷毛、羊角、挡箭棚）比：铁灰短鬃、低压的长吻、白獠牙、背上是竖起的转轮不是棚；和黑熊（黑褐、可人立）比：蹄、长吻、獠牙。
  - 识别特征：①两根上弯白獠牙伸到吻前上方（改轮廓）②背上四臂手里剑转轮高出背线（改轮廓，三倍频率的来源）③面罩 + 两条长飘带 ④导火索尾 + 小铁炸弹（改轮廓）⑤背脊白长鬃。
  - 武器 + 握法 + 攻击类型：背负 × 连射（转轮一次甩 3 枚），同族无重复（火猪口衔 × 投、月豹背负 × 单发射、狼咬 / 扑、熊挥掌）。
  - 待机个性：低头用獠牙在地上磨（前后蹭、牙尖冒尘），背上转轮缓慢空转、0.8 s 卡一下「咔」轴心一亮。
  - 步态：重蹄冲步——对角步，每个接触帧 3 颗尘 + 身体顿 1 格。
  - 死亡方式：前扑犁地——前膝跪折、胸口和獠牙插进地里往前犁（lie 1 + pitch -3），土沟裂纹；转轮从背上脱落飞过头顶、落地滚开后倒平。和火猪（四脚朝天侧翻）、熊狼（侧躺）拉开。
  - 主色：铁灰（iron）+ 白；四足里没有铁灰主材质的（攻城羊奶油、针刺者骨白黑尖、黑剑蓝黑）。
