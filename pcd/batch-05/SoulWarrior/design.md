# 灵魂战士 SoulWarrior

模块：`pcd/chars/SoulWarrior.js`　查看：`pcd/view.html?c=SoulWarrior`　截图 / 导出：`shots/`

## 角色设定卡

- **名称 / 身份**：灵魂战士，恶魔族先锋（传说）。先祖战士从坟里长成的披甲英雄——同一个先祖，穿上了赤甲，断剑被墓火接成了传说之剑。
- **一句话剪影**：赤甲面盔两侧一对向后掠的骨白王角；肩上扛着一把半截锈铁、半截青绿魂火的长剑；身前立一面赤甲镶边的碑形塔盾；肩后两条魂火飘带。
- **尺寸**：待机 29×34 格（含角），比先祖战士高 6 格。体型档英武重甲（`parts.rig` heroic，stride 4）：头身比约 6.5，宽肩长腿、站得笔直。
- **材质色阶**（[勾线, 暗, 基, 亮]）
  - 板甲 plate：blood 色阶，band 2（面积最大）
  - 甲缘 / 碑顶金冠 / 铆钉：gold；腰带：boot；铁靴：iron
  - 王角：bone，角根金箍；白辫：white，辫梢骨珠 bone
  - 碑形塔盾：碑面 stone + 镶边 blood
  - 剑：锈剑根 iron + leather 锈斑，握把缠布 [20, 7, 6, 5]，柄头 / 护手 gold
  - 墓火 glow（发光体，flat）：grave 色阶 `#10302a #2a7462 #62d0a4 #d4f6e4`——魂刃、碑纹、甲缝、飘带、盔缝眼光
- **部件顺序（从后往前）**：两条魂火飘带 → 白辫 → 后臂（板甲、肩甲）→ 胫甲腿 → 板甲躯干（金缘、菱形胸徽、甲缝墓火同一部件）→ 头 → 赤甲面盔（金盔箍、眼缝墓火）→ 王角 → 碑形塔盾（后手）→ 传说之剑 → 前臂（金缘肩甲）→（技能）浮起的甲片。
- **细节清单**
  - 面部：面盔眼缝 1 格墓火光 + T 形金面饰
  - 发：面盔后垂下的白辫，辫纹逐行亮暗，辫梢骨珠会摆
  - 头饰：后掠王角（远侧暗一级）、金角箍、金盔箍
  - 躯干：板甲中脊、胸腹分界、甲片铆钉、金缘、菱形胸徽、腰带金扣；甲缝 4 处墓火像呼吸一样明灭
  - 手臂：板甲袖、肘甲、肩甲
  - 腿脚：胫甲（膝甲外凸）、铁靴
  - 盾：圆顶碑形塔盾 9×16，赤甲镶边、金碑冠、4 颗金铆钉、碑面中央一列墓火符文（和先祖战士墓碑同纹，从下往上逐行点亮，5 档）
  - 武器：金柄头、缠布握把、金护手、锈剑根带锈斑、接缝一道白、魂刃 2 格宽（受光侧最亮）、剑尖
- **攻击方式**：近战。劈——塔盾护身，单手把传说之剑举过头顶，前冲 4 格竖直劈到前下方。
- **差异化**
  - 体型档：英武重甲（先祖战士是矮壮微驼，同一个人长高、挺直）
  - 识别特征：碑形塔盾（外轮廓）、后掠王角（外轮廓）、半锈半魂火的传说之剑（外轮廓）、肩后两条魂火飘带（外轮廓）、白辫
  - 武器 × 握法 × 攻击：单手剑 + 塔盾，举过头顶竖劈（先祖战士是上撩；同族血骑士 / 黑铁卫 / 维京战士的握法与攻击类型都不同）
  - 待机个性：剑扛在肩上挺胸站定，甲缝魂火随呼吸明灭；循环里挺胸一下、剑在肩上一颠，甲缝和碑纹一齐烧旺、飘带扬起
  - 步态：行军正步，步幅 4，接触帧身子一沉、剑在肩上一颠，每步 2 颗尘
  - 死亡方式：散架空甲（死亡套件 parts）——面盔、王角、肩甲手臂、塔盾、剑各自飞出，空甲里升起一团墓火后熄灭
  - 主色：赤血色板甲（blood，band 2），和先祖战士的墓苔绿褐拉开；升级线共用 grave 墓火、白辫、骨白角
- **升级线对照**：墓碑盾 → 碑形塔盾（同一套碑纹）；上弯长角 → 后掠王角；白辫保留；锈断剑 → 剑根仍是那截锈断剑、上半截由墓火魂刃接续；grave 色阶保留，加赤甲、金缘和飘带这一层华丽度。

## 特效设定卡

- **元素色阶**：墓火 · 青绿，fxRamp `grave`：21 白 → `#d4f6e4` → `#62d0a4` → `#2a7462` → `#10302a`（同升级线），衬赤甲；光柱核心是 21 白。
- **攻击「竖劈」**：预兆——剑举过头顶（1 帧，魂刃亮一档）；出手——前冲 4 格、定格 1 帧，impact 色阶拖影弧从头顶劈到前下方；命中——impact 外爆 12 颗 + 十字星芒，假人小摇。
- **技能「浅坟 · 升级」**（灵魂从天而降回到甲胄里，复活后更快更凶）
  - 蓄力 1.4 s：把传说之剑插进身前的地里（剑身贴地截断），塔盾收到身前；魂火从剑尖一格格往上爬到剑根（锈铁被点亮）；赤甲甲片一片片脱离身体浮起 1–2 格（肩、盔顶、胸、胯、背共 5 片，最后 0.3 s 抖动）；碑纹逐行点亮；四周墓火粒子定点汇聚到剑上，余烬沿剑身上飘；轮廓光 2 档；剑头上方蓄满小星。
  - 施放 0.5 s：一道青绿墓火光柱从天而降落在剑上（fx.pillar grave），浮起的甲片磁吸回身（每片位置迸 3 颗火星），蓄力粒子外爆 + 30 颗墓火外爆 + 大冲击环 + 十字星芒，震屏 2 格 + 天空闪白；接着拔剑举过头顶。
  - 命中：十字墓火斩（两段 fx.slash 交叉）+ 向前 18 格的墓火地裂（fx.crack grave），墓火外爆 28 颗 + 冲击环，假人闪白大摇击退，震屏 1 格。
  - 收招 0.7 s：魂刃 / 碑纹 2→1→0，余烬从魂刃飘升。
- **受击**：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 眼缝熄灭 + 甲缝暗下、白辫与飘带反甩；赤甲火花（impact 22 颗 + 4 颗墓火星），震屏 1 格。
- **死亡**：26 颗火花 + 4 颗墓火星 + 震屏 2 格 + 闪白 → 踉跄 → 拄剑单膝跪地（尘土、落地声）→ 魂刃与甲缝闪几下熄灭 → 散架：面盔、王角、肩甲手臂、塔盾、剑按部件飞出、落地弹跳（落地声）→ 空甲里一团墓火升起 10 格、逐帧闪灭 → 碎片抖动消散，墓火 + 魂光上升。
- **音色**：甲片铿锵 + 墓火呼啸 + 一声拖长的剑鸣，重量 0.75。SFX `{ body: 'armor', how: 'collapse', pal: 'blood', style: 'beam', w: 0.75 }`；step 在步态接触帧，swing / hit 在出手帧，impact 在光柱落地与十字斩，fall 在跪地帧和碎甲落地。
