# 天使弓手 AngelArcher

模块：`pcd/chars/AngelArcher.js`。身体用部件库拼（`rig slim`、`legs bare` `torso robe` `arm B` `hand` `head`），翅膀的画笔用 `parts.beast.util`（`poly` / `dot` / `seg`）；模块里的候选部件：
`angelWing`（残破天使翼：翼姿表带「收拢下垂」——腕部高过头顶、飞羽沿背垂下，B.wing 的翼姿表摆不出这种收法）、`longbow`（斜举长弓：焦布缠绕 + 两梢火羽）、`beakSkull`（同前两级，本级羽冠变白后掠）、`drawArm`（手肘显式的拉弦臂）、燃烧的光环。
升级线：`EagleBeakedArcher.js` → `CatapultArcher.js` → 本级。**同一个僵尸升华了**：同一顶鹰颅盔（羽冠变白）、同一张脸和牙、同一道缝合前臂；上一级拖到后腰的破羽披风长成一对残破羽翼；从佝偻变成挺胸站直；后手握弓、前手拉弦的握法不变。

## 角色设定卡

- 名称 / 身份：天使弓手，稀有品质、整条线最「升华」的一级：带翼、头顶燃烧光环的僵尸射手，每一箭都点燃目标。
- 一句话剪影：**一对残破天使翼（收拢时腕部高过头顶）+ 头顶上方悬一圈燃烧的光环 + 比身体还高、斜举的骨制长弓**。
- 尺寸：待机 36×41 格（身体到颅顶 28，光环火苗顶 41；翼展张开约 30 格）；体型 `slim`，覆盖 `leg 11 · torso 9 · head 6 · sw 3 · stride 3`，不驼背（hunch 0）——挺直瘦高。
- 材质色阶（[勾线, 暗, 基, 亮]；除皮肤外全部取自共享色板）：
  - 白麻破袍（主材质，躯干 + 袖）`white` [7, 18, 17, 21] · 腰绳 / 弓臂焦布 `boot` [0, 20, 20, 19]
  - 皮肤 尸绿灰（共用，专属色 4 个）[#1c2414, #4a5a36, #7a8f5c, #a3b682]（赤足、前臂、脸）
  - 羽翼 `pale` [8, 59, 60, 17]（近侧覆羽用暗一级 [8, 59, 59, 60]，远侧覆羽 [0, 8, 8, 59]）· 翼骨 `bone`
  - 鹰颅盔 / 长弓 `bone` [8, 7, 6, 17] · 牙 [8, 18, 17, 21] · 白羽冠 `white` · 弦 [8, 18, 18, 17]
  - 圣火（光环、胸口缝线、弓梢火羽、火羽箭、着火的羽尖；发光体，flat）[12, 26, 47, 51] · 缝线 `ink`
- 部件顺序（从后往前）：远侧翼（暗一级、往上 / 往前错开）→ 后臂（白麻袖）→ 赤足腿 → 躯干（白麻长袍 + 腰绳，腰以下剪成布条；胸口缝线里的火光，同一部件）→ 近侧翼 → 头（脸 + 牙 + 鹰头骨同一部件）→ 白羽冠 → 燃烧光环 → 长弓（弓臂 + 焦布 + 火羽 + 弦）→ 火羽箭 → 后手 → 拉弦臂（白袖上臂 → 缝合前臂 → 手）。
- 细节清单：
  - 脸：同前两级（大眼窝一点圣火光、钩喙、喙下的嘴和牙、凹进去的眼）。
  - 头饰：3 根白羽贴着颅顶往后掠（给光环让出位置，羽尖会摆）；头顶上方悬一圈扁椭圆火环（前弧亮、后弧暗、两侧 2 格粗），上面窜 3 簇火苗（一跳一跳，5 档：暗 / 常亮 / 火势大 / 爆燃 / 熄灭）。
  - 服装：白麻长袍（外扩下摆、褶、领口）、腰绳 + 骨扣；腰以下隔 3 列剪开成布条、布条长短参差、随 sway 飘，露出里面的赤足尸腿；胸口一道缝合线（墨线和火光一格隔一格）。
  - 翅膀：覆羽成片盖住飞羽根部（暗一级）、3 根次级短羽沿后缘垂下、5 根初级长羽从腕部扇开（近侧 2 格宽，1、3 号带缺口）；前缘翼骨中段露出白骨，腕骨节一格高光；着火时从羽尖往里烧。
  - 手臂：白麻袖；拉弦臂的尸皮前臂上两针缝线（和前两级同一道）。
  - 武器：骨制长弓（半长 13，约 26 格，2 格粗骨弓臂、握把和两段弓臂缠焦布、两梢各一簇火羽），斜举（上梢朝前，箭沿 2:1 朝前下方）；火羽箭（骨杆、火羽尾、火焰箭头，蓄满后长成 5 格长的火羽）。
  - 发光体：光环、火羽箭头、胸口缝线火光、弓梢火羽、眼窝光；死亡时光环掉到地上熄灭。
- 攻击方式：远程「射」——借翼跃起（上扬 → 下扇，离地 2–3 格），斜举长弓搭箭 1 帧 → 拉满 1 帧 → 放箭定格 1 帧，由高处向前下方射出火羽箭 → 半张双翼滑翔落回。站位 HX 34。
- 差异化（对照已通过角色和同升级线）：
  - 体型档：瘦高挺直 + 一对大翼（上一级屈膝前探、再上一级佝偻蹒跚）；已通过角色里没有带翼的人形。
  - 识别特征（≥ 2 个改外轮廓）：①残破天使翼（收拢时腕部高过头顶、飞羽垂到大腿，张开时翼展约 30 格）（轮廓）②头顶上方的燃烧光环（轮廓）③比身体还高的斜举长弓、两梢火羽（轮廓）④布条下摆 ⑤胸口透火的缝合线。
  - 武器 + 握法 + 攻击类型：后手斜举长弓 + 前手拉弦 + 跃起下射（上一级抛物线投射、再上一级竖弓平射）。
  - 动作个性：待机 = 1.6–2.0 s 双翼慢慢半张再收拢，光环火苗一闪一闪，站姿挺直；步态 = 跳翔（落地微张 → 上扬起跳 → 下扇到最高 3 格 → 半张滑翔落下，落地无尘，起跳时身后飘下 1 片羽毛）；死亡 = 跪倒自焚化灰。
  - 主色：白麻 + 灰白羽 + 玫红圣火（上一级暗酒红、再上一级褐皮）；和修女的鸽灰蓝、巫师的星辉紫都拉开。
  - 特效：圣火偏玫红（白 → 淡金 → 金橙 → 玫红 → 酒红），和火葬人的橙黄炉火、赤龙的熔岩色拉开。

## 特效设定卡

- 元素：圣火（火焰），`fxRamp('holyfire')` = 白 21 → 淡金 51 → 金橙 47 → 玫红 26 → 酒红 12（只用共享色板里已有的颜色）；飘落的羽毛另用 `fxRamp('angelfeather')` = 白 21 → 17 → 60 → 59 → 8。
- 攻击「火羽折射」
  - 预兆：双翼上扬、搭箭（箭头亮 1 档）→ 下扇起跳、拉满。
  - 出手：离地 3 格放箭定格 1 帧；圣火十字枪口光 2 帧 + 5 颗火星；弹道 = 白芯箭头 + 骨杆 + 火羽尾，200 格/秒朝前下方飞，隔步火色拖尾。

- 技能「燃烧 + 水之弹射」（被动特性生效的样子：一箭点燃目标，再弹到第二个目标也点着）
  - 蓄力 1.4 s：双翼完全张开上扬，身体升到离地 4 格，光环火势变大（火苗 2–3 格、一跳一跳）；火羽从两侧翼尖一根根飞出、螺旋汇聚到箭头，0.7 s 起箭变成 5 格长的火羽；轮廓光从光环照下来（2 档，施放 3 档）、地面隔点映光；羽冠被吹向后。

- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 眼光熄灭、光环一暗 + 双翼一惊微张、羽冠反甩；骨灰（dust 12 颗）+ 少量火星 + 2 片被打落的羽毛飘下；震屏 1 格。
