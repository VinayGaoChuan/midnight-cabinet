# 铁甲战士 IroncladWarrior

模块：`pcd/chars/IroncladWarrior.js`。身体用部件库拼：`rig`（stocky，覆盖 leg 7 · torso 9 · sw 5 · limb 1.3）`legs torso('bare') arm`；库里没有的写在模块里（都带「// 候选部件」注释）：`coffinLid` 棺材盖盾、`bucketHelm` 倒扣铁水桶盔（含提梁弯环）、`crowbar` 铁撬棍（分配里写的是借 `axe` 的 crook 头，1 格细杆 + 小钩在夜色里读成一条细线，改成自画：钩根 3 格加粗到 2 格、钩尖回勾）、`nailString` 腰间棺材钉；另有本角色专用的 `lowerFace`（桶沿下的腐烂下颌）、低一行的圆肩甲 `pauldron` 和压在盾背沿上的握盾拳 `lidFist`。
升级线：→ `SteelWarlord.js`（钢铁军阀）。两级共用的识别点：**酸绿眼透过铁皮上的洞 / 缝、水桶的提梁环、灰绿皮肉 + 钉进肉里的钢铆钉、腕上铁箍、「铁盖子」（棺材盖 → 全身铁处女）、弯钩铁器（撬棍 → 战镐）、收招时从缝里喷气**。

## 角色设定卡

- 名称 / 身份：铁甲战士，前排先锋的重装僵尸（优质：比普通兵多铆钉、铁十字补丁、腰间一串棺材钉）。
- 一句话剪影：**头上倒扣一只外翻卷边的铁水桶（脑后挂提梁环）+ 身前竖着一块 20 格高的棺材盖 + 撬棍的弯钩从盾沿上方探出**。纯黑剪影读成「躲在高盾后面的矮壮守卫」。
- 尺寸：待机 23×29 格（身体到桶顶 24 格，撬棍弯钩顶 27 格）；体型 `stocky` 调高（leg 7 · torso 9 · sw 5），宽肩厚背、没有脖子（下颌直接压在肩上）、手臂粗（limb 1.3），重心低。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 主材质 锈褐铁板（胸板 / 腹板 / 胯甲、桶盔、靴）自定 [#170d0a, #3a1f16, #63392a, #8c5a3c]
  - 皮肉 尸绿灰（僵尸人形共用）自定 [#1c2414, #4a5a36, #7a8f5c, #a3b682]；硬化后换成 `steel` [27, 28, 29, 30]
  - 撬棍、盾的铁包边和十字补丁、桶口卷边、提梁、护腕、肩甲 [0, 28, 29, 30]（分配写的是 iron [0, 27, 28, 29]；1 格细杆用 iron 在夜色里全黑，按「iron 往亮挪一级」用，仍是同一族铁灰）；腰带 `iron` [0, 27, 28, 29]
  - 钢铆钉 `steel` 第 4 级（30）· 棺材盖木芯 `wood` [0, 20, 19, 16]（band 2）· 牙 / 下颌骨 `bone` [8, 7, 6, 17]
  - 发光体：酸绿眼（flat）[48, 49, 50, 38]；盾面十字补丁发光档（flat）[27, 29, 30, 21]
  - 专属色 8 个（锈铁 4 + 尸绿 4），其余全取自 64 色共享色板。
- 部件顺序（从后往前）：撬棍（后手武器，永远在身体后面）→ 后臂（灰绿 + 护腕 + 拳，握在撬棍上）→ 腿（灰绿小腿 + 锈铁靴）→ 躯干（灰绿赤膊，同一部件里钉上胸板、腹板、胯甲、钢铆钉、皮肉缝线）→ 腰间棺材钉 → 桶盔（同一部件里画桶沿下的下颌和牙）→ 提梁弯环 → 前臂（灰绿 + 铁护腕）→ 圆肩甲 → 棺材盖盾 → 握盾的拳（2×2，压在盾背沿中部：盾是被手握着的，不是自己立在地上）。
- 细节清单：
  - 脸：桶身前面凿一个眼洞，透出 1 格酸绿眼（4 档：常亮 / 蓄满更亮 / 受击闭 / 死亡熄灭）；桶沿下露出两行——腐肉脸颊（一处凹陷）、上牙三颗、前端翘出 1 格的下颌骨；下颌一张一合（张嘴时上牙行变黑洞只剩一颗獠牙）。
  - 头饰：倒扣的铁水桶（平顶桶底、两侧每 2 行外扩 1 格的直斜边、桶口外翻卷边）、中间一道箍、左侧受光的斜棱、锈斑凹坑、侧面一颗亮耳座；提梁弯环从桶后上角绕到脑后、下半段会摆。
  - 躯干：灰绿赤膊上钉三块锈铁板（胸板、腹板、胯甲），胸腹之间一道皮肉缝 + 横跨的缝线，板角 4 颗钢铆钉；铁腰带 + 钢扣。
  - 手臂：粗的灰绿赤臂 + 铁护腕 + 2×2 拳；盾侧 6×4 圆肩甲（比部件库的 round 低一行，不顶住下颌）+ 一颗铆钉。
  - 腿脚：灰绿小腿 + 3 行锈铁靴，前脚尖多 1 格。
  - 配件：腰后一串 3 根棺材钉（钉头亮 + 钉身 2 格），随步子摆。
  - 武器：棺材盖盾——上宽下窄的长六边形（20 行、最宽 9 格），一圈铁包边、每 3 行一颗钢铆钉，木芯两道竖板缝，上半一块铁十字补丁（十字四个端头也是铆钉；5 档亮度，死亡熄灭）；铁撬棍（`crowbar`）——1 格直柄 + 一端弯钩：钩根 3 格加粗成 2 格、钩顶 2 格、钩尖回勾 2 格；竖持时钩尖朝前，勾砸平伸时钩尖朝下。
- 攻击方式：近战 **勾砸**：盾收回、撬棍抡到脑后（预兆）→ 前冲 3 格、盾往前一顶，后手越过盾沿把撬棍由上往下勾砸（弯钩朝下，落在假人肩头）→ 收回。站位 HX 76。
- 差异化：
  - 体型档：矮壮无脖（同批僵尸人形：鹰喙弓手 / 投石弓手 / 天使弓手是瘦高，月光使徒 / 时空法师是高瘦长袍；本角色是全批最矮最宽的一个）。对照已通过：焚尸人也是矮壮，但它是方块铁面罩 + 长柄火铲 + 背骨灰坛；本角色是倒扣水桶 + 身前 20 格棺材盖 + 撬棍（查重最近就是焚尸人：待机 IoU 0.686、配色 0.369）。
  - 识别特征（≥ 2 个改外轮廓）：①倒扣水桶 + 外翻卷边 + 脑后提梁环（轮廓）②身前竖着的 20 格棺材盖（轮廓）③盾沿上方探出的撬棍弯钩（轮廓）④胸前钉在皮肉上的锈铁板 ⑤腰间棺材钉。守夜人是远侧手塔盾 + 灯 + 长戟 + 宽檐帽；维京战士是近侧手圆盾 + 角盔 + 盾击。
  - 武器 + 握法 + 攻击类型：前手持盾 + 后手单手撬棍 **勾砸（越过盾沿由上往下）**——已通过的持盾角色是刺（守夜人）和盾击冲撞（维京战士）。
  - 动作个性：待机 = 下颌一张一合、撬棍往前一倒用杆身敲两下盾沿上角（两下火星）；步态 = 行军重步（盾稳在身前、撬棍随步点头，接触帧顿挫 1 格 + 3 颗尘；接触 A 盾侧前脚多跨 1 格，两个接触帧剪影不同）；死亡 = 跪倒被盖（棺材盖倒下扣在身上，合上棺材）。
  - 主色：锈褐铁 + 灰绿皮肉 + 木色棺材盖（焚尸人是炭灰袍、维京是靛蓝、守夜人是橄榄绿）。
  - 自动查重：`compare.mjs` 退出码 0。

## 特效设定卡

- 元素：守护 · 锈铁硬化，`FXI.steel` = 白 21 → 冷白 31 → 亮钢 30 → 钢 29 → 暗钢 28；蓄力阶段混 `dust` 色阶的锈屑；尸气 / 魂光用酸绿 `poison`（21 → 50 → 49 → 48 → 34）。
- 攻击「勾砸」
  - 预兆：盾收回、身体后缩 1 格、撬棍抡到脑后，下颌张开（2 帧缓出）。
  - 出手：定格 1 帧，前冲 3 格；身后留一个后引姿的冷钢残影（0.25 s 抖动消散）；从脑后越过盾沿的一道冲击弧（impact 色阶，半径 13，2 格宽 → 1 格断续）。
  - 命中：钩尖处 14 颗 impact 外爆 + 十字星芒，脚下往后扬 3 颗尘；假人闪白小摇。
- 技能「硬化」（被动特性生效的样子：开战时把盾砸进地里、皮肉一段段变铁）
  - 蓄力 1.4 s：半蹲缩到盾后（盾底贴地）；四周的铁屑（steel，2 格短条：亮头 21 / 31 朝前、尾巴 30 / 29）和锈渣（dust）从上半圈和两侧顺时针螺旋收拢到盾面十字上（定点汇聚，越来越密；起点落进身体剪影就往外推）；十字补丁 1 档 → 0.45 s 后 1 / 2 档逐帧闪（亮钢 → 白芯）；桶洞里的眼变亮；0.9 s 后咬牙发抖（左右 1 格）；轮廓光逐档加强：0.2 s 起 1 档（亮钢 30）→ 0.7 s 起 2 档「亮档」（白 21 / 冷白 31，半径放大，盾的铁包边、撬棍、手臂也吃光，和铁包边的 29 / 30 拉开）；盾脚下地面隔点映光（白 → 冷白 → 亮钢，每帧错一格）。
  - 施放 0.5 s：盾往下一砸（下蹲 3 格，盾底插进地 2 格），身体闪白 1 帧；左右两道地裂 + 冲击环 + 24 颗钢屑外爆 + 12 颗尘 + 十字星芒；震屏 2 格、天空闪白。随后**高光带**从脚到头扫过身体（白 → 冷白 → 亮钢三行，每帧上移 4 格），带经过的地方灰绿皮肉变成铁灰（小腿 → 手臂 / 躯干 → 下颌三段），盾上的钢铆钉随带逐颗白闪；2/12 s 点阵护罩（`fx.dome` steel，17×30）从身后亮起（`impact` 一次）。
  - 收招 0.7 s：护罩碎成一圈钢屑落下；颈、肘、膝三处关节缝喷出白蒸汽（dust 慢升）——之后虚弱一波的代价；铁灰一段段褪回灰绿；十字 2 → 1 → 0。
- 受击：enemy 敌弹打在棺材盖上 → 白色剪影 1 帧 + 击退 2 格 + 眼洞熄灭 + 下颌张开 + 提梁环反甩；14 颗 impact + 6 颗长寿命钢火星 + 5 颗锈灰；震屏 1 格。
- 死亡：22 颗 impact + 钢火星 + 震屏 2 格 + 天空闪白 → 踉跄下蹲 → 跪倒、盾撑在地上，撬棍脱手（空中翻一帧后落到身前地上）→ 仰面倒下（离地 3 → 1 → 0，落地 12 颗尘 + `fall`）→ 棺材盖向后倒下：竖着停一帧 → 横在半空 → 0.75 s「哐」地扣在身上（18 颗尘、震屏 1 格、`fall`），只露出头端的水桶盔和脚端的靴子，像合上的棺材；十字补丁熄灭、眼洞闪几下熄灭 → 盖缝冒出一股酸绿尸气 → 1.6–2.4 s 自上而下消散 + 酸绿魂光上升。复活用酸绿色阶汇聚。
- 音色：锈铁摩擦的嘎吱 + 棺材盖木铁相撞的闷响；标志性的一声 = 盾砸进地里的「咚」接一串铆钉「咔咔咔」硬化声；重量 0.75（`SFX: body armor · how collapse · pal metal · style shield · w 0.75`）。钩子：`step` 在步态接触帧、`swing` + `hit`（metal）在勾砸出手帧、`impact`（metal）在护罩亮起帧、`fall` 在身体落地和盖子扣下两帧。
