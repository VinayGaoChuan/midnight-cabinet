# 鹰喙弓手 EagleBeakedArcher

模块：`pcd/chars/EagleBeakedArcher.js`。身体用部件库拼（`rig slim + hunch 1`、`legs` `torso leather` `mantle` `arm B` `hand` `head`），库里没有的写在模块里、标了「候选部件」：
`beakSkull`（鹰头骨盔）、`recurve`（短反曲骨弓）、`drawArm`（手肘显式的拉弦臂，parts.arm 的两节 IK 摆不出肘在身后），外加本角色的细箭袋。
升级线：本级 → `CatapultArcher.js`（投石弓手）→ `AngelArcher.js`（天使弓手）。三级共用：**鹰颅盔（骨白钩喙 + 眼窝一点光）、喙下的僵尸下颌和牙、尸绿灰皮肤、前臂一道黑线缝合、乱羽**，后手握弓、前手拉弦的握法也不变。

## 角色设定卡

- 名称 / 身份：鹰喙弓手，僵尸射手，普通品质的后排输出，瘦弱、驼背、脚步拖沓。
- 一句话剪影：**整只鹰头骨扣在头上、钩喙向前下方伸出 4 格 + 身前竖着一张反曲骨弓 + 背后斜插细箭袋（3 个水青箭头露在肩后上方）**。纯黑剪影里读得出「弓手」。
- 尺寸：待机 26×28 格（身体到颅顶 26，箭袋箭头 28）；体型 `slim`，覆盖 `hunch 1 · headX -1 · leg 10 · torso 8 · head 6 · sw 3 · stride 3 · lift 1`——瘦高佝偻，头前探，窄肩细腿。
- 材质色阶（[勾线, 暗, 基, 亮]；除皮肤外全部取自共享色板）：
  - 褐皮猎装（主材质，躯干 + 袖）`leather` [20, 19, 32, 33] · 裤 `stone` [0, 8, 9, 10] · 破靴 / 腰带 / 箭袋 / 斜挎带 `boot` [0, 20, 20, 19]
  - 皮肤 尸绿灰（僵尸人形共用，本角色专属色 4 个）[#1c2414, #4a5a36, #7a8f5c, #a3b682]
  - 鹰颅盔 / 骨弓 / 箭杆 `bone` [8, 7, 6, 17] · 牙 [8, 18, 17, 21] · 弦 [8, 18, 18, 17] · 握把皮绳 `leather`
  - 破羽披肩 / 箭羽 / 弓梢羽饰 `wood` [0, 20, 19, 16]（band 1）
  - 眼光 / 水刃箭头（发光体，flat）[39, 23, 22, 21] · 缝线 `ink`
- 部件顺序（从后往前）：箭袋 → 箭袋里的 3 支箭 → 后臂（握弓的窄袖）→ 腿（远侧暗一级）→ 躯干（皮猎装 + 腰带 + 斜挎带）→ 乱羽披肩（+ 3 根长羽，同一部件）→ 头（脸、下颌、牙和鹰头骨同一部件：头只有 6 格高，头骨单独成部件会把脸压成勾线色）→ 反曲骨弓（+ 弦）→ 水刃箭 → 后手（压在握把上）→ 拉弦臂（皮袖上臂 → 尸皮前臂 → 手）。死亡时被打飞的鹰颅盔单独一个部件。
- 细节清单：
  - 脸：鹰头骨的大眼窝（2 格暗）+ 1 格水青眼光、喙脊高光、鼻孔；喙下露出僵尸的嘴（暗缝）、两颗牙、瘦削下颌、颅盔下凹进去的眼。
  - 头饰：圆颅 + 颅顶骨缝和反光 + 钩喙（前伸 b+4 格、向下勾、喙尖暗一级），后脑骨沿垂到下颌。
  - 服装：皮猎装（前沿缝线、胸前系带、下摆）、骨扣腰带、斜挎箭袋带；破羽短披肩锯齿下摆 + 背后 3 根长羽参差翘出轮廓，随步伐 / 受击甩动。
  - 手臂：握弓的窄袖后臂；拉弦臂是皮袖上臂 + 裸露的尸皮前臂，前臂上两针黑线缝合。
  - 腿脚：灰裤 + 破靴，近侧靴尖露出 1 格尸皮脚趾。
  - 武器：短反曲骨弓（弓臂向后弯、梢尾往前翻 1 格、握把缠皮绳、上梢挂一根小羽饰随动作摆）；水刃箭（骨杆、羽尾、弯月刃形青白箭头，蓄满后长成 5 格高的弯月水刃）；背上细箭袋（两道箍，3 支箭头露在外面，收招时依次闪）。
  - 发光体：眼窝光（待机常亮、受击 / 死亡熄灭）、搭在弦上的水刃箭头（5 档：待机 / 蓄力 1 / 蓄力 2 / 施放 / 熄灭）。
- 攻击方式：远程「射」——竖弓在胸前快速平射：搭箭举弓 1 帧 → 拉满 1 帧 → 放箭定格 1 帧（拉弦手往后弹开、弦回直、枪口十字光 2 帧）→ 延续 → 收回。箭搭在握把上方 2 格（箭台），不和握弓的手臂叠在一起。站位 HX 34。
- 差异化（对照已通过：星辉巫师 / 守夜人 / 寡妇 / 修女 / 屠夫领主 / 钟表匠 / 火葬人 / 蛮兵 / 邪眼王 / 维京战士 / 奴隶主 / 两匹马，以及同批分配）：
  - 体型档：瘦高佝偻（hunch 1、sw 3，比钟表匠的驼背更瘦更高，也没有背箱）；同升级线里投石弓手是「练壮了的屈膝潜行」、天使弓手是「挺直 + 羽翼」。
  - 识别特征（≥ 2 个改外轮廓）：①鹰头骨钩喙前伸 4 格（轮廓）②身前竖握的反曲骨弓、弓梢过肩（轮廓）③背后斜插的细箭袋、箭头露在肩后上方（轮廓）④破羽披肩背后 3 根长羽（轮廓）⑤缝合前臂、露趾破靴。
  - 武器 + 握法 + 攻击类型：后手竖握弓 + 前手拉弦 + 平射——已通过角色里没有弓（钟表匠是双手端铳、寡妇是甩腕飞牌）。
  - 动作个性：待机 = 鹰颅盔每 0.4 s 一顿（前探 / 回收 1 格，像鸟在听动静）+ 1.6–2.0 s 前手指弹一下弓弦（弦抖 1 帧）；步态 = 蹒跚（经过帧后脚只抬 1 格，接触帧 1 颗尘 + 后脚拖出 1 颗尘）；死亡 = 散架。
  - 主色：褐皮猎装 + 骨白头骨 + 尸绿灰皮肤（和维京的靛蓝、火葬人的炭灰、钟表匠的铜绿都拉开）。
  - 特效：水刃（刀锋）走海水深蓝色阶，X 形水刃斩 + 折线弹射；已通过角色里没有水系。

## 特效设定卡

- 元素：水刃（刀锋），`FXI.water` = 白 21 → 青 22 → 蓝 41 → 深蓝 40 → 墨蓝 39（海水深蓝，和蓝龙偏淡金的雷电色阶拉开）。形态用刀锋：斩线、X 形、弯月刃。
- 攻击「弹射箭」
  - 预兆：搭箭举弓 → 拉满（箭头亮 1 档、羽摆向前）。
  - 出手：放箭定格 1 帧；枪口十字光 2 帧（白 → 青）+ 5 颗水花；弹道 = 白芯弯月箭头 + 骨杆 + 羽尾，200 格/秒，隔步 1 格水色拖尾。
  - 命中：7 颗水花外爆、假人闪白小摇；箭折向斜后方弹起，沿抛物线飞到假人后方 13 格（「附近小范围的 1 个敌人」），落点小十字 + 6 颗水花。
- 技能「水之弹射」（被动特性生效的样子：蓄满水刃的一箭射中后弹向第二个目标）
  - 蓄力 1.4 s：拉满定格、略直起身；水滴一半从地面、一半从四周螺旋汇聚到箭头（越来越密）；0.6 s 起箭头长成 5 格高的弯月水刃，0.45 s 后 1 / 2 档逐帧闪，前方十字星芒；轮廓光 2 档（从箭头照过来）、地面隔点映光；乱羽被吹向后方。
  - 施放 0.5 s：放箭，拉弦手往后甩开；汇聚的水滴外爆 + 12 颗水花 + 十字星芒 + 小冲击环；水刃大箭（弯月刃 + 箭杆，2 行水色拖尾）150 格/秒；震屏 2 格、天空闪白。
  - 命中：两道对角水刃斩先后 1 帧劈在假人身上成 X 形（白 / 青亮芯 + 深蓝刃边，奶白假人上也看得清，后半段断续消散）+ 22 颗水花外爆 + 十字星芒；假人闪白大摇、震屏 1 格；随后箭以约 45° 从假人弹起，沿抛物线飞向后方约 16 格的第二个点，落点小十字 + 小冲击环 + 一道短水刃弧（第 2 次 impact）。
  - 收招 0.7 s：弓放下，箭袋里的 3 个水刃箭头依次闪一下，箭头 2 → 1 → 0。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 眼光熄灭 + 乱羽反甩；火花换成僵尸的骨灰（dust 12 颗）+ 少量水色魂光 + 1 片土色碎羽；震屏 1 格。
- 死亡（散架，死亡套件 `parts`）：20 颗骨灰 + 震屏 2 格 + 天空闪白 → 鹰颅盔先被打飞、翻滚着落到身后（喙朝天）→ 骨弓脱手翻倒在身前 → 0.36 s 跪塌的那一帧按部件拆散，躯干塌成一堆（8 颗尘）→ 0.62 s 碎块落地（尘 12 颗、震屏 1 格）→ 静止约 0.9 s → 碎块抖动消散 + 水青魂光上升。
- 音色：干涩的骨弓弦「嘣」+ 水刃出手的「嘶」，标志性的一声是箭弹射时清脆的「叮——咻」两段；重量 0.35（`SFX: body flesh · how collapse · pal water · style blade · w 0.35`）。钩子：步态接触帧 `step w 0.3`；放箭帧 `swing bow` + `shoot arrow`；命中 `hit flesh`，弹射落点再一声轻 `hit`；技能 X 斩 `impact water 0.6`、第二目标 `impact water 0.35`；碎块落地 `fall 0.35`。
