## 角色设定卡

- **名称 / 身份**：蜥蜴。僵尸阵营的普通射手：一只被雷电劈活的死蜥蜴，身上缝着线、背上插着避雷杆，靠发电越打越快。
- **一句话剪影**：一条低伏在地上的长尾灰蜥蜴，背上竖着一根顶端弯钩的铜避雷杆，尾巴末端是一个两脚铜插头。
- **识别特征（5 个，3 个改变外轮廓）**
  1. 【轮廓】铜避雷杆：肩后 3 格竖起 8 格，顶端往前弯成钩，杆上缠两圈铜线圈；钩尖是发光体（待机时每个循环跳一下电火花，蓄力时冒十字星芒）。
  2. 【轮廓】长尾末端的铜插头：3 格宽的插头座 + 两根亮铜插脚，伸出尾尖 2 格（两脚之间是一格暗缝）。
  3. 【轮廓】颈上两颗弗兰肯斯坦式电极螺栓：从颈线上斜伸出 2 格（远侧那颗暗一级，只露出伸出颈线的部分）。
  4. 身侧从肩到胯一条粗缝合线（墨线 + 十字针脚），背上一排亮鳞点，骨白腹线。
  5. 大头宽嘴：近侧眼酸绿发光，远侧眼浑浊发白、鼓在头顶；待机会吐红色分叉信子。
- **体型档**：低伏爬行档（四足，头大尾长）。胸臀距 12、胸半径 3.8、臀 3.4、腿长 3（短腿，背高约 11 格）、颈 3、尾 14。待机 47 × 23 格（含尾和避雷杆），避雷杆把总高顶到 23 格，满足待机高度 16–44。普通品质，细节密度低。
- **材质色阶**（`[勾线, 暗, 基, 亮]`）
  - 死灰石板鳞：`[0, 9, 10, 18]`（分配的 stone `[0, 8, 9, 10]` 整体提亮一级：原色阶在夜景和远山前只剩一团暗块，缝合线、鳞点、腿都读不出来；色相仍是石板灰紫，和宝石蜥蜴的冷钢蓝灰明度相近、色相不同）。躯干 band 2，四肢 band 1，远侧腿暗一级 `[0, 9, 9, 10]`。
  - 腹线：bone `[8, 7, 6, 17]`；爪：bone。
  - 铜件（避雷杆、螺栓、插头）：leather `[20, 19, 32, 33]` 当铜色。
  - 眼 / 口中电光：平涂 `50` 酸绿、`38` 淡黄绿；钩尖发光：`[50, 50, 21, 21]`；远侧浑浊眼 `[8, 7, 6, 6]`；信子 blood `[55, 56, 57, 58]`。
  - 专属色 0 个（全部取自共享色板）。
- **部件顺序**（从后往前）：远侧两腿 → 远侧螺栓 → 尾 → 尾插头 → 躯干 + 颈（紧跟着画鳞点、缝合线）→ 近侧两腿 → 避雷杆 → 近侧螺栓 → 头（紧跟着画远侧浑浊眼、信子）。翻肚躺倒时四条腿挪到最后画；折断的避雷杆最后画。
- **细节清单**：脸（酸绿发光眼 + 亮眉、远侧浑浊眼鼓在头顶、鼻孔、宽嘴线、张嘴时口里发光、分叉信子）；鳞（背上亮鳞点、scales 暗鳞纹、骨白腹线带分隔）；缝合（墨线 + 十字针脚，从肩到胯）；配件（避雷杆：铜底座压在背线上、竖杆明暗交替、两圈线圈、弯钩、钩尖；插头：插头座 + 两根插脚；两颗电极螺栓）；脚（短腿、骨白爪尖）。
- **攻击方式**：远程「吐」。0–0.12 s 头往后上一缩、嘴里亮起（预兆）→ 第 2 帧猛地前伸、嘴张到最大、前身抬 1 格（出手定格）→ 吐出一颗酸绿电火球（2 × 2 白芯 + 锯齿拖尾，略往上飞打在假人身上）→ 延续 → 回位。站位 HX 34。
- **差异化**
  - 体型档：低伏爬行四足（本批只有蜥蜴线是低腿长尾的爬行兽；赤龙是厚重的破翼坦克龙，蓝龙悬浮，飞鹰是飞禽）。和已通过的四足（黄鬃马、汗血马）拉开：它们是高腿长颈的马，这里腿长只有 3 格、身体贴地、尾巴拖在地上。
  - 轮廓特征：背上的钩形避雷杆 + 尾端插头 + 颈螺栓，三者都伸出轮廓，没有别的角色有这组形状。
  - 武器 + 握法 + 攻击类型：口（吐）+ 背负避雷杆（充电器，不直接攻击）；本批的远程是弓、投石弓、月牙杖、沙漏杖，只有它是「吐」。
  - 待机个性：吐信 + 电抽搐（每个循环全身抖 1 帧，一道小电弧沿背从避雷杆跑到尾插头）；钩尖每个循环还跳一下电火花。
  - 步态：低伏爬行，对角步，头随步点一下、尾巴反向甩，轻快，每次落爪 1 颗尘。
  - 死亡方式：翻肚抽搐（肚皮朝上、四腿僵直朝天，电火花在腿间跳 3 次后熄灭）；避雷杆折断甩到身后。本批其余角色是后仰 / 散架 / 碎裂 / 坠落，没有翻肚。
  - 主色：石板灰紫鳞 + 铜 + 酸绿；和已通过角色配色相似度都在 0.81 以下（最接近是赌徒寡妇，剪影 IoU 只有 0.43）。
  - 查重：`compare.mjs` 对 `assets/reference` 和 `pcd/accepted` 退出码 0，最接近蛮兵（待机 IoU 0.444、施放 IoU 0.464、配色 0.258）；和宝石蜥蜴（同一条升级线）待机 IoU 0.552、配色 0.185，同一骨架但体量、颜色、背上的形状都拉开了。

## 特效设定卡

- **元素色阶**：尸电（雷电）`corpseBolt` = `[21, 38, 50, 49, 48]` 白 → #d2f08c 淡黄绿 → #c4e84a 酸绿 → #7aa018 橄榄 → #3a4a0a 墨绿，形态用锯齿 / 折线。僵尸族的酸绿，和蓝龙的青蓝闪电（FXI.bolt）拉开。宝石蜥蜴沿用同一色阶。
- **攻击「吐电火球」**
  - 预兆：头后缩、嘴里亮（glow 1），轮廓光 1 档。
  - 出手（第 2 帧）：嘴张到最大、口中发光 2 档；嘴前 3 格十字枪口光（2 帧，白 → 淡黄绿）+ 6 颗外爆。
  - 弹道：2 × 2 白芯 + 酸绿壳 + 6 格上下错位的锯齿拖尾（逐帧翻转）+ 拖尾粒子，170 格 / 秒。
  - 命中：8 颗酸绿火花 + 小十字星芒，假人闪白小摇。
- **技能「发电机 · 越打越快」**
  - 蓄力 1.4 s：0–0.6 s 缓入「四爪抓地压低」（crouch 2、前低、低头）；0.3 s 尾插头竖直扎进地面（插脚埋进土里，插头座立在地上），扎地处扬起尘土 + 电火花，之后地面映光（插头两侧 4 格）；0.35 s 起一道短锯齿电弧从插头沿尾巴 → 臀 → 背 → 避雷杆一路往上爬（两趟：第一趟 0.6 s，第二趟 0.35 s 更快），线圈上两颗火花绕杆转、越转越快；钩尖星芒 1 档 → 0.5 s 起 1 / 2 档逐帧闪 → 0.9 s 起 2 档；钩尖螺旋汇聚；轮廓光 1 → 2 档；0.9 s 起口中发光，最后 0.3 s 尾巴跟着电流抽动。
  - 施放 0.5 s：进入时避雷杆放出小冲击环 + 26 颗酸绿外爆 + 十字星芒（臂长 6）+ 蓄力粒子外爆，震屏 2 格 0.28 s、天空闪白 0.05 s；钩尖 3 档、轮廓光 3 档。随后 6 帧动作「吐 · 定 · 缩 · 吐 · 缩 · 吐（最大）」，在 0.05 / 0.25 / 0.42 s 连吐三颗电火球（间隔 0.2 → 0.17 s），弹速 150 → 190 → 240，所以到达间隔越来越短（约 0.14 → 0.09 s）；第三颗最大（3 × 3 白芯、8 格拖尾）。
  - 命中：每颗一个十字星芒 + 一道锯齿短弧斜穿假人 + 外爆，假人每次闪白（各一次 `impact`，越来越重）；第三颗十字臂长 7、大冲击环、震屏 1 格，`dummyFx outline` 酸绿描边 1.3 s + 摇晃变慢（麻痹抽搐）。
  - 收招 0.7 s：前 0.15 s 尾巴还插着，0.15–0.3 s 拔出地面往上一甩；钩尖 2 → 1 → 0、轮廓光 2 → 1 → 0；避雷杆钩尖余火花噼啪两下（两道小折线）+ 余烬。
- **移动**：每次落爪 1 颗尘（dust），无元素拖尾（普通品质、轻）。
- **受击**：白色剪影 1 帧 + 击退 2 格 + 闭眼、抬头、尾巴反向甩、吐出信子；impact 10 颗 + 骨灰（dust）7 颗 + 漏电火花 4 颗（僵尸肉）；震屏 1 格。
- **死亡**：impact 16 + 骨灰 12 + 漏电火花 + 震屏 2 格 + 闪白 → 0.3 s 塌下 → 0.5 s 侧翻成肚皮朝上、四腿僵直朝天（离地 3 → 1 → 0）→ 0.45 s 避雷杆折断往身后甩出 20 格、0.75 s 落地（金属磕地一声）→ 0.66 s 落地尘 14 颗 + 震屏 1 格；翻倒后信子耷拉出来，尾巴抽搐；0.8 / 1.02 / 1.22 s 电火花在朝天的腿间跳三次（一次比一次短）；钩尖闪 3 下熄灭；1.6–2.4 s 自上而下消散，魂光用酸绿（尸电色阶）上升。
