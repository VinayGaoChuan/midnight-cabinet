## 角色设定卡

- **名称 / 身份**：蓝龙，「长成龙的那只鹰」——飞鹰升级后的僵尸法师。修长、羽质、轻盈的蓝羽龙，一直悬在半空，胸口肋窗里装着一颗风暴核心。
- **一句话剪影**：细长的蓝羽龙身悬在离地 6 格处，一对破口的蓝羽翼，后面拖着一条 S 形长尾、尾尖张开一把扇形尾羽，钩喙龙头上顶着后掠羽冠。
- **识别特征（5 个，3 个改变外轮廓）**
  1. 【轮廓】钩喙龙吻：龙头，吻尖 2.5 格换成骨白鹰式钩喙，吻尖往下勾 1 格；头顶还是那 3 根后掠羽冠（长成 6 / 5.5 / 4 格的蓝羽冠），冠尖是静电色，待机个性和蓄力时噼啪冒电火花。
  2. 【轮廓】一对蓝色羽翼（不是膜翼）：覆羽浅 `[0, 40, 41, 23]`、飞羽深 `[0, 39, 40, 41]`，5 根初级飞羽仍缺第 2、3 根、露出白色翼指骨，缺口之间跳电弧。
  3. 【轮廓】细长 S 形尾（16 格，波相逐帧往尾尖传），尾端张开 3 片鹰式扇形尾羽。
  4. 胸侧肋窗变大：尸绿烂肉里 4 根斜向前下的白肋骨，肋骨缝里透出风暴核心（法师的发光体，常亮，轮廓光 1 档）。
  5. 后爪是骨黄鹰爪（羽毛大腿 + 沙黄跗骨 + 3 根骨白钩爪），跗骨上套着当年钱袋的铜扣环；前腿蜷在胸下。
- **体型档**：修长蛇形 + 悬浮：躯干胸臀距 11、胸半径 3.5、臀半径 3、颈 6（细、几乎竖直）、尾 16 + 扇羽 5；腹底离地 6 格；翼展约 36 格（单翼 18）。待机包围盒 49 × 31。整条龙往后挪 9 格，站位 HX 76 时吻尖离假人约 6 格。
- **材质色阶**（`[勾线, 暗, 基, 亮]`）
  - 蓝羽鳞（头颈背、尾、覆羽）：`[0, 40, 41, 23]`，躯干 band 2（勾线用墨色，夜空里剪影才读得出来）
  - 深色飞羽：blue `[0, 39, 40, 41]`；远翼暗一级
  - 腹鳞：blue `[0, 39, 40, 41]`（暗一级，隔点鳞纹）
  - 羽冠：`[0, 41, 23, 22]`，冠尖静电 `[22, 22, 22, 21]`（平涂发光）
  - 钩喙 / 钩爪 / 肋骨 / 翼指骨：bone `[8, 7, 6, 17]`；跗骨：sand `[20, 61, 62, 5]`（远侧 `[20, 61, 61, 62]`）；铜扣环：gold `[20, 19, 14, 5]`
  - 风暴核心：`[40, 23, 22, 21]`（平涂，按档位手工 tone）；眼：`[0, 0, 22, 21]`（青色发光）
  - 肋窗烂肉：尸绿灰 `[#1c2414, #4a5a36, #7a8f5c, #a3b682]`（僵尸族共用，专属色 4 个）
- **部件顺序**（从后往前）：远侧鹰爪后腿 → 远侧前腿 → 远翼 → S 形扇尾 → 躯干 + 颈（+ 腹鳞、肋窗核心）→ 近侧鹰爪后腿 → 近侧前腿 → 近翼 → 羽冠 → 头（+ 钩喙）。
- **细节清单**：脸（青色发光眼 + 眉亮点、鼻孔、钩喙亮上缘 + 下钩、张嘴牙）；羽（覆羽 / 飞羽两色、飞羽亮尖、4 道飞羽分隔线、前缘亮线、翼指骨、扇形尾羽亮尖、尾背亮点）；躯干（背上羽纹、腹鳞隔点、肋窗 4 根肋骨 + 核心 5 档）；腿（羽毛大腿、跗骨、铜环、3 根钩爪，耙抓时张开）；羽冠（3 根、冠尖静电色、受击 / 移动时甩）。
- **攻击方式**：近战「俯冲爪击」：拔高 2 格、后仰、双翼高举（预兆）→ 前冲 11 格、前倾下压到离地 1 格、双翼收拢俯冲，鹰爪前伸耙抓（出手定格）→ 下扑延续 → 回位；3 道平行爪痕拖影。站位 HX 76。
- **待机个性**：悬停慢扑翼（每 0.4 s 换一个翼姿），尾巴 S 形慢慢波动；第 1.6–2.0 秒尾巴卷起再展开、羽冠左右抖着冒静电、抬头又低头张望。
- **步态**：蛇形滑翔：不落地，身体俯仰和头反向错一拍，尾巴 S 形波往尾尖传（每步态帧前移 2 相位）；翼姿 `[张开, 张开, 上扬, 下压]`，一个周期只扑一次翅；身下拖 1–2 颗青色电火花，地面影子；羽冠偶尔冒静电。
- **死亡方式**：爆裂：受击（闪白、击退）→ 风暴核心过载，失去升力往下沉、翅膀垂落，肋窗核心逐帧在白 / 暗之间闪（至少 3 次白）、轮廓光 3 / 0 档跟着闪 → 0.6 s `death.start('burst')` 从核心位置炸开，碎块连同蓝羽四散，电火花随碎块落地熄灭 → 碎块 1.2 s 后抖动消散，青色魂光上升。
- **音色**：雷声般的噼啪爆裂 + 带鹰啸尾音的高亢龙吟，标志性的一声是锁链闪电的五连「啪-啪-啪-啪-啪」逐次变远变小；重量 0.7。`SFX { body: 'beast', how: 'explode', pal: 'bolt', style: 'bolt', w: 0.7, hover: 1 }`；出手 swing claw w 0.6、命中 hit flesh w 0.6、技能 impact bolt × 5（w 0.8 → 0.66 → 0.52 → 0.38 → 0.24）、核心爆裂 impact bolt w 0.6。

### 差异化

- **对同批的赤龙 / 黑龙**：它们是厚重膜翼龙（赤龙走在地上、黑龙巨型悬停），蓝龙是纤细的羽翼龙：羽翼两色 + 缺羽翼指骨、钩喙、羽冠、扇尾、鹰爪后腿，外轮廓完全不同；攻击是俯冲爪击（赤龙咬、黑龙甩尾）；死亡是核心过载爆裂；主色蓝羽鳞，元素是经典青蓝闪电，和蜥蜴线的酸绿尸电拉开。
- **对已通过角色**：`compare.mjs` 退出码 0，最接近汗血马（待机 IoU 0.34、施放 IoU 0.37、配色 0.52）。
- **对飞鹰（同一条升级线）**：3 根后掠羽冠、缺第 2、3 根飞羽露翼指骨的两色破羽翼、斜向前下的白肋骨肋窗都保留并放大；钱袋的铜扣变成爪腕的铜环；加了龙身、长尾、扇尾、风暴核心和雷电特效层次。

## 特效设定卡

- **元素色阶**：雷电 `FXI.bolt` = 21 白 → 51 淡金 → 22 青 → 23 蓝 → 40 深蓝；雷云用 41 / 40 / 39 三级深蓝，闪的时候透出 22 / 21；蓝羽碎屑 `blueFeather` = 21 → 41 → 23 → 40 → 39；魂光 soul。
- **攻击「俯冲爪击」**
  - 预兆（0–0.12 s）：拔高 2 格、后仰、双翼高举、爪垂下、羽冠后甩。
  - 出手（第 2 帧定格）：前冲 11 格、下压 3 格、双翼收拢、鹰爪前伸张开；假人前方 3 道平行斜向爪痕（第 1 帧白 + 青，第 2 帧蓝、断续）。
  - 命中：假人闪白大摇、震屏 1 格；impact 14 颗 + 电火花 6 颗。
- **技能「闪电打击 · 闪电锁链」**
  - 蓄力 1.4 s：0–0.7 s 缓入盘身上升 3 格、尾巴卷起、抬头；头顶聚起一团深蓝雷云（7 团叠圆，0.9 s 长到最大，隔几帧内部闪青白）；0.35 s 起云里细闪电逐次接到羽冠尖；火花从雷云螺旋汇聚进口中；翼缺口跳电弧、羽冠冒静电；肋窗核心 1 档 → 0.45 s 后 1 / 2 档逐帧闪；轮廓光 2 档，最后 0.3 s 3 档（围着核心）；地面隔点映光。
  - 施放 0.5 s：第 1 帧仰头（口前小星芒预兆），第 2 帧起猛地前探张嘴、双翼张开；口前十字星芒臂长 6 + 大冲击环 + 16 颗火花，粗闪电（核心白 + 两侧辉光 + 分叉，宽 3）从嘴直劈假人；进入时震屏 2 格 0.28 s、天空闪白 0.05 s。
  - 命中：假人闪白大摇 + 青色描边 + 头顶转星（1.1 s），落点十字 + 冲击环 + 20 颗火花；之后每 0.07 s 闪电从上一个落点跳向下一个隐形目标（后方低处 → 上方 → 更远处 → 最远的地面），一段比一段细（宽 2 → 2 → 1 → 1）、一段比一段暗，每个落点十字（臂长递减）+ 小冲击环 + 8 颗火花，共 5 次 impact，0.36 s 内跳完。
  - 收招 0.7 s：雷云 0.4 s 内缩小散成火花往下落；嘴里余烬飘出；羽冠平复；核心 2 → 1 → 0，轮廓光 2 → 1。
- **移动**：不落地；每个步态帧身下 2 颗青色电火花拖尾；地面影子。
- **受击**：白色剪影 1 帧 + 击退 2 格、闭眼、尾巴反卷、羽冠甩、核心闪；impact 16 颗 + 蓝羽碎屑 8 颗；震屏 1 格。
- **死亡**：26 颗 impact + 震屏 2 格 + 闪白 → 下沉、翅膀垂落、核心白 / 暗逐帧闪 → 爆裂（死亡套件 burst，冲击点在核心）+ 大冲击环 + 30 颗火花 + 天空闪白 + 震屏 2 格；14 颗电火花带重力落地熄灭，10 片蓝羽慢慢飘落 → 碎块抖动消散，1.6–2.4 s 青色魂光上升。
