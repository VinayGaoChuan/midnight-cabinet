# 惩戒牧师 PunishingCleric

模块：`pcd/chars/PunishingCleric.js`。身体用部件库拼：`rig（standard，stride 2）legs（shoe）torso（robe）arm（bell）hand head book lantern`；库里没有的写在模块里并标「候选部件」：`sunHalo`（头后日轮光环，12 根芒 = 法力条，可裂成左右两半）、`censerChain`（提香炉的铜链 + 按链角 90° 翻转的香炉）、`stoles`（并进长袍部件的两条金圣带）、`tonsure`（并进脸部件的剃顶：秃顶 + 发圈 + 后脑短发）。

## 特效设定卡

- 元素：日耀，`fxRamp('solar', [21, 51, 47, 14, 61])` = 白 21 → 淡金 51 → 日黄 47 → 金 14 → 暗金 61。比通用 holy（21 51 5 14 61）多一级饱和日黄；和 impact（21 5 14 19 20）有 3 级不同。
- 攻击「粒子波」
  - 预兆：香炉往后一荡（1 帧），炉里余烬亮一档。
  - 出手：往前甩出半圈、炉口朝前定格 1 帧；炉口十字枪口光 2 帧；香炉余烬 3 档；轮廓光 2 档。
  - 弹道：一条正弦波形的金色粒子流（振幅 3、波长 13，1 格宽；波头白、往后淡金 → 日黄 → 金、尾巴断续），170 格/秒，地面隔点映光。
  - 命中：8 颗日耀外爆，假人闪白小摇；假人头顶亮起一颗小日点（十字 5 格，叠层最多 3 颗，1.6 s 后闪烁熄灭）。
- 技能「太阳耀斑」+「粒子波」叠层（被动特性生效的样子：法力蓄满 → 攻速翻倍 → 连续打同一个目标越打越痛）
  - 蓄力 1.4 s：前手伸到身前侧，把香炉抡成竖直整圈（开始约 0.9 s 一圈，越转越快，最后 0.35 s 一圈），身后留一道金色圆形拖影；光环 12 根芒从暗金逐根点亮（从后下方经头顶到前方，1.3 s 全亮 = 每秒回 8% 法力）；金色光点从脚下螺旋上升、汇聚并环绕光环中心；香炉余烬 0.45 s 后 1 / 2 档逐帧闪；轮廓光从头后照出（1 → 2 档）；地面隔点映光。
  - 施放 0.5 s：太阳耀斑——香炉高举，光环向外爆出一圈放射日冕（12 道芒各伸长 6 格，第 1 级白 2 帧）+ 冲击环 + 28 颗外爆 + 十字星芒（臂长 6），环绕的光点一起外爆；震屏 2 格、天空闪白；光环 12 根芒变白。随即两倍速连甩：后荡 1 帧 → 前甩 1 帧，施放第 2 帧、第 4 帧、收招第 0 帧各射出一道粒子波，一道比一道粗（1 → 2 → 3 格宽、波头依次加大）。
  - 命中：三波依次打中，假人头顶的日点 1 → 2 → 3 颗；每波外爆 8 → 14 → 22 颗，第三波假人闪白 + 大摇 + 击退 1 格 + 冲击环 + 十字星芒，震屏 1 格；每波一次 `impact`。
  - 收招 0.7 s：香炉减速回到小幅晃荡；光环的芒逐根回暗（白 → 淡金 → 日黄 → 平时的金），轮廓光 2 → 1；余烟从香炉上飘。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼、香炉往后甩、袍摆反摆；16 颗 impact 火花；震屏 1 格。
- 死亡：26 颗 impact + 震屏 2 格 + 天空闪白 → 踉跄 → 双膝跪下、双手合十，香炉从手里滑脱落在身前 → 侧身仰倒（离地 3 → 1 → 0 两帧下落）→ 落地尘土 16 颗 + 震屏 1 格；香炉在地上滚一整圈（4 个朝向）停住，冒出最后一缕烟；日轮光环从中间裂成两半落在头边，芒逐根熄灭 → 静止 → 1.6–2.4 s 自上而下消散 + 魂光上升。
