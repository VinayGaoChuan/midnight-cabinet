# 奴隶主 SlaveLord

模块：`pcd/chars/SlaveLord.js`（身体全部用部件库拼：`rig legs torso mantle arm hand head hair helm axe` + 本批补进部件库的 `targe braids horns chain`）。
升级线：维京战士 → 奴隶主，是**同一个人**：保留角盔、姜红编辫胡、靛蓝（成了板甲下的罩袍和裤子）、红白四分圆盾（加大、镶金边、背到背上）、斧（换成双手月牙大斧）；新添闭面桶盔 + 一对大牛角、灰狼皮披肩、尖刺肩甲、板甲、前臂缠着一截带镣铐的锁链（奴隶主的身份）。

## 角色设定卡

- 名称 / 身份：奴隶主，重装近战战士（优质：比维京战士多金饰、毛皮、更大的角和盾）。
- 一句话剪影：**闭面桶盔上一对外张大牛角 + 身前竖着的双手月牙大斧 + 背上的大圆盾**；前臂垂着锁链和镣铐。剪影读成「扛大斧的重装战士」（输出靠斧、简单防御靠背盾）。
- 尺寸：待机 28×34 格（身体到盔顶 29 格，角尖 33 格）；体型 `heroic`，覆盖 `leg 10 · torso 9 · sw 6 · head 7 · limb 1.35 · lw 4`——比维京战士高 2 格、肩宽 12 格、四肢更粗，头保持同样大小（同一个人）。
- 材质色阶（全部取自 64 色共享色板，没有新增颜色）：
  - 板甲 `steel` [27, 28, 29, 30] · 罩袍 / 裤 靛蓝 `blue` [0, 39, 40, 41] · 灰狼皮 [8, 10, 18, 17]（band 2）· 金饰 `gold` [20, 19, 14, 5] · 腰带 / 护腕 `leather` · 铁靴 / 盔 `iron` [0, 27, 28, 29]
  - 肤 `skin` [11, 16, 15, 15]，狂怒时涨红 [11, 16, 58, 15] · 姜红胡 / 发 [20, 44, 45, 46] · 角 `bone` [8, 7, 6, 17]
  - 大斧：斧头 `steel` + 金箍 + 木柄 `wood`；斧面一格怒纹（flat 发光）[55, 56, 57, 47]，同一色阶也是狂怒时眼缝的红光
  - 背盾：`crimson` + `bone` 四分漆、`gold` 边框、`iron` 盾心；锁链 `steel` + 镣铐 `iron`
- 部件顺序（从后往前）：背盾 → 后臂（板甲袖 + 尖刺肩甲，握斧的手晚画）→ 腿（胫甲）→ 躯干（板甲 + 靛蓝罩袍 + 金菱形胸徽）→ 灰狼皮披肩 → 头发（盔下，头盔滚掉时露出来）→ 头（脸）→ 闭面桶盔 → 大牛角 → 月牙大斧 → 后手（压在斧柄上，3×3 大拳）→ 前臂（板甲袖 + 尖刺肩甲 + 金边 + 皮护腕 + 大拳）→ 锁链（缠前臂 + 垂下 4 节 + 张开的镣铐）→ 编辫胡（垂在最前面）。
- 细节清单：
  - 脸：闭面桶盔的眼缝（平时是暗缝，狂怒时一格红光 + 两道横向光芒）、T 形面饰、盔箍金边；头盔滚掉后露出脸（眼、大鼻、颊上一道浅疤、下颌阴影）和姜红短发。
  - 胡：从盔下伸出的八字胡 + 下巴胡 + 两条 7 格长辫（金辫环 2 个，辫梢会摆）。
  - 头饰：桶盔 + 外张上翘的大牛角（根部金箍、远侧角暗一级）。
  - 服装：板甲（中脊、胸腹分界、腿甲裙分段 + 铆钉、护颈）、靛蓝罩袍布条、金菱形胸徽、皮腰带 + 金扣、灰狼皮披肩（毛尖逐格亮暗）、胫甲（膝甲外凸）、铁靴。
  - 手臂：板甲袖 + 肘甲高光、尖刺肩甲（前肩金边）、皮护腕、3×3 大拳；前臂斜缠锁链（亮暗交替的链点）+ 垂下的链节 + 张开的镣铐，走路和攻击时会甩。
  - 武器：月牙大斧（木柄 12 + 6 格、金箍、6×7 月牙斧头、刃口亮色、斧面一格怒纹，死亡时熄灭）；背盾（半径 6：金边框 8 颗铆钉、竖木板缝、红白四分、铁盾心）。
- 攻击方式：近战 **双手大斧过顶斜劈**：大斧抡到脑后（预兆）→ 前冲 3 格、斧刃从头顶劈到假人身上（出手定格）→ 斧刃压低收回。
- 差异化（对照已通过：守夜人 / 寡妇 / 修女 / 屠夫领主 / 钟表匠 / 火葬人 / 蛮兽 / 邪眼王 / 星辉巫师）：
  - 体型档：英武宽肩重甲（屠夫领主是 32 格桶形大肚、头小；火葬人矮壮短腿；本角色是宽肩直身、腿长、头盔 + 大角把高度拉到 33 格）。
  - 识别特征（≥ 2 个改外轮廓）：①桶盔上外张的一对大牛角（轮廓）②身前竖着的月牙大斧，斧头高过肩（轮廓）③背上 13 格大圆盾（轮廓）④姜红编辫胡 + 前臂锁链镣铐。屠夫领主的链钩是武器、挂在手上甩出去；本角色的锁链只是缠在前臂上的身份物件，技能里被自己挣断。
  - 武器 + 握法 + 攻击类型：**双手** + 劈（屠夫领主是单手剁骨刀劈、火葬人双手扫、蛮兽单手砸、守夜人刺）。
  - 动作个性：待机 = 扭脖子、甩手上的锁链（斧面怒纹闪一下）；步态 = 重步（接触帧下沉、每步 4 颗尘、锁链大幅甩）；死亡 = 拄斧跪下 → 仰面倒下，角盔滚到脑后、盾甩到脚边、眼里的红光闪几下熄灭。
  - 主色：钢灰板甲 + 靛蓝罩袍 / 裤 + 灰狼皮 + 姜红胡（和火葬人的炭灰厚袍、屠夫领主的肉粉 + 褐皮都拉开）。

## 特效设定卡

- 元素：狂怒，色阶 `fxRamp('rage')` = 白 21 → 怒黄 47 → 血红 57 → 暗红 56 → 墨红 55（只用共享色板里已有的颜色）。和 fire（橙 → 棕红）、blood（粉 → 深红）都至少 2 级不同。
- 攻击「过顶斜劈」
  - 预兆：大斧抡到脑后、身体后仰（2 帧缓出），辫子前甩。
  - 出手：定格 1 帧，前冲 3 格；身后留一个抡斧姿的单色残影（冷灰，0.2 s 抖动消散）；从脑后到假人身上的一道大斩击弧（impact 色阶，半径 15）。
  - 命中：12 颗 impact 外爆 + 十字星芒，假人闪白小摇。
- 技能「无拘之怒」（被动特性生效的样子：残血时攻速翻倍）
  - 蓄力 1.4 s：压低身子、斧头拖在地上；红点从四周吸进胸口（定点汇聚），身上冒起越来越密的怒焰（上飘的余烬）；0.45 s 脸涨红、盔缝眼光 1 / 2 档逐帧闪（蓄满时拉出两道横向光芒）；0.7 s 后浑身发抖（左右 1 格、锁链乱甩）；轮廓光 1 档（整圈血红描边）、地面映光。
  - 施放 0.5 s：怒吼——挺胸抬头、大斧高举（2 帧）；**前臂上的锁链崩断**，12 个铁环飞散；30 颗狂怒火花外爆 + 冲击环 + 眼缝十字光；震屏 2 格、天空闪白；轮廓光 2 档（黄到红的整圈怒光）。随后以两倍攻速连劈：施放 3/12 s 过顶劈、5/12 s 横扫、收招 2/12 s 再一记过顶劈——每斧都是 1 帧回抡 + 1 帧劈下，身后留一个暗红残影，狂怒色斩击弧（3 格宽 → 断续）+ 14 / 26 颗火花 + 十字星芒，第三斧假人大摇 + 震屏 1 格；每一斧一次 `impact`。
  - 收招：从最后一劈缓回待机，前冲距离收回；眼光 2 → 1 → 0，怒焰变稀，脸色退回（锁链在收招里保持断开）。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 辫子和锁链反甩；16 颗 impact 火花；震屏 1 格。
- 死亡：26 颗 impact + 震屏 2 格 + 天空闪白 → 踉跄 → 拄着大斧单膝跪下（眼缝红光闪）→ 仰面倒下（离地 3 → 1 → 0 两帧下落）→ 落地扬尘 18 颗 + 震屏 1 格，角盔滚到脑后、背盾甩到脚边、大斧横在身旁 → 露出的眼睛里红光闪几下熄灭 → 静止 → 1.6–2.4 s 自上而下消散 + 魂光上升。
- 音色：铁甲和锁链的哗啦声；标志性的一声 = 怒吼后锁链崩断的「铮」+ 三下越来越快的劈砍；重量 0.9（`SFX: body armor · how topple · pal blood · style buff · w 0.9`）。
