# 维京战士 VikingWarrior

模块：`pcd/chars/VikingWarrior.js`（身体全部用部件库拼：`rig legs torso arm hand head helm axe` + 本批补进部件库的 `targe braids`）。
升级线：→ `SlaveLord.js`（奴隶主）。两级共用识别特征：**角盔、姜红编辫胡、靛蓝衣、红白四分圆盾、斧**；升级后体量、装备、特效都加一级。

## 角色设定卡

- 名称 / 身份：维京战士，廉价的前排先锋步兵（普通品质，细节克制：没有金饰、没有披风）。
- 一句话剪影：**小角铁盔 + 前手红白四分大圆木盾挡在身前 + 肩扛胡子斧（斧头从脑后横着伸出）**。剪影一眼读成「持盾防御的兵」。
- 尺寸：待机 25×31 格（身体到盔顶 27 格，角尖 31 格）；体型 `standard`，覆盖 `sw 5`（肩宽 10 格）、`head 7`、`limb 1.15`——标准偏宽，头略大给胡子和脸留位置。
- 材质色阶（[勾线, 暗, 基, 亮]，全部取自 64 色共享色板，没有新增颜色）：
  - 短衣 靛蓝 `blue` [0, 39, 40, 41]（band 2）· 下摆织边 / 扣 `gold` [20, 19, 14, 5] · 腰带 / 护腕 / 靴 `leather` [20, 19, 32, 33] · 裤 `stone` [0, 8, 9, 10]
  - 肤 `skin` [11, 16, 15, 15] · 姜红胡 [20, 44, 45, 46] · 辫环 `steel` [27, 28, 29, 30]
  - 盔 `iron` [0, 27, 28, 29] · 角 `bone` [8, 7, 6, 17] · 斧柄 `wood` [0, 20, 19, 16] · 斧头 `steel`
  - 盾漆 `crimson` [11, 12, 13, 26] + `bone` [8, 7, 6, 17] · 盾边 `iron` · 盾心 `steel` · 石肤符文（flat）[28, 59, 31, 21]
  - 化石后：皮肤 `pale` [8, 59, 60, 17] · 布 [0, 8, 59, 60]
- 部件顺序（从后往前）：后臂（远侧袖 + 护腕）→ 腿 → 躯干（短衣）→ 头（脸）→ 角铁盔 → 胡子斧 → 后手（握柄，压在柄上）→ 前臂（盾臂）→ 编辫胡（垂在盾臂前面，身份特征不让手臂挡住）→ 大圆盾。
- 细节清单：
  - 脸：眼（1 格墨）、护鼻条挡住鼻梁、两行肤色脸颊；盔檐下一行阴影。
  - 胡：八字胡（前梢下垂 1 格）+ 下巴一团 + 两条辫子（逐行亮暗交错的辫纹、每 3 行一个钢辫环、辫梢会摆，后面那条暗一级）。
  - 头饰：半球铁盔（盔顶脊亮点、盔箍一行、护鼻条）+ 两只外弯骨角。
  - 服装：靛蓝短衣（前沿缝线、胸前系带、背光侧 2 格暗边）、金色下摆织边、皮腰带 + 金扣、灰裤、高皮靴（翻口、近侧脚尖多 1 格）。
  - 手臂：宽袖 + 皮护腕 + 2×2 手。
  - 武器：胡子斧（木柄斜过上背、铁箍、斧头刃口亮色、刃朝后）；大圆盾（半径 5：铁边框 8 颗铆钉、竖木板缝、红白四分漆、3×3 铁盾心、盾心嵌一格石肤符文，5 档亮度，死亡时熄灭）。
- 攻击方式：近战 **盾击（冲撞）**：盾收回、身体后缩 → 前冲 5 格把盾撞出去（盾沿正好碰到假人）。斧一直扛在肩上。
- 差异化（对照已通过：守夜人 / 寡妇 / 修女 / 屠夫领主 / 钟表匠 / 火葬人 / 蛮兽 / 邪眼王 / 星辉巫师）：
  - 体型档：标准偏宽 + 大头（守夜人也是标准档，但它是挺直细长 6 头身 + 宽檐帽，本角色 4 头身、肩宽、头顶是两只外弯角）。
  - 识别特征（≥ 2 个改外轮廓）：①前手 11 格大圆盾挡住半个身子（轮廓）②盔上两只外弯骨角（轮廓）③肩扛胡子斧、斧头从脑后横伸（轮廓）④姜红编辫胡。守夜人的盾在远侧手、是塔盾 + 灯；本角色是近侧手圆盾、没有发光灯。
  - 武器 + 握法 + 攻击类型：单手持盾 + **冲撞（盾击）**——已通过的角色里没有冲撞类攻击（守夜人刺、屠夫劈、火葬人扫、蛮兽砸）。
  - 动作个性：待机 = 把斧从肩上抡下来、斧柄在盾沿上敲两下（火星）；步态 = 行军（盾稳在胸前、斧随步点头，落脚 2 颗尘）；死亡 = 跪在盾后 → 化成石像 → 碎成一堆石块（没人用过）。
  - 主色：靛蓝短衣 + 红白盾 + 姜红胡（修女是低饱和鸽灰蓝，本角色是饱和靛蓝；和守夜人的橄榄绿、火葬人的炭灰都拉开）。
  - 特效：花岗灰蓝的石壳 / 化石，已通过角色里没有土石系元素。
  - 自动查重：`compare.mjs` 退出码 0。

## 特效设定卡

- 元素：石肤（花岗灰蓝），色阶 `fxRamp('granite')` = 白 21 → 冷白 31 → 灰蓝 60 → 石蓝 59 → 暗钢 28（只用共享色板里已有的颜色，没有新增）。和通用的 dust / steel 至少 2 级不同。
- 攻击「盾击」
  - 预兆：盾收回、身体后缩 1 格、辫子前甩（2 帧缓出）。
  - 出手：定格 1 帧，前冲 5 格；身后留一个后引姿的单色残影（灰蓝，0.25 s 抖动消散）；盾前一道冲击弧（impact 色阶，2 格宽 → 1 格断续）。
  - 命中：盾沿处 12 颗 impact 外爆 + 十字星芒 + 前脚往后扬 3 颗尘；假人闪白小摇。
- 技能「石肤术」（被动特性生效的样子：受到的伤害减少）
  - 蓄力 1.4 s：缩到盾后下蹲 2 格；地上的碎石从身体两侧、下方吸到胸口（定点汇聚，1.4 s 内越来越密）；盾心符文 1 档 → 0.45 s 后 1 / 2 档逐帧闪；0.5 s 脸和手先化成灰蓝石头、0.95 s 全身变成石像（每一下都是一声「咔」：碎石外爆 + 符文十字光），石像胸口有裂纹；轮廓光 2 档（从盾心照出来）、地面隔点映光。
  - 施放 0.5 s：盾砸进地里（下蹲 3 格、盾下沿插进地面）；**石壳**从两侧地面升起、0.17 s 在头顶合拢（半椭圆 16×29，石片 4 格一片、两层）；两道地裂、冲击环、26 颗石屑外爆 + 尘土；震屏 2 格、天空闪白。0.08 s 一发敌弹从右边飞来，0.2 s 撞碎在石壳上：石壳命中处闪白 2 帧、碎石溅开、只剩几点敌弹火星——这就是「受到的伤害减少」。
  - 收招 0.7 s：石壳崩落成碎石落地；石像一层层剥落（全身 → 只剩脸和手 → 恢复），剥落时碎石往下掉；符文 2 → 1 → 0。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼 + 辫子反甩；接着 2 帧「石肤一闪」（脸和手变成石头）；12 颗 impact + 8 颗碎石；震屏 1 格。
- 死亡：20 颗 impact + 10 颗碎石 + 震屏 2 格 + 天空闪白 → 踉跄下蹲 → 跪在盾后（盾插在地里挡在身前），斧从肩上滑落到身后 → 膝盖落地扬尘 14 颗 → 0.75–0.95 s 慢慢化成石像、符文闪几下熄灭（静止 0.64 s）→ 1.3 s 石像碎成小块落地成堆（死亡套件 `chunks`）→ 碎块抖动消散 + 魂光上升。
- 音色：石头和木盾的闷响；标志性的一声 = 盾沿撞上去的「咚」和化石时的「咔啦」；重量 0.7（`SFX: body stone · how shatter · pal earth · style shield · w 0.7`）。

## 第 1 轮修改记录

审核阻断问题 → 怎么改的（部件库 `pcd/lib/parts.js` 同一轮一起修，见 README「部件库」）：

1. **MOVE 接触 B 两只靴子重叠成一只**（步态第 2 帧 = 导出第 4–5 帧）：原因是 `parts.rig` 的步态 bug（step −1 时两脚往中间合拢）。库里改成接触 A 的镜像：`footFx = hipBx − stride`、`footBx = hipFx + stride`，两条腿也互换出腿的胯位（A 字形，不在胯下交叉）。现在接触 A / B 地面行都是两只靴、间距一样：A 靴在 x −8..−3 和 3..9，B 在 x −8..−2 和 3..8（远侧靴脚尖少 1 格）。模块没改。
2. **MOVE 经过帧（步态第 1 帧 = 导出第 2–3 帧）抬起的远侧脚被大圆盾盖住**：库里经过帧改成两只脚都回到各自胯下，远侧脚抬起时在近侧腿后面（不再往前错到近侧腿前面）。现在抬起的远侧靴在 x −4..0、y −4..−2，盾面最左只到 x 1，整只露出来；盾没挪。
3. **drawHero 取状态**：去掉模块里的 `curState` 闭包和 `poseAtS` 包装，改成 `poseAt` 开头写 `P.st = 状态`，`['st', 0, 8]` 编进 KEY2；死亡时「斧从肩上滑落」的分支读 `P.st === DEATH`。残影、死亡套件重画时状态不会再对不上。
4. 部件库改动带来的连带变化（都是审核要求的库修改）：
   - 角盔 `horned`：角改成 `parts.horns`（默认 crescent 月牙角、size 4），在盔帽之前画、根部压在盔下，形状和原来的外弯短角接近；护鼻条只画到眼睛那一行，鼻尖不再被压成勾线色。
