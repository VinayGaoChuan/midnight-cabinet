# 暗夜射手 NightArcher

模块：`pcd/chars/NightArcher.js`（身体用部件库拼：`rig legs torso arm hand hood head`；本模块自画、标了「候选部件」的：`repeater` 月牙重连弩（竖箭匣 + 侧摇柄 + 月牙弩臂）、`coatTails` 开衩长风衣的两片后摆、`hoodPeak` 加长的兜帽尖角、`thighQuiver` 腿侧矢筒；银面罩和脸画在同一个部件里）。
升级线：精英猎手 → 暗夜射手，**同一个人换了夜装**：保留尖角兜帽（加长、压暗成墨绿，尖端垂到肩胛）、绿色系、绿羽箭（腿侧矢筒里一排绿羽弩矢）、瘦长身形；长弓换成劲弩（月牙重连弩），加及小腿的开衩长风衣、银面罩、月华元素。猎手是前倾猫腰，射手站得笔直、冷静。

## 角色设定卡

- 名称 / 身份：暗夜射手，人类射手（擅长输出、很脆弱：没有盔甲，只有风衣和皮带）。传说品质：细节密度高（银扣、铆钉、面罩纹、交叉皮带、风衣双片下摆、弩身银饰）。
- 一句话剪影：**肩前横端的一只大月牙（重连弩的月牙弩臂）+ 弩身顶上竖插的方箭匣 + 垂到肩胛的尖兜帽 + 及小腿、向后飘成燕尾的长风衣**。纯黑剪影读成「端着大弩的高瘦射手」。
- 尺寸：待机约 32 格高（兜帽顶 31；验收 bbox 31×34 含勾线和月牙尖），体型 `slim` 拉长：覆盖 `leg 11 · torso 11 · neck 1 · head 6 / 5 · sw 3 · lw 2 · stride 5 · arm 10`。比精英猎手高 5 格，同样窄肩长腿，站得笔直（lean 0）。全批最高最瘦的射手。
- 材质色阶（全部取自 64 色共享色板，没有新增颜色）：
  - 兜帽 / 长风衣 墨绿 `moss` [0, 34, 35, 36]（风衣 band 2、兜帽 band 1）——就是精英猎手的林绿压暗一档
  - 皮带 / 手套 / 靴 `boot` [0, 20, 20, 19]；裤 `stone` [0, 8, 9, 10]
  - 银饰 / 面罩 / 弩臂月牙 / 扣 `steel` [27, 28, 29, 30]；弩身 `wood` [0, 20, 19, 16]；弦 [8, 18, 17, 21]（白弦配深勾线，读成细亮线）；箭杆 `bone`
  - 绿羽 [35, 37, 38, 21]；肤 `skin`（只露眼周）
  - 发光体（flat）：眼光、月牙尖、上弦弩矢的箭头 = 月白 [4, 60, 5, 21]（分配里的月白 5 / 21 是亮的两级，另加苍蓝灰 60 做暗档、夜靛 4 做熄灭档），按 5 档亮度（待机 / 蓄力 / 蓄满 / 施放 / 熄灭）换色
- 部件顺序（从后往前）：风衣两片后摆（远片暗一级）→ 后臂（窄袖 + 手套，握弩尾扳机）→ 腿（高筒靴，远侧暗一级）→ 长风衣前身（前襟、开衩、银扣、领、交叉皮带 + 银扣）→ 腿侧矢筒（筒 → 箭羽）→ 兜帽后层（+ 加长尖角，同一部件）→ 头（眼周皮肤 + 银面罩 + 月白眼光，同一部件）→ 兜帽前檐 → 月牙重连弩（弩身 → 月牙弩臂 + 弦 → 箭匣 → 摇柄 → 上弦的弩矢，各自一个部件）→ 前臂（窄袖 + 银袖扣 + 手套，托住前握把）。
- 细节清单：
  - 脸：银面罩遮住鼻子以下（面罩上一道暗纹 + 下沿一格高光），只露眼周一条皮肤和一双月白冷光的眼（受击闭眼时变成暗缝）；兜帽前檐压在眉上。
  - 头饰：墨绿兜帽，顶后方伸出 2 格后折下垂的长尖角，尖端垂到肩胛，走路和施放时被风吹平。
  - 服装：长风衣（前襟开口、银扣、立领、前后开衩、口袋盖）、两道交叉皮带 + 银扣；风衣后摆分两片（远片暗一级），走路、施放时向后飘成燕尾。
  - 手臂：墨绿窄袖、银袖扣、黑皮手套。
  - 腿脚：石灰裤 + 高筒黑靴（靴口翻边），远侧腿暗一级；近侧大腿外侧一只皮矢筒，插着 3 支绿羽弩矢。
  - 武器：月牙重连弩——深木弩身（导轨 + 下沿、枪托加厚抵在前肩、前握把在弩身下 2 格、扳机、两道银箍、银鼻），弩身比手高 2–3 行，前臂从下面托住，不压住弩身；银色月牙弩臂（上下各 6 格：背面外弧、正面内弧，中段 3 格厚往两端收尖，两只尖向前弯出 4–5 格，尖端 2 格是月白发光体）；白弦（上弦时从两尖拉回机括，发射那一帧弹直、把月牙口封成 D 形）；弩身顶上竖插一只 3×5 方箭匣（银包角、侧面露出三截弩矢、顶上一撮绿羽）；枪托上沿的侧摇柄（银转轴 + 曲柄 + 木握头，4 个角度，上弦时后手跟着握头转）；上弦弩矢躺在导轨上，月白箭头嵌在月牙口里。
- 攻击方式：远程（站位 34）。
- 差异化（对照已通过和同批分配）：
  - 体型档：瘦长 31 格、站得笔直（精英猎手 26 格前倾猫腰；星辉巫师是佝偻老者 + 及地长袍；奴隶主英武 33 格但宽肩重甲）。全批最高最瘦的射手。
  - 识别特征：①肩前横端的月牙重连弩，前方是一只大月牙（外轮廓）②弩身顶上竖插的方箭匣（外轮廓）③垂到肩胛的加长尖兜帽（外轮廓）④及小腿、向后飘成燕尾的开衩长风衣（外轮廓）⑤银面罩 + 月白眼光、腿侧绿羽矢筒。
  - 武器 + 握法 + 攻击类型：双手端弩、肩抵 + **连射**（4 连发）。和精英猎手的前手竖弓、钟表匠端铳单发齿轮都不一样。
  - 动作个性：待机 = 上弦（摇柄转两圈，棘轮咔嗒，箭匣下沉一格装填，眼光一闪、兜帽偏头看向目标）；步态 = 长步疾行（步幅 5，身体不起伏，风衣后摆向后扬、兜帽尖被风吹平，每个接触帧在身后 4 格留一个单色残影（苍蓝灰 → 夜靛）、0.15 s 抖动消散，落脚无尘）；死亡 = 融影（单膝跪下，连弩脱手落地、月牙尖闪两下熄灭，身体从脚往上按列塌成一滩深色影子，化成月白光点飘散，最后银面罩「叮」地掉在地上）。
  - 主色：墨绿长风衣（守夜人是墨橄榄斗篷 + 宽檐帽 + 灯盾，本角色更冷更绿，大面积是瘦长风衣）。
  - 特效：迅捷 · 月华色阶（奶白 → 苍蓝灰 → 夜靛 → 深夜蓝，最暗两级融进夜空），招牌是「残影分身 + 五连珠 + 全屏横向速度线」。
  - 自动查重：见自检记录。

## 特效设定卡

- 元素：迅捷 · 月华，色阶 `fxRamp('moonlight', [21, 5, 60, 4, 3])` = 白 → 月光奶白 → 苍蓝灰 → 夜靛 → 深夜蓝（全部是共享色板里已有的颜色）。最暗两级会融进夜空，正好是残影消失在夜色里；和维京的花岗灰蓝至少 3 级不同，也和马的法力蓝、巫师的奥术拉开。
- 攻击「四连射」（0.75 s）
  - 预兆 1 帧（1/12 s）：连弩举到眼前，摇柄一压（转到下方）、身体微沉 1 格、眼光亮 1 档。
  - 出手：第 2–5 帧（2/12–5/12 s）连射 4 矢，间隔 1 帧（约 0.08 s）；发射帧后坐 1 格、箭匣跳起 1 格、弩口一个月白十字枪口光，和下一帧交替（像机括连响）。
  - 弹道：月白弩矢（白 → 奶白箭头 + 骨白杆 + 绿羽），300 格/秒，月华拖尾。
  - 命中：4 下像鼓点依次落在假人身上（胸 → 头 → 胸 → 腹），每下 6 颗月华外爆 + 小十字，假人闪白小摇。
- 技能「超速射击」（每次攻击连打四下：快到出残影）
  - 蓄力 1.4 s：两脚前后分开扎稳步（前脚前 3 格、后脚后 3 格，膝微屈、身体下沉 1 格），侧身把连弩架到肩上、上身后仰 1 格、低头看摇柄（0.5 s 缓入）；后手握住摇柄的木握头跟着转；摇柄飞快转（4 帧一圈，越转越快：0.7 s 后每帧一个角度），箭匣连跳装满；月白光点从四周吸进上下两只月牙尖（两个定点汇聚）；眼光 1 → 2 档；0.75 s 拍下蓄力姿的快照，0.8 / 1.0 / 1.2 s 身后依次叠出 1 → 3 个残影（copySprite + blitShape，每层退后 3 格：最近一层苍蓝灰 = 第 3 级，后两层第 4 / 5 级，越远越融进夜空）；轮廓光 0.5 s 起 1 档、1.0 s 起 2 档（地面映光）。
  - 施放 0.5 s：扎稳步平端瞄准（攻击是直立端射；技能一直是分开的两条腿，残影剪影里也看得出腿）。进入施放时残影换成瞄准姿的快照。五连发（施放 0 / 2 / 4 帧 + 收招 0 / 2 帧），本体和残影交替开火：本体（第 1、3、5 发，后坐 1 格）和第 1、2 层残影（第 2、4 发，残影闪亮一档）；每发弩口一个月白十字枪口光，五道月白弩矢拖着长拖尾平射。全屏横向速度线：5 条横线从右往左扫过夜空，隔行白 / 月光奶白。进入施放时汇聚光点外爆、震屏 2 格、天空闪白。
  - 命中：五发依次钉在假人身上（头 → 胸 → 腹 → 胸 → 头，间隔 2 帧），每发一个小十字 + 6 颗月华外爆 + 一次 `impact`；第五发加大冲击环 + 一道月牙形斩痕（`fx.slash` 短弧）。假人连摇 5 下，最后一下大摇、击退 1 格，震屏 1 格。
  - 收招 0.7 s：残影从远到近逐个消散，连弩放下回到待机端姿，摇柄凭惯性再转半圈；眼光 2 → 1 → 0。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼；兜帽尖和风衣后摆反向甩；impact 16 颗；震屏 1 格。
- 死亡：26 颗 impact + 震屏 2 格 + 天空闪白 → 踉跄 → 单膝跪下，连弩脱手落在身前地上（月牙尖闪两下熄灭）→ 0.66 s 起身体从脚往上按列塌成一滩深色影子（死亡套件 `melt`：快照不含连弩和面罩，身体像素按明暗压成 苍蓝灰 60 / 墨绿 35 / 34 / 墨 0；地上的连弩单独烤成精灵照常画，和影子一起在 1.3 s 后抖动消散）→ 那滩影子化成月白光点往上飘散，魂光上升 → 银面罩从塌下去的头的位置掉到地上，「叮」地弹一下、闪一个小十字 → 静止 → 一起消散。
- 音色：长风衣的布料翻动 + 夜风；标志性的一声 = 摇柄棘轮越转越快的「嗒嗒嗒嗒」+ 五连发的机括「咔咔咔咔咔」，残影消散时一声轻「咻」；重量 0.45（`SFX: body flesh · how dissolve · pal shadow · style shadow · w 0.45`）。步态接触帧 `step`（w 0.25）、第一发 `swing`（bow）、每发 `shoot`（arrow）、每矢到达 `hit`（metal）、技能五处命中各一次 `impact`（shadow）。死亡方式是融影（dissolve），不发 `fall`。

## 自检记录

- 第 1 轮（结构）：连弩第一版弩身和前握把同一行，前臂横着压住整条弩身；上弦弩矢单独一个部件画在导轨上一行，把导轨整行压成勾线色；弦的勾线是浅暖灰，两根弦加勾线读成一个粗「>」，月牙弩臂只有 1 格细线，整只弩看成箭头形。改成：弩身抬到手上 2–3 行（前臂从下面托）、弩矢并进弩身部件、弦换深勾线材质并只拉到机括、月牙弩臂改成外弧 / 内弧之间填满的新月（中段厚、两端收尖）。
- 第 2 轮（细节）：月牙中段从 4 格减到 3 格（4 格读成斧刃）；走路残影原来和本体重合被挡住，改成留在身后 4 格；蓄力后段轮廓光升到 2 档，补上地面映光。
- 第 3 轮（确认 + 小修）：技能的蓄力 / 施放姿和待机、攻击几乎一样（都是直立端弩），三层残影叠在身后只读成一圈光边。技能改成扎稳步：蓄力 0.25 s 起两脚前后分开（技能专用体型 `stride 3`）、膝微屈下沉 1 格、连弩抬高 1 格；施放和收招前半保持扎稳步，收招 0.45 s 后收脚回待机。残影快照跟着换成分腿姿，剪影里看得出一排分身的腿。`compare.mjs --prev` 只标出施放 / 收招（IoU 0.874，消失的 40 格就是并拢的腿和原来高 1 格的上身，是有意改的），其余状态 IoU 1。
- 验收：`shoot.mjs` 退出码 0（`audit.json` 没有问题：待机 12 个不同帧、移动 4、攻击 8、蓄力 12、施放 4、收招 8、受击 6、死亡 8（死亡套件 melt，至少 3）；没有裁切、没有色板外颜色）。音效时间线：move.step 5、attack.swing 1 / shoot 4 / hit 4、skill.charge / release / shoot 5、skill.impact 5、hurt、death（dissolve，不发 fall）。
- 查重：`compare.mjs` 对范式 + `pcd/accepted`（24 个）退出码 0；最近的是巨魔（待机 IoU 0.595、施放 0.544、配色 0.165）、投石弓手（0.567 / 0.492 / 0.317）、星辉巫师（0.566 / 0.448 / 0.116）。和精英猎手（同一升级线）：0.486 / 0.372 / 0.69——剪影明显不同，配色相近是有意的（同一个人换夜装）。
