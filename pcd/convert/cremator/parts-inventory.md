# 焚尸人（cremator）部件清单

模块：`pcd/chars/cremator.js`。行号按当前模块。坐标以脚底为原点、面朝右、y 向上为负；材质写法 `[勾线, 暗, 基, 亮]`，27 起的下标是原版专属色（模块里经 `pc()` 换成本页下标）。
缓冲 72×48，脚底 (32, 42)；肩线 `yT = -17 + bob + crouch`，下摆 `hem = -5 + min(crouch, 3)`，面罩顶 `mT = yT - 7`（`drawStanding` L179）。
