# 守夜人 · 可复用部件清单

模块：`pcd/chars/watchman.js`（行号以此文件为准）。坐标以脚底为原点、面朝右；色板下标写原版下标（27 以后是本角色专属色，模块里用 `pc(原下标)` 取）。

专属色：27–30 斗篷墨橄榄绿 `#0e130b #1f2a16 #36472a #56693b` · 31–34 灯盾铁 `#15161c #2e3038 #4e525c #7c8290` · 35 暗铜 `#8a5a1e` · 36–39 琥珀灯火 `#fff2a0 #ffcf4a #c8701e #4a2410`。
材质定义在 L19–23；轮廓光不打：灯罩、白热芯、木杆、眼睛（L27）。

## 站姿的部件顺序（`drawStanding` L188）

斗篷后片 → 长戟（杆 → 戟头）→ 后臂 → 后手套 → 后腿 → 前腿 → 外套（躯干 + 交叉皮带 + 铜扣 + 腰带）→ 钥匙串 → 头 → 短披肩 → 帽 → 前臂 → 灯盾 → 笼灯 →（双手持盾时）两只手套。

特殊规则：
- 直刺（`thrust`：单手、戟角 > 0.8）时长戟 + 后臂改画在前臂之后、盾之前——戟从盾顶一侧刺出，盾仍压在最前（L199、L224）。
- 双手举盾过头（`over`：盾顶高于 −26）时，后臂先向后上折再绕到盾下沿，前臂肘向外绕开脸（两段 `limb`，L199、L223）。
- 跪地拄盾（`hmode 2`）时前手按在盾顶（L197、L226）。

## 身体 / 服装

**1. 刷子肢体** — `limb(x0, y0, x1, y1, r, m)` L119
- 画：两点之间用圆刷扫出的一段肢体（袖、裤腿、屈膝的腿）。
- 参数：起止点；`r` 刷子半径（1 = 3 格粗）；`m` 材质。
- 要点：采样数 = 长度 × 1.5，斜向也不断点；一段折线（肩→肘→手）用两次 `limb`、同一个 `part()`，关节处不出分界线。

**2. 皮手套** — `glove(x, y)` L120
- 画：2×2 手，左上角 1 格高光。
- 材质：皮 `[0, 20, 19, 16]`。
- 要点：握杆的手单独一个 `part()`，压在杆和袖子前面。

**3. 及膝斗篷后片** — `drawCloak(yS, cr, L)` L157
- 画：从肩后垂到膝的斗篷，下摆外张、后侧开衩、一道竖褶。
- 参数：`yS` 肩行；`cr` 下蹲（下摆行 = min(−1, −6 + cr)，蹲下时下摆跟着缩）；`L` 前倾（上段跟着平移）；读 `P.sway`（下摆左右摆，按 t² 加权）、`P.bend`（下摆被吹向后，0–3）。
- 材质：斗篷 `[27, 28, 29, 30]` band 2。
- 要点：最后 3 行在中缝挖空（`sp(x, y, 0)`）做开衩，最后一行下摆角再挖 1 格；竖褶用色调 2。画在最后面（第一个 `part()`）。

**4. 腿柱 + 靴** — `legCol(hx, hy, fx, up, kn)` L167、`drawLegs(yB, cr)` L172
- 画：3 格宽的腿，从胯逐行插值到脚，下 5 行变靴（翻口 1 格高光）+ 2 格靴尖。
- 参数：`hx/hy` 胯；`fx` 脚的 x；`up` 抬脚格数；`kn` 膝盖前弯量（按 sin 曲线）。`drawLegs`：`cr ≥ 4` 画单膝跪（后腿膝盖着地、小腿贴地向后；前腿大腿水平、小腿竖直）；否则按 `P.step` 让两脚前后分开 7 格（两个接触帧前后脚互换），`P.wup` 抬脚。
- 材质：裤 `[0, 20, 19, 19]`、靴 `[0, 8, 9, 10]`。
- 要点：后腿、前腿各一个 `part()`，后腿先画。

**5. 外套躯干 + 交叉皮带 + 腰带** — `drawStanding` 内 L201–206
- 画：躯干（下摆比肩宽 1 格）、胸前交叉的两道皮带 + 交叉处 2 格铜扣、腰带 + 铜带扣、下摆 1 格暗褶。
- 参数：`yS` 肩行、`yB` 腰行、`L` 前倾（逐行按 L×(1−t) 平移，肩随前倾、腰不动）。
- 材质：外套 `[27, 28, 28, 29]`（比斗篷暗一档，靠分界线分开）、皮、黄铜 `[20, 35, 14, 5]`。

**6. 铜钥匙串** — `drawStanding` 内 L207–209
- 画：腰侧 1 个环 + 两把钥匙（3 格、2 格斜线）。
- 参数：钥匙尖端随 `P.beard × 0.5` 摆（呼吸、步伐、受击反甩）。
- 材质：黄铜。要点：单独一个 `part()`，压在外套前。

**7. 帽檐阴影下的脸** — `drawStanding` 内 L210–217
- 画：5 行的脸，上 2 行强制色调 1（帽檐阴影）；两点反光的眼（近眼亮、远眼暗）、突出 1 格的鼻尖、髭、下巴胡茬、耳、脑后深发。
- 参数：`hx0` 头中心（= 前倾 + 转头）；`P.eyes` 0 常态 · 1 闭眼（不画眼）· 2 反光变白；`P.head` −1/1 时眼睛整体左右移 1 格（张望），`head < 0` 时不画鼻尖。
- 材质：肤 `[20, 16, 15, 15]`、发 / 髭 `[0, 20, 20, 19]`、眼睛 `[0, 6, 36, 21]`（flat，不吃轮廓光）。
- 要点：阴影不是另一个材质，是同一材质强制色调 1——和帽子之间不会多一条分界线。

**8. 短披肩** — `drawStanding` 内 L218–221
- 画：4 行领口到肩的短披肩，锯齿下摆（每 3 格一个暗齿，随 sway 移动）、铜领扣、两格暗褶。
- 参数：`L` 前倾；`P.bend ≥ 1/2` 时左下角多伸 1 格（被吹向后）；`P.sway` 移动锯齿相位。
- 材质：斗篷同色阶 band 1（和斗篷后片分开两个材质，保证边缘明暗不同）。

**9. 宽檐平顶帽** — `drawHat(cx, by, down)` L183
- 画：12 格平直帽檐 + 2 行平顶帽身 + 皮帽带（色调 2）+ 铜帽徽；`down = 1` 画倒扣版（帽檐在上，给滚落翻转用）。
- 参数：`cx` 头中心、`by` 帽檐行；站姿里 `by = fy − 1 − P.hatY`（受击震起 1 格）。
- 材质：黑毡 `[0, 8, 9, 10]`、皮、黄铜。

## 武器 / 道具

**10. 长戟** — `hp(u, v, m, t)` L123 + `drawHalberd(hx, hy, a)` L124
- 画：25 格木杆（手后 15、手前 10）+ 铁銎 + 后刺 + 两角朝外的小月牙刃 + 3 格宽的叶形矛尖（尖端高光）。
- 参数：`hx/hy` 握点；`a` 杆角（0 竖直向上，π/2 水平向前）。
- 材质：木 `[0, 20, 19, 16]`（不吃轮廓光）、铁 `[31, 32, 33, 34]`、刃钢 `[31, 33, 34, 17]`。
- 要点：戟头像素在杆的局部坐标 u（沿杆）/ v（垂直杆）里摆，整 90° 时无损；杆一个 `part()`、戟头一个 `part()`；`hp` 和 `line(..., maxY = 0)` 都不画进地面以下。倒地时用同一个函数、角度 −π/2 + 弹起档（L230）。

**11. 圆顶塔盾** — `drawShield(X, Y)` L134 + 行宽表 `SHR` L133
- 画：7×12 圆顶塔盾：暗铜镶边 + 铁面 + 3 颗铆钉 + 盾面 2 格冷光、2 格凹痕。
- 参数：`X/Y` 盾左上角。
- 材质：盾缘 `[20, 35, 35, 14]`（大面积暗铜，只在受光边出 14 金，免得像金盾）、铁、黄铜。
- 要点：每行 `[a, b]` 查表，首尾行和每行两端是镶边。

**12. 笼灯（发光体）** — `drawLantern(X, Y)` L148 + `LAMP_PX` L140 / `LAMP_LV` L141
- 画：嵌在盾心的 5×6 笼灯：灯帽、灯座、铜提环、两侧铁框、3×3 灯罩（十字亮芯 = 火苗，四角暗一档）。
- 参数：`P.gem` 5 档（0 微亮 · 1 蓄力 · 2 蓄满白热芯 · 3 施放整罩白热 · 4 熄灭）；`P.glint` 摇曳（火苗往后上方歪 1 格，只在 gem < 3）；`P.door` 灯门弹开（前框变成漏出的光 + 弹出的门板）。
- 材质：灯罩 `[39, 38, 37, 36]` flat、白热 `[36, 36, 21, 21]` flat（这两个是 GLOW_MATS）、铁、黄铜。
- 要点：发光档用「每格 [材质, 色调]」表驱动，换档不改形状；灯和铁笼同一个 `part()`，所以灯罩和铁框之间没有分界线。

**13. 倒下的灯盾** — `drawLyingShield()` L245
- 画：面朝上倒在地上的灯盾（整 90° 旋转：盾身 3 行厚、两端圆、铆钉），笼灯朝上立着、已熄。
- 要点：盾身、笼灯各一个 `part()`；熄灭的灯罩中心留 1 格色调 2。

**14. 倒地姿** — `drawLying()` L229、`drawLyingHat()` L250
- 画：侧歪仰倒（头在左）、屈膝；长戟倒在身后（`P.halB` 让戟头弹起 0–2 档）；斗篷铺在身下；外套 + 交叉皮带；摊开的钥匙；搭在胸前的手；仰面闭眼的头；帽子滚到一边（`hatX / hatY / hatR` 倒扣翻滚）。
- 部件顺序：长戟 → 斗篷 → 后腿 → 前腿 → 躯干 → 钥匙 → 短披肩 → 手 → 头 → 盾 → 帽。

## 特效图案

**15. 贴地扁椭圆光环** — `grRing(front, f12)` L312（`GR_LIFE`、`grRX` L259）
- 画：从砸地点向两侧扩散的贴地椭圆环，横半径 3 + 95t、纵半径 = 横半径 × 0.22。
- 参数：`front` 0 画后半弧（放 `fxBack`，在人物后面）、1 画前半弧（放 `fxFront`）；寿命 0.42 s。
- 颜色：元素色阶 0 → 1 → 2 → 3 按时间走；前 0.16 s 加 1 格厚度（色阶 2）；0.2 s 后每 4 点断 1 点。
- 要点：同一个环拆前后两半画，人物站在环中间。

**16. 头顶转星** — `stars(cx, cy, t)` L319
- 画：3 颗十字 5 像素小星绕 6×2 椭圆转（7 弧度 / 秒）。
- 颜色：芯色阶 0、四臂色阶 2。用在眩晕 / 定格的目标头顶。

**17. 辐射光芒线** — `fxFront` 内 L341–344（`RAY_R0` L311）
- 画：以发光体为中心的 6 条放射线，逐帧变长（`grow = min(9, 2 + 帧数 × 0.6)`，斜向 × 0.7），末 2 格隔帧断续。
- 参数：`RAY_R0` 每个方向的起点半径（0 = 不画）：避开盾本身和下方的脸。
- 颜色：离起点 < 30% 色阶 0/1（发光体蓄满时 0），< 65% 色阶 2，其余色阶 3。

**18. 灯位向上短光柱 + 下砸速度线** — `fxFront` 内 L346–350（`colT`）；施放前 2 帧的三向十字星芒在 L345
- 画：第 1 帧 3 格宽 25 格高全亮（芯白、两侧色阶 1）+ 盾上方 3 道隔行速度线；第 2 帧 1 格宽断续（色阶 2）。

**19. 水平直刺拖影** — `fxFront` 内 L352–355（`smT`）
- 画：第 1 帧 2 行（前端 4 格白、上行前端 6 格色阶 1），第 2 帧 1 行隔点（色阶 2 / 3）。
- 参数：`smX0 / smX1 / smY` 预备位矛尖 → 出手位矛尖。

**20. 横向探照光带** — `fxBack` 内 L323–326（场外「照夜」）
- 画：从角色处向右 240 格 / 秒扫过的光带（26 行高）：前沿 1 格白 + 2 格色阶 1，身后棋盘格 + Bayer 抖动（`B8 ≥ fade`）淡出，上下边色阶 2。

**21. 目标头顶小灯** — `fxMid` 内 L337
- 画：3×4 铁框小灯 + 每 2 帧闪一次的芯（色阶 0 / 1）+ 下方转星。给「被照住的敌人」做标记。

**22. 直线汇聚光点** — `rayIn(a, r, v)` L265、更新 L298、绘制 L356（池子 L263）
- 画：沿 8 个固定方向（其中一个方向不发）直线向发光体收拢的光点，越近越亮（年龄 = 0.9 × (r − 3) / (r0 − 3)，走元素色阶）。
- 要点：引擎没有这种粒子，模块自带小池子；施放时每颗交给引擎 `spawn(K_BURST, …)` 沿原方向外爆。

**23. 琥珀定格（假人）** — `syncDummy()` L288
- 画：目标被罩成元素单色剪影：第 1 帧整片色阶 1（`R_FILL`，L15），之后 `dummyFx({ tint })` 按原色亮度映射；不摇、不褪，到点直接解除（`dur: 1e-4`）。
- 缺：原版还外罩一圈色阶 3 的描边，引擎的假人没暴露剪影，暂时画不出（已提引擎请求）。
