# 屠宰场主（butcherlord）部件清单

模块：`pcd/chars/butcherlord.js`。行号按当前模块。坐标一律以脚底为原点、面朝右、y 向上为负；材质写法 `[勾线, 暗, 基, 亮]`，27 起的下标是原版专属色（模块里经 `pc()` 换成本页下标）。
缓冲 64×52，脚底 (31, 47)；肩线 `topY() = -22 + bob + crouch`，头参考 x `headX() = lean + head`（L58–59）。
