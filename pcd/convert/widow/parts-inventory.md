# 赌徒寡妇 · 可复用部件清单

模块：`pcd/chars/widow.js`（行号以此文件为准）。坐标以脚底为原点、面朝右；色板下标写原版下标（27 以后是本角色专属色，模块里用 `pc(原下标)` 取）。

专属色：27–30 丧服黑紫 `#08060c #17101f #2a1d3a #45335e` · 31–32 苍白肤 `#c49a92 #f2d8cc` · 33–36 桃红 `#34082a #8a1860 #f048a8 #ffd0ec`。
材质定义在 L17–22；轮廓光表 `SKIP_BASE / SKIP_ARM` 在 L27–29（见第 16 条）。

## 站姿的部件顺序（`drawStanding` L236）

后臂袖 → 白袖口 →（施放时）牌扇 + 左手 → 长裙 → 胸衣 → 金筹码腰链 →（平时）牌扇 + 左手 → 头（发髻 + 面纱脸）→ 黑羽 → 帽 → 烟嘴 → 烟头 → 前臂袖 → 白袖口 → 指间小牌 → 右手 → 红心 A + 指尖。

特殊规则：
- 牌扇手 x < 2（施放时甩到背后）时，牌扇和左手改画在裙子之前（身体后面），L240、L243。
- 羽毛在帽子之前画（插在帽带后端、被帽冠压住根部），和帽冠之间留 1 格空。

## 身体 / 服装

**1. 钟形裙边** — `skirtEdges(y, wy, sway, spread)` L141
- 画：钟形长裙每一行的左右边界（写进 `skL / skR`）。
- 参数：`y` 行、`wy` 腰行；`sway` 下摆左右摆（t² 加权）；`spread` 塌落时向两边摊开。
- 要点：右边 2 + 5.2·t^0.8（前摆外鼓）；左边 −2 − 5.8·t^0.95 − 裙撑高斯凸起 3.4·exp(−((t−0.2)/0.17)²)，t 在 0.05–0.36 再多凸 1 格——后腰裙撑的轮廓。

**2. 钟形长裙 + 蕾丝波浪下摆** — `drawStanding` 内 L244–258（波形表 `HEM_WAVE` L53）
- 画：腰到地的长裙；下摆波浪（待机最下 2 行、滑行最下 3 行，裙撑一侧后摆滞后 1 帧反向摆）；蕾丝下摆最后一行每 4 格挖 1 格、倒数第 2 行每 4 格 1 格高光；两道裙褶 + 一道高光；裙撑上的 5 格垂褶。
- 参数：`P.wph` 波相位 0–3、`P.walk` 滑行（扩到 3 行）、`P.sway`、`P.crouch`（塌落时腰行下移、`spread` 外扩）。
- 材质：丧服 `[27, 28, 29, 30]` band 2（大面积用 band 2 才有两色明暗）。
- 要点：裙子不吃轮廓光（光源在胸口以上，裙前沿整列变亮会像条纹）。

**3. 窄肩细腰胸衣 + 高领 + 沙漏徽** — `drawStanding` 内 L259–264
- 画：6 档行宽表 `BOD` 按实际行数插值的胸衣；高领 3 格；胸前 3 行红色沙漏（2-1-2）。
- 参数：`lean` 前倾（肩按 lean×(1−k/n) 平移）；行数 < 4（塌落）时不画沙漏。
- 材质：丧服 band 1、桃红点缀 `[33, 34, 35, 36]` flat。

**4. 金筹码腰链** — `drawStanding` 内 L265–269
- 画：沿腰线一串筹码，每 3 格一枚（高光 5 · 金 14 · 暗金 19），前侧垂 3 枚。
- 材质：金 `[20, 19, 14, 5]`。
- 要点：单独一个 `part()`，压在裙子和胸衣前面（和胸衣之间自动出分界线）。

**5. 2 格窄袖** — `arm(x0, y0, x1, y1, m2)` L146
- 画：肩到手 2 格粗的袖子（偏水平时向下加 1 格、偏竖直时向右加 1 格）。
- 参数：`m2` 不为 0 时后半段（前臂）换成这个材质——出手帧只让前臂吃轮廓光。
- 材质：丧服 band 1。

**6. 白哭袖** — `cuff(x0, y0, x1, y1)` L150
- 画：手腕处垂直于手臂方向的 3 格白袖口（维多利亚丧服）。
- 材质：白 `[7, 18, 17, 17]`。要点：单独一个 `part()`，在袖子和手之间。

**7. 面纱下的脸** — 模板 `FACE` L235、绘制 `drawStanding` 内 L272–285
- 画：6×5 字符模板：`0` 墨色蕾丝（flat，色调 1）、`k` 暗肤、`E` 眼光、`l / L` 红唇；与墨色交替成棋盘格，脸前一列是面纱帘边。脑后发髻 + 金簪。面纱下摆垂到下巴下一格，3 个点随 `P.beard` 左右摆，`beard ≥ 1 / 2` 前帘多甩 1–2 格、`≤ −2 / −3` 后帘多拖。
- 参数：`P.eyes` 1 时眼光和亮唇都变成墨色（闭眼张嘴）。
- 材质：蕾丝 `[0, 0, 8, 8]` flat、苍白肤 `[27, 31, 32, 32]`、发 `[27, 27, 28, 29]`、桃红、金。
- 要点：用字符模板画小脸，改表情只替换字符；面纱、墨点不吃轮廓光。

**8. 宽檐矮冠丧帽** — `drawHat(hx, hy)` L226
- 画：两行宽帽檐（后端下垂 1 格、前端上翘 1 格，让开斜伸的烟嘴）+ 8 格宽 2 格高的平顶帽冠（酒红帽带色调 2 + 帽顶）+ 帽带后端 1 格金别针。
- 材质：丧服 band 1、桃红、金。倒地时同一个函数画飘落的帽子（L321）。

**9. 细长鸵羽** — `drawFeather(hx, hy, bend)` L214 + 点表 `FEA_BASE / FEA_TAIL` L208–213
- 画：1 格粗的细长弧：固定基段 6 点（从帽带后端向后上拱起，最高点比帽顶高 4 格）+ 4 档尾段（0 受击回卷 · 1 常态下垂 · 2 被吹向后 · 3 甩到最后）；隔一点长 1 格羽枝，垂直于羽轴、左右交替。
- 材质：羽 `[27, 27, 28, 30]`（不吃轮廓光）。
- 要点：细长部件用点表 + 档位切换，不做连续插值；羽枝方向由相邻两点算法向。

**10. 象牙烟嘴 + 烟头** — `drawStanding` 内 L289–291（档位表 `EMB_T` L54）
- 画：从唇边向前上方斜伸 5 格的烟嘴（象牙 + 金箍）+ 末端烟头。
- 参数：`P.emb` 0 暗 · 1 常亮 · 2 亮（多 1 格）· 3 熄。
- 材质：烟嘴 `[27, 18, 18, 17]`、烟头 `[33, 34, 35, 36]` flat（GLOW_MATS）。烟嘴、烟头各一个 `part()`，都不吃轮廓光。

**11. 塌落姿（最终姿）** — `drawLying()` L301
- 画：塌成一圈的裙摊（行宽表 `PL`，`P.sink` 控制 5–7 行）+ 裙撑隆起 + 蕾丝下摆 + 三道斜褶；散开的筹码；塌下的上身 + 垂下的头；摊在裙边的手 + 合拢滑落的牌扇；地上散落的牌；滚出的烟嘴（`P.holdX`）；最后飘落盖上的帽子 + 羽毛 + 面纱（`P.hatX / hatY`）。
- 部件顺序：散牌 → 烟嘴 → 烟头 → 裙摊 → 筹码 → 上身 → 头 → 手 → 牌扇 → 指尖 → 羽毛 → 帽 → 面纱。

## 武器 / 道具

**12. 斜牌（像素画牌面画法）** — `cardGeo(A, L)` L161、`card(px, py, A, L, st, i)` L173、`cardLen(i)` L168、`cardHead(i)` L169（斜率表 `SNAP` L159）
- 画：一张从手心伸出的扑克牌。方向吸附到 5 个像素画斜率（竖 · 1:2 · 45° · 2:1 · 横，四象限对称）；偏竖的牌每行 3 格、逐行错位的平行四边形（远端两行对齐），偏横的逐列错位——远端永远是 3 格宽的平头。远端行 = 牌面，往里 1 行 = 金色内框（只在最上两张点 1 格高光），再往里 1 格 = 花色点（红心 / 黑桃交替）。
- 参数：`A` 角度、`L` 远端到枢轴距离、`st` 0 正面 · 1 侧面（翻面中，只露 1 格金边）· 2 点亮、`i` 第几张（决定花色和高光）。`cardHead` 给特效挂点（牌角外一格）。
- 材质：牌 `[27, 18, 17, 21]`、牌面金框 `[27, 19, 14, 5]`（勾线用墨 27，不让暖褐在牌边围一圈）、点亮的牌 `[27, 36, 21, 21]`、桃红、墨。
- 要点：牌根 1 行藏在手心里（从 k = 2 开始画）；吸附角度避免斜线出锯齿。

**13. 五张牌扇** — `drawFan()` L189（张开度表 `FAN_STEP`、牌长 `CARD_LEN` L54）
- 画：左手握的 5 张牌扇，从后往前每张一个 `part()`，牌与牌之间自动压出墨色分界线。
- 参数：`P.fan` 张开度 0–3（0 = 收拢成一叠，牌码齐变短）；`P.lit` 0–10 蓄力逐张翻亮（`lit >> 1` 张已亮，奇数 = 下一张正在翻面）；`P.a` 扇中轴角。

**14. 指间小牌** — `drawHeld(x, y, roll)` L193
- 画：立在指尖右上的 2×3 小牌：0 正面（红心点）· 1 侧面（金边 1 格宽）· 2 背面（酒红 `[33, 33, 34, 35]` + 亮点）。翻牌动画就是 0 → 1 → 2 → 1 → 0。

**15. 红心 A 大牌** — `drawAce(x, y)` L199
- 画：5×6 大牌 + 红心图案（`P.gem ≥ 2` 牌面点亮、`≥ 3` 红心也亮）+ 捏着牌角的 3 格指尖（单独一个 `part()`，压在牌前）。

**16. 只让出牌手吃轮廓光** — `SKIP_BASE / SKIP_ARM` L27–29、`bakeHero` L325
- 做法：两张轮廓光跳过表，`P.rimArm = 1`（攻击出手帧）时换成「除了前臂袖、白袖口、手以外全部跳过」；前臂袖和手是和丧服 / 肤同色的独立材质（`M_SLEEVE`、`M_HAND`），只为了能单独打光。

## 特效图案

**17. 身侧弹跳金筹码** — `drawChips(front)` L467（位置 / 高度 / 频率表 `CHIP_X / CHIP_H / CHIP_W` L350）
- 画：7 枚金筹码在身侧竖直小抛（|sin| 相位，振幅 0.4 s 缓入）：出现第 1 帧 2 格白，顶点露侧面（1 格 19），其余 2 格（5 + 14），落地多 1 格影子。按 x 正负分前后两层（`fxBack` / `fxFront`）。

- 画：命中点两道 ±45° 的 15 格斜线，4 帧里元素色阶逐级变暗，中间 5 格比两端亮一级，第 3 帧起隔点断续。

**19. 钉在目标上的牌** — `fxFront` 内 L491（`stickT`）
- 画：命中点左侧 3×2 牌 + 左侧 1 列金边 + 1 格红心，保留 0.9 s。

**20. 甩腕拖影弧** — `fxFront` 内 L489（`smT`）
- 画：肩前上方到正前的半径 8 小弧（11 点），第 1 帧色阶 1、第 2 帧隔点色阶 2。

**21. 出手金光** — `fxFront` 内 L490（`mzT`）
- 画：impact 色阶 1 格十字，第 1 帧芯白并向前多 1 格。

**22. 纸牌 / 筹码碎片** — `debris(k, x, y, vx, vy, life, v)` L345，更新在 `stepFX` 内 L418–424，绘制在 `fxFront` 内 L494–499
- 画：比 1 格粒子大的 2 格小物件：纸牌（摆动飘落，竖 2 格 ↔ 横 2 格逐帧交替像在翻，落地躺平；`v` 选桃红牌 / 白牌、红心 / 黑桃）、筹码（重力下坠，弹一次，飞行中每 3 帧露侧面）；寿命最后 28% 按 Bayer 抖动消散。
- 用在：死亡牌雨、施放时筹码四散、场外牌雨。

**23. 飞牌弹道外形** — `drawShot(k, x, y, d, f12)` L508
- 画：`k = 1` 小飞牌 1×3（白边 + 红点），横竖逐帧交替；`k = 2` 致命一牌：金边白芯菱形 ↔ 金边白牌面 + 红心，两帧交替像在旋转，朝前一角 1 格高光。敌弹返回 false 交给引擎默认外形。

**24. 3×5 像素字** — `glyphs(str, x, y, c)` L443（字形表 `GLYPH` L442）
- 画：`+ 0 . 1 A` 五个字形（15 位掩码），`.` 占 1 列。

**25. 场外大 A 牌 + 积分筹码** — `drawOff(f12)` L444、`chipFly()` L441、`stepOff(dt)` L434
- 画：右上角 11×14 大 A 牌：先翻面（1 → 5 → 11 格宽），桃红边框每 0.25 s 在 35 / 36 之间闪、金色内框、A 字 + 20 格红心；最后 0.5 s Bayer 淡出。击杀时目标头顶弹出一枚筹码，沿抛物线飞到积分栏（smoothstep + 上拱 16 格）带「+0.1」，落下后在积分栏旁叠一枚、再冒一个「+0.1」上浮。

**26. 本角色粒子** — `qSpawn(...)` L338，更新在 `stepFX` 内 L405–412，绘制在 `fxFront` 内 L500–505；致命一牌的第 2 道拖尾在 L413–417
- `Q_IN` 汇聚光点：从随机方向直线（带 ±0.8 的小角速度）汇向发光体，按序号 6 帧一轮闪（色阶 0 / 1 / 2）；施放时每颗交给引擎 `spawn(K_BURST, …)` 随机方向外爆。
- `Q_SMOKE` 烟：慢拖曳（e^−1.6t）+ 正弦左右飘，走 dust 色阶。
- `Q_PUFF` 烟圈：10 点小椭圆环整体向前飘、慢拖曳。
- 要点：引擎没有这三种运动方式，模块自带小池子（已提引擎请求：自定义粒子种类）。
