# 圣骑士（_trial-paladin）· 可复用画法清单

模块：`pcd/chars/_trial-paladin.js`（行号指这个文件）。坐标一律以脚底为原点、面朝右、y 向上为负；`part()` 表示新开一个部件（压分界线）。
材质写法：`[勾线, 暗, 基, 亮]`；板甲钢 `STEEL = [0, #3a4068, #7884aa, #c6cfe8]` 是本角色追加色（共享色板没有这组冷灰蓝钢），其余都是共享色阶名。

## 色阶

- `holyGold`（12 行）：`[21, 5, #ffdc5e, 14, #a0601c]` 白 → 奶油 → 圣光金 → 金 → 暗金。共享 `holy` 是 `[21, 51, 5, 14, 61]`（偏淡黄），两者不同。
- `plateSteel`（13 行）：`[21, #c6cfe8, #7884aa, #3a4068, 8]`。共享 `steel` 是另一组钢色 27–31。
- 提炼共享库时建议把板甲钢 3 色、圣光金 2 色补进共享色板（圣骑士、骑士类敌人都会用到）。
