# 驱魔修女 · 可复用部件清单

模块：`pcd/chars/nun.js`（行号以此文件为准）。坐标以脚底为原点、面朝右；色板下标写原版下标（27 以后是本角色专属色，模块里用 `pc(原下标)` 取）。

专属色：27–30 鸽灰蓝修女袍 `#12161f #2e3647 #4f5b73 #7c89a2` · 31–33 白亚麻 `#6d6a78 #b9b6c4 #e6e4ee` · 34–36 银 `#3a4050 #8a93a4 #c9d2de` · 37–40 圣疗薄荷 `#e4ffd8 #b8ffb0 #4cc46a #1a5a34`。
材质定义在 L20–23；轮廓光不打：圣石、圣石白热、银十字架、念珠、脸（L27–28）；头巾翼在轮廓光档 < 2 时也不打（L259）。

## 站姿的部件顺序（`drawStanding` L191）

远侧头巾翼 →（后手在身后时）后袖 → 白袖口 → 手 → 念珠 → 修女袍（+ 袍褶 + 白方领 + 胸前金十字 + 腰带）→ 腰间挂件（圣书 + 圣水瓶）→ 后脚鞋 → 前脚鞋 → 头 → 头巾帽冠 + 近侧翼 →（双手捧十字架时）后袖 → 白袖口 → 手 → 念珠 → 十字架 → 前袖 → 白袖口 → 握十字架的手 →（死亡时）抛飞的十字架。

特殊规则：
- 远侧头巾翼画在最后面（根部藏在头后），近侧翼和帽冠一起画在头之后。
- `P.back` 决定后手画在身后（0 垂在后腰、2 甩开）还是身前（1 双手捧十字架）。
- 碎步时领先的那只脚画在另一只之后（压在前面、带亮鞋尖），L215–216。

## 身体 / 服装

**1. A 字修女袍边** — `robeEdges(y, yT, sway, lean)` L130
- 画：窄肩 A 字袍每一行的左右边界（写进 `robeL / robeR`）。
- 要点：左边 −2 − 2.3·t^1.1、右边 2 + 1.4·t（比巫师的长袍窄得多，娇小体型）；`sway` 按 t² 摆下摆，`lean` 只推上段。

**2. 修女袍 + 方领 + 胸前金十字 + 腰带** — `drawStanding` 内 L202–207
- 画：肩到脚的袍子，最下一行每 3 格 1 格暗（袍摆一跳一跳）；一道袍褶；两行白色方领 + 领下 4 格；胸前小金十字（竖 3 格 + 横臂两端各 1 格）；皮腰带。
- 材质：袍 `[27, 28, 29, 30]`、白亚麻 `[31, 32, 33, 21]`、金 `[20, 19, 14, 5]`、腰带 `[27, 20, 20, 19]`。
- 要点：方领、十字、腰带和袍子同一个 `part()`（不同材质之间仍会出分界线，但不会压成整条黑线）。

**3. 腰间挂件：小圣书 + 圣水瓶** — `drawStanding` 内 L208–211
- 画：前腰挂一本 3×3 小圣书（书脊一列色调 2 + 1 格铜扣），探出袍边；后腰袍边挂圣水瓶（银盖 + 两格绿水）。
- 材质：圣书 `[20, 20, 19, 16]`、圣水 `[34, 39, 38, 37]`、银。

**4. 碎步鞋（两脚真正换位）** — `drawStanding` 内 L212–216，脚位表 `FEET` L51
- 画：两只黑鞋，领先的脚 3×2 + 1 格亮鞋尖，另一只整体暗一级（鞋面 9、鞋底 8、无鞋尖）。
- 参数：`FEET` 表 [前脚 A, 后脚 B] × 5 档（站立 / 接触 A 在前 / 经过 B 抬起过前 / 接触 B 在前 / 经过 A 抬起过前），步幅 ±2；`P.wup` 抬哪只脚。
- 材质：鞋 `[0, 8, 9, 10]`。
- 要点：谁在前谁后画，两脚交叉时分界线方向才对。

**5. 海鸥翼头巾翼** — `drawWing(x0, y0, dir, flap)` L137，形状表 `WING_TOP / WING_BOT` L134
- 画：从头顶两侧向外伸出的上浆白亚麻翼：5 列，顶边平、下沿从根部 4 行斜收到末端 2 行，最外一列错上 1 行 → 翼端是向外上方斜出的扁尖；翼根两列 1 格折痕（色调 2）。
- 参数：`dir` 1 远侧翼（向前）/ −1 近侧翼（向后）；`flap` 只动最外 1 列（−1 下沉压平、1 上扬）。
- 材质：白亚麻（单独的 `M_WING` 材质，方便按轮廓光档开关）。
- 要点：任何状态下翼尖最多比帽冠高 1 行，剪影不会变成兔耳 / 尖角；整顶头巾托起 = 帽冠和两翼一起上移 1 行（`cy` 里的 `P.bend ≥ 2`）。

**6. 头巾帽冠** — `drawStanding` 内 L218–219
- 画：两行帽冠，延到两侧翼根，顶边和两翼连成一条线（翼展 15 格）。和近侧翼同一个 `part()`。

**7. 侧脸 + 白头巾（可转 90°）** — `hp(u, v, m, t)` L146 + `drawHead(ax, ay, rot, closed)` L147
- 画：圆脸（4×5 去掉前角）、白头巾包额头 / 后脑 / 下巴（后脑圆角）、耳旁褶；一只眼：睁眼 = 1 格墨 + 眉影，闭眼 = 下垂的眼睑线；小嘴 1 格。
- 参数：`ax / ay` 下巴那一行；`rot = 1` 整体转 90°（仰躺：头顶朝左、脸朝上，额前再多包 3 格白巾）；`closed` 闭眼。
- 材质：脸 `[20, 16, 15, 15]`（和手同色但单独成材质，不吃轮廓光）、白亚麻、墨。
- 要点：局部坐标 u 向前、v 向下，一套像素两种朝向；下巴行和下颌前角强制基色（底边自动取暗会读成胡子）；脸前沿不放任何深色（否则勾线在脸前伸出黑横杠）。

**8. 喇叭袖** — `sleeve(sx, sy, hx, hy, r0, r1)` L189
- 画：肩到手逐渐变粗的刷子袖（半径 r0 → r1），止于手前 1.6 格；返回袖口位置，接着画白袖口（`brush` 0.9）和 2×2 手。
- 材质：袍色。要点：袖、袖口、手各一个 `part()`。

**9. 念珠** — `drawRosary(x0, y0, n, swing)` L184
- 画：从手里垂下的珠串，每 2 格一颗珠（珠间被分界线压成深色的线），亮珠（色调 4）随 `P.bead` 相位往下滑；末端 5 格小银十字。
- 参数：`n` 长度；`swing` 末端摆动（按 q² 加权）。
- 材质：银 `[34, 35, 36, 21]`（不吃轮廓光）。

**10. 飘落的头巾翼（小版）** — `drawCornette(cx, cy, tilt)` L234
- 画：和戴着时同轮廓的 11 格宽缩小版：3 格帽冠（比两翼低 1 行）+ 两翼各 4 列、末端 2 列上翘 1 行。
- 参数：`tilt` 0 平 · 1 左倾 · 2 右倾（两翼整体错开 1 行）。

**11. 仰面倒地姿** — `drawLying()` L243
- 画：仰面后倒（头在左、脸朝上）：躺平的袍子、竖着的白方领和腰带、胸前金十字、转 90° 的闭眼头（复用 `drawHead`）、搭在腹上的手臂（复用 `sleeve`）、断线前的念珠、横躺的十字架（位置独立于躯体）、飘落的头巾翼。
- 部件顺序：十字架 → 鞋 → 袍 → 头 → 手臂（袖 → 袖口 → 手）→ 念珠 → 头巾翼。

**12. 按轮廓光档开关某个材质** — `bakeHero` L258
- 做法：`skip[M_WING] = P.rim < 2`——待机的弱轮廓光不打在白头巾翼上（否则翼下沿成一道绿线），蓄力 / 施放才照亮。

## 武器 / 道具

**13. 长柄银十字架 + 圣石** — `drawCross(cx, cy, a)` L171，圣石表 `STONE / STONE_LV` L163–170
- 画：长柄（`line`，不画进地面以下）+ 柄尾 + 缠柄银箍；1 格粗的十字头，上臂和左右横臂各伸出 2 格（臂长 3），四角留 2×2 空——纯黑剪影里是清楚的「+」；中心嵌 5 格薄荷圣石。
- 参数：`cx / cy` 圣石中心；`a` 倾角（0 竖直，π/2 头朝右）；`P.gem` 圣石 5 档（待机 / 蓄力 1 / 蓄力 2 / 施放 / 熄灭）；`P.glint` 右上 1 格闪光。
- 材质：银、圣石 `[40, 39, 38, 37]` flat、圣石白热 `[38, 38, 37, 21]` flat（这两个是 GLOW_MATS）。
- 要点：局部坐标 u 横向、v 沿柄向下；圣石按圆整后的中心画，任意角度都不变形。

**14. 十字架脱手抛飞** — `crossFly(d)` L55
- 做法：姿势生成器：抛物线上抛再落到身前（先快后慢），每 0.13 s 转 90°（转 5 次正好横躺），落地后弹一下；写进 `P.cx / cy / cr`，`drawCross` 按 `cr × π/2` 画。

## 特效图案

**15. 脚下椭圆点阵法阵** — `drawCircle(front, f12)` L344，点表 `CIRC / CIRC_Q` L342–343
- 画：24×6 的椭圆，每 2 格一点，按角度从正前方起逐点亮起；上半圈画在人物后（`fxBack`）、下半圈画在人物前（`fxFront`）。
- 模式：蓄力逐点亮起（最新亮起的点白、其余 1/3 亮）· 施放全亮闪烁 · 收招前段暗 · 收招后段隔点断续。

**16. 天降光柱** — `drawPillarAt(X, t, front, f12)` L359（本角色 `drawPillar` L358）
- 画：3 格宽光柱，0.06 s 从天顶落到地，前 2 帧全白，之后芯随机亮点、外侧隔行闪点；0.5 s 后从上往下断开并断续；柱脚 19 格映光。`front = 1` 画罩在身上的一层稀疏光点（只在断开前）。
- 要点：一个函数给上场技能和场外「每个单位一道」共用（场外按 0.08 s 错开）。

**17. 贴地圣焰波** — `drawWave(dir, f12)` L377、`waveFront(dir)` L308
- 画：12 列火舌贴地向外推进（不是圆环）：前沿 3 行最高最亮、火舌尖朝前卷，尾部变矮变暗、按哈希断续；右侧推到目标脚下后每 0.05 s 暗一级并缩短，左侧推出一段后熄灭。
- 参数：`dir` ±1；170 格 / 秒；在 `fxMid`（目标前、人物后）。

**18. 目标身上的小火苗** — `drawBurn(f12)` L392，位置表 `BURN` L391
- 画：目标身上 4 簇 3×4 小火苗（深色火根 → 中 → 淡 → 白色焰尖），各自相位左右摆；最后 0.3 s 变小变暗、少一簇。持续 0.8 s。

**19. 十字光点** — `plusMote(x, y, vy, life)` L274，本角色粒子池 `qSpawn` L269，更新在 `stepFX` 内 L332–337，绘制在 `fxFront` 内 L458–461
- 画：5 颗同速粒子组成「中心 + 上下左右」的十字，臂的起始年龄 = 寿命 × 0.2 → 臂比中心早一级变暗、早消失；只拖曳竖直速度（e^−1.1t），不左右飘。
- 用在：蓄力脚下上升、施放柱内上升、收招余韵、场外每个单位身上。

**20. 断线念珠** — `Q_BEAD`（同上池子），生成在 `onTime` L296
- 画：16 颗银珠四散：重力 170、水平拖曳 e^−0.9t，落地速度 > 22 反弹 45%，否则停住；走银色色阶 `bead` = 白 → 36 → 35 → 34 → 27。

**21. 前推拖影 + 十字枪口光** — `fxFront` 内 L455（`smT`）、L456（`mzT`）
- 画：前推拖影 = 上下两道平行线（±3 格）+ 前端 3 格白芯，第 2 帧隔点；枪口光 = 臂长 3 的十字（芯白、1 格色阶 0/1、2 格色阶 1、3 格色阶 2）。

**22. 圣石十字星芒** — `fxFront` 内 L454
- 画：发光体两档星芒（蓄满：3–4 格臂，隔帧伸缩；施放：6 格臂 + 四个对角点）——与范式巫师的宝石星芒同一套。

**23. 十字光矢弹道** — `drawShot(k, x, y, d)` L463
- 画：3×3 十字（芯 2 格白）+ 1 格拖尾；敌弹返回 false 交给引擎默认外形。

**24. 占位小兵剪影** — `drawPawn(cx)` L417，字符图 `PAWN` L416
- 画：7×14 的暗色小兵（石色 9 + 左侧亮边 10），演示页里代表「己方单位」。

**25. 回血数字「+35%」** — `drawHealNum(cx, y, lt)` L420，字形 `GLY` L419
- 画：3×5 像素字 4 个，先画深色描边（上下左右 4 邻）再画填色；出现的前 2 帧淡色，最后 0.25 s 去掉描边、褪成暗一级；随时间上浮。

**26. 飘落白羽** — `drawFeathers()` L429，出发表 `FEA` L428
