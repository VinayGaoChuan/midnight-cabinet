== 设计 ==
- 体型：矮墩圆滚档（貔貅 / 石狮式），待机 32×25 格；前后一样圆、腿最短（腿长 4）、头大，和同组野猪 / 赤瞳的楔形、赤蠕虫的贴地软身、宝石蜥蜴的长身拉开。
- 识别特征：
  - 背上三颗由小到大的圆顶青玉，根部一圈金毛茬；
  - 额前一支往后弯过头顶的单支玉角，攻击就用它上挑；
  - 尾梢用朱红绳拴一串 5 枚方孔铜钱（商人读法，避开赤蠕虫的钱袋）；
  - 大圆眼、笑脸、胸前奶油色围兜。
- 配色：暖杏沙色毛（sand）+ 自建羊脂青玉色阶（玉石为发光体），尾绳朱红，铜钱金色。
- 待机个性：招财猫式举爪招手，铜钱串跟着晃。移动：短腿碎步颠跑，隔一步掉一颗小金点。
- 攻击：玉角上挑（swing thrust），玉色短弧拖影。
- 技能「玉石共鸣」（被动，画生效的那一刻）：坐起昂首，三颗玉在 0 / 0.45 / 0.9 秒依次点亮；施放时爆闪，最大那颗玉拉出两条玉色虚线连到身后两个友军商人（ALLIES: 'skill'、allyPoints()、allyFx 描玉边、染金）；头顶倍率 ×1.1 → ×1.2 跳两档；自己和两个友军头上各落一场金币雨，外加玉屑。
- 死亡：侧翻，肚皮朝上；三颗玉按大 → 小依次崩落滚到地上，铜钱串断绳，玉闪 3 次后熄灭，身体消散。
- SFX：body beast · how topple · pal coin · style buff · w 0.35（style 用 buff，和赤蠕虫的 coin 区分开）。
