# 首领角色的制作标准和步骤

后面 39 个首领照这份批量做。两个试点：小首领 **奔雷**（`pcd/chars/B_centaur.js`）、最终首领 **深渊魔王**（`pcd/chars/B_demon.js`）。接入代码只有一个文件 `src/mc-bossart.js`；设计文档是 `docs/design.md` §8.3「首领的画法」。

## 1. 标准（验收就按这几条）

| 项 | 小首领 | 最终首领 |
|---|---|---|
| 模块 | `pcd/chars/B_<名>.js`，`PCD.define('B_<名>', f, { W, H })` | 同左 |
| 舞台（meta W×H） | 约 200×110 | 约 220×136 |
| 战斗里的像素大小 | 1 格 = 4 像素（和普通单位一样，`e.pxBig = 1`） | 1 格 = 6 像素（大一档，`KF = 6`） |
| 色阶 | 主材质用 `defDeep`（8～12 级），不用普通角色的 4 级 `defMat` | 同左 |
| 立绘 | `portrait()`：同一套形状按两倍分辨率（`B.zoom(2)`）画一张静帧 | 同左 |

- **更多像素，不是更粗的像素**：不能把普通单位的图放大。大，是指画布更大、部件更多、细节更多。
- **深色阶材质**：在 `pcd/lib/pcd.js` 的 `DRAMP` 里加一条 11 级色阶，暗 → 亮，暗端要够黑，这样描边和缝才压得住。然后用 `defDeep(名, { depth, amb, dark })`：
  - `depth`：鼓起的格数，越大越圆润。
  - `amb`：暗部下限。
  - `dark`：整体压暗几级，远侧的肢体用 `dark: 3～4`。
  - 引擎按部件剪影算体积，对左上的光打光，量化成硬边色带，不抖动。
  - 手画的加减光用 tone：`3` 是缝，`7`/`8` 是高光，`10` 是勾线色。
- **魔法光源**（`bake` 的 `lights`）：熔岩心、符文、岩浆面，每个都是 `{ x, y, r, ramp:[亮,中,弱], k }`。被照到的面会换成光源的颜色，也是硬边三档。
  - 轮廓光用 `rim` + `rimRamp`；按招式档位 0～3 调 `RIM.rim`。
  - 发光材质（`GLOW_MATS`）不吃轮廓光，要放进 `RIM.skip`。
- **主色 vs 光色**：主体要暗、要饱和不足，光（裂纹、符文、火）才亮得出来。深渊魔王第一版的皮太亮，熔岩裂纹看不见；把 `dark` 压 2 级、岩浆映光的 `k` 降到 0.46 才好。
- **不能比领袖差**：拿 `pcd/chars/watchman.js` 这类领袖的动作表并排看，细节、动作幅度和特效量都要在它之上。

## 2. 动画清单（全部 12 fps 量化：`q12` / `f12of`）

所有状态的姿势都用关键姿势表 `K = { idle, wind, strike, … }` 插值。`pose(a, b, q)` 配 `ease.*`，最后一定要量化到 12 fps。

| 状态 | 要求 |
|---|---|
| 待机 | 呼吸 2 档起伏、翼 / 尾 / 鬃各自摆动，外加一个「个性」小动作。奔雷刨蹄喷鼻；魔王抬头从鼻孔喷烟 |
| 移动 | 小首领要有步态（奔雷是 4 拍小跑，冲锋时换快速奔跑）。最终首领不走，这一格给「攀爬」 |
| 普攻 | 有蓄势 → 出手 → 收势，出手那一帧亮起、张嘴 |
| 每个招式 | 各自有 **蓄力 / 出手 / 收招**，用 `setMove(id)` 切换，并返回 `{ 3: 蓄力秒, 4: 出手秒, 5: 收招秒 }`。蓄力要一眼看出在蓄力：抬高、后仰、手上聚能、颤动、光越来越亮 |
| 受击 | 闪白 1 帧 → 后仰 → 回位 |
| 过半 | 小首领：怒吼（`setMove('roar')`，从 cast 开始播）。最终首领：第二阶段仪式里它自己的变身（`p2`：抱胸 → 两声心跳 → 仰天怒吼、双翼全开，共 2.9 秒）。之后用 `setMove('hot1')` 让裂纹 / 光一直亮着 |
| 死亡 | 小首领：跪倒、倒下（它自己的，不用游戏通用的翻倒）。最终首领：哀嚎 → 瘫软 → 化成火星 / 碎片沉回地形 |
| 升起（最终首领） | `setMove('rise')`：蓄力 2.2 秒，对齐游戏里的升起时间，爬出地形；出手是在顶端张翼怒吼 |

模块要导出 `SHEET`：动作表里每个状态、每个招式的关键帧。`pcd/tools/boss-sheet.cjs` 可以直接出图，不用开浏览器。

## 3. 招式特效

- 每个招分四段做：**警示**（游戏里的警示圈已有）、**飞行物**、**命中**、**地面残留**。
  - 模块画身边的那部分：手上聚能、出手的环、地裂、火浪、飞溅。
  - 砸到部队身上的部分由游戏画：陨石落点、雷环。
- 颜色统一用这个首领的主题色板（`FXI.fire` / `FXI.bolt` …）。粒子按 白 → 主色 → 暗 逐级变色。
- 震屏、白闪、停顿按强度来：
  - 普攻：`shake(0.15, 2)`。
  - 招式：`shake(0.35, 3)` + `flash(0.06～0.12)`。
  - 怒吼 / 变身：`ring` 两道 + `flash(0.12)`。
- 身上常驻的环境粒子：魔王是往上飘的火星，第二阶段更密；奔雷是鬃毛上的电光。

## 4. 音效（关键帧上 `sfx(...)`）

- 通用事件：`swing`、`hit{mat}`、`impact{pal}`、`fall`、`shoot`。
- 首领自己的声音：`sfx('boss', { k, w })`，在 `src/mc-audio.js` 的 `BOSSV` 表里合成。已有：snort、neigh、thunder、bolt、roar、growl、heartbeat、slam、throw、thud、sink、fade、lavaGather、lavaRise、demonDie。新首领优先复用，不够再往 `BOSSV` 里加一条。
- 至少要有这几个：
  - 蓄力开始
  - 出手（和伤害同一帧）
  - 命中 / 落地
  - 脚步 / 冲锋 / 攀爬
  - 怒吼
  - 死亡的哀嚎和倒地 / 沉没

## 5. 接进游戏（`src/mc-bossart.js`）

1. 表里加一行：
   - 小首领：`MINI[<单位 key>] = 'B_<名>'`。
   - 最终首领：`FINAL['FB_<名>'] = 'B_<名>'`。
   - 如果有招式要映射，小首领在 `MOVES`、最终首领在 `FMV` 里写 `游戏招式 id → 模块招式`。模块里招式同名就不用写。
2. 小首领：接管单位的 `hd.key`，由 `mc-pcd-game.js` 的动作引擎来画。
   - 招式在 `bkBegin` 开始时播自己的蓄力，按游戏的蓄力时间裁掉开头，所以 **出手帧 = 伤害帧**。
   - 半血怒吼时，下一招等 1 秒再出。
   - 冲锋（`bk.dash`）画快速奔跑 + 电光。
   - 死亡跳过 `kbDie` 的通用翻倒。
3. 最终首领：每个首领一台自己的引擎（`fbEng`），`fbDrive` 按 `e.ai.st` 和 `e.casting` 选动作：
   - `rise` → 升起。
   - 招式 → 蓄力；游戏一出手就切到 cast。
   - `roar` / `b.p2` → 变身。这时战斗是冻结的，引擎改用仪式自己的真时钟推进。
   - `dead` → 死亡。
   - 被打到时每 3 秒最多一次受击。
   - 第二阶段仪式在变暗的屏幕上面再画一次首领（`GP.tick`）。
4. 立绘自动出现在这些地方，不用另外接：
   - 地图首领节点的悬浮说明
   - 碑的悬浮说明
   - 左边「前面的首领」牌子
   - 首领战开场
   - 剧情画面
   - 输给首领后的牌子

## 6. 步骤（一个首领一轮）

1. 读设定：`docs/design.md` 附录 G / G2、`src/mc-bosskit.js` 里它的 `K('<key>', …)`（被动、招式、第二阶段），再加 `src/mc-scenes.js` 的描述。写一段设定卡，放在模块开头的注释里：剪影、识别特征、主色、光源、每个招式的动作和特效。
2. 如果需要新色阶，在 `pcd/lib/pcd.js` 的 `DRAMP` 里加一条。已有：hellhide、obsidian、ivory、membrane、magma、stormcoat、tan、stormmane、hide、bladesteel、brass。
3. 拷一个试点改：小首领拷 `B_centaur.js`，最终首领拷 `B_demon.js`。然后改：
   - `K` 姿势表
   - 部件绘制（从后往前，每块前面调 `part()`）
   - `movePose`
   - 特效（`onEnter` / `onTime` / `stepFX`）
   - `SHEET`
   - `portrait()`
4. 出图检查：
   - `node pcd/tools/boss-sheet.cjs B_<名> out.png 2` 出动作表。
   - `ONLY='[[0,[0]]]' node pcd/tools/boss-sheet.cjs B_<名> one.png 4` 出单帧大图。
   - 加 `portrait` 参数出立绘。
   - 要看的：剪影、主色和光色的对比、蓄力读不读得出来、立绘的脸看不看得清。
5. 在 `src/mc-bossart.js` 的表里加一行，然后 `node tools/pcd-pack.mjs && python3 tools/mk.py`。
6. 实战：
   - `node pcd/tools/boss-drive.mjs pcd/tools/boss-fight-final.mjs`（最终首领；把 `FB_demon` 换成自己的 key）
   - 或 `pcd/tools/boss-fight-mini.mjs`（小首领；改 `miniOf` 的 key）
   - 看升起、招式的蓄力和命中、过半、死亡。加 `OLD=1` 就是旧版同一时刻的对比图。
7. 验证：
   - `SECS=120 node pcd/tools/boss-drive.mjs pcd/tools/boss-check.mjs`：bot 的 `viewErrs` 要是 0，`designCheck` 要 `ok`。
   - `node tools/gen-effects.js`。
   - 在 `docs/design.md` §8.3 的首领画法里补一句这个首领。
8. 提交。

（这几个脚本都在 `pcd/tools/`：`boss-drive.mjs` 开一个无头 Chrome，用 CDP 打开 `index.html`，再跑传进来的步骤文件。截图写到 `OUT` 环境变量指定的目录，默认是 `.ai/`，用完就关掉浏览器。）

## 7. 试点花了多少

| 试点 | 时间 | 大约 token（自己估的） | 备注 |
|---|---|---|---|
| 奔雷 | 约 40 分钟 | 约 25 万 | 含引擎能力：深色阶材质、彩色光源、舞台高度、`setMove`、立绘，以及旧 216 个角色的逐像素回归 |
| 深渊魔王 | 约 60 分钟 | 约 30 万 | 模块约 20 分钟；最终首领的驱动、第二阶段在暗屏上重画、立绘接到 6 个地方约 40 分钟 |

接入和工具现在都是现成的。后面每个首领主要是画模块本身，估计小首领 20～30 分钟、最终首领 30～40 分钟，每个 10～15 万 token。

## 8. 最终首领模块契约（批量做时照这个写，接入代码不用改）

- 文件：`pcd/chars/B_<x>.js`，对应游戏里的 `FB_<x>`。有了这个模块就自动替换，`mc-bossart.js` 的 `artOf` 会按名字找。定义写 `PCD.define('B_<x>', f, { W: 220, H: 136 })`，最大 W 240、H 150。
- 原点是地形表面（岩浆 / 水 / 地面），只画上半身。战斗里 1 格 = 6 像素，默认往下沉 18 格；头特别高或特别矮的，用 `SINK` 自己定。
- **招式名就用游戏里的招式 id**：`K('FB_<x>')` 里 p1 和 p2 的全部 id，加上 `poke`、`rise`、`p2` 三个固定的；`setMove('hot1'/'hot0')` 切常亮。这些名字都要出现在 `MOVES` 里，`setMove(id)` 返回 `{ 3: 蓄力, 4: 出手, 5: 收招 }`。
  - `rise` 蓄力 2.2 秒。
  - `p2` 是 0.7 / 0.5 / 1.7 秒，一共 2.9 秒，对齐第二阶段仪式。
  - 其它招式的蓄力写成 `MV.<id>.wind`，游戏会按自己的蓄力时间裁掉开头。
- 导出的字段照 `B_demon.js` 抄一份；另外可以加：
  - `VOICES: { 名字: (syn, t, w, pan) => { … } }`：自己的声音。`syn` 里有 tone、nz、fm、ring、thud、whoosh、riser、crackle、blip、bell、rumble、brass、choir、timp、cymbal、coins、step、rnd、pick、hz、thunder，参数和 `mc-audio.js` 里的同名函数一样。在关键帧上用 `sfx('boss', { k: 名字, w })` 叫它，名字要带首领前缀免得撞车，比如 `bellToll`。
  - `portraitHead()`：在 `portrait()` 里算好，返回 `[x, y, r]`（立绘缓冲里的坐标和半径），地图节点的头像从这里裁。要是立绘的姿势看不清脸，就另外做一个 `headShot()`。
- **色板**：`defDeep([11 个颜色，暗 → 亮], { depth, amb, dark })` 可以直接传数组，不用改 `pcd.js`。主体暗，光源亮。
- **认得出**：头 / 脸 / 标志物（钟、树冠、王冠、船锚……）要占剪影的大头，站在战场右边一眼就知道是谁。和别的首领的剪影不能撞。
- 只用 node 自检：`node pcd/tools/boss-sheet.cjs B_<x> .ai/<x>-sheet.png 2`，再加 `portrait` 出立绘。浏览器的实战验证由主会话统一跑。
