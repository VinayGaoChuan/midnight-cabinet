# 巨型歼灭者 GigaAnnihilator

模块：`pcd/chars/GigaAnnihilator.js`。身体不用现成骨架：粗反关节鸟腿 ×4、连弩机身、双层弩弓臂、旋转弹鼓、眼杆都是本模块自画的部件（函数前标了「// 候选部件」）。
升级线：歼灭者 → 巨型歼灭者，**同一台弩进化了**：保留反关节鸟腿（从 2 条加到 4 条、粗一圈）、热铜反曲弓臂（上下叠成两副）、红色瞄准眼（单眼 → 伸出机身前 3 格的眼杆，三只红眼竖排一列）、火焰箭与拖火苗的箭杆；背后的箭匣换成插满火焰箭的旋转弹鼓；机身从焦黑枪铁换成暗红漆装甲 + 枪铁骨架带，比歼灭者高 10 格、宽一倍。

## 角色设定卡

- 名称 / 身份：巨型歼灭者，维克特拉造的传说级虚空连弩机甲，射手——四条腿托着的一台双层连弩，一次齐射好几支火焰箭。
- 一句话剪影：**四条往后折膝的粗鸟腿 + 横长的暗红连弩机身 + 前端上下两副热铜弓臂（形成「E」字前沿）**，背上顶一只插着火焰箭的圆弹鼓。
- 尺寸：待机约 41×42 格（机身 25 格长、腿 19 格、弹鼓箭尖顶到 −40）。传说品质，巨型四足反关节档。
- 材质色阶（色板下标）：
  - 暗红漆装甲 [0, 55, 56, 57]（blood 色阶压暗一级，band 2）
  - 枪铁骨架 / 托尾 / 导轨 / 腿 / 眼杆 `iron` [0, 27, 28, 29]（远侧两条腿暗一级）；关节、脚爪 `steel`
  - 弹鼓 `steel`（常温）→ 烧红 [44, 45, 46, 47] → 烧白 [45, 47, 21, 21]；鼓边暗红箍
  - 热铜弓臂 `gold`；弓弦平涂 [8, 59, 60, 17]；三只红眼（发光体）[12, 13, 26, 58]；火焰箭头（发光体）[45, 46, 47, 21]；箭杆 `wood`；散热口 `ink`
- 部件顺序（从后往前）：远后腿 → 远前腿 → 弹鼓 → 机身（+ 同部件两根弓弦）→ 近后腿 → 近前腿 → 导轨 → 眼杆 → 弩箭 → 上弓臂 → 下弓臂。
- 细节清单：
  - 「脸」：伸出机身前 3 格的铁眼杆，三只红眼竖排（每只 2–3 格、5 档：暗 / 常亮 / 亮 / 爆闪 / 亮满），待机个性时依次亮。
  - 「发 / 须」：弹鼓沿伸出的四支火焰箭（每档转 45°，上半圈的露出箭杆 + 箭头），鼓面铆钉跟着转。
  - 头饰：背上旋转弹鼓 + 中心钢轴。
  - 「服装」：暗红装甲楔形舱，枪铁骨架带（每 4 格一颗亮铆）、竖肋条、装甲缝、5 颗铆钉、顶上散热口三道、托尾 + 托板。
  - 「手臂」：无手臂；上下两条枪铁导轨从机身伸到弓臂铁夹。
  - 「腿脚」：大腿 3 格、后折膝（钢关节 + 液压杆点）、胫 2 格、脚掌 + 前爪 + 后距；对角两腿一组。
  - 武器：上下两副热铜反曲弓臂（各半长 5、中段 2 格厚、弓梢回勾）+ 上下两支火焰弩箭（技能时上导轨再推上一支，共三支）。
  - 发光体：三只红眼 + 火焰箭头 + 烧红 / 烧白的弹鼓（`GLOW_MATS`）。
- 攻击方式：远程 **射 · 交替齐射**：两副弓弦一起再拉一格（预兆）→ 第 2 帧上弓放、第 3 帧下弓放（机身后坐 1 → 2 格），两支火焰箭先后命中 → 空弦震颤 → 弹鼓咔哒一格、重新装箭。
- 差异化（对照已通过角色 + 同组分配 + 升级前的歼灭者）：
  - 体型档：巨型四足反关节档（机身水平、四条鸟腿），和歼灭者（双足小舱）、Pulsebot（矮方箱）、Skybot（悬停）、CrawlingCatapult（六足虫足投石车）、WanderingTrebuchet（高跷投石机）拉开。
  - 识别特征（≥ 2 个改外轮廓）：①前端上下两副弓臂（轮廓）②背上圆弹鼓 + 伸出的箭（轮廓）③四条后折膝鸟腿（轮廓）④三眼眼杆。
  - 武器 + 握法 + 攻击类型：机体即武器 × 射（双弓交替齐射）；歼灭者是单弓单射。
  - 动作个性：待机 = 转鼓（1.6 s 弹鼓咔哒转一格、机身一顿，1.65 s 散热口喷一口白汽，1.7–2.0 s 三只红眼依次亮）；步态 = 四足重步（对角两腿一组，接触帧顿挫 1 格 + 两只脚各 2 颗尘 + 1 格震屏）；死亡 = 过热熔化（歼灭者是跪折崩弦）。
  - 主色：暗红漆装甲（歼灭者是焦黑枪铁）。
  - 特效：三箭扇形齐射 + 三团火依次爆开 + 地面火线（歼灭者是单箭火尾 + 二段爆）。
  - 自动查重：`compare.mjs` 对已通过角色退出码 0（最近的邪眼王，待机 IoU 0.481）。

## 特效设定卡

- 元素：火焰箭齐射 · 橙焰，色阶 `fire` = 21 白 → 47 淡黄 → 46 橙 → 45 红 → 44 深红；箭芯 43 淡紫；落地碎屑 `earth`、白汽 `dust`。
- 攻击「双弓交替齐射」
  - 预兆：两根弓弦一起再拉一格、腿屈 1 格、三只红眼亮一档。
  - 出手：上弓放（弓臂弹直、枪口十字光 2 帧）→ 下一帧下弓放、后坐 2 格；两支火焰箭 250 格/秒斜飞向假人。
  - 命中：每支 8 颗火焰外爆 + 5 颗 impact，假人闪白小摇两次。
- 技能「火焰箭 · 连弩齐射」
  - 蓄力 1.4 s：弹鼓 0.2 s 起逐帧飞转；0.35 s 上导轨再推上一支箭（共三支）；两副弓弦同时拉到最后；箭头从橙烧到黄再到白热（白热后外冒火芒）；三只红眼在 0.3 / 0.6 / 0.9 s 逐个亮满；火焰粒子分三股螺旋汇聚到三只箭头；散热口持续喷白汽；轮廓光 2 档（红眼在剪影内，`rimAll`）；最后 0.3 s 弓弦颤。
  - 施放 0.5 s：三箭扇形齐射——下弓一支射向假人前的地面、上弓一支射向假人身上、上弓第二支射向假人后的地面；三个枪口十字光；后坐让四条腿往后滑 2 格（脚下 10 颗扬尘）；冲击环 + 20 颗外爆 + 汇聚粒子外爆；弹鼓继续转；震屏 2 格、天空闪白。
