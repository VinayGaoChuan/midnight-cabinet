# 歼灭者 Annihilator

模块：`pcd/chars/Annihilator.js`。身体不用现成骨架：反关节鸟腿、弩身舱、弩弓臂、箭匣、冷却鳍都是本模块自画的部件（函数前标了「// 候选部件」）。
升级线：歼灭者 → 巨型歼灭者，是**同一台弩长大了**：保留反关节鸟腿（2 → 4 条）、热铜弓臂（1 → 上下 2 副）、红色瞄准眼（单眼 → 三眼眼杆）、火焰箭；箭匣换成旋转弹鼓，枪铁机身换上暗红漆装甲。

## 角色设定卡

- 名称 / 身份：歼灭者，维克特拉造的虚空战争机械，射手——一台会走的弩：没有手臂，机体本身就是武器，每一箭都烧着火。
- 一句话剪影：**两条细长的反关节鸟腿（膝往后折）+ 腿上顶着一只小弩身舱 + 舱前竖着一副上下展开 19 格的热铜弓臂**，背后箭匣的三根红羽箭尾翘出顶上 4 格。
- 尺寸：待机约 30×31 格（弓臂 19 格高、箭尾顶到 −29、腿 13 格）。稀有品质，高瘦反关节档。
- 材质色阶（色板下标）：
  - 焦黑枪铁 `iron` [0, 27, 28, 29]：弩身舱 band 2，箭匣 / 冷却鳍 / 鸟腿 band 1（远侧腿暗一级 [0, 27, 27, 28]）
  - 关节 / 脚爪 / 镜筒 `steel` [27, 28, 29, 30]；热铜弓臂 `gold` [20, 19, 14, 5]；弓弦平涂 [8, 59, 60, 17]
  - 红色单眼（发光体，平涂按档写色调）[12, 13, 26, 58]；火焰箭头（发光体）[45, 46, 47, 21]；冷却鳍热光 [44, 45, 46, 47]
  - 箭杆 `wood`、箭羽 `crimson`、箭槽 / 镜框 `ink`
- 部件顺序（从后往前）：箭匣 → 远侧鸟腿 → 弩身舱（+ 同部件弓弦）→ 近侧鸟腿 → 冷却鳍 → 瞄准镜 → 弩箭 → 弩弓臂。
- 细节清单：
  - 「脸」：鼻端上方的钢镜筒 + 镜框 + 2×2 红色单眼，扫描时亮点上下换；5 档（暗 / 常亮 / 亮 / 爆闪 / 熄灭）。
  - 「发 / 须」：箭匣里三根斜插的火焰箭，红羽箭尾；箭头余烬持续往上飘。
  - 头饰：冷却鳍两片，合拢贴平 / 半开 / 全开，鳍缝透热光。
  - 「服装」：楔形舱 + 托尾 + 托板，面板缝、3 颗铆钉、散热格、鼻端箭槽；箭匣铁箍 + 铜扣。
  - 「手臂」：无手臂（设定如此）；弓弦从两个弓梢拉到弦扣，按 pull 0–3 画出一条直弦 / 三角弦。
  - 「腿脚」：大腿 2 格、往后折的膝（钢关节 2×2）、往前下的胫、三趾爪 + 前爪尖 + 后距；远侧腿暗一级。
  - 武器：热铜反曲弓臂（中段 2 格厚、弓梢回勾 1 格、铁夹固定在鼻端）+ 装在箭槽上的火焰弩箭（杆 + 三格箭头 + 倒刺）。
  - 发光体：红色单眼 + 火焰箭头 + 冷却鳍热光（`GLOW_MATS`）。
- 攻击方式：远程 **射**：弓弦再拉一格（预兆）→ 放弦，弓臂弹直、机身后坐 2 格 → 箭飞出（260 格/秒，火苗拖尾）→ 空弦震颤 → 重新上弦装箭。
- 差异化（对照已通过角色 + 同组分配）：
  - 体型档：高瘦反关节档（两条鸟腿托一只小舱），全库第一台双足机械；和同组的方块机甲 Pulsebot（矮壮方箱双足）、悬停 Skybot、四足的巨型歼灭者拉开。
  - 识别特征（≥ 2 个改外轮廓）：①舱前竖直的大弓臂（轮廓，前沿）②往后折膝的细鸟腿（轮廓，下半）③箭匣三根红羽箭尾（轮廓，顶上）④红色单眼瞄准镜。
  - 武器 + 握法 + 攻击类型：机体即武器（无握持）× 射；同组 GoblinCopter 是双联炮点射、Whirlybird 是火箭筒、Pulsebot 是冲拳。
  - 动作个性：待机 = 扫描（弩身在鸟腿上左右转 1 格、镜片亮点上下扫、0.8–1.2 s 一道红色虚线瞄准光来回扫、1.6–2.0 s 松一下弦、弦震颤、再上弦）；步态 = 高抬腿快步（经过帧抬 3 格、脚爪落地 1 颗尘 + 1 颗火花）；死亡 = 跪折崩弦。
  - 主色：焦黑枪铁 + 热铜弓臂 + 红眼，巨型歼灭者换成暗红漆装甲。
  - 特效：单支大火焰箭 + 火尾光束 + 停半拍二段爆；巨型歼灭者是三箭扇形齐射 + 地面火线。
  - 自动查重：`compare.mjs` 对已通过角色退出码 0。

## 特效设定卡

- 元素：火焰箭 · 橙焰紫芯，色阶 `fire` = 21 白 → 47 淡黄 → 46 橙 → 45 红 → 44 深红；箭芯点缀 43 淡紫。
- 攻击「火焰弩箭」
  - 预兆：弓弦从弦扣再往后拉一格、弓臂更弯，机身后引 1 格、腿微屈，单眼亮一档。
  - 出手：放弦定格 1 帧——弓臂弹直、机身后坐 2 格、机鼻上扬，枪口十字光 2 帧 + 6 颗火星。
  - 弹道：铁杆 + 紫芯 + 黄 / 白热箭头，杆上火苗逐帧跳，隔步拖火屑。
  - 命中：8 颗火焰外爆 + 5 颗 impact，假人闪白小摇。
- 技能「火焰箭」
  - 蓄力 1.4 s：弓弦缓缓后拉到最后（pull 1 → 3，弓臂弯到最深），箭头从橙烧到黄再到白热（fire 第 3 → 2 → 1 级，白热后箭头外冒十字火芒），两片冷却鳍 0.3 s 半开、0.6 s 全开，鳍缝透热光、喷白汽；火焰粒子螺旋汇聚到箭头；腿屈 1 格；轮廓光 2 档；最后 0.3 s 弓弦颤。
  - 施放 0.5 s：放弦——弓臂弹直、机身后坐 2 格；火焰箭 300 格/秒直线射出、身后长火屑拖尾；枪口十字星芒 + 冲击环 + 18 颗外爆，汇聚粒子外爆，冷却鳍喷一口热气；震屏 2 格、天空闪白。
  - 命中：箭插进假人（箭杆、红羽露在外面，箭头处火苗乱窜），同时从枪口到假人留一条火焰拖尾光束（`fx.beam` 0.4 s）+ 10 颗火星 + 小摇 + 震屏 1 格；停 0.2 s 后二段爆开——34 颗火焰外爆 + 大冲击环 + 十字星芒，假人点燃 0.7 s（`dummyFx tint fire`）、大摇 + 击退，余火在目标身上飘 0.5 s；每段一次 `impact`。
  - 收招 0.7 s：冷却鳍 2 → 1 → 0 合拢、余汽散去，弓弦 0.35 s 回到弦扣，0.45 s 新箭上弦，单眼 2 → 1。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 单眼熄灭、机鼻上扬、弓臂和弦震颤；金属火花 20 颗 impact + 4 颗长寿命钢色火星；震屏 1 格。
- 死亡（跪折崩弦）：26 颗火花 + 震屏 2 格 + 闪白 → 腿屈到底、单眼闪 → 0.3 s 鸟腿从膝处折断跪下（大腿斜到地上、胫平摊在地、爪尖翘起）→ 0.45 s 弓弦崩断（火花 + 铜屑），弓臂弹飞（抛物线 0.3 s、最高 7 格、向前 12 格）落地躺成一条 → 0.5 s 弩身向前扑倒（离地 3 → 1 → 0）→ 0.66 s 落地：尘土 16 颗 + 震屏 1 格 + `fall` → 冒烟、单眼闪 3 次熄灭 → 1.6 s 起自上而下消散，魂光上升。
