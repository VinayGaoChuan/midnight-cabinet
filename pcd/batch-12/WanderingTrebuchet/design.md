# 流浪投石机 WanderingTrebuchet

模块：`pcd/chars/WanderingTrebuchet.js`。身体不用现成骨架：高跷节肢、补丁平台、吊着的碎木片、A 字机架、晶簇配重、配重投臂、抛兜 + 巨石都是本模块自画的部件（函数前标了「// 候选部件」）。所有落笔都经过一个本地变换：站着时按 `sh` 逐行剪切（越高越往前歪，表现「摇摇欲坠」），倒地时整架按 90° 转（顶朝前、前沿贴地），部件照常画。
升级线：爬行投石车 → 流浪投石机，是**同一台机器长大了**：六条虫足长成四条细长高跷节肢（同一套紫黑甲壳、膝拱、骨白足尖）；木投臂 + 抛兜保留，变成配重投臂、高出机架 12 格；车尾的虚空石配重长成吊在机架里的一大块晶簇；木料被漂白、到处是补丁。

## 角色设定卡

- 名称 / 身份：流浪投石机，神话级的高跷攻城器械；射手，站得越歪、叫得越响，砸得越狠。
- 一句话剪影：**四条细长高跷节肢托着一座 A 字机架 + 超长投臂斜指后上方、末端垂着巨石 + 机架里吊着一簇发紫光的晶石**，整架向前歪。
- 尺寸：待机 30×46 格（高跷 16、平台 4、机架到转轴 31、投臂末端 44）。神话：同族最高，是爬行投石车高的 1.6 倍；巨型高跷器械档，头重脚轻。
- 材质色阶（色板下标）：
  - 漂白旧木 `bone` [8, 7, 6, 17]（平台 band 2，机架 / 投臂 band 1）；补丁木板 `wood` [0, 20, 19, 16]
  - 高跷节肢 `shadow` [0, 52, 53, 54]（远侧暗一级）；足尖 `bone`
  - 铁钉 / 转轴 `iron`；绳 `leather` [20, 19, 32, 33]
  - 巨石 [8, 10, 18, 17]；火焰巨石（发光体，平涂）[44, 45, 46, 47] + 白热芯 [46, 47, 51, 21]
  - 晶簇配重（发光体，平涂）`purple` [25, 42, 24, 43] + 最亮芯 [43, 43, 21, 21]
- 部件顺序（从后往前）：远侧 2 条高跷 → 平台（木板缝 + 两块补丁 + 螺钉 + 缠绳）→ 近侧 2 条高跷 → 吊着的碎木片 → A 字机架 → 晶簇配重 → 投臂 →（拉绳）→ 抛兜 → 巨石。
- 细节清单：
  - 「脸」：没有脸；发光体是晶簇（中间一根高、两侧矮的尖晶，3 档亮度 + 熄灭），晃得越歪越亮，3 档时出十字紫芒。
  - 「须 / 毛」对应物：抛兜巨石左右甩；平台下两根短绳吊着两片碎木，随步伐反向晃。
  - 「服装」对应物：平台木板缝、两块深色补丁木板 + 螺钉、缠绳；机架柱上补丁 + 缠绳 + 铁钉；投臂中段补丁。
  - 「手臂」：配重投臂 2 格粗，短端 5 格（吊晶簇）、长端 17 格，末端铁箍、转轴铁。
  - 「腿脚」：四条高跷节肢，近侧上段 2 格粗、膝拱过平台、小腿中段一个节、骨白足尖。
  - 武器：抛兜 + 4×4 巨石，点燃后成火焰巨石 + 火舌。
- 攻击方式：远程 **投**：投臂压到水平、配重升起（预兆 2 帧）→ 配重坠落、投臂甩向前上方（出手 1 帧，拖影弧，机架被反冲顶起 1 格、往后仰）→ 火焰巨石超高弧线 0.42 s 砸在假人身上。
- 差异化（对照爬行投石车和同组分配、已通过的 13 个角色）：
  - 体型档：巨型高跷器械（瘦高、头重脚轻、整体前倾），和爬行投石车的低矮多足、歼灭者 / 巨型歼灭者的反关节鸟腿机甲拉开（这里是木结构 + 节肢腿 + 机架）。
  - 识别特征（≥ 2 改轮廓）：①超长投臂高出机架 12 格 + 垂着的巨石（轮廓）②四条细长高跷（轮廓）③机架里吊着的发光晶簇（发光）④补丁、缠绳、吊着的碎木片（轮廓下沿）。
  - 武器 + 握法 + 攻击类型：配重投臂 · 投（重力配重，比爬行投石车的扭力甩更高的弧线）。
  - 动作个性：待机 = 整架吱嘎前后晃（剪切 0 → 2），1.6–2.0 s 猛一歪、掉下一片木板和一颗螺钉；步态 = 高跷蹒跚（对角两条一组大步迈，机身前后大幅摇摆，每步震屏 1 格 + 扬尘）；死亡 = 向前倾倒后散架（和爬行投石车的烧毁化灰拉开）。
  - 主色：漂白骨色旧木（爬行投石车是焦黑旧木），节肢和晶簇保留同线的紫黑 / 紫光。

## 特效设定卡
