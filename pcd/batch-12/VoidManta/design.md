# 虚空魔鬼鱼 VoidManta

模块：`pcd/chars/VoidManta.js`（查看 `pcd/view.html?c=VoidManta`）· 自检输出：`shots/`

## 角色设定卡

- 名称 / 身份：虚空魔鬼鱼，虚空族祭司，传说。曲速之翼长大后的样子：体型大一倍半，背上长出一片流动的星图，攻击从甩尾弹变成从腹下吐出会弹射的等离子盘。
- 一句话剪影：宽大的菱形魔鬼鱼，上下两片大鳍翼，头前一对向前抱拢的弯角，身后长尾挂三颗串珠。
- 尺寸：待机约 45×32 格（身体 23×8，翼展上下各约 11 格，尾长 14）；离地 12 格。体型档：巨型扁平飞行。
- 身体：和曲速之翼同一套自画部件（`// 候选部件：finWing`，这里翼缘画两道等离子线），身体更厚（半厚 4 格）。
- 材质色阶 [勾线, 暗, 基, 亮]：
  - 背（主材质）虚空品红紫 [25, 42, #9a3aa0, #d06fcf]，band 2。**我补的**：分配写的是 gem 色阶，但 gem 的基 / 亮是蓝 / 青（23 / 22），会和翼缘等离子青混成一片，读不出「品红紫」。所以保留 gem 的深紫 25 作勾线、暗 42，基 / 亮追加两个品红紫专属色（本角色专属色 2 个）。
  - 近侧鳍 [25, #9a3aa0, #d06fcf, 43]；远侧鳍 [25, 42, #9a3aa0, #d06fcf]；尾 同背
  - 背上星图：夜空底 [0, 1, 2, 3] + 星点（平涂 23 / 22 / 21）
  - 腹 [25, 18, 17, 21]；头鳍 purple [25, 42, 24, 43]（保留曲速之翼的头鳍色）
  - 翼缘等离子线 / 腹下等离子口 [25, 24, 22, 21]（平涂）；尾珠 [25, 23, 22, 21]；眼 [0, 24, 22, 21]
- 部件顺序（从后往前）：远侧鳍 → 远侧头鳍 → 长尾 → 三颗尾珠 → 身体（背、星图 + 星点、腹、眼、眉骨高光、嘴缝、腹下等离子口）→ 近侧鳍 → 近侧头鳍。
- 细节清单：青色眼 + 眉骨高光 + 3 格嘴缝；背上星图 8 颗星点（绕星图中心转、三相轮流闪）；白腹；腹下 3–5 格等离子口（合 / 开 / 吐三档）；两片鳍各两道鳍骨；翼缘两道等离子线（外道亮、内道暗一级，各分 5 段）；头鳍 10 格长、根部加厚、尖端往回抱；三颗尾珠（逐颗亮、爆闪、熄灭）。
- 攻击方式：远程射——抬头露出腹部（腹口打开）→ 出手帧腹口吐出一枚扁的等离子盘，身体往后一顿；盘打中假人后弹开往回上方飞走（「会在目标间弹射」）。
- 差异化：
  - 体型档：巨型扁平飞行（和曲速之翼同一体系但大一倍半、身体加厚；同组没有飞行体）。
  - 识别特征：① 上下两片大鳍翼 ② 头前一对 10 格长的前抱弯角 ③ 长尾三颗串珠 ④ 背上星图（轮廓内）——前三个改外轮廓。
  - 武器 + 握法 + 攻击类型：腹下等离子口 × 吐 × 射弹射盘，和曲速之翼的尾鞭甩弹不同。
  - 待机个性：环游——身体缓缓前后倾斜（6 档循环）、鳍慢扇，星点轮流闪、尾珠一颗颗亮；循环里抬头翻身一次，星图一齐亮、尾珠爆闪。
  - 步态：深海巡游——4 帧大幅扑翼，身体随之起伏 2 格、头一抬一低，不落地，身下等离子拖尾。
  - 死亡方式：内爆（和曲速之翼的翻面坠地不同）。
  - 主色：品红紫 + 夜空星图，同组没有品红紫主材质。
- 升级线：保留曲速之翼的头鳍（变长变弯）、长尾尾球（变三颗串珠）、翼缘等离子线（变两道）、白腹、青眼。

## 特效设定卡

- 元素色阶：等离子衰减 · 星辉青紫 magic = 白 21 → 青 22 → 蓝 23 → 紫 24 → 深紫 25；被削弱的假人用 plasmaDecay（22 → 23 → 24 → 25 → 1）；虚空点用 shadow 色阶最暗一级（墨 0）。
- 攻击：预兆（2 帧抬头、腹口打开、头鳍抱紧）/ 出手（腹口吐 → 5 格白芯等离子盘，腹下 7 颗火花）/ 弹道（扁盘一宽一斜地转，150 格/秒）/ 命中（8 颗外爆 + 4 颗下沉粒子 + 假人小摇，盘弹开往回上方飞走、落点 5 颗小火花）。
- 技能「等离子衰减（弹射版）」：
  - 蓄力 1.4 s：背上星图开始旋转（前 0.7 s 慢、之后快），星点全亮；星尘从四周定点汇聚到腹下等离子口；三颗尾珠在 0.3 / 0.6 / 0.9 s 依次亮起，最后 0.25 s 爆闪；翼缘等离子线每 0.2 s 亮一段白热；鳍抬起后发抖；轮廓光 2 档（光源在腹口）+ 地面映光。
  - 施放 0.5 s：鳍张到最大、腹口全开，汇聚的星尘外爆 + 小冲击环；吐出一枚等离子盘，沿「腹下 → 假人胸 → 地面 → 假人腰 → 地面 → 假人腿 → 弹开飞走」来回弹射 3 次，每段留 6 格拖尾；震屏 2 格 + 天空闪白；尾珠旁十字星芒。
  - 命中（施放 +0.14 / 0.28 / 0.42 s）：每打中一次假人闪白大摇 + 12 颗外爆 + 震屏 1 格，身上压一圈紫环（从上往下 3 圈叠在一起，后半圈在假人后面、前半圈在前面，第 1 帧白、之后紫，1.3 s 后闪烁消失）；第一下起假人被染成暗一级的等离子色 1.6 s、摇晃变慢，下沉粒子比曲速之翼更密；两次落地各 6 颗火花 + 4 颗尘。
  - 收招 0.7 s：星图停转，尾珠 3 → 0 一颗颗暗回，腹口合上，翼缘回到常亮。
- 移动：不落地；每秒 10 颗等离子拖尾从腹下往后飘。
- 受击：引擎 impact 火花 + 白色剪影 1 帧 + 击退 2 格；闭眼、鳍猛扬、尾巴下甩、头鳍张开，尾珠熄灭。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 腹下裂开一个墨色虚空点（外圈紫青转动）、身体僵住发抖、鳍垂下 → 翼缘等离子线一段段熄灭，身体从离虚空点最远的翼缘开始按抖动碎掉，碎掉的地方化成星尘螺旋着被吸进虚空点（1.4 s）→ 虚空点越缩越小 → 最后一闪（十字星芒 + 小冲击环 + 天空闪白）消失。
- 音色：深空鲸歌般的低鸣 + 等离子盘弹射的「咻—咻—咻」，重量 0.7。SFX 声明 `{ body: 'beast', how: 'dissolve', pal: 'arcane', style: 'spiral', w: 0.7, hover: 1 }`；出手帧 swing（throw）+ shoot（orb），盘到达 hit（magic），技能每打中假人一次 impact（共 3 次）。
