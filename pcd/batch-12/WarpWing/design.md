# 曲速之翼 WarpWing

模块：`pcd/chars/WarpWing.js`（查看 `pcd/view.html?c=WarpWing`）· 自检输出：`shots/`

## 角色设定卡

- 名称 / 身份：曲速之翼，虚空族祭司，优质。一只小型的虚空魔鬼鱼，靠翼缘的等离子光削弱周围敌人（祭司 = 削弱型的施法者，身体扁薄、没有护甲，读得出「脆」）。
- 一句话剪影：扁菱形身体 + 一上一下两片宽三角鳍翼，头前一对向前卷的角，身后一条长鞭尾，尾尖一颗亮球。
- 尺寸：待机约 32×22 格（身体 15×6，翼展上下各约 8 格，尾长 11）；离地 10 格滑翔，没有腿。体型档：小型扁平飞行。
- 身体：自画部件。3/4 俯视的魔鬼鱼：近侧鳍平展时伸向镜头（画面下方）、远侧鳍伸向画面上方，扑翼时两片鳍的翼尖按仰角上下移动。库里的 `B.wing` 没有鳍翼，本轮部件库冻结，鳍翼写在模块里（`// 候选部件：finWing`，参数：翼根前后点、仰角、翼展、后掠、后缘滞后、等离子线条数）。
- 材质色阶 [勾线, 暗, 基, 亮]：
  - 背（主材质）天青 sky [39, 40, 41, 23]，band 2
  - 近侧鳍 [39, 41, 23, 60]（比背亮一级，离开背后山影也看得见）；远侧鳍 [39, 40, 41, 23]
  - 腹 淡白 [39, 18, 17, 21]（勾线换成深蓝，免得白腹下面出现暖灰线）
  - 头鳍 purple [25, 42, 24, 43]，远侧暗一级
  - 翼缘等离子线 [25, 24, 22, 21]（平涂，手工色调：熄灭 25 / 暗 24 / 常亮青 22 / 白热 21）；尾球 [25, 23, 22, 21]；眼 [0, 24, 22, 21]
- 部件顺序（从后往前）：远侧鳍 → 远侧头鳍 → 长尾 + 尾球（拖在身后时）→ 身体（背、腹、眼、嘴缝）→ 近侧鳍 → 近侧头鳍 → 长尾 + 尾球（后引 / 前甩时换到最前）。倒地时身体和头鳍绕中线上下翻（肚子朝上），鳍摊在地上。
- 细节清单：青色眼 + 嘴缝；背脊高光行 + 两道暗纹；白腹一行；两片鳍各一道暗色鳍骨；翼缘等离子线分 5 段（逐段亮 / 灭）；头鳍根 2 格厚、尖端下卷；尾根 2 格粗渐细；尾球 5 档（暗 / 亮 / 大 / 爆闪 / 熄灭）。
- 攻击方式：远程施法——尾鞭后引上翘（尾球变大）→ 出手帧尾巴从上方往前一甩，尾球爆闪，甩出一颗等离子弹。
- 差异化：
  - 体型档：小型扁平飞行（已通过角色里没有飞行体；同组都是四足兽、人形、蟹、机械）。
  - 识别特征：① 上下两片宽三角鳍翼（最大的外轮廓）② 身后 11 格长鞭尾 + 尾球 ③ 头前一对前卷的角状头鳍——三样都改外轮廓。
  - 武器 + 握法 + 攻击类型：尾鞭（身体的一部分）× 甩 × 施法弹，同组没有。
  - 待机个性：慢扇——鳍翼缓慢起伏、长尾 S 形摆、尾球一明一灭；循环里抬尾看尾球一次（头鳍卷紧、尾球亮一下）。
  - 步态：波浪滑翔——4 帧扑翼（高扬 → 平展 → 最低 → 回收时后缘滞后），身体起伏 1 格，不落地，身下 1–2 颗等离子拖尾。
  - 死亡方式：翻面坠地。
  - 主色：天青 + 白腹 + 青色翼缘，与同组的白熊、黑熊、白桦、蓝黑狼、紫绸、酒红、墨蓝、墨黑、珊瑚、岩灰、钢蓝、黄铜、军绿、焦铁、暗红、焦木、漂白木都不同。
- 升级线：虚空魔鬼鱼保留头鳍、长尾尾球（变三颗串珠）、翼缘等离子线（变两道），体型放大一倍半。

## 特效设定卡

- 元素色阶：等离子衰减 · 星辉青紫 magic = 白 21 → 青 22 → 蓝 23 → 紫 24 → 深紫 25。被削弱的假人用同一色阶往暗端挪一级的 plasmaDecay（22 → 23 → 24 → 25 → 1），只借色板里的颜色。
- 攻击：预兆（2 帧尾巴后引上翘、头抬、尾球 1 → 2 档）/ 出手（尾巴前甩定格 1 帧，尾球爆闪，尾根处一道弧形拖影 2 帧，尾球处十字枪口光 2 帧）/ 弹道（2×2 白芯 + 青晕 + 上下跳的电火花，170 格/秒）/ 命中（8 颗外爆 + 3 颗往下沉的等离子粒子，假人小摇）。
- 技能「等离子衰减」：
  - 蓄力 1.4 s：两片鳍抬起（最后 0.3 s 发抖），翼缘等离子线从翼根到翼尖每 0.2 s 亮一段白热；尾球 1 → 2 → 大 / 爆闪交替；星辉粒子螺旋汇聚到尾球；身下地面浮现一圈旋转的点阵光环（半径 4 → 14）；轮廓光 2 档 + 地面映光。
  - 施放 0.5 s：鳍张到最大，翼缘全白，汇聚粒子外爆 + 24 颗新粒子 + 小冲击环；一圈扁椭圆的等离子光环从身体向外扩散（断续点阵，内外两圈，后半圈在角色 / 假人后面、前半圈在前面，颜色白 → 青 → 蓝 → 紫）；震屏 2 格 + 天空闪白。
  - 命中（施放 +0.28 s，光环扫过假人）：假人闪白大摇，之后被染成暗一级的等离子色 1.3 s、摇晃放慢一半（伤害被削弱），身上 1 秒内持续冒出往下沉的等离子粒子（第 3–5 级）；震屏 1 格。
  - 收招 0.7 s：鳍收回，翼缘白热 → 回到常亮青，尾球 2 → 1，地面光环断续熄灭。
- 移动：不落地；每秒 9 颗等离子拖尾从身下往后下方飘。
- 受击：引擎 impact 火花 + 白色剪影 1 帧 + 击退 2 格；闭眼，鳍猛地扬起，尾巴往下甩，头鳍张开；尾球熄灭。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 鳍扬起、尾球闪 → 失去浮力翻滚坠落（半路翻成肚子朝上，离地 10 → 0）→ 落地 10 颗尘 + 6 颗等离子火花 + 震屏 1 格 → 鳍抽两下 → 翼缘等离子线从翼尖往里一段段熄灭、尾球闪两下熄灭 → 1.6 s 起自上而下消散，星辉粒子（星尘）往上飘。
- 音色：滑翔的空气低啸 + 等离子的电流嗡嗡 + 尾鞭一声脆「啪」，重量 0.3。SFX 声明 `{ body: 'beast', how: 'topple', pal: 'arcane', style: 'nova', w: 0.3, hover: 1 }`；出手帧 swing（throw）+ shoot（orb），弹道到达 hit（magic），光环扫到假人 impact，落地 fall。
