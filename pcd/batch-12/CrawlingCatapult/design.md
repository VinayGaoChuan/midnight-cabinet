# 爬行投石车 CrawlingCatapult

模块：`pcd/chars/CrawlingCatapult.js`。身体不用现成骨架：节肢虫足、木车架、虚空石配重、铁绞盘 + 绞索、投石臂、抛兜、石弹都是本模块自画的部件（函数前标了「// 候选部件」），画笔借 `parts.beast.util`（seg / dot）。
升级线：爬行投石车 → 流浪投石机。保留给下一级的识别特征：木投臂 + 抛兜、紫黑节肢腿（升级后长成高跷）、车尾虚空石配重（升级后长成吊着的晶簇）。

## 角色设定卡

- 名称 / 身份：爬行投石车，虚空里爬出来的活体攻城器械；射手（后排远程、很脆）。
- 一句话剪影：**低矮木车架 + 六条紫黑虫足拱过车顶（蜘蛛式膝拱）+ 投臂斜伸向后上方、末端抛兜垂着一颗石弹 + 车尾一块发紫光的尖晶配重**。
- 尺寸：待机 36×29 格（车架 24×7、虫足脚展 32、投臂末端离地 26、抛兜石弹最高 27）。史诗：比同族人形矮、宽一倍，低重心多足器械档。
- 材质色阶（色板下标）：
  - 焦黑旧木车架 `wood` [0, 20, 19, 16]（band 2）；投臂 `wood` band 1；烧焦一 / 二档 [0, 0, 20, 19] / [0, 0, 0, 20]（死亡用）
  - 虫足甲壳 `shadow` [0, 52, 53, 54]（远侧暗一级 [0, 52, 52, 53]）；足尖 `bone`
  - 铁箍 / 绞盘 / 转轴 `iron` [0, 27, 28, 29]；绞索、抛兜 `leather` [20, 19, 32, 33]
  - 石弹 `pale` [8, 59, 60, 17]；燃石（发光体，平涂）[44, 45, 46, 47] + 白热芯 [46, 47, 51, 21]
  - 虚空石配重（发光体，平涂）`purple` [25, 42, 24, 43] + 最亮芯 [43, 43, 21, 21]
- 部件顺序（从后往前）：远侧 3 条虫足 → 车架（木板 + 铁箍 + 转轴座）→ 配重 → 近侧 3 条虫足 → 绞盘 + 绞索 → 投臂 → 抛兜 → 石弹。
- 细节清单：
  - 「脸」：没有脸；发光体是车尾的虚空晶石（3 档亮度 + 熄灭档），轮廓光在待机时从配重打紫边，技能时从燃石打火边。
  - 「须 / 毛」对应物：抛兜垂在投臂末端，待机 / 移动时左右甩；虫足膝节高光。
  - 「服装」对应物：车架两道木板缝（每 7 格断一次）、两道铁箍 + 铆钉、4 处烧焦斑、顶上铁转轴座。
  - 「手臂」：投石臂 2 格粗，短尾 3 格、长端 14 格，末端铁箍，转轴 1 格铁；绷紧时一根绞索从绞盘顶拉到投臂。
  - 「腿脚」：六条节肢虫足，近侧上段 2 格粗，前后两条膝拱过车顶，足尖骨白。
  - 武器：抛兜 + 石弹（3×3），点燃后成燃石 + 火舌；绞盘 4 根辐条 + 摇把，每档转 45°。
- 攻击方式：远程 **投**：绞盘咔咔后压投臂（预兆 2 帧）→ 投臂猛甩到竖直、抛兜甩出（出手 1 帧，拖影弧）→ 燃石高抛物线 0.4 s 落到假人身上。
- 差异化（对照同组分配的熊 / 狼 / 蟹 / 机甲 / 旋翼 / 飞行鳍翼 / 反关节机甲，以及已通过的 13 个角色）：
  - 体型档：低矮多足器械（全库唯一的「车 + 六足」），比蟹术士宽、没有壳；和歼灭者（两条鸟腿托弩身）完全不同的腿型。
  - 识别特征（≥ 2 改轮廓）：①投臂 + 抛兜斜伸出车身后上方（轮廓）②六条拱过车顶的虫足（轮廓）③车尾尖晶配重（轮廓，发光）④车侧铁绞盘（内部）。
  - 武器 + 握法 + 攻击类型：机械投臂 · 投（扭力弹射、高抛物线）；同组没有第二个「投」。
  - 动作个性：待机 = 虫足轮流轻踏、抛兜晃，1.6–2.0 s 绞盘自己咔哒一下、投臂一沉；步态 = 极慢爬行（每帧只抬一条腿，四帧一轮，演示只走 8 格）；死亡 = 烧毁化灰（同组无）。
  - 主色：焦黑旧木 + 紫黑甲壳 + 紫光配重；和机甲的钢灰 / 铁黑拉开。
  - 特效：火焰 + 瞄准点（从近到远亮起）+ 高抛燃石 + 地裂碎石，和同组火焰箭（歼灭者，直射）拉开：这里是抛物线 + 落点标记。
  - 自动查重：`compare.mjs` 对 reference + accepted 退出码 0（最高待机 IoU 0.455）。

## 特效设定卡

- 元素：火炮 · 燃石，色阶 `fire` = 21 白 → 47 淡黄 → 46 橙 → 45 红 → 44 深红；落地碎石 `earth`；配重轮廓光 `curse` 紫。
- 攻击「燃石高抛」
  - 预兆：2 帧，绞盘转两档、绞索绷紧、投臂压到 2:1、石弹点起小火、车身压低 1 格。
  - 出手：投臂甩到竖直定格 1 帧，车身反冲抬 1 格，身后投臂拖影弧（2 帧），抛兜甩直。
  - 弹道：2×2 燃石 + 闪烁火舌，每 2 步 1 颗火尾，高抛物线（顶点比出手点高约 20 格）。
  - 命中：12 颗火花外爆 + 5 颗碎石落地弹，假人闪白小摇。
- 技能「火炮：目标越远，砸得越狠」
  - 蓄力 1.4 s：绞盘每帧转一档、投臂 0.7 s 内缓缓压到水平，绞索绷直；0.35 s 石弹点燃（1 档）、0.8 s 后 1 / 2 档逐帧闪 + 十字火芒；地面从近到远在 0.35 / 0.7 / 1.05 s 依次亮起 3 个瞄准点（越远越大越亮，最远的在假人脚下、两侧竖刻度闪烁）；火星螺旋汇进石弹；轮廓光 2 档（火）。
  - 施放 0.5 s：投臂猛甩过竖直，车身被反冲抬起 2 格；身后一道从水平到前 1:2 的投臂拖影弧；燃石（4×4 白热芯）以极高抛物线飞出（顶点高出约 35 格）；汇聚火星外爆 + 小冲击环 + 反冲扬尘；震屏 2 格、天空闪白。
  - 命中（施放后 0.34 s）：燃石砸在最远的瞄准点——34 颗火焰外爆 + 大冲击环（比攻击大一档）+ 十字星芒 + 左右两道地裂 + 14 颗碎石四溅；假人闪白大摇 + 击退 + 染成火色 0.9 s；震屏 1 格；瞄准点熄灭。
  - 收招 0.7 s：投臂摆回 45°，抛兜 0.5 s 后重新装上石弹，虫足轮流重新抓地。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 投臂向后一震、抛兜反甩、配重熄一下；12 颗 impact + 6 颗木屑（earth）+ 4 颗紫甲壳屑；震屏 1 格。
- 死亡（烧毁化灰）：26 颗火花 + 震屏 2 格 + 天空闪白 → 虫足一齐软塌（0.3 s）→ 绳索绷断、投臂翻着飞到车后落地（0.5–0.8 s）→ 虫足摊平、车架落地（离地 3 → 1 → 0，尘土 16 颗 + 震屏 1 格 + `fall`）→ 车架上窜火舌、火星，木头烧焦两档，配重闪几下熄灭 → 1.6 s 化灰（死亡套件 `ash`，灰色粒子飘走）→ 紫色魂光上升。
- 音色：绞盘棘轮咔咔 + 虫足窸窣 + 投臂甩出的一声「嘭」，重量 0.7（`SFX: body machine · how collapse · pal fire · style fire · w 0.7`；步态 step w 0.5，攻击 swing throw + shoot stone + hit stone，技能 shoot fire + impact fire，倒地 fall w 0.6）。
