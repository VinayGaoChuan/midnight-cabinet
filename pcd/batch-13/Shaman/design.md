## 角色设定卡

- 名称 / 身份：萨满，野兽族敌人，史诗，远程施法者。按分配做成山魈萨满：野兽基调（长毛、长尾、兽吻），职能是给友军上「嗜血」加攻速，所以法器是一根血光牛颅图腾杖。
- 一句话剪影：瘦高挺直、长臂垂到膝下的山魈，头顶一圈竖起的血红羽冠，单手拄一根比自己还高的牛颅图腾杖，身后一条长尾高高翘起卷个弯、尾尖挂一只小红葫芦。
- 尺寸：待机约 30×39 格（身体 25 格 + 羽冠 5 格；图腾杖顶的牛颅再高出 8 格；长尾往后伸 10 格）。体型档：瘦高长臂（slim：腿 10、躯干 8、头 7、臂长 12，头身比约 5.5）。
- 身体：`parts.rig slim` + `legs bare` + `torso bare`（缠腰布 + 腰绳）+ `mantle fur`（肩背长毛）+ `arm bare`；自画部件都标了 `// 候选部件`：`mandrillHead` 山魈头、`featherCrest` 羽冠、`monkeyTail` 长尾 + 小葫芦、`totemStaff` 杖身、`bullSkull` 杖顶牛头骨（眼窝发光体）、`clothStrips` 牛角上的红布条。
- 材质色阶 [勾线, 暗, 基, 亮]：
  - 主材质 深巧克力褐长毛 [0, #2a160c, 20, 19]（本角色唯一的专属色 #2a160c），远侧暗一级；肩背长毛 [0, 20, 19, 32]
  - 脸：鼻梁 crimson [11, 12, 13, 26]、两颊 blue [0, 39, 40, 41]；眼 金 [0, 0, 14, 5]
  - 羽冠 blood [55, 56, 57, 58]；手脚 墨灰 [0, 0, 27, 28]
  - 图腾杖 wood [0, 20, 19, 16] + 缠绳 leather；牛头骨 bone [8, 7, 6, 17]；红布条 / 缠腰布 / 尾葫芦 crimson
  - 牛骨眼窝（发光体，平涂）[55, 56, 57, 58] / 蓄满 [57, 58, 21, 21]
- 部件顺序（从后往前）：长尾 → 尾葫芦 → 后臂（长臂垂到膝下）→ 两腿 → 躯干（缠腰布）→ 肩背长毛 → 山魈头 → 羽冠 → 杖身 → 牛头骨 → 红布条 → 前臂 + 手（握在杖身上）。
- 细节清单：脸——重眉骨高光、金眼 + 眼窝暗影、红鼻梁往前伸 3 格、红鼻孔尖、两颊蓝底带三道竖纹、下巴一撮亮毛、耳、脑后长毛；羽冠 4 根扇形张开、羽尖亮、随动作摆；肩背长毛锯齿下摆；胸肌 / 腹线、缠腰布、腰绳；手脚墨灰；杖身两道缠绳；牛头骨额顶高光、鼻梁、两鼻孔、外弯上翘的牛角、眼窝 5 档亮度（待机偶尔一亮 / 蓄力 1–2 档闪 / 施放粉白 / 死亡熄灭）；红布条 4 档飘动相位；尾巴顶端卷弯、葫芦挂绳 + 高光。
- 攻击方式：远程施法——杖往后一引（2 帧）→ 出手帧杖向前一点、牛颅对准目标，眼窝射出一颗血色光珠（杖头十字枪口光 2 帧）。
- 差异化：
  - 体型档：瘦高长臂挺直（和野人祭司的佝偻、鹿颅面具拉开：身板挺直、露出本脸；和蜥蜴兵拉开：长臂、羽冠、图腾杖、尾巴翘起而不是贴地）。

  - 主色：深巧克力褐长毛 + 红蓝脸 + 血红羽冠。

## 特效设定卡

- 元素色阶：嗜血 · 猩红 FXI.blood = 白 21 → 淡粉 58 → 红 57 → 暗红 56 → 酒红 55。
- 攻击「血珠」：预兆（杖后引、眼窝 1 档）/ 出手（杖向前一点定格，眼窝 3 档，杖头十字光 2 帧 + 6 颗火花）/ 弹道（默认小弹，血色，170 格/秒）/ 命中（10 颗外爆 + 十字光，假人小摇）。
- 技能「嗜血」（给一名友军攻速 +50%）：
  - 蓄力 1.4 s：杖举过头（后手也抬起），眼窝血光 1 → 2 档逐帧闪；血滴从脚下地面螺旋汇聚到杖顶牛颅并绕着转；红布条狂舞（每帧换相位）；羽冠被吹向后、尾巴抖；脚下暗红法阵（fx.circle blood，转动）；轮廓光 2 档 + 地面映光；最后 0.3 s 杖抖。
  - 施放 0.5 s：杖斜指身前的友军（ALLIES 'skill'，友军站在 x 72 和 14），眼窝粉白；血线从牛颅连到友军胸口（自画，跟着杖头走满整个施放段 0.5 s，虚线往友军方向流、一颗白珠顺线跑过去）+ 杖头十字星芒；友军脚下血环外爆（冲击环 + 18 颗外爆）；只有被点中的那一名友军（ALLY_X[0]）描 1 格血边（自画遮罩 + outlineSprite，不染色，头盔和长矛照常可见，持续到收招结束，最后 0.25 s 隔帧闪），另一名保持原样；这名友军头顶循环飘起 3 个上升的血色「»」（错开 1/3 周期，任何时刻三个都在）；震屏 2 格 + 天空闪白。
  - 命中（施放 +0.2 / +0.32 s）：友军身前快速两道血色挥砍弧（一上一下，加速的样子），各 6 颗火花；肩头持续冒红蒸汽（一直冒到收招结束）；第一下震屏 1 格。
  - 收招 0.7 s：血线从友军端断开、0.3 s 内回缩到杖头；杖放下；眼窝 2 → 1 → 0。
- 移动：每步杖点地 + 脚下各 1 颗尘土。
- 受击：引擎 impact 火花 + 白色剪影 1 帧 + 击退 2 格；闭眼、羽冠和尾巴反向甩、布条甩起。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 腿软下蹲（眼窝闪）→ 瘫坐：两腿往前伸、膝盖拱起，头垂下，后手软垂在地上，杖脚抵在身前地上、杖身斜靠在肩上、牛颅落在头侧，尾巴盘在身后，羽冠只剩两根、两根掉在脚边（坐倒两帧下落）→ 落地尘土 12 颗 + 震屏 1 格 → 眼窝闪烁熄灭 → 自上而下消散，同时血雾（blood 色阶上升粒子）从身上往上飘。复活用 blood 色阶汇聚。
- 音色：骨铃叮当 + 杖头顿地如手鼓，标志性一声是一声高亢的猴啸战吼，重量 0.45。SFX 声明 `{ body: 'beast', how: 'collapse', pal: 'blood', style: 'buff', w: 0.45 }`；步态接触帧 step（0.45）、出手帧 swing（staff）+ shoot（orb）、光珠到达 hit（magic）、友军第一下挥砍 impact（blood）、坐倒 fall（0.45）。
