# 女巫（Witch）

## 角色设定卡

- 名称 / 身份：女巫，蟾蜍头的沼泽女巫（敌人，稀有，远程召唤者）。用长汤勺舀蛙卵，蛙卵落进泥沼就孵出蛙人。
- 一句话剪影：歪折的高尖帽（帽尖折向后下垂，上面蹲一只小青蛙）+ 宽扁蟾蜍头下鼓起的淡黄喉囊 + 伸出身前的长柄木汤勺（勺里一团发光蛙卵）。
- 尺寸：待机外框约 25×36 格（身体约 24 格，含帽和帽尖青蛙 36 格），头身比约 5。
- 体型档：高挑长袍档（parts.rig tall 改：leg 9 · torso 8 · head 5 / headW 7 · sw 3 · arm 9）；细长身体裹在拖地长袍里看不见脚，头是宽扁的蟾蜍头。和寡妇 widow 拉开：尖帽不是宽檐、没有裙撑、手持长勺；和星辉巫师拉开：没有胡子和杖头宝石，帽子歪折且更矮，武器是汤勺。
- 材质色阶（[勾线, 暗, 基, 亮]，全部取自共享色板）：
  - 沼泽墨绿长袍 moss [0, 34, 35, 36]（band 2，面积最大）
  - 蟾蜍皮（绿偏黄）[48, 36, 37, 38]；疣点（平涂）poison [48, 49, 50, 38]
  - 喉囊 sand [20, 61, 62, 5]
  - 尖帽 purple [25, 42, 24, 43]；帽带 poison [48, 49, 50, 38]；袖口 purple
  - 长勺 wood [0, 20, 19, 16]；麻绳腰带 sand；腰后皮袋 / 背后补丁 leather [20, 19, 32, 33]
  - 眼（平涂）[20, 19, 14, 5] + 墨色横瞳；口腔 pink
  - 蛙卵（平涂发光体）[48, 50, 38, 21]：5 档（待机 / 蓄力 / 蓄满 / 施放 / 熄灭）
- 部件顺序（从后往前）：后臂（喇叭袖 + 蛙手）→ 拖地长袍（褶、腰带、皮袋、补丁同一部件）→ 蟾蜍头 → 歪尖帽 → 帽尖小青蛙 → 蛙卵长勺 → 前臂（喇叭袖 + 紫袖口）→ 喉囊 → 前手（压在勺杆上）。死亡时：沉下去的身体 → 泥沼 → 掉落的帽子 → 小青蛙。
- 细节清单：
  - 脸：头顶前方鼓出的金色大眼（墨色横瞳 + 眼睑亮点）、后面一只远眼鼓包、通宽大嘴线（嘴角下弯）、鼻孔、背上 4 颗疣点；张嘴时下颚掉 1 行露出粉色口腔。
  - 喉囊：4 档（小鼓包 → 胀到最大多鼓出 2 格），左上 1 格高光。
  - 帽：宽帽檐 + 荧绿帽带（两个亮点）、帽身逐行收窄后倾并在中段折一下、两处褶、帽尖向后下垂（随动作甩动 −1..2 档），帽尖蹲一只 4×2 小青蛙（金眼）。
  - 袍：肩下逐行外扩、下摆拖地成波浪（后摆多拖 1–2 格）、前后两道褶、麻绳腰带 + 绳结垂头、腰后小皮袋、背后补丁 + 缝线；喇叭袖 + 紫袖口。
  - 长勺：1 格木杆、杆尾亮点、4×2 小木碗（碗口朝上），碗里 3–4 格荧绿蛙卵（甩出后变空碗，0.6 s 后又盛满）。
- 攻击方式：远程投掷（长勺一舀一甩，把一团蛙卵甩成抛物线砸向目标）。站位 HX 34。
- 差异化：
  - 体型档：高挑长袍（同组人形有矮墩鼹鼠、标准女炮手、佝偻隐士、瘦高山魈、巨型食人魔、细肢恶鬼、孩童小恶魔；本角色是唯一看不见脚的长袍档）。
  - 识别特征：①歪折高尖帽 + 帽尖青蛙（外轮廓，高出头 8 格以上）②喉囊（外轮廓，胀大时多鼓 2 格）③蛙卵长勺（外轮廓，勺头伸出身前 5 格以上）④蟾蜍鼓眼（外轮廓头顶小鼓包）。
  - 武器 + 握法 + 攻击类型：长勺 · 单手 · 投（抛物线蛙卵团）；同组投掷只有隐士（屈指弹种子）和蜥蜴人（过肩投枪），握法和弹道都不同。
  - 待机个性：搅锅——长勺在身前绕小圈虚空搅动（4 个位置每 0.3 s 一换），1.6–2.0 s 喉囊一鼓一鼓，最后张嘴「呱」一下、眨眼。
  - 步态：拖袍滑步——袍下不见脚，下摆波纹每帧前移 1 格（4 个相位），身体起伏 1 格、下摆左右拖摆、帽尖反向甩；落「脚」时后摆带起 1 颗泥点。
  - 死亡方式：融化成沼（同组没有融化）。
  - 主色：沼泽墨绿袍 + 黄绿蟾皮 + 紫帽，和寡妇的黑裙桃红、巫师的蓝紫袍拉开。
  - 与衍生单位蛙人的呼应：召出的蛙人同款紫尖帽 + 荧绿帽带、同色疣点蛙皮，像她的小徒弟。

## 特效设定卡

- 元素：召唤 · 沼泽毒绿，色阶 FXI.poison = 21 白 → 50 淡黄绿 → 49 黄绿 → 48 绿 → 34 墨绿；泥点 / 泥泡用自建 witchMud = 38 → 36 → 35 → 34 → 0（通用溅液）。
- 攻击「甩卵」：
  - 预兆：长勺往身后下方一舀（勺头甩到身后），蛙卵亮一档。
  - 出手：长勺扬到前上方定格，勺头拖影弧 2 帧，勺里变空；甩出一团 3×3 荧绿卵团（白芯，130 格/秒，抛高 12 格的抛物线，身后洒出拖尾光点）。
  - 命中：12 颗毒绿火花 + 6 颗泥点溅落，目标闪白小摇。
- 技能「召唤蛙人」：
  - 蓄力 1.4 s：长勺插地搅动（手和勺角逐帧晃），身前 27 格处浮出三层冒泡的泥沼法阵（外 / 中 / 内三圈椭圆点阵反向转动 + 随机泥泡点）；0.3 s 起蛙卵一颗颗（每秒 7 颗，2×2）沿抛物线从勺里飞进法阵中心；泥泡不断从法阵上冒；喉囊 0 → 3 档胀到最大；蛙卵 1/2 档逐帧闪 + 勺边小十字；轮廓光 2 档、地面映光。
  - 施放 0.5 s：喉囊一收、张嘴「呱」、身体后仰、帽尖甩起；法阵中心泥浆外爆（毒绿 24 颗 + 泥点 14 颗）+ 大冲击环；震屏 2 格、天空闪白；一只小蛙人（9×11 剪影：紫尖帽 + 荧绿帽带、嫩绿蛙皮 + 疣点、奶白肚、金眼）从泥里跳出，0.3 s 抛物线（高 16 格）往前落地。
  - 命中（施放 0.3 s，蛙人落地）：溅起 16 颗绿泥点（K_PHYS，落地贴住走完色阶）+ 5 颗尘土，震屏 1 格。
  - 收招 0.7 s：法阵由外往里逐点熄灭（外圈 → 中圈 → 内圈，每圈 0.2 s）；帽尖小青蛙跳一下（抬起 3 格 → 1 格 → 落回）；蛙人蹲着，最后按抖动淡出；蛙卵 2 → 1 → 0。
- 受击：布、肉——引擎 impact 16 颗 + 白色剪影 1 帧 + 击退 2 格 + 闭眼、喉囊一鼓、下摆和帽尖反向甩；震屏 1 格。
- 死亡：来袭命中闪白（蛙卵闪烁）→ 踉跄下蹲 → 整具身体往地下沉（0.36 s 内沉 28 格，按地面截断），脚下泥沼从半宽 5 格扩到 12 格 → 0.45 s 尖帽脱开、自己往下落 → 0.66 s 帽子落在泥沼上弹一下立住（10 颗泥点溅起、震屏 1 格）→ 帽尖小青蛙三跳跳出画面 → 泥沼冒泡（泡点 4 相位）、毒绿光点蒸发上升 → 1.6–2.4 s 自上而下抖动消散，蒸汽里混入魂光。
