模块：`pcd/chars/Needler.js`（查看 `pcd/view.html?c=Needler`）· 自检输出：`shots/`

## 角色设定卡

- 名称 / 身份：针刺者，野兽雇佣兵射手，史诗。一只背上长满长针的刺鼠：红巾、黄铜单片瞄准镜、斜挎弹带，把自己背上的针当子弹打出去；「急速射击」读成：每打一针，针刺就多充一层电、射得越来越快。
- 一句话剪影：低伏弓背的四足，背上一整扇竖起的骨白黑尖长针（射击时整扇前倾像一排炮管）；尖吻上一截黄铜瞄准镜，额前红巾两根飘带往后飞。
- 尺寸：待机约 38×27 格（身长 11、腿 4、背刺扇占身体上半约 60%，针尖伸出背线 7–11 格）；远程站位 HX 34。体型档：低伏弓背四足（像一只加长的刺猬）。
- 身体：`B.quad`（rat 头放大到 w 7 · h 6 · snout 4 · snH 3.5、foot claw、tail stub、fur 0、rump 5、hump 2、neckA 0.75）；背刺、刺皮、红巾、瞄准镜、弹带、蜷成的刺球是本模块自画部件（`// 候选部件：`：`quill` 单根长针、`quillFan` 两层背刺扇、`quillCoat` 刺皮、`bandana` 头巾、`scopeMonocle` 单片瞄准镜、`bandolier` 斜挎弹带、`quillBall` 刺球）。库里的 `ridge` 背刺是 2 格粗的均匀鬃刺、不能单独前倾 / 充电 / 脱落，所以自画。
- 材质色阶 [勾线, 暗, 基, 亮]：
  - 身体 沙褐往暗一段 [20, 19, 61, 62]（躯干 band 2，四肢 band 1，远侧暗一级；亮色留给刺、刺尖和镜片）；腹线 bone
  - 背刺（主材质，面积最大）前层 bone [8, 7, 6, 17]、后层暗一级 [8, 8, 7, 6] + ink 黑尖 / 黑环；充电刺平涂 [23, 22, 51, 21]。待机帧骨白 + 墨色像素约 286、身体沙褐约 240
  - 红巾 crimson [11, 12, 13, 26]；弹带 深棕带芯 + 浅皮边 [0, 20, 20, 32]、铜扣、弹带上的备用针 bone
  - 瞄准镜 黄铜 [0, 28, 14, 5]（墨色勾线、铁色暗部）+ 铁箍 iron [0, 27, 28, 29]；镜片平涂 [0, 19, 51, 21]（发光体 51 / 21，4 档：暗 / 常亮 / 闪 / 爆闪）
  - 眼 金豆眼、鼻 ink、爪 bone
- 部件顺序（从后往前）：远侧两腿 → 短尾 → 躯干 → 背刺扇（一个部件：后层 7 根 → 刺皮盖住整条背线和躯干上缘 3–4 格 → 前层 8 根）→ 近侧两腿 → 斜挎弹带（压在近侧前腿上，尾端垂在两前腿之间）→ 头（rat 头 + 圆耳）→ 红巾（额带 + 脑后结 + 两根飘带）→ 黄铜瞄准镜（目镜 + 横筒 + 镜片，单独部件，和头之间有分界线）。
- 细节清单：眼（被目镜罩住，发光）、鼻头、圆耳、张嘴露牙；红巾两行额带（眼睛上方、横过额头到脑后）+ 结 + 两根往后伸出头部轮廓 4 格的飘带（错开 1/4 相位摆，受击往上往前甩）；瞄准镜：眼上一格起、沿吻部上方前伸的 2 格高黄铜横筒（两道铁箍、顶上隔格高光），伸出吻尖 2 格的 2×2 镜片（前端 1 格最亮），纯黑剪影里吻部上方有一个前伸小方凸；背刺 15 根：前层 8 根（长 8–12 格，下半 2 格粗 / 隔根只根部粗，骨白身、1 格黑尖，每三根一道黑环）+ 后层 7 根（长 7–10 格，暗一级、错开半根）；刺按「肩前下方扇心 → 刺根」放射，尾端平伏、肩后竖起，刺尖散开；刺皮盖住躯干上缘 3–4 格（亮顶、斜暗纹、锯齿下沿）；弹带：近侧肩头铜扣斜到两前腿之间，深棕带芯 2 格 + 两侧浅皮边，3 根横插的骨白备用针，尾端垂下摆动；爪尖骨白。
- 攻击方式：远程射——弓背压低、背刺竖起（预兆 2 帧）→ 出手帧整扇前倾、最前一根针射出（1 格后坐），针直线飞行（钢白 + 钢色拖尾）。
- 差异化：
  - 体型档：低伏弓背四足（短腿长身、背刺占上半）。和同组宝箱怪（箱形矮墩 + 节肢）、安全鼹鼠（直立人形）拉开：真四足、背上全是刺；和已通过的狼 / 熊线（高腿、肩峰、鬃）拉开：腿短、全身被刺扇盖住。
  - 识别特征：① 两层 15 根的背刺扇（外轮廓，前倾时像炮管）② 吻部上方的黄铜瞄准镜横筒（外轮廓前伸 2 格）③ 红巾飘带往后飞 3–4 格（外轮廓）④ 斜挎弹带。
  - 武器 + 握法 + 攻击类型：背负（身体本身）× 射（同组唯一背负发射）。
  - 待机个性：抖身——循环里全身一抖、背刺哗地竖起再伏下，然后抬前爪擦一下瞄准镜（镜片闪一下）。
  - 步态：小碎步快跑——短腿对角交替，身体几乎不起伏，背刺随步点整齐颤动。
  - 死亡方式：蜷成刺球滚半圈侧倒，背刺一根根脱落散开，瞄准镜弹开，刺球化灰（死亡套件 ash）。
  - 主色：骨白黑尖刺（面积最大）+ 暗沙褐身（同组无），点缀红巾、黄铜镜筒。
- 升级线：无。

## 特效设定卡

- 元素色阶：急速射击 · 电黄疾光 FXI.bolt = 白 21 → 淡黄 51 → 电青 22 → 蓝 23 → 深蓝 40；叠层环用第 1–2 级；普通攻击的针芯和拖尾用 FXI.steel（白 → 银 → 灰蓝 → 铁 → 深铁）。
- 攻击：预兆（弓背、刺竖起、镜片亮一档）/ 出手（刺扇前倾，最前一根刺尖 3 格十字枪口光 2 帧 + 4 颗钢色火星）/ 弹道（5 格长针：白尖 + 骨白身 + 棕尾，260 格/秒，钢色拖尾）/ 命中（6 颗钢色火花，假人小摇）。
- 技能「急速射击」：
  - 蓄力 1.4 s：弓背伏低，背刺竖起；前层背刺从尾到头每 0.2 s 多亮一根（蓄力末 7 根，施放时 8 根全亮），亮着的刺尖不停跳电黄小火花；瞄准镜在 0.4 / 0.8 / 1.2 s 闪 3 次；身下 0.35 / 0.75 / 1.1 s 依次浮出 3 个递增的叠层小环（电黄点阵）；轮廓光 2 档（光源在刺扇中部）+ 地面映光；最后 0.3 s 背刺发抖。
  - 施放 0.5 s：背刺一齐前倾到 45°，0.5 s 内射出 6 根电针，间隔逐根缩短（0.15 → 0.12 → 0.09 → 0.07 → 0.05 s），每根带 1 格电黄拖尾、每发后坐 1 格；第 3 针时身后甩出 2 帧速度线残影（电蓝剪影 + 横向速度线）；震屏 2 格 + 天空闪白。
  - 命中：前 5 针各一小团电黄火花（6 颗）+ 假人小摇 + impact 音；第 6 针十字星芒 + 电黄小冲击环 + 14 颗外爆 + 假人大摇，震屏 1 格。
  - 收招 0.7 s：刺尖余电逐根熄灭（8 根，每 0.09 s 一根），背刺伏下，叠层环一个个消失，轮廓光 2 → 1 → 0。
- 移动：小碎步，每次接触帧 1 颗尘土，几乎无声（step w 0.2）。
- 受击：引擎 impact 火花 + 白色剪影 1 帧 + 击退 2 格；闭眼、背刺炸起、红巾飘带往前甩、尾巴翘起。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 弓身、背刺炸起、红巾飘带往前甩 → 蜷成刺球（外圈骨白刺皮 + 16 根放射长刺，只在脸那一侧露出沙褐） → 往后滚半圈（离地 3 → 1 → 0）→ 侧倒落地（尘 12 颗 + 震屏 1 格 + fall）、瞄准镜弹开 → 背刺一根根脱落（每根掉成骨白碎屑落地）→ 刺球化灰飘走（死亡套件 ash，尘灰色阶）→ 魂光上升。
- 音色：细密的针刺沙沙 + 电流噼啪，标志性一声是连射越来越急的「嗖嗖嗖嗖」，重量 0.35。SFX 声明 `{ body: 'beast', how: 'collapse', pal: 'bolt', style: 'bolt', w: 0.35 }`；接触帧 step（w 0.2）、出手帧 swing（bow）+ shoot（arrow）、针到达 hit（wood）、技能每根针 shoot + 每次命中 impact（bolt，共 6 次）、刺球落地 fall。
