# 蜜熊 HoneyBear

模块：`pcd/chars/HoneyBear.js`。身体用非人形部件库 `parts.beast.quad`（bear 头、hump 0、chest 5.5 / rump 5.2 圆滚、leg 4 短腿、lw 3、stub 短尾、pad 熊掌、侧躺伸腿死亡）；蜜罐、蜜蜂群是本模块自画的部件（函数前标了「// 候选部件」），胸斑、捆罐藤绳、嘴角和前掌的蜜紧跟躯干 / 头 / 腿画在同一部件里。

## 角色设定卡

- 名称 / 身份：蜜熊，背着一大罐蜂蜜的圆胖野熊，敌方的「移动补给」：它倒下时蜜罐摔碎，金蜜淌给身边受伤的同伴（敌人，无职业，按特性定位为死亡治疗）。
- 一句话剪影：**一颗圆滚滚的毛球熊 + 背上一只罐口朝上的大陶罐（高出背线 6 格）+ 罐口绕飞的 4 只小蜜蜂**。
- 尺寸：待机 31×29 格（身体约 28×22，罐口和蜜蜂顶到 −28）。稀有品质，圆滚短腿熊档。
- 材质色阶（色板下标 / 专属色）：
  - 蜜糖橘棕熊毛（主材质，躯干 band 2，四肢 / 头 band 1，远侧两腿暗一级平涂、不压分界线；背上不画毛纹）：勾线 #2a1406 · 暗 #6a3410 · 基 #a8601e · 亮 #d8963a
  - 吻部 `sand` [20, 61, 62, 5]；胸前月牙斑 `bone` [8, 7, 6, 17]（平涂）；墨眼墨鼻 ink；熊爪 [0, 20, 20, 19]
  - 陶罐 `wood`：罐身用暗段 [0, 20, 20, 19]（比橘毛深两级，和毛拉开明度），罐肩 1 行 wood 亮段 16 做高光；外翻罐沿 `gold`；藤绳 `sand`；蜂蜜 `gold` [20, 19, 14, 5]（平涂）
  - 罐口蜜光（发光体，平涂）[14, 5, 51, 21]：4 档 金 → 奶油 → 淡金白 → 白
  - 蜜蜂：金身 [0, 0, 14, 5] + 墨条纹
- 部件顺序（从后往前）：（碎罐片）→ 远侧两腿 → 短尾 → 躯干（+ 同部件捆罐藤绳）→ 近后腿 → 近前腿（+ 同部件掌上蜜、胸前月牙斑）→ 背上蜜罐 → 头（+ 同部件嘴角蜜）→（抱罐 / 举罐时：近前腿 → 蜜罐）→（甩出的罐）→（侧躺：四条腿）→ 蜜蜂群。
- 细节清单：
  - 脸：bear 头 7×6（够加面部细节），圆耳、墨豆眼、浓鼻头、浅色吻部，嘴角挂一滴金蜜；张嘴露墨色口腔。
  - 毛：quad 自带背毛纹；短尾随步子甩；「会摆的部分」= 罐子上半截随身体晃 1 格 + 罐沿挂着的蜜滴一格格伸长。
  - 服装的对应物：捆罐藤绳从罐腹绕过躯干垂到腹下（亮暗相间的绳纹）+ 罐腹一圈藤绳 + 绳结。
  - 前腿：沾蜜的右前掌（3 格金蜜）；熊掌 3 爪。胸前奶油色月牙（4 格，弧口朝上）贴在近侧前腿根前沿、头下，和前腿同一部件，不会被前腿盖住。
  - 背负：陶罐 9 宽 8 高（罐底 → 圆腹 → wood 亮段罐肩 → 罐颈 → gold 外翻罐沿），罐腹斜绑 1 格 sand 藤绳；罐口冒出一汪金蜜（高出罐沿 1 行），一条蜜流从罐沿沿罐腹右侧往下挂 4 格，再挂一滴会伸长的蜜滴。
  - 发光体：罐口蜜光 5 档（待机 / 蓄力 1 / 蓄力 2 / 施放 / 碎了没有）；技能时轮廓光 2–3 档（`holy`）。
- 攻击方式：近战 **砸**：前身抬起 4 格、近侧前掌举高（预兆）→ 前冲 4 格前掌拍下（出手）→ 保持 → 收回。
- 差异化（对照已通过角色 + 同组分配）：
  - 体型档：圆滚短腿（胸臀都圆、没有肩峰、腿 4 格）。熊线的北极熊（矮壮低伏、肩峰 + 树苗）、生命树（背上大树）、黑熊（巨型肩峰、人立）都有肩峰和背上的植物；它没有肩峰、没有树，是一颗毛球。和同组的头狼（高大犬科）、龙龟（低矮巨壳）拉开。
  - 识别特征（≥ 2 改外轮廓）：①背上罐口朝上的大陶罐，高出背线 6 格（外轮廓）②罐口外绕飞的 4 只蜜蜂，飞出身体轮廓（外轮廓）③胸前奶油色月牙斑 + 嘴角 / 前掌的金蜜（内部）。
  - 武器 + 握法 + 攻击类型：徒手沾蜜熊掌 × 单掌 × 砸（半抬身单掌拍）。黑熊是完全人立双掌合砸、北极熊是低头肩撞、生命树是根须横扫。
  - 动作个性：待机 = 坐下舔前掌上的蜂蜜、抬头咂嘴，蜜蜂一直绕罐转、罐沿蜜滴一格格伸长偶尔滴落；步态 = 摇摆慢走（身体和罐子左右晃、头一点一点，每步 2 颗尘，隔一步从罐沿滴一滴蜜落到地上）；死亡 = 侧倒碎罐。
  - 主色：蜜糖橘棕（熊线唯一的暖橘色；北极熊冷白、黑熊黑褐、生命树白桦）。
  - 特效：金蜜治疗（holy）：碎罐溅蜜 + 友军头上落蜜滴 + 十字光点上升；北极熊是嫩芽绿叶片环绕、黑熊是熔火禁果爆裂、生命树是晨露光柱。
  - 自动查重：`compare.mjs` 退出码 0。

## 特效设定卡

- 元素：蜜罐 · 金蜜治疗，色阶 `holy` = 21 白 → 51 淡金白 → 5 奶油 → 14 金 → 61 暗金；碎罐片借 `impact`，尘土 `dust`。
- 攻击「蜜掌拍」
  - 预兆：前身抬起、前掌举高、张嘴，罐子后仰。
  - 出手：前冲 4 格前掌拍下定格，三道竖掌风 2 帧（淡金白实线 → 奶油断续），罐沿蜜滴甩到最长。
  - 命中：10 颗 impact + 6 颗金蜜（带重力落地）；假人闪白小摇。
- 技能「蜜罐」（特性：死亡时为身边受伤的友军回血；技能状态演一遍它生效的样子，友军占位 `ALLIES: 'skill'`）
  - 蓄力 1.4 s：0–0.35 s 坐起；0.35–1.1 s 从背上取下蜜罐放在身前抱住，蜜光 1 → 2 档逐帧闪，金色光点从四周螺旋汇进罐口，蜜蜂加速（每帧转一格），罐口蜜光十字、地面映光、轮廓光 2 档；1.1–1.4 s 双掌把罐子举过头顶发抖、张嘴。
  - 施放 0.5 s：双掌举罐砸地、罐碎——汇聚光点带重力外爆、30 颗金蜜外爆（带重力，落地成滩）+ 8 片碎罐片 + 冲击环 + 十字星芒，蜜蜂四散；地上铺开一滩金蜜；每名友军头上各落下一颗 2×2 金蜜滴；震屏 2 格、天空闪白。
  - 命中（0.3 s，蜜滴落到友军头上）：友军金色描边（`allyFx`）+ 头顶十字星芒 + 每人 3 组十字形光点上升；震屏 1 格；再发一次 `impact`。

- 死亡（侧倒碎罐，死亡即技能）：26 颗火花 + 震屏 2 格 + 闪白 → 前腿先软塌下 → 0.5 s 侧躺翻倒（离地 3 → 1 → 0，四腿僵直伸出），背上的罐子甩出往后飞 → 0.66 s 落地摔碎：16 颗尘 + 34 颗金蜜外爆 + 碎罐片 + 冲击环，蜜蜂四散，地上铺开一大滩金蜜（2.1 s 慢慢变暗），友军现身、头上落金蜜滴 + `fall` → 0.95 s 友军金描边 + 十字光点上升 → 1.6 s 起自上而下消散，魂光上升。
