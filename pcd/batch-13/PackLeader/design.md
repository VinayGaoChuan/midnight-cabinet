# 角色设定卡 · 头狼 PackLeader

- 名称 / 身份：头狼，领着狼群冲锋的鼓手首领（敌人，野兽，稀有）。「战鼓被动地提升盟友」→ 背上驮一只战鼓，尾巴擂鼓；「提升伤害、降低防御」→ 鼓声把友军染红：伤害上升箭头 + 身上裂纹。
- 一句话剪影：狼线里最高最壮的灰褐大狼，背上驮一只插着两根骨鼓槌的蒙皮战鼓，狮鬃般的灰白颈毛把前身撑宽，蓬尾高举、尾尖染红。
- 尺寸：稀有档，站姿 41×31 格（尾尖到吻尖 × 鼓槌尖到脚底；待机 bbox -17..22 × -28..1），狼线最高最大；地面线统一。
- 体型档：高大壮硕头狼。`B.quad` canine：len 14、胸 5.5 / 臀 4.3、肩峰 1.5、腿 7、腿粗 2、大腿 2.9、颈粗 3.2、颈角 0.8（昂头），头放大到 7·6、吻 4.5·3.5；狮鬃 lion、蓬尾 bushy（长 12、上翘 0.85）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 狼毛（主材质）：灰褐 stone 暖段 [#1a1614, #3e3630, #6a5e52, #9a8c7a]（模块内 `E.ramp` 追加 4 色）
  - 颈鬃：灰白 [#1a1614, #6a5e52, 18, 17]（pale 一系的灰白，勾线用本身的暖黑，避免冷蓝色和灰褐打架）
  - 腹线 / 吻部：[#1a1614, #6a5e52, #9a8c7a, 17]；尾尖、红布条：crimson [11, 12, 13, 26]；骨珠、鼓槌：bone；伤疤、撕裂耳伤口：pink
  - 鼓：鼓身 wood [0, 20, 19, 16] + crimson 漆环 + leather 之字皮绳；鼓面蒙皮 sand [20, 61, 62, 5]，亮一档 [11, 12, 13, 26]、亮两档 [12, 26, 58, 21]（发光体）；挎带 leather
  - 眼：金豆眼 [0, 0, 14, 5]，蓄力 / 嚎叫时换成赤红 glow [11, 13, 26, 26]
- 部件顺序（从后往前）：远侧两腿 → 交叉鼓槌 → 蓬尾 → 躯干 + 颈 → 近侧两腿 → 战鼓（+ 挎带）→ 狮鬃（+ 红布条、骨珠）→ 头（+ 撕裂耳、竖疤）。侧躺时四条腿挪到最后；死亡时鼓单独成部件滚落。
- 细节清单：
  - 脸：金豆眼 + 浅色眉、黑鼻头、张嘴露牙；眼上一道粉色竖疤（侧视只看得到靠镜头的右眼，疤画在可见一侧，设定里的「左眼」按侧视改到可见眼上，属补充）。
  - 耳：右耳上半撕成前后两叉，叉口露 1 格粉色伤口（候选部件 `tornEar`）。
  - 毛：背上每 4 列一撮暗毛纹；狮鬃 9 束尖端亮、隔束暗；红布条两条随 `mane` 摆，骨珠 4 颗；蓬尾末端 crimson 染红，随 `tail` 甩。
  - 背负物：战鼓（候选部件 `warDrum`）：圆筒木鼓身、后端一道红漆环、中段之字皮绳、鼓面外圈木箍 + 内圈蒙皮，鼓面 3 档亮度；交叉骨鼓槌（候选部件 `drumSticks`）槌头伸出背线；皮挎带从鼓下沿绕到腹线（候选部件 `drumStrap`）。
  - 发光体：鼓面（待机 0 / 尾击 1 / 蓄满 2 / 熄灭时掉落破开）+ 眼光 / 口光。
- 攻击方式：近战「咬」——后坐蓄势 1 帧 → 前扑 5 格张口（尾巴顺势擂鼓一下，鼓面亮两档）→ 咬合（上下两排牙印合拢 + impact 火花）→ 甩头撕扯 → 退回。
- 差异化：
  - 体型档：高大壮硕头狼，狼线最高最壮（黑剑瘦长低伏 28×18、暗牙标准健壮 32×22，头狼 41×31）；同组四足：针刺者低伏刺背、攻城羊楔形、四眼蹲伏、蜜熊圆滚、龙龟低壳，都不撞。
  - 识别特征（≥3，其中 ≥2 改外轮廓）：① 背上战鼓 + 两根交叉骨鼓槌，高出背线约 8 格（外轮廓）② 狮鬃般蓬乱颈毛把前身撑宽约 5 格，编红布条和骨珠（外轮廓）③ 蓬尾高举、尾尖染红（外轮廓）④ 右耳撕成两叉 + 眼上竖疤（耳朵轮廓 + 内部）。
  - 武器 + 握法 + 攻击类型：利齿 + 背负战鼓（尾巴甩打鼓面）× 徒手 / 背负 × 咬。黑剑是剑角剑尾、暗牙是声波弹，头狼是扑咬。
  - 待机个性：尾巴擂鼓——尾巴每 0.8 秒甩打一次鼓面（一下一顿，鼓面亮一档、溅两颗红火星），之后昂头环视（抬头 → 耳朵一抖 → 回正）。暗牙是坐下舔爪，不撞。
  - 步态：昂首稳步小跑——对角两腿一组，头比普通狼高一档，每两步（一个步态循环）尾巴擂一下鼓，落脚扬尘 3 颗（重）。
  - 死亡方式：长嚎后侧倒——受击 → 仰头嚎最后一声（嘴前一圈小鼓声环）→ 侧倒四腿僵直伸出（离地 3 → 1 → 0）→ 战鼓从背上滚落、翻两圈落在身后，鼓面破开、鼓槌散在地上 → 静止 → 自上而下消散 + 魂光。暗牙是褪灰化灰。
  - 主色：灰褐斑驳狼毛 + 灰白鬃 + 红布条；黑剑蓝黑、暗牙金毛，不撞。

# 特效设定卡 · 领袖光环 · 战意赤红

- 元素色阶：FXI.enemy 白 21 → 淡粉红 26 → 红 13 → 暗红 12 → 深红 11（同一技能只用它 + 通用 impact / dust / soul）。
- 攻击（咬）：预兆 = 后坐压低、尾巴后甩 1 帧；出手 = 前扑 5 格张口，尾巴擂鼓（鼓面亮两档 + 4 颗红火星）；命中 = 假人前上下两排牙印合拢（第 1 帧白 / 淡粉、第 2 帧红且合拢）+ impact 外爆 10 颗 + 红色 5 颗，假人小摇。
- 技能「领袖光环」（被动：身边友军伤害更高但更脆）：
  - 蓄力（1.4 s）：前腿撑地压低、尾巴高举，眼睛泛红；0.5 s、1.0 s 尾巴各擂一下，鼓面随每下亮一档（1 → 2），每下嘴边弹一圈小鼓声环；脚下赤红法阵（两圈虚线椭圆）随鼓点收缩（22 → 17 → 12 格），红点从法阵外沿往里收；轮廓光 2 档（鼓面为光源）、地面映光。
  - 施放（0.5 s）：尾巴连擂三下，每下从鼓面扩出一圈赤红冲击环（18 → 26 → 38 格，逐次变大，后半段断续）；第三下接仰头长嚎（身体颤）；震屏 2 格 + 天空闪白；身后两名友军（`ALLIES: 'skill'`，站在尾后 25 / 41 格）出现。
  - 命中（第三下，施放 +0.33 s）：友军 `allyFx` 红色描边闪烁、各一团红色外爆 + 头顶十字星芒；头顶浮出红色上升箭头（伤害↑，逐帧上浮 3 格），身上一道暗红裂纹逐格画出（受伤害↑、更脆）；震屏 1 格。
  - 收招（0.7 s）：从长嚎缓回站姿，鼓面 2 → 1 → 0，鼓声环断续消失，鼓面飘红色余烬；箭头和裂纹最后 0.3 s 闪烁褪去。
- 受击：兽 → impact 火花 + 灰褐毛屑（专属毛屑色阶）+ 白色剪影 1 帧 + 击退 2 格；闭眼、耳贴后、尾巴和鬃反甩。
- 死亡：来袭命中 → 失衡 → 仰头长嚎（嘴前小鼓声环 + 红火星）→ 侧倒（离地 3 → 1 → 0）→ 落地尘土 16 颗 + 震屏 1 格 → 战鼓翻滚落到身后、鼓面破开（鼓皮碎屑 + 尘）→ 静止 → 1.6–2.4 s 自上而下消散 + 魂光上升。
- 音色：厚重狼嚎 + 蒙皮战鼓咚咚，标志性一声是三下鼓点「咚、咚、咚」接一声长嚎，重量 0.75。SFX 声明：body beast、how topple、pal blood、style buff、w 0.75；step 在对角落脚的两个接触帧、swing（bite）在前扑帧、hit（flesh）在咬合帧、impact（blood）在施放的三下鼓点（蓄力里每下尾击另有一个轻的 impact）、fall 在侧倒落地帧和战鼓落地帧。
