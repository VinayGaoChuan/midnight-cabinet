# 角色设定卡 · 半人马 Centaur

- 名称 / 身份：半人马，荒原上的双斧劈砍手（敌人，野兽，史诗）。「高伤害输出者」「劈砍」→ 双持斧、劈；「连击次数+1」→ 一次攻击两下、两把斧先后落下。
- 一句话剪影：四蹄长腿的栗色马身 + 宽肩窄腰的古铜人上身；两手各一柄新月弯斧向前后外展；头顶一道竖起的黑莫西干鬃冠一路连到马背；身后甩一条系白羽的编辫马尾。
- 尺寸：史诗档，约 36 格高（含鬃冠）、40 格长（尾辫到前斧），同组最高；地面线统一。
- 体型档：半人马英武档——`B.quad` 马身（len 14、leg 11 长腿、胸 4.8 / 臀 4.6、收腹 0.25、蹄）+ `parts.rig` heroic 骨架（torso 10、arm 10、head 6），人形的胯挂在 `rig.NB`（马颈根）上当腰；人上身是自画的倒梯形（肩宽 10、腰宽 6，肩头再各鼓出 1 格）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 马皮（主材质，面积最大）：栗色，wood 色阶偏红 [0, #4a2014, #7a3a1e, #a8603a]
  - 人上身：skinDark 古铜 [20, 19, 16, 15]；战纹 moss [0, 34, 35, 36]
  - 鬃冠 / 马背鬃 / 尾辫：墨黑 [0, 0, 27, 28]（ink 加钢蓝高光，才有两色明暗）
  - 斧刃 steel [27, 28, 29, 30]；刃口冰蓝寒光（发光体）glow [22, 22, 21, 21]；斧柄 bone [8, 7, 6, 17]
  - 白羽 white [7, 18, 17, 21]；腰带 / 护腕 leather [20, 19, 32, 33]；蹄 iron [0, 27, 28, 29]
- 部件顺序（从后往前）：远侧两腿 → 尾辫（+ 白羽）→ 马身 → 近侧两腿 → 后手斧 → 后臂（肩头 + 二头肌 → 护腕 → 拳）→ 倒梯形人躯干（赤膊 + 锁骨战纹 + 腰带）→ 头 → 莫西干鬃带（头顶鬃冠 → 后脑 → 后颈 → 人背 → 马背，一个部件）→ 前手斧 → 前臂。
- 细节清单：
  - 脸：方下巴粗犷脸（脸颊浅疤）、墨眼、粗眉、大鼻、嘴线；左颊一道苔绿战纹。
  - 毛发：头顶 7 束往后斜的鬃束（前低后高，最高处高出头顶 4–5 格），沿后脑、后颈、人背、马鬐甲连成一条 ink 锯齿鬃带（约 10 列马背段）；齿长 2 / 1 / 0 三相循环，`mane` 换相位让鬃尖错开摆，`blow`（小跑、出手、冲刺）时鬃束更斜、齿更长往后飘；尾辫亮暗交替辫纹、每 3 格一个辫环、辫梢两根白羽会摆。
  - 躯干：skinDark 基色倒梯形（10 → 8 → 6，接马身处最窄）；胸肌分界 1 格 + 胸肌下沿、腹线 2 道手工暗色、胸 / 腹高光；锁骨一道 1 格苔绿锯齿战纹；皮腰带 + 金扣压在人马交界处；马身腹线浅一级、四蹄铁灰。
  - 手臂：3 格宽肩头（三角肌，鼓出躯干 1 格）+ 鼓起的二头肌 + 2 格前臂；上臂两道 1 格苔绿斜战纹；皮护腕；待机时双臂外展，露出躯干的倒梯形。
  - 武器：新月弯斧 = 骨柄（1 格，柄尾包铁）+ 7 格高钢刃新月（上下两只角往回勾，只在中间三行连柄，刃背和柄之间留空，刃头伸出柄 5 格）+ 刃口一线 7 格弧形冰蓝（发光体，5 档：待机 / 蓄 1 / 蓄满 / 施放 / 熄灭）。
- 攻击方式：近战「劈」，双斧先后交叉劈砍，一次攻击两下（第 2 帧前手斧右上劈下、第 4 帧后手斧左下反撩），前冲 6 格，每一下各一道冰蓝斩弧和一次命中。
- 差异化：
  - 体型档：半人马英武档，同组最高最长；和同组其他四足（针刺者、攻城羊、四眼、蜜熊、头狼、龙龟）拉开：唯一一个人上身直立在马身上的。和幽灵骑士（同属半人马）拉开：血肉之躯、有人头、不穿甲、双持短斧，幽灵骑士是无头空甲 + 骷髅马头 + 单持长枪。和已通过的黄鬃马 / 汗血马拉开：没有马头马颈，前端竖起的是人上身。
  - 识别特征（≥3，其中 ≥2 改外轮廓）：① 双手新月弯斧外展，斧刃伸出身体前后各约 5 格（外轮廓）② 黑莫西干鬃冠竖出头顶 3 格往后飘、一路连到马背（外轮廓）③ 编辫马尾 + 两根白羽，甩出身后约 6 格（外轮廓）④ 古铜皮肤上的苔绿战纹（内部）。
  - 武器 + 握法 + 攻击类型：新月弯斧 × 双持 × 劈（交叉两下）。
  - 待机个性：转斧刨蹄——一只前蹄轻刨地两下，同时两把斧在手里各转一圈（斧头 90° 一档换朝向）。
  - 步态：对角小跑——四蹄对角两组交替、腿长步幅大，人上身挺直只随步伐起伏 1 格，鬃冠和尾辫反向往后飘，落蹄扬尘 2 颗。
  - 死亡方式：前腿跪倒前扑——前腿先跪（马身前低），人上身向前扑倒，双斧一前一后甩出去落地，马身再侧倒（四腿朝前后水平伸出，不朝天），人上身趴在马身前面。
  - 主色：栗红马皮 + 古铜肤 + 墨黑鬃；同组四足主色为骨白针刺、奶油羊毛、煤黑、蜜橘、灰褐、岩青，不撞。

# 特效设定卡 · 顺劈 · 寒风冰刃

- 元素色阶：FXI.frost 白 21 → 冰青 22 → 青 23 → 钢蓝 40 → 深蓝 39（同一技能只用它 + 通用 impact / dust / soul）。
- 攻击（劈，两下）：预兆 = 马身微压、双斧举过头（斧刃亮一档）；出手 1（第 2 帧）= 前冲 6 格，前手斧右上劈下，冰蓝斩弧（宽 1）+ 命中火花 + 假人小摇；出手 2（第 4 帧）= 后手斧左下反撩，第二道斩弧（反方向），冰屑 + 假人再摇一下；收回缓入。
- 技能「顺劈」（连击 +1）：
  - 蓄力：后腿下蹲、马身前倾（前低），双斧交叉在胸前；刃口寒光 1 → 2 档逐帧闪，冰屑沿斧刃向外螺旋（外旋，不是汇聚）；身后地面拉出两道风纹；轮廓光 2 档。
  - 施放：冲刺 8 格；第一斧右上劈下、第二斧左下反撩（两段 `fx.slash`，冰青第 1 级起，2 格宽）；身后 2 个马身残影（`blitShape` 冰青 / 钢蓝）；震屏 2 格 + 天空闪白。
  - 命中：两次十字星芒 + 冰屑外爆各 18 颗，假人连摇两下 + 击退，第二下震屏 1 格。
  - 收招：半人立（前高）收斧回位，寒光 2 → 1 → 0。
- 受击：肉身 → impact 火花 + 白色剪影 1 帧 + 击退 2 格；人上身后仰、闭眼，鬃冠和尾辫反向甩。
- 死亡：前腿跪倒 → 人上身前扑 → 双斧脱手一前一后抛出落地（刃口寒光熄灭）→ 马身侧倒（离地 3 → 1 → 0）→ 落地扬尘 16 颗 + 震屏 1 格 → 静止 → 自上而下消散 + 魂光上升。
- 音色：急促的马蹄嗒嗒 + 刀刃破风的冷啸，标志性一声是双斧交叉的「锵、锵」两响，重量 0.7。SFX 声明：body beast、how topple、pal frost、style blade、w 0.7；step 在对角落蹄帧、swing（slash）在两个出手帧、hit（flesh）在两个命中帧、impact（frost）在施放两段斩击、fall 在侧倒落地帧。
