# 角色设定卡 · 幽灵骑士 GhostKnight

- 名称 / 身份：幽灵骑士，和骨马长在一起的无头空甲骑士（敌人，野兽，稀有）。「受到的自动攻击伤害减少」「幽灵行者」「潜行」→ 半透明的魂体，普通攻击会从身体里穿过去；近战 → 夹枪冲刺直刺。
- 一句话剪影：一匹瘦骨嶙峋、离地漂着的骨马（骷髅马头 + 折断独角），背上长出一副没有头的空心板甲上身，颈口冒一簇往上飘的魂火；右手平端一支超长破骑枪伸出马头前 8 格，枪上挂一面撕烂的三角小旗；后腿膝下化雾往后拖。
- 尺寸：稀有档，约 32 格高（魂火顶）、34 格长（雾尾到马头；枪尖再伸出 8 格）；整体离地漂 1 格。
- 体型档：枯瘦骨马骑士档——`B.quad` 马身（len 12、胸 4 / 臀 3.8、收腹 0.45、腿细 lw 1、horse 头 bone 色、neck 5.5）+ `parts.rig` standard 空甲上身（torso 8、sw 4，不画头），甲身悬在马背上方 1 格。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 魂体骨皮（主材质，面积最大）：灰蓝，sky 暗段 + pale [39, 59, 60, 17]
  - 骨（马头、前腿、肋骨高光）：bone [8, 7, 6, 17]
  - 空甲：iron 锈铁 [0, 27, 28, 29]，锈斑 leather 暗段点缀
  - 魂火 / 眼窝 / 枪尖（发光体）：soul 青紫，平涂 [25, 24, 23, 22] + 亮芯 [22, 22, 21, 21]
  - 枪身：iron；破旗：boot [0, 20, 20, 19]
- 部件顺序（从后往前）：后臂（空甲袖）→ 远侧腿（前腿骨 / 后腿化雾）→ 雾尾 → 马身（肋骨纹同一部件）→ 近侧腿 → 颈 + 骷髅马头（眼窝魂火、骨齿同一部件）→ 断独角 → 空甲躯干（颈口黑洞）→ 颈口魂火 → 骑枪 + 破旗 → 前臂（肩甲 + 铁手套压在枪杆上）。
- 细节清单：
  - 脸：骷髅马头——眼窝 2 格墨 + 1 格魂火眼光、吻部上下一排骨齿（亮暗交替）、鼻孔 1 格墨、耳 2 格。
  - 毛 / 须：没有鬃；魂火代替头，3 条火舌逐帧摇、尖端往上飘；后腿雾尾会摆。
  - 躯干：马身 4 道肋骨（暗色弧线 + 骨白高光）、收腹见脊；板甲中脊高光、胸腹分界、腿甲裙分段、铆钉、护颈；颈口一圈墨黑空洞。
  - 手臂：板甲袖 + 肘甲、尖刺肩甲、铁手套。
  - 武器：破骑枪——锈铁枪身 1 格、锥形枪尖（魂光发光体，5 档）、枪身上挂 5×4 撕烂三角旗（锯齿缺口，随风摆）。
- 攻击方式：近战「刺」，夹枪冲刺 6 格直刺（后缩 → 出手帧冲出，枪尖一道横向刺光 + 命中星芒）。
- 差异化：
  - 体型档：枯瘦骨马骑士档，和同组半人马（肌肉血肉、人头、双斧）拉开：无头空甲、骷髅马头、单持长枪、冷色半透明、离地漂。和已通过的黄鬃马 / 汗血马拉开：骨瘦见肋、后腿化雾、背上长出空甲、没有鬃和马具。和骨龙拉开：是马不是龙、有甲有枪、不飞。
  - 识别特征（≥3，其中 ≥2 改外轮廓）：① 骷髅马头 + 额顶折断的独角骨刺（外轮廓）② 无头空甲上身 + 颈口往上飘的魂火，高出肩 5 格（外轮廓）③ 超长破骑枪平端伸出马头前 8 格、挂撕烂三角旗（外轮廓）④ 后腿膝下化雾往后拖（外轮廓）⑤ 马身肋骨（内部）。
  - 武器 + 握法 + 攻击类型：破骑枪 × 单手夹持平端 × 刺。
  - 待机个性：忽隐忽现——整体上下漂 1 格，身体局部一块像素按抖动时隐时现，魂火忽大忽小。
  - 步态：飘浮空踏——前蹄空踏不落地（离地 1–2 格），后半身拖雾尾，无脚步、无尘（hover）。
  - 死亡方式：散架——空甲一块块散落，骨马塌成一堆骨头（死亡套件 chunks），魂火绕一圈飞起后熄灭，骨堆化灰消散。
  - 主色：灰蓝魂体 + 骨白 + 锈铁 + 青紫魂光；同组没有这组冷色主材质。

# 特效设定卡 · 幽灵行者 · 魂光

- 元素色阶：FXI.soul 青 22 → 蓝 23 → 紫 24 → 深紫 25 → 墨 3（加通用 impact / dust；敌方普攻小弹用 enemy 色阶）。
- 攻击（刺）：预兆 = 后缩 2 格、枪尖抬起、魂光亮一档；出手（第 2 帧）= 冲出 6 格，枪尖前一道 2 行横向刺光 + 身后 3 条魂光速度线；命中 = 十字星芒 + 魂光火花 10 颗 + 假人小摇；收回缓入。
- 技能「幽灵行者」（被动：普攻伤害 −20%，表现生效的样子）：
  - 蓄力：身体从头到尾逐行变成 bayer 抖动的半透明（删像素，不是半透明色），魂火转紫；四周魂光粒子向身体汇聚；轮廓光 2 档。
  - 施放：身体化为纯魂光剪影（`blitShape` soul 第 2 级）闪一下；假人方向射来一发敌方普攻小弹，直接穿过剪影；身后留下 2 个剪影残像；震屏 2 格 + 天空闪白。
  - 命中：弹道从身后穿出，只在背后溅起 8 颗魂光，身体不击退；震屏 1 格。
  - 收招：剪影逐行从头到尾恢复实体，魂火褪回青色。
- 受击：幽灵 → 火花换成魂光色阶 + 白色剪影 1 帧 + 击退 2 格；魂火往后甩、枪尖一抖。
- 死亡：受击 → 失衡下沉 → 散架（空甲、枪、骨头按 4 格小块散落、弹跳成堆）→ 魂火从颈口飞起绕一圈后熄灭 → 骨堆抖动化灰消散 + 魂光上升。
- 音色：空洞的铁甲摩擦 + 低沉的风声呜咽，标志性一声是攻击穿体时的一声幽灵叹息，重量 0.55（悬浮）。SFX 声明：body ghost、how shatter、pal shadow、style shadow、w 0.55、hover 1；swing（thrust）在出手帧、hit（metal）在命中帧、impact（shadow）在弹道穿体溅魂光时、fall 在骨堆落地帧。
