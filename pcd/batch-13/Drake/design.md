# 角色设定卡 · 幼龙 Drake

- 名称 / 身份：幼龙，刚学会喷火的双足翼龙少年（敌人，野兽，优质）。「虽然年轻」→ 短钝幼角、刚冒头的颈刺、轻瘦体格、会打喷嚏；「炽热的呼吸」→ 喉下热囊是发光体，攻击吐火球，技能喷一道火流。
- 一句话剪影：没有前腿、一对折叠膜翼当前肢（翼肘撑地像拐杖、翼指收在背上竖起）的前倾双足小龙；瘦长颈 + 头顶一对短钝幼角；身后一条长尾，尾尖一团小火苗。
- 尺寸：优质的双足翼龙少年档，约 26 格高（含翼指）、约 34 格长（尾焰到吻尖）；张翼施放时翼展约 26 格；地面线统一。
- 体型：`B.quad` 只取两条后腿（len 7 · chest 3.8 · rump 4.2 · leg 6 · pitch 2 前高，身体前倾靠翼肘撑地）；颈 neck 5 · neckA 1.05 · neckW 1.8；dragon 头缩短吻部（w 6 · h 5 · snout 3.5 · snH 2.8，不用库里的角，改画自己的实心短钝角）；long 长尾 tailLen 11。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 焦橙红幼鳞（主材质，面积最大）：[#2a0c04, #6e2410, #b8481c, #e8803a]（4 个专属色），鳞纹 scales
  - 腹线：sand [20, 61, 62, 5]
  - 翼膜：crimson [11, 12, 13, 26]（远翼暗一级）；翼臂骨 / 翼指：主材质暗一级 [#2a0c04, #6e2410, #6e2410, #b8481c]，远翼再暗一级 [#2a0c04, #6e2410 ×3]
  - 后腿：近侧亮一档 [#2a0c04, #b8481c, #e8803a, #f7b068]，远侧暗一档 [#2a0c04, #6e2410, #6e2410, #b8481c]
  - 角、颈刺、爪：bone [8, 7, 6, 17]（远侧角暗一级 [8, 7, 7, 6]）；眼：[0, 0, 14, 5] 金豆眼
  - 热囊 / 尾焰（发光体）：fire [44, 45, 46, 47] 平涂 + 白热 [46, 47, 21, 21] 平涂；张嘴口里火光 fire 平涂

- 细节清单：
  - 脸：金豆眼 + 亮眉、鼻孔点、张嘴露牙；喷吐时口里 fire 火光、眼睛也被映亮。
  - 头饰：一对实心短钝幼角——近侧 2 格宽 × 3 格高，从头顶往后上斜（每升 2 格后退 1 格）；远侧角往后错开 3 列、低 1 格、暗一级，两角之间是一道开口的缝。

  - 翼：臂骨 2 格 + 3 根翼指（前缘最亮）+ 指间扇贝凹边的膜 + 拇指爪；撑地时拇指爪伸出去扣地。收拢撑地时翼指贴着前臂收上去、从肩后扇出，指尖伸出背线 ≥3 格，膜只在前臂后面留一条窄带；腕撑地点离后脚 ≥3 格。7 个翼姿：收拢撑地 / 往前撑一步 / 张开撑地 / 上扬 / 下压 / 全展 / 瘫软垂地。

- 差异化：
  - 体型档：双足翼手少年档；和已通过的翡翠龙（圆滚四足、叶翼、花脊）、毒龙（重龙、巨花）、青龙（无翼游龙悬浮）、天龙（羽翼、C 形长身）、骨龙拉开：没有前腿、翼就是前肢、轻瘦前倾站在后腿上。同组的恐龙是双足但巨头小手无翼，龙龟是壳。
  - 识别特征（≥3，≥2 改外轮廓）：① 折叠膜翼当前肢——翼肘斜撑到身前地面、翼指收拢竖在背上（外轮廓），全展时翼展 26 格 ② 瘦长颈 + 短钝幼角 + 颈后小骨刺（外轮廓）③ 长尾末端一团小尾焰（外轮廓、发光体）④ 喉下热囊透出橙光（内部）。
  - 武器 + 握法 + 攻击类型：炽热吐息 × 徒手（口）× 射（火球）；同组机器人也用火，但它是扇形连续火流 + 黑烟，幼龙是吐息火柱 + 火浪。
  - 待机个性：打喷嚏——鼻孔一直冒两缕烟；吸鼻 → 闭眼 → 「嚏」地喷出一小团火星 → 被自己吓得缩脖子（颈长 5 → 3.2、身子一沉）。
  - 步态：双足蹦 + 翼肘点地——后腿交替蹦，两翼肘轮流往前撑地，经过帧扑一下翅膀（上扬 / 下压），身体离地 1–2 格。
  - 死亡方式：坠落——扑腾翅膀离地 1 → 3 格，翼一软侧摔落地（3 → 1 → 0），尾焰熄灭冒一缕黑烟，化灰。
  - 主色：焦橙红鳞 + 暗酒红翼膜；同类龙主色是翠绿、墨绿、翠青、天青，同组没有橙红为主色的角色。
