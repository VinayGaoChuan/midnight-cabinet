# 角色设定卡 · 小鬼 Imp

- 名称 / 身份：小鬼，成对出没的孩童小恶魔（敌人，野兽，优质）。「造成高额伤害」→ 手里一柄比自己还高的三叉叉、俯冲连戳；「成对出现」→ 技能是召出同款搭档。
- 一句话剪影：会飞的大头小不点——背后一对扑个不停、翼尖高过头顶的紫色小蝠翼，头顶两只弯弯的小羊角 + 脑后一只支棱出去的大尖耳，身前竖着一柄比自己还高的三叉叉（离头 ≥ 5 格），身后细尾末端一个箭头尾尖。
- 尺寸：优质档，约 18 格高（不含翼、叉），离地 2 格悬停；叉竖起时总高约 25 格。头身比约 3（头 7×7）。
- 体型档：孩童小恶魔档——`parts.rig` child（leg 5、torso 5、head 7 / headW 7、sw 3、arm 9、lw 1、belly 1 小肚子微鼓；手臂用 2 格细的 tight 袖形画赤臂，前臂握叉时肘往下弯）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 小恶魔皮（主材质）：品红紫 [11, #6e1f63, #a8388f, 63]（酒红墨勾线 → 暗品红 → 品红 → 粉；分配写的「gem 色阶」是蓝紫青，品红紫本身不在共享色板里，补了 2 个专属色，勾线和亮部仍取共享色）
  - 翼膜：近翼 [53, 53, 54, 43]（勾线深紫 53、基色紫 54、亮部淡紫 43，夜空前看得见）；远翼暗一级 [52, 52, 53, 54]；臂骨是膜的亮部（43），翼指是暗部（53），腕上一颗骨白爪
  - 小羊角：bone [8, 7, 6, 17]；蓄力时换成发光的 [52, 54, 43, 21]
  - 眼：金色发光 [20, 14, 47, 51]（flat）
  - 三叉：木杆 wood [0, 20, 19, 16]；叉头 steel [27, 28, 29, 30]；齿尖暗紫火 [52, 53, 54, 43]，蓄满 / 施放换 [54, 43, 21, 21]
  - 缠腰布：shadow [0, 52, 53, 54]；箭头尾尖：皮色（亮部 63）；耳内 pink；牙 white
- 部件顺序（从后往前）：远翼 → 近翼（都在躯干之前，翼根被身体盖住，分界线压在翼上，不压在皮上）→ 箭头尾 → 后臂 → 两腿 → 躯干（一个部件：大块皮色 + 缠腰布）→ 两只小羊角 → 大头（和大尖耳同一个部件）→ 三叉叉 → 后手（压在叉杆上）→ 前臂 + 手。
- 细节清单：
  - 脸：7×7 圆头整块一个部件，脸上只有眼、眉、嘴——金色发光大眼（2 格）、往前压的坏眉（2 格）、翘鼻（伸出 1 格）、咧嘴坏笑（嘴角上翘 + 一颗尖牙，jaw 张嘴、下巴往下开）；明暗全靠自动的左上亮边。
  - 毛发 / 耳：没有头发；脑后一只往后上方支棱的大尖耳，伸出头轮廓 5 格（耳内粉，受击时后贴），和近翼前缘之间留 ≥ 3 格空。
  - 头饰：两只 2 格粗的小羊角从头顶往上长 4 行再往后卷，远侧那只暗一级、错后 3 格；角的最前沿和三叉之间空 ≥ 5 格。
  - 躯干：赤膊小肚子（大块基色 + 左上亮边，不画胸腹肌暗线），墨紫缠腰布。
  - 手臂腿脚：细赤臂 + 2×2 手；赤足细腿悬在半空，移动时两腿交替蹬。
  - 武器：小三叉叉 = 木杆（每 4 格一个木节高光）+ 杆尾铁箍 + 5 格铁横档 + 三根直齿（中齿长 2 格）+ 齿尖暗紫火（发光体，5 档：待机 / 亮 / 蓄满 / 施放 / 熄灭）；待机竖在身前 x 9，杆尾垂到脚下，叉头高过角尖。
- 攻击方式：近战「刺」——俯冲 4 格，叉平端，戳 · 收 · 戳 · 收 · 戳，三下连戳。
- 差异化：
  - 体型档：孩童体 + 悬停，全组最小的会飞的人形；和恶鬼 Fiend（细肢巨躯、落地）拉开：小、轻、会飞、成对；和已做的恶魔 Diabolic（焦红小骷髅、盘腿、掌心火球）拉开：有血有肉的品红皮、大尖耳、手持长兵器、站着悬停不盘腿。
  - 识别特征（≥3，其中 ≥2 改外轮廓）：① 背后一对快速扑动的小蝠翼（外轮廓）② 头顶一对小羊角 + 脑后支棱的大尖耳（外轮廓）③ 比自己还高的三叉叉 + 细尾箭头尾尖（外轮廓）④ 金色发光眼、坏笑尖牙（内部）。
  - 武器 + 握法 + 攻击类型：三叉叉 × 双手握 × 刺（三连戳）。
  - 待机个性：坏笑搓手——空中翻一个跟头（收身 → 倒立 → 侧翻 → 张翅落回，转过的朝向只有 2 帧，翅膀收拢），落回后搓手嘿嘿笑、尾巴左右猛甩，接着回头（整个头镜像）朝身后搭档的方向招手。
  - 步态：扑翼飞行——不落地，4 帧扑翼（上扬：翼尖高过头顶 7 格 / 平展：往后平伸 16 格 / 下压：翼尖垂到脚边 / 回收：半收在身后），剪影里每帧翼形都不同；身体一颠一颠（0 / -1 / -2 / -1），两腿交替蹬，身下拖 1 颗暗紫火星。
  - 死亡方式：化烟——挨打失衡往下坠，「噗」地炸成一团紫黑烟，三叉掉在地上，烟里弹出一对小角落地，然后连叉带角化灰。
  - 主色：品红紫皮 + 墨紫翼 + 金眼；同组人形主色为灰青蓝、巧克力褐、墨绿袍、橄榄军装、橙背心、灰白病态肉，不撞。

# 特效设定卡 · 恶魔二人组 · 暗影紫焰

- 元素色阶：FXI.shadow 淡紫 43 → 紫 54 → 深紫 53 → 墨紫 52 → 墨 0（只用它 + 通用 impact / dust）。
- 攻击（刺，三连）：预兆 = 叉往后引平端、身体上抬 1 格、齿尖亮一档；出手 = 第 2 / 4 / 6 帧各戳一下，前冲 4–5 格俯冲下压 1 格，身后三道暗紫速度线 2 帧 + 叉尖十字；命中 = 每戳 6 颗暗紫火星 + impact 1 颗，假人小摇，第三下 10 颗。
- 技能「恶魔二人组」：
  - 蓄力：转身、降到贴地，叉尖朝下抵住身后地面来回划；地面上的五芒阵按笔画一笔一笔画出来并慢慢转（外椭圆点阵 + 五角星，蓄满后星线闪白）；阵心不断冒暗紫火苗，叉尖划地迸火星；0.7 秒起小羊角和齿尖亮起（角换发光材质、齿尖 1 / 2 档逐帧闪），轮廓光 2 档，眼光变亮。
  - 施放：转回来升起、张翅高举三叉（之后翅膀压低扑动，不挡搭档）；法阵（身后 26 格）裂开（断续、闪白）+ 28 颗暗影外爆 + 冲击环 + 两道地裂 + 十字星芒，震屏 2 格 + 天空闪白；第 0–2 帧第二只小鬼以实心墨紫（第 4 级）剪影 + 一圈淡紫亮边从阵里弹起，第 3 帧落到阵上变成实体（尘土 + 小火星）；第 4 帧两只一起竖叉，叉尖各射出一颗暗紫火花飞向假人。
  - 命中：双击——第一颗 10 颗外爆 + 十字、假人小摇；第二颗 16 颗外爆 + 冲击环、假人大摇击退，震屏 1 格。
  - 收招：搭档蹦到身后 16 格处，本体收拢翅膀、后手举到头后上方，搭档（叉换到后手）前手举起，两只击掌——一圈淡紫火星 + 十字；随后搭档从头顶开始化成暗烟（烟团 + 往阵里沉的烟粒），法阵暗下去熄灭（演示循环用）。
- 受击：肉身 → 引擎 impact 火花 + 白色剪影 1 帧 + 击退 2 格；闭眼张嘴、耳朵后贴、翅膀猛张、尾巴甩直。
- 死亡：受击闪白 → 翅膀垂落、缩身下坠 2 格 → 「噗」紫黑烟团（两团 fx.cloud + 22 颗外爆 + 震屏 1 格）→ 三叉从 9 格高掉到地上（尘土、齿尖熄灭）→ 一对小角从烟里弹出，往身后抛落、弹一下 → 静止 → 自上而下消散，灰（dust）和少量暗紫烟上升。
- 音色：小翅膀的急促扑扇 + 尖细的嘻嘻坏笑，标志性一声是召唤时「噗！」的烟雾爆开接两声击掌，重量 0.2（悬浮）。SFX 声明：body flesh、how explode、pal shadow、style summon、w 0.2、hover 1；step（扑翼下压帧，w 0.1）、swing（thrust）+ hit（flesh）在三个戳出帧、shoot（orb）在两只一起发火花、impact（shadow）在法阵裂开 / 两颗火花命中 / 击掌、fall 在三叉落地帧。
