# 水战士 WaterWarrior

模块：`pcd/chars/WaterWarrior.js`。身体用部件库拼（`rig slim` + `legs bare` + `torso bare` + `arm tight` + `hand` + `head` + `hair short`），另外自己画了 3 个候选部件（湿长发、背鳍、反握骨刃，见文末）。
升级线：→ `ImmortalBlueDemon.js`（不朽蓝魔）。两级共用的识别特征：**湿发 → 长鬃、背鳍 → 带骨刺的大鳍、鱼骨短刃 → 鱼骨月牙弯刃、颈侧腮裂 → 发光腮纹、腰间烂布条 → 暗影破布**。

## 角色设定卡

- 名称 / 身份：水战士，溺亡后爬回来的尸体刺客（优质品质：细节中等，只有眼窝两点魂火是发光体）。
- 一句话剪影：**伏得很低的瘦尸 + 背脊一排往后上方斜的半透明鱼鳍棘 + 一头湿发垂到腰后再往身后拖 + 前手平伸、骨刃贴在前臂下伸出肘外**。剪影一眼读成「贴地潜伏的刺客」。
- 尺寸：站直约 26 格；平时常驻伏低（crouch 3 + 前倾 lean 2 + 微驼 hunch 1），待机只有约 23 格高（含发顶，包围盒 23 × 25 含勾线）。分配写的是「常驻 crouch 2、伏低 22 格」：rig 每档 crouch 压低 1 格，crouch 2 待机会到 24 格，所以取 crouch 3，让伏低高度最接近 22 格。体型 `slim` 覆盖 `arm 11`（手臂长过膝）、`sw 3`（窄肩）、`lw 2`（细腿）、`stride 3`、`head 7 / headW 6`（头 7 格给脸、腮留位置）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 苍绿泡水尸肤 [#1a2420, #3c5248, #6a8a76, #a4c2a8]（主材质，面积最大）
  - 海草发 墨绿褐 [#0c140a, #1e2e16, #34482a, #54683e]
  - 背鳍 淡青半透 [#1e3a40, #3a6a70, #6aa0a4, #a0d0d0]
  - 鱼骨刃 `bone` [8, 7, 6, 17]
  - 烂渔网绳 灰褐 [#1c1814, #3e362c, #6a5c48, #8c7c62] · 烂布条 `stone` [0, 8, 9, 10]
  - 眼窝魂火（发光体，flat）= 溺潭碧色阶 [#0c2a3e, #1e6a8a, #4ab8d8, #b0f0ff]
  - 本角色追加 20 个专属色（上限 24）。
- 部件顺序（从后往前）：湿长发后层 → 背鳍 → 后臂（暗一级）→ 后手骨刃 → 后手 → 腿（远侧暗一级）→ 躯干（赤膊 + 腰绳 + 缠腰布 + 斜挎的烂渔网 + 肋骨 + 腰后垂下的破布，同一部件）→ 头（瘦削长脸、魂火眼、鼻、嘴线、颈侧三道腮裂，同一部件）→ 发顶 + 额前一绺湿发 → 前臂 → 前手骨刃 → 前手。
- 细节清单：
  - 脸：魂火眼（亮 + 暗 2 格）、眉骨、尖鼻、嘴线、瘦削下巴；颈侧三道腮裂（待机随呼吸一张一合：张开 = 深缝 + 下沿亮边）。
  - 发：头顶一层湿发（一点湿光）+ 额前一绺；后脑贴着头皮垂下一片（2 列）；后层分三绺顺着背垂下——外绺（根部 2 格粗）到腰后、中绺到背中偏下、内绺最短——再各自往身后拖（外绺 4 格、中绺 3 格、内绺 2 格），梢头各亮一格 = 湿光、会滴水。垂着时发梢下坠；小跑 / 甩水时三绺各自 1 格细、波浪错相（外绺往下弯、中绺往上挑），拖成几条分开的海草，不会并成一块。
  - 背鳍：后颈 → 胯 3 根鳍棘往后上方斜（第一根最长），棘间鳍膜隔点镂空（透出后面的发 / 勾线色 = 半透明），膜外沿在两棘之间凹下去 = 锯齿。
  - 服装：赤膊（胸线、肋骨）、一条斜挎的烂渔网（两根绳 + 网眼结）、腰绳 + 缠腰布、腰后垂下的一条破布（随下摆摆动）、手腕缠一圈烂绳。
  - 手臂 / 腿：2 格细臂（长过膝）、2×2 手；赤足，前脚脚尖多 1 格。
  - 武器：一对反握鱼颌骨短刃——刃沿「手 → 肘」方向贴在前臂外下侧，伸出肘外 3 格；刃脊在受光一侧，刃口一侧隔格缺一格 = 锯齿；柄头一颗骨节，柄缠海草；前手刃出手时刃尖闪一下。
- 攻击方式：近战 **斩（反握双持）**：伏身、前手举到头侧 → 前冲 5 格，前手向下斜斩（第 2 帧）→ 后手向上斜斩（第 4 帧），两道溺潭碧弧形刃痕一前一后交叉 → 缓回伏低。
- 差异化（对照同组 / 已通过）：
  - 体型档：瘦削伏低档（全组唯一常驻伏低的人形）。步卒是佝背站立的渔夫（hunch 1、尖锥斗笠、龟壳盾），本角色不戴帽、一头湿发、整个身体压低前倾；守夜人 / 维京战士都是直立标准档。
  - 识别特征（≥ 2 个改外轮廓）：①湿发垂到腰后再往后拖（轮廓）②背脊鳍棘（轮廓，锯齿）③反握骨刃伸出肘外（轮廓）④苍绿尸肤 + 颈侧腮裂 + 魂火眼。
  - 武器 + 握法 + 攻击类型：反握双持 + 斩（交叉两道斜弧）。同组步卒是双手钩竿钩拉、赤十字双手钩镰横扫、炎帝双手上挑、食人魔单手反手横拍——没有反握双持。
  - 动作个性：待机 = 甩水（每个循环猛甩一次头，湿发甩出 4 滴水珠，落地溅开 + 留水渍；腮裂一张一合；发梢平时也会滴水）；步态 = 伏身潜行小跑（小步快跑、贴地，头发和背鳍往后拖，每个脚印留 1 格水渍、不扬尘）；死亡 = 融化（死亡套件 melt，全组唯一）。
  - 主色：苍绿泡水尸肤 + 墨绿褐发 + 淡青鳍，和步卒的稻草黄蓑衣、赤十字的朱红、食人魔的灰紫都拉开。
  - 特效：溺潭碧水系（自建色阶），同组没有水元素（步卒是冷魂青魂火）。
  - 自动查重：`compare.mjs` 对范式 + accepted 退出码 0（最近：鹰喙弓手，待机 IoU 0.597、配色 0.42；驱魔修女 0.591）；对同批已产出的角色也没有撞脸（最近：步卒 0.607、雏鸡 0.595）。

## 特效设定卡

- 元素：伏击 · 溺潭碧，`fxRamp('drownpool')` = 21 白 → #b0f0ff 水白 → #4ab8d8 碧蓝 → #1e6a8a 深碧 → #0c2a3e 墨潭。受击另混 impact 火花。
- 攻击「反握交叉斩」
  - 预兆：伏身，前手举到头侧、刃朝后上（1 帧缓出），魂火亮一档。
  - 出手：第 2 帧前冲 5 格，前手向下斜斩，前手刃尖闪一下；溺潭碧斩击弧（半径 11，从后上到前下，2 格宽 → 1 格断续）。第 4 帧后手向上斜斩，第二道弧从前下到前上。
  - 命中（两次）：假人闪白小摇；8 颗 impact 火花 + 4 颗水花（带重力落地）。
- 移动：伏身潜行小跑，每个接触帧在脚印处留 1 格水渍（K_STILL，溺潭碧后三级，0.3 s 走完），不扬尘；偶尔发梢滴一滴水。
- 技能「伏击」（开战遁地潜行，几秒后从敌人脚下破水而出偷袭）
  - 蓄力 1.4 s：0–0.35 s 脚下渗出一滩水（地面上碧色隔点的扁椭圆，外沿一圈亮）；水从四周贴着地面旋进水潭（扁螺旋定点汇聚）；他蹲下，0.42 s 起按行沉进水面（贴地截断 clipY，每帧沉 3 行）；0.9 s 只剩头和肩在水上；1.0–1.25 s 只剩头发在水面上漂转一圈；1.25 s 连头发一起没入——小环 ring + 两圈扁椭圆涟漪 + 几滴溅水（「咕咚」）。轮廓光 2 档（光从脚下的水潭照上来，照亮手脚下沿和水线），魂火 1/2 档逐帧闪。
  - 施放 0.5 s：原位水面消失（溅几滴水）；假人脚下鼓起一圈水面，一道水柱从地面往上冲起（0.1 s 冲到 34 格高，顶上一圈水花，0.2 s 后塌回去、合斩前落完，候选特效「水柱」）；18 颗碧色外爆 + 小冲击环；震屏 2 格、天空闪白。第 1 帧他在假人身后（镜像朝左）显形闪白、跃出水柱，第 2–3 帧空中举刃（前刃在上、后刃在下）。
  - 命中（施放第 4 帧）：剪刀合斩——两道带弧度的长斩痕（22 × 24）在假人身上交成 X（前 2 帧碧蓝芯 + 深碧边、两头水白、交叉点纯白——压在闪白的假人上也看得清，之后断续变暗）；24 颗水花溅液（K_PHYS 带重力，4 颗 2×2）+ 10 颗外爆 + 大冲击环；假人闪白大摇、击退 1 格（往回击）；震屏 1 格。
  - 收招 0.7 s：落地甩水（头一甩，4 滴水往身后甩）→ 沉进身后的水洼（2 帧）→ 从原位的水潭里一行行冒出来，缩回伏低姿；魂火 2 → 1 → 0。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼（魂火灭）+ 湿发往前甩起；10 颗 impact 火花 + 8 颗溅水；震屏 1 格。
- 死亡：16 颗火花 + 12 颗溅水 + 震屏 2 格 + 天空闪白 → 踉跄 → 跪倒（手垂到地）→ 0.72 s 融化：身体从脚往上按列塌成一滩（死亡套件 melt），两把短刃脱手掉进水滩（落地一弹）；身下的水滩越摊越大，塌下去的尸身表面泛一行水光；1.27 s 塌下去时「啪」一声（fall）+ 两圈涟漪 + 溅水；1.62 s 塌平成一滩，静止 0.6 s → 2.22 s 起水滩连同短刃抖动消散（0.6 s），水面蒸发成上升的溺潭碧粒子（魂光换成水汽）。
- 音色：滴水声和湿脚掌的「啪嗒」；标志性的一声 = 沉入水中的「咕咚」，接着破水而出的「哗啦」水柱声；重量 0.35（`SFX: body flesh · how collapse · pal water · style shadow · w 0.35`；step 0.25、swing slash 0.35 ×2、hit flesh 0.35 ×2、impact water 0.6（水柱）+ 0.8（合斩）、fall 0.35（塌成水滩））。

## 候选部件（写在模块里，函数前有「// 候选部件」注释，以后收进 parts.js）

- `wetHair(R, o)` 湿长发（后层）：`o = { mat, len 外绺往后拖的格数 }`，三绺长短不一（外绺到腰后、中绺到背中、内绺最短），拖出去的那段 1 格细；读 `P.beard`（< 0 往后飘直拖长、三绺波浪错相，> 0 甩起、发梢上翘）和 `P.sway + P.step`（波浪相位）。头顶那层用 `parts.hair 'short'`。
- `dorsalFin(R, o)` 背鳍：`o = { mat, h 棘长, n 棘数, y0 / y1, spike 棘尖骨刺材质 }`，读 `P.beard`。不朽蓝魔用同一个部件画更高、带骨刺的鳍。
- `boneBlade(T, gx, gy, a, m, wrap, len, glint)` 反握鱼颌骨短刃（吸附 16 向，斜放按主轴折算长度）+ `armBlade(R, arm, off, …)`：用 `parts.arm` 返回的手、肘位置，让刃贴着前臂伸出肘外。
- 特效「水柱」（fxFront 里自己画：从地面往上冲起、顶上水花、塌回去）和「扁椭圆水面 / 涟漪」（fxBack），通用的话可收进 `fx.*`。
