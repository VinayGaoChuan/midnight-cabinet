# 食人魔 Ogre

模块：`pcd/chars/Ogre.js`。身体用部件库拼：`rig`（stocky 改）`legs cape torso(bare) head arm hand hair`；库里没有的写在模块里，标「候选部件」：平底锅 `drawPan`、背锅 `drawPot`、熊头兜帽 `bearHood`、半截围裙 `waistApron`、岩壳甲片 `rockPlate`（外加缝合线 `stitch` 小画笔）。
设定：给格拉尔烤肉的亡灵厨子（描述里的「秘制烤肉」）。熊皮、铁锅、平底锅、獠牙四样一直传到两个升级形态：棕熊（熊皮长进身体、锅更大、平底锅成了锅盖）、指挥官（熊头变肩甲 + 披风、锅改成炮、平底锅铆在盾心）。

## 角色设定卡

- 名称 / 身份：食人魔，先锋（擅长防御）——剪影读成「肩背极厚、扛着大锅的矮壮前排」。优质：比普通多兜帽、围裙、缝合线这一层细节，发光体只有一双暗琥珀眼。
- 一句话剪影：**背上麻绳绑的大铁锅（锅沿高出肩 3 格，冒一缕汽）+ 头顶一张棕熊头皮兜帽（两只圆耳高出 2 格、熊吻向前伸出 3 格）+ 右手（前手）6×5 大平底锅**。
- 尺寸：待机 35×28 格（身体到熊耳 26 格，汤汽到 28 格）；体型 `stocky` 改 `leg 7 · torso 10 · head 5 · sw 6 · limb 1.5 · hunch 2 · neck 0 · arm 10 · lw 4 · waist 1.2 · belly 0`：倒三角——肩臂极宽、收腰、粗短腿；头只有 5 行高、陷在两肩之间（头顶只比斜方肌高 3 格），驼背前探；肚子不突出。
- 材质色阶：
  - 灰紫尸肤 [#1e1622, #3e3046, #62526a, #8c7c92]（主材质；远侧后臂暗一级）
  - 熊皮（兜帽、披在背后的熊皮、裹腿）灰褐熊毛 [#1e1814, #423830, #6a5c4c, #94846c]（和棕熊同一色阶；背后大块熊皮 band 2）
  - 铁锅 `iron` [0, 27, 28, 29]；平底锅面 `steel` [27, 28, 29, 30]（铸铁再亮一级才读得出锅面）+ 木柄 `wood`
  - 油渍围裙 [0, 20, 19, 32]（深皮革）+ 油渍 `boot`；麻绳 [20, 19, 61, 62]；獠牙 / 熊牙 `bone`；烤肉 [20, 44, 32, 33]
  - 岩壳 [0, 19, 61, 62]（土色石块）；眼 [20, 61, 62, 5]（平涂，暗琥珀 → 亮奶油 5 档）；汤 [20, 19, 61, 62]；汤汽 `white`
- 部件顺序（从后往前）：熊皮（`cape`）→ 背锅 + 一缕汤汽 →（反手后引时：平底锅）→ 后臂 → 腿（熊皮裹腿 + 赤脚）→ 躯干（赤膊 + 斜方肌隆起 + 斜挎麻绳 + 胸口缝合线）→ 半截围裙 →（背、大腿、胸口岩壳）→ 平底锅 → 前臂（+ 三角肌 + 缝合线）→（前臂岩壳）→ 头（+ 眼 + 两颗獠牙）→ 熊头兜帽 →（肩头岩壳）→（偷吃时：后臂 + 烤肉）→ 前手。头画在前肩之后：驼背前探的小头压在肩上，脸不被三角肌挡住。
- 细节清单：
  - 脸：兜帽下沿压出一行眉影、一格暗琥珀眼（发光体，5 档：暗 / 蓄力 / 亮 / 施放 / 熄灭）、小鼻、下颌线、脸颊浅疤；下颚两颗外翻黄獠牙（前一颗伸出脸外、斜向上翻；嚼东西时跟着下巴动）。
  - 熊头兜帽：3 行帽身、两只缺角圆耳（前耳会一抖往后贴）、熊吻伸出 3 格（吻背亮、黑熊鼻）、空洞熊眼 + 亮眉、上颚一颗白牙垂在额前、毛尖亮点；后沿一片熊皮垂下接到背后的熊皮。
  - 躯干：赤膊胸肌下沿 + 肚脐、两肩之间隆起的斜方肌、胸口一道缝合线（深色线 + 浅色针脚）、斜挎麻绳（绑锅）；半截围裙：腰带 + 背后绳结 + 口袋 + 5 点油渍 + 锯齿下摆（随 sway 摆）。
  - 手臂：粗臂（limb 1.5）、厚三角肌 + 高光、前臂一道缝合线、3×3 大拳。
  - 腿：熊皮裹腿（远侧暗一级）+ 赤脚。
  - 武器：平底锅——3 格木柄、6×5 锅面（锅心暗、右下一圈焦黑、左上一点冷光）。背锅：外翻锅沿（高光）、沿下阴影、鼓腹、锅耳、一道麻绳。
- 攻击方式：近战「拍」——单手反手横拍：平底锅拉到身后 1 帧（锅画到身体后面）→ 前冲 4 格、锅面横着拍出去（出手定格），锅面拖出身后 → 身前的一道扁横弧，「咣」一声火花。
- 差异化（对照已通过的屠夫领主 / 焚尸人 / 蛮兵 / 奴隶主 / 维京战士，和同组的石魔像、巨人战神）：
  - 体型档：倒三角矮壮（上宽下窄的猩猩式）。屠夫领主是 32 格桶腹前凸；焚尸人是方块状敦实、铁面罩；蛮兵是四肢着地的猿——食人魔直立、手不撑地、肚子不突出，宽的是肩和背锅。
  - 识别特征（≥ 2 改轮廓）：①背锅（轮廓，全组唯一的背负锅）②熊头兜帽两只圆耳 + 前伸熊吻（轮廓）③前手大平底锅（轮廓）④獠牙、尸肤缝合线、油渍围裙（内部）。
  - 武器 + 握法 + 攻击类型：平底锅 · 单手反手 · 横拍（屠夫领主单手过肩竖劈、蛮兵单手竖砸、焚尸人双手扫、石魔像直拳、巨人战神双手过顶砸）。
  - 动作个性：待机 = 偷吃（后手从背后锅里摸出烤肉，送到嘴边啃一口、嚼两下，熊耳跟着一抖）；步态 = 外八蹒跚（身体左右晃 1 格、接触帧顿挫 1 格、扬 3 颗尘、背锅每步颠一下）；死亡 = 后仰（仰面倒下，平底锅脱手转两圈落地，背锅压在身下挤出一滩汤，兜帽滑落）。
  - 主色：灰紫尸肤 + 灰褐熊皮 + 黑铁锅（屠夫领主肉粉、焚尸人炭灰、蛮兵锈红褐都拉开）。
  - 自动查重：`compare.mjs` 退出码 0（最近的奴隶主待机 IoU 0.598、维京战士 0.592）；同批三只互比：和指挥官 0.526、和棕熊 0.501。

## 特效设定卡

- 元素：硬化 · 岩壳土，色阶 `earth` = 奶油 5 → 62 → 61 → 19 → 20。汤汽另用 `ogreSteam` [21, 17, 18, 10, 9]（只做背锅冒的汽，不进技能）。
- 攻击「反手横拍」
  - 预兆：第 1 帧锅拉到身后、身体后仰 1 格（锅画到身体后面，前臂横过胸口）。
  - 出手：第 2 帧定格，前冲 4 格，锅面横在身前；身后 → 身前一道扁横弧拖影（第 1 帧 2 行亮、第 2 帧 1 行断续，earth 色阶）。
  - 命中：12 颗 impact + 5 颗钢色火星 + 十字星芒，假人闪白小摇。
- 技能「硬化」（被动特性生效的样子：开战一硬化，皮上结出岩壳、防御提高）
  - 蓄力 1.4 s：锅举到胸前（0.3 s），然后在 5/12、9/12、13/12 s 用平底锅「咚、咚、咚」敲自己胸口三下——每下锅面拍到胸口、身体往后顿 1 格（1 帧），拍出一片 3×3 岩壳（肩 → 胸 → 前臂依次出现），拍的地方溅土屑；脚下尘土沿两侧往上卷、沙土螺旋吸进胸口；轮廓光 1 → 2 档（只打在尸肤和岩壳上），眼 1 / 2 档逐帧闪，蓄满后浑身发抖。
  - 施放 0.5 s：全身岩壳一起合拢（背、大腿再多两片），整个身体闪一帧土色剪影；两臂张开仰头、双脚一跺（下蹲 2 格），脚下扬尘 + 冲击环，跺脚处裂开一道地裂直冲假人；震屏 2 格、天空闪白。2/12 s 地裂到假人脚下：碎石外爆（20 颗 + 10 颗带重力的碎石）+ 冲击环 + 十字星芒，假人闪白大摇、击退；震屏 1 格。
  - 收招 0.7 s：缓回待机，岩壳保持到 0.45 s，之后三帧里一片片剥落，每掉一片落一把土屑和尘。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼 + 熊皮后甩、熊耳一贴、背锅颠起；impact 16 颗；震屏 1 格。
- 死亡：26 颗 impact + 震屏 2 格 + 闪白 → 下蹲踉跄 → 平底锅脱手、两手乱抓后仰 → 仰面倒地（离地 3 → 1 → 0）→ 0.66 s 落地扬尘 16 颗 + 震屏 1 格；兜帽从头上滑到头边的地上（露出光头一圈残发）；背锅压在身下，汤从上背下面往两边淌开、冒汽 → 平底锅在空中转两圈（8 个 90°）后「咣」地平躺落地（钢色火星 + 尘）→ 眼闪几下熄灭 → 1.6–2.4 s 自上而下消散 + 魂光上升。
- 音色：肉体拍打的啪啪声，加铸铁「咣」的一声闷响；标志：锅敲胸口的「咚咚咚」（蓄力里三次 `hit metal`），接着岩壳合拢的「咔嚓」；重量 0.75（`SFX: body flesh · how topple · pal earth · style shield · w 0.75`）。音效时间线：move.step 5、attack.swing / hit、skill.charge / release、skill.hit 3（咚咚咚）、skill.impact、hurt、death、death.fall、death.hit（平底锅落地）。
