# 魔龙 MagicDragon

## 角色设定卡

- 名称 / 身份：魔龙，金龙进化成的巨型悬浮机械龙，远程射手（轨道炮光束），神话品质。「昂贵的造价」→ 紫黑钢装甲满身鎏金镶边、魔晶和发光导管；射程最远 → 武器从炮弹换成光束。
- 一句话剪影：一台悬在半空的巨型紫黑钢机械龙——前高后低昂首，吻前伸出两片平行的金色轨道炮颚，胸口一颗紫色魔晶被三道黄铜环绕着转，背上一面嵌着发光导管的大翼、翼后 3 根尖顶散热鳍塔，四只脚底是喷火的喷口。
- 尺寸：待机约 59 × 44 格（身体约 44 格长，离地 4 格悬浮）；神话档、同组最大。缓冲 116 × 72，脚底锚点 (56, 66)。
- 体型档：巨型悬浮机械四足（len 18、胸半径 8，比金龙长一截、胸更厚；lift 4 悬浮、pitch 1 前高后低）。身体用 parts-beast `B.quad`（dragon 头型放大 8 × 6.4、吻 6.5、后掠金角 7）+ `B.wing` 膜翼（翼展 20、4 根翼骨）+ `tail long`。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 紫黑钢装甲 [0, 53, 42, 54]（主材质，shadow 色阶亮面偏紫，身体 band 2）
  - 鎏金镶边 / 连杆 / 翼骨 / 角 gold [20, 19, 14, 5]
  - 紫黑钢片翼膜 shadow [0, 52, 53, 54]（比身体暗一级）
  - 魔晶 [25, 42, 24, 43] + 过载 [43, 43, 21, 21]（平涂发光体，5 档）
  - 符文导管 / 魔晶导轨 magic 青紫 [25, 24, 23, 22]（平涂发光体）
  - 喷口火 fire [44, 45, 46, 47] + 白热 [47, 47, 21, 21]；喷嘴 iron
  - 烧红外壳（只在融化前 1 帧用）[44, 55, 45, 46]
- 部件顺序（从后往前）：远翼 → 远侧两条喷口腿 → 尾 → 躯干 + 颈（+ 金边、金甲缝、金龙骨、颈上三道金箍）→ 胸口反应堆（环后半圈 → 魔晶 → 环前半圈）→ 近侧两条喷口腿 → 近翼（+ 导管节点）→ 翼根大齿轮 → 散热鳍塔 → 头（+ 金甲脊）→ 后掠金角 → 轨道炮颚。
- 细节清单：
  - 面部：淡紫发光豆眼、鼻孔、额顶到吻背一道金色甲脊；后掠长金角。
  - 口：轨道炮颚——上下两片金色颚板沿头部方向伸出吻前 6 格，张嘴时下颚板跟着张开，中间夹一根魔晶导轨（青紫发光，蓄力时导轨上跑白色光点）。承接金龙的口炮。
  - 胸：魔晶反应堆——7 × 9 菱形紫晶（5 档：暗 / 常 / 亮 / 过载白 / 裂灭加墨色裂纹）+ 三道黄铜环（各自错相绕转，看得出正面 / 侧面切换；蓄力时收紧）。承接锅炉门。
  - 背：3 根尖顶散热鳍塔（3 格宽，金 / 铁相间的鳍缝，顶上 2 格尖，最高高出背线 6 格；过载时塔身透白）。承接烟囱。
  - 翼：4 根金翼骨 + 翼根 7 格大齿轮（轴心是导管色）；紫黑钢片翼膜；导管节点在臂骨中点、腕、每根翼指 0.45 / 0.78 处（4 组，位 0 翼根 … 位 3 翼梢），亮 / 暗 / 白热三态。承接齿轮骨翼。
  - 腿：四条垂着的腿，脚底 3 格铁喷嘴 + 1–3 格火舌（白热芯）。
  - 躯干：背线金边（隔格高光）、每 5 列一道金甲缝、腹底金龙骨。
- 攻击方式：远程（光束）：昂头张颚，两片炮颚之间射出一道 2 格宽的紫焰光束直达目标。
- 差异化：
  - 体型档：巨型悬浮机械四足（金龙站地；复仇之龙 / 天龙悬浮但一个是翼龙两足腐肉、一个是蛇身；本组唯一靠喷口悬浮的四足）。
  - 识别特征：①吻前 6 格的轨道炮颚（改轮廓）②竖起的导管大翼 + 翼根齿轮（改轮廓）③3 根尖顶散热鳍塔（改轮廓）④胸口旋转反应堆（轮廓内发光体）⑤四只喷口脚（改轮廓下沿）。
  - 武器 + 握法 + 攻击类型：轨道炮颚 · 口含 · 光束（金龙是单发抛物线炮弹）。
  - 待机个性：反应堆旋转——胸口三道黄铜环慢慢错相转动，翼上导管从根到梢依次亮一遍后整翼一闪，长尾左右缓摆，喷口火舌一闪一闪。
  - 步态：喷射悬浮——身体离地 4 格滑行、上下飘 1 格，垂着的四足对角划动、火舌一长一短，身下掉紫焰余烬，地面有影子。
  - 死亡方式：融化——反应堆过载闪紫白 → 喷口熄火坠地 → 外壳烧红、按列熔成一滩（死亡套件 melt）→ 魔晶在熔滩上闪几下后裂成碎片熄灭 → 蒸汽上升后消散。
  - 主色：紫黑钢 + 鎏金（本组唯一紫黑主材质；毒龙的腐紫只在翼膜和花上，主体是墨绿）。
