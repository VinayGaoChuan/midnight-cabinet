# 巫师 Wizard

模块：`pcd/chars/Wizard.js`。身体用部件库拼（`parts.rig` tall 加长臂、`legs` shoe、`torso` coat、`arm`、`head`、`hand`），库里没有的部件在模块里自画，函数前标了「// 候选部件」：`dynamoPack`（背负手摇发电机 + 曲柄 + 两根避雷针）、`staticHair`（静电炸毛）、`electrode`（铜电极棒 + 发光铜球）。
升级线：巫师 → 监工。背负发电机变成步行椅背上的秘银核心引擎，静电白发、额上放大镜（到监工变成单片眼镜）保留，电极棒变成铆钉枪电极和指挥手杖。

## 角色设定卡

- 名称 / 身份：巫师，科技族的疯狂电学家（祭司：给身边友军充电加攻速，本人很脆）。
- 一句话剪影：背上一台圆铜壳手摇发电机，顶上两根铜避雷针高出头 6 格；一头四面竖起的静电白发把头撑宽；两手各握一根铜电极棒，在胸前交叉成 X：前手那根朝前上、铜球伸到脸前，后手那根朝后下、铜球伸出长褂后沿 3 格（在发电机下面），剪影两侧各有一颗铜球。
- 尺寸：待机 24×37 格（人 28 格，炸毛到 30，避雷针顶到 35）。优质，高个细长档（头身比约 5，腿 11、身 10、头 6，臂长 12）。

  - 白发 / 眉 `white`；肤 `skin`；裤 `stone`；鞋 `boot`；衬衫领 `white`

## 特效设定卡

- 元素：充能 · 紫电。自建色阶 `wizVolt` = 21 白 → 43 淡紫 → 24 紫 → 42 深紫 → 25 靛紫（全是共享色；FXI.curse 前面补上白色这一级，爆发帧有最亮的一刻）。
- 攻击「放电」：
  - 预兆：两棒竖起收到胸前 1–2 帧，铜球 1 档。
  - 出手：两棒并拢平指目标，定格 1 帧；铜球 3 档 + 枪口十字光 2 帧；一道 `fx.bolt` 折线紫电弧从棒头直达假人，逐帧抖动。
  - 命中：目标处 10 颗紫火花外爆 + 假人闪白小摇。
- 移动：踮脚碎步，只在接触 A 那一步带 1 颗尘土；两根电极棒保持交叉握法，随步子各摆一档角度。
- 技能「充能」（光环：让身边友军攻速提高）：
  - 蓄力 1.4 s：后手反手疯狂摇曲柄（前 0.5 s 每 3 帧一档 → 每 2 帧 → 最后每帧），前手举电极朝天；避雷针之间的电弧由断续变连续、由 1 行变 2 行并往上拱；白发全部竖直；紫火花从四周螺旋汇向两根针尖；铜球 1/2 档逐帧闪；轮廓光 2 档；脚下紫色法阵 + 地面隔点映光。
  - 施放 0.5 s：两根电极棒举过头顶交叉；避雷针向四周射出 5 道折线电弧（2 道到身边两名友军头顶，另有 `fx.link` 虚线连到友军；1 道朝天、2 道落在左右地面），每个落点炸一颗紫火花；十字星芒 + 蓄力火花外爆；震屏 2 格 0.28 s + 天空闪白 0.05 s；友军描紫边 1.15 s。
  - 命中：以巫师为中心，地面一圈紫色点阵环向外扩散 3 次（时长 0.46 → 0.32 → 0.20 s，一次比一次快＝节拍加速），每圈开始时两名友军站位上各跳起 4 颗向上蹦、落地走完色阶的小电火花。
  - 收招 0.7 s：曲柄慢下来（每 3 帧一档后停住），头发塌回一半，铜球 2 → 1 → 0。
- 受击：引擎默认 impact 火花 + 白色剪影 1 帧 + 击退 2 格 + 闭眼；炸毛被打得往后甩、长褂下摆反甩。
- 死亡（化灰）：命中闪白 → 全身紫白交替闪 2 帧、两臂张开僵直、头发全竖 → 变成焦黑剪影（外沿一圈灰烬色勾线）并冒黑烟（dust 色阶暗段上升）、沿外沿不时升起紫电火星，静止约 0.95 s → 从头到脚像素消散，消散线上落下灰屑、升起紫色魂光，脚边灰堆由小变大 → 两根黄铜避雷针（没被烧黑）向后倒下、落在身后地上叮当一声 + 几点紫火星，最后才消失。
- 音色：手摇发电机「咯啦咯啦」越摇越快 + 电弧「噼啪」连跳，重量 0.35。SFX 声明 `{ body: 'flesh', how: 'dissolve', pal: 'bolt', style: 'buff', w: 0.35 }`；`step`（接触帧 0.25）、`swing`（staff）+ `hit`（magic）在出手帧、`impact`（bolt）在施放电弧落地、`fall`（0.2）在避雷针落地。
