# 监工 Supervisor

模块：`pcd/chars/Supervisor.js`。人的上半身用部件库（`parts.rig` fat、`torso` coat、`arm`、`head`、`beard` mustache、`hat` top、`hand`）；坐姿、步行椅和法器是模块自画的部件（函数前标了「// 候选部件」）：`mithrilCore`（秘银核心 + 四片护罩花瓣 + 四根避雷针）、`walkerChair`（椅背 + 座箱 + 脚踏）、`pistonLeg`（活塞直腿）、`hatHair`（帽檐下炸开的白发）、`seatedLegs`（坐姿双腿）、`cane`（秘银头指挥手杖）、`rivetArm`（三节机械臂 + 铆钉枪）。

## 特效设定卡

- 元素：秘银 · 银白齿轮光，FXI.steel（21 白 → 31 银 → 30 灰蓝 → 29 铁 → 28 深铁）起手；紫电收尾用巫师同一条 `wizVolt`（21 → 43 → 24 → 42 → 25），承接升级线。

  - 出手：手杖一指定格，枪身后坐 1 格，枪口 2 档 + 火色枪口光 2 帧 + 5 颗银火花；铆钉弹道 fire 色阶拖尾。

- 移动：每步活塞落地——液压白汽（银白色阶，朝后喷）+ 3 颗尘土 + 身体顿挫 1 格。
- 技能「秘银核心」（大幅攻速光环）：
  - 蓄力 1.4 s：护罩花瓣从半开到全开；核心由慢到快转（刻线每 3 帧 → 2 帧 → 每帧移一格）；4 根避雷针在 0.3 / 0.55 / 0.8 / 1.05 s 依次点亮，每亮一根冒一个小十字光；监工起身半站、手杖高举；银白粒子从四周螺旋汇向核心；脚下法阵反转；轮廓光 2 → 3 档（rimAll，核心周围外沿全打光）。
  - 施放 0.5 s：手杖向前一指 + 前手把铜哨送到嘴边吹响（哨口冒白汽）；核心放出一圈带齿的银白齿轮环（椭圆，环边约每 3 格一个齿，边转边扩大到 50 格，0.62 s）；蓄力粒子外爆 + 20 颗银火花 + 十字星芒；震屏 2 格 0.28 s + 天空闪白 0.05 s；友军描银边 1.15 s。

- 死亡（瘫塌）：命中闪白 → 秘银核心闪三下熄灭、护罩花瓣合拢，人往后歪 → 两条活塞腿同时折叠（两帧下沉 4 → 7 → 9 格），椅子「咚」地坐到地上：16 颗尘土 + 震屏 1 格 → 监工歪倒在椅背上、闭眼，礼帽滚落到脚边（抛物线 0.3 s，滚动时转 90°）→ 静止 → 自上而下消散，银白魂光上升。
