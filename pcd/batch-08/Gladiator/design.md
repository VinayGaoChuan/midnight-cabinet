# 角斗士（Gladiator）

## 角色设定卡

- 名称 / 身份：角斗士，科技族刺客（部队，稀有，近战 272）。竞技场机械斗士，升级线第一级（升级为狂战士）。
- 一句话剪影：盔顶一道从前额弯到后脑的黄铜鱼鳍冠（高出头 4 格）+ 右臂整条套着的超大机械护臂（肩甲高出肩 2 格）+ 左手挡在身前的尖钉小圆盾，右手宽刃短剑斜指前方。
- 尺寸：约 29 格高（鳍冠顶），待机外框约 25×31；脚底在地面线。
- 体型档：精悍斗士档——`parts.rig slim` 改：sw 5（宽肩）、waist 1（收腰）、neck 1、torso 9、limb 1.15、stride 4、lift 1；全程 crouch 1 低重心半蹲、身体侧对目标。刺客的轻快（细腿、侧滑步）加上「防御型」的小盾。
- 材质色阶（[勾线, 暗, 基, 亮]，全部取自共享色板）：
  - 古铜肤 skin = skinDark [20, 19, 16, 15]（面积最大：赤膊）
  - 黄铜护臂 / 盔 / 护手 brass = gold [20, 19, 14, 5]
  - 铁（肩甲主体、活塞杆、格栅缝、未亮的刻度灯）iron = [0, 27, 28, 29]
  - 竞技红缠腰 cloth = crimson [11, 12, 13, 26]
  - 刃 / 盾面 steel = [27, 28, 29, 30]，刃口 edge = white [7, 18, 17, 21]
  - 凉鞋绑带 / 剑柄缠皮 / 护腕 strap = leather [20, 19, 32, 33]
  - 刻度灯（发光体）light = fire [44, 45, 46, 47] flat；面罩眼光 eye = fire flat
  - 盔脱落后的短发 hair = boot
- 部件顺序（从后往前）：腰后缠腰带尾 → 后臂（赤膊 + 皮护腕，grip none）→ 腿（凉鞋）→ 躯干（赤膊 + 红缠腰 + 铜扣 + 前垂布）→ 格栅鳍冠盔（盔 + 下巴同一部件）→ 鳍冠 → 尖钉小圆盾（左手，挡在胸前）→ 宽刃短剑 → 机械护臂（臂 + 刻度灯同一部件）→ 肩甲 → 3×3 黄铜爪手（压在剑柄上）。
- 细节清单：
  - 脸：竖格栅面罩（框 · 缝 · 栅 · 框 4 列）、缝里 1 格橙色眼光、格栅下露出下巴；受击 / 死亡眼光熄灭。盔脱落后露出方下巴、粗犷脸和短发。
  - 头饰：黄铜圆顶 + 箍带铆钉 + 护颈 + 面罩铰链；鳍冠 2 格宽的弧，外沿每 3 格一个高光。
  - 躯干：赤膊胸肌下沿、腹肌、肚脐；红缠腰 2 行 + 铜扣 + 前垂布；腰后两条带尾（4 格 + 3 格，末端下垂，随步伐 / 风甩）。
  - 手臂：右臂黄铜机械护臂——上臂分节 + 背侧铁活塞杆、前臂粗一倍 + 两道铁分节箍、肘关节铜轴、上沿一排 5 颗刻度灯（亮几颗 = 连击数）；铁肩甲 + 黄铜镶边、高出肩 2 格；左臂赤膊 + 皮护腕。
  - 腿脚：凉鞋，远侧腿暗一级。
  - 武器：宽刃短剑（钢刃 + 白色刃口 + 血槽 + 黄铜护手 + 缠皮握把，刃长 7）；尖钉小圆盾（targe r 3：钢面 + 黄铜边框 4 颗铆钉 + 盾心铜包 + 盾心前伸 2 格尖钉）。
  - 发光体：刻度灯 5 档亮度（待机 / 蓄力 1 / 蓄满 / 施放 / 熄灭），死亡时一颗颗熄灭。
- 攻击方式：近战 · 刺——侧身弓步向前突刺 3 格，短剑从盾沿外平伸一戳即收（预兆 2 帧收剑压低 → 出手帧定格 → 3 帧延续 → 回位）。
- 差异化（和已通过角色比较）：
  - 体型档：精悍斗士（slim 改宽肩收腰 + 常驻半蹲）。影剑士也是 slim，但是前倾狐面具轻装；游侠 / 死亡射手是瘦高射手；角斗士是全队唯一赤膊 + 半蹲的 slim。
  - 识别特征：① 鳍冠盔（改外轮廓：盔顶弧形鳍向后伸出 4 格）② 超大机械护臂 + 高肩甲（改外轮廓：右肩鼓起、前臂粗一倍）③ 尖钉小圆盾（改外轮廓：胸前圆盾 + 前伸尖钉）④ 腰后红带尾（改外轮廓）。
  - 武器 + 握法 + 攻击类型：单手短剑 + 单手小盾 · 刺（守夜人是矛刺、野人矛兵双手端矛刺；持剑盾的角色都是劈 / 盾击）。
  - 待机个性：挑衅——剑背「锵锵」敲两下盾沿（钢色火星）→ 剑尖平指对手往上勾两下。
  - 步态：侧滑步——侧身半蹲、前脚滑出后脚跟上，重心不起伏（bob 0、抬脚 1 格），每步 1 颗尘土。
  - 死亡方式：侧倒——扭身踉跄（剑甩到头后、盾甩到身后）→ 仰面侧倒 → 鳍冠盔脱落翻滚着滚开 → 小圆盾立着滚出一段路、打转、平躺 → 刻度灯一颗颗熄灭。
  - 主色：古铜肤 + 黄铜（skinDark + gold），和同组的靛蓝、月白、烟熏皮、天青、钢灰、枪铁灰、酒红、深紫、黑礼服、鎏金龙、紫黑龙、土黄拉开；鎏金龙是整块黄铜，但它是四足龙，角斗士的大面积是赤膊古铜肤。
- 查重：compare.mjs 对 111 个已通过 / 参考角色全部不判重，最接近的待机 IoU 0.694、施放 IoU 0.453。

## 特效设定卡

- 元素：决斗 · 竞技红刃，色阶 blood = 21 白 → 58 淡粉 → 57 红 → 56 暗红 → 55 酒红；刃光点缀 steel（21 → 31 → 30）。
- 攻击「突刺」：
  - 预兆：收剑、身体压低 1 格、盾往前顶（2 帧）。
  - 出手：前冲 3 格定格，刻度灯多亮一颗、闪到蓄满档，剑尖后拉出一道红白直线拖影（第 1 帧白 / 粉 2 行，第 2 帧暗红 1 行断续），剑尖一点钢白星芒。
  - 命中：impact 8 颗 + blood 4 颗火花，假人闪白小摇。
- 技能「决斗者」（被动特性生效的样子：盯住同一个目标越打越痛）：
  - 蓄力 1.4 s：剑直指目标、身体压低 2 格；目标头顶张开一个红色决斗靶环（外圈 20 点隔点、内圈 10 点 + 十字准星）；护臂 5 颗刻度灯每 0.28 s 亮一颗；血色火星从四周螺旋吸进刻度灯；0.45 s 后灯在 1 / 2 档逐帧闪；轮廓光 2 档、地面隔点映光；缠腰带尾被吹向后。
  - 施放 0.5 s + 收招开头：连续三段突刺，每段 3 帧（出剑前冲 2 格 → 红白直线拖影 → 收剑），拖影长 12 格；每刺一次目标头顶靶环旁多一道刻痕（1、2、3 道竖线，新的一道先白），血色火花 10 颗 + 假人小摇 + 震屏 1 格。第三刺落在收招开头：前冲 3 格定格 0.34 s，18 格长拖影，目标身上爆出十字斩花（两道 45° 交叉斩线 + fx.cross 星芒）+ blood 外爆 30 颗 + 4 颗钢色火星，假人大摇击退，震屏 2 格 + 天空闪白。
  - 收招 0.7 s：靶环缩小消失，刻度灯保持亮着，亮度 3 → 2 → 1 慢慢暗回。
- 受击：肉身——引擎默认 impact 16 颗 + 白色剪影 1 帧 + 击退 2 格 + 眼光熄灭 + 缠腰带尾反甩；震屏 1 格。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 扭身踉跄 → 仰面侧倒（离地 3 → 1 → 0）→ 落地尘土 16 颗 + 震屏 1 格 → 鳍冠盔脱落翻滚着滚开、小圆盾立着滚出 16 格、打转（压扁）、平躺（尖钉朝天）、剑滑落在身旁 → 刻度灯每 0.12 s 灭一颗 → 自上而下消散 + 魂光上升。
- 音色：皮革与黄铜的轻碰声 + 短剑「锵」地敲盾，三连刺「嗖嗖嗖」后一声厚重的「噗」，重量 0.5。
  - SFX 声明：body flesh · how topple · pal blood · style blade · w 0.5；step（侧滑步接触帧 w 0.2）、swing thrust + hit flesh（出手帧 w 0.3）、impact blood（三刺各一次，第三刺 w 0.6）、fall（落地帧 w 0.45）。
