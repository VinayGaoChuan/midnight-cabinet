# 金龙 GoldenDragon

## 角色设定卡

- 名称 / 身份：金龙，科技种族造出来的发条机械龙，远程射手（口炮），史诗品质；会升级成魔龙。
- 一句话剪影：一整块黄铜铸成的方正四足机械龙——张开的下颌里伸出一截扩口黄铜口炮，背上一面齿轮骨翼竖起像一面铜帆，翼后一排 3 根短烟囱，腹侧一扇透出炉火的圆形锅炉门。
- 尺寸：待机约 49 × 38 格（身体约 40 格长 × 24 格高，翼顶到 36）；史诗档。缓冲 100 × 56，脚底锚点 (48, 52)。
- 体型档：机械四足龙（方正厚重：收腹 0、肩峰小、腿中等 leg 5、颈短粗 neck 3 / neckW 3.4）。身体用 parts-beast `B.quad`（dragon 头型 w 7 · h 6 · 吻高 4.8，去掉默认后掠角、不露牙）+ `B.wing` 膜翼 + `tail long`。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 鎏金黄铜装甲 gold [20, 19, 14, 5]（主材质，身体 band 2，四肢 / 头 / 口炮 band 1）
  - 铁关节 iron [0, 27, 28, 29]（爪、颈箍、烟囱筒、锅炉门框、腹底龙骨、关节螺栓、口炮铁箍、翼腕铁销、齿轮轴心）
  - 黄铜翼骨连杆 gold（近翼画成 tone 4 浅色 05 连续斜线，远翼自动明暗）
  - 红铜翼片 [0, 16, 16, 33]（只用 16 / 33，band 2；不借黄铜的暗色 19，和金色身体、齿轮拉开色相）

- 细节清单：
  - 面部：2 格猩红眼 + 眼正上方 2 格亮色 05 眉骨（在头部件最后画，甲缝从眼前 2 格才起）、鼻孔墨点、铁颌铰螺栓、吻背一道甲缝；张嘴时口里透炉火光（蓄力 / 攻击）；闭眼 / 死后熄火是 2 格暗酒红。
  - 头饰 / 口：口炮——待机下颌张开 2 格，2 格粗黄铜炮管卡在上下颌之间（上排亮 5、下排基色 14，管下留一行墨色口腔），两道铁箍（嘴里一道、炮口后一道，比管身暗）；炮口扩口 4 格高、伸出吻尖 4 格，扩口和吻尖之间隔 1 列只有炮管（扩口单独凸出来；蓄力再多伸 2 格），炮膛 1 格墨色、蓄力时映出炉火。炮管在屏幕上吸附到水平（头低到 1:2 以上才斜）。

  - 背负：3 根短烟囱立在翼后缘之后的腰背段（铁筒在 x −13 / −7 / −1）：2 格铁筒（左列亮、右列一深一浅）+ 3 格黄铜帽檐（向后翻的风帽），高度从后往前 2 / 3 / 4 格；相邻帽檐之间、最前一根和翼 / 齿轮之间都隔 ≥ 3 格（勾线 + 空 + 勾线），纯黑剪影里是 3 个独立小凸起；喷汽时帽檐掀起 1 格、露出墨色烟口。

  - 翼高偏离分配说明：分配写的是「半张时高出背 7 格」，现在待机竖帆的翼顶高出背线约 18 格。保留的原因：升级线下一级魔龙已经通过验收，它的剪影就是一对大竖翼，金龙的竖帆是它的前身，这样才读得出是同一个个体；而且竖帆是金龙远看唯一的高点，如果压到 7 格，会和 3 根烟囱、齿轮挤成一排小凸起，失去轮廓特征。
  - 腿 / 尾：腿膝中段一颗铁螺栓，铁爪；尾巴每 2 节一道节缝。
- 攻击方式：远程（射）：伏低后仰头，口炮「嘭」地射出一颗黄铜小炮弹（微微抛物线），炮口冒一团白汽。
- 差异化：
  - 体型档：方正厚重的机械四足（翡翠龙是圆滚幼龙、毒龙是前重后轻的肉身重龙、骨龙是骨架、游龙 / 天龙是蛇身、复仇之龙是悬浮翼龙）。
  - 识别特征：①口炮（张开的下颌里一根炮管，扩口伸出吻前 4 格，改轮廓）②竖起的齿轮骨翼 + 翼根大齿轮（改轮廓，翼顶高出背线约 18 格，齿轮上半露出背线）③背上 3 根烟囱（改轮廓）④腹侧锅炉门（轮廓内的发光体）。前三样升级线共有。
  - 武器 + 握法 + 攻击类型：口中炮管 · 口含 · 射（单发实心炮弹，走抛物线；其他龙是吐息 / 咬 / 魂焰弹）。
  - 待机个性：锅炉喷汽——三根烟囱轮流掀盖吐一口白汽，然后下颌咔哒咔哒合上又张开两下（2 → 0 → 2），翼根齿轮空转一圈；炉火偶尔一跳。
  - 步态：四足爬行，对角步态，金属爪落地身体顿挫 1 格、每步 2 颗尘土、第一根烟囱漏一口汽，翼齿轮随步转。
  - 死亡方式：侧卧散件——锅炉门弹开 → 侧倒四脚朝天 → 铁齿轮 / 铆钉从腹里滚出散落，眼随炉火闪几下后一起熄灭，尾部冒最后一缕烟。
  - 主色：鎏金黄铜（本组唯一金色主材质的龙；同组蝙蝠系是铁灰 / 酒红、法师系是靛蓝 / 月白 / 皮革 / 紫）。

## 第 1 轮修改记录

验收意见（review-1）的五条阻断问题逐条处理：
