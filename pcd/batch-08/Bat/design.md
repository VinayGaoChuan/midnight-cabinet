# 机枪蝠（Bat）

## 角色设定卡

- 名称 / 身份：机枪蝠，科技族射手（部队，优质，远程 640，飞行）。科技的蝙蝠就是一台铆钉扑翼机，腹下吊着一个真正开枪的小机枪手。升级线第一级，会升级成吸血蝠。
- 一句话剪影：一对帆布铆钉膜翼（3 根黄铜翼骨）+ 头顶两根钢支杆顶着两面会转的苍白钢碟形雷达（顶替蝠耳）+ 腹下两根吊杆挂的小圆吊舱，舱里戴皮帽的机枪手端着一挺往前伸的转管机枪。
- 尺寸：小型扑翼机档。身体离地 12 格（B.fly alt 12，rx 5 · ry 3.5），翼根到翼尖 16 格（后根距 6），待机外框约 27 宽 × 34 高（上扬翼尖到吊舱底）；吊舱让下半身轮廓往下垂 6 格，舱底离地 3 格。
- 材质色阶（[勾线, 暗, 基, 亮]，全部取自共享色板）：
  - 铁皮身体 body = iron [0, 27, 28, 29]，band 2（面积最大）；胸腹 belly = [0, 28, 29, 30]
  - 头（机头）head = steel [27, 28, 29, 30]；鼻头 steel
  - 翼膜 wing = 旧帆布暖灰 [8, 9, 7, 6]，band 2（低明度、偏冷，和黄铜翼骨拉开色相和明度）；远翼暗一级
  - 翼骨 / 吊舱镶边 / 机匣 = gold [20, 19, 14, 5]；远翼翼骨暗黄铜 [20, 20, 19, 14]；吊杆 gold 暗一级
  - 雷达碟 pale [8, 59, 60, 17]（碟沿亮），远侧暗一级；雷达支杆 steel
  - 吊舱 iron；转管机枪 steel；机枪手 皮帽 boot [0, 20, 20, 19]、夹克 leather、脸 skin
  - 眼（琥珀灯）eye = [0, 0, 47, 47] flat；枪口 / 雷达耳心（发光体）= [28, 30, 31, 21] flat
  - 降落伞 pale + crimson 条纹
- 部件顺序（从后往前）：远翼 → 远侧雷达耳 → 吊杆 → 身体（+ 竖接缝、铆钉）→ 机枪手（头、帽、肩）→ 吊舱 → 转管机枪（枪口发光体在同一部件）→ 机枪手的手 → 近翼 → 头 → 近侧雷达耳。
- 细节清单：
  - 脸：蝠头换成钢灰机头，琥珀灯眼 + 高光、鼻头；机枪手有皮帽前檐、护目镜、鼻、帽后护耳。
  - 头饰：两面碟形雷达耳，钢支杆（远耳 2 格、近耳从额头斜伸 4 格）+ 3 格苍白钢碟，两只碟之间连勾线空 1 列，都在翼根前面 ≥ 2 格；朝前时侧看是「(」+ 前伸的馈源，朝镜头时是 3×3 圆碟，朝后镜像；耳心（馈源）蓄力时发亮。
  - 身体：铁皮身体一道竖接缝 + 5 颗铆钉、浅钢胸腹。
  - 翅膀（本模块 notchedWing）：暖灰帆布膜 + 1 格黄铜臂骨与 3 根 1 格黄铜翼指（后两根从 1/3 处起，腕部露帆布）+ 指尖亮铆钉帽 + 腕部铰链；两指之间的膜边往腕部凹进 4 成（平展 / 下压帧的纯黑剪影里凹口 ≥ 2 格）。
  - 吊舱：黄铜上沿、铁舱壁一排铆钉、舱底收尖。
  - 武器：转管机枪——黄铜机匣 + 握把、3 根枪管（spin 相位决定哪根亮，高速时逐列明暗交替成残影）、一道黄铜箍、枪口发光体（暗 / 亮 / 白 / 熄 5 档）。
- 攻击方式：远程射击。机枪手压枪点射 3 发曳光小弹（1×2 白芯 + 银尾），每发吊舱后坐晃一下，吊舱下掉一颗黄铜弹壳。
- 差异化：
  - 体型档：小型扑翼机（B.fly 飞行骨架）。同为飞行的巫毒信徒 / 守卫是昆虫、曲速之翼 / 虚空魔鬼鱼是扁鳍、石像鬼是蹲伏人形；机枪蝠是唯一「身体 + 吊舱」两段式的剪影。
  - 识别特征：①帆布铆钉膜翼（改外轮廓）②头顶两面碟形雷达（改外轮廓）③腹下吊舱 + 前伸 6 格的转管机枪（改外轮廓，下垂 6 格）。三样全都留给吸血蝠。
  - 武器 + 握法 + 攻击类型：吊舱机枪手双手操纵转管机枪 · 射（连发曳光弹）。同为科技的哥布林直升机是双联炮交替点射铜弹、没有机枪手人形；机枪蝠是一个人端着一挺转管枪。
  - 待机个性：扑翼悬停，机枪手拿白抹布擦枪管（枪管跟着转），雷达耳左右转着张望（朝前 → 朝镜头 → 朝后 → 朝前）。
  - 步态：扑翼 4 帧（上扬 → 平展 → 下压 → 回收），身体前倾起伏 2 格，吊舱滞后半拍横摆 / 纵摆；身下拖银色尾迹，地面画影子。
  - 死亡方式：散架（见特效卡）。
  - 主色：枪铁灰铁皮 + 旧帆布翼，和同飞行体型的淡青绿、靛紫、天青、品红、墓石灰拉开。

## 特效设定卡

- 元素：曳光 · 刀锋银，FXI.steel = 21 白 → 31 银 → 30 灰蓝 → 29 铁 → 28 深铁；弹壳用 gold 小点（14 / 5 翻面交替）。
- 攻击「压枪点射」：
  - 预兆（2 帧）：雷达耳对准前方、耳心亮一格，枪管起转，机头微抬，枪口亮 1 档。
  - 出手（第 2、3、4 帧各一发）：枪口十字光 2 帧，曳光小弹 270 格/秒微微上扬打向假人胸口，每发吊舱后坐 1 格、弹壳从吊舱下掉落弹一下。
  - 命中：银色 + impact 小火花，假人闪白小摇。
- 技能「机枪手」（每 0.5 秒扫射附近一个敌人）：
  - 蓄力 1.4 s：机枪手拉一下枪栓（0.1–0.4 s），枪管从 3 帧一圈 → 每帧一圈 → 残影；雷达耳一齐转向目标、耳心在 1/2 档逐帧闪；银色火花螺旋收向枪口；轮廓光 2 档、地面映光；身体升高 2 格，蓄满后吊舱跟着抖。
  - 施放 0.5 s：12 发曳光小弹（每 0.04 s 一发）连成一串射向目标，枪口十字光每帧闪、吊舱每帧后坐，吊舱底下哗哗掉黄铜弹壳（带弹跳）；进入时蓄力火花外爆 + 小冲击环，震屏 2 格 + 天空闪白。
  - 命中：每发在目标身上迸一串银白小火花（每 3 发一个十字星芒），假人连续小摇；地面从近到远一排扬尘点（扫射线）。
  - 收招 0.7 s：枪管减速停下，枪口冒一缕细烟（dust 色阶上升粒子），枪口 2 → 1 → 0。
- 受击：机械材质——impact 火花 16 颗 + 白色剪影 1 帧 + 击退 2 格 + 闭眼；翅膀上扬、吊舱被甩向前、机枪手缩头、雷达耳甩到朝后；震屏 1 格。
- 死亡「散架」：26 颗火花 + 震屏 2 格 + 闪白 → 翼骨铰链崩开（两处翼根迸银火花）→ 两片翅膀先后翻飞飘落（近翼 1.1 s、远翼 1.35 s 落地，各起一小撮尘）→ 铁皮身体直线坠地（0.7 s）摔成几块：身体裂成两半、机头滚开、雷达耳朝天、吊舱侧翻、机枪甩到前面、铆钉崩飞（尘土 16 颗 + fall）→ 机枪手跳出吊舱、小降落伞弹开张开、慢慢飘到后方落地、伞布塌成一堆 → 枪口熄灭 → 一起自上而下消散 + 魂光上升。
- 音色：翼骨铰链「咔嗒咔嗒」的扑翼 + 转管机枪「哒哒哒哒」连发，弹壳叮当落地，重量 0.45。
