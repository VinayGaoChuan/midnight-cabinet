# 吸血蝠（VampireBat）

## 角色设定卡

- 名称 / 身份：吸血蝠，科技族祭司（部队，史诗，远程 760，飞行光环单位）。机枪蝠升级后的巨型扑翼轰炸机：保留铆钉膜翼、雷达耳、腹下吊舱；祭司的「强化」读法是头顶的扩音喇叭和红色光环，原来的机枪手升成了举旗的指挥官。
- 一句话剪影：36 格翼展的酒红燕尾膜翼（5 根黄铜翼骨）+ 两只大雷达耳中间一只朝前的黄铜扩音喇叭 + 腹下装甲弹舱挂 3 枚红尾翼炸弹，弹舱站台伸到机头前方，站着戴大檐帽、高举红信号旗的指挥官（整个人在机身轮廓外、旗尖高出机背 4 格）。
- 尺寸：巨型扑翼机档。身体离地 12 格（B.fly alt 12，rx 9 · ry 4.5，比机枪蝠长 4 格、厚 1 格），翼根到翼尖 19 格（上扬帧压低到 [1.05, -0.15, 0.15]），待机外框约 38 宽 × 35 高（翼尾到信号旗、上扬翼尖到炸弹尖）；身体更长更低，扑翼每 3 帧换一次翼姿（机枪蝠每 2 帧），慢而沉。
- 材质色阶（[勾线, 暗, 基, 亮]，全部取自共享色板）：
  - 翼膜 wing = blood [55, 56, 57, 58]，band 2（面积最大的酒红帆布）；远翼暗一级
  - 黑铁身体 body = iron [0, 27, 28, 29]，band 2（两色明暗）；胸腹 [0, 28, 29, 30]；机头亮一级 [0, 28, 29, 30]
  - 翼骨 / 喇叭 / 弹舱镶边 = gold [20, 19, 14, 5]；雷达碟 pale（承接机枪蝠的苍白钢碟）+ 钢支杆；獠牙亮钢 [27, 29, 30, 31]（远侧 [27, 28, 29, 30]）

  - 獠牙撞角 steel（远侧暗一级）；弹舱 / 吊架 iron；炸弹 [0, 27, 28, 29] + 尾翼 crimson
  - 指挥官：皮夹克 leather（承接机枪手）+ 金肩章、大檐帽 [0, 27, 28, 30]（墨色帽檐 + 受光帽顶）+ 金帽徽、皮靴 boot、脸 skin；信号旗 crimson、旗杆 wood + 金杆顶；指挥官整个人不吃喇叭的红轮廓光
  - 眼 [0, 0, 57, 58] flat；喇叭口 / 雷达耳心（发光体）= [12, 13, 26, 21] flat
- 部件顺序（从后往前）：远翼（+ 燕尾）→ 远侧雷达耳 → 吊架 → 身体（+ 两道接缝、铆钉）→ 弹舱（+ 伸到机头前的站台、斜撑、舱门）→ 炸弹 → 指挥官（靴、夹克、脸、帽、举旗的手臂同一个部件）→ 旗杆 → 旗面 → 近翼（+ 燕尾）→ 远侧獠牙 → 头 → 近侧獠牙 → 近侧雷达耳 → 扩音喇叭（+ 支柱，喇叭口发光体同一部件）。
- 细节清单：
  - 脸：黑铁机头、红灯眼 + 高光、钢鼻头；吻前一对下弯的钢獠牙撞角（先往前 2 格再往下勾 3 格，远侧那只暗一级错后 1 格）。指挥官：大檐帽 + 金帽徽、眼、鼻。

- 攻击方式：远程施法。抬头吸气 1–2 帧 → 喇叭向目标吼出一道声波（3 层同心红弧），身体后坐 1 格。
- 差异化：
  - 体型档：巨型扑翼机，机枪蝠放大一倍半、翼指 3 → 5、更长更低、扑翼慢一拍。与所有飞行角色（昆虫、扁鳍、蹲伏石像鬼、机甲）拉开。

  - 步态：滑翔——扑一下（上扬 → 下压）后展平滑行 2 帧（第 2 帧身体下沉），身体前倾，弹舱滞后摆，尾翼跟着抖；身下拖红色尾迹，地面画影子。
  - 死亡方式：坠落 + 殉爆（机枪蝠是空中散架 + 跳伞）。
  - 主色：酒红帆布翼 + 黑铁身体，和机枪蝠的沙色帆布 + 枪铁灰拉开，同时保留黄铜翼骨 / 雷达这条升级线的共同点缀。
