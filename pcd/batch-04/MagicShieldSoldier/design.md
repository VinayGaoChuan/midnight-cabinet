# 魔盾兵 MagicShieldSoldier

模块：`pcd/chars/MagicShieldSoldier.js`。身体用部件库拼（`rig 'stocky'`（覆盖 `sw 6 · limb 1.35 · lw 4`）`legs torso arm head`），库里没有的四个部件写在模块里，都标了「// 候选部件」：`runeTower`（矩形符文塔盾）、`finHelm`（鳍冠盔）、`layerPauldron`（三层叠片肩甲）；另有本角色专用的半截碎盾、腰间符文石片和坐倒的腿。
推导：名字里的「魔盾」→ 一面刻满符文的青铜大塔盾，占了身体一大半；「重装」+「不以攻击力著称」→ 矮壮、全身甲、没有像样的武器，只会顶盾推人；没有特性，技能状态表现名字里的「魔盾」：盾面张开一道符文护壁。
升级线：破魔守卫是同一个兽人，塔盾、鳍冠盔、叠片肩甲都保留，青铜升级成秘银。

## 角色设定卡

- 名称 / 身份：魔盾兵，兽人重装盾兵（先锋 = 防御）。
- 一句话剪影：**一面举在身前、上沿两角翘着獠牙护角的长方形塔盾**，盾后缩着一顶竖着锯齿鳍冠的圆盔（盔顶和盾顶齐平，盔缝里的琥珀小眼和外翻獠牙露在头和盾之间的缝里），背后伸出一大块三层叠片肩甲；没有武器。纯黑剪影读成「躲在大盾后面的矮个重甲兵」：头和盾之间留一道凹口，两块形状分得开。
- 尺寸：待机外框 26×27 格（身体约 18×24，鳍冠顶到 −25）；塔盾 11×17 格。体型 `stocky`（覆盖 `headX −2`：头缩在肩后）：胯高 6、躯干 9、肩宽 12 格，腿短粗（腿粗 4）、重心低；待机下蹲 2 格缩在盾后，双手把盾举在身前 3 格（盾面左沿和盔面之间空 2 格），站位 `HX 74`。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 暗青铜（塔盾与重甲，面积最大）[#1a1208, #4a3418, #7a5a2a, #b08a48] —— 本角色专属色（共享色板里没有青铜）；盾单独一个同色材质，轮廓光只照盾沿
  - 铁 `iron` [0, 27, 28, 29]：叠片肩甲、腿甲、鳍冠、腰带
  - 皮肤 墨绿 `moss` [0, 34, 35, 36]：只从盔缝里露出下巴
  - 獠牙 / 盾的獠牙护角 `bone` [8, 7, 6, 17]
  - 符文（flat 发光体）[42, #8a5ce0, 43, 21]：熄灭 = 深紫 42，待机 = 符文紫，蓄力 = 淡紫 43，施放 = 白 21
  - 眼（flat）[0, 20, 14, 47]：一对小琥珀眼；符文石片 `stone` + 挂绳 `leather`
- 部件顺序（从后往前）：后臂（铁臂甲，暗一级）→ 后肩叠片肩甲 → 腿（胫甲 + 青铜靴；坐倒时换成往前伸的腿）→ 躯干（青铜板甲，下摆收到胯）→ 腰间符文石片 → 前臂 → 近侧肩甲 → 头 → 鳍冠盔（盔体 → 鳍冠）→ 塔盾（碎后换成半截盾）。近侧肩甲画在头之前，护颊和獠牙压在肩甲上面。
- 细节清单：
  - 脸：闭口圆盔的眼缝（暗缝里一对小琥珀眼，远侧那只暗一级）、眉脊高光、口缝里露出墨绿下巴、一根从口缝伸出盔沿往上翘的獠牙；受击 / 死亡时眼缝全黑（闭眼）。
  - 头饰：圆盔 + 两颗铆钉 + 近侧獠牙形护颊（从盔底垂下 3 行、尖端往前勾）；鳍冠是单独的部件，头顶正中一道前后贯通的锯齿鳍（高 4 格，三个齿尖受光）。死亡时整顶盔往后下歪 1 格，鳍往后斜，露出两格墨绿头皮。
  - 躯干：青铜板甲（中脊高光、胸腹分界、腿甲裙分段 + 铆钉、护颈）、铁腰带 + 青铜扣；腰带后半截挂三片 2×2 符文石片（每片一格符文，下半片随摆动错 1 格）。
  - 肩：三层叠片铁肩甲，每层上行受光、下行压暗，一层比一层宽，最下一层比躯干宽出 3 格，每层一颗铆钉。
  - 手臂：铁臂甲 + 肘甲高光、青铜大手套（握在盾后）。
  - 腿脚：短粗的铁胫甲（膝甲外凸）+ 青铜靴。
  - 盾：11×17 青铜塔盾，盾框自动明暗 + 上下内框线 + 四角铆钉 + 两道冷光；上沿两角各一根 3 格高的獠牙护角（往里勾）；盾面 3 列竖排符文（每列一道暗刻槽，符文 = 槽上 2 格竖笔 + 隔一个一格横钩；中间一列往下错 1 行，读成一行行刻字而不是窗格），和盾面同一个部件；裂纹、半截碎盾两种损坏状态。
- 攻击方式：近战 **双手持盾 · 盾推（冲撞）**：蹲低、盾收回 1 格（预兆）→ 双脚不挪，整面塔盾往前一顶 3 格（出手定格），盾心星芒、符文亮一下 → 缓回。
- 差异化：
  - 体型档：矮壮重甲（组内巨魔瘦高、黄魔佝偻、绿魔巨型挺胸；已通过的焚尸人矮壮但是方块面罩 + 长火铲、屠宰场主桶腹）。
  - 识别特征（≥ 2 个改外轮廓）：①长方形青铜塔盾 + 上沿两根獠牙护角（轮廓）②头顶锯齿鳍冠（轮廓）③背后比身体宽出 3 格的三层叠片肩甲（轮廓）④盔缝里的小眼和外翻獠牙、腰间符文石片（轮廓内）。和维京战士（圆盾 + 胡子斧 + 角盔）、守夜人（灯盾 + 长戟 + 宽檐帽）拉开：矩形塔盾、没有任何武器、更矮更宽。
  - 武器 + 握法 + 攻击类型：双手持盾 × 冲撞（维京是单手圆盾前冲撞击；本角色脚不挪，整面盾往前顶，接一道贴着盾面鼓出的冲击波）。
  - 动作个性：待机 = 盾后探头（平时缩在盾后只露盔冠，1.6–2.0 s 盾放低、从盾沿上探头张望，盾面三列符文依次闪一下）；步态 = 顶盾蹭步（盾一直挡在前面，每步往前一拱，接触帧顿挫 1 格 + 2 颗尘）；死亡 = 碎盾瘫坐（符文一格格熄灭 → 盾崩碎 → 手里剩半截 → 往后一屁股坐倒 → 头盔歪到一边）。
  - 主色：暗青铜（和奴隶主 / 破魔守卫的钢灰、秘银拉开）+ 铁 + 符文紫。
  - 自动查重：`compare.mjs` 退出码 0（最近：焚尸人待机 IoU 0.692、配色 0.012；投石弓手 0.667 / 0.101）。

## 特效设定卡

- 元素：魔盾 · 符文紫（奥术），`fxRamp('runeward')` = 白 21 → 淡紫 43 → 符文紫 #8a5ce0 → 深紫 42 → 墨紫 52（和共享 magic 在 2–5 级都不同，不走青蓝；比蛮兵的灰紫诅咒更饱和）。碎盾碎片另用青铜色阶 `bronzeShard` = 白 → 青铜亮 → 基 → 暗 → 勾线。
- 攻击「盾推」
  - 预兆：盾收回、蹲低 1 格（1 帧），符文 1 档。
  - 出手：定格 1 帧，盾往前 3 格；盾心十字星芒；盾面前一道往前鼓出的弧形冲击波（2 帧：白 / 淡紫 → 断续的符文紫）；脚后 2 颗尘。
  - 命中：12 颗 impact 外爆 + 十字星芒 + 6 颗符文紫余光，假人闪白小摇。
- 技能「魔盾」（没有特性：表现名字里的魔盾）
  - 蓄力 1.4 s：先把盾提起来（0.25 s）→ 盾底「哐」地插进地里（下沉 1 格，两边扬尘、地面裂出两道细纹），整个人蹲低缩到盾后；盾面符文先全暗，0.35 s 起从下往上逐行点亮（每 0.15 s 一行，亮一行冒一点火星），0.8 s 后 1 / 2 档逐帧闪；紫色小符文粒子从盾两边的地面定点汇聚到盾心；轮廓光 2 档，只照盾沿；地面映光。
  - 施放 0.5 s：盾心十字星芒（臂长 7）+ 18 颗外爆，汇聚的粒子全部甩进护壁；身前 3 格立起一面竖直的符文护壁（3 格宽、24 格高的蜂巢点阵，每 4 行一个六边形符文格，3 帧内从下往上逐行亮起，领头那一行白色）；紫色冲击环；震屏 2 格 + 天空闪白。
  - 命中：两颗 enemy 敌弹（0.1 s、0.2 s 发出）先后撞上护壁：撞击处的符文格变白 1 帧，敌弹被吸在护壁上 2 帧（第 1 帧敌色、第 2 帧被染紫），然后碎成 16 颗紫色火花 + 几点敌色碎屑 + 小十字，震屏 1 格；护壁本身不动，假人不受影响（挡弹的技能）。
  - 收招 0.7 s：护壁从上往下逐行熄灭（4 帧）；0.3 s 盾从地里拔出来（扬尘），缓回待机；符文 2 → 1 → 0，轮廓光 2 → 1 → 0。
- 受击：enemy 敌弹打在盾面上 → 白色剪影 1 帧 + 击退 2 格 + 闭眼 + 腰间石片反甩；盾面上半截符文暗 1 帧；22 颗快速 impact 火花 + 3 颗长寿命火星 + 6 颗符文屑；震屏 1 格。
- 死亡：28 颗 impact + 震屏 2 格 + 天空闪白 → 盾面符文一格格熄灭、盾面裂开 → 0.3 s 盾崩碎（16 块青铜碎片带重力落地、20 颗紫色符文碎片散开、十字星芒）→ 手里只剩下半截盾（断口从左上斜到右下，一列熄灭的符文）→ 往后一屁股坐倒（离地 3 → 1 → 0），落地 16 颗尘 + 震屏 1 格 → 0.8 s 头盔磕歪到一边（两点火星）→ 静止 → 1.6–2.4 s 自上而下消散 + 魂光上升。
- 音色：青铜盾的闷响 + 肩甲叮当；标志性的一声是盾底插地的「哐」+ 符文护壁张开的嗡鸣；重量 0.7（`SFX: body armor · how collapse · pal arcane · style shield · w 0.7`；移动 `step w 0.7`、攻击 `swing smash` + `hit metal`、蓄力插地 `impact metal`、施放 `impact arcane`、每颗敌弹碎掉一次 `impact arcane`、坐倒 `fall`）。
