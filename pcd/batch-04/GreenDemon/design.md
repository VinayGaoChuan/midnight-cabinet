# 绿魔 GreenDemon

模块：`pcd/chars/GreenDemon.js`。身体用部件库拼（`rig`（giant，覆盖 torso 12 · hunch 0 · sw 6 · waist 2 · limb 1.4，fall back）`legs bare`、`torso bare`、`arm bare`（尖刺肩甲 `pauldron spike` + 骨护腕 `cuff bracer`）、`hand big`），头、长耳、巨獠牙、骨冠、骨刺领、骨塔盾、肩背骨鳞、兽骨腰带小头骨自己画。
自己画的通用部件：`// 候选部件：boneTower`（骨塔盾 9×18：骨板拼合、骨缝 1–4 按档逐条亮起 / 熄灭、盾心兽头骨、上沿 3 个骨尖、前后沿骨刺；竖 / 横 / 侧边三种朝向，倒地时自由落笔）、`// 候选部件：spineCrown`（背脊骨刺长成的扇形骨刺领：极坐标栅格化，根部实心半圆 + 5 根三角骨刺）。和巨魔的 `boneSlab` 是同一个东西长大了。
升级线：巨魔 → 绿魔（挺胸的独裁者；另一支是佝偻的黄魔）。巨魔的三件识别特征全部保留并放大：**前臂骨板 → 从肩到膝的骨塔盾；背脊骨刺 → 围在后脑的骨刺领；上翘獠牙 → 向外卷的巨獠牙（保留后掠长耳）**，再加一顶骨冠。

## 角色设定卡

- 名称 / 身份：绿魔，骄傲的独裁者——一个人顶在最前面防御极高，容不得别人和他并列（史诗品质：骨冠、骨刺领、骨鳞甲、腰挂头骨，骨缝发光）。
- 一句话剪影：**倒三角的巨人（宽肩、收腰、粗直腿）+ 身前一面从肩到膝的白骨塔盾 + 后脑一圈扇形骨刺领 + 头顶骨冠**，下巴抬着。
- 尺寸：待机 28×38（含勾线；身体到头顶 33 格，骨冠顶约 35 格，骨刺领最高高出头顶 4 格）；头 7×7，完全不驼背。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 墨翠绿皮（主材质）`green` [34, 35, 36, 37]（#16301c, #2b5a2a, #4f8a3a, #8cc45a）；腿同色单独材质（不吃轮廓光）
  - 骨塔盾 / 骨刺领 / 骨冠 / 肩甲 / 骨鳞 / 腰带 / 小头骨 / 獠牙 `bone` [8, 7, 6, 17]
  - 苔绿骨缝（发光体，flat）[34, 34, 36, #b4d88a]：未亮 36、亮 #b4d88a、施放 / 闪烁时更亮、熄灭 34
  - 眼（flat）[34, 36, #b4d88a, 21]；头骨眼窝 [0, 0, 8, 8]；皮兜 [20, 20, 19, 32]；张嘴 [55, 55, 56, 57]
  - 专属色只有 #b4d88a 一个（和巨魔共用的元素色）
- 部件顺序（从后往前）：远侧手臂（尖刺骨肩甲、空拳）→ 骨刺领 → 腿 → 趾爪 → 躯干 → 兽骨腰带 + 皮兜 → 两枚小头骨 → 肩背骨鳞 → 头 → 巨獠牙 → 长耳 → 骨冠 → 近侧手臂（尖刺骨肩甲 + 骨护腕）→ 骨塔盾 → 近侧大手（握在盾的左沿，压在盾上）。倒地时骨冠、骨塔盾改成自由落笔（不跟身体转）。
- 细节清单：
  - 脸：抬着的下巴、前凸眉骨（亮 3 格）、苔绿小眼（斜眼时眼珠往后移 1 格、眉压下来）、鼻头 + 鼻孔、嘴线（张嘴露暗红）、厚下颌；向外卷的巨獠牙（6 格，从下颌往前卷、尖端回勾）。
  - 头饰：骨冠（一圈骨箍 + 4 个骨尖，正中一颗苔绿骨缝）；后掠长耳；骨刺领（5 根三角骨刺扇形围在后脑，像王座靠背）。
  - 身体：赤膊（胸肌、腹肌、收腰），肩背上两排扇贝边骨鳞；两边尖刺骨肩甲、近侧前臂骨护腕。
  - 腰：兽骨腰带（一节亮一节暗的骨节）+ 前后两枚小头骨（眼窝 + 鼻骨）+ 短皮兜。
  - 腿脚：粗直的赤腿，脚尖两格骨白趾爪。
  - 武器：骨塔盾 9×18（左上受光的骨板、4 条苔绿骨缝、盾心凸起的兽头骨（眼窝施放时发亮）、上沿 3 个骨尖、前沿 4 根 + 后沿 2 根骨刺、盾底平边）；后手空拳。
- 攻击方式：近战 **砸（双手压盾 · 盾砸）**：双手把骨塔盾举到胸高（预兆）→ 前冲 2 格，用盾底边向前下方猛砸（定格）→ 竖直砸击拖影 + 落点小地裂 + 6 颗尘。
- 差异化（对照已通过角色和同批）：
  - 体型档：巨型挺胸倒三角（史诗）——和屠夫领主的桶腹巨型、奴隶主的英武重甲拉开：裸身披骨甲、腰细、下巴抬高；和巨魔、黄魔的弓背拉开。
  - 识别特征：①骨塔盾（从肩到膝，轮廓）②骨刺领（高出头顶，轮廓）③骨冠 + 巨獠牙 + 长耳（轮廓）④骨鳞、腰挂头骨、苔绿骨缝（轮廓内）。
  - 武器 + 握法 + 攻击类型：双手压盾 · 盾底砸——维京是单手圆盾平推冲撞，本角色是双手举起、盾底竖直往下砸。
  - 动作个性：待机 = 抬下巴斜眼俯视、鼻孔喷一口气、盾提起再在地上顿一下（2 颗尘）；步态 = 昂首阔步（上身只在接触帧沉 1 格、盾稳在身侧，每步 3 颗尘）；死亡 = 像被砍倒的树一样直挺挺向后倒，塔盾脱手翻一圈拍在胸口，骨冠滚到脑后，骨缝逐条熄灭。
  - 主色：墨翠绿——和巨魔的青灰、黄魔的硫黄拉开；已通过角色里没有绿皮。
  - 自动查重：`compare.mjs` 退出码 0（最近的是奴隶主，待机 IoU 0.638；钟表匠 0.621）。

## 特效设定卡

- 元素：统治 · 骨白苔绿（守护，沿用巨魔的色阶 `boneMoss`）：21 白 → 17 #ebe9e1 骨白 → #b4d88a 淡苔 → 36 #4f8a3a 苔绿 → 34 #16301c 墨绿；护罩画成点阵，外圈骨白、内圈苔绿，裂口段用第 4–5 级。
- 攻击「盾砸」
  - 预兆：双手把盾举到胸高、身子后仰、张嘴（2 帧缓出）。
  - 出手：定格 1 帧，前冲 2 格；盾前沿上方两道竖直落下的拖影（下段白、上段骨白，第 2 帧断续）。
  - 命中：假人大摇；impact 火花 14 颗；落点两道小地裂（dust 色阶）+ 6 颗尘；震屏 1 格。
- 技能「统治」（被动特性生效的样子：独自顶盾时防御暴涨；身边的强力友军让护罩开裂）
  - 友军占位 `ALLIES: 'skill'`，一名紧挨着站在绿魔身后（`ALLY_X = [HX − 22]`）。
  - 蓄力 1.4 s：把骨塔盾举过胸；盾上 4 条骨缝每 0.22 s 亮起一条；骨刺领每 0.2 s 竖高一根（+2 格、往后仰）；骨白碎片从地上被螺旋吸向盾心头骨（越来越密）；0.5–0.9 s 斜眼瞪一下身边的友军（友军被描一圈灰边、一僵）；轮廓光 2 档（从盾心照出）。
  - 施放 0.5 s：盾底砸地（下蹲 3 格，定格）→ 左右各一道 8 格地裂 + 骨翠点阵护罩（半椭圆 18×38，以自己为中心：0.2 s 内从两侧地面按角度逐点亮到头顶，外圈骨白、内圈苔绿交错）；24 颗骨屑 + 12 颗尘外爆、汇聚粒子外爆；震屏 2 格 + 天空闪白。
  - 命中（施放 0.2 s）：一发敌弹（0.05 s 从右边飞来）撞上护罩右侧，被弹开碎成苔绿火花（星芒 + 16 颗 + 6 颗飞散），护罩那一段变白 1 帧；**同时靠友军的那一侧护罩出现 3 格裂口**：裂口上下的点变暗（第 5 级）、断续闪，一道裂纹往里爬（统治的代价）；震屏 1 格。
  - 收招 0.7 s：护罩从外往里（两侧地面 → 头顶）逐点熄灭；骨缝 5 → 3 → 1、骨刺领一根根回位。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 1 格（很重）+ 闭眼张嘴；impact 火花 16 颗 + 震屏 1 格。
- 死亡：火花 26 颗 + 震屏 2 格 + 天空闪白 → 受击后仍挺着 → 前后摇晃一下 → 像被砍倒的树一样直挺挺向后倒（离地 3 → 1 → 0，20 颗尘 + 震屏 1 格）→ 塔盾从手臂上脱落：竖着 → 翻成横的 → 侧边，拍在他胸口（8 颗尘）→ 骨冠滚到脑后（按 90° 翻滚）→ 苔绿骨缝逐条熄灭（1.0–1.5 s）→ 自上而下消散 + 魂光上升。
- 音色：厚重的骨板相撞 + 鼻腔闷哼；标志性的一声是骨塔盾底砸地的「咚」+ 护罩张开的低鸣；重量 0.9（`SFX: body armor · how topple · pal nature · style shield · w 0.9`；攻击 `swing smash` + `hit stone`，技能施放 `impact`、敌弹撞罩 `hit stone` + `impact`，倒地 `fall w 0.9`，盾拍在胸口 `hit stone`）。
