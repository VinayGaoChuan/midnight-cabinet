# 巨魔 Troll

模块：`pcd/chars/Troll.js`。身体用部件库拼（`rig`（tall，覆盖 leg 12 · torso 10 · head 5 · hunch 1 · arm 12 · limb 1.1 · lw 2 · stride 5）`legs bare`、`torso bare`、`arm bare`、`hand`），头、长耳、獠牙、骨臂盾、背刺、骨爪、缠腰布、疤自己画。
自己画的通用部件（以后收进库）：`// 候选部件：boneSlab`（前臂骨板，按前臂方向 90° 换朝向，5 种朝向）、背脊骨刺（`spines`，黄魔同一写法 4 根版）。
升级线：→ `YellowDemon.js`（黄魔：佝偻扛旗的跟班）/ `GreenDemon.js`（绿魔：挺胸的独裁者）。三者共用识别特征：**前臂骨臂盾、后掠长尖耳 + 下颌上翘獠牙、背脊骨刺**，骨白部件（bone 色阶）一致。

## 角色设定卡

- 名称 / 身份：巨魔，廉价的前排兽人先锋（普通品质，细节克制：没有金属、没有发光法器）。两条升级线的共同起点。
- 一句话剪影：**瘦长微驼的高个 + 近侧前臂上一块肩胛骨形的白骨板竖在胸前 + 背上斜伸出的三根骨刺 + 脑后长尖耳**。
- 尺寸：待机 22×29（含勾线；身体到头顶约 27 格），头 5 格高，约 5.4 头身；窄胸长腿，手臂 12 格垂过胯。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 青灰苔皮（主材质，全身皮肤）[#121a18, #2c4540, #4a6e60, #78a088]（专属 4 色）；腿用同色的单独材质（不吃轮廓光）
  - 骨板 / 骨刺 / 獠牙 / 骨爪 / 趾爪 `bone` [8, 7, 6, 17]
  - 缠腰布 兽皮 [20, 20, 19, 32]
  - 缝合疤 [55, 55, 56, 57]（暗红 55 / 56，伤口裂开时 57）；缝线用 bone
  - 苔绿再生痂（发光体，flat）[34, 34, 36, #b4d88a]；眼（flat）[0, 0, 62, 5]
- 部件顺序（从后往前）：远侧手臂（暗一级）→ 骨爪 → 腿（+ 大腿疤）→ 趾爪 → 躯干（+ 胸口 / 肚子的缝合疤、再生痂，同一部件）→ 缠腰布 → 背脊骨刺（压在背上，分界线落在皮肤上）→（抠伤疤时：远侧手臂改到这里）→ 头 → 长耳 → 近侧手臂（+ 上臂疤，同一部件）→ 骨臂盾 → 近侧手。
- 细节清单：
  - 脸：小而长的头；前凸的眉骨（亮 2 格）压着一格沙色小眼；长鼻头 + 鼻孔；嘴一道暗线（张嘴时露出暗红）；下颌前突；近侧一根獠牙从下颌翘起、高出上唇 2 格。
  - 耳：后掠长尖耳伸出脑后 3 格，待机和步态里错相位抖（竖起 / 平 / 耷拉三档）。
  - 身体：赤膊（胸肌下沿、腹肌、肚脐），胸口一道斜的缝合疤（缝线骨白点）+ 一块苔绿再生痂，肚子一道短疤，近侧大腿一道疤 + 痂，上臂一道疤（待机抠的就是它）。
  - 背：三根骨刺（根部 3 格厚压进背里 1 格，斜向后上方，最高 3 格，尖端骨白）。
  - 下身：兽皮缠腰布（腰一圈 + 前片垂到大腿中段、后片短，下摆尖角随步子摆）；三趾赤脚，脚尖一格骨白趾爪。
  - 武器：骨臂盾 5×9（肩胛骨形：手那端宽、肘那端尖，斜的骨脊亮线 + 一格苔绿痂，上沿高过肩）；远侧手三根骨爪扇形张开（攻击时 3 格长、平时收拢 2 格）。
- 攻击方式：近战 **爪（徒手单爪 · 斜劈）**：骨臂盾护胸，远侧手高高抬到身后（预兆）→ 前冲 3 格，三根骨爪从盾下侧斜向下抓出（出手定格）→ 三道平行爪痕拖影。
- 差异化（对照已通过：守夜人 / 寡妇 / 修女 / 屠夫领主 / 钟表匠 / 火葬人 / 蛮兽 / 邪眼王 / 星辉巫师 / 维京战士 / 奴隶主 / 两匹马）：
  - 体型档：瘦长高个（普通）——比维京、守夜人的标准体更瘦、更高、手更长；和蛮兽（前倾猿形、指节撑地）拉开：直立两足、手不撑地。
  - 识别特征：①前臂骨臂盾（轮廓）②后掠长尖耳 + 上翘獠牙（轮廓）③背脊三根骨刺（轮廓）④缝合疤 + 苔绿再生痂、兽皮缠腰布、三趾赤脚（轮廓内）。
  - 武器 + 握法 + 攻击类型：徒手单爪 · 斜劈——已通过角色没有徒手爪击。
  - 动作个性：待机 = 低头用爪抠胳膊上的伤疤（痂掉下 1 格、伤口冒两颗苔绿光点又合上）；步态 = 长臂甩荡的大步（两臂反向甩到膝下、身子一前一后地摇，落脚 1–2 颗尘）；死亡 = 骨臂盾先撑地、撑不住面朝下扑倒，伤口想再生两次后熄灭、背刺一根根缩回。
  - 主色：青灰苔皮——和蛮兽的锈红褐毛、屠夫的肉粉、维京的靛蓝都拉开；和组内黄魔（硫黄赭）、绿魔（墨翠绿）拉开。
  - 自动查重：除了 accepted 里已通过的自己，`compare.mjs` 不判重（最近：投石弓手 待机 IoU 0.629、精英猎手 0.624、鹰喙弓手 0.619）。

## 特效设定卡

- 元素：骸骨再生 · 骨白苔绿（治疗），`fxRamp('boneMoss')` = 21 白 → 17 #ebe9e1 骨白 → #b4d88a 淡苔 → 36 #4f8a3a 苔绿 → 34 #16301c 墨绿（和 nature 在 2、4、5 级不同，多出的骨白一级让它和普通治疗绿分开；绿魔沿用同一色阶）。
- 攻击「骨爪」
  - 预兆：远侧手抬到身后、半蹲 1 格、耳朵竖起（2 帧缓出）。
  - 出手：定格 1 帧，前冲 3 格，张嘴；三道平行的斜爪痕（第 1 帧骨白 → 第 2 帧淡苔断续）。
  - 命中：假人闪白小摇；impact 火花 12 颗 + 5 颗血点。
- 技能「骸骨再生」（被动特性生效的样子：持续回血）
  - 蓄力 1.4 s：半蹲弓背、骨臂盾竖起挡住头脸；地上的骨屑（骨白）定点汇聚，飞回胸口和上臂的伤口（`K_SPIRAL_PT`，越来越密）；伤口从暗红逐格变成苔绿（0.3 / 0.6 / 0.9 s 三档）；0.5 s 背脊骨刺缩进皮下；再生痂 1 → 1/2 档闪；轮廓光 2 档（苔绿，从胸口伤口照出）；最后 0.3 s 憋劲发抖。
  - 施放 0.5 s：猛地挺身张臂，三根背刺「咔」地一起弹出、比平时长 2 格（定格）；骨臂盾边缘长出一圈新骨刺；骨白碎屑外爆 30 颗 + 12 颗落地的骨渣；贴地压扁的苔绿冲击环；震屏 2 格 + 天空闪白。
  - 命中（作用在自己身上，施放 0.16 s 起）：全身伤疤自下而上逐行合上（0.4 s，大腿 → 肚子 → 胸口 → 上臂，暗红像素换回皮色）；8 个苔绿十字光点（中心 + 上下左右各 1 格）错开 0.045 s 冒出、缓慢上升并走完色阶；震屏 1 格。
  - 收招 0.7 s：骨刺回到平时长度、盾边新刺收回；几颗苔绿光点从肩头飘起；伤疤保持合上。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼张嘴、长耳耷拉、缠腰布反甩；impact 火花 16 颗 + 震屏 1 格。
- 死亡：火花 26 颗 + 震屏 2 格 + 天空闪白 → 踉跄下蹲 → 骨臂盾先撑地（盾落地扬 5 颗尘），撑不住 → 面朝下扑倒（离地 3 → 1 → 0，16 颗尘 + 震屏 1 格）→ 伤口冒两次苔绿光点（想再生），随即熄灭 → 背脊骨刺从下往上一根根缩回（1.1 / 1.25 / 1.4 s）→ 自上而下消散 + 魂光上升。
- 音色：湿皮肉的拍打声 + 骨头长回原位的「咔啦」；标志性的一声是施放时三根背刺同时弹出的脆响；重量 0.55（`SFX: body flesh · how topple · pal nature · style heal · w 0.55`；攻击 `swing claw` + `hit flesh`，技能 `impact` 两段（施放、伤疤合拢），倒地 `fall`）。

## 自检

- `shoot.mjs` 退出码 0（audit 无问题，专属色 5 个；音效时间线 move.step ×5、attack.swing / hit、skill.charge / release / impact ×2、hurt、death、death.fall）。
- `compare.mjs` 对范式和 accepted：唯一被判重的是 `accepted/Troll` 里已通过的巨魔自己（待机 / 施放 IoU 1.0）；去掉自己那一份再比退出码 0（最近：投石弓手 待机 IoU 0.629、精英猎手 0.624、鹰喙弓手 0.619）。三个同批角色 `--all` 互查也不重复。
- `frames.mjs`：移动 gaitEvery2 前 4 个编号各不相同（0, 2, 4, 6），剪影行接触帧换腿清楚；待机 7 个不同帧（呼吸 2 帧 + 抖耳 + 抠伤疤 4 帧）。
- 早先自检共 3 轮：第 1 轮骨板浮在手外、背刺被分界线压成黑点 → 骨板改成盖在前臂上、手画在骨板之后，背刺改到躯干之后画；第 2 轮头部重画（眉骨、长鼻、上翘獠牙）、缠腰布改成前后两片、腿换成不吃轮廓光的同色材质；第 3 轮只确认，骨板收到 5×9。
- 本轮（和黄魔、绿魔一起重做升级线）只修了一处：再生痂的「熄灭」档原来算成了最亮（`gem >= 2` 先判断，gem 4 落进亮档），死亡时伤口想再生两次后反而一直亮着；改成熄灭档用第 2 级墨绿（`mossT()`）。形象、动作、特效都没变，`compare.mjs --prev review-1 → shots` 退出码 0。
