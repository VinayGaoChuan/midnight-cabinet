# 浪人 Ronin

模块：`pcd/chars/Ronin.js`。身体用部件库拼：`parts.rig 'slim'`、`torso tunic`、`arm`（窄袖 + 绑腕）、`hand`、`head`、`scarf wrap`、`parts.beast` 的 `B.util.shadow`（悬停影子）。库里没有的写在模块里、函数前标了「// 候选部件」：

- `batWing`：侧视蝙蝠式皮膜翼（一个部件）。构造和 `B.wing` 的膜翼相同（臂骨 → 腕 + 拇指爪 → n 根翼指扇开 → 指间膜边往腕部凹成扇贝边），但每个翼姿直接给「腕 / 3 个指尖 / 膜后缘贴背点」的坐标表，并且走 rig 的落笔变换（翻跟斗、倒地时跟着身体转）。没直接用 `B.wing` 的原因：在这个体量（翼展 16 格）下，`B.wing` 的收拢 / 半收翼姿只剩一根棒子，读不出是翅膀；需要「半收时三根翼指往后扇开、膜边三个尖」这种姿势。支持 4 指、指尖骨钩、膜上破洞（狂王用）。
- `kasa`（竹编锥形斗笠）、`boomerang`（V 形骨回旋镖，4 个朝向 = 旋转）、`wrapLegs`（悬空细腿 + 绑腿 + 脚尖朝下；`dangle` 悬停时远侧腿往后上收 1 格）、`longScarf`（两条会垂会飘的长围巾尾）。

升级线：→ `MadMonarch.js`（狂王）。两级共用：**竹编斗笠、朱红围巾、深色皮膜翼（同一个 `batWing`、同一张翼姿表）、V 形骨回旋镖、灰绿兽人脸、炭灰短打 + 绑腿**；狂王在这些上面加歪金冠、金边王袍披巾、第二把镖、更大的带爪破翼。
