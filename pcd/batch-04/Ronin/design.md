# 浪人 Ronin

模块：`pcd/chars/Ronin.js`。身体用部件库拼（`parts.rig 'slim'`、`torso tunic`、`arm`、`hand`、`head`、`scarf wrap`、`parts.beast` 的 `B.wing` 膜翼），库里没有的写在模块里、函数前标了「// 候选部件」：`kasa`（竹编锥形斗笠）、`boomerang`（V 形骨回旋镖）、`wrapLegs`（悬空细腿 + 绑腿 + 脚尖朝下）、`foldedWing`（收拢贴背的膜翼，走 rig 变换，翻跟斗 / 倒地时跟着转）、`longScarf`（两条会垂会飘的长围巾尾）。
升级线：→ `MadMonarch.js`（狂王）。两级共用：**竹编斗笠、朱红围巾、深色皮膜翼、V 形骨回旋镖、灰绿兽人脸、炭灰短打 + 绑腿**；狂王在这些上面加歪金冠、金边王袍披巾、第二把镖、更大的带爪破翼。

## 角色设定卡

- 名称 / 身份：浪人，兽人流浪射手（普通品质：没有金饰，镖尖包铜不包金，只有一把镖）。
- 一句话剪影：**压到半张脸的宽檐竹斗笠 + 背后半收的蝙蝠式皮膜翼 + 身后拖着的两条朱红围巾尾**，手里一把「<」形骨镖；悬停在离地 3 格处、脚尖朝下。纯黑剪影读成「飞着的斗笠客、手里有飞镖」。
- 尺寸：身体 18 格宽（不含翼），脚尖到笠尖 25 格；翼收拢时整体宽约 24 格，展开（移动滑翔帧、施放）约 30 格；悬停离地 3 格，待机外框 24×28。体型 `slim`，覆盖 `leg 8 · torso 7 · head 6 · headW 5 · sw 3 · arm 8 · lw 2`（4.5 头身、四肢细长、腰细，组内最轻最小的人形）。
- 材质色阶（[勾线, 暗, 基, 亮]；专属色 13 个，其余取自 64 色共享色板）：
  - 炭灰短打 / 绑腿 [#0e0e12, #24242e, #3c3c4a, #5e5e70] · 腰绳 `sand`
  - 朱红围巾 `crimson` [11, 12, 13, 26] · 斗笠 `sand` [20, 61, 62, 5]
  - 皮膜翼 深褐皮 [#1a0e0a, #3a2218, #5e3a28, #86583a]（翼骨用同一色阶提亮一级）· 翼指拇爪 `bone`
  - 皮肤 灰绿 [#121a14, #2e4a38, #4a7058, #70987a] · 獠牙 `bone` · 眼 `ink`
  - 骨镖 `bone` [8, 7, 6, 17] + 镖尖包铜 `leather` [20, 19, 32, 33] + 镖心红布 `crimson`
  - 发光体：只有技能里斗笠阴影下的眼光（flat，用元素色阶 21 / 31）
- 部件顺序（从后往前）：远翼 → 近翼（两只翼根都在后背，都画在身体后面）→ 围巾尾 → 后臂（窄袖 + 绑腕 + 手）→ 远腿 / 近腿（绑腿 + 赤足）→ 躯干（短打 + 交领 + 腰绳）→ 围巾绕颈（在下巴后面，分界线压在围巾上，不压脸）→ 头（脸 + 下獠牙 + 尖耳）→ 斗笠 →（待机个性时）压帽檐的后手 → 骨镖 → 前臂（窄袖 + 绑腕 + 握镖的手）。翻跟斗帧两只翼换成 `foldedWing`，随身体一起转。
- 细节清单（对照 standard.md 第 5 节）：
  - 脸：笠檐压住额头，眼睛在笠檐下的一行阴影里；鼻头突出 1 格、嘴线、下獠牙 1 格骨白；尖耳从笠檐下往后伸出 2 格。技能里阴影中亮一下眼光（1–2 格）。
  - 发 / 毛：光头（摘下斗笠——死亡时——才看到）；会摆的部分交给两条长围巾尾：逐格下垂 + 波浪、相位随 sway 走，尾梢分叉；远侧那条暗一级、短 3 格。
  - 头饰：竹编锥形斗笠，檐宽 12、5 行收到尖顶 1 格，斜向竹篾纹（每 3 格一道暗纹）、左上一格高光、檐下自动阴影行。
  - 服装：炭灰短打（前沿缝线、胸前系带、交领两格亮线、下摆开衩）、沙色腰绳；小腿绑腿斜向缠布纹。
  - 手臂：窄袖 + 绑腕（bracer 式缠布）+ 2×2 灰绿手。
  - 腿脚：两条细腿各一个部件，远侧暗一级；赤足脚尖朝下，悬停时像踮着脚。
  - 翅膀：蝙蝠式皮膜翼，3 根翼指 + 扇贝形膜边 + 拇指骨爪，远翼暗一级；待机在「收拢 ↔ 半收」之间轻拍。
  - 武器：V 形兽骨回旋镖（两臂各 4 格斜 45°、臂端包铜、镖心缠朱红布）；四个朝向（开口朝前 / 下 / 后 / 上），旋转 = 换朝向。
- 攻击方式：远程 **投**：镖甩到身后（后引转身，开口朝后）→ 甩腕掷出（手臂前伸，镖离手）→ 镖旋转飞向假人、命中 → 沿高弧线飞回，第 8 帧「啪」地接在手里，身体被带得一沉。
- 差异化（对照同组：巨魔 / 黄魔 / 绿魔 / 赤蠕虫 / 镰刃虫 / 沙漠信徒 / 蛇神使者 / 魔盾兵 / 破魔守卫 / 巨型野猪 / 赤瞳；已通过：守夜人 / 寡妇 / 修女 / 屠宰场主 / 钟表匠 / 焚尸人 / 蛮兵 / 邪眼王 / 维京战士 / 奴隶主 / 两匹马 / 星辉巫师）：
  - 体型档：轻巧瘦小 + 悬停（组内唯一飞行的人形；巨魔瘦高直立、黄魔佝偻、绿魔巨型挺胸、魔盾兵矮壮、信徒标准偏瘦都落地）。
  - 识别特征（≥ 2 个改外轮廓）：①宽檐竹斗笠（轮廓，12 格宽的锥形）②背后皮膜翼（轮廓）③两条朱红长围巾尾拖在身后（轮廓）④骨回旋镖、尖耳、下獠牙、灰绿皮肤。已通过角色里宽檐帽只有守夜人（平顶宽檐），本角色是尖顶锥形笠、压到半张脸。
  - 武器 + 握法 + 攻击类型：单手投掷 + **回旋**（镖会飞回手里）。寡妇也是「投」，但她是扇形牌、甩腕平飞、不回来；本角色是一把会旋转、走弧线回来的骨镖，而且是空中悬停投。组内其他人：爪 / 刺 / 砸 / 咬 / 劈 / 施法 / 冲撞，没有投。
  - 动作个性：待机 = 指尖转镖两圈（4 个朝向转两轮）+ 后手压一下帽檐；步态 = 跳跃滑翔（脚尖点地一蹬 → 展翼滑翔 → 另一只脚点地 → 滑翔，每次点地 1 颗尘）；死亡 = 直坠 + 趴倒，斗笠在他倒地之后才晃晃悠悠飘下来。
  - 主色：炭灰短打 + 朱红围巾 + 沙色斗笠 + 深褐翼（和焚尸人的炭灰厚罩袍比：本角色面积最大的是翼、笠、围巾三块，炭灰只是瘦小的身子；配色余弦最近的是守夜人 0.655）。
  - 特效：疾风银蓝的速度线 + 残影，组内没有迅捷系；和 frost / water 在第 2、3 级不同，不用冰晶。
  - 自动查重：`compare.mjs` 退出码 0（最近的是守夜人，待机 IoU 0.52 / 施放 0.327）。

## 特效设定卡

- 元素：超级杂技 · 疾风银蓝（迅捷），`fxRamp('gale')` = 21 白 → 31 #dde3ee 银白 → #a0d8f0 薄天青（专属色）→ 41 #3a7ad0 钴蓝 → 40 #1f4a8a 深蓝。图案是速度线、残影、旋转拖尾，不用冰晶。轮廓光用 [31, #a0d8f0, #a0d8f0]（光源在胸口，`rimAll`：风从四面裹住身体）。
- 攻击「回旋骨镖」
  - 预兆：镖甩到身后、开口朝后，身体后仰、围巾前甩（1 帧缓出）。
  - 出手：第 2 帧甩腕定格，手臂前伸；肩前一道银蓝甩手拖影弧（2 帧）+ 5 颗出手火花；镖离手。
  - 弹道：骨镖逐帧换朝向（旋转），去程略向上拱 0.2 s，身后 2 格银蓝旋转拖尾。
  - 命中：10 颗 impact + 6 颗银蓝外爆，假人闪白小摇；镖沿高弧线回程 0.3 s，第 8 帧「啪」接住（6 颗银蓝小火花，身体一沉 1 格）。
- 技能「超级杂技」（被动特性生效的样子：每扔一次镖攒一点法力，攻速一次比一次快）
  - 蓄力 1.4 s：0–0.33 s 团身升高 3 格；0.33–0.58 s 空中后空翻一圈（4 帧：头朝后 → 倒立 → 头朝前 → 正，整具身体绕腰转 90°，翼收紧贴背），每帧一道银蓝速度弧（翼尖 / 围巾拖出来的）；之后镖甩到身后蓄势，横向速度线从两侧向身体收拢、银蓝细粒从两侧卷进来；身侧 3 颗法力珠每 0.35 s 亮一颗；0.75 s 和 1.25 s 斗笠阴影下眼光一闪；轮廓光 1 → 2 档。
  - 施放 0.5 s：连掷三镖（第 0、2、3 帧出手，间隔越来越短，身体每掷一次往前冲一截），每掷一次在原位留一个银蓝残影剪影（`copySprite + blitShape`，逐个抖动消散）、出手点十字星芒一次比一次大；镖的旋转拖尾 2 → 4 → 6 格；第三镖出手：翼张到最大、定格、30 颗外爆 + 震屏 2 格 + 天空闪白。
  - 命中：三镖依次命中（0.2 / 0.33 / 0.37 s，间隔越来越短），前两下 12 颗外爆 + 小十字、假人小摇；第三下最大：斜十字风刃（两道对角光束）+ 十字星芒 + 30 颗银蓝外爆 + 冲击环，假人闪白大摇 + 击退，震屏 1 格。前两镖回程时化成残影淡掉，最后一镖沿高弧线飞回，收招 0.2 s「啪」地接住。
  - 收招 0.7 s：残影逐个消散，法力珠暗掉 1 颗（3 → 2）再淡出，身体从离地 6 格落回 3 格，轮廓光 2 → 1 → 0。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 下沉 1 格；翅膀惊起（上扬）、斗笠被顶起 1 格、围巾往上甩；impact 16 颗 + 震屏 1 格（引擎默认）。
- 死亡：26 颗 impact + 震屏 2 格 + 闪白 → 翅膀一收，镖脱手旋转飞出 → 离地 3 → 2 → 1 → 0 直直坠地（落地 6 颗尘）→ 弹起 1 格 → 趴倒（前扑，围巾摊在地上，落地 16 颗尘 + 震屏 1 格）→ 镖插进身前的地里 → 斗笠留在半空、左右晃着飘了 0.9 s 才落在他身后 → 1.6 s 起自上而下消散 + 魂光上升。
- 音色：皮翼扑扑声 + 回旋镖「呼呼」的旋转风声；标志性的一声是镖回到手里的「啪」；重量 0.25。`SFX: body flesh · how topple · pal bolt · style blade · w 0.25`；步态点地 `step w 0.15`、出手 `swing throw` + `shoot proj stone`、命中 `hit flesh`、技能每一镖命中 `impact bolt`、接镖 `hit wood w 0.1 catch 1`（「啪」）、倒地 `fall w 0.25`。
