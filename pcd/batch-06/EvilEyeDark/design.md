# 暗邪眼 EvilEyeDark

模块：`pcd/chars/EvilEyeDark.js`。身体用 `parts-beast` 的 `B.blob.body`（orb 球身）+ `B.wing`（membrane 膜翼，远翼通过镜像画笔朝前画）；龙角、竖瞳鳞睑眼、铲尖龙尾、鳞纹是本模块的候选部件（函数前有「// 候选部件」注释）。

## 角色设定卡

- 名称 / 身份：暗邪眼，有龙血的飞行邪眼（敌人，没有职业）。「飞行」→ 悬浮不落地；「龙之血脉」→ 龙角、龙翼、龙尾、竖瞳；「魔法抗性」→ 全身黑鳞，技能按奥术做。
- 一句话剪影：**黑鳞眼球 + 两侧张开的一对龙膜翼 + 额顶一对后掠龙角**，身后拖一条带铲尖的龙尾。
- 尺寸：史诗，龙翼悬浮眼档。眼球直径 14 格、离地 10 格；待机约 33 格高（含上扬的翼尖）、翼展 34–37 格（两翼平展时）。
- 材质色阶（全部取自共享色板，没有新增颜色）：
  - 黑鳞身体 `[0, 52, 53, 54]`（墨 → 暗影紫 → 紫灰鳞脊），band 2
  - 翼膜 `[0, 25, 42, 24]`（紫的暗段），翼骨 `[0, 52, 53, 54]`
  - 龙角 `bone [8, 7, 6, 17]`，远侧角 `[8, 7, 7, 6]`
  - 眼白 `pale [8, 59, 60, 17]`，鳞睑 `[0, 0, 52, 54]`
  - 虹膜（发光体，手工色调）`[25, 24, 23, 22]`；施放白芯 `[22, 22, 21, 21]`；蓄力时的鳞缘亮紫 `[24, 24, 43, 43]`
- 部件顺序（从后往前）：远翼（朝前张开，暗一级）→ 铲尖龙尾 → 远侧龙角 → 黑鳞身体（+ 鳞纹）→ 竖瞳眼 → 鳞睑 → 近翼 → 近侧龙角。
- 细节清单：
  - 眼（相当于脸）：杏仁形眼缝、浅色眼白、紫色虹膜（外圈深、内圈亮，5 档：待机 / 蓄力 1 / 蓄力 2 / 施放 / 熄灭）、竖瞳 3 档（一条线 / 收 / 放）、湿高光 1 格。
  - 鳞：身体上错位排布的鱼鳞纹（每 3 行一排、每 4 列一片，鳞片上沿亮一格）；鳞睑一圈 1–2 格黑鳞，上睑一排亮色鳞突，眨眼时上睑往下合，合上后留一道缝。
  - 头饰：一对后掠龙角，根部 2 格粗、先竖起再向后弯，尖 1 格，近角上两道环纹。
  - 翼：膜翼 3 根翼指、扇贝形膜边、拇指爪；远翼暗一级。
  - 尾：逐格变细，背上每 3 格一个鳞突，末端往回卷，尖端一枚箭头形铲尖（翼膜色）。
- 攻击方式：近战冲撞 —— 后仰张翼（预兆 2 帧）→ 收翼俯冲 12 格，身体前倾 67°，额顶龙角撞上目标（出手定格）→ 顿住 → 扑翼飞回。
- 移动：展翼滑翔，不落地 —— 4 帧：平展 → 平展（上浮 1 格）→ 上扬 → 下压，上下飘 2 格；身下拖奥术尾迹。
- 差异化（对照已通过的同族邪眼王尼克松、同组的赤邪眼，以及其他飞行 / 龙类）：
  - 体型档：龙翼悬浮眼（尼克松是 38 格巨眼 + 王袍的首领；赤邪眼是 18 格小眼球飞虫）。
  - 识别特征（≥ 2 个改外轮廓）：①两侧张开的龙膜翼，翼展 34 格（轮廓）②额顶一对后掠龙角（轮廓）③身后铲尖龙尾（轮廓）④黑鳞眼睑 + 竖瞳。**没有王冠、没有触须、不放光束**（尼克松的三样标志）。
  - 武器 + 攻击类型：身体本身（龙角）× 冲撞（尼克松是瞳孔光束「射」，赤邪眼是双爪「扫」）。
  - 动作个性：待机 = 慢慢悬浮、竖瞳一收一放、1.6 秒时鳞睑合拢眨一下眼、眨完竖瞳一收；步态 = 展翼滑翔、隔一拍才扑一次；死亡 = 翅膀垂下、眼睑合上、打着转坠地、龙尾最后落下（尼克松是坠地爆裂溅酸液）。
  - 主色：黑紫鳞 + 深紫膜翼 + 骨白角（尼克松是病黄眼白 + 紫灰腐肉 + 墨绿王袍，赤邪眼是充血粉红）。
  - 自动查重：`compare.mjs` 退出码 0（最接近的待机剪影 IoU 0.48）。

## 特效设定卡

- 元素：龙血奥术 · 星辉紫，色阶 `FXI.magic` = 白 21 → 青 22 → 蓝 23 → 紫 24 → 深紫 25（技能、攻击、尾迹、残影都只用它；命中火花加通用 impact，死亡加 dust / soul）。
- 攻击「龙角冲撞」
  - 预兆：后仰 2 格、翅膀张开、竖瞳收成一条线（2 帧）。
  - 出手：收翼俯冲 12 格（第 2 帧定格），身后 3 道奥术速度线 2 帧（亮 → 断续）。
  - 命中：impact 10 颗 + 奥术 8 颗外爆，目标闪白 + 小摇。
- 技能「龙裔俯噬」（没有特性，按「龙之血脉 / 魔法抗性」设计）
  - 蓄力 1.4 s：盘旋上升 4 格（左右 ±1.5 格盘旋），翅膀慢而有力地扇、最后 0.4 s 全张开并抖动；竖瞳收成一条线；奥术粒子螺旋汇入瞳孔；虹膜 1 / 2 档逐帧闪；鳞片边缘一片片亮紫（sg 0 → 1 → 2）；轮廓光 2 档 + 地面映光。
  - 施放 0.5 s：粒子外爆 + 小冲击环 + 震屏 2 格 0.28 s + 天空闪白；收翼俯冲 12 格分 3 步，每步留下一个紫色残影（第 4 级 → 第 5 级，0.4 s 内抖动消散）；瞳孔前十字星芒。
  - 命中（施放 +0.25 s）：龙角撞中，目标身上印出一只竖瞳图案（白边、青色眼、深紫竖瞳，2 帧）+ 奥术 36 颗大外爆 + 大冲击环 + impact 火花；目标闪白 + 大摇 + 击退、描一圈奥术边；震屏 1 格。
  - 收招 0.7 s：扑翼飞回原位，远翼重新朝前张开，虹膜 2 → 1 → 0，鳞光熄灭，余烬从瞳孔飘起。
- 受击：敌弹来袭 → 白色剪影 1 帧 + 击退 2 格 + 鳞睑半合、竖瞳收紧 + 翅膀猛地上扬、龙尾翘起（惯性部件反甩）；impact 火花 16 颗 + 震屏 1 格。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 翅膀垂下、眼睑合上 → 失去浮力打着转坠落（每帧转 67°，离地 10 → 0）→ 落地压扁 1 帧 + 尘土 16 颗 + 震屏 1 格 → 虹膜闪几下熄灭 → 龙尾最后落下（扬 6 颗尘）→ 1.6–2.4 s 自上而下像素消散 + 魂光（soul）上升。
- 音色：皮膜翼低沉的拍打声 + 龙喉低鸣；标志音是竖瞳收缩时的一声「嗡」；重量 0.5。
  - SFX 声明：`{ body: 'beast', how: 'collapse', pal: 'arcane', style: 'spiral', w: 0.5, hover: 1 }`；攻击出手帧 `swing`（thrust）+ `hit`（flesh）；技能命中 `impact`（arcane）；坠地 `fall`，龙尾落下再一声轻 `hit`。
