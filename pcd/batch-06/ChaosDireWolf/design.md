# 混沌恐狼 ChaosDireWolf

模块：`pcd/chars/ChaosDireWolf.js`。身体用 `parts-beast` 的 `B.quad`（canine 头放大并改圆耳、hump 2、claw 脚、spots 斑点）；前身抬高（鬣狗式）、镰刀长爪、肩部混沌裂晶簇、断链项圈是本模块的候选部件（函数前有「// 候选部件」注释）。

## 角色设定卡

- 名称 / 身份：混沌恐狼，被混沌侵蚀的巨爪狼（敌人，没有职业）。「利爪」→ 超长的镰刀爪是整只狼的武器和识别点；「高伤害」→ 人立交叉劈、三连爪痕；种族混沌 → 肩上长出的混沌裂晶。
- 一句话剪影：**前高后低的鬣狗身形 + 身前插在地上的 4 道镰刀长爪（前掌被爪撑离地面）+ 肩上竖起的两簇尖晶**，喉下挂着一截短断链。
- 尺寸：优质，长臂巨爪狼档。身体约 32 格长 × 28 格高（晶尖），连同身前的镰爪约 45 格长；前腿比后腿长 4 格，胸、颈、头整体抬高 4 格，背线往后斜。
- 材质色阶：
  - 焦赭褐狼毛 `[0, #4a1a10, #7e3620, #a8542c]`（leather 暗段偏红，共享色板里没有这组红褐，追加 3 色），band 2；深色斑点（spots）；吻部暗一级 `[0, 0, #4a1a10, #7e3620]`
  - 镰刀长爪 `bone [8, 7, 6, 17]`（远侧 `[8, 7, 7, 6]`），爪尖 `ink`；蓄力时爪尖换电光 `[51, 51, 21, 21]`
  - 混沌裂晶 `[39, 23, 22, 51]`（深蓝勾线、蓝暗面、青基色、淡金亮面），晶内电光 `[51, 51, 21, 21]`
  - 铁链项圈 `iron [0, 27, 28, 29]`；眼 `[0, 0, 51, 21]`（淡金）
- 部件顺序（从后往前）：远侧两条腿（远前爪 + 3 根镰爪）→ 尾 → 远侧晶簇 → 躯干 + 颈 → 近侧两条腿（近前爪 + 4 根镰爪）→ 近侧晶簇 → 断链项圈 → 头。侧躺时四条腿挪到最后画。
- 细节清单：
  - 脸：粗吻（暗色吻部）、淡金眼 + 眉骨、鼻头、张嘴时两颗牙、圆耳（鬣狗式，和其他狼的尖耳拉开）。
  - 毛：身上深色斑点；肩胛两排斜毛纹，近侧大腿两道斜毛纹，跗关节一道 1 格暗线；蓬尾尖端随待机 / 步态摆。
  - 配件：铁项圈横穿颈部（铆钉亮点），喉下垂 3 节短链（横环 / 竖环交替）+ 一只张开的断环，止于胸口（约 5 格），随步伐晃。
  - 爪（武器）：每只前爪 4 根逐根加长的镰刀爪，站着时嵌套成 4 道弧：从掌尖往前往上拱（最长那根拱起 5 格），再勾下去插进地里，落点在掌尖前 2 / 6 / 10 / 14 格，相邻爪尖之间空 3 格；骨白基色、爪根一段背缘亮一级、爪尖 1 格墨色；前掌被爪撑离地面 2 格。站定时远侧前掌在近侧后面 2 格，它的爪被挡住不画。前臂抬起时爪顺着前臂扇形伸出、尖端往回勾；蓄力时爪尖变成电光。
  - 发光体：肩上晶簇 3 根尖晶（高 3 / 5 / 4，各自前后倾），最高那根里有一道逐帧跳动的电光（暗 / 跳动 / 全亮 3 档，死亡时碎掉）。
- 攻击方式：近战 **人立 × 双爪交叉劈**：前臂前伸 → 人立、双爪高举过头（预兆）→ 扑前 4 格，出手帧（第 2 帧）前身仍抬 5 格、昂头，近侧前臂平伸、爪往前下劈，远侧前臂往前下、爪往前上撩，两排爪在身前交成 X，爪尖越过吻尖 8 格（X 形爪痕）→ 第 3 帧定格 → 第 4 帧起才慢慢放低，爪压在前下方 → 收回着地。
- 移动：前重后轻的沉重小跑，对角两腿一组交替；前身每步起伏 1 格；前爪落地时刮起 3 颗尘 + 2 颗电火星。
- 差异化（对照已通过的狼线：恐狼 DireWolf、灰狼 GrayWolf、黑剑 BlackSword、头狼 PackLeader、暗牙 DarkFang，以及同组的混沌恶犬、刻耳柏洛斯）：
  - 体型档：鬣狗式前高后低（前身抬 4 格）、长臂巨爪、站在镰爪上（恐狼是肩峰楔形焦骨巨狼、灰狼是标准骨狼、黑剑瘦长低伏、头狼高壮昂头）。
  - 识别特征（≥ 2 个改外轮廓）：①身前插地的镰刀长爪（轮廓）②两肩竖起的混沌裂晶簇（轮廓）③喉下垂着的断链（轮廓）④圆耳 + 斑点毛。恐狼的地狱火鬃是一排火舌，本角色是 3 根晶体尖刺 + 晶内电光。
  - 武器 + 攻击类型：身体本身（镰爪）× 劈（人立、双爪交叉）。恐狼是单爪横拍、黑剑扑咬、头狼扑咬、暗牙嚎叫施法、黑熊人立双掌砸（砸，不是交叉劈）。
  - 动作个性：待机 = 前爪刨地两下、低头低吼、肩上晶簇闪一下；步态 = 沉重小跑、前爪刮出带电火星的尘；死亡 = 侧躺，前爪抽搐两下后不动，晶簇碎掉（恐狼是爆燃炸碎、灰狼是散架）。
  - 主色：焦赭红褐 + 深色斑点 + 青 / 淡金晶体（恐狼是炭黑骨 + 熔红、灰狼钢灰、黑剑蓝黑、暗牙金、头狼灰褐）。
  - 自动查重：`compare.mjs` 退出码 0（最接近的是恐狼：待机剪影 IoU 0.681、配色相似度 0.248；第 1 轮是 0.788）。

## 特效设定卡

- 元素：混沌裂光 · 电黄，色阶 `FXI.bolt` = 白 21 → 淡金 51 → 青 22 → 蓝 23 → 深蓝 40（攻击、技能、晶体、火星都只用它；命中加通用 impact，倒地加 dust，魂光 soul）。
- 攻击「交叉劈」
  - 预兆：前臂前伸 1 帧 → 人立、双爪高举 1 帧，晶簇电光跳动。
  - 出手：扑前 8 格落爪（第 2 帧定格），目标身上 X 形爪痕 3 帧（第 1 帧白 + 淡金 2 格宽，之后青 / 蓝断续）。
  - 命中：impact 12 颗 + 电光 8 颗外爆，目标闪白 + 小摇。
- 技能「裂爪三连」（没有特性，按描述「利爪 / 高伤害」设计）
  - 蓄力 1.4 s：人立、双爪高举；晶簇全亮，电光沿前臂流到爪尖（每秒 14 段 `fx.bolt` 从晶尖连到爪尖，逐帧抖动）；爪尖亮度 1 → 2（0.6 s / 1.0 s）；嘴里电光闪；轮廓光 2 档 + 地面映光；最后 0.3 s 发抖。
  - 施放 0.5 s：晶尖外爆 + 十字星芒 + 身后扬尘，震屏 2 格 0.28 s + 天空闪白；扑前 10 格落爪。
  - 命中（施放 +2 / 3 / 4 帧，三连）：三道竖直爪痕自上而下（三道并排的 `fx.slash`，各差 2 格）+ 每道电光飞溅；第三道落下时地面裂开三条平行的 `fx.crack` 电光缝、一道闪电劈进地面、大冲击环；目标身上留三道爪痕（0.7 s 闪烁褪去），闪白 + 大摇 + 击退，眩晕（`dummyFx stun`，0.6 s）；震屏 2 格。
  - 收招 0.7 s：往后跳回原位，爪尖、晶簇电光褪去。
- 受击：敌弹来袭 → 白色剪影 1 帧 + 击退 2 格 + 闭眼、耳贴后、尾巴甩起 + 晶簇闪亮；impact 火花 16 颗 + 震屏 1 格。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 前腿先软、塌下 → 侧躺（离地 3 → 1 → 0），四腿僵直伸出 → 落地：尘土 16 颗 + 震屏 1 格，肩上晶簇碎成 14 颗电光碎片 + 一道小闪电 → 前爪抽搐两下（0.8 s、1.0 s）后不动 → 1.6–2.4 s 自上而下像素消散 + 魂光（soul）上升。
- 音色：爪子刮石头 + 电弧噼啪；标志音是一声夹着开裂声的嘶吼；重量 0.65。
  - SFX 声明：`{ body: 'beast', how: 'topple', pal: 'bolt', style: 'bolt', w: 0.65 }`；步态接触帧 `step`（w 0.65）；攻击出手帧 `swing`（claw）+ `hit`（flesh）；技能三道爪痕各一次 `impact`（bolt）；倒地 `fall` + 晶簇碎裂 `hit`（stone）。
