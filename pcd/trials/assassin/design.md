# 影刃刺客 · 设定卡

依据：用户原话「兜帽面罩、双匕首，技能是影袭——化影瞬移到目标身后连斩」。其余（配色、围巾、步态、待机个性、死亡方式、暗影色阶）为按身份补全。

## 角色设定卡

```
角色设定卡
  名称：影刃刺客
  身份：近战刺客（双持），轻装
  一句话剪影：鸟喙前檐的圆兜帽 + 两条向后飘的深红围巾尾 + 前手正握 / 后手反握、一前一后伸出轮廓的双匕首，长腿低重心
  尺寸：待机约 28×27 格（含两把刃；兜帽顶到脚 25 格），128×96 画布，脚底在地面线 y=79；缓冲 68×54
  材质色阶（[勾线, 暗, 基, 亮]）：
    衣（上衣、袖）        [0, 9, 10, 18]   band 2
    兜帽 / 面罩 / 裤      [0, 8, 9, 10]    band 1（三个独立材质，同一色阶）
    围领 / 围巾 / 腰带    [11, 12, 13, 26] band 1（深红点缀）
    皮（靴、护腕）        [0, 20, 19, 16]
    肤（眼缝、手）        [11, 16, 15, 15]
    钢（刃、护手、柄头、扣）[0, 10, 18, 17]
    刃光（发光体，flat）  [30, 28, 27, 21]
    墨（眼）              [0, 0, 0, 0] flat
  部件顺序（从后往前）：围巾尾 → 后手匕首 → 后臂 → 后手 → 后腿 → 后靴 → 前腿 → 前靴
                        → 上衣（斜襟 / 腰带 / 扣 / 腰带结）→ 兜帽 → 脸（眼缝 + 面罩 + 围领）
                        → 前手匕首（刃光）→ 前袖 → 皮护腕 → 前手
  细节清单（对照细节密度表）：
    脸：眼（1 格墨 + 眼缝高光）、眉（兜帽前檐压出的暗线）、鼻（面罩鼻梁凸 1 格 + 高光）、面罩褶
    发/须对应物：两条围巾尾，逐格收细，上面那条尖端随衣摆摆，受击 / 蓄力时甩起 / 拉直
    头饰：兜帽圆顶、鸟喙前檐、宽后脑、披肩垂布（随 bend 后摆）、兜帽褶
    躯干：窄肩收腰、交领斜襟、外扩短下摆 + 前开衩 + 褶、深红腰带 + 钢扣 + 身后腰带结垂尾
    手臂：皮护腕，2×2 手盖住握把
    腿脚：长腿外露 5 格，两只靴、前脚尖多 1 格，前后脚分开
    武器：柄头 + 3 格护手（左上亮右下暗）+ 亮刃口 + 刃根一半的暗刃脊 + 刃尖
    发光体：前手刃光 5 档（待机刃尖紫 / 蓄力 1 半刃淡紫 / 蓄力 2 整刃 / 施放白刃 / 熄灭暗钢），后手刃蓄满后也亮
  攻击方式：近战（前冲 4 格弓步 + 双刃交叉拖影）
  差异化（同族已通过角色：星辉巫师）：
    体型档：瘦长低姿（窄肩、长腿外露、始终半蹲）       ↔ 巫师 标准（长袍罩到脚）
    识别特征：双匕首（轮廓）、围巾尾（轮廓）、鸟喙兜帽（轮廓）、暗色面罩（内部）
                                                      ↔ 巫师 折角尖帽 / 长杖 / 长白胡
    武器 + 握法 + 攻击：双持正握 + 反握 × 劈（近战）   ↔ 巫师 单手杖 × 施法（远程弹）
    待机个性：每 ~2.4 秒前手匕首在指间转一圈（3 帧）   ↔ 巫师 宝石闪
    步态：潜行小跑（弓身、大步、经过帧抬脚 2 格、无声无尘）↔ 巫师 迈步 + 落脚扬尘
    死亡方式：前扑（脸朝下、手伸向弹飞的匕首）+ 先沉成暗影再消散 ↔ 巫师 后仰
    主色：石板灰紫衣 + 深红点缀 + 暗影紫               ↔ 巫师 酒红袍 + 金 + 星辉青
    自动查重（compare.mjs 对巫师）：待机剪影 IoU 0.521、施放剪影 IoU 0.427、配色相似度 0.562 → 不重复
```

## 特效设定卡

```
特效设定卡（元素：暗影）
  元素色阶：白 21 → 淡紫 27 → 紫 28 → 深紫 29 → 墨紫 30（色板末尾追加 27–30）
  移动：四帧潜行小跑（每秒 6 帧），前后脚交替、经过帧抬脚、接触帧下沉 1 格、衣摆反向摆、围巾始终后飘；
        轻装刺客落脚无声无尘；转身 = 镜像
  攻击「双刃交错」
    预兆：蓄势下蹲 1 格，前手刃举到肩后、后手刃压低（刃光 1 档）
    出手：前冲 4 格弓步定格 1 帧，前手刃自上而下、后手刃自下而上两段拖影弧（以肩为轴，半径 12→15 格）
          在身前交叉；第 1 帧 2 格宽白 / 淡紫，第 2 帧 1 格宽紫且断续；刃尖 6 颗暗影火花，蹬地 3 颗尘

  技能「影袭」
    蓄力「化影」1.4 s：伏低（crouch 2），暗影火花螺旋收拢 → 绕身体环绕；脚下暗影池随蓄力扩大（外圈隔点）、
                       暗烟从地面升起（从色阶第 3 级起步）；刃光 1/2 档逐帧闪；轮廓光 2 档；地面映光；
                       围巾被吹直拉长，最后 0.3 s 抖动；最后 0.2 s 身体闪成暗影剪影
    施放「瞬移连斩」0.5 s：进入时，环绕火花外爆 + 30 颗暗影外爆 + 冲击环；原地留暗色残像（填色 29 / 勾线 30）
                       3 帧后按 Bayer 阈值删像素；28 颗拖尾连到假人身后；天空闪白 0.05 s + 震屏 2 格 0.28 s；
                       在假人身后转身（镜像）以暗影剪影显形 1 帧 → 连斩一 ↙（前手刃）→ 连斩二 ↗（后手刃），
                       两条斩线交叉（白芯 2 格 → 淡紫 → 紫断续 → 深紫稀疏，4 帧），每刀假人闪白小摇 + impact 6 颗；
                       最后双刃交叉举过头顶（白刃 + 十字星芒），蓄 3 帧
    命中「十字斩」（收招第 2 帧）：两条长斩线同时亮（3 格宽白芯）+ 36 颗暗影外爆 + 10 颗 impact + 大冲击环；
                       假人闪白 + 大摇 + 从身后被击退 1 格；震屏 1 格 0.12 s
    收招「回影」：十字斩姿定格 3 帧 → 身后留暗色残像、原地以暗影剪影显形 1 帧 → 缓入待机；刃光 2→1→0，
                  轮廓光 2→1，余烬从刃尖飘升
  受击：来袭敌弹（enemy 色阶）300 格/秒 → 白色剪影 1 帧 + 击退 2 格 + 闭眼 + 围巾尾向上甩、兜帽后摆反甩；
        impact 16 颗（布、肉）；震屏 1 格
  死亡：26 颗 impact + 震屏 2 格 + 闪白 → 踉跄 → 跪倒（双刃下垂、刃尖点地）→ 前扑倒地（离地 3→1→0）

        → 自上而下像素消散 + 魂光（soul 色阶）上升
```

## 第 3、4 节以外的改动（及原因）

- **第 1 节 色板**：末尾追加 4 色 27–30（暗影 淡紫 / 紫 / 深紫 / 墨紫），同步 `FLASH`，`FXR` 追加暗影色阶并加 `R_SHADOW`。这是技能允许的做法（色板只在末尾成组追加），全套 31 色。
- **第 6 节 render()**，改动都标了 `[刺客]`：
  1. **元素色改成变量**：地面映光、弹道地面光、十字星芒、单弧拖影、枪口光和己方弹道原来直接写死星辉色下标 21–24 / `R_MAGIC`，现在改取第 4 节定义的 `EL = FXR[R_SHADOW]`。不改的话，暗影技能在 `rim ≥ 2` / `gem ≥ 2` 时会冒出巫师的青蓝色，违反「一个技能只用一个元素色阶」。
  2. **两个绘制钩子**：在假人和主角 blit 之间调用 `fxUnder(f12)`（画脚下暗影池、化影残像），投射物之后调用 `fxOver(f12)`（画双刃拖影弧、影袭斩线）。模板 render 只有一条固定半径 15.5（杖长）的拖影弧，没有地方画精灵残像和直线斩线，第 4 节也没有绘制入口。
  3. **假人反应方向 `dumDir`**：摇晃方向、击退方向乘以 `dumDir`，并调整缓存键 `dkey`。原模板假人永远往 +x 倒；影袭从身后出刀时，假人会倒向刺客，和受力方向相反。
  4. **移植新版模板的跳帧接口**：加了 `STATE_OF`、`at(name, t)`，`__pc` 增加 `at` / `resume`，第 4 节配套加 `fxReset()`（另外清空刺客新增的拖影弧、斩线、残像、暗烟、假人方向）。技能在我做完后又更新了一次（14:36），新版 `shoot.mjs` 靠 `__pc.at()` 按确定时间点截图，没有的话会退回按等待时间截图，时间会漂移。
- 第 2 节（引擎）、第 5 节（舞台）一字未改。第 6 节的状态机、`REEL`、动作表、按键、`audit()`、`exportData()` 都没动。
- 没有跟进 14:36 之后新版模板的其余改动：第 3 节 `R_EL`、钩子改名 `fxBack` / `fxFront` / `drawShot`、近战把 `HX` 右移让攻击够到假人。它们和本文件的 `EL`、`fxUnder` / `fxOver` 等价；近战距离见下方「自检结果」的说明。
- 第 3 节内对「保持 `P` 字段语义」的扩展：
  - 双持新增 `bhx/bhy/ba`（后手与后手刃）和 `shade`（化影剪影），都已进缓存键。
  - `walk` 从 0/1 扩成步态帧 1–4：模板的经过帧总是抬前脚，做不出左右交替。攻击和施放的弓步也借用 `walk = 1`。
  - `bend` 改为驱动兜帽后摆（没有帽尖）；`back` 保留，恒为 0。
  - 影袭的瞬移和转身复用模板给 MOVE 用的 `P.mx / P.flip`。
  - 倒地头部复用站姿的画头函数，按整 90° 换坐标重画，不是旋转缓冲。

## 自检结果（最终版 HTML，用技能当前的 shoot.mjs / compare.mjs）

- `shoot.mjs`：退出码 0，通过 `__pc.at()` 按确定时间点跳帧截图。audit 通过，每个状态的不同帧数：待机 5、移动 4、攻击 7、蓄力 9、施放 4、收招 6、受击 7、死亡 22。无裁边、无色板外像素，log.txt 无报错。
- `compare.mjs`（对技能自带的 `assets/reference/star-wizard.sprite.json`）：退出码 0，待机 IoU 0.521、施放 IoU 0.427、配色 0.562，未判重。
- `shots/` 里有 16 张状态截图（待机、移动 ×2、攻击 预兆 / 出手 / 延续、蓄力、施放 ×2、命中、收招、受击 闪白 / 击退、死亡 跪倒 / 倒地 / 消散）、3 张动作表，以及 `audit.json`、`sprite.json`、`sprite-lite.json`、`log.txt`。
