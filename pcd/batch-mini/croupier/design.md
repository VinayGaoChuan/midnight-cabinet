## 补全说明（资料里没有、按身份补的）

- 燕尾服用墨蓝近黑而不是纯黑：纯黑在夜景和赌场暗背景上会只剩勾线；墨蓝三级能看出驳领、褶线和左上受光。
- 金表链、袖扣（用户给的「金色表链或袖扣」两样都做了，表链在腰线以上，游戏里看得见）。
- 技能命中目标的部分（金色轮光 + 转晕）是查看页里的演示；游戏里只取身体帧，拨轮的动作本身（扣轮沿 → 带运动模糊的横扫）在身体帧里就能读出来。
- 引擎验收的待机高度上限原来是 48 格；荷官按设定就是 57 行，所以给共享引擎加了一个模块返回项 `MAX_H`（待机高度上限，默认 48），荷官写 60。

## 实现要点

- 身体用 `parts.rig`（`slim` 覆盖成腿 19 / 躯干 16 / 头 9 / 脖子 2 / 臂长 17 / 腿粗 2、`fall: 'back'`）+ `parts.legs`（shoe）+ `parts.arm`（tight）；燕尾服、燕尾、翼领、领结、瓷脸（侧 / 正两套）、礼帽、手套（8 种手型，ASCII 网格定义）、拨轮运动模糊是本模块自画，全部走 rig 的落笔变换，仰面倒地（rig 转 90°）时照样能画。
- 新姿势参数：`look / tilt`（转脸、歪头）、`tap`（敲桌 0–3）、`hm / bm`（前 / 后手型 0–7）、`crack / grin / glow`（裂纹、咧嘴、冷光档）、`ball`、`tie`、`smear`（施放帧的运动模糊）、`hatM / hatX / hatY / hatR / hatJ`（帽子戴着 / 飞走的位置和翻滚档、受击跳起的格数）、`rimK`（轮廓光用哪个色阶）；全部用 `E.keyer` 编进 k1 / k2。
- 施放的「整条手臂拖影」：进入施放时用 `armOnly` 只画前臂和手，把蓄力姿、扫到一半的两张手臂剪影拷进 ghA / ghB，在 `fxMid` 里按暗金 / 金色抖动消散（第一版拷整个身体，前倾差 1 格，身体前沿一整条金点，改掉）。
- 身体帧里就带着施放的运动模糊（`smear`），游戏只取身体帧也看得出「一把抓住 → 横扫」。
- 发球的小球是模块自己模拟的抛物线（重力 240），不用引擎弹道；拨轮的轮光用引擎弹道 k = 2 + 自画 `drawShot`。
- 引擎改动：`pcd/lib/pcd.js` 的验收读模块返回项 `MAX_H`（默认 48），荷官写 60；`pcd/lib/README.md` 补了这一行。
