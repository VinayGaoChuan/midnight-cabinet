# 老猎犬 OldHound

## 角色设定卡

- 名称 / 身份：老猎犬，恶魔召唤出来的小鬼宠物，骷髅系近战战士，普通品质。
- 一句话剪影：一只又老又瘦的驼背狗——长垂耳耷拉到下巴下，头顶一对小弯恶魔角，尾巴末端一枚箭头尾尖，嘴里横叼一根比脑袋还长的大腿骨。
- 尺寸：待机 29 × 19 格（身体约 22 格长 × 16 格高，含尾和骨头），本组最小的兽，贴地。
- 体型档：老瘦驼背四足（parts-beast `B.quad`：体长 len 9、胸 3.6、臀 3、收腹 0.55、肩峰 1.2、腿长 5、腿粗 1；canine 头放大到 7 × 6，吻高 3.5，头角朝下 0.3 低垂）。坐下挠耳时换一份臀收到胸下的形体（len 5.5）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 旧毛 [0, 20, 19, 33]（wood 色阶，亮部偏黄的褐黄；身体小，band 1）
  - 灰白老狗吻 [0, 20, 7, 18]
  - 垂耳 [0, 20, 20, 32]（wood 暗段，受光沿一格浅褐）；远侧耳 [0, 20, 20, 20]
  - 小弯角 / 箭头尾尖 [0, 52, 53, 54]（shadow，和恶魔同色）；远侧角 [0, 52, 52, 53]
  - 骨（斑秃露骨、大腿骨）bone [8, 7, 6, 17]
  - 眼窝紫光 [0, 0, 24, 24]，蓄力时 [24, 24, 43, 21]；骨头符文 [25, 24, 43, 21]（发光体，平涂 5 档）
- 部件顺序（从后往前）：远侧两条腿 → 箭头尾 → 躯干 + 颈（肋沟、斑秃露骨并进躯干）→ 近侧两条腿 →（死亡时：放在前爪间的骨头）→ 远侧垂耳 → 远侧角 → 近侧角 → 头（眼窝并进头）→ 叼着的大腿骨 → 近侧垂耳。角和远侧耳画在头之前，只露出伸出头外的部分（头小，压在脸上的分界线会把脸压黑）。
- 细节清单：
  - 面部：2 格眼窝（墨 + 1 格紫光）、眉骨高光、灰白吻、鼻头、张嘴露牙。
  - 毛：背上毛纹；驼背上凸出两节脊椎骨、髋骨和肩胛各一块斑秃露骨；胸侧三道肋沟（肋骨在皮下一根根凸起）。
  - 头饰：一对 2 格高、往后上方弯的小角（`impHorn` size 2，恶魔用 size 3 同一画法）。
  - 耳：长垂耳 2–3 格宽，从后脑垂到下巴以下 2 格，跑动 / 受击时下半截往后甩，蓄力时竖起一下。
  - 尾：6 节细尾往后上方翘，末端 3 格宽铲形箭头尾尖（恶魔同款）。
  - 武器：叼着的大腿骨，9 格长，两端骨节（上亮下暗）+ 骨节中心一格奥术符文（5 档：暗 / 亮 / 很亮 / 爆闪 / 熄灭）；随头的角度吸附到 0 / 1:2 / 45°。
  - 腿：细腿、爪垫；近侧后腿是瘸腿（站着时脚尖点地，走路时只抬 1 格、拖在后面）。
- 攻击方式：近战（口衔 × 砸）：扬头把骨头前端往上抬，前冲 5 格甩头横砸目标。
- 差异化（同组四足：灰狼 标准骨狼 / 咬、恐狼 肩峰巨狼 / 爪拍、骨龙 巨型骨架 / 吐息；已通过的黑剑、暗牙、熊类）：
  - 体型档：老瘦驼背小犬，同组最小，腿细、背驼、头低垂——灰狼标准比例、恐狼前重后轻的楔形、骨龙巨型骨架。
  - 识别特征：①长垂耳耷拉到下巴以下（改轮廓，其余犬类都是立耳）②头顶一对小弯恶魔角（改轮廓）③箭头尾尖（改轮廓）④嘴里横叼的大腿骨，两头伸出嘴外（改轮廓，发光体）。
  - 武器 + 握法 + 攻击类型：口衔大腿骨 · 砸（灰狼徒口咬、恐狼爪拍、骨龙吐息）。
  - 待机个性：坐下挠耳——坐下用瘸后腿挠垂耳三下，叼着的骨头跟着上下晃，眼窝紫光眯一下，挠下一撮旧毛。
  - 步态：瘸腿蹒跚——身体一高一低（接触 B 时瘸腿承重、臀部往下一沉），瘸腿只抬 1 格拖在后面，每两步 1 颗尘土。
  - 死亡方式：趴下睡去（安静，不倒不散）——灰狼侧倒化灰、骨龙连锁散架。
  - 主色：褐黄旧毛（本组唯一的暖褐色狗）；点缀恶魔同款的暗紫角和奥术紫。
