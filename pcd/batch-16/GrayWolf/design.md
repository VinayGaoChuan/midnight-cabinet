# 灰狼 GrayWolf

模块：`pcd/chars/GrayWolf.js`（`pcd/view.html?c=GrayWolf`）。身体用 `parts-beast.js` 的 `quad`（canine 头、颈圈毛 ruff、腿与头的几何）；本模块的候选部件：`furFront`（只画前半截的皮毛、烂毛参差边）、`boneTrunk`（脊椎 + 棘突 + 肋骨 + 骨盆）、`boneTail`（裸尾椎钩）、`petCollar`（项圈 + 蝴蝶结 + 骨牌）、`stubEar`（软骨耳尖）。骨后腿 / 骷髅头用同一份几何换骨材质（`oBone` / `oSkull`）。

## 角色设定卡

- 名称 / 身份：灰狼，召唤师放出来的骷髅猎犬，高伤害的近战宠物。
- 一句话剪影：**前半身是灰毛狼、后半身是一副骨架**——背线上一根根肋骨、腰只剩一截脊椎、骨盆和骨后腿；屁股后面一串往上翘成钩的裸尾椎。
- 尺寸：待机 33 × 23 格（含骨尾钩与耳；身体约 28 长 × 18 高）。体型档「标准骨狼」：体长 12、胸 4.5 / 臀 3.6、腿 7、颈角 0.55；比例是标准狼，不像黑剑那样压低。
- 材质色阶（全部取自共享色板）：
  - 灰蓝狼毛 `steel` `[27, 28, 29, 30]`（躯干 band 1，面积小不整块发暗）；颈圈毛 `[27, 28, 30, 31]`；吻部 / 腹线 `[27, 29, 30, 31]`
  - 骨 `bone` `[8, 7, 6, 17]`（远侧腿暗一级）；闭孔 / 骷髅眼窝 `ink`
  - 项圈皮带 `leather`；蝴蝶结 `purple` `[25, 42, 24, 43]`（召唤师同色）；骨牌 `bone`；软骨耳尖 `[8, 7, 16, 15]`（淡肉色）
  - 眼 `[0, 0, 22, 22]` 冰青；发光眼 `[22, 22, 21, 21]`
- 部件顺序（从后往前）：远侧两腿（后腿骨、前腿毛）→ 骨尾 → 骨架躯干 → 前半截皮毛（颈 + 胸）→ 近侧两腿 → 颈圈毛 → 项圈 → 软骨耳尖 → 头。侧躺时四条腿挪到最后。
- 细节清单：
  - 脸：冰青眼 + 眉骨高光、墨鼻、张嘴露牙；近侧尖耳完整、远侧只剩 2 格软骨尖。
  - 毛：背毛纹、浅色腹线、颈圈毛一圈尖；皮毛在肋骨中段戛然而止，边缘 2 列按 hash 参差（烂毛）。
  - 骨：背线上每 2 列一格棘突（背线参差）、肋骨往后斜（前长后短，间隙是深色缝）、腰椎一截、骨盆一团 + 髂骨斜板 + 坐骨后伸 + 闭孔；骨后腿细（1 格），骨爪。
  - 配件：皮项圈（2 格宽）+ 喉下紫蝴蝶结（结 + 两瓣 + 两条尾巴）+ 下垂的 2×2 骨牌。
- 攻击方式：近战扑咬——低伏 1 帧 → 前扑 4 格张嘴（出手帧）→ 下一帧一口咬合 → 缓回。
- 差异化（对照已通过的黑剑、暗牙，及同批恐狼）：
  - 体型档：标准骨狼（黑剑瘦长低伏、暗牙健壮昂头、恐狼肩峰巨狼）。
  - 识别特征：①后半身露骨（肋骨 / 腰椎 / 骨盆 / 骨腿，腰下一个空缺口——改轮廓）②裸尾椎钩向上翘 5 格（改轮廓）③召唤师同款项圈 + 紫蝴蝶结 + 骨牌（喉下伸出轮廓）④一只耳朵只剩软骨尖。
  - 武器 + 握法 + 攻击类型：利齿 · 徒手 · 咬（黑剑扑咬带剑角上挑、暗牙嚎叫施法、恐狼爪拍）。
  - 动作个性：待机「嗅地」（低头贴地嗅两下、耳朵一竖一竖、骨尾左右摇）；步态「轻快小跑」（对角步态、每步 1 颗尘、骨尾随步甩）；死亡「侧倒化灰」（毛化灰、剩骨架再消散）。
  - 主色：灰蓝毛 + 大面积骨白，和黑剑蓝黑、暗牙金毛、恐狼焦黑都拉开。
  - 自动查重：`compare.mjs` 退出码 0（最近：暗牙待机 IoU 0.62、施放 0.31）。

## 特效设定卡

- 元素：猎犬扑杀 · 幽霜蓝。`FXI.frost` = 白 21 → 冰青 22 → 青 23 → 钢蓝 40 → 深蓝 39（和召唤师同一色阶）；受击毛屑 `grayWolfFur` = 31 → 30 → 29 → 28 → 27，骨屑 `grayWolfBone` = 21 → 17 → 6 → 7 → 8。
- 攻击「扑咬」

  - 出手（2/12 s）：前扑 4 格张嘴定格，轮廓光 1 档；上下两道白色咬合短弧（2 帧，第 2 帧断续）。
  - 命中：10 颗 impact + 4 颗霜粒，假人闪白小摇；3/12 s 一口咬合。
- 技能「猎杀扑咬」（无特性：表现描述「高伤害近战」的一次重扑）
  - 蓄力 1.4 s：伏到最低（crouch 4）、耳贴后、张口；霜粒螺旋汇入口中；0.3 s 起口中溢出白色霜气（慢速 K_DUST，frost 色阶）；眼窝冰蓝 0.45 s 后 1 / 2 档逐帧闪，0.9 s 起保持 2 档；轮廓光 2 档 + 地面映光；最后 0.3 s 后腿蹬地抖动（身体一颤一颤，后脚扬尘）。
