# 恶魔 Diabolic

## 角色设定卡

- 名称 / 身份：恶魔，骷髅系的小恶魔法术师宠物，远程射手（徒手施法），普通品质，悬浮。
- 一句话剪影：一个盘腿飘在半空的焦红小骷髅——大圆颅骨上一对向后弯的恶魔角，身后一对小骨蝠翼和一条卷成问号的箭头尾，两掌之间托着一团奥术紫火球。
- 尺寸：待机 19 × 24 格（身体约 20 格高，离地 5 格飘着），孩童比例，比守卫更小更瘦、姿态是坐着飘。
- 体型档：孩童悬浮档（`parts.rig` child：胯高 3（盘腿）、躯干 6、头 8 × 8、sw 3、臂长 7、腿粗 1）；翅膀用 parts-beast 的 `B.wing`（membrane，翼展 11、3 根翼指）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 焦红骨 [0, 44, 19, 45]（fire 暗段：骨头被魔焰熏成红褐；后臂 / 远腿暗一级）
  - 尾 [0, 44, 44, 45]（fire 暗段）
  - 角 / 箭头尾尖 [0, 52, 54, 18]（shadow，亮面提到灰紫，夜空里看得见）；远侧角暗一级
  - 翼膜 [0, 52, 54, 43]（暗紫膜）、远翼 [0, 52, 53, 54]；翼指焦骨、拇指爪角色
  - 眼窝紫光、火球 [25, 24, 43, 21]（发光体，平涂按档取色）；火球外焰一点 fire [44, 45, 46, 47] 第 4 级
- 部件顺序（从后往前）：远翼 → 箭头尾 → 后臂 → 盘起的腿 → 肋骨架（脊椎、锁骨、肋骨、胸骨、骨盆）→ 近翼 → 远侧角 → 近侧角 → 颅骨 → 火球 → 前臂。角画在颅骨之前，根部压在颅顶下，不在脸上压分界线。
- 细节清单：
  - 面部（骷髅）：眉骨一行亮面、2 × 2 墨色眼窝 + 1 格紫光（5 档，蓄力 / 施放时 2 格）、颧骨亮点、鼻腔 1 格墨 + 上方 1 格骨白鼻骨点、一排骨白尖牙（牙缝墨色）+ 上翘的嘴角（恶作剧的笑），颅顶高光、太阳穴凹；下颌 0–2 张开、张嘴露下排骨白牙。牙和鼻骨用没被熏黑的骨白 tooth [0, 19, 6, 17]，让大红颅一眼读成骷髅。
  - 头饰：一对后弯恶魔角（`impHorn`）：每只角 2 格宽的角根先竖直长上去，再往后弯 2–3 格收成往后平伸的 1 格粗尖；近角在眼窝上方（horn 3 / 前缘与尖 4 灰紫亮面），远角在后脑（hornD，矮一格、弯得更早），两角根隔 3 格，空隙往上越开越大，剪影里是两只分开的角。
  - 躯干：后沿一列脊椎、锁骨、两根整肋 + 一根短肋（肋间暗缝）、胸骨、骨盆 + 闭孔。
  - 手臂：细骨臂，肘节高光，2 × 2 骨手 + 爪尖。
  - 腿：两条细骨腿盘起（大腿前伸、小腿折回交叉），悬空不落地。
  - 翼：小骨蝠翼，展开高出肩线，翼指把膜分成扇贝边。扑翼只用 上扬 1 → 半收 4 → 下压 3 → 半收 4（不用平展 2：这么小的膜翼平展时侧看只剩一条横线）；死亡用收拢 0 贴在背上。
  - 尾：细长尾在身后卷成问号，末端 3 格宽箭头尾尖；蓄力时竖直、死亡时软塌塌垂到胯下、末端往回卷一个小钩（横向最多 7 格）。
  - 发光体：掌间火球 半径 1 十字 / 2 圆团 / 3 大团（白芯 → 淡紫 → 紫 → 深紫边），顶上一格橙色外焰跳动；熄灭档 = 眼窝深紫。
- 攻击方式：远程（徒手 × 射）：火球收到胸前，双手一推，扔出一颗直飞的紫色火弹。
- 差异化（同组飞行 / 悬浮：守卫 蹲伏石像鬼抱墓碑 / 冲撞；复仇之龙 腐肉翼龙 / 口吐；已通过的巫毒信徒、巫毒守卫、影剑士复制体、暗影死神）：
  - 体型档：孩童盘腿悬浮（守卫蹲姿抱碑、复仇之龙是龙；本组唯一盘腿坐着飘的）。
  - 识别特征：①后弯恶魔角（改轮廓）②小骨蝠翼（改轮廓）③问号形长尾 + 箭头尾尖（改轮廓，身后一个圈）④掌间奥术紫火球（发光体）。
  - 武器 + 握法 + 攻击类型：徒手 · 双手推出 · 射（守卫抱碑冲撞、复仇之龙口吐魂焰）。
  - 待机个性：抛接火球——后手把火球往上一抛，弧线落进前手，尾巴跟着甩，咧嘴、眼光亮一下。
  - 步态：飘浮上下——不落地，身体上下飘 2 格、翅膀 4 帧快扇，身下拖 1 颗紫火星，地面画影子。
  - 死亡方式：沉入星门——坠地瘫住后被身下的五芒星吸进去（守卫坠落碎裂、复仇之龙另算）。
  - 主色：焦红骨（本组唯一的红褐骷髅），点缀暗紫翼膜、奥术紫。

## 特效设定卡

- 元素色阶：奥术召唤 · 星辉紫 FXI.magic = 21 → 22 → 23 → 24 → 25（和老猎犬同一色阶）；火球外焰点缀 fire 第 2 级（47）；受击焦骨火星 diabolicAsh [47, 45, 44, 20, 8]。
- 攻击「紫火弹」：
  - 预兆：火球收到胸前、身体后仰 1 格、翼半收（2 帧，眼光 1 档）。
  - 出手：双手前推定格 1 帧，翼张开；枪口十字光 2 帧 + 6 颗紫火花；火弹 2 × 2 白芯 + 淡紫 / 紫外焰 + 跳动火舌 + 一格橙，180 格 / 秒直飞，带紫拖尾和地面映光。
  - 命中：10 颗紫外爆 + 一颗橙火星，假人小摇。
- 技能「召唤小鬼」（特性：召唤一只小鬼，魔法 / 奥术；fx 召唤）：

  - 施放 0.5 s：第 1 帧把大火球举过头顶（蓄力粒子外爆 + 小冲击环 + 震屏 2 格 + 天空闪白），之后往前下方一砸，火球 2 帧砸到法阵上：大冲击环 + 26 颗紫外爆 + 十字星芒 + 尘土 + 再一次震屏闪白；五芒星竖起成一扇星门（竖直椭圆点阵，2 帧开到 8 × 20 格，门里隔点透紫光，门框上的亮点转动、冒紫火星）。

  - 收招 0.7 s：星门在前 0.3 s 收拢；咧嘴笑、火球 0.35 s 后重新在掌间点亮；小鬼站到收招末尾按抖动消散；眼光 2 → 1 → 0。
- 受击：白色剪影 1 帧 + 击退 2 格 + 闭眼张嘴、翼张开、尾巴甩起、头后仰；焦骨火星 12 颗 + 紫 5 颗；震屏 1 格。
