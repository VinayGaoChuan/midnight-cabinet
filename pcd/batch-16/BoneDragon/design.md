# 骨龙 BoneDragon

## 角色设定卡

- 名称 / 身份：骨龙，死神召唤的巨型骨架龙，远程射手（吐息），普通品质。
- 一句话剪影：贴地低伏的巨型骨架四足龙——空肋骨笼里悬着一团冥霜魂焰，背上一对挂着裹尸布条的骨翼，后掠长角的龙头骨，长尾椎末端一枚骨刺铲。
- 尺寸：待机约 59 × 36 格（含尾和翼；身体约 40 格长 × 28 格高），本组最大的兽，贴地。
- 体型档：巨型四足（骨架画法）。四条腿的几何、龙头、角用 parts-beast 的 `B.quad`（dragon 头型、`horn: 'back'`、hornLen 10）；躯干不用 quad.body，改成自画骨架。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 骨 bone [8, 7, 6, 17]（主材质，大块骨面带 tone 1 裂纹暗段；远侧腿暗一级）
  - 裹尸布 white [7, 18, 17, 21]（死神同款灰白；远翼 [7, 18, 18, 17]）
  - 爪与角 [0, 8, 7, 6]（bone 暗段）
  - 笼中魂焰 [39, 40, 23, 22] + 炽芯 [22, 22, 21, 21]、口中寒光 [39, 40, 22, 21]、眼窝光点 [0, 0, 22, 21]（发光体）
- 部件顺序（从后往前）：远骨翼（裹尸布条 → 翼骨）→ 远侧两条骨腿 → 尾椎 → 笼中魂焰 → 骨架躯干（脊椎 + 肋骨笼 + 胸骨 + 骨盆）→ 近侧两条骨腿 → 近骨翼 → 椎骨长颈 → 龙头骨 → 后掠长角。
- 细节清单：
  - 面部（骷髅）：2×2 墨色眼窝 + 1 格冥霜光点、鼻孔墨点、颅上裂纹 2 格、张嘴见一排白牙；下颌开合。
  - 头饰：后掠长角，伸出头后约 5 格（和死神镰座龙颅同一造型：后掠长角 + 张开的下颌）。
  - 躯干：沿背线的脊椎（每 3 格一节 + 棘突）；前半身 5 根肋骨从脊椎弯到胸底、肋间留 2 格空，看得见笼里的魂焰；胸骨；臀部骨盆 + 闭孔；骨盆和头骨上的裂纹随技能合上。
  - 颈：7 节椎骨沿往前上弯的曲线排开（节间暗关节、节上棘突），长而弯。
  - 翼：只剩骨架——2 格臂骨、1 格翼指 × 3、拇指爪；臂骨和每根翼指上各垂一条灰白裹尸布条（长短参差，下半截随风摆）；半张时高出背线约 10 格。
  - 腿：骨腿（肩 / 髋骨结、上段 2 格下段 1 格腿骨、关节骨结、3 格骨爪）。
  - 尾：12 节尾椎（粗节 + 暗关节 + 棘突），尾尖骨刺铲（菱形）。
- 攻击方式：远程（射 · 吐息光束）：伏低后张口喷出一道骨片夹冥霜的直线细吐息。
- 差异化：
  - 体型档：巨型贴地四足骨架（和复仇之龙的悬浮翼龙、毒龙的肉身重龙、天龙的蛇身完全不同；全身无肉）。
  - 识别特征：①背上挂裹尸布条的骨翼（改轮廓，高出背线 10 格）②后掠长角龙头骨（改轮廓，角伸出头后 5 格）③长尾椎 + 骨刺铲（改轮廓）④空肋骨笼里的冥霜魂焰（轮廓内的发光体）。
  - 武器 + 握法 + 攻击类型：无持械 · 口吐 · 射（光束型吐息，不是单发弹；复仇之龙是单发魂焰弹）。
  - 待机个性：咔哒下颌——低伏不动，下颌骨一开一合，笼中魂焰随之明暗；1.6–2.0 s 抬头连咬两下，魂焰炽亮一闪。
  - 步态：四足骨节爬行——低伏的对角步态，接触帧压低 1 格顿挫，每步爪落地 4 颗尘土。
  - 死亡方式：连锁散架——从尾尖开始按 7 节一节节塌到地上（每节先塌一半、下一帧落地散开），一直塌到头骨；笼中魂焰熄灭，骨堆化灰（死亡套件 ash）。
  - 主色：骨白（本组骷髅兽里唯一全身骨白的），点缀死神同款灰白裹尸布、冥霜青白。

## 特效设定卡

- 元素色阶：冥霜吐息 · 冥霜青白 FXI.frost = 21 → 22 → 23 → 40 → 39（白 → 冰青 → 青 → 钢蓝 → 深蓝）；回血魂光 FXI.soul（22 → 23 → 24 → 25 → 3，呼应死神）；吐息骨片 / 受击骨屑 boneChip [21, 17, 6, 7, 8]；化灰 boneAsh [17, 6, 7, 10, 8]。
- 攻击「冥霜细吐息」：
  - 预兆：伏低 3 格、低头、下颌半张 2 帧（魂焰亮一档）。
  - 出手：抬头张嘴到 3，身体后坐 1 格，口边寒光 2 帧；1 格宽冥霜光束从口直射目标 0.22 s，5 片白骨屑沿光束飞。
  - 命中：10 颗冥霜外爆，假人小摇。
- 技能「吞魂回血」（desc：击杀敌人时恢复自身生命值）：
  - 蓄力 1.4 s：伏低、翼骨张开（翼姿 5），肋骨笼里的魂焰 1 → 2 → 3 档越烧越亮（笼缝透光，火星从笼里冒出），冰霜粒子逆时针螺旋吸进张开的下颌（K_SPIRAL_PT 定点汇聚），轮廓光 2 档、地面映光；最后 0.3 s 身体抖动。
  - 施放 0.5 s：张口喷出宽 3 格的冥霜吐息光束（fx.beam frost 0.45 s）+ 十字星芒 + 冲击环，汇聚粒子沿光束飞向目标，光束里一路翻滚白骨片（每秒 40 片），震屏 2 格、天空闪白。
  - 命中：目标冰封外罩（dummyFx outline frost + 冰色 + 减速 0.4，1.4 s），冲击环 + 20 颗外爆；一团魂光从目标身上被抽出，沿光束倒流回肋骨笼（以笼为圆心的 K_SPIRAL_PT，0.7 s）。
  - 收招 0.7 s：0.25 s 魂光入笼，魂焰一亮（笼缝星芒 + 魂光外爆 + 小冲击环），骨缝的裂纹逐帧合上（crack 2 → 0），翼骨收回。
- 受击：白色剪影 1 帧 + 击退 2 格 + 闭眼 + 翼一收、尾反甩，魂焰闪烁；骨屑火花 + 少量魂光；震屏 1 格。
- 死亡：26 颗骨屑 + 震屏 2 格 + 闪白 → 踉跄伏低 → 从尾尖开始 7 节骨头依次塌落（每节落地扬起骨屑 + 尘土；骨盆、肋骨笼那一节和头骨那一节加震屏 1 格）→ 头骨最后塌下 → 1.1 s 魂焰熄灭（冥霜烟 + 魂光上升）→ 静止骨堆 0.6 s → 1.7 s 骨堆从上往下化灰飘走（ash）。
- 音色：巨大骨节的咔咔摩擦 + 冰风呼啸般的长吐息 + 骨片碰撞的碎响，重量 0.9。
  - SFX 声明：`{ body: 'stone', how: 'collapse', pal: 'frost', style: 'beam', w: 0.9 }`
  - 关键帧：移动接触帧 `step`（w 0.9）；攻击出手帧 `swing`（bite）+ `hit`（magic）；施放命中 `impact`（frost 0.9）；收招魂焰回亮 `impact`（frost 0.4）；散架时肋骨笼 / 头骨落地 `fall`。
