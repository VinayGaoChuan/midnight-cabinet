# 游侠 Ranger

模块：`pcd/chars/Ranger.js`（身体用部件库拼：`rig cape pack(quiver) arm legs torso(leather) hood(cowl) head(pointy) bow hand`；模块里自画的小部件：兜帽尾 `hoodTail`（候选部件）、精灵长尖耳延长、拿在手上的箭、散落在地上的箭）。
升级线：游侠 → 死亡射手是**同一个人**：长弓、尖顶兜帽 + 长尖耳、兜帽尾、背后箭袋、斜挎带都保留，死亡射手升级成骨弓、破边长披风、骨面罩和死亡标记。

## 角色设定卡

- 名称 / 身份：游侠，朴素的林地猎手（普通品质：没有发光体、没有金饰，只有一张好弓）。
- 一句话剪影：**比身高还长的竖直长弓 + 尖顶兜帽后坠的长兜帽尾 + 肩后高出的箭羽束**；剪影一眼读成「弓手」。
- 尺寸：待机 21×31 格（身体到兜帽顶 27 格，长弓 27 格竖在身前，弓梢高过兜帽）；体型 `slim`（leg 10 · torso 8 · head 6 · headW 5 · sw 3），窄肩细长腿，头身比约 6。
- 材质色阶（全部取自 64 色共享色板，没有新增颜色）：
  - 兜帽 / 短斗篷 苔绿 `moss` [0, 34, 35, 36]（斗篷 band 2）· 皮甲 浅褐 `leather` [20, 19, 32, 33] · 护腕 / 腰带 / 斜挎带 `wood` · 裤 `sand` · 靴 `boot`
  - 肤 浅象牙 `skin` [11, 16, 15, 15] · 眉 `sand` · 眼 `ink`
  - 长弓 浅木 [20, 19, 33, 5] · 弦 `white` · 箭杆 `wood` · 箭头 `steel` · 弓上箭的箭羽 `green`；箭袋 `wood` + 皮边 `leather` + 白色箭羽束 `white`
  - 发光体：蓄力时箭头换成 flat 的刃光材质 [28, 30, 31, 21]（`GLOW_MATS`）
- 部件顺序（从后往前）：短斗篷 → 箭袋（+ 箭羽束）→ 后臂（窄袖 + 护腕）→ 腿（高靴）→ 躯干（皮甲 + 斜挎带 + 钢扣）→ 兜帽后层 + 兜帽尾 → 头（尖耳 + 延长的耳尖）→ 兜帽前檐 → 前臂（握弓）→ 长弓（弓臂 + 弦 + 搭上的箭）→ 手上的箭（待机 / 收招）→ 后手（搭箭 / 拉弦）。
- 细节清单：
  - 脸：细长眼（2 格墨）、浅色眉、小鼻尖、瘦削长下巴；精灵尖耳从兜帽侧面向后上伸出 4 格。

  - 服装：皮甲前沿缝线 + 胸前系带、斜挎带、腰带 + 钢扣；苔绿短斗篷有两道褶、下摆会摆；高靴翻口。
  - 手臂：窄袖 + 长护腕，2×2 手。
  - 武器：27 格长弓（握把加厚、弓梢亮一级、弦、拉满时搭箭：木杆 + 钢箭头 + 绿羽）；箭袋斜挎在背后，三支白羽箭高出肩线。
- 攻击方式：远程 **双手拉满长弓直射**：1 帧拉弓（预兆）→ 松弦定格（后手向后弹开、兜帽尾前甩）→ 箭（钢头 + 木杆 + 绿羽）平直飞出。
- 差异化（对照已通过：守夜人 / 寡妇 / 修女 / 屠夫领主 / 钟表匠 / 火葬人 / 蛮兽 / 邪眼王 / 星辉巫师 / 维京战士 / 奴隶主 / 两匹马）：
  - 体型档：瘦高（`slim`）；巫师也是瘦高但罩长袍、佝偻老者；游侠是窄肩细长腿、露出两条腿的年轻猎手。

## 特效设定卡

- 元素：精准 · 刀锋银白，色阶 `FXI.steel` = 白 21 → 银 31 → 灰蓝 30 → 铁 29 → 深铁 28；箭羽点缀 `nature` 绿（37 / 36）。
- 攻击「长弓直射」
  - 预兆：1 帧拉满（后手拉到前手后 7 格，兜帽尾前甩）。
  - 出手：松弦定格，后手向后弹；弓前枪口十字光 2 帧（steel）。
  - 弹道：钢头 + 3 格木杆 + 绿羽的箭，210 格/秒，淡银拖尾。
  - 命中：8 颗 impact 外爆，假人闪白小摇。
- 技能「精准」（被动特性生效的样子：瞄准弱点，一箭带刃光命中并追加一道锋利裂口）
  - 蓄力 1.4 s：半蹲 1 格、身体后仰，拉弓不放（pull 1 → 2 → 3）；0.3 s 后眼前一道横向银色瞄准线（隔点、逐帧流动）伸到假人，假人身上一枚银色菱形准星从 10 格逐帧收缩到 3 格，中心一闪一闪；箭头换成刃光材质并在 1 / 2 档间逐帧闪，箭头周围银色火花螺旋收拢；轮廓光 2 档、地面映光。
  - 施放 0.5 s：松弦定格 2 帧（后手向后弹开），箭变成 1×5 白刃光（银色刀锋拖尾 + 两颗绿羽），240 格/秒；枪口十字光 + 12 颗银色火花；震屏 2 格、天空闪白。
  - 命中：箭刺入点十字星芒 + 一道斜切口（`fx.slash`）+ 20 颗 steel 外爆 + 5 颗绿羽屑，假人闪白大摇、震屏 1 格；0.2 s 后第二段额外伤害：交叉的第二道裂口 + 星芒 + 18 颗外爆，假人再大摇（两段各一次 `impact`）。
  - 收招 0.7 s：后手伸到肩后箭袋再抽出一支箭，横握着放回待机。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼 + 兜帽尾 / 斗篷反甩；impact 16 颗；震屏 1 格。
- 死亡：26 颗 impact + 震屏 2 格 + 闪白 → 踉跄 → 单膝跪下 → 向前扑倒（离地 3 → 1 → 0 两帧下落）→ 长弓脱手横着弹到身前、两支箭散落在脚边 → 落地扬尘 14 颗 + 震屏 1 格 → 静止 → 1.6–2.4 s 自上而下消散 + 魂光上升。
- 音色：细弦嗡响 + 箭离弦的轻快「嗖」，木弓轻吱，重量 0.25（`SFX: body flesh · how topple · pal metal · style blade · w 0.25`；`step` 在步态接触帧、`swing bow` + `shoot arrow` 在松弦帧、`hit` 在箭到达、技能两段各一次 `impact`、`fall` 在扑倒落地帧）。
