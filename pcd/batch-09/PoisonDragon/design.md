# 毒龙 PoisonDragon

## 角色设定卡

- 名称 / 身份：毒龙，精灵族先锋，传说。翡翠龙长成的成年重龙：保留背上花脊、叶形翼、尾尖花，花变成腐毒巨花，喉下长出毒气囊。
- 一句话剪影：一头前重后轻的墨绿低伏大龙，肩后开着一朵紫黑大王花、喉下吊着一只荧绿发光的毒囊、头顶一对后掠骨角。
- 尺寸：待机约 53×28 格（`len 16`、胸 6 / 臀 5、肩峰 2、`leg 6`），成年重龙档；先锋读法 = 厚胸肩峰、低重心、身体比幼龙长一倍。
- 身体：`parts-beast` 的 `quad`，dragon 头型（w 7.5 · h 6 · 吻 6）+ 后掠长角（hornLen 6）+ 鳞纹；叶片翼（破洞枯叶）、腐毒巨花、小毒花、喉囊、鳞缝荧光、尾花是模块自画部件（候选部件 `leafWing(holes)` / `rotFlower` / `throatSac`）。
- 材质色阶 [勾线, 暗, 基, 亮]：
  - 鳞（主材质）墨绿 moss [0, 34, 35, 36]；腹甲 暗橄榄 [34, 48, 49, 36]；鳞缝 荧绿 [48, 49, 50, 38]（按档手工取色）
  - 巨花 / 小毒花 / 尾花 腐紫 [52, 53, 42, 54]；花口 [0, 52, 52, 53]；花心荧绿点
  - 叶翼 膜 [52, 53, 54, 43]、叶脉 moss（远侧暗一级），叶缘参差 + 两个破洞
  - 喉囊 [48, 49, 50, 38] + 亮芯（平涂 38 / 21）；眼 荧绿（平涂）；角、爪 bone
- 部件顺序（从后往前）：远叶翼 → 远侧腿 → 尾 → 尾花 → 躯干 + 颈（鳞缝并进躯干）→ 近侧腿 → 近叶翼 → 3 朵小毒花 → 腐毒巨花 → 喉囊 → 头 → 角。
- 细节清单：荧绿眼 + 眉骨 + 鼻孔 + 张嘴露双牙；后掠长角；鳞纹 + 荧绿鳞缝（技能时逐档变亮）；腹甲分隔；叶翼中脉 / 侧脉 / 破洞 / 参差缘；巨花 5 片厚瓣 + 瓣上斑 + 深色花口，大张时花心透荧绿；喉囊高光 + 鼓到 3 档起出亮芯；爪尖骨白。
- 攻击方式：远程（近距离）喷吐——后仰鼓囊 → 张口向前喷一小股毒液团（3×3 + 下挂一滴，带拖尾），命中一小团毒雾。
- 差异化：
  - 体型档：成年重龙（前重后轻的长身四足，和幼龙的圆滚、两匹高腿马、蛮兵的前倾猿形都不同）。
  - 识别特征：①肩后紫黑腐毒巨花（直径约 10 格）+ 背后 3 朵小毒花 ②破洞枯叶大翼，半张时伸出背线约 8 格 ③喉下荧绿毒囊 ④头顶一对后掠长角（①②④改外轮廓）。
  - 武器 + 握法 + 攻击类型：徒手 × 施法（喷吐）；与幼龙的「咬」拉开。
  - 待机个性：喉囊一鼓一瘪（每 4 帧），嘴角冒毒泡；个性时刻巨花慢慢张开吐出一缕紫雾。
  - 步态：沉重爬行（低伏压腹，每步 3 颗尘土 + 一滴毒液落地冒烟）。
  - 死亡方式：融化（塌下后按列塌成一滩墨绿毒泥，巨花最后凋落在泥上，毒泥冒泡蒸发）。
  - 主色：墨绿鳞 + 腐紫花翼 + 荧绿毒囊；比翡翠龙暗、浓，和同组巫毒系（淡青绿 / 靛紫甲壳 + 骨白面具）、翠玉系拉开。

- 元素色阶 `toxinRot`：白 21 → 淡黄绿 50 → 绿 49 → 墨绿 34 → 腐紫 53；孢子 `rotSpore`（shadow 紫点缀）：淡紫 43 → 54 → 42 → 53 → 52。
