# 死亡射手 DeathShooter

模块：`pcd/chars/DeathShooter.js`（部件库：`rig cape(tattered) arm legs torso(leather) hood(cowl) head(pointy) hand`；模块里自画、标了「候选部件」的：反曲骨弓 `recurveBow`、弦上标记石、高骨箭袋 `tallQuiver`、骷髅面罩 `skullMask`、兜帽尾 `hoodTail`）。
升级线：游侠 → 死亡射手是**同一个人**：同款尖顶兜帽 + 向后伸出的精灵长尖耳 + 兜帽尾、同样竖在身前的长弓、背后斜挎箭袋、斜挎带和皮甲都保留；体量加高 2 格、换成反曲骨弓、破边长披风、骨面罩、黑羽箭和紫色死亡标记。

## 角色设定卡

- 名称 / 身份：死亡射手，阴冷的标记猎手（稀有：比游侠多一层披风、骨饰、发光的标记石和更复杂的技能特效）。
- 一句话剪影：**半蹲低姿 + 两端骨刺钩外翻的反曲骨弓 + 垂到脚边的破边长披风**，兜帽尖、尖耳、肩后紫羽箭束从头后伸出；剪影读成「弓手」，但比游侠更低、更宽、更阴。
- 尺寸：待机 23×33 格（身体到兜帽顶约 28 格，半蹲后 26 格；骨弓 29 格 + 骨刺钩）；体型 `slim` 加长（leg 11 · torso 9 · stride 2 · lift 1），与游侠同一体型但更高，待机 `crouch 2` 半蹲 + 前倾 1。
- 材质色阶（全部取自 64 色共享色板，没有新增颜色）：
  - 兜帽 / 长披风 墨黑绿 [0, 52, 34, 35]（披风 band 2：暗部是墨紫、亮部是深绿）· 皮甲 深褐 `wood` · 斜挎带 / 靴 `boot` · 裤 `iron` · 骨饰（面罩、护腕、铆钉、弓梢、箭袋）`bone` [8, 7, 6, 17]
  - 肤 `skin`（只露上半张脸和尖耳）· 眼 = 标记石同色的紫光
  - 骨弓：弓臂 [0, 52, 54, 43]（每 3 行一道暗箍 = 缠黑布）+ 3 格 `bone` 骨梢 · 弦 `pale` · 黑羽箭：杆 [0, 52, 53, 54] + 箭头 `steel` + 紫羽 `purple`
  - 发光体：弦上的标记石 2×2，`gem` [25, 42, 24, 43] + `glow` [43, 43, 21, 21]（flat，5 档：待机 / 蓄力 / 蓄满 / 施放 / 熄灭）
- 部件顺序（从后往前）：破边长披风 → 高骨箭袋 → 箭羽束 → 后臂（窄袖 + 骨护腕）→ 腿（高靴）→ 躯干（皮甲 + 骨铆钉 + 斜挎带 + 骨扣）→ 兜帽后层 + 兜帽尾 → 头（尖耳 + 骷髅面罩，同一部件）→ 兜帽前檐 → 前臂（握弓）→ 反曲骨弓（弓臂 + 弦）→ 黑羽箭 → 标记石 → 后手。
- 细节清单：
  - 脸：兜帽下一线紫色眼光；下半张脸是骨白骷髅面罩（鼻骨尖、鼻孔、牙缝一排、下颌尖）；尖耳伸出兜帽 4 格。
  - 头饰：同款尖顶兜帽 + 兜帽尾；披风从肩垂到脚边，下摆 3 格锯齿缺口，走路时贴地摆。
  - 服装：深褐皮甲（缝线、系带、骨铆钉）、斜挎带、骨扣腰带。
  - 手臂：窄袖 + 骨护腕，黑手套。
  - 武器：反曲骨弓（黑木弓臂缠黑布、握把加厚、两端 3 格骨梢向前外翻、末端骨刺回勾）、弦、弦上标记石；14 格高骨箭袋（每 4 格一道骨环），三支黑羽箭的紫羽高出肩 4 格。
- 攻击方式：远程 **半蹲快速连射**：1 帧拉弓预兆 → 松弦 → 再搭 → 第二次松弦（一次攻击两箭），出手更快。
- 差异化（对照已通过角色 + 同批游侠）：
  - 体型档：瘦高加长 + 半蹲低姿（游侠直立、24 格级；本角色 28 格级、蹲低前倾）。
  - 识别特征（≥ 2 个改外轮廓）：①反曲骨弓两端外翻的骨刺钩（轮廓）②垂到脚边的破边长披风（轮廓，游侠只有到胯的短斗篷）③高出肩 4 格的紫羽箭束（轮廓）④骨白骷髅面罩。
  - 武器 + 握法 + 攻击类型：双手 + 射，但为快速连射（两箭）；钟表匠端铳单发。
  - 动作个性：待机 = 不搭箭空拉弓弦试弦，标记石随之一亮一暗；步态 = 潜行（低姿、步幅 2、抬脚 1 格、不起尘，披风下摆贴地拖动）；死亡 = 化灰（单膝跪地、弓立在身前 → 从头顶化为紫灰粒子飘散 → 空披风塌落在地后消散）。
  - 主色：墨黑绿 + 墨紫暗部（游侠是苔绿 + 浅褐；守夜人墨橄榄绿配铜灯）；点缀骨白 + 诅咒紫。
  - 特效：诅咒紫靶心符 + 扇形三连射 + 越收越紧的三圈标记 + 被标记的描边，和游侠的银白准星 / 刃光单箭拉开。
  - 自动查重：`compare.mjs` 对已通过角色退出码 0；与游侠对比 `tooSimilar: false`。

## 特效设定卡

- 元素：标记 · 诅咒紫，色阶 `FXI.curse` = 淡紫 43 → 紫 24 → 深紫 42 → 墨紫 25 → 墨 52；箭刃与切口用 `steel`（21 → 31 → 30 → 29 → 28）。
- 攻击「快速连射」
  - 预兆：1 帧拉满（标记石亮 1 档）。
  - 出手：1/12 s、4/12 s 两次松弦，每次标记石亮 2 档、枪口紫十字 2 帧、兜帽尾前甩。
  - 弹道：钢头 + 黑杆 + 紫羽黑羽箭，250 格/秒，紫色拖尾。
  - 命中：每支 8 颗 impact + 4 颗 curse 外爆，假人闪白小摇。
- 技能「标记目标」（表现连续命中在目标身上叠起死亡标记，靶心逐层收紧）
  - 蓄力 1.4 s：蹲得更低、后仰拉满（pull 1 → 2 → 3）；标记石从暗到亮 2 档逐帧闪；紫色符文粒子（K_SPIRAL）绕弓臂收拢到标记石；0.35 s 起假人头顶浮现紫色靶心符（圆 + 十字，逐帧长大，蓄满后闪）；轮廓光 2 档、地面映光。
  - 施放 0.5 s：扇形连射 3 支黑羽箭（0、2/12、4/12 s，向上 / 平直 / 向下三个角度），每支 1 帧松弦 + 1 帧再搭，每次枪口紫十字；第 3 支震屏 2 格 + 天空闪白 + 14 颗紫火花。
  - 命中：靶心符落到假人胸口，每支箭命中在外面加一圈（半径 12 → 9 → 6，越收越紧，新圈白闪 2 帧），每支各一次 `impact`；最后一圈：30 颗 curse 外爆 + 小冲击环 + 一道 steel 刀锋斜切，假人大摇并被 `dummyFx { tint curse, outline curse }` 染紫描边（被标记）；标记圈 0.9 s 后断续消失。
  - 收招 0.7 s：低头、面罩下呼出一口紫雾（上飘的 curse 粒子），放下弓，标记石 2 → 1 → 0。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼 + 兜帽尾 / 披风反甩；impact 16 颗；震屏 1 格。
- 死亡：26 颗 impact + 震屏 2 格 + 闪白 → 踉跄 → 单膝跪地、骨弓立在身前（落膝扬尘 8 颗）→ 标记石闪几下熄灭 → 0.9 s 死亡套件 `ash`（curse 色阶）从头顶化为紫灰粒子飘散，同时脚下塌落一堆空披风（墨绿 / 墨紫），1.7 s 内抖动消散；另有紫色余烬上升。
- 音色：低沉的骨弓弦「嘣」+ 连续三声急促破风，诅咒符文的低鸣，重量 0.35（`SFX: body flesh · how dissolve · pal curse · style spiral · w 0.35`；`step` 在接触帧、`swing bow` + `shoot arrow` 在每次松弦、`hit` 在箭到达、技能每支一次 `impact`、`fall` 在单膝落地帧）。
