# 翠盾（VerdantShield）

## 角色设定卡

- 名称 / 身份：翠盾，精灵族守护者（部队，神话，近战）。黑铁卫进化后的同一个人：保留尖刺塔盾、翼耳桶盔、背上的旗，黑铁里长出翠绿活木与藤叶，背旗旗杆长成一株小树。
- 一句话剪影：身前一面更大的翠玉活木塔盾（盾顶三根抽芽的木刺）+ 缠藤翼耳盔（叶尖再伸出 2 格）+ 头顶上方散开的一团树冠，枝上垂一面翠绿议会长旗。
- 尺寸：身体约 35 格高（盔顶），树冠再高出盔顶约 10 格，待机外框约 45 格；地面线统一在脚底。
- 体型档：巨型守护（parts.rig giant 改：leg 12 · torso 14 · head 7 · headW 7 · sw 7 · arm 14 · lw 4 · stride 3 · limb 1.5），比黑铁卫更高更宽；站姿同样双脚分开立盾，脚下根须抓地。
- 材质色阶（[勾线, 暗, 基, 亮]，全部取自共享色板）：
  - 翠玉活木甲 jade = green [34, 35, 36, 37]（躯干、肩甲——面积最大）；盾面 face = [34, 35, 35, 36]（band 2，比甲暗一档，让翠玉花跳出来）
  - 黑铁 iron = iron [0, 27, 28, 29]（盔、臂甲、胫甲、盾框）
  - 藤叶 vine = moss [0, 34, 35, 36]；叶尖 leaf = [35, 36, 37, 38]
  - 树干 / 木刺 wood = wood [0, 20, 19, 16]；树冠 crown = moss（band 2）
  - 议会长旗 cloth = green（band 2）+ 淡黄绿边 leaf
  - 翼耳 wing = [28, 29, 30, 31]（沿用黑铁卫的亮银）
  - 面甲缝眼光 eye = [34, 36, 38, 38] flat（淡黄绿）
  - 盾心翠玉花（发光体）gem = [35, 36, 37, 38] flat · glow = [38, 50, 21, 21] flat
- 部件顺序（从后往前）：小树（树干 + 枝 + 议会长旗 + 树冠）→ 后臂（铁臂甲）→ 腿（铁胫甲）→ 根须 → 躯干（翠玉板甲 + 藤叶腰带，藤叶和躯干同一部件）→ 远侧翼耳 → 近侧翼耳（缠藤 + 叶尖）→ 桶盔 → 前臂（铁臂甲 + 翠玉肩甲）→ 塔盾（铁框、翠玉面、木刺、翠玉花同一部件）→（死亡时）藤蔓裹身。
- 细节清单：
  - 脸：桶盔面甲缝 + 1 格淡绿眼光、T 形翠玉面饰；受击 / 死亡时眼光熄灭。
  - 头饰：同款叶形翼耳（亮银），上面缠 3 格藤，尖端各冒出一片 4 格大叶（远侧暗一级）。
  - 躯干：板甲中脊、胸腹分界、甲片分段 + 铆钉；腰间一圈藤叶腰带（波浪藤 + 叶子）。
  - 手臂：黑铁臂甲 + 翠玉圆肩甲（铁边），铁手套。
  - 腿脚：黑铁胫甲；站定时脚下各伸出 2–3 根根须抓地。
  - 武器（塔盾）：11×16 格，黑铁框 + 铆钉，翠玉活木盾面带淡绿叶脉，顶边三根木刺（两侧 3 格、中间 4 格）各抽出嫩叶；盾心翠玉花（花心 + 4 片十字花瓣 + 4 片斜花瓣），开合 3 档 × 发光 5 档（待机 / 蓄力 1 / 蓄力 2 / 施放 / 熄灭）。
  - 小树：1 格树干从腰后伸出、越过肩后斜向头顶，树冠在盔顶上方散开（10 格宽、随 sway 摆），往后伸一根枝，挂一面 4×9 的翠绿议会长旗（下摆随 beard 摆，淡黄绿边 + 叶纹）。
- 攻击方式：近战 · 砸（同黑铁卫的盾砸：双手举盾过头 → 前冲 4 格砸地），砸地时盾底根刺沿地面向前扎出一排。
- 差异化：
  - 与黑铁卫（同一条升级线，要像同一个人进化）：保留塔盾 + 三刺、翼耳盔、背上的杆；加体量（35 格 → 大一档、sw 7）、主色从黑铁换成翠绿、背旗变成树 + 竖挂长旗、技能从「举盾插地的银点阵护罩」变成「扎根 + 大圆法阵 + 藤蔓连线 + 叶盾」。
  - 与其他已通过角色：体型档是全队最高的巨型步兵；轮廓特征（树冠、木刺盾、叶尖翼耳）都改外轮廓；武器 + 握法 + 攻击类型（双手盾砸 + 根刺）和守夜人（矛刺）、维京（盾撞）、奴隶主（斧劈）都不同。
  - 待机个性：盾心翠玉花缓慢开合（闭 → 半开 → 全开 → 半开），树冠摇曳、偶尔落一片叶。
  - 步态：生根重步——步幅 3、接触帧下沉 1 格、盾底磕地，每次落脚冒出 2 棵小草芽 0.4 s 后缩回 + 3 颗尘。
  - 死亡方式：跪地生根——单膝跪下以盾撑住，藤蔓从地面往上一层层裹住全身（3 档），最后整个人化成一地落叶飘走（死亡套件 ash，nature 色阶）。
  - 主色：翠绿（green），和黑铁卫的黑铁、守夜人的橄榄绿斗篷（更暗、更黄）拉开。
