# 翡翠龙 EmeraldDragon

## 角色设定卡

- 名称 / 身份：翡翠龙，精灵族先锋，优质。开花的幼龙，香气来自背上的花。
- 一句话剪影：一只矮胖圆滚的绿色小蜥龙，背脊一排粉色花苞、尾巴尖顶着一朵花、背上翘着一片叶子。
- 尺寸：待机约 37×21 格（`len 10`、`leg 4`、胸 4.6 / 臀 4.3），圆滚幼龙档；先锋读法 = 厚胸、低重心、头大颈短。
- 身体：`parts-beast` 的 `quad`，dragon 头型放大（w 7 · h 6 · 吻 3.5）+ 一对短骨角；叶片翼、背脊花苞、尾花是模块自画部件（候选部件 `leafWing` / `spineFlowers` / `tailFlower`）。
- 材质色阶 [勾线, 暗, 基, 亮]：
  - 鳞（主材质）翠绿 [34, 36, 37, 38]；腹线 浅黄绿 [35, 37, 38, 5]
  - 叶翼 膜 [34, 35, 36, 37]、叶脉 moss [0, 34, 35, 36]（远侧各暗一级）
  - 花苞 / 尾花 pink [11, 12, 63, 58]；花萼 = 叶翼色；花蕊 gold
  - 眼 金豆眼（平涂）；角、爪 bone
- 部件顺序（从后往前）：远叶翼 → 远侧腿 → 尾 → 尾花 → 躯干 + 颈 → 近侧腿 → 近叶翼 → 背脊花苞 → 头 → 角；侧躺时四条腿挪到最后（肚子朝镜头），再画散落的花瓣。
- 细节清单：眼 + 眉骨高光 + 鼻孔 + 张嘴露牙；短骨角；腹线带腹甲分隔；叶翼有中脉 + 斜向侧脉；花苞分花萼 / 花瓣 / 苞尖，盛开后有金色花蕊；爪尖骨白；尾花五瓣 + 花蕊。
- 攻击方式：近战，咬——扑前 5 格一口咬合（上下两道弧往中间合拢），命中火花 + 少量粉花粉。
- 差异化：
  - 体型档：圆滚幼龙（四足低矮，和已通过的四足角色——两匹高腿马、前倾猿形的蛮兵——都不同）。
  - 识别特征：①背脊 4 朵粉花苞代替背刺（最高一朵高出背线 4 格，随呼吸开合）②叶片形小膜翼收在背上翘出约 3 格 ③短粗尾尖一朵张开的花（前 3 个都改外轮廓）。
  - 武器 + 握法 + 攻击类型：徒手 × 咬。
  - 待机个性：嗅花打喷嚏（仰头往后嗅 → 皱鼻闭眼 → 猛一低头打喷嚏，喷出一小团粉花粉）。
  - 步态：摇摆小跑（短腿快倒腾、头一点一点，尾花一甩一甩，每步 2 颗小尘）。
  - 死亡方式：侧倒（翻身侧躺伸腿，花苞合拢垂下，花瓣散落在身边）。
  - 主色：翠绿鳞 + 粉花；和同组的毒龙（墨绿 + 腐紫）、巫毒虫（淡青绿软虫 + 骨白面具）、翠玉系（活木 + 黑铁）拉开。
