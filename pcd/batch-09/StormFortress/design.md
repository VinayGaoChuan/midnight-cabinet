# 风暴堡垒 StormFortress

模块：`pcd/chars/StormFortress.js`。身体不用现成骨架：树根双足、阶梯雉堞塔、带电荆棘藤、三只卷物藤臂、香蕉串、香蕉叶、雷云都是本模块自画的部件（函数前标了「// 候选部件」）。
升级线：玉藤堡垒 → 风暴堡垒，是**同一座塔长大了**：保留四垛雉堞塔顶（上层塔 = 玉藤堡垒同款 15 格塔身）、香蕉叶、射孔双眼光、缠塔的倒刺藤、卷香蕉串的藤臂、树根腿；新添下层宽塔 + 走道角垛、更粗的根腿、倒刺长成带电蓝刺尖的粗荆棘、藤臂从 1 只长到 3 只、塔顶悬一团雷云；石色从玉青褪成灰青风暴石。

## 角色设定卡

- 名称 / 身份：风暴堡垒，神话级的两层植物石塔；前排防御（先锋），一次抡三只藤臂连投三个香蕉，挨打时带电荆棘把伤害反弹回去并引雷劈回攻击者。
- 一句话剪影：**顶上悬着一团雷云 + 两层阶梯塔（下宽上窄、雉堞顶）+ 三只伸出轮廓 6–8 格的藤臂各挂一串香蕉（左右两侧 + 背后举过顶）**，全身外沿一圈荆棘毛刺。
- 尺寸：待机 53×48 格（塔 19 宽、雉堞顶 32 格、叶顶 37 格、雷云顶 46 格；三只藤臂把宽度撑到 53）。神话品质，比玉藤堡垒高 12 格、宽一倍。
- 材质色阶（色板下标；风暴石是本角色追加的 3 个颜色）：
  - 灰青风暴石 [27, #2f4a52, #50727a, #8fb2b4]（塔身 band 2，走道 / 雉堞 band 1）
  - 荆棘藤 墨绿 [0, 34, 34, 35]（背后那只藤臂 [0, 0, 34, 34]）· 荆棘刺身 [0, 34, 35, 36] · 电蓝刺尖 / 云中电光（发光体，flat）[40, 23, 22, 21]
  - 雷云 `steel` [27, 28, 29, 30]（band 2）· 香蕉叶 `green` · 树根腿 `wood`（远侧暗一级）· 香蕉 [20, 14, 47, 51]
  - 射孔 `ink`；眼光（发光体）[40, 23, 22, 21]——眼光从玉藤堡垒的绿变成电蓝
- 部件顺序（从后往前）：远侧叶 → 背后藤臂 + 香蕉串 → 左侧藤臂 + 香蕉串 → 远侧根腿 → 近侧根腿 → 中间叶 → 前侧叶 → 下层塔（塔基、塔身、走道、角垛、砖缝 + 同部件的荆棘藤）→ 上层塔（塔身、挑檐、雉堞、射孔 + 眼光 + 同部件的荆棘藤）→ 右侧藤臂 → 香蕉串 → 雷云。
- 细节清单：
  - 「脸」：上层射孔 + 两点电蓝眼光（待机左右扫、个性动作时抬头看云；1–3 档；熄灭档）。
  - 「发 / 须」：三片香蕉叶（叶尖摆动）；雷云三个云包隔 0.4 s 翻滚一次、底部一排暗点。
  - 头饰：同款四垛雉堞 + 挑檐落石孔；下层走道两角各一个角垛（阶梯轮廓）。
  - 「服装」：石砖灰缝 + 错缝 + 砖角高光；四道斜缠的墨绿荆棘藤，藤顶每 3 格一根刺，蓄力后刺顶亮电蓝；外沿 9 根荆棘（刺身 2–3 格 + 电蓝刺尖，技能里长到 5–6 格，蓄满时再加 6 根）。
  - 「手臂」：三只 2 格厚藤臂，顶上几根刺，末端卷一圈；背后那只暗一级。
  - 「腿脚」：两条 5 格粗树根腿，树皮暗纹两道，根须外扩（着地时伸出 6 格）。
  - 武器：三串香蕉（同玉藤堡垒的扇形香蕉串，每串投出后少一根）。
  - 发光体：眼光 + 刺尖 + 云中电光（`GLOW_MATS` 两种）。
- 攻击方式：远程 **投 · 连击三下**：右臂后引 → 右臂抡出（第 1 只）同时背后那只后引 → 背后那只从塔顶上方抡出（第 2 只）、左臂后引 → 左臂从塔顶甩过（第 3 只）；三只香蕉 2 / 12、4 / 12、6 / 12 s 出手，各飞 0.22 s 命中。
- 差异化（对照已通过 13 个角色 + 同线的玉藤堡垒）：

  - 武器 + 握法 + 攻击类型：三臂轮流卷握 + 连投（玉藤堡垒是单臂单投）。
  - 动作个性：待机 = 雷云翻滚、0.9 s 云里闪一下，1.6–2.0 s 雷云劈出一道细闪电、塔身嘎吱一晃、眼光抬头看云，三只藤臂错相位晃香蕉；步态 = 根须重踏（接触帧下沉 2 格顿挫、每步 4 颗尘 + 碎土、雷云拖后 1 格）；死亡 = 倒塌（和玉藤堡垒的原地碎裂拉开）。
  - 主色：灰青风暴石 + 墨绿荆棘 + 电蓝刺尖 + 灰蓝雷云（玉藤堡垒是玉青 + 深绿 + 白刺）。
  - 特效：闪电三连劈 + 8 根带电刺弹，元素换成 bolt，和玉藤堡垒的纯绿刺雨拉开。

## 特效设定卡

- 元素：荆棘风暴 · 雷绿，色阶 `bolt` = 21 白 → 51 淡黄 → 22 电青 → 23 蓝 → 40 深蓝；荆棘刺弹本体仍用 `nature` 绿（35 / 36）+ 电青尖；雨丝 `water`、散云 `steel`。
- 攻击「三连投」
  - 预兆：每只藤臂出手前 1 帧后引（右臂举过塔顶、背后那只往后拉、左臂压低到身后），眼光 1 / 2 档交替，雷云往前拖 1 格。

  - 命中：每只 8 颗 impact + 6 颗香蕉黄外爆，假人闪白小摇三次。
- 技能「荆棘 + 部落战争」
  - 蓄力 1.4 s：两颗敌弹（enemy）分别在 0.4 s、0.65 s 打在塔身（下层 / 上层），每次火花 + 电光十字 + 震屏 1 格、塔身一晃；荆棘随之逐根亮起（外沿刺 2 → 5 格，刺尖从暗蓝点亮成电青、第 2 档起藤上的刺也亮）；雷云一档档压低 3 格、云肚电光逐帧闪，电光粒子在云下螺旋汇聚；三只藤臂先缩起、再一齐高举；轮廓光 2 档（电青）。
