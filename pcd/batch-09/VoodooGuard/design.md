# 巫毒守卫 VoodooGuard（模块 pcd/chars/VoodooGuard.js）

## 角色设定卡

- 名称 / 身份：巫毒守卫，精灵族先锋，优质品质的飞行甲虫。巫毒信徒进化后的成虫：保留同一张面具、同色软虫身、同款膜翅和毒囊，加上甲壳、一对大镰爪，毒囊变成两节。
- 一句话剪影：背上拱起的靛紫硬甲壳（鞘翅半张、后缘外翻），前面一张放大的骨白面具戴一圈骨刺冠，面具下收着一对螳螂镰爪，腹下两节串珠毒囊。
- 尺寸：待机约 28 × 26 格（优质），身体离地 7 格悬停（比信徒更低、更沉）；地面画影子。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 软虫身 / 腹线 / 翅膜：与巫毒信徒相同（同一个体进化）
  - 甲壳：[0, 25, 42, 24]，band 2（purple 暗段）；高光 [22, 22, 22, 21]（紫青，平涂）
  - 面具 / 骨刺冠 / 镰爪：bone [8, 7, 6, 17]（远侧爪暗一级）；涂纹：crimson [11, 12, 13, 26]（平涂，深红）
  - 爪尖毒：[48, 49, 50, 38]（平涂，发光体）
  - 毒囊皮：shadow [0, 52, 53, 54]（深紫）；毒液：[48, 49, 50, 38]（比信徒整体高一级亮度）；毒液炽亮 [50, 38, 21, 21]；眼孔紫光 [42, 24, 43, 21]
- 部件顺序（从后往前）：远侧下翅 → 远侧上翅 → 远侧镰爪 → 两节毒囊 → 软虫身 → 近侧下翅 → 近侧上翅（膜翅从壳下伸出）→ 鞘翅甲壳 → 骨刺冠 → 面具 → 近侧镰爪
- 细节清单：
  - 脸（面具）：放大到 8 × 10，四格宽的眼孔 + 1 格上挑眼角（平时墨色，蓄力亮紫）、2 格亮鼻梁、额上锯齿纹、两道深红泪痕、嘴缝 + 5 格齿列
  - 头饰：5 根骨刺冠沿面具顶弧放射，中间一根最高（高出面具 3–4 格），刺尖亮
  - 甲壳：拱顶硬壳，刻点纹，后下缘外翻 2 格并提亮，紫青高光 3 格；以前端为铰点抬起（合 / 半张 / 全张三档）
  - 镰爪：股节 + 9.5 格长的弯刃，刃背加厚，内侧每 2 格一颗锯齿，爪尖 2 格荧绿毒（发光体），蓄力时挂毒滴
  - 身体 / 毒囊：分节软虫身比信徒粗一圈；两节串珠毒囊（后节小、前节大），各自一档亮度
  - 翅：同信徒的细长膜翅，加长到 12 / 8
- 攻击方式：近战扫——双镰爪交叉横扫（近爪高举下劈、远爪低引上撩），前冲 6 格（站位 HX 70）。
- 差异化：
  - 体型档：悬浮甲虫档（优质，约 28 × 26，前重：面具 + 镰爪在前，甲壳拱在后）。和巫毒信徒同一骨架但比例变了：身体更粗、离地更低、甲壳把背线拱成穹顶；同组其他角色是人形、四足龙、植物堡垒。
  - 识别特征（3 个，全部改变外轮廓）：骨刺冠（面具顶上放射 5 根刺）；拱起的靛紫甲壳（后缘外翻，蓄力时全张再宽约 4 格）；前胸一对镰爪（折成 V 收在面具下，攻击 / 蓄力时高举出轮廓）。
  - 武器 + 握法 + 攻击类型：双持（一对骨镰爪）× 扫（交叉横扫），同组没有重复；和信徒的冲撞拉开。
  - 待机个性：磨爪——1.6–2.0 s 两只镰爪上下交错互刮，爪尖亮起，1.95 s 爪尖滴下一滴毒液。
  - 步态：低空重扑翼——每 2 个 12 fps 帧换一次翼姿（比信徒慢一半），身体每拍下坠 1 格再弹起，鞘翅随扑翼开合；下压时把地上的尘吹起 2 颗。
  - 死亡方式：坠落碎壳（翅膀收拢直坠 → 落地压扁 → 死亡套件 chunks 碎成块弹开 → 两节毒囊依次爆雾），和信徒的空中爆裂拉开。
  - 主色：靛紫甲壳（面积最大）+ 骨白 + 青绿；同组没有紫色主材质（毒龙的腐紫只是背花与翼膜）。
  - 与巫毒信徒：查重剪影 IoU 约 0.52、施放 IoU 约 0.42，配色相似度 0.89（同一个体有意共用软虫身、翅膜、面具色）；轮廓靠甲壳、冠、镰爪拉开。

## 特效设定卡

- 元素：剧毒 · 荧绿加深，色阶 poison（21 白 → 50 → 49 → 48 → 34）用于爆发帧和火花；蓄力汇聚、毒雾、毒痕、毒滴、毒洼用本模块新建的深两级色阶 venomDeep（50 淡黄绿 → 49 黄绿 → 48 橄榄 → 34 墨绿 → 52 墨紫，最后一级带一点诅咒紫）。
- 攻击「双镰交叉横扫」：预兆 1 帧（后引 2 格，近爪高举、远爪低引，鞘翅全张，爪尖亮）→ 出手帧前冲 6 格定格，近爪下劈、远爪上撩 → 两段交叉的毒色斩击弧（fx.slash，一段在角色前、一段在角色与假人之间，2 帧）→ 命中 impact 火花 10 颗 + 毒色 6 颗 + 一滴毒液落地，假人闪白小摇。
- 移动：每 0.17 秒后节毒囊下 1 颗毒色拖尾，翅膀下压帧地面扬尘 2 颗。
- 技能「副过敏反应」（表现毒素浓度更高：两节毒囊依次注满，镰爪蘸毒后远程甩出剧毒）：
  - 蓄力 1.4 s：后退 4 格；鞘翅全张（外轮廓变宽约 4 格），膜翅张开并在最后阶段扑动；两节毒囊从后往前点亮（后节 0.3 s、前节 0.65 s，0.9 s 后交替闪）；镰爪半举，爪尖 1/2 档逐帧闪并挂毒滴、被荧绿轮廓光包住（爪尖外 2 格十字点）；深毒色粒子螺旋收拢到爪尖；轮廓光 2 档、地面映光。
  - 施放 0.5 s：双爪交叉一挥（近爪下劈、远爪上撩，第 1 帧毒囊 / 爪尖 / 眼孔全亮）；收拢粒子外爆 + 两爪尖火花 + 小冲击环；震屏 2 格 + 天空闪白；甩出两道毒刃弧（上刃「\」往下飞、下刃「/」往上飞，路上交叉成 X，带毒色拖尾）。
  - 命中：两道刃各一团深毒雾叠在假人身上 + 各 16 颗外爆；第一道命中时大冲击环 + 假人闪白大摇 + 中毒染色 + 减速（dummyFx tint poison slow 0.5，1.6 s）+ 震屏 1 格；X 形毒痕贴在假人胸口 0.9 s（后半断续闪）；毒滴受重力落地，假人脚下漫开一滩小毒洼 1.2 s。
  - 收招 0.7 s：回到原位，鞘翅合回半张，0.17 s 近爪上甩、把残毒甩成 4 滴抛出去。
- 受击：引擎 impact 火花 16 颗 + 白色剪影 1 帧 + 击退 2 格；闭眼、翅膀甩上扬、鞘翅震开、两爪垂软、尾上翘；震屏 1 格。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 0.3–0.62 s 翅膀收拢、鞘翅合上、镰爪垂软，按加速度直坠 6 格 → 0.62 s 落地压扁，扬尘 16 颗 + 震屏 1 格 → 0.7 s 甲壳碎成块弹开（死亡套件 chunks，从甲壳中心往外），后节毒囊爆出深毒雾 + 毒色外爆 → 0.88 s 前节毒囊再爆一团 + 小冲击环 → 碎块 1.2 s 后抖动消散，1.6–2.4 s 魂光上升。
- 音色：甲壳咔哒开合 + 镰爪刮擦的尖锐骨声，毒液嘶嘶，重量 0.45。SFX = { body: armor, how: shatter, pal: poison, style: blade, w: 0.45, hover: 1 }；swing（claw）/ hit（stone，骨爪）在出手帧，两道毒刃各发一次 impact（poison），落地帧发 fall（0.45）；悬浮不落脚，不发 step。
