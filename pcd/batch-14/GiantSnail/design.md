# 角色设定卡 · 巨蜗 GiantSnail

- 名称 / 身份：巨蜗，军团法术「巨型蜗牛」召来的巨型铁壳蜗牛（敌人，野兽，普通）。「近战肉盾」→ 背着一只铁箍战壳当盾、壳侧挂木盾、壳顶带撞角，攻击是连壳带身撞过去，技能是缩壳立墙把敌人顶回去；「巨型蜗牛」→ 和蜗牛同样的眼柄、黏液、同色系软身，只是放大并武装。
- 一句话剪影：贴地的暗粉灰厚软身上扛一只直径 22 格、高过身体一倍的骨黄巨壳，三道铆钉铁箍箍住，壳顶斜伸一截尖锥铁撞角；壳侧挂一面方木盾；前端两根粗眼柄张成 V 字、各套一只铁护环、眼睛眯成缝。
- 尺寸：巨型档，待机约 34 格高（含撞角和勾线）、46 格长（含身后黏液带）；地面线统一。
- 体型档：巨型铁壳蜗牛档——`B.blob` slug（r 11，身体 34 格长、11 格高），螺壳半径 11；是蜗牛的放大版（蜗牛 r 5 / 壳 4.5），比例不变，体量翻倍；和同组龙龟（短腿四足趴着的壳）拉开：没有腿，是软体。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 软身（主材质）：暗粉灰 [#1e1216, #4a3038, #7a5860, #a8868a]（专属 4 色，和蜗牛同色系更深；厚身用 band 1）；眼柄用同一色阶的平涂材质（基色 #7a5860，近侧左边一格亮色 #a8868a）
  - 巨壳：sand 骨黄 [20, 61, 62, 5]（手动两色：基色 + 右下暗弯，左上一块 4 格高光）；螺纹 wood 19 / 20；铁箍与眼柄护环 steel [27, 28, 29, 30]（暗 1c · 基 1d · 亮 1e）；撞角 / 盾包边 iron [0, 27, 28, 29]；铆钉 gold 0e
  - 木盾：wood [0, 20, 19, 16]；盾心小蜗牛纹 gold
  - 铁箍亮银（技能，发光体）：[29, 30, 31, 21]（flat）
  - 黏液带：white；眼缝 ink
- 部件顺序（从后往前）：黏液带 → 远侧眼柄（+ 护环）→ 近侧眼柄（+ 护环）→ 软身（B.blob.body，紧跟着画嘴线、下触角、脸上旧疤、蠕行波峰）→ 撞角 → 巨壳（候选部件 ironShell：壳 + 螺纹 + 三道铁箍 + 铆钉）→ 木盾（候选部件 plankShield）。死亡时软身换成往前流的一滩（puddle）。
- 细节清单：
  - 脸：眼柄顶端 3×2 亮色眼球，中间一行墨缝（眯眼），闭眼时缝拉满 3 格；嘴线 3 格、张嘴往下开；两根下触角；脸上一道旧疤。
  - 眼柄：2 格粗平涂（左亮右基），中段一只 4 格宽的铁护环（基色 1d + 左端 1 格亮 1e）；顶端 3×2 亮色眼球夹一行墨色眼缝；V 字张开，待机时慢慢转。
  - 巨壳：一条 1 格宽的连续 wood 螺线，从壳底外圈绕进壳心 1.5 圈，穿过铁箍处断开、铁箍之间每段都是弧线；左上 1/4 一块 4 格高光，其余不撒高光；三道 2 行铁箍（上行基色 1d、左侧 2 格亮 1e，下行暗 1c），下行每 5 格一颗金铆钉 0e；壳顶斜前方 5 格尖锥撞角（尖端高光）。
  - 木盾：8×9 竖木板缝、铁包边 + 包角亮点、盾心一只金色小蜗牛（3×3 螺壳 + 头 + 2 格眼柄 + 一行腹足，呼应蜗牛）；死亡时掉落平躺。
  - 发光体：三道铁箍（技能从下到上逐道亮起；死亡时闪几下熄灭）。
- 站位：HX 67（待机眼柄尖离假人手臂 ≥ 2 格）。
- 攻击方式：近战「冲撞」，软身后缩、壳往后仰（预兆）→ 出手帧整体前冲 11 格、壳往前推 5 格、头缩到壳下，用壳侧和撞角撞上假人（竖直冲击弧 + 撞击火花 + 银屑），假人大摇。
- 差异化：
  - 体型档：巨型铁壳蜗牛档（同族蜗牛的放大版）；和同组克拉肯（贴地圆顶 + 8 触腕 + 铁锚）拉开：没有触腕，一只巨壳占身体上半；和已通过的蟹巫 / 蟹术士（寄居蟹、腿、螯、法器）拉开：没有腿和螯，壳是铁箍战壳。
  - 识别特征（≥3，其中 ≥2 改外轮廓）：① 壳顶斜伸的尖锥铁撞角（外轮廓）② 壳侧方木盾，伸出壳后沿（外轮廓）③ 两根粗眼柄张成 V 字、各套铁护环（外轮廓）④ 三道铆钉铁箍（内部）⑤ 身后两行宽黏液带（贴地）。
  - 武器 + 握法 + 攻击类型：铁箍巨壳 + 撞角 × 背负（身体本身）× 冲撞。
  - 待机个性：喘气——软身一鼓一缩、壳跟着起伏；眼柄慢慢转一圈，顶层铁箍上一道反光从左往右扫过。
  - 步态：大型蠕行——拉长 → 尾部拱起 → 缩短 → 颈部拱起，壳随波前后晃，每个接触帧扬尘 4 颗。
  - 死亡方式：融流留壳——软身化成一滩往前流走（6 档：摊开 → 变薄 → 往前流 → 一道湿痕 → 没了），空壳原地落地并向后倒下 90°，木盾掉落平躺，铁箍闪几下熄灭，壳化灰。
  - 主色：暗粉灰软身 + 骨黄壳 + 铁灰箍；同组软体克拉肯深海酒紫、四足龙龟岩青，不撞；和蜗牛同色系更深，壳从金色换成骨黄 + 铁。

# 特效设定卡 · 近战肉盾 · 冷铁

- 元素色阶：FXI.steel 白 21 → 银 31 → 灰蓝 30 → 铁 29 → 深铁 28（同一技能只用它 + 通用 impact / dust / soul）。和攻城锤同色阶但图案不同：巨蜗是壳前立起一堵弧形点阵墙把敌人顶回；攻城锤是斜面弹箭。
- 攻击（冲撞）：预兆 = 软身缩短、壳后仰、眼柄往后倒 1 帧；出手 = 前冲 6 格，假人身前一道 2 帧的竖直冲击弧（银第 1 级 → 第 3 级断续）；命中 = 撞击火花 16 颗 + 银屑 8 颗 + 地面扬尘，假人大摇，震屏 1 格。
- 技能「近战肉盾」（无特性 → 表现描述）：
  - 蓄力：0–0.36 s 软身整个缩回壳里（缩壳 1 → 3 档、眼柄收回），巨壳落地；0.45 s 壳下地面向两边压出裂纹 + 扬尘；三道铁箍从下到上逐道亮银（0.45 / 0.7 / 0.95 s），一颗火花沿亮起的铁箍从左往右跑；银屑螺旋收拢；最后 0.3 s 壳一抖一抖；轮廓光 2 档 + 地面映光。
  - 施放：壳猛地前顶 4 格（2 帧），壳前立起一堵弧形银色点阵墙（从地面往上 0.12 s 立起；1/4 椭圆，圆心在壳前 4 格，外层 16×29、内层隔 2 空格，中段离壳前沿 4–5 格）；外爆 24 颗 + 大冲击环 + 十字星芒 + 前方扬尘；震屏 2 格 + 天空闪白。
  - 命中（施放 2/12 s）：假人撞在墙上被顶回——撞点那一段墙内外两层连成实线全白（第 2 帧外白内银），银火花外爆 20 颗 + 金属冲击环 + 十字星芒 + 4 颗银屑弹落，假人击退，震屏 1 格。
  - 收招：墙逐点熄灭（0.5 s），壳退回原位，软身慢慢探出来，眼柄一格一格小心地伸出（先眯着眼），铁箍 3 → 0。
- 受击：「肉盾」壳甲 → impact 火花 16 颗 + 白色剪影 1 帧 + 击退 2 格；眼柄缩短并往后甩、眯眼。
- 死亡：26 颗火花 + 闪白 → 抽搐 → 软身融成一滩往前流走（溅出尘点）→ 空壳落下（离地 3 → 1 → 0）并向后倒下 → 木盾掉落平躺（尘土 + 木头声）→ 落地尘土 16 颗 + 震屏 1 格 → 铁箍闪几下熄灭 → 自上而下消散，灰和魂光一起上升。
- 音色：铁箍沉闷的嗡鸣 + 厚重的黏液拖曳，标志性一声是铁壳撞击的「哐——」，重量 0.85。SFX 声明：body armor、how collapse、pal metal、style shield、w 0.85；step 在蠕行的两个接触帧、swing（smash）在出手帧、hit（metal）在撞上的那一帧、impact（metal）在假人撞墙那一帧、fall 在空壳落地帧、hit（wood）在木盾落地。
