## 角色设定卡

- 名称 / 身份：恐龙，野兽族的双足小霸王龙，近战敌人；又呆又肉。
- 一句话剪影：巨大方头 + 咧着的大嘴 + 头顶一根歪长肉冠，胸前两只可笑的小短手，粗尾巴贴地拖在身后。
- 尺寸：待机约 39×33 格（含尾巴和肉冠）；头约占全身 1/3，躯干圆胖、身体前倾靠尾巴平衡，后腿粗短。普通品质。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 鳞（主材质）：苔绿粗鳞，专属 4 色 `#141c08 / #34481a / #5a7a2c / #8aaa4a`（moss 亮段偏黄），躯干 band 2、四肢 band 1、远侧腿 / 手暗一级
  - 腹：sand；背板：wood；牙 / 爪：bone；肉冠：pink；眼：金 [0, 0, 14, 5] + 白眼仁 [7, 18, 17, 21]
  - 蓄力眼光（发光体，平涂）：[19, 61, 62, 5]
- 部件顺序（从后往前）：远侧小短手 → 远侧后腿 → 尾 → 背板 → 躯干 + 颈（+ 腹部两行，同一部件）→ 近侧后腿 → 头（+ 钝牙、嘴角、眼，同一部件）→ 肉冠 → 近侧小短手；仰倒时两条后腿挪到最后画（朝天）。
- 细节清单：
  - 脸：2 格大眼（白眼仁 + 金瞳）+ 眉脊亮点、吻尖鼻孔、嘴线上一排隔格钝牙（张嘴时上下两排）、嘴角往上咧的墨点；闭眼 / 眨眼。
  - 鳞 / 背：躯干鳞纹（隔行错位的暗格）、背上 4 块圆钝骨板 + 颈上 1 块、腹部沙色两行带腹甲分隔。
  - 头饰：歪长肉冠（根粗梢细、往后歪、梢端下垂 1 格，随尾巴摆动换位）。
  - 手：两只 2 格小短手 + 骨白小钩爪，伸出胸前轮廓；垂 / 够脸 / 乱挥 / 缩 4 种姿势，远侧那只错相位。
  - 腿脚：粗圆大腿 → 前顶的膝 → 后折的跗 → 往前的三趾脚 + 骨白爪；远侧腿整条暗一级。
  - 发光体：没有法器，蓄力时眼睛发土黄光（熄灭 = 平常的金眼）。
- 攻击方式：近战咬——头先后缩张大嘴（预兆 2 帧）→ 猛往前一伸（前冲 7 格）一口咬下（出手定格 + 上下咬合拖影）。
- 差异化：
  - 体型档：双足大头档（本组唯一）。和龙龟（低矮壳四足、壳是主体）拉开：直立双足、巨头小手；和蜥蜴人（兽头人身、瘦高、投枪）拉开：兽体不是人形、没有武器；和已通过的龙（翠绿幼龙圆滚四足带翼、毒龙重龙、青龙游龙、天龙羽翼）拉开：没有翅膀、不是四足。
  - 识别特征 ≥ 3（3 个改变外轮廓）：①巨大方头 + 永远咧着的钝牙嘴（外轮廓）②头顶歪长肉冠（外轮廓）③胸前小短手伸出一对小钩（外轮廓）④贴地拖的粗尾（外轮廓）⑤背上一排圆钝骨板。
  - 武器 + 握法 + 攻击类型：徒手 × 咬（技能是头槌冲撞）。
  - 待机个性：发呆——歪头看天、嘴张着、慢慢眨两次眼，小手往上够脸（够不着）乱挥。
  - 步态：笨重双足踏步——接触帧下沉 1 格、每步震地 2 颗尘土、尾巴左右甩、头随步点一下、小手晃。
  - 死亡方式：仰倒蹬腿（往后一仰 → 翻倒肚皮朝天 → 两腿朝天蹬两下、小手还在晃 → 不动 → 化灰）。
  - 主色：苔绿偏黄粗鳞；和青龙 / 翠绿幼龙的绿拉开在明度和黄味上，点缀粉色肉冠、木色背板。

## 特效设定卡（元素：蛮劲 · 尘土）

- 元素色阶：earth = 5 奶油 → 62 淡土黄 → 61 土褐 → 19 深褐 → 20 墨褐；扬尘用 dust，咬合火花用 impact。
- 攻击「一口咬」：
  - 预兆：后缩 2 格、仰头、嘴张到 3 档，尾巴上翘，小手缩起。
  - 出手：前冲 7 格、低头、嘴猛合上定格 1 帧；上下两道咬合弧合向嘴尖 2 帧（第 1 帧白、第 2 帧断续金）。
  - 命中：12 颗 impact 外爆，目标闪白小摇。
- 技能「非常肉」（冲撞头槌）：
  - 蓄力 1.4 s：0.3 s 内低头刨地、身体压低后退 2 格；两只后腿轮流抬起跺地 4 次（0.35 / 0.65 / 0.95 / 1.2 s），每跺一下地面裂一道小纹 + 4 颗尘 + 震屏 1 格；尘土螺旋聚到脚边成一团；0.7 s 后眼睛发土黄光、冒土黄火星，尾巴抖动；轮廓光 1→2 档。
  - 施放 0.5 s：脚边尘团炸开，低头冲撞 8 格（2 帧），身后扬起一长溜尘土，前方一道土浪（fx.wave），脚下尘环；震屏 2 格 + 天空闪白。
  - 命中（施放 +2/12 s）：头槌撞上目标 —— 大冲击环 + 十字星芒 + 24 颗带重力的土块外爆（落地）+ impact 火花，目标大摇 + 击退；恐龙弹回 1–2 格、闭眼，头顶转两颗晕星；震屏 1 格。
  - 收招 0.7 s：摇摇头（左右甩 4 帧）、嘴张着，小手乱挥，晕星转到 0.65 s，慢慢退回原位。
- 受击：enemy 色阶敌弹来袭 → 白色剪影 1 帧 + 击退 2 格 + 闭眼 + 张嘴 + 尾巴反甩 + 小手乱挥；impact 16 颗 + 震屏 1 格（引擎默认）。
- 死亡：26 颗 impact + 震屏 2 格 + 闪白 → 往后一仰（仰头张嘴「嗷？」、小手乱挥）→ 翻倒肚皮朝天（离地 3 → 1 → 0）→ 落地尘土 16 颗 + 震屏 1 格 → 两腿朝天蹬两下 → 小手晃到 1.2 s 停下 → 静止 → 1.6 s 起自上而下消散，同时尘土色上升粒子（化灰，不用魂光）。
- 音色：沉重的肉脚踏地 + 喉咙里的傻呼噜；标志性一声是头槌撞上的「咚！」，接一声迟钝的「嗷？」；重量 0.9。
