# 角色设定卡 · 蜗牛 Snail

- 名称 / 身份：蜗牛，野地里慢吞吞的小软体（敌人，野兽，普通）。「弱」→ 同组最小、没有任何武装，攻击只是用头轻轻顶一下；「主要用作收入来源」→ 背着一只铜钱纹金螺壳、壳顶竖着一枚方孔铜钱，身后的黏液里闪着金点。
- 一句话剪影：贴地的淡粉小软身 + 背上一只圆滚滚的金螺壳，壳顶竖一枚方孔铜钱像顶小帽；两根眼柄一直一弯；身后拖一道亮晶晶的黏液。
- 尺寸：小怪档，待机约 19 格高（含壳顶铜钱和勾线）、26 格长（含身后黏液），同组最小；地面线统一。
- 体型档：小蛞蝓档——`B.blob` slug（r 5，身体 16 格长、5 格高），头抬在前端；螺壳半径 4.5 压在背中偏后。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 软身（主材质）：淡粉米色 [#2a1818, #7a5050, #c09080, #e8c4b0]（专属 4 色，小身体用 band 1，远侧眼柄暗一级）
  - 螺壳：gold [20, 19, 14, 5]；螺纹凹槽 wood [0, 20, 19, 16]
  - 方孔铜钱（平涂）：钱缘 金 14 一圈 → 面 62（受光左上）/ 暗金 61（背光右下）→ 左上 1 格 5 高光 → 2×2 方孔 棕 20；发光时同色（只登记为发光体），施放爆闪 2 帧换 [14, 5, 21, 21]
  - 螺纹亮金（技能，发光体）：[61, 14, 5, 21]（flat）
  - 黏液：white [7, 18, 17, 21]，每 4 格一个 gold 亮点；眼瞳 ink
- 部件顺序（从后往前）：黏液 → 远侧眼柄 → 近侧弯眼柄 → 软身（B.blob.body：足沿波纹、抬起的头、湿高光，紧跟着画嘴、下触角、脸颊亮点、蠕行波峰）→ 螺壳（候选部件 coinShell）→ 壳顶铜钱（候选部件 squareCoin）→ 掉在地上的金币。
- 细节清单：
  - 脸：两根眼柄用软身基色 #c09080，顶端眼球（亮 1 格 + 墨瞳 1 格，眯眼时变成一道暗缝）、嘴（墨 1 格，张嘴往下开 1–2 格）、一对下触角、脸颊亮点。
  - 软身：足沿波纹（随步态前移）、左上湿高光、蠕行时尾部 / 颈部拱起的波峰。
  - 螺壳：一条从外圈往里 1.5 圈的连续螺纹、外圈 4 个钱纹亮点、壳心高光；空壳时露出墨色壳口。
  - 铜钱：6×6 圆角立着、嵌在壳顶，中间 2×2 棕色方孔；技能里转成 6 / 4 / 2 / 4 宽；死亡时弹飞、平躺在地上。
  - 发光体：铜钱（待机 / 闪光 / 亮 / 施放爆闪 / 熄灭）+ 技能里逐圈亮起的螺纹。
- 攻击方式：近战「冲撞」，身体先缩短拉高（预兆），出手帧身体前伸拉长 + 前冲 3 格，用头轻轻顶在假人上（小弧线 + 少量撞击火花）。
- 差异化：
  - 体型档：小蛞蝓档，同组最小最矮，贴地无腿；和同组巨蜗（28 格高的铁箍巨壳）是同族放大关系，靠体量、壳（金钱纹 vs 铁箍）、武装（无 vs 撞角木盾）拉开；和已通过的蟹术士（寄居蟹 + 螺壳 + 尖帽 + 杖）拉开：没有腿、没有螯、没有法器，身体是软体。
  - 识别特征（≥3，其中 ≥2 改外轮廓）：① 壳顶竖一枚方孔铜钱像小帽（外轮廓）② 两根长眼柄一直一弯、伸出身体约 4 格（外轮廓）③ 身后一行亮晶晶带金点的黏液（外轮廓，贴地）④ 螺壳上的铜钱纹亮点（内部）。
  - 武器 + 握法 + 攻击类型：无武器 × 徒手（软身）× 冲撞（头轻顶）。
  - 待机个性：伸缩眼柄——两根眼柄交替缩回再伸出，最后壳顶铜钱反光一闪。
  - 步态：蛞蝓蠕行——拉长 → 尾部拱起 → 缩短 → 颈部拱起，一波一波往前推，极慢（演示只走 6 格），每次接触帧在黏液里留一个金点。
  - 死亡方式：缩壳掉钱——身体缩进壳里 → 空壳倒地滚半圈（离地 3 → 1 → 0）→ 壳顶铜钱弹飞、壳口掉出三枚金币 → 壳化灰。
  - 主色：淡粉米色软身 + 金壳；同组软体克拉肯是深海酒紫、巨蜗是暗粉灰 + 骨黄铁箍，不撞。

# 特效设定卡 · 收入来源 · 金币

- 元素色阶：FXI.coin 白 21 → 淡金 5 → 金 14 → 暗金 61 → 棕 20（同一技能只用它 + 通用 impact / dust / soul）。和宝箱怪同色阶但图案不同：蜗牛是壳里往外喷一小串钱、最大一枚被收走；宝箱怪是吸金币。
- 攻击（顶）：预兆 = 身体缩短拉高、眼柄往后收 1 帧；出手 = 前伸拉长 + 前冲 3 格，头前一道 2 帧的小弧（金色第 1 级 → 第 3 级断续）；命中 = 8 颗撞击火花，假人小摇。
- 技能「收入来源」（无特性 → 表现描述）：
  - 蓄力：0–0.3 s 身体缩进壳里（缩壳 1 → 3 档，眼柄收回，壳落到地上）；0.35 s 起螺纹从外圈往里逐圈亮金（4 圈），0.5 s 起壳顶铜钱旋转（宽 5 / 3 / 1 / 3），金屑螺旋绕壳收拢；最后 0.3 s 壳憋着劲一抖一抖；轮廓光 2 档 + 地面映光。
  - 施放：「啵」地探出头（身体拉高、张嘴），壳顶铜钱爆闪变白 2 帧后回到金色，壳里喷出 12 枚金币（K_PHYS 抛物线，部分 2×2）落向身后的黏液；外爆 14 颗 + 小冲击环 + 铜钱十字星芒；震屏 2 格 + 天空闪白。
  - 命中（施放 0.38 s）：金币落地，三处十字星芒（臂长 7 / 5 / 4），6 颗金币再弹一下（叮当）；最大一枚金币 3×3 白芯 + 暗金外沿，沿弧线飞向画面左上角（被收走），身后拖 5 格金色尾迹；震屏 1 格。
  - 收招：眼柄伸出，头一上一下满足地晃晃、眯着眼；铜钱亮度 2 → 1 → 0。
- 受击：肉身 → impact 火花 16 颗 + 白色剪影 1 帧 + 击退 2 格；两根眼柄猛地缩回（惯性部件反向甩）、眯眼，然后一根先伸回来。
- 死亡：26 颗火花 + 闪白 → 抽搐（身体一缩一伸）→ 缩进壳里 → 空壳倒地滚半圈 → 壳顶铜钱弹飞平躺 → 落地尘土 + 壳口洒出 6 颗金币粒子，地上依次多出三枚金币（各闪一下星芒）→ 铜钱闪几下熄灭 → 自上而下消散，灰（dust）和魂光一起上升。
- 音色：黏滑的吧唧声 + 金币叮叮，标志性一声是壳里喷钱的「啵叮」，重量 0.1。SFX 声明：body flesh、how collapse、pal coin、style coin、w 0.1；step 在蠕行的两个接触帧、swing（thrust）在出手帧、hit（flesh）在顶到的那一帧、impact（coin）在金币落地、fall 在空壳落地帧。
