# 角色设定卡 · 炮手 Cannoneer

- 名称 / 身份：炮手，扛着青铜臼炮的野猪头女炮兵（敌人，野兽，优质）。「远程大炮」→ 肩扛臼炮、高抛物线炮弹；「威力十足」→ 技能是装一颗特大炮弹、长引信、一炮轰出大爆炸；「她」→ 收腰、睫毛、耳环、红头巾。
- 一句话剪影：往后倾的壮实身板，肩上斜扛一门比她还长、喇叭口朝前上方的青铜臼炮；野猪头上扎红头巾、两根飘带往后飞；腰后一串叠着的黑铁炮弹。
- 尺寸：优质档，约 28 格高（含头巾，待机包围盒 27×31 含飘带与炮弹）、约 26 格宽（含炮）；地面线统一。头身比约 4（头 7 高 × 7 宽 + 3 格吻）。
- 体型档：标准偏壮女炮手档——`parts.rig` standard（leg 8、torso 9、head 7 / headW 7、neck 1、sw 5 宽肩、arm 9、lw 3、limb 1.3 粗臂、waist 1 收腰、headX -1），待机站弓步（step 1）、lean -1 被炮压得往后倾。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 军装（主材质）：橄榄绿 [0, #434e1c, #6e7c30, #9eac50]（moss 亮段偏黄，补 3 个专属色），躯干 band 2
  - 猪皮：粉灰 [20, #8a5a5e, #c08a88, #e0b4aa]；鬃 ink [0, 0, 27, 28]；鼻头 pink；獠牙 white（flat）
  - 臼炮：青铜 gold [20, 19, 14, 5]；铁箍 iron [0, 27, 28, 29]；木托 wood；引信 sand；引信火星（发光体）[44, 46, 47, 21]
  - 头巾 crimson；腰带 / 斜挎带 / 护腕 leather；扣 / 耳环 gold；靴 boot；炮弹 iron 暗段 [0, 27, 28, 29]
- 部件顺序（从后往前）：后手拿着的大炮弹 → 后臂 → 两腿 → 躯干（短军装 + 腰带 + 扣 + 斜挎带）→ 腰后炮弹串（1 格皮吊带 + 每颗炮弹各一个部件，挂在身体后轮廓外）→ 前臂 + 手（从下面托炮身）→ 臼炮（含木托、引信）→ 野猪头（头颅含吻 / 眼 / 獠牙 → 垂耳）→ 红头巾 → 擦炮时手里的头巾角。
- 细节清单：
  - 脸：1 格墨眼 + 1 格睫毛、腮红、往前伸 3 格的吻（前 2 格是 2×3 粉鼻盘，盘上 2 个墨鼻孔）、嘴线（jaw 咧嘴）、近侧獠牙 2 格白从吻根往上翘过吻顶。
  - 毛发：后颈一溜墨黑鬃毛（逐行亮暗），脑后 2×3 垂耳（头巾下沿，内侧粉），耳尖挂金耳环。
  - 头饰：红头巾包住头顶两行（亮色花点），脑后打结，两根飘带从结上往后飞 3 格（高过垂耳）、4 相位飘动。
  - 躯干：橄榄绿短军装（前沿缝线、胸前系带）、皮腰带 + 金扣、斜挎皮带；收腰。
  - 手臂腿脚：宽松袖 + 皮护腕 + 2×2 手；短粗腿 + 高靴。
  - 武器：青铜臼炮（压在右肩上，待机炮尾 (−9, −12) → 炮口 (12, −20)，整根低于猪吻）= 炮尾球钮 → 粗炮尾 → 3 格厚的炮身 → 炮颈 → 喇叭形炮口（黑洞）+ 两道 1 格铁箍 + 炮尾下的木托 + 炮尾上沿的引信（短引信 / 蓄力时放下的长引信），引信火星 5 档（暗 / 亮 / 蓄 / 喷 / 灭）。
- 攻击方式：远程「射」——半蹲、后手按住引信点火 → 出手帧后坐 2 格，炮口十字光 + 一团硝烟，一颗黑铁炮弹高抛物线飞向假人。
- 差异化：
  - 体型档：标准偏壮人形，和同组安全鼹鼠（矮墩圆胖）、机器人（小铁罐独轮）拉开：标准身高、大件武器扛肩；和已通过的炮灰法师（背葫芦种荚炮的球茎身）、哥布林直升机（旋翼座舱双联炮）拉开：人形步兵扛单管青铜臼炮。
  - 识别特征（≥3，其中 ≥2 改外轮廓）：① 右肩上扛的青铜臼炮，喇叭口伸出吻前约 8 格（外轮廓）② 野猪头：上翘獠牙 + 垂耳，头顶红头巾两根飘带往后飞（外轮廓）③ 腰后 1 格皮吊带吊着一串 3 颗 4×4 圆形黑铁炮弹（四角空，1d 基 / 1c 右下暗 / 1f 左上 1 格高光，颗间 1 格 00 分界线），Z 字叠在 x −15..−8、y −13..−4，伸出身体后轮廓 3–4 格（外轮廓）④ 金耳环、睫毛、腮红（内部）。
  - 武器 + 握法 + 攻击类型：臼炮 × 肩扛双手扶 × 射（高抛物线）。
  - 待机个性：擦炮——前手顺着炮身滑到炮口，用头巾一角来回擦两下，凑过去吹一口（炮口冒一小团灰），手退回来拍两下炮身，獠牙一咧笑。
  - 步态：扛炮重步——稳步走，每个接触帧炮身往下一颠 1 格，脚下 2 颗尘土，头巾飘带随步子摆。
  - 死亡方式：后仰——像被后坐推倒一样仰面倒下，大炮从肩上滚落「咚」地砸地冒一团黑烟，头巾飘落，身体化灰。
  - 主色：橄榄绿军装 + 青铜炮 + 粉灰猪皮 + 红头巾；同组人形主色为灰青蓝、巧克力褐、墨绿袍、品红紫、橙背心、灰白病态肉，不撞。
