# 龙龟 DragonTurtle

模块：`pcd/chars/DragonTurtle.js`（查看 `pcd/view.html?c=DragonTurtle`）· 自检输出：`shots/`

## 角色设定卡

- 名称 / 身份：龙龟，野兽族敌人，普通，近战肉盾。描述的关键词是「坚硬的外壳」「肉盾」，所以身体的主体就是一只高拱的石刺龟壳，攻击是龙口一咬。
- 一句话剪影：趴在地上的低矮巨壳——高拱龟壳上竖着三排锥形石刺（中排最高），壳沿一圈外翻锯齿，壳顶长一株小蕨；前面探出长吻龙头（后掠短龙角、两撇金龙须），后面一截短粗龙尾带一簇硬刺。
- 尺寸：待机约 40×23 格（壳顶石刺到 -21，长约 34 格 + 头尾），同组重心最低。体型档：低矮巨壳四足（`B.quad`：len 12、胸 5、臀 4.5、腿 3、腿粗 3）。
- 身体：`B.quad`（头 `lizard` 放大到 7 · 5.5 · 3.5 + `horn: 'back'` 短角 3 格，`foot: 'claw'`，`tail: 'none'` 改自画尾）；颈长做成 5 档形体（缩进壳 / 探出 / 平常 / 前伸 / 猛咬），姿势里选档。自画部件都标了 `// 候选部件`：`turtleShell` 龟壳（拱顶 + 甲片缝 + 锯齿壳沿 + 苔斑 + 近侧小石刺 + 中排高石刺）、`turtleTail` 短粗龙尾 + 尾刺、`fern` 壳顶小蕨、`flippedShell` 翻过来的龟壳；龙须紧跟头画（同一部件）。
- 材质色阶 [勾线, 暗, 基, 亮]：
  - 主材质 岩青龟壳 [#0e1614, #2a3a34, #4a6258, #7a9488]（本角色 4 个专属色，band 2）
  - 皮肤 moss [0, 34, 35, 36]（green 暗段），远侧腿暗一级；腹甲 / 腹线 sand
  - 石刺、角、爪 bone [8, 7, 6, 17]；龙须 gold [20, 19, 14, 5]；苔斑、蕨 green [34, 35, 36, 37]；眼 金
  - 石刺苔绿光（发光体，平涂）[36, 37, 38, 21]
- 部件顺序（从后往前）：远侧两腿 → 龙尾 + 尾刺 → 远侧一排石刺 → 躯干 + 颈 → 近侧两腿 → 头（+ 龙须）→ 角 → 龟壳（+ 近侧小石刺）→ 中排高石刺 → 小蕨。龟壳压在颈根和腿根上，头缩进去时被壳沿盖住。
- 细节清单：头——金眼 + 眉、长吻、鼻孔、嘴线、张嘴露牙、后掠短角（远侧暗一级）、两撇金龙须会摆；龟壳——拱顶左上亮、甲片横缝 + 上下错开的竖缝、壳沿一道暗缝、外翻锯齿壳沿（隔 3 格一个齿，前端上翘给脖子留口）、两块苔斑、近侧 4 个小石刺、中排 5 根高石刺（中间高 4 格往两端变矮，尖端骨白高光）、远侧一排从缝里露出来；小蕨 3 格茎 + 交替叶片随风摆；腿短粗带骨白爪；尾——根粗尖细 + 3 根硬刺。发光体：石刺的苔绿光按排亮起、5 档亮度（0 暗 / 1–2 蓄力闪 / 3 施放全亮），死亡熄灭。
- 攻击方式：近战咬——头先往回一缩（预兆 1 帧）→ 出手帧脖子猛伸 3 格 + 身体前冲 4 格一口咬合（张嘴露牙），上下两道咬合拖影弧 2 帧。站位 HX = 68（壳长头远，按猛咬时的吻尖正好碰到假人算出来，比人形近战的 76–80 靠后）。
- 差异化：
  - 体型档：低矮巨壳四足，壳是主体（和恐龙拉开：趴着、四足、没有大头小手；和宝箱怪拉开：有头有尾会爬；和巨蜗拉开：有四条腿、壳上是石刺不是铁箍）。
  - 识别特征：① 高拱龟壳 + 中排高石刺（外轮廓）② 长吻龙头 + 后掠短角 + 金龙须（外轮廓）③ 短粗龙尾 + 尾尖硬刺（外轮廓）④ 壳沿锯齿、苔斑、小蕨。
  - 武器 + 握法 + 攻击类型：龙口（徒手）× 咬；龟壳是格挡。
  - 待机个性：缩头探看——循环 1.4–2.25 s 头慢慢缩进壳里（闭眼）、再伸出来抬头低头张望，壳上小蕨一直随风摆。
  - 步态：慢爬——四腿对角缓慢交替，壳一顿一顿，每次落脚 2 颗尘土。
  - 死亡方式：翻壳碎裂（同组没有）。
  - 主色：岩青灰绿龟壳 + 骨白石刺。

## 特效设定卡

- 元素色阶：龟甲 · 苔绿自然 FXI.nature = 白 21 → 淡黄绿 38 → 叶绿 37 → 深绿 36 → 墨绿 35（和隐士同色阶，图案不同：这里是壳上弹开敌弹 + 反咬，隐士是撒种长芽）。
- 攻击「咬」：预兆（头缩 1 帧、身体压低）/ 出手（脖子猛伸 + 前冲 4 格定格，张嘴）/ 挥砍（上下两道苔绿咬合弧 2 帧）/ 命中（impact 10 颗，假人小摇）。
- 技能「铁壁反咬」（表现描述「坚硬的外壳」）：
  - 蓄力 1.4 s：头尾四肢缩进壳（头缩到壳沿下、腿和尾不画，壳落低 2 格，闭眼）；石刺逐排亮起苔绿光——0.35 s 近侧一排 → 0.6 s 远侧一排 → 0.85 s 中排最高的；发光 1/2 档逐帧闪；绿叶粒子从外面螺旋收拢、绕壳旋转（扁椭圆轨道）；脚下苔绿法阵；轮廓光 2 档（rimAll，壳的外沿全打光）；最后 0.3 s 壳抖。
  - 施放 0.5 s：壳顶十字星芒，震屏 2 格 + 天空闪白；三发敌弹（enemy 色阶 2×2 弹丸）从假人那边接连飞来（到达 0.04 / 0.14 / 0.24 s），每发打在壳上：十字星芒 + 带重力的石屑外爆 10 颗 + 弹丸往后上方弹飞；打的那几帧壳纹闪苔绿（甲片缝换成发光色）。
  - 命中（施放 +4/12 s）：头猛地伸出、前冲 4 格咬住假人——绕壳的绿叶全部射向假人，苔绿冲击环 + 叶屑外爆 20 颗 + 十字光，假人大摇击退，震屏 1 格。
  - 收招 0.7 s：头收回常位，四肢慢慢伸出（身体从贴地抬回），0.35 s 左右晃壳抖掉石屑（12 颗带重力石屑），石刺光逐排熄灭。
- 移动：慢爬，每次落脚 2 颗尘土。
- 受击：引擎 impact 火花 + 白色剪影 1 帧 + 击退 2 格；闭眼、头往回一缩、龙须和小蕨反向甩、尾巴甩起。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 头缩回一半 → 头尾四肢全缩进壳 → 壳翻过来肚皮朝天（两帧下落：离地 3 → 1 → 0），砸地尘土 16 颗 + 震屏 1 格 → 腹甲朝天左右摇两下 → 1.3 s 碎成几块石片（死亡套件 chunks，块 5 格，碎的那一刻 14 颗石屑外爆 + 震屏 1 格）→ 石片落地后按抖动消散，灰烬（dust）为主、少量魂光上升（化灰）。
- 音色：石壳沉闷的「咚」+ 慢吞吞的鼻息，标志性一声是敌弹打在壳上的一串石磬「铛、铛、铛」，重量 0.9。SFX 声明 `{ body: 'stone', how: 'shatter', pal: 'nature', style: 'shield', w: 0.9 }`；步态接触帧 step（0.9）、出手帧 swing（bite）+ hit（flesh）、三发敌弹打在壳上各一次 hit（stone，就是「铛、铛、铛」）、反咬 impact（nature）、翻壳砸地 fall（0.9）、碎壳 hit（stone）。
