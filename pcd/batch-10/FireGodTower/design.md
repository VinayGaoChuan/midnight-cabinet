# 火神塔 FireGodTower

模块：`pcd/chars/FireGodTower.js`。身体不用现成骨架（固定塔）：熔岩裂缝石堡、盘根须、烟囱耳、火苗、双联炮塔、火神面具、喇叭口炮管都是本模块自画的部件（函数前标了「// 候选部件」）。死亡用死亡套件 `burst`。
升级线：充能塔 → 火神塔。保留充能塔的盘根、右侧铜边投币口和那颗琥珀晶（嵌在火神面具额心）；老树干被火山岩包成石堡，石缝底下还露出一截树干；年轮刻线变成从下往上发光的熔岩裂缝；塔顶的晶体爪冠换成双联炮塔。体量从 25×34 长到约 35×38，是本组最高最宽的固定物。

## 角色设定卡

- 名称 / 身份：火神塔，自然族商人塔的最终形态：会铸币的熔炉堡垒，靠双联装铜炮远程连射（range 880）。
- 一句话剪影：**下宽上窄的石堡 + 两侧冒火的烟囱耳 + 顶上圆鼓炮塔，正面怒目火神面具、两颊火焰胡须向外卷起 + 面具下两根平行前伸的喇叭口铜炮管**。
- 尺寸：待机约 35×38 格（石堡底宽 23 格，炮管伸到 x +16，火苗顶约 -37 行）。传说品质，细节最密的一档。
- 材质色阶（色板下标 / 本角色追加色）：
  - 火山岩石堡 [#120808, #2e1614, #4e2a24, #7a4636]（石堡 band 2；炮塔、近侧烟囱 band 1；远侧烟囱暗一级）
  - 岩缝熔光 / 眼 / 火苗 `fire` [44, 45, 46, 47]（flat 发光体）；白热 [45, 46, 47, 21]
  - 铜炮 [#2a1606, #6a3e10, #b07028, #e8b060]；过热换色：暗红 [44, 44, 45, 46] → 烧红 [44, 45, 46, 47] → 白热 [45, 46, 47, 21]
  - 火神面具 `crimson` + 金眉金边 `gold`；额心琥珀晶 [#3a1a02, #a05a0a, #f0a020, #ffe08a]；口 `ink`；盘根 `wood`（远侧暗一级）
- 部件顺序（从后往前）：远侧盘根 ×2 → 远侧烟囱耳（+ 火苗）→ 石堡（砌缝、岩缝熔光、露出的树干同一部件）→ 近侧盘根 ×3 → 投币口 → 近侧烟囱耳（+ 火苗）→ 炮塔（铜箍铆钉、圆顶铜钮）→ 火神面具（眉、眼、鼻、口、额心晶、火焰胡须同一部件）→ 上炮管 → 下炮管。
- 细节清单：
  - 脸：火神面具——金边额、金色怒眉（外高内低）、2 格炽眼（5 档：暗 / 亮 / 炽 / 白 / 闭）、2 格鼻梁高光、墨色口 + 两颗金獠牙（技能时张口吐火光）、额心 2×2 琥珀晶。
  - 须：两颊火焰胡须各 8 格，向外上方卷起，伸出炮塔 3 格，梢头随火苗相位摆动，喷火时梢头白热。
  - 塔身：错缝砌石（3 道砌缝 + 竖缝 + 每块左上一格亮），两道从下往上发光的熔岩裂缝，石堡顶一圈矮垛，底下石缝里露出老树干。
  - 配件：铜边投币口（蓄力时缝里透出熔光）；两根 L 形烟囱耳（宽口 + 两道暗箍），口上火苗 3 档。
  - 武器：双联装铜炮，2 格粗、一道亮箍、喇叭口扩成 4 格；可平射 / 1:2 斜向上，各自后坐 0–2 格，随温度从铜色烧到白热。
- 攻击方式：远程射击（双管交替）：两根炮管一前一后后坐，连射两发熔金炮弹。
- 差异化：
  - 体型档：堡垒塔档（固定建筑）；和充能塔（瘦高锥形树干 + 晶体爪冠）拉开：厚重梯形 + 炮塔；和玉藤 / 风暴堡垒（方塔、雉堞、藤臂投香蕉）拉开：梯形石堡、烟囱耳、双炮、面具，没有藤臂（查重 idleIoU 0.55 / 0.54）。
  - 识别特征：①两根前伸 8 格的喇叭口铜炮（改外轮廓）②两侧烟囱耳 + 火苗（改外轮廓）③火神面具两颊火焰胡须伸出 3 格（改外轮廓）④熔岩裂缝、投币口、额心琥珀晶（内部，承接充能塔）。
  - 武器 + 握法 + 攻击类型：双联装炮、固定炮塔、射（双管交替）；同组没有火炮类。
  - 待机个性：炮塔左右扫视 1 格、两根炮管轮流冒一缕烟、烟囱耳吐火星、眼光和烟囱火一明一暗；步态：石座跳挪（下沉 → 跳起 3 格 → 落地扬尘 4 颗 + 震屏 1 格 → 站稳，盘根落地张开、悬空下垂）；死亡：爆炸。
  - 主色：红黑火山岩 + 铜 + 熔光橙；同组主色没有这一组。
- 音色：铜炮「轰—轰」双响，加熔炉风箱的呼呼声和金币砸地的哗啦声，最重的机械，重量 0.95。`SFX: { body: 'machine', how: 'explode', pal: 'fire', style: 'meteor', w: 0.95 }`；step 在落地帧，swing(gun) + 两次 shoot(fire) 在两次开火帧，hit(wood) 在炮弹到达，impact(fire) 在熔金炸开和第一枚金币流星落地，fall 在碎石落成堆。

## 特效设定卡

- 元素：熔金 · 火金，`fire` 色阶 21 白 → 47 淡黄 → 46 橙 → 45 红 → 44 深红；金币和「+」闪光点缀 `coin` 色阶。
- 攻击「双联连射」：预兆 1 帧（炮塔后转 1 格、眼炽亮）→ 第 2 帧上管后坐 2 格开火（炮口十字光 2 帧、6 颗火花、熔金炮弹 210 格/秒，白芯 + 金黄 + 橙尾、隔步拖尾）→ 第 4 帧下管后坐开火，第二发 → 命中：火色外爆 10 颗 + 金币色 4 颗，假人闪白小摇 → 炮管微红、两管冒白烟回位。
- 技能「美味 · 熔炉铸币」：
  - 蓄力 1.4 s：炮口抬成 1:2 斜向上、石座下沉 1 格；岩缝熔光每 0.25 s 往上亮一段，最后流到炮塔底箍的铆钉；炮管 0.5 s 后暗红、1.0 s 后烧红；投币口吸入金光（`K_SPIRAL_PT`，coin 色阶）；面具眼 1/2 档逐帧闪，最后 0.3 s 嘴一开一合；烟囱火变大；轮廓光 2 档。
  - 施放 0.5 s：双炮同时朝天斜轰两团熔金大弹（带重力的抛物线，火尾拖尾）；炮管白热后坐 2 格，面具眼白、张口吐火光；两侧烟囱耳喷火（向上各 10 颗）；额心晶十字星芒 + 冲击环；震屏 2 格、天空闪白。
  - 命中：熔金在假人上空炸开（火色外爆 20 颗 + 金币色 8 颗 + 星芒 + 小冲击环），各化成 8 枚带火尾的金币流星（共 16 颗），砸在目标周围，每枚落地溅起火星和金色「+」；第一枚落地时假人脚下大冲击环、假人大摇 + 点燃染色 0.9 s、震屏 1 格；金币在地上弹一下平躺后消散。
  - 收招 0.7 s：炮管从烧红退回铜色、炮口放平，两管冒白烟；岩缝熔光从上往下暗掉；眼光 2 → 1 → 0。
- 受击：白色剪影 1 帧 + 击退 2 格；炮塔被打偏 1 格、面具闭眼、上炮管一震、烟囱火一窜；火花 impact + 碎石 dust + 岩缝溅出的火星，震屏 1 格。
- 死亡「爆炸」：受击闪白（炮管烧红、闭眼）→ 过热 0.3 s：炮管白热、全身岩缝亮起、面具眼白张口、整座塔左右颤抖、下沉 1 格 → 炸开（死亡套件 `burst`，碎块以炮塔为中心四散，炮管、面具碎块飞得最远）+ 30 颗火色外爆 + 烟尘 + 大冲击环 + 天空闪白 + 震屏 2 格 + 10 枚熔金币四散弹跳 → 碎石落成一堆（扬尘 + 震屏 1 格）→ 碎块抖动消散，火星和烟一起上升。
