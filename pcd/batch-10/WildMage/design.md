# 野法师（WildMage）

## 角色设定卡

- 名称 / 身份：野法师，自然族法师（部队，普通，近战施法）。升级线第一级：一株刚发芽的小洋葱，力量还藏在后面的形态里。
- 一句话剪影：8 格宽的奶白洋葱球茎头 + 头顶两片左右分叉的嫩叶芽 + 右手细枝杖头一片锯齿大叶刃伸出身前。
- 尺寸：约 26 格高（含叶芽），21 格宽（含叶刃）；地面线在脚底。
- 体型档：孩童体（parts.rig child，head 8 · headW 8 · stride 1）：头身比约 3，四肢细短，头就是球茎；本组唯一的孩童体。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 叶片 leaf = #13240c #2f5a1a #5f9a2c #a6d45a（嫩黄绿：叶披肩、叶芽、叶刃，面积最大的外层）
  - 茎 stem = green [34, 35, 36, 37]（身体、细胳膊细腿）
  - 球茎 bulb = #3a3020 #8a7a8c #d8ccae #f4efe0（奶白洋葱皮，暗级偏淡紫，纵纹就用它画）
  - 根须 root = sand；杖 wood；眼 ink；腮红 pink；枯叶 dry = leather
  - 叶脉（发光体）vein = #2f5a1a · 37 · 38 · 21（flat，5 档亮度）
- 部件顺序（从后往前）：后臂 → 腿（赤足）→ 躯干短衣（茎绿 + 叶边下摆 + 根须腰带）→ 球茎头（脸、纵纹同一部件）→ 叶披肩（+ 外翘叶尖）→ 根须 → 叶芽 → 杖身 → 叶刃（叶脉同一部件）→ 前臂 + 手。
- 细节清单：
  - 脸：1×2 大眼 + 眼侧高光、腮红、小嘴；受击闭眼。
  - 发 / 须的对应物：头顶两片嫩叶芽（5 个姿态：V 形 / 右转 / 一字 / 左转 / 蔫垂），球茎底垂两条根须到下巴（随 beard 摆）。
  - 头饰：洋葱尖顶 + 淡紫纵纹 2 道。
  - 躯干：茎绿短衣、叶边下摆、根须腰带；叶披肩 3 行 + 锯齿下摆 + 前后两端外翘的叶尖。
  - 手臂 / 腿：2 格细茎臂，2×2 手；赤足短腿，远侧暗一级。
  - 武器：1 格细枝杖（吸附方向）+ 杖身一颗小芽 + 7 格叶刃（宽 1-2-3-3-3-2-1，单侧两颗锯齿、叶尖亮），叶脉 5 档亮度（待机 / 蓄力 1 / 蓄力 2 / 施放 / 熄灭）。
- 攻击方式：近战施法（HX 76）——杖甩到肩后 → 出手帧前冲 4 格单手横甩，杖水平指向目标 → 甩出 3 片旋转飞叶刀，绕目标和它身边扫一圈（溅射）。
- 差异化：
  - 体型档：孩童体（本组唯一）；和修女 nun 的娇小体型拉开：没有头巾，头本身就是 8 格宽的球茎。
  - 识别特征：①头顶两片嫩叶芽（改外轮廓，高出球茎 4 格）②杖头锯齿大叶刃（改外轮廓，伸出身前）③外翘的叶披肩叶尖（改外轮廓）④根须（内部）。
  - 武器 + 握法 + 攻击类型：单手 · 叶刃杖 · 近身施法横甩（巫师是远程甩杖弹，诅咒剑士是劈，野人祭司是双手抡杖喷雾）。
  - 待机个性：头顶两片嫩叶像螺旋桨转半圈再停住，脑袋晃一下（1.6–2.0 s）。
  - 步态：蹦跳——步幅 1，经过帧整个人离地 1–2 格、叶芽转成一字，落地帧球茎头压扁 1 格；很轻，不扬尘。
  - 死亡方式：枯萎——叶芽先蔫垂，从腰部折弯跪下，侧着倒下；叶片、茎依次变枯褐，杖弹开；自上而下消散，绿色魂光上升。
  - 主色：嫩黄绿叶 + 奶白洋葱头（同组的剑士苔锈铁、祭司苔泥绿褐、青龙翠青都不同）。

## 特效设定卡

- 元素：飞叶 · 嫩绿叶刃，色阶 nature = 21 白 → 38 淡黄绿 → 37 叶绿 → 36 深绿 → 35 墨绿；收招落叶用「枯叶」色阶 leafWither = 38 → #a6d45a → 62 → 61 → 20（绿慢慢变枯）。
- 攻击「飞叶刀」：
  - 预兆：杖甩到肩后 1–2 帧，叶脉亮 1 档，叶芽右甩。
