# 炮灰法师（CannonFodderMage）

## 角色设定卡

- 名称 / 身份：炮灰法师，自然族商人（部队，优质，远程抛射）。升级线第二级：野法师那株长胖了，整颗球茎就是身体，里面攒着秘晶。
- 一句话剪影：一颗紫红大洋葱（头身一体）+ 顶上 4 叶莲座叶冠 + 背上斜扛的干葫芦炮（炮口越过肩膀朝前上方）+ 腰间鼓鼓的钱袋。
- 尺寸：约 29 格高（含叶冠）、27 格宽（含背后葫芦底与钱袋）；球茎本体 18 格宽、18 行高。

  - 洋葱皮 skin = #2a0f24 #5e2352 #9a3f7e #d07aa8（紫红，band 2，面积最大）
  - 洋葱肉 flesh = #3a3020 #8c7d62 #d8ccae #f4efe0（裂开后的切面，一圈圈的环）
  - 叶冠 leaf = #13240c #2f5a1a #5f9a2c #a6d45a（沿用野法师的嫩黄绿）；腿臂 stem = green
  - 葫芦炮 gourd = sand；藤绳 vine = wood；钱袋 pouch = leather；眼 ink；腮红 pink
  - 秘晶裂缝光（发光体）crack = #2a0f24 · #7a3a8a · 63 · 21（flat，5 档）
- 部件顺序（从后往前）：葫芦炮 → 后臂 → 短腿 → 球茎身（脸、纵纹、3 条秘晶裂缝同一部件）→ 斜挎藤背带 + 叶结 → 叶冠 → 钱袋（藤绳 + 束口 + 露出的秘晶）→ 前臂 + 手。

  - 脸：1×2 眼 + 高光、眯眼（^ 形）、腮红、2 格小嘴；受击闭眼。

  - 躯干：洋葱纵纹 2 道 + 左上高光弧；3 条秘晶裂缝（胸口前下、左上、头顶），头顶那条技能时张开成 V 形缺口。
  - 手臂 / 腿：短茎臂从球茎两侧伸出，2×2 手；3 格粗的短腿赤足。
  - 背负物：干葫芦炮（下葫芦 → 细腰藤绑 → 上葫芦 → 细颈 → 炮口暗洞），沿轴线按半径表刷圆，任意仰角都是圆截面；斜挎藤背带。
