# 小螃蟹 Crabling

依据：衍生单位「小螃蟹」；描述「肉盾近战宠物。（小螃蟹）」；职业 先锋「该职业擅长防御。」；品质 普通；近战（range 240）；种族 自然；traits 为空；up 无。召唤者是巨蟹系（蟹术士 CrabWarlock 的技能「召唤小螃蟹」）。

## 角色设定卡

- 名称 / 身份：小螃蟹，巨蟹系召唤出来的肉盾近战宠物（自然 · 先锋 · 普通 · 衍生单位）。
- 一句话剪影：正面看的一只扁平沙黄小蟹——一块宽 16 格、只有 6 格高的圆壳贴着地，左右各举一只一样大的小螯，两根短眼柄顶着黑豆眼，8 条尖腿向两侧放射张开。
- 视角（补充）：蟹横着走，所以画成**正面**（左右对称）：朝假人冲撞 / 横窜就是往屏幕右边横移。同组的巨蟹钳、已通过的蟹术士都是侧视，靠视角和对称剪影直接拉开。
- 尺寸：约 13 格高（含眼柄）、壳宽 16 格、脚尖到脚尖约 36 格（后两条腿近乎平伸，放射状）。本组最小、最矮、最扁（普通品质）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 沙黄蟹壳 / 腿 / 螯（主材质，本模块专属色）[#2a1e08, #6a5020, #b08e40, #e0c47a]；远侧（后排）腿用同色阶暗一级。
  - 壳底 / 口器：bone 奶白 [8, 7, 6, 17]。
  - 壳背螺旋斑：leather 墨褐 [20, 19, 32, 33]。
  - 螯尖：fire 暗档橘红（#b8401a，平涂一格）。
  - 眼：ink 墨黑平涂 + 1 格白高光。
  - 泡泡：water 特效色阶（白 → 淡水青 → 水蓝 → 深蓝 → 墨蓝）。
- 部件顺序（从后往前）：后排腿（每侧第 3、4 条，暗一级）→ 前排腿（每侧第 1、2 条）→ 壳（壳顶 + 壳沿 + 壳底 + 口器 + 螺旋斑，一个部件）→ 远眼柄 → 近眼柄 → 左螯 → 右螯。缩壳（技能）时只画壳球一个部件。
- 细节清单：
  - 面部：两根眼柄 + 黑豆眼（带 1 格高光）；壳底正中两格口器（吐泡泡时张开）；闭眼 = 眼柄缩短、眼变成一横。
  - 壳：壳顶亮边、壳沿一圈高光、壳面 3 个暗斑、壳背一枚墨褐螺旋斑（技能里逐帧换位表示旋转）。
  - 肢体：8 条尖腿各有膝节（腿在膝盖处拱起），足尖是尖的；两只小螯 = 螯臂 + 钳掌 + 上下两指，指尖橘红。
- 攻击方式：近战冲撞。压低身子、螯收拢 → 横着飞快冲 11 格，用硬壳侧沿撞上假人 → 弹回。
- 差异化：
  - 体型档：小蟹档（正面扁宽）。本组最小最扁；和巨蟹钳（一只超大单螯、侧视）拉开：身体是主体，两只小螯对称。
  - 识别特征：①宽扁沙黄圆壳（改变轮廓：扁宽）②左右对称高举的两只小螯（伸出轮廓 3 格）③两根眼柄（伸出轮廓）④8 条放射张开的尖腿（改变轮廓：横向伸出）。
  - 武器 + 握法 + 攻击类型：一对小螯（徒手）× 冲撞（用壳撞）。蟹术士是举珊瑚杖射泡，巨蟹钳是巨钳夹，互不重复。
  - 待机个性：吐泡泡——嘴边冒出 2–3 个水泡往上飘、破掉，两只螯轮流举一下。
  - 步态：横窜急停——横着飞快窜 4 格，停 1 帧，再窜；8 条腿两组密集交替，每 2 帧扬 1 颗沙尘。
  - 死亡方式：钻沙——被打翻、四脚朝天挣扎翻身失败，翻回来后猛刨沙，身体陷进地面，只剩眼柄露在外面眨一下，然后缩进去，留下一小堆沙，沙堆再消散。
  - 主色：沙黄（本组没有别的角色用沙黄做主材质；蟹术士是珊瑚粉、巨蟹钳是珊瑚红）。

## 特效设定卡

- 元素色阶：泡沫 · 浅海白蓝，water 色阶 21 白 → 22 淡水青 → 41 水蓝 → 40 深蓝 → 39 墨蓝；以第 1–2 级泡沫白为主（和巨蟹钳的深水蓝区分）。沙尘用 earth 色阶（沙色）。
- 攻击「硬壳冲撞」：
  - 预兆：身子压低 1 格、往后缩 1 格，两只螯收到壳前（1 帧）。
  - 出手：横冲 11 格定格 1 帧，身后 3 道横向速度线（泡沫白 → 水蓝，2 帧），脚下扬 3 颗沙。
  - 命中：壳沿撞上假人：impact 外爆 8 颗 + 2 个小泡泡溅出，假人闪白 + 小摇。
  - 收回：弹回原位，螯重新举起。
- 移动：横窜急停，每 2 帧 1 颗沙尘（earth 色阶），不震屏。
- 技能「缩壳翻滚」（没有特性的肉盾宠物，表现它的招牌动作：缩进壳里当轮子滚过去撞人，并吐泡泡护身）：
  - 蓄力 1.4 s：螯和腿逐步缩进壳下（0.35 s 螯、0.6 s 腿），壳落地，原地打转并越转越快（壳背螺旋斑逐帧换位：先 3 帧换一次、最后每帧一次），身周冒出一圈白色小圆泡（K_EMBER，水色阶），轮廓光 2 档、地面隔点映光。
  - 施放 0.5 s：壳变成轮子横滚出 16 格冲向目标（4 个朝向逐帧换：横 → 斜 → 竖 → 斜），身后拖一串泡沫尾和沙尘；进入施放时蓄力泡外爆 + 冲击环 + 震屏 2 格 + 天空闪白。
  - 命中（施放 0.25 s）：壳弹起撞中目标，一圈泡泡外爆（fx.circle 小泡点阵 + 水色外爆 + 大冲击环）破成水花，假人闪白 + 大摇 + 击退 1 格，震屏 1 格。
  - 收招 0.7 s：壳弹回半空翻身落地，螯和腿「啪」地一下伸出来（落地扬沙），然后横窜回原位。
- 受击：enemy 色阶敌弹来袭 → 白色剪影 1 帧 + 击退 2 格 + 眼柄缩下（闭眼）+ 两只螯往外甩开；impact 火花 16 颗 + 震屏 1 格。
- 死亡：来袭命中（引擎：火花 + 震屏 2 格 + 闪白）→ 被掀翻（0.3–0.5 s）→ 四脚朝天落地（离地 3 → 1 → 0，0.66 s 落地：沙尘 12 颗 + 震屏 1 格）→ 腿乱蹬翻身失败 → 1.05 s 翻回来猛刨沙（沙粒往两侧飞）并逐渐陷进地面 → 只剩眼柄露在外面眨一下 → 眼柄缩进去，留下一小堆沙 → 沙堆自上而下消散 + 魂光上升。没有掉落物和发光体（普通小宠物）。
- 音色：小壳啪嗒啪嗒的密集碎步，加泡泡「啵啵」破裂声，最轻巧，重量 0.2。SFX：body beast · how collapse · pal water · style shield · w 0.2。
