# 角色设定卡

- 名称 / 身份：影骑士，影剑士修成的重甲骑士（部队，神话，召唤师）；巨剑能斩开「现实之织」，从裂缝里放出自己的强力分身。
- 一句话剪影：一对向后掠的尖耳狐首盔 + 竖起来比人还高的双手巨剑（中间一道空心紫白裂隙）+ 拖到身后地面的破披风；肩上蹲一只小狐影。
- 尺寸：待机 35×38 格（身体约 36 格，蓄力举剑时剑尖到 −56）；英武档 parts.rig `heroic`（leg 11、torso 11、head 7 / headW 7、sw 5 宽肩、arm 11），本组唯一的英武档。
- 材质色阶：
  - 夜甲（主材质）墨紫 [0, 52, 53, #52407a]（设定给的 #08050e / #1c1230 / #32224e 和共享色 0 / 52 / 53 几乎一样，直接用共享色，只新增亮级）
  - 破披风 / 罩袍布 墨黑 [0, 52, 8, 9]；狐首盔 white [7, 18, 17, 21] + gold 眉脊 / 腮线 / 耳内
  - 小狐影 shadow [0, 52, 53, 54]；剑身 [0, 52, 8, 9] 墨黑；缠柄 / 腰带 [0, 11, 12, 13] 暗酒红；护手、柄头、腰扣 gold
  - 发光体：剑中裂隙 / 盔眼 / 狐眼 [42, 43, #e4dbff, 21]（flat）
- 部件顺序（从后往前）：破披风（tattered，拖地再往后拖 6 格）→ 后臂（板甲、肩甲）→ 胫甲腿 → 板甲躯干（长甲裙到 −3、墨黑罩袍布、酒红腰带 + 金扣）→ 肩上小狐影（候选部件 shoulderFox）→ 狐首盔（候选部件 foxHelm：耳朵 → 盔）→ 裂织巨剑（候选部件 riftSword）→ 后手铁手套 → 前臂（板甲 + 尖肩甲 + 铁手套）。
- 细节清单：
  - 脸：全盔狐吻前伸 3 格、黑鼻尖、吻上高光；眼缝 2 格紫白光（闭眼 / 死亡熄灭）；眉脊金边、腮线金边
  - 头饰：一对尖耳向后掠（前耳白金 + 金耳内、后耳暗一级更往后倒），高出盔顶 5 格；后颈护甲外翻
  - 躯干：板甲胸腹分界、甲片分段长甲裙 + 中缝 + 铆钉、护颈、中间墨黑罩袍布、酒红腰带 + 金扣
  - 手臂：板甲臂 + 肘甲高光、尖肩甲、铁手套（双手叠在剑柄上）
  - 腿：胫甲（膝甲外凸），甲裙只露出下半截，步子很小
  - 武器：宽十字金护手 7 格、酒红缠柄 3 格、金柄头、3 格宽墨黑剑身（左沿刃光、右沿暗）、中列空心裂隙
  - 披风：破边缺口、会摆的后下角、沿地面再拖 6 格并碎成锯齿
  - 发光体：裂隙 5 档（待机暗紫隔格亮 / 蓄力 / 蓄满逐格闪 / 施放整把剑发光 / 熄灭）
- 攻击方式：近战「劈」：双手举剑过顶（预兆 2 帧）→ 前压 3 格竖直劈下（出手定格、斩光弧半径 22）→ 劈到底 → 回到拄剑。
- 差异化（对照同组 / 已通过角色）：
  - 体型档：英武档（宽肩长腿、上身厚重），除魔王近卫外最高；和 SlaveLord 拉开：没有牛角桶盔和斧，是狐首盔 + 巨剑 + 拖地披风。
  - 识别特征：①后掠尖耳狐首盔 + 前伸狐吻（改变外轮廓）②竖起高过盔顶的双手巨剑（改变外轮廓）③拖到身后地面的破披风（改变外轮廓）④肩上小狐影（在头后露出一截）。
  - 武器 + 握法 + 攻击类型：双手巨剑 · 劈（竖劈）；和影剑士的单手反握 · 扫拉开。
  - 待机个性：巨剑拄地、双手交叠按在剑柄上，披风下摆慢慢翻卷；循环里肩上小狐影回头、甩尾，剑中裂隙一闪。
  - 步态：滑行——步子很小、身体不起伏，披风拖地，脚下影子向前铺开，身后扬起暗影。
  - 死亡：碎裂——单膝跪地拄剑 → 身上从胸口放射出紫白裂纹（两档）→ 像镜子一样碎成块（死亡套件 chunks）→ 巨剑竖插在地上，裂隙一闪后熄灭 → 消散。
  - 主色：墨紫夜甲 + 白金狐盔 + 墨黑披风 + 紫白裂隙光。
- 与升级前（影剑士）的呼应：狐面具长成狐首盔（同样的尖耳、狐吻、发光眼缝），破围巾长成破披风（同样的碎锯齿边），弯刀长成巨剑；体量从瘦高档升到英武档，特效从墨青影子升到紫白裂隙。

# 特效设定卡

- 元素色阶：裂织 · 紫白裂隙 riftweave = 21 白 → #e4dbff 淡紫白 → 43 紫 → 42 深紫 → 52 墨紫（和影剑士的墨青刃光拉开）。
- 攻击：预兆 = 举剑过顶、裂隙 1 档；出手 = 前压 3 格、整把剑发光（3 档）+ 斩光弧（半径 22，从头后劈到身前下方）；命中 = 十字星芒 + 紫白外爆 14 颗 + impact 8 颗，目标大摇，震屏 1 格。
- 技能「憎恨繁殖者」：
  - 蓄力 1.4 s：巨剑从拄地抡起到竖直高举（剑尖高出盔顶约 20 格），裂隙 1 → 2 档逐帧闪；紫白光点向剑身中段螺旋汇聚；0.5 / 0.8 / 1.1 s 各有两道紫白折线细裂纹从四周空气向剑刃汇聚；轮廓光 2 → 3 档，盔眼亮，小狐影回头。
  - 施放 0.5 s：竖劈落下（斩光弧 + 身前一道 26 格高的白光竖线），天空闪白、震屏 2 格；竖线留成裂缝，0.12 s 起向两侧撕开成菱形空洞（最宽 6 格，里面墨黑，外沿紫白），裂缝周围不停冒紫白烟。
  - 命中（施放 0.3 s）：1:1 的影骑士剪影（墨紫填色 + 紫白外沿、眼缝亮白）从裂隙里踏出、面朝敌人（在裂缝左沿以左的部分还藏在裂缝里）；紫白碎片外爆 30 颗 + 大冲击环 + 十字星芒，目标大摇，震屏 1 格。
  - 收招 0.7 s：裂缝从上下两端合拢消失，巨剑回到拄地；分身留到约 1 s 后抖动淡出。
- 受击：金属甲——impact 火花 20 颗 + 3 颗长寿命白金火星 + 紫白碎光 6 颗；白色剪影 1 帧 + 击退 2 格 + 盔眼熄灭 + 披风甩动、小狐影回头。
- 死亡：来袭命中（26 颗火花 + 震屏 2 格 + 闪白）→ 踉跄 → 单膝跪地、巨剑插在身前（落地尘土 12 颗 + 震屏 1 格）→ 胸口放射紫白裂纹两档 → 碎成 4 格小块炸开（紫白外爆 24 颗 + 十字星芒 + 震屏 2 格 + 闪白），碎块落地成堆后消散 → 插在地上的巨剑裂隙一闪（十字星芒）后熄灭 → 自上而下消散，紫白光点与魂光上升。
