# 充能塔 ChargeTower

模块：`pcd/chars/ChargeTower.js`。身体不用现成骨架（固定塔）：盘根须、年轮树干塔身、铜边投币口、铜铃、六角充能晶、爪枝都是本模块自画的部件（函数前标了「// 候选部件」），画笔只用引擎的 `part / sp`，外加一个本模块的落笔变换 `S()`（原位前倾 / 斜切后倒 / 转 90° 躺倒）。
升级线：充能塔 → 火神塔。本级是「一截老树干 + 盘根 + 投币口 + 琥珀晶」，火神塔保留盘根、投币口和琥珀晶（嵌到火神面具额心），把树干包成火山岩石堡。

## 角色设定卡

- 名称 / 身份：充能塔，自然族的商人塔：一截中空老树干，靠攒电赚钱；不会走（「无法移动」），射程很远，放电打远处的敌人。
- 一句话剪影：**塔顶四根弯树枝像爪子托着一颗六角琥珀晶 + 底部一圈向两侧伸开的盘根 + 右侧铜边投币口和挂着的小铜铃**。树干上窄下宽，稳得像树桩。
- 尺寸：待机约 25×34 格（树干 13 格宽，盘根跨 20 格，晶顶 -31 行）。稀有品质。
- 材质色阶（色板下标 / 本角色追加色）：
  - 老树皮 [#1a0e06, #3e2410, #6a4220, #9a6a3a]（塔身 band 2；爪枝、铃枝 band 1）
  - 盘根深褐 [#1a0e06, #3e2410, 20, 19]，远侧暗一级 [#1a0e06, #3e2410, #3e2410, 20]
  - 琥珀晶 [#3a1a02, #a05a0a, #f0a020, #ffe08a]（flat，按档位直接写色调）；白热 [#3a1a02, #ffe08a, 21, 21]；发光刻线同琥珀色阶
  - 铜边投币口 [20, 19, 32, 14]（gold 暗档）· 铜铃 `gold` · 窗洞 / 投币缝 `ink`
- 部件顺序（从后往前）：远侧盘根 ×2 → 树干塔身（同一部件里画树洞口、竖向树皮纹、6 圈年轮刻线、两扇窗、死亡裂纹）→ 近侧盘根 ×3 → 投币口 → 铃枝 → 铜铃 → 后爪枝 ×2 → 六角晶 → 前爪枝 ×2。
- 细节清单：
  - 「脸」：树干中段两扇 2×2 小窗（窗楣亮一格），像一双眼：待机暗、左下一格琥珀光；充能时整窗发亮；受击时闭窗（上半格被树皮盖住）。
  - 纹理：竖向树皮纹（暗一级断续短线）；年轮刻线两端上翘 1 格，像圆柱上的一圈；树顶断口毛边 + 中空树洞口。
  - 配件：铜边投币口（4×4 铜框、横缝、下沿暗一级）；小铜铃挂在一根伸出塔身的小枝上，铃身和铃舌反向摆。
  - 武器 / 发光体：六角琥珀晶 8 格高、左中右三个棱面 + 尖 + 左上高光，5 档（待机 / 蓄力 / 蓄满 / 施放白热 / 熄灭）。
- 攻击方式：远程施法（固定放电）：晶体充能 → 一闪 → 折线琥珀电弧直接打到远处目标。
- 差异化：
  - 体型档：塔档（固定建筑，没有腿，用根须代替步态）；同组其他角色都是人形 / 四足 / 爬行，只有它和火神塔是塔；和已有的玉藤堡垒（方塔 + 雉堞 + 两条根腿）拉开：瘦高锥形树干、顶上是晶体爪冠，没有雉堞和藤臂。
  - 识别特征：①塔顶爪枝托琥珀晶（改外轮廓）②盘根向两侧伸开 20 格（改外轮廓）③右侧投币口 + 铜铃（改外轮廓，同时读出「商人」）④年轮发光刻线（内部）。
  - 武器 + 握法 + 攻击类型：发光体本身、无握法、施法放电（电弧）；同组没有电弧类攻击。
  - 待机个性：充能脉动（刻线从下往上一圈圈亮到晶体，晶体闪一下）；步态：根须挪移（盘根一左一右蠕动、塔身前倾后仰）；死亡：倾倒（从中间断开，上半截向后倒下摔断）。
  - 主色：老树皮暖褐 + 琥珀金；同组主色没有褐木 + 琥珀的组合。
- 音色：中空木头的「咚」回响，加电弧噼啪和铜铃叮当，重量 0.6。`SFX: { body: 'stone', how: 'topple', pal: 'coin', style: 'coin', w: 0.6 }`；step 在盘根落地帧（crouch 帧），swing(staff) + hit(magic) 在放电帧，impact(coin) 在第一枚币落地，fall 在上半截落地。

## 特效设定卡

- 元素：充能 · 琥珀金，`coin` 色阶 21 白 → 5 淡金 → 14 金 → 61 暗金 → 20 棕；电弧芯就是色阶第 1 级的白。
- 攻击「放电」：预兆 1 帧（晶体 1 档、刻线亮 3 圈、塔身后仰 1 格、窗亮）→ 出手帧（晶体白热 3 档 + 闪光、刻线全亮、前倾，`fx.bolt` 折线电弧 0.25 s 打到假人，晶体十字星芒）→ 下一帧再一道短电弧噼啪 → 命中：金色外爆 12 颗 + 几颗 bolt 白蓝火花，假人闪白小摇；延续帧刻线每帧暗两圈。
- 技能「美味 · 存钱罐塔」：
  - 蓄力 1.4 s：金币粒子定点螺旋吸进投币口（`K_SPIRAL_PT`）；年轮刻线每 0.2 s 从下往上亮一圈，像进度条；晶体 1/2 档逐帧闪；窗亮；塔身下沉 1 格；最后 0.5 s 铜铃左右摇；轮廓光 2 档、地面隔点映光。
  - 施放 0.5 s：「叮」——晶体白热、星芒 6 格、冲击环、20 颗金色外爆；塔顶喷出 12 枚琥珀币（5 枚落向身后、7 枚落向身前，抛物线、边飞边翻面）；震屏 2 格、天空闪白。
  - 命中：金币落在塔周地面上弹一下再平躺，每枚落地溅起金色「+」小闪光和 3 颗火花；第一枚落地时塔脚下一圈大冲击环 + 地面映光一圈（0.45 s）+ 震屏 1 格。
  - 收招 0.7 s：刻线从上往下每帧暗一圈，晶体 2 → 1 → 0，铜铃余摆，晶体上飘几颗琥珀光点；地上的币闪一下后抖动消散。
- 受击：白色剪影 1 帧 + 击退 2 格 + 后仰；闭窗、晶体熄一下、铜铃反向甩；火花 impact + 木屑 earth + 两三颗琥珀光点，震屏 1 格。
- 死亡「倾倒」：受击闪白 → 断口裂纹从中间横向裂开、塔身下沉 1 格 → 上半截向后斜切倾倒两帧（木屑崩出）→ 转 90° 躺在树桩左边，两帧下落（离地 3 → 1 → 0）→ 落地扬尘 16 颗 + 散出 7 枚铜币 + 震屏 → 晶体从断枝里滚开、闪三下熄灭 → 自上而下消散，金色光点上升。树桩和盘根留在原地。
