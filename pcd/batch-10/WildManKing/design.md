# 野人王 WildManKing

模块：`pcd/chars/WildManKing.js`（身体用部件库拼：`rig(fat) arm(bare) legs(bare) torso(bare) mantle(fur) hand`；模块里自画的候选部件：王冠面具 `crownMask`（下颌能张开）、掌状鹿角 `palmAntlers`（4 叉 + 金藤）、红羽 `feathers`、拖地兽皮斗篷 `hideCape`、草裙 + 骨串 `grassSkirt`、骨棒权杖 `boneScepter`、坐地的腿 `sitLegs`；召唤的矛兵剪影是模块里单独烤的小精灵）。
升级线：和野人祭司是**同一个野人**——同样的苔泥绿褐皮肤、鹿颅骨面具（放大一圈，鹿角从 2 叉长到 4 叉、缠金藤、插红羽）、草裙；进化后变胖、披上虎斑兽皮大斗篷、骨杖换成顶着小矛兵头骨的骨棒权杖，特效从一个召唤物变成两个。

## 角色设定卡

- 名称 / 身份：野人王，沼泽野人部落的胖酋长（稀有品质：金藤王冠、红羽、会亮的头骨眼窝）。
- 一句话剪影：**宽大的掌状鹿角王冠 + 从肩一路拖到地的三角大斗篷 + 右手竖起的骷髅骨棒**；剪影是一个宽大的三角堆，一眼读成「部落王」。
- 尺寸：待机 38×35 格（颅顶约 −24，鹿角到 −32，斗篷后下角拖到身后 12 格）；体型 `fat`（leg 6 · torso 10 · head 7 · headW 7 · sw 5 · belly 3 · arm 9），大肚子、粗短腿。
- 材质色阶：
  - 斗篷 虎斑兽皮 [#2a1606, #6a3a14, #b0702c, #e0aa5a]（band 2，每 4 行一道墨褐断续横纹）；领口蓬毛同色（band 1，`mantle fur`）

  - 面具 / 鹿角 / 权杖 `bone`；金藤 `gold`；红羽 `crimson`；草裙 `sand`；骨串 `white`
  - 发光体：权杖头骨眼窝、王冠金藤、面具眼洞 泥金 flat [20, 61, 62, 5] → 蓄满 [61, 62, 5, 21]（`GLOW_MATS`）

- 细节清单：
  - 脸（面具）：7 格圆颅 + 11 格长吻、2 格眼洞（蓄力时发金光）、眉骨高光、鼻孔、齿列、额前一道金藤箍（蓄力时一节节亮起）；打哈欠时下颌掉 1 格、露出黑口。
  - 头饰：每边一根掌状主干 + 3 根竖叉 + 主干尖（共 4 叉），后支暗一级，主干上各 4 节金藤；角根后垂两根红羽，尖端随 beard 摆。
  - 毛 / 披挂：领口一圈蓬毛（竖毛束 + 锯齿下摆）；斗篷两道褶 + 虎斑横纹，后下角拖地外翘。
  - 躯干：赤膊大肚（胸下沿、肚脐、赘肉褶）+ 肚子上的锯齿白泥纹 + 胸口白泥点；草裙 + 腰间一串白骨片。
  - 手臂：赤臂，3×3 大手；后手搭在肚子上（待机拍肚子）。
  - 武器：骨棒权杖（2 格粗腿骨 + 骨节柄头 + 3 节金藤缠柄 + 顶端小野人头骨：两只小角、发光眼窝、齿缝、闪光）。
- 攻击方式：砸（单手）：权杖举过头顶 → 前冲 3 格往下砸，头骨走过的弧留 2 帧拖影，砸点土金外爆 + 星芒 + 尘。
- 差异化：
  - 体型档：肥胖（本组唯一）；屠夫领主是桶腹 + 剁骨刀 + 小礼帽，野人王是大肚 + 拖地斗篷 + 宽鹿角，剪影是宽三角堆不是桶；地主也胖但是袍子 + 算盘、远程。

  - 特效：泥土金，砸地双裂缝 + 两个泥丘 + 两个蹦出来的矛兵剪影；祭司是一根泥柱 + 一个慢慢浮出的剪影，同一条升级线但形态拉开。
