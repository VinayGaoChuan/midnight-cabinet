# 诅咒剑士（CursedSwordsman）

## 角色设定卡

- 名称 / 身份：诅咒剑士，自然族守护者（部队，优质，近战）。一个被诅咒之剑缠上的老兵，升级线的第一级。
- 一句话剪影：背后斜插 3 柄锈剑张成扇形（剑柄高出肩 5 格）+ 平顶桶盔（盔顶一撮苔藓）+ 身前一面上宽下尖的鸢形盾。
- 尺寸：待机外框约 29×28 格（身体约 24 格高，剑扇把后背撑出 11 格）；地面线统一在脚底。
- 体型档：矮壮重甲（parts.rig stocky，head 7：头身比约 4、方肩短腿、belly 1），本组唯一的矮壮档。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 苔锈铁甲 armor / arm = [#111512, #2f3530, #56605a, #8a948a]（躯干 band 2，盔 / 臂 / 腿 band 1）+ moss 苔斑
  - 诅咒布条（胸前罩布）cloth = [#140a1c, #34204a, #5a3a78, #8c6ab0]
  - 盾框 / 盔箍 / 靴 iron；鸢形盾面 = arm + moss 苔斑
  - 阔剑 steel 刃 + leather 锈色刃口 + iron 护手 + wood 握把；背后剑扇同款（锈色刃口）
  - 剑身诅咒纹 / 盾面裂纹（发光体）rune = [25, 42, 24, 43] flat；盔缝独眼 eye = [25, 42, 24, 43] flat，蓄力 eyeHot = [24, 43, 43, 21] flat
- 部件顺序（从后往前）：背后剑扇 3 柄（每柄一个部件）→ 后臂（远侧，肩甲）→ 腿（胫甲）→ 躯干（板甲 + 诅咒罩布 + 苔斑，同一部件）→ 桶盔 → 盔顶苔藓 →（蓄力时）头顶悬剑 → 鸢形盾（远侧手挎着，护在身前）→ 阔剑 → 前臂（近侧，肩甲 + 铁手套）。
- 细节清单：
  - 脸：桶盔横缝 + 1 格紫色独眼（受击 / 死亡熄灭，蓄力变亮），T 形面饰，盔箍。
  - 毛发对应物：盔顶一撮苔藓，尖端随 beard 摆。
  - 躯干：板甲胸腹分界、甲裙分段 + 铆钉、护颈；胸前墨紫诅咒罩布垂到甲裙下；5 处苔斑；铁腰带 + 锈扣。
  - 手臂：板甲臂 + 圆肩甲 + 3×3 铁手套。
  - 腿脚：胫甲（膝甲外凸）+ 铁靴，前脚多 1 格。
  - 武器：阔剑（柄头、握把、5 格护手、3 格宽刃 + 血槽 + 锈色刃口高光、紫色诅咒纹 5 档）；鸢形盾（高 11、宽 7，铁框 + 铆钉、苔斑、紫色裂纹按发光档亮、盾面冷光）。
  - 背后剑扇：3 柄长剑按 2:1 / 45° / 1:2 吸附插进后背，护手 + 握把 + 柄头露在肩后。
- 攻击方式：近战 · 劈（右手单手阔剑，盾护身、过肩斜劈，前冲 4 格）。
- 差异化：
  - 体型档：矮壮（同组唯一）；和 cremator 的矮壮拉开——不是方箱面罩配火铲，而是桶盔持盾剑士、背后插剑。
  - 轮廓特征：背后剑扇（改外轮廓，全线标志）、鸢形盾（改外轮廓）、盔顶苔藓；桶盔横缝紫眼全线共有。
  - 武器 + 握法 + 攻击：单手阔剑 + 远侧手挎盾 × 劈；和维京战士（盾撞）、奴隶主（大斧劈，双手）、守夜人（戟刺）不同。
  - 待机个性：盾底拄地喘气（盾下沉 1 格），背后三柄剑依次轻颤一下，刃尖冒一点紫光。
  - 步态：行军——步子短而整齐，每步盾轻磕身体（盾回收 1 格），落地 2 颗尘。
  - 死亡方式：跪倒——单膝跪下、阔剑插地拄住身体，背后的剑一柄柄滑落斜插在身后地上，最后桶盔低垂、紫眼熄灭，然后消散。
  - 主色：苔锈绿灰铁（和 Brute 的锈红褐、cremator 的炭灰、维京的靛蓝拉开）。

## 特效设定卡

- 元素：铁雹 · 锈钢寒灰，色阶 steel = 21 白 → 31 淡钢 → 30 钢灰 → 29 铁 → 28 墨（共享 FX.steel）；命中后的削弱印记用 curse 第 2–3 级紫（假人暗紫描边），和 Brute 的诅咒灰紫主色拉开。
- 攻击「诅咒劈」：
  - 预兆：盾护在身前，阔剑举过肩（剑身紫纹亮 1 档），身体后缩 1 格。
  - 出手：前冲 4 格斜劈到前下方，定格 1 帧；钢色斩击弧（fx.slash，2 帧）。
  - 命中：impact 火花 12 颗 + 钢色十字星芒，假人闪白小摇。
- 技能「铁之冰雹」（法力满后，诅咒之剑对目标小范围砸两轮并削弱敌人伤害）：
  - 蓄力 1.4 s：背后 3 柄剑依次拔出（0.25 / 0.45 / 0.65 s，每拔一柄冒钢屑 + 紫色小星芒）、浮到头顶剑尖朝天，上下浮动；剑身紫纹 1→2 档闪，盔缝独眼变亮；钢屑（夹少量紫）螺旋汇聚到悬剑；轮廓光 2 档、地面隔点映光。

  - 命中：两轮铁剑冰雹竖直坠落（每轮 6 柄 1×4 剑 + 3 格护手，第 2 轮晚 0.2 s），插在目标周围一小圈，每柄落点火星 + 尘土 + 小星芒；每轮第一柄落地时冲击环 + 钢屑外爆 + 假人大摇 + 震屏 1 格；假人 dummyFx curse 暗紫描边 + slow 0.45（削弱伤害）。
  - 收招 0.7 s：地上的剑抖动化灰（冒灰尘上升），背后剑扇一柄柄重新长回来，紫纹 2→1→0。

- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 踉跄下蹲 → 单膝跪地、阔剑插地（尘土 12 颗 + fall）→ 背后三柄剑依次滑落、斜插在身后地上（每柄一声金属轻响 + 火星）→ 紫纹闪烁熄灭、桶盔低垂、紫眼熄灭 → 自上而下消散 + 魂光上升。
