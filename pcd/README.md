# pcd：像素人物重做

按技能「像素人物设计」（`~/.claude/skills/pixel-character-design`）重做游戏里全部角色和敌人。每个角色都按资料里的文字设定重新设计，不参考现有精灵。每个角色要有六个状态：待机、移动、攻击、技能（蓄力 / 施放 / 收招）、受击、死亡，并配上对应的技能特效。

## 目录

| 路径 | 内容 |
|---|---|
| `roster.json` | 全部 215 个角色的文字资料（名字、种族、职业、品质、描述、技能原文、升级关系、远近程），由 `src/mc-db.js`、`src/mc-data2.js`、`src/mc-pskill.js` 导出 |
| `batch-XX-*/<key>/` | 一个角色的全部产出：`<key>.html`（可直接打开的角色页，按 T 看动作表）、`design.md`（设定卡、依据、修改记录）、`shots/`（制作者自检）、`review-N/`（第 N 轮验收的独立复检截图与报告） |
| `accepted/<key>/sprite-lite.json` | 已通过验收的角色，供后续批次查重 |

## 流程

1. **分配**：一个代理读全批资料，给每个角色分配体型、识别特征、武器握法、攻击类型、待机个性、步态、死亡方式、主色、技能特效组合，保证同批互不重复。
2. **制作**：每个角色一个代理，按技能从模板制作，跑自检（`shoot.mjs` 自动验收 + `compare.mjs` 查重）。
3. **验收**：另一个代理独立重跑自检，看截图，按 12 个维度打分并列出阻断问题。
4. **打回**：不通过就带着阻断问题重做，最多 3 轮；3 轮还不过的角色单独列出，交给人工处理。
5. **整批查重 + 画廊**：整批两两查重，生成动作表画廊页供人工抽查。
6. **替换进游戏**：全部通过后，把角色的第 3、4 节代码接进游戏引擎（见技能 `references/standard.md` 第 11 节的模块契约），逐批替换，每批跑回归机器人。

这个目录不在 git 里时，一次 `git clean` 就会把它删掉，建议尽早提交。
