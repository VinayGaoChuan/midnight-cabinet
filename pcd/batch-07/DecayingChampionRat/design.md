依据：腐烂鼠王（敌人 · 混沌 · 稀有 · 近战 272）描述原文「高伤害单位。以群集作战著称。」；没有特性、没有升级（up 为空）。和腐尸鼠同族：同一种破甲虫壳在它背上长成了带刺的甲壳鞍，也同样烂出肋骨；名字里的「鼠王」画成背上的鼠群和尾结。

# 角色设定卡：腐烂鼠王 DecayingChampionRat

- 身份：混沌敌人，稀有品质的鼠王。「高伤害」＝一张大嘴和前扑咬合；「以群集作战」＝它从不单独出现，背上永远驮着一窝小腐鼠，打起来小鼠也一起上。
- 一句话剪影：一只比腐尸鼠大一倍、肩峰高耸的腐鼠，背上扣着一座沙色圆顶甲壳鞍（腐尸鼠那块破壳长大了，两端长出 5 根三角尖刺），鞍顶蹲着 3 只 5×4 的小腐鼠，三颗脑袋在剪影里分得开；颅顶戴一顶骨冠（骨箍 + 5 根朝上的尖骨）；身后垂着一个和小鼠尾巴缠在一起的肉色尾结。
- 尺寸：待机约 24 格高、46 格长（含尾结和拖地的尾梢），身体本身约 34 格长。大体量腐鼠王档：胸半径 5.5、臀 5、肩峰 2、胸底离地 5，头放大到 8·6.5·4。
- 骨架：`parts-beast` 的 `B.quad`（rat 头放大、hump 2、脚 claw）；刺甲鞍、鞍上小鼠、骨冠、尾结、肋骨洞、霉斑自己画（都标了「候选部件」）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 腐绿灰皮 `[0, 34, 7, 6]`（橄榄灰基色、墨绿暗部，比腐尸鼠的苍灰皮深一级、偏绿；暗部用 34 而不是苔绿 35，腿边不会描出一圈绿线）；霉斑 moss，只点 4 块
  - 刺甲鞍 `[0, 20, 61, 62]`（sand 暗段 61 作基色、62 受光边、band 2）+ 壳顶高光 `[0, 61, 62, 5]`（5 号亮点）；刺和壳同一个部件同一材质，刺尖 `[0, 61, 5, 6]` 骨白；裂缝用墨色
  - 骨冠 bone（骨箍下排两个 ink 眼窝）；肋骨 bone；洞里 ink；洞边烂肉 `[11, 55, 12, 13]`
  - 小鼠 `[8, 59, 60, 17]`（pale 色阶），墨色眼，耳朵和鼻尖 pink 63；小鼠尾巴和尾结 `[11, 12, 16, 15]`（发炎的粉褐秃尾）
  - 眼 curse 紫 43（平涂、发光体，蓄力 / 攻击时口里也发光）
- 部件顺序（从后往前）：远侧两条腿 → 尾结（主尾 + 两根小鼠尾 + 结 + 三根拖地尾梢）→ 躯干 + 颈（+ 霉斑）→ 肋骨洞 → 近侧两条腿 → 头 → 刺甲鞍 → 鞍上 3 只小鼠（按座面截掉下半身）→ 骨冠
- 细节清单：
  - 面部：诅咒紫眼、眉骨高光、黑鼻头、圆耳、大门牙（张嘴露两颗）
  - 皮：橄榄灰皮 + 暗绿霉斑；侧腹烂洞露出 3 根肋骨（腹线缺口）
  - 鞍：23 格宽、8 格高的沙色圆顶（顶面较平，好让小鼠蹲），壳沿两端外翻；5 根单尖三角刺（根部 3 格宽、3–4 格长、尖端 1 格骨白；鞍尾 3 根往后上 / 往后 / 往后下，鞍头 2 根往前上 / 往前），没有分叉；两道从壳顶斜着裂下来的旧裂缝（和腐尸鼠破壳上的两道一样，顶上崩一格），落在小鼠之间的空档里
  - 小鼠：每只 5×4 格——平直的苍白背、1 格竖起的粉耳、1 格墨色眼、2 格长吻朝外（粉鼻尖）、后腿和前爪之间空一格，2 格粉褐尾巴垂在壳上；后面两只朝后、前面那只朝前；两两之间空 3 列；探头 0 缩进壳 / 1 露耳和头顶 / 2 整只蹲着 / 3 站起露脚
  - 骨冠：戴在颅顶、压在诅咒紫眼睛的上方偏后脑：9 格宽 2 格厚的骨箍（下排两个墨色眼窝，像一只鼠头骨）+ 5 根朝上的尖骨（高 3 / 3 / 4 / 3 / 3、中间最高，根挨着根往上略外张，尖和尖之间空 2 列）
  - 尾结：长秃尾从臀后斜垂下来，和两只小鼠的细尾缠成一个疙瘩——三个互相套住的圈，交叉处压 1 格暗线；结下三根尾梢分开拖到地上（往后 9 格、往后 5 格、往前 1 格），梢尖亮一格
- 攻击方式：近战咬。压低、张嘴（预兆 2 帧）→ 前扑 7 格、嘴张到最大定格 → 一合（咬合）→ 退回；最前面那只小鼠同时从鞍上跳出去，扑到目标头上补咬一口，再摔下来跑回鞍上。
- 差异化（与同族 / 同体型的对比）：
  - 体型档：大体量腐鼠王（肩峰高、前重、身长），比腐尸鼠大一倍；同组四足里混沌鼠贴地瘦长、豪猪是球、刻耳柏洛斯是三头巨犬。
  - 识别特征：①圆顶刺甲鞍 + 鞍顶 3 只小鼠（外轮廓：圆顶上三颗分开的小鼠头，两端伸出三角尖刺）②颅顶骨冠（外轮廓：头上一排朝上的尖骨）③尾结（外轮廓：身后一团疙瘩 + 三根拖地尾梢）④侧腹肋骨洞。
  - 武器 + 握法 + 攻击类型：巨门牙 + 背上的鼠群 × 咬。同组咬的还有蛛母、熊首蛞蝓、甲壳狗，都没有「背上的帮手一起扑」这一下。
  - 待机个性：背上的小鼠钻来钻去（三只错相位地探头、缩头），隔一会儿鼠王低头嗅地，两只小鼠站起来张望。
  - 步态：身体压低、前冲式小跑，经过帧前低；背上小鼠跟着颠、轮流站起来；落脚扬尘较重。
  - 死亡方式：背上的小鼠站起来、跳下去四散逃走（两只往后、一只往前）→ 鼠王瘫软趴倒 → 骨冠从头上滚开、侧躺在地上 → 消散。
  - 主色：橄榄灰皮 + 暗黄刺甲 + 苍白小鼠 + 诅咒紫眼；和腐尸鼠（苍灰 + 沙黄）同族但深一级。

# 特效设定卡

- 元素色阶：鼠潮 · 诅咒紫 `FXI.curse` = 43 淡紫 → 24 紫 → 42 暗紫 → 25 深紫 → 52 墨紫。咬合火花 impact，小鼠补咬 blood。
- 攻击「群咬」：
  - 预兆：压低、张嘴 2 帧，前面那只小鼠站起来
  - 出手：前扑 7 格定格，口里发光；上下两排牙印弧拖影 2 帧（第 1 帧最亮、第 2 帧断续）
  - 命中：impact 外爆 10 颗 + 诅咒 6 颗，目标小摇；0.25 s 小鼠扑上目标头部补咬一口（blood 火花 + 小摇），0.5 s 摔下来跑回鞍上
- 技能「鼠潮」（没有特性，按「以群集作战」设计）：
  - 蓄力 1.4 s：仰头尖叫（前身抬起 3 格、嘴张到最大、一抖一抖），诅咒微光螺旋汇聚到眼睛；脚下前方开出紫色 `fx.circle` 鼠洞法阵，0.25 s 起每 0.18 s 从法阵里钻出一只诅咒小鼠（共 5 只，冒出时小外爆），跑到鼠王脚边每隔 7 格排好；背上三只小鼠全站起来；轮廓光 1 → 2 档
  - 屏幕上的小鼠（蓄力、地浪、爬满目标）一律是鼠形：4×2 身子（curse 第 2 级 24，屁股暗一格第 3 级 42）、1 格吻、1 格耳、43 小眼、2 格尾（42）、脚一帧一换，外圈墨色描边；攻击扑咬和死亡逃散的小鼠同形、用苍白色阶
  - 施放 0.5 s：一低头把鼠群推出去——紫色 `fx.wave` 贴地地浪涌向目标，集合好的小鼠加上新冒出来的 2 只沿地浪同速狂奔（保持间距、不叠成一团）；施放外爆 + 震屏 2 格 + 天空闪白
  - 命中（施放第 3 帧）：6 只诅咒小鼠分两列三层爬满目标、在假人身上乱动 1.3 s；诅咒外爆 28 颗 + 大冲击环 + 十字星芒；目标大摇、整个染成诅咒紫（`dummyFx tint curse`）；震屏 1 格
  - 收招 0.7 s：鼠王低头回位，眼光 2 → 1，轮廓光熄灭
- 受击：默认 impact 火花 + 白色剪影 1 帧 + 击退 2 格；闭眼、耳朵贴后，背上小鼠吓得缩进鞍里再慢慢探出来
- 死亡：挨打（小鼠全缩回去）→ 小鼠站起来跳下鞍四散逃走（画在屏幕上，逃远后闪烁消失）→ 鼠王瘫软趴倒（离地 3 → 1 → 0，扬尘 + 震屏，`fall`）→ 骨冠弹起滚开、歪着立在地上（小扬尘）→ 1.6 s 起自上而下消散，魂光混着诅咒紫上升
- 音色：成群吱吱叫的声浪 + 骨冠的叮当声；标志音是鼠群涌动时沙沙的潮声；重量 0.7。
  - SFX 声明：`{ body: 'beast', how: 'collapse', pal: 'curse', style: 'summon', w: 0.7 }`
  - 关键帧：移动接触帧 `step`（w 0.6）；攻击出手帧 `swing`（kind bite）+ `hit`（mat flesh），小鼠补咬再一次 `hit`；技能鼠群爬满目标 `impact`（pal curse）；趴倒那一帧 `fall`（w 0.7）

# 第 1 轮修改记录

- 鞍上 3 只小鼠（待机 / 移动 / 攻击每一帧）：原来是三个淡紫三角 + 紫点，像雪堆。改成 5×4 的鼠：平直的苍白背、1 格竖起的粉耳、1 格墨色眼、2 格长吻朝外（粉鼻尖）、后腿和前爪分开，2 格尾巴垂在壳上；后两只朝后、前一只朝前；两两之间空 3 列，剪影行看得出三颗分开的头。待机探头表去掉了“全缩进去”，大部分帧整只可见。
- 刺甲鞍：原来是一块扁平的暗褐木板（20 占大头）+ 两端 Y 形叉角。改成腐尸鼠那种沙色圆顶（基色 61、受光边 62、壳顶 5 号高光、band 2），带两道从壳顶斜裂下来的旧裂缝；5 根刺全换成单尖三角刺（根 3 格、长 3–4 格、尖端骨白），鞍尾 3 根、鞍头 2 根，没有分叉。
- 骨冠：原来 5 根细长骨从脖子往前张开，像胡须 / 鬃毛，骨箍看不见。改成戴在颅顶、压在眼睛上方：9 格宽 2 格厚的骨箍（两个墨色眼窝）+ 5 根朝上的尖骨（2–4 格，中间最高，尖和尖之间空 2 列）；锚点改用眼睛位置，仰头、低头时跟着头走，不挡诅咒紫的眼。死亡时骨冠滚开后歪着立在地上。
