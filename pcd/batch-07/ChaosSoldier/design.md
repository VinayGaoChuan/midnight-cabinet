# 混沌士兵（ChaosSoldier）

## 角色设定卡

- 名称 / 身份：混沌士兵，被混沌改造过的步兵（敌人，史诗，近战）。描述只有「数量稀少但是十分强力」，所以形象走「一个人顶一队」：盔甲不是穿上去的，是从身体里长出来的骨质甲壳；右臂整条变异。
- 一句话剪影：左手挎一面甲虫背壳骨盾（盾面一只混沌紫眼，护在身前）+ 右边灰紫骨甲大臂在胸口高度握一柄竖起的锯齿骨刃胡子斧（斧柄在脸前方 x10，斧头高出盔顶）+ 骨甲盔额顶两根后弯上翘的长骨角、后脑一排骨刺；盔的面罩缝朝右，露出 2 格紫眼和暗紫方下巴。
- 尺寸：英武变异战士档，parts.rig heroic（leg 10 · torso 10 · head 7 · sw 5），待机外框约 27 宽 × 36 高（含竖起的斧），身体本身约 30 格高；右臂 13 格（heroic 默认 10，长 3 格；上臂 5.5 + 前臂 7.5，变异前臂更长）、4 格粗，肩点比常规前移 2 格，左臂是 2 格窄袖——身体微微不对称。
- 材质色阶（[勾线, 暗, 基, 亮]，全部取自共享色板）：
  - 骨白甲壳甲 carapace = bone [8, 7, 6, 17]，band 2（主材质，躯干）；小块骨甲（盔、角、刺、胫甲、斧的骨刃）bone band 1
  - 变异大臂和大骨肩甲 mutant = [8, 7, 18, 17]：偏冷的灰紫骨（暖灰暗段 → 灰紫 → 骨白），和奶白躯干一眼分开；分节缝露出皮肤色的紫灰皮肉
  - 皮肤 skin = [0, 53, 54, 60] 暗紫灰（shadow 亮段 → 苍灰）；远侧暗一级
  - 甲虫壳盾面 shell = sand [20, 61, 62, 5]，band 2（沙褐壳，和骨白身体拉开）；盾边、锯齿 bone
  - 盾面眼纹 curse = purple [25, 42, 24, 43] 平涂 + 墨色竖瞳；盔下眼睛 [0, 0, 43, 43] 平涂（混沌紫）
  - 斧：骨刃 bone、刃口 steel [27, 28, 29, 30]，铁柄 iron；刃光（发光体）[29, 30, 31, 21] 平涂
  - 缠布 blood [55, 56, 57, 58]
- 部件顺序（从后往前）：后臂（左，窄袖 + 骨护腕）→ 腿（骨胫甲 + 暗紫赤足）→ 躯干（骨甲板甲 + 背脊骨刺 + 胸前骨板缝，同一部件）→ 腰间缠布 → 头 → 骨甲盔（后脑骨刺；脸的露出部分和盔同一部件画，不被盔压出黑边）→ 骨角 → 甲虫骨盾（后手）→ 斧柄 → 斧头 → 变异上臂 → 大骨肩甲 → 变异前臂 → 爪手。
- 细节清单：
  - 脸：面罩缝朝右——眉骨一整行压在眼睛上方、前沿探出 1 格；眉骨下 2 格混沌紫发光眼 [0, 0, 43, 43]、两行紫灰脸、1 行暗紫方下巴（skin 35 / 36）。
  - 头饰：骨壳圆盖 + 颊甲 + 两根 back 后弯上翘骨角（size 7，角根在盔顶那一行）+ 后脑两根横着往后的骨刺。
  - 躯干：plate 板甲换成骨白甲壳（胸腹分界、甲片分段、铆钉）、背上两根往后上的骨刺、胸前两道弧形骨板缝；腰间血红缠布（腰带 + 前垂破布锯齿下摆 + 后腰结和布尾，会摆）。
  - 手臂：右臂两段 IK 灰紫骨甲大臂——上臂、前臂各自一个部件，每段中间一道露出紫灰皮肉的分节缝，前臂下沿一排暗段，肘尖一根外刺；大骨肩甲压在躯干前面，两根刺朝上伸出肩线 2 格；3×3 暗紫爪手 + 骨爪尖。待机时上臂往下、前臂斜着往前上抬到胸口，从躯干前沿伸出 4–5 格。左臂窄袖 + 骨护腕。
  - 腿脚：骨胫甲（膝甲外凸）、暗紫赤足，前后脚分开。
  - 武器：锯齿骨刃胡子斧（斧头约 7×10）——上半实心、刃口沿柄往下垂成长胡子（比上一版多垂 2 格以上），胡子和柄之间留空；刃口每 3 行多伸出 1 格 = 锯齿（齿间 2 格平刃）；待机时刃口整列用钢色阶最亮一级；铁柄 + 骨柄头 + 铁箍；刃口是发光体（5 档：钢 / 刃光 1–3 / 熄灭）。
  - 盾：甲虫背壳 11×13 椭圆、骨边一圈、鞘翅中缝、左右边缘每 2 行一颗锯齿、壳面高光、盾心混沌紫眼纹（外眶 → 亮眼白 → 墨色竖瞳）。
- 攻击方式：近战「劈」——盾顶在前，右臂把斧从脑后举起，出手帧前冲 4 格斜劈而下（刀锋银斩击弧拖影）。
- 差异化：
  - 体型档：英武变异战士（heroic + 右臂加长加粗，左右不对称）。同为「盾 + 单手武器」的人形：诅咒剑士是 stocky 矮壮、维京战士 standard、血骑士 heroic 但瘦骨架；混沌士兵是唯一一侧手臂畸形变大的。同组黑卡托斯是 giant 40 格黑铁巨锤，混沌士兵 30 格骨白。
  - 识别特征：①竖举高出盔顶的锯齿骨刃胡子斧（改外轮廓）②甲虫背壳骨盾，边缘锯齿、盾面紫眼（改外轮廓）③骨甲盔两根后弯骨角 + 后脑骨刺、背脊骨刺（改外轮廓）④变异骨甲大臂 + 大骨肩甲。
  - 武器 + 握法 + 攻击类型：单手胡子斧 + 甲虫盾 · 劈。维京战士是盾击冲撞、奴隶主双手月牙大斧三连劈、诅咒剑士是阔剑过肩斜劈；混沌士兵是单手斧、先盾后劈，技能再加盾撞前冲。
  - 待机个性：斧头往下一磕，斧背「咚咚」敲两下盾沿（敲出火星）。
  - 步态：持盾行军——盾稳在胸前，斧随步子一点一点，落脚 3 颗尘。
  - 死亡方式：前扑（踉跄前跪 → 斧脱手甩飞 → 前扑倒地，骨盾压在背上 → 斧落地弹一下）。
  - 主色：骨白甲壳 + 暗紫灰皮 + 沙褐壳盾 + 血红缠布；和黑铁（黑卡托斯）、苔锈（诅咒剑士）、靛蓝（维京）拉开。
