# 骸骨法师 Mage

模块：`pcd/chars/Mage.js`。身体用部件库拼：`rig(tall, sw 4, headX 1)`、`torso(robe, 下摆到地 hem 0, flare 5)`、`arm(loose + 金袖口)`、`hand`、`head(gaunt)`。模块里自画的部件（标了「// 候选部件」）：`candleCrown` 倒扣破锅盔烛台冠（3 根蜡烛、烛火 3 档错相位摇曳）、`bellStaff` 断旗杆铃摆杖（横梁 + 吊铃 + 发光铃舌 5 档）、`skull`；旗角金穗、袍上破洞露箭羽画在躯干部件里。
升级线：逃兵 → 骸骨法师是**同一个骷髅**：凹陷破锅盔倒扣着戴（左端凹痕保留）变成烛台冠；逃兵脖子上的蓝布条长成整面军旗裹身；背后断箭从袍子破洞露出箭羽。体量比逃兵高 4 格，优质多了金穗、金袖口和三根烛火。

## 角色设定卡

- 名称 / 身份：骸骨法师，披着一整面军旗、头顶烛台冠、摇铃打拍子给友军提速的骷髅祭司（优质）。
- 一句话剪影：**头顶宽沿上的三根蜡烛（中间高、两边低，烛火高出盔顶 4 格）+ 上窄下宽拖地的旗袍三角 + 身前高过头的旗杆杖，杖顶横梁吊一只左右摆的铜铃**。
- 尺寸：待机 26×38 格（含烛火与杖顶，身体本身约 28 格）；体型 `tall` 高个档（leg 11 · torso 10 · head 6），腰背挺直，长袍拖地看不见脚。
- 材质色阶（全部来自共享色板，无新增颜色）：
  - 旗袍 军旗蓝 `blue` [0, 39, 40, 41]（band 2）+ 金边 / 立领 / 袖口 / 下摆金穗 `gold`
  - 骨 `bone`；烛台冠 `iron` + 锈斑；蜡烛 `white`（蜡泪暗格）；烛火（发光体）flat [45, 46, 47, 21]
  - 旗杆 `wood` + 铁箍 / 横梁 `iron` + 杖顶金钉；铜铃 gold 暗段 [0, 20, 19, 14]；铃舌（发光体）flat [22, 14, 51, 21]
  - 眼窝火：待机磷绿，技能里换成铃舌同色（电黄）
- 部件顺序（从后往前）：左臂（后手，袖子藏在身后）→ 袍子破洞里的断箭羽 → 旗袍（同一部件：立领、金前襟、下摆波浪、后摆金穗、破洞）→ 骷髅头 → 烛台冠 → 蜡烛 → 烛火 → 旗杆杖（杆 + 铁箍 + 横梁）→ 铃绳 + 铜铃 + 铃舌 → 左手（压在杖上段）→ 右臂（金袖口，握杖下段）。
- 细节清单：
  - 脸：眼窝 2 格（前一格发光）、鼻孔、颧骨、牙排、打颤的下颌；点头时整颗头骨和烛台冠下沉 1 格。
  - 头饰：倒扣的锅盔 3 行（窄口扣头上、宽沿朝上、左端凹进去耷拉一格、锈斑、亮沿）+ 3 根蜡烛（2 / 4 / 2 格高、间隔 ≥ 3 格，剪影里看得出三个尖）+ 蜡泪。
  - 服装：robe 下摆外扩拖地、两道褶、下摆波浪、金前襟、立领、后摆 3 格金穗 + 下摆一排金点。
  - 手臂：喇叭状宽袖 + 金袖口、骨手 2×2。
  - 武器：旗杆 30 格高（两道铁箍、杖顶金钉、6 格横梁），横梁前端铃绳 + 3×3 铜铃（左上高光）+ 铃舌发光 5 档（待机暗 / 蓄力 / 蓄满 / 施放三格亮 / 熄）。
- 攻击方式：远程施法——预兆 旗杖提起往后收、铃摆甩到后面 → 出手帧旗杖往前一顿（杖尾顿地扬 2 颗尘），铃摆甩到最前，「叮」地甩出一颗旋转的铃音弹（3 格环弹，亮点绕环转）→ 命中 8 颗电黄火花。
- 差异化：
  - 体型档：高个长袍档；同族里唯一长袍拖地、看不见脚；和同组死灵法师（佝偻）、死神（巨型佝偻）都不同。
  - 识别特征 4 个（3 个改外轮廓）：烛台冠 3 根蜡烛、杖顶横梁吊铃（左右摆出杖头 2 格以上）、旗袍拖地的三角外形 + 身后金穗；轮廓内：袍子破洞里的箭羽。
  - 武器 + 握法 + 攻击类型：双手竖持旗杆杖 × 施法（顿杖甩铃音弹）；已通过的巫师是甩杖、修女是前推十字架，法师是**杖尾顿地 + 铃摆甩弹**。
  - 待机个性：摇铃打拍（铃摆 8 帧一个来回，循环末尾头骨跟着节拍点两下头，三根烛火错相位摇曳）。
  - 步态：杖点地滑步（袍子遮脚，身体轻起伏，旗杖前后换位，每两步杖尖点地一颗尘）。
  - 死亡方式：融化（死亡套件 melt）。
  - 主色：军旗蓝长袍；和已通过的巫师（酒红袍）、修女（鸽灰蓝）拉开。查重最接近 idleIoU 0.747 / 配色 0.167，未判重。

## 特效设定卡

- 元素色阶：攻速光环 · 电黄节拍 `FXI.bolt`（攻击与技能共用，未改色阶）（21 白 → 51 淡金 → 22 青 → 23 蓝 → 40 深蓝）；蓄力时烛火粒子掺少量 `fire`。
- 攻击「铃音弹」：预兆 杖后收 1 帧（铃舌 1 档）→ 出手 顿杖定格、铃舌 2 档、枪口一圈环光 2 帧 → 弹道 旋转的 3 格环弹（150 格/秒，每 3 步一颗短尾）→ 命中 8 颗火花 + 3 格十字，假人小摇。
- 技能「充能」（中范围光环，身边友军攻速 +10%）：
  - 蓄力 1.4 s：旗杖举高、仰头看铃；铃摆越摆越急（频率 1.2 → 5.7 次/秒，摆幅 1 → 3 格）；三根蜡烛的火苗被拉高、火星从三根蜡烛螺旋汇聚到铃舌（K_SPIRAL 跟着铃摆走）；**脚下一圈 8 格节拍刻度盘（贴地椭圆 12×4）从身后顺时针逐格充满**——没充上的是暗蓝短横，充上的变亮十字、刚亮的那格闪白并迸 3 颗火花，1.25 s 充满后整圈交替闪并连成虚线圈；眼窝火变电黄；铃舌 1 / 2 档闪；轮廓光 2 档；地面映光；两名友军站到身边（一后一前）。
  - 施放 0.5 s：旗杖往地上一顿（身子压低 1 格，杖尾顿地扬 2 颗尘 + 6 颗贴地火花），铃被震到最前、随后左右大幅回荡逐拍收小；铃口一圈环光 2 帧；汇聚火星外爆 + 12 颗电黄火花；刻度盘炸成**三道节拍波纹**（白 → 淡金 → 青 → 蓝，间隔 0.06 s）贴地向外扩散，0.22 s 扩到中范围（半径 22 格，把左右两名友军都圈进去），停成光环；震屏 2 格 + 天空闪白。
  - 命中（施放后 2 帧，波纹扫过友军脚下）：圈里两名友军同时描电黄轮廓（allyFx 约 0.9 s，最后 30% 闪烁褪去）、头顶十字星芒、各 8 颗火花；之后每人头顶两只上升箭头循环往上走（攻速提升），身后 3 道横向速度线滚动；无震屏。光环本身：青色虚线椭圆，断口跟着转，8 个刻度里有一个按铃摆的 8 帧节拍转圈亮白（像节拍器的指针在地上走）。
  - 收招 0.7 s：旗杖从地上拔起回到待机，铃摆慢下来回到节拍，眼窝火转回绿；光环和友军箭头在最后 0.4 s 按有序抖动散掉。
- 受击：白色剪影 1 帧 + 击退 2 格 + 眼窝熄、下颌张开、铃摆甩到最后又弹回来、袍摆反甩；骨灰 dust 火花；震屏 1 格。
- 死亡：挨打闪白 → 身子一塌、三根烛火同时熄灭冒青烟 → 0.85 s 融化：死亡套件 melt，长袍连骨架按列塌成一滩 → 烛台冠和铜铃（单独烤的小精灵）从滩里一左一右滚出来（尘 + fall）→ 魂光上升 → 滩和锅盔、铜铃一起抖动消散。
- 音色：铜铃急促的叮叮节拍越敲越快（充能）+ 旗杖顿地「咚」一声带出一圈嗡鸣扩散开 + 骨指扣杖的笃笃声，重量 0.25。
  - `SFX: { body: 'flesh', how: 'dissolve', pal: 'bolt', style: 'buff', w: 0.25 }`；`step`（w 0.15）在滑步的接触帧、`swing`（staff）+ `shoot`（orb）在顿杖帧、`hit`（magic）在铃音弹命中时、`impact`（bolt）在光环波纹扫到友军脚下时、锅盔铜铃滚出时 `fall`。
