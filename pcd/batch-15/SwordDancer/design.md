# 剑舞者 SwordDancer

模块：`pcd/chars/SwordDancer.js`。身体用 `parts.rig` standard（腿加长到 12、收腰 waist 1、肩窄 sw 3）+ `parts.head` / `parts.hair` / `parts.arm` / `parts.sword`（saber）拼；踮脚灯笼裤腿、短胸衣露骨细腰、金币腰链裙、钱袋、高发髻金币簪、垂到腰的面纱、骷髅正 / 背面头都是本模块自画的部件（函数前标了「// 候选部件」）。
升级线：剑舞者 → 幻影舞者，是**同一个舞娘死得更彻底了**：保留高发髻金币簪、面纱（→ 三条幽灵飘带）、金币腰链裙（→ 幽灵币燕尾裙）、后腰钱袋、踮脚；两把月牙短弯刀长成反握月牙镰。

## 角色设定卡

- 名称 / 身份：剑舞者，骷髅舞娘，商人——靠跳剑舞讨赏的死者，全部家当都挂在腰上那条沉甸甸的金币腰链上。「高伤害但防御低」：只穿一件短纱胸衣，腰是露在外面的脊椎。
- 一句话剪影：**头顶高发髻 + 斜插出来的金币簪、钟形外扩的金币腰链裙（下摆宽 14 格）、身体两侧各伸出一把月牙短弯刀**，身后一条薄面纱。
- 尺寸：待机约 28×34 格（含簪头），稀有品质，舞者档：细腰长腿、肩窄，始终踮着脚尖。
- 材质色阶（色板下标）：
  - 孔雀青纱 `sky` [39, 40, 41, 23]：纱裙 band 2，胸衣 / 灯笼裤 band 1（远侧腿暗一级）
  - 金币 `gold` [20, 19, 14, 5]：腰链、三层垂币、脚铃、臂钏、护手、胸口金币坠
  - 面纱 `white` [7, 18, 17, 21]（隔点透，空格由选择性勾线补成暖灰）；骨 `bone` [8, 7, 6, 17]
  - 弯刀 `steel` [27, 28, 29, 30]；刀柄 / 钱袋 `leather` [20, 19, 32, 33]；发髻墨青 [0, 0, 39, 40]
  - 眼窝 / 鼻孔 `ink`；眼窝金光 + 簪头金币（发光体，平涂 5 档）[20, 14, 5, 21]
- 部件顺序（从后往前）：面纱 → 左手弯刀 → 左臂 → 远侧腿 → 近侧腿 → 胸衣 + 露骨细腰 → 金币腰链裙 → 钱袋 → 骷髅头（+ 发）→ 高发髻 → 金币簪 → 右手弯刀 → 右臂 →（待机个性）翻飞的金币。背面帧把面纱挪到头之后（垂在朝镜头的背上）。
- 细节清单：
  - 脸：骷髅侧脸——2 格眼窝 + 窝里 1 格金光、眉骨暗边、鼻孔、下颌一排牙（亮 / 墨交替）、颧骨凹、长下巴；正面帧两个眼窝各 1 格金光 + 居中鼻孔 + 一排牙；背面帧后脑盖满发。
  - 发：头顶一层墨青发 + 4 行高发髻（盘纹两格、金发箍）；面纱从发髻后垂到腰，末端 2 行随 sway 摆，被风吹起时整条水平飘。
  - 头饰：金簪斜插出发髻后上方 3 格，簪头 2×2 金币（发光体，5 档，glint 闪白）。
  - 服装：3 行纱胸衣 + 胸口金币坠；胸衣下一行肋骨、一行只剩脊椎（露骨细腰）；腰链亮暗交替的链节；纱裙两道褶 + 下摆波浪；裙面三层垂币（叮当晃：亮暗随相位换），下摆每 3 格垂一枚币出轮廓。
  - 手臂：2 格细骨臂 + 金臂钏 + 2×2 骨手握刀柄。
  - 腿脚：灯笼裤（中段鼓 3 格）→ 金色脚铃一圈 → 2 格细骨小腿 → 只有脚尖 1 格斜着点地（踮脚）；远侧腿暗一级。
  - 武器：月牙短弯刀 ×2（钢刃后三分之一弯、金护手 3 格、皮缠柄、柄头）。
  - 配件：后腰一只鼓肚钱袋（金束口 + 冒出袋口的一枚金币 + 袋面金币印）。
  - 发光体：眼窝金光 + 簪头金币（`GLOW_MATS`），待机偶尔闪一档，死亡时熄灭。
- 攻击方式：近战 **扫**（双持）——预兆：双刀收到身后、屈膝 → 第一斩：踮脚前移 3 格，右手刀水平扫出（侧面）→ 转身：正面（双臂平伸）→ 侧镜像 → 背面 → 第二斩：左手刀从低处扫出（侧面）→ 收回。两道绕身一圈的扁椭圆弧（金币色），先高后低。
- 差异化（对照已通过角色 + 同组分配）：
  - 体型档：舞者档（细腰长腿、踮脚），同组的逃兵是缩肩标准、弓手瘦高猫腰、法师长袍三角、守卫蹲伏飞行、教堂卫矮壮、召唤师 / 糖果女孩孩童、骑士英武、狮锤桶甲、死灵 / 死神佝偻。
  - 识别特征（≥ 2 个改外轮廓）：①高发髻 + 金币簪（轮廓，头顶后上）②钟形金币腰链裙 + 下摆垂币（轮廓，下半身宽 14）③两侧伸出的月牙短弯刀（轮廓，左右）④后腰鼓钱袋 ⑤脚踝铃铛。
  - 武器 + 握法 + 攻击类型：双持弯刀 × 扫（原地旋转两斩）；同组没有双持，已通过的影剑士是反握单刀闪步扫、维京海盗是弯刀 + 铁钩刺。
  - 动作个性：待机 = 抛金币（左手刀夹在腋下，指骨把一枚金币弹起、翻 3 帧、接住）；步态 = 踮脚交叉舞步（接触 B 两腿在裙下交叉成 X，腰链一甩一甩，无尘，每步脚铃一粒金光）；死亡 = 旋转倒下。
  - 主色：孔雀青纱 + 金，全库没有以 sky 为主材质的人形。
  - 特效：金币环绕 → 喷泉上抛 → 落地弹跳聚堆，同组没有金币系。

## 特效设定卡

- 元素：美味 · 金币，色阶 `coin` = 21 白 → 5 淡金 → 14 金 → 61 暗金 → 20 棕。
- 攻击「旋舞连斩」
  - 预兆：双刀收到身后、屈膝 1 格，眼窝金光亮一档。
  - 出手：两次出手帧（第 2、6 帧）各一道绕身一圈的扁椭圆弧（前半圈在身前，第 1 帧 2 格宽第 1–2 级，第 2 帧 1 格断续第 3 级）；面纱被甩成水平。
  - 命中：每斩一次 impact 8 颗 + 金色 4 颗 + 十字星芒，假人闪白小摇。
- 技能「美味」（表现死亡时掉落积分：舞者转身抛洒金币）
  - 蓄力 1.4 s：踮脚原地加速旋转（前 0.7 s 每个朝向停 3 帧，之后每帧换一个朝向：侧 → 正 → 侧镜像 → 背），双臂举起；腰链上的金币一层层被甩脱（裙面垂币从下往上消失），12 枚金币一枚枚绕着腰环绕、越转越快（2×1 正面 ↔ 1 格侧面翻转，转到身后的半圈画在身后），偶尔闪白；金色火花螺旋汇聚；面纱水平飘起；眼窝 / 簪头金光 1 / 2 档闪；轮廓光 2 档，地面隔点映光。
  - 施放 0.5 s：猛地定格亮相——双刀交叉举过头；环绕的金币全部向上向外喷泉般抛出 + 汇聚火花上抛；交叉处十字星芒（臂长 6）+ 18 颗外爆 + 冲击环；震屏 2 格，天空闪白。
  - 命中：金币落地弹两下，每枚第一次落地闪一个金色「+」（第一枚落地发 `impact`），弹完滑进脚边的币堆（4 + 3 + 2 + 1 金字塔，另两枚散在旁边）；币堆聚齐时一圈金色火花 + 第二次 `impact`，停一会儿抖动消散。
  - 收招 0.7 s：双刀放下，金光 2 → 1 → 0，裙面垂币最后长回来。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 眼窝闭上、面纱往前甩、裙摆反甩；骨灰火花（dust 色阶，`R_HURT`）；震屏 1 格。
- 死亡（旋转倒下）：26 颗骨灰 + 震屏 2 格 + 闪白 → 踉跄 → 原地转半圈（正面 → 侧镜像）→ 0.3 s 腰链断开：10 枚金币撒一地、叮当弹两下后散在地上，钱袋从后腰掉下翻滚着落地 → 屈膝 → 侧身倒地（离地 3 → 1 → 0），双刀散在身体两边 → 0.66 s 落地：尘土 14 颗 + 震屏 1 格 + `fall` → 眼窝金光闪几次熄灭 → 1.0 s 面纱飘落、1.1 s 覆满全身 → 1.6 s 起自上而下消散（地上的金币一起抖散），魂光上升。
- 音色：一串金币叮叮当当的撒落声 + 脚踝铃铛的碎响 + 弯刀轻快的刷刷声，重量 0.3（`SFX: body stone（骨头磕碰）· how topple · pal coin · style coin · w 0.3`；步态 step w 0.15、攻击两次 swing slash + hit flesh、技能落地 / 聚堆两次 impact coin、腰链断开 hit metal、倒地 fall w 0.3）。
