# 骸骨弓手 Archer

模块：`pcd/chars/Archer.js`。身体用部件库拼：`rig(slim, leg 10, sw 3, lw 2, headX 1)`、`pack(quiver)`、`legs(bare)`、`torso(leather, 加长下摆)`、`arm(tight)`、`scarf(wrap)`、`hand`、`head(gaunt)`。模块里自画的部件（标了「// 候选部件」）：`tiltBow` 能仰角 1:2 的短猎弓（弓臂按瞄准方向的法线排开、缠破布、上弓梢系布条）、`fireJar` 陶火罐（带提梁、罐口火苗 4 档、能打翻）、`dentPot` + 3 根备用箭羽、`skull`、`backArrow`。
升级线：逃兵 → 骸骨弓手是**同一个骷髅**：凹陷破锅盔（左后角塌陷、帽檐前翘）、蓝军旗布条（改系在上弓梢，尾梢金边）、背后断箭都在；新增火罐、短弓、箭袋，腿长 1 格、猫腰。

## 角色设定卡

- 名称 / 身份：骸骨弓手，猫着腰、箭在火罐里蘸一下再抛射的骷髅猎手（普通：粗糙短弓、陶罐，没有贵重装备）。
- 一句话剪影：**破锅盔后面翘起的 3 根箭羽 + 腰侧向前凸出 3 格的冒火陶罐 + 身前一张短猎弓 + 背后插满红羽箭的破箭袋**。
- 尺寸：待机 23×30 格（含盔上箭羽和箭袋羽）；体型 `slim` 瘦高档（leg 10 · torso 8 · head 6 / headW 5），比逃兵腿长 1 格、肩窄，常驻下蹲 1 格（猫腰）。
- 材质色阶（全部来自共享色板，无新增颜色）：
  - 皮甲 + 破裙甲 烟熏深褐 `leather` [20, 19, 32, 33]；骨（烟熏偏黄）[8, 7, 6, 5]
  - 锅盔 `iron` + 锈斑；盔上箭羽 `wood` 杆 + `white` 羽；布条 `blue` + 金边 `gold`
  - 短弓 [0, 20, 19, 32] + 缠布 `sand` + `white` 弦；箭 `wood` 杆 + `steel` 箭头 + `white` 羽
  - 陶火罐 `crimson` [11, 12, 13, 26] + `wood` 提梁；火苗 / 蘸火箭头（发光体）flat [45, 46, 47, 21] 与 [46, 47, 51, 21]
  - 箭袋 `boot` [0, 20, 20, 19] + 铁箍 `iron` + 红羽 `crimson`
  - 眼窝火：待机磷绿 flat [35, 36, 37, 38]，技能里换成炉火橙
- 部件顺序（从后往前）：箭袋 → 背后断箭 → 左臂（后手，袖子）→ 两条骨腿 → 皮甲 + 撕成一条条的裙甲 → 颈上皮绳 → 骷髅头 → 盔上箭羽 → 破锅盔 → 右臂（握弓）→ 短弓 + 布条 → 箭 → 陶火罐（挂在近侧腰上，压在下弓梢前面）→ 蘸火的箭（蘸箭时）→ 左手（搭箭 / 拉弦）。
- 细节清单：
  - 脸：眼窝 2 格（前一格是火）、鼻孔、颧骨、牙排、会张开的下颌。
  - 头饰：凹陷锅盔（同逃兵）+ 盔沿后插 3 根备用箭羽，向后上方翘出 3 格。
  - 服装：皮甲缝线、胸前系带、斜挎带、锈扣、加长 2 行的裙甲下摆撕成一条条（隔 3 列缺口 + 暗格）。
  - 配件：陶火罐（提梁 2 格拱、罐口亮沿、罐身左亮右暗、罐口火苗一跳一跳）。
  - 武器：短猎弓 13 格高（弓臂两处缠破布、弓梢亮、弦可拉到后手）；箭（羽 + 杆 + 箭头，蘸过火后箭头发光）；上弓梢的蓝布条 4 格往后飘。
  - 发光体 5 档：罐口火苗（0–3 档高）+ 箭头（待机钢色 / 蘸火 / 蓄满 / 施放 / 熄）。
- 攻击方式：远程抛射——箭头在火罐里一蘸（第 0 帧）→ 仰角 1:2 拉满（第 1 帧）→ 松弦（第 2 帧，后手往后弹开，枪口十字光 2 帧）→ 火箭走抛物线（峰高 12 格、0.36 s）落到假人。
- 差异化：
  - 体型档：瘦高猫腰（常驻下蹲 1、前倾 1）；和同族逃兵（缩肩标准）、法师（高个长袍）、武士（巨型）以及同组召唤师（孩童）都不同。
  - 识别特征 4 个（3 个改外轮廓）：盔后翘起的 3 根箭羽、腰侧向前凸出的陶火罐、背后插满红羽箭的箭袋；轮廓内：弓梢的蓝布条。
  - 武器 + 握法 + 攻击类型：双手短弓 × 射（**仰角抛射**）；已通过的游侠 / 死亡射手 / 藤弓法师都是平射长弓，弓手的弓只有它们的一半长，弹道是弧线。
  - 待机个性：蘸箭（循环末尾把箭伸进火罐一蘸，火苗窜高一格，再收回搭在弦上）。
  - 步态：猫腰潜行（下蹲 2、轻脚，每两步 1 颗尘）。
  - 死亡方式：化灰——火罐打翻，火从脚往上把骨架烧成灰（贴地截断一行行上升 + 火线 + 灰烬），破锅盔最后落地。
  - 主色：烟熏深褐皮甲；和游侠（苔绿斗篷）、死亡射手（墨黑绿）拉开。查重最接近 idleIoU 0.704 / 配色 0.598，未判重。

## 特效设定卡

- 元素色阶：燃烧箭 · 炉火橙 `FXI.fire`（21 白 → 47 淡黄 → 46 橙 → 45 红 → 44 深红）。
- 攻击「火箭」：预兆 蘸箭 1 帧（罐口火苗窜到 3 档）+ 仰角拉满 1 帧 → 出手 枪口十字光 2 帧 → 弹道 抛物线火箭（箭头吸附 8 向朝飞行方向，1 格火尾粒子）→ 命中 8 颗火花 + 3 格十字，假人小摇。
- 技能「火焰箭」（一支满法力的大火箭）：
  - 蓄力 1.4 s：0–0.4 s 箭深插进火罐，罐口窜起 1 格宽火柱（最高 9 格，白 → 淡黄 → 橙 → 红），火星从罐口大量飘升，下颌打颤；0.4 s 起仰角拉满（pull 1 → 2 → 3，满弦保持 10 帧以上），箭头发光 1 / 2 档闪，火星螺旋收拢到箭头、余烬从箭头飘升；眼窝火变橙；轮廓光 2 档；地面隔点映光。
  - 施放 0.5 s：松弦定格 2 帧（后手往后弹开）；仰角射出大火箭（峰高 20 格、0.4 s，箭尾 3 格火尾 + 密集火尾粒子）；枪口十字光；罐口火苗被带出一圈火星外爆（14 颗）；震屏 2 格 + 天空闪白。
  - 命中：箭从上往下扎进目标 → 目标整体点燃（dummyFx tint fire 1.3 s）+ 2 格宽短火柱 + 20 颗火星外爆 + 5 格十字，假人大摇，震屏 1 格。
  - 收招 0.7 s：弓放下、重新搭箭，眼窝火由橙转回绿。
- 受击：白色剪影 1 帧 + 击退 2 格 + 眼窝熄、下颌张开、布条甩向前、罐口火苗惊得窜高；骨灰 dust 火花；震屏 1 格。
- 死亡：挨打闪白 → 踉跄、火罐打翻躺在脚前（火洒出来）→ 0.45 s 单膝跪倒（尘 + fall）→ 0.55–1.5 s 火从脚往上把骨架一行行烧掉（火线贴着剩下骨架的底边往上爬，灰烬 / 火星上升）→ 火烧到头时破锅盔掉下来、往前滚半圈，1.55 s 落地（尘 + fall）→ 魂光上升 → 锅盔最后抖动消散。
- 音色：陶罐里的火苗呼呼声 + 箭离弦时一声带火的「嗖—噗」+ 骨指拨弦的干响，重量 0.3。
  - `SFX: { body: 'stone', how: 'dissolve', pal: 'fire', style: 'fire', w: 0.3 }`；`step`（w 0.15）在步态接触帧、`swing`（bow）+ `shoot`（arrow）在松弦帧、`hit`（flesh）在火箭落到假人时、技能 `shoot`（fire）在施放帧、`impact`（fire）在大火箭命中时、跪倒和锅盔落地各一次 `fall`。
