# 死灵法师 Necromancer

模块：`pcd/chars/Necromancer.js`。身体用部件库拼：`parts.rig`（hunched，leg 11 / torso 11 / head 7 / hunch 3 / arm 12）+ `legs bare`（骨腿）+ `torso robe` + 两只 `arm bell`。部件库里没有的部件写在模块里，函数前标了「// 候选部件」：`ribCollar` 肋骨立领、`skullHead` 骷髅头、`boneCrown` 三尖骨冠、`wyrmSkull` 小飞龙头骨（下颌 0–2 档开合）、`soulLamp` 腰间小魂灯。
升级线：死灵法师 → 死神，是**同一个佝偻骷髅长大了**：龙颅杖 → 巨型龙颅镰，肋骨立领 → 骨翼领，三尖骨冠 → 骨龙冠（多一对后掠龙角），魂灯 → 魂光沙漏；魂光色阶两级共用（soul）。

## 角色设定卡

- 名称 / 身份：死灵法师，佝偻的老骷髅召唤师，用杖顶那颗飞龙头骨召唤复仇之龙。
- 一句话剪影：**比人高 4 格的龙颅杖（杖顶一颗张着嘴的小飞龙头骨）+ 脖子后扇形竖起的一圈肋骨立领 + 头顶三尖骨冠**，墓苔绿长袍拖地。
- 尺寸：待机约 28×36 格（骨冠顶 -29，龙颅角尖 -34）；史诗，佝偻档（驼背前倾、头压在肩线前、手臂长）。
- 材质色阶（共享色板下标）：
  - 长袍 `moss` [0, 34, 35, 36] band 2（大面积），袖子 `moss` band 1，后臂暗一级
  - 骨（骷髅头 / 骨腿 / 骨手 / 立领 / 骨冠 / 龙颅）`bone` [8, 7, 6, 17]
  - 杖身 `wood` [0, 20, 19, 16]（两格：左亮右暗）+ 三道缠骨；腰绳 / 前襟 `wood`；腰扣 `bone`
  - 魂灯铁笼 `iron` [0, 27, 28, 29]
  - 发光体（flat）：魂光 [3, 25, 24, 23]（待机 / 蓄力）、魂光亮 [24, 23, 22, 21]（蓄满 / 施放）；眼窝 / 鼻孔 [0, 0, 52, 53]
- 部件顺序（从后往前）：肋骨立领 → 后臂（喇叭袖 + 骨手）→ 骨腿 → 长袍（+ 同部件的破碎下摆布条）→ 魂灯 → 骷髅头 → 骨冠 → 龙颅杖（杖身 → 龙颅）→ 前臂（喇叭袖 + 骨手，握杖）。
- 细节清单：
  - 脸：7×7 颅骨、亮眉骨、2 格眼窝（前一格是魂光点，受击时熄灭）、鼻孔、上牙排亮暗相间、下颌、太阳穴凹陷和颅缝。
  - 「发 / 须」：没有毛发；会摆的部分是魂灯（下半随 lamp 左右摆）和龙颅下颌（开合）。
  - 头饰：三尖骨冠——骨箍亮暗相间，后尖往后斜、前尖往前斜、中尖最高（高出头顶 3 格），尖之间留 3 格缝，剪影里分得开。
  - 服装：长袍外扩下摆、两道褶、木色前襟线、腰绳 + 骨扣、下摆波浪 + 后半截参差下垂的破布条；肋骨立领 4 根（带弯折、内侧暗面、尖端按发光档亮起）。
  - 手臂：喇叭袖、骨手 2×2；后手在待机个性里抬起去抚摸龙颅。
  - 腿脚：骨腿、赤骨足，前脚多 1 格；长袍盖到 -2，脚露在下摆下面。
  - 武器：龙颅杖——两格黑木杖身、三道缠骨、铁杖尖；杖顶飞龙头骨（后掠小角、眉骨、眼窝、鼻孔、长吻、上牙、下颌 3 档）。
  - 发光体：龙颅眼窝 + 口中魂光、骷髅眼窝魂光点、魂灯魂光，5 档（待机 / 蓄力 / 蓄满 / 施放 / 熄灭）。
- 攻击方式：远程**施法**——杖往回收（预兆）→ 单手把龙颅杖往前一探（出手帧：龙颅张到最大、白色口光 2 帧）→ 龙颅吐出一颗旋转骨弹（白骨芯逐帧转 45° + 魂光尾）→ 收回。
- 差异化（对照已通过角色 + 同组分配）：
  - 体型档：佝偻档，本组唯一佝偻人形（同组 Mage 是挺直的高个长袍、Warrior 巨型重装、Summoner / CandyGirl 孩童）；和已通过的野人祭司（佝偻 + 鹿颅面具 + 双手横握骨铃杖）拉开：本角色单手竖拄杖、头是骷髅 + 骨冠、背后是肋骨扇领。
  - 识别特征（≥ 2 个改外轮廓）：①龙颅杖（比人高 4 格、杖顶龙颅伸出轮廓前上方）②肋骨立领（扇形伸出头后 3 格）③三尖骨冠（头顶 3 个尖）④腰间魂灯（轮廓内）。
  - 武器 + 握法 + 攻击类型：单手拄杖 × 施法（口吐骨弹）；同组 Mage 是双手顿杖甩铃音弹，Archer 抛射火箭。
  - 动作个性：待机 = 抚颅低语（左手抬到龙颅后脑，龙颅下颌开合两次、眼窝闪光，魂灯晃）；步态 = 拄杖蹒跚（接触 A 杖先着地在前 → 经过提杖 → 接触 B 杖落在后，杖尖每步 1 颗尘）；死亡 = 落袍（空袍塌成一堆）。
  - 主色：墓苔墨绿长袍（全库人形里没有同色的长袍主材质），骨白点缀，魂光蓝紫发光。
  - 特效：法阵 + 螺旋汇入龙颅 / 魂光团展开成飞龙剪影 / 飞龙俯冲落地实体化；和死神的「沙漏吸魂 + 划地裂缝 + 骨龙从裂缝升起」拉开。
  - 自动查重：`compare.mjs` 退出码 0（最接近的 idle IoU 0.60）。

## 特效设定卡

- 元素：死灵召唤 · 魂光蓝紫，色阶 `soul` = 22 青 → 23 蓝 → 24 紫 → 25 深紫 → 3 墨；爆发点用 21 白；骨灰用 `dust`；智力回法点缀 `magic` 一颗小紫光。
- 攻击「骨弹」
  - 预兆：杖往回收、身体后仰，龙颅合嘴，眼窝亮一档。
  - 出手：单手把杖往前一探（前倾 + 半蹲 1 格），龙颅张到最大、口中魂光最亮，嘴前白色口光 2 帧 + 6 颗魂光。
  - 弹道：白骨芯（十字 ↔ 斜十字逐帧转）+ 3 格魂光尾，隔步拖魂光屑，地面映光。
  - 命中：8 颗魂光 + 5 颗骨灰外爆，假人闪白小摇；一颗紫色小光往上飘（智力：击杀回法）。
- 技能「召唤巨龙」
  - 蓄力 1.4 s：脚下展开暗色魂光法阵（`fx.circle` soul 慢转 0.45）；法阵上的魂光螺旋汇入龙颅口；左手举过头顶、杖举高、身体后仰；龙颅下颌 0 → 1 → 2 越张越大，眼窝 1 → 2 档逐帧闪；骨领每根尖端按发光档亮起；轮廓光 2 档；袍摆被吹向后、魂灯乱晃。
  - 施放 0.5 s：杖往前上方一送，龙颅张到最大；汇聚粒子外爆、嘴前 24 颗魂光 + 冲击环 + 十字星芒；吐出一大团魂光（0–0.08 s 白芯魂光团长大）→ 在空中展开成一只飞龙剪影（0.08–0.16 s，抖动显形，双翼上扬）→ 俯冲向目标前方（0.16–0.33 s，翼上下拍、身后 3 个渐暗残影）；震屏 2 格、天空闪白。
  - 命中（施放 +0.33 s）：飞龙落到目标前方实体化——剪影第 1 帧白亮，之后由亮到暗收翼站在地上；落点魂光大冲击环 + 20 颗魂光 + 18 颗骨灰外爆 + 10 颗尘，假人大摇，震屏 1 格；`impact`（shadow）。
  - 收招 0.7 s：下颌 2 → 1 → 0、发光 2 → 1 → 0，龙颅冒魂光烟；实体化的飞龙 0.3 s 后抖动消散。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 眼窝熄灭、龙颅下颌张开咔嗒、袍摆和魂灯反向甩；火花换成骨灰（`R_HURT` = dust）16 颗；震屏 1 格。
- 死亡（落袍）：26 颗骨灰 + 震屏 2 格 + 闪白 → 骨架在袍里往下塌（半蹲 3 格、前倾、杖往前歪）→ 0.5 s 半堆（骷髅头陷进领口、只剩颅顶和骨冠露出、肋骨从后面戳出，杖倾斜）→ 0.58 s 更低的一堆，龙颅杖往前倒 → 0.66 s 落成一堆空袍：骨冠落在袍堆顶上，龙颅杖横倒在袍上、龙颅落在前面地上，魂灯掉在一旁；尘 16 颗 + 震屏 1 格 + `fall` → 魂灯闪几下熄灭 → 0.8–1.6 s 一缕魂光从袍里左右摇摆着升起 → 1.6 s 起自上而下消散，魂光上升。
- 音色：龙颅开合的骨节咔嗒 + 魂光汇聚时幽深的低语回响 + 一声远处的龙啸，重量 0.5（`SFX: body flesh · how collapse · pal shadow · style summon · w 0.5`；步态 step w 0.3、攻击 swing staff + shoot orb + hit magic、技能 shoot orb + impact shadow、倒地 fall 0.4）。
