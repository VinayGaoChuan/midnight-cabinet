# 幻影舞者 PhantomDancer

模块：`pcd/chars/PhantomDancer.js`。身体用 `parts.rig` slim（加长：腿 13、躯干 9、sw 2、收腰）+ `parts.head` / `parts.hair` / `parts.arm` 拼；幽灵飘带、单足点地 + 飘带腿、幽灵币燕尾裙、反握月牙镰都是本模块自画的部件（「// 候选部件」）。身后的残影用「当前时间 − j 帧」重新摆姿势烤进残影缓冲，再用 `blitShape` 画成单色剪影；瞬移起跳残影用 `copySprite + blitShape`。
升级线：剑舞者 → 幻影舞者，**同一个舞娘进化成了半个幽灵**：保留高发髻 + 金币簪、面纱（→ 三条幽灵飘带）、金币腰链裙（→ 幽灵币 + 燕尾）、后腰钱袋（瘪了）、踮脚（→ 只剩一只脚尖点地）；两把月牙短弯刀 → 一对反握月牙镰；孔雀青纱 → 幻影紫黑纱；加一层残影。

## 角色设定卡

- 名称 / 身份：幻影舞者，死透了的剑舞者，刺客——舞步快到身后永远拖着自己的残影，每砍一刀就从敌人身上收割一丝能量刻进镰刃。刺客的读法：瘦、单足、残影、两把勾刃。
- 一句话剪影：**比剑舞者更高更瘦的单足舞者，身体两侧各勾出一把猩红刃口的月牙镰，头后拖三条幽灵飘带，下半身化成向后拖的飘带和燕尾**，身后跟着 1–3 个暗紫残影。
- 尺寸：待机约 30×37 格（含簪头），传说品质，幻影残像档。
- 材质色阶（色板下标）：
  - 幻影紫黑纱 `shadow` [0, 52, 53, 54]：纱裙 + 燕尾 band 2，胸衣 / 支撑腿 / 飘带腿 band 1（远侧腿暗一级）
  - 幽灵币（gold 暗段）[20, 61, 14, 62]：腰链、两层半透明垂币、脚铃、镰箍、金币簪
  - 幽灵飘带 `pale` [8, 59, 60, 17]；骨 `bone`；发髻墨青 [0, 0, 39, 40]（和剑舞者同一个）；瘪钱袋 [0, 20, 19, 32]
  - 镰刃 `shadow`，刃口 `crimson` [11, 12, 13, 26]；刃背刻痕 + 眼窝光（发光体，平涂 5 档）[56, 57, 58, 21]
  - 残影：shadow 第 3 / 4 级单色（53 / 52），远的更碎
- 部件顺序（从后往前）：三条幽灵飘带 → 左手镰 → 左臂 → 飘带腿（远）→ 支撑腿（近）→ 胸衣 + 露骨细腰 → 燕尾裙 → 瘪钱袋 → 骷髅头（+ 发）→ 高发髻 → 金币簪 → 右手镰 → 右臂。残影在假人与角色之间的特效层。
- 细节清单：
  - 脸：骷髅侧脸，2 格眼窝 + 1 格猩红眼光、眉骨、鼻孔、牙、长下巴。
  - 发：墨青发 + 4 行高发髻；三条飘带从发髻后向后拖 8 / 10 / 12 格、逐条往下错 2 格，正弦起伏随步态前移，末端 3 格碎成隔点的烟。
  - 头饰：同款金簪 + 2×2 幽灵金币。
  - 服装：3 行纱胸衣 + 胸口幽灵币坠；肋骨一行 + 脊椎一行；腰链；纱裙外扩 + 褶 + 下摆波浪；两层隔格亮、隔格空的半透明幽灵币；后摆两条燕尾（2 格变 1 格、拖到离地 2 格、会摆）。
  - 手臂：2 格细骨臂 + 幽灵币臂钏 + 骨手反握镰柄。
  - 腿脚：支撑腿 = 收窄的灯笼裤 + 幽灵币脚铃 + 2 格细骨小腿 + 脚尖 1 格点地；另一条腿从胯往后折到膝，膝下化成两条向后拖的飘带（离地、末端碎成烟点）。
  - 武器：反握月牙镰 ×2——骨柄 2 格 + 幽灵币箍，刃沿月牙弧从手下扫出再往上勾，外弧黑刃背、内弧猩红刃口；刃背 5 道刻痕（平时亮 2 道），蓄力时刃口往外多长 1–3 格。只按 90° 换朝向 + 镜像。
  - 发光体：刃背刻痕 + 眼窝光 + 刃口（`GLOW_MATS`），死亡时熄灭。
- 攻击方式：近战 **劈**（反握双镰）——预兆：双镰举过头 → 出手：瞬身贴近 7 格（原地留一帧紫色起跳残影、0.35 s 抖散），两镰交叉由上往下十字斩（两道交叉斩击弧 + 猩红十字）→ 延续 → 退回；命中后刃背多亮一道刻痕。
- 差异化（对照已通过角色 + 同组分配）：
  - 体型档：幻影残像档（最瘦高、单足点地、下半身半幽灵），和同组所有人形都不同；已通过的影镰死神（ShadowGrimReaper）是悬浮烟雾下摆 + 双手单把长镰过头劈，这里是着地单足 + 反握双镰十字斩。
  - 识别特征（≥ 2 个改外轮廓）：①两侧勾出的反握月牙镰（轮廓，左右各 6 格）②三条向后拖的幽灵飘带（轮廓，头后）③燕尾 + 飘带腿（轮廓，后下）④高发髻金币簪（轮廓，头顶）⑤残影。
  - 武器 + 握法 + 攻击类型：反握双持镰 × 劈（十字斩）；同组死神是双手巨镰远程飞镰。
  - 动作个性：待机 = 转镰（单脚尖点地，前手镰在指骨间转一圈 90° × 4、再换后手，残影慢一拍跟着转）；步态 = 单足滑行（不抬步，飘带 / 燕尾 / 裙摆的波浪前移，身后两个残影慢 2 帧拖着，无尘）；死亡 = 残像碎裂。
  - 主色：幻影紫黑纱 + 猩红刃口 + 暗金幽灵币；和剑舞者的孔雀青 + 亮金拉开。
  - 特效：能量丝抽取 + 瞬移背刺 + 斜 X 斩痕，同组没有。
  - 自动查重：`compare.mjs` 对已通过角色退出码 0（最接近 守夜人 idle IoU 0.592；影骑士配色 0.829 但剪影 0.522）；和剑舞者互查也不判重。

## 特效设定卡

- 元素：收割 · 暗影紫，色阶 `shadow` = 43 淡紫 → 54 紫 → 53 深紫 → 52 墨紫 → 0 墨；收割能量丝、X 斩痕、刻痕用 `blood`（21 → 58 → 57 → 56 → 55，主用第 2 级 58）。
- 攻击「幻影十字斩」
  - 预兆：双镰举过头、屈膝，眼光亮一档，飘带被甩起。
  - 出手：瞬身 7 格 + 起跳残影；两道交叉斩击弧（暗影色）+ 猩红十字 + 刃尖星芒；飘带、燕尾反甩。
  - 命中：暗影 10 颗 + 猩红 5 颗外爆，假人闪白小摇；刃背第 3 道刻痕亮起。
- 技能「致命」（每次攻击永久 +2 攻击力：从敌人身上收割能量、镰刃变强）
  - 蓄力 1.4 s：双镰在胸前交叉、屈膝；0.25 s 起目标身上被抽出 3 条猩红能量丝（从假人头 / 胸 / 腹三个点出发，0.5 s 内伸到刃尖），蛇形起伏、虚线往镰刃流；刃尖不断有猩红火花定点汇聚（`K_SPIRAL_PT`）；刃口 0.5 / 0.8 / 1.1 s 逐格变长、1.1 s 后转亮红；残影 1 → 2 → 3；轮廓光 2 档、地面映光；刻痕 / 眼光 1 / 2 档闪。
  - 施放 0.5 s：瞬移——起跳姿烤成残影留在原地（第 1 帧淡紫、之后深紫抖散），汇聚粒子外爆；本体一帧出现在目标背后（`mx = DUMMY_X + 14 − HX`、镜像）并闪白；两段交叉斩击弧（0 / 1 帧各一道，各一次 `swing`）；震屏 2 格、天空闪白。
  - 命中（施放 +0.25 s）：目标身上留下猩红斜 X 斩痕（0.6 s，第 1 帧白芯，后半断续）+ 30 颗暗影外爆 + 10 颗猩红 + 冲击环；假人大摇、朝背后反方向击退；刃背第 3 道刻痕亮起并闪白（+2 的读法），刃尖一道猩红十字；3 个残影跟到本体身后；震屏 1 格；`impact shadow`。
  - 收招 0.7 s：在目标背后停 0.3 s → 瞬身回原位（目标旁留一个残影）→ 收镰，刃口缩回，残影 3 → 2。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼、飘带 / 燕尾往前甩；骨灰火花（dust）；震屏 1 格；残影只剩 1 个。
- 死亡（残像碎裂）：26 颗骨灰 + 震屏 2 格 + 闪白 → 定格在受击姿（残影一起收拢）→ 0.3 s 本体和身后两层残影一起裂成 5 片横切的暗紫残片（第 1 帧淡紫、裂缝一道亮线），残片左右错开 2–4 格、逐帧抖动，从上往下依次消散（远层残影先散）；同时双镰和一把幽灵币从手的高度掉落 → 0.6 s 落地：尘 6 颗 + `fall` + 震屏 1 格，弹一下 → 暗影魂光持续上升 → 1.6 s 起地上的双镰和币自上而下消散。
- 音色：丝绸撕裂般的尖锐风声 + 双镰交错的「嚓」+ 幽灵币空洞的回响，重量 0.35（`SFX: body ghost · how shatter · pal shadow · style blade · w 0.35`；步态脚尖轻点 step w 0.1、攻击 swing slash + hit flesh、技能两次 swing + impact shadow、镰落地 fall w 0.15）。
