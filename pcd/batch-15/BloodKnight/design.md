# 血骑士 BloodKnight

模块：`pcd/chars/BloodKnight.js`（查看 `pcd/view.html?c=BloodKnight`）· 自检输出：`shots/`

## 角色设定卡

- 名称 / 身份：血骑士，骷髅族守护者，优质。穿半身甲的骷髅骑士，盾上的圣杯盛着血，给身边友军分血（守护者 = 持盾站在前排、护着身后的人，剪影一眼读出「鸢盾 + 桶盔骑士」）。
- 一句话剪影：桶盔顶上竖起一撮向后甩的血红马鬃 + 身前一面鸢形圣杯盾 + 身后三道燕尾的酒红长披风，右手一柄竖起的锯齿弯剑。
- 尺寸：约 30 格高（含盔缨，身体 27）× 22 格宽（披风燕尾到盾尖）。体型档：英武骑士（`parts.rig heroic`：腿长 10、躯干 10、肩宽 sw 5），站得笔直。
- 身体：`parts.rig heroic` + `legs greave`（骨腿 2 格细，小腿套铁胫甲）+ `torso plate`（只到胸口，hem = 腰行上一行）+ `helm great` + `shield kite` + `sword saber` + `cape tattered`；骨骼手臂 `arm tight`（2 格细骨）。库里没有的：盔顶马鬃（`// 候选部件：maneCrest`）、骨腰（脊椎 + 骨盆，`// 候选部件：boneWaist`）、腰前垂布、盾面圣杯纹章、锯齿刃背都写在模块里。
- 材质色阶 [勾线, 暗, 基, 亮]：
  - 披风 / 罩袍（主材质）暗酒红 [0, 55, 56, 57]（blood 色阶往暗挪一级），披风 band 2
  - 胸甲 / 肩甲 / 胫甲 iron [0, 27, 28, 29]（steel 暗段）；盾面 steel [27, 28, 29, 30]，盾边 / 护手 / 盔箍 gold [20, 19, 14, 5]
  - 骨 bone [8, 7, 6, 17]（腰、手、下颌、大腿）
  - 盔缨 crimson [11, 12, 13, 26]
  - 剑刃 steel + 刃口 [27, 29, 30, 31]
  - 发光体「血」平涂 [55, 57, 58, 21]（圣杯里的血、剑的血槽）；盔缝眼光 [55, 56, 57, 58]
- 部件顺序（从后往前）：披风 → 后臂（骨，握盾）→ 腿（远侧暗一级）→ 骨腰（脊椎 + 骨盆）→ 腰前垂布 → 胸甲（罩袍竖条）→ 桶盔 → 骷髅下颌 → 马鬃盔缨 → 鸢形圣杯盾（后手托在身前）→ 锯齿弯剑 → 前臂（骨 + 铁肩甲）+ 骨手。倒地时盾、剑脱手单独画，盔缨在身体落地后单独立起再倒下。
- 细节清单：
  - 脸：桶盔面罩缝 + 1 格血红眼光、T 形面饰；盔下露出 3 格骷髅下颌（牙排亮暗交替）
  - 发 / 毛：马鬃盔缨竖起一撮 + 向后甩 5 格，每 2 列一道暗鬃丝，尖端随 beard 摆，蓄力时被吹得上扬
  - 躯干：铁胸甲（护颈、胸腹分界）+ 胸前酒红罩袍竖条；腰部只剩 2 格宽的脊椎（逐节亮暗）+ 一根浮肋；骨盆 + 铁腰带 + 金扣 + 酒红垂布（两道褶，下摆摆动）
  - 手臂：2 格细骨臂，前肩铁圆肩甲 + 金边；2×2 骨手
  - 腿脚：骨大腿 + 骨膝盖凸起 + 5 格铁胫甲 + 铁靴尖（前脚多 1 格）
  - 武器：锯齿弯剑——骨握把、金护手 3 格、刃背每 2 格一个锯齿、刃中线血槽流着血光（5 档：待机隔 4 格 / 蓄力隔 3 格 / 蓄满隔 2 格 / 施放整条 / 熄灭）
  - 盾：鸢形 14 行，金边 + 铆钉 + 冷光，盾面金圣杯（杯口、杯身、杯柄、底座），杯里的血是发光体
  - 发光体 5 档：待机暗红 / 蓄力亮红 / 蓄满溢出杯口 / 施放白芯 / 熄灭墨红
- 攻击方式：近战「刺」——盾护在身前，剑往后收平（预兆 1 帧）→ 出手帧前冲 4 格从盾沿上方单手平刺，刺入假人，身后一道血色直线拖影 2 帧 → 拔剑时带出一串血珠（带重力落地）。
- 差异化（同组 / 同族已通过角色对比）：
  - 体型档：英武骑士（本组逃兵缩肩标准、弓手瘦高、法师高个长袍、战士巨型重装、教堂守卫矮壮、狮锤桶甲肥壮）；已通过的骑士里赤卫 / 圣光骑士是精灵翼骑、黑铁卫巨型塔盾，没有英武骨腰骑士。
  - 识别特征：① 盔顶血红马鬃向后甩（改外轮廓）② 身前鸢形圣杯盾（改外轮廓）③ 三道燕尾长披风到小腿（改外轮廓）④ 竖起的锯齿弯剑（改外轮廓）⑤ 腰部只有一根脊椎的细腰（骷髅读法）。
  - 武器 + 握法 + 攻击类型：单手弯剑 + 后手托盾 × 刺（逃兵盾撞、战士劈、教堂守卫链锤砸、剑舞者双刀扫，都不一样）。
  - 待机个性：举杯敬酒——循环末尾圣杯溢出一滴血顺着盾面滑下，骑士低头 1 格致意，圣杯闪一下。
  - 步态：大步迈步（heroic 步幅 3），披风燕尾左右摆，每步 2 颗尘土。
  - 死亡方式：后仰倒地（仰面，头在左），盾先脱手翻滚落地（翻滚 4 档，落地横躺露出圣杯），盔缨立在头边最后倒下，身体化成血雾上升。
  - 主色：暗酒红 + 铁灰 + 骨白 + 金；和同组的土黄、烟褐、军旗蓝、黑铁、花岗白、灰紫、草莓粉、孔雀青、幻影紫、墓苔绿、灰白、骨白不同。
- 升级线（→ 狮锤）：盔缨长成整颗狮子头盔、盾上的溢血圣杯长成背后的炖汤锅、燕尾披风变成狮皮披风，骨手骨腰保留。

## 特效设定卡

- 元素色阶：吸血 · 暗红 FXI.blood = 白 21 → 淡粉 58 → 红 57 → 暗红 56 → 墨红 55。
- 攻击「放血刺」：预兆（剑后收平、身体后倾 1 帧，血槽 1 档）/ 出手（前冲 4 格平刺定格 1 帧，血槽 2 档；剑身后一道血色直线拖影 2 帧）/ 命中（impact 12 颗外爆 + 命中点十字星芒，假人小摇）/ 拔剑（第 4 帧从假人前沿带出 6 颗血珠，抛物线落地走完色阶）。
- 技能「吸血光环」（特性被动，表现光环展开、友军攻击时血丝回流）：
  - 蓄力 1.4 s：盾举到齐胸，圣杯满溢——血滴从脚下逆流向上汇到盾心（K_SPIRAL_PT 从下半圆出发、几乎直线上升）；盔缨被气流吹起；血槽、圣杯 1/2 档逐帧闪；轮廓光 2 档暗红 + 地面隔点映光。
  - 施放 0.5 s：盾往地上一顿（盾尖插地、半蹲 2 格），脚下一圈血色法阵（fx.circle，扩到 32 格半径罩住身后两名友军）、冲击环、汇聚血滴外爆、短地裂；两名友军被映红（allyFx tint + outline blood）；震屏 2 格 + 天空闪白。
  - 命中（施放 +2 帧）：每名友军与盾心之间连一条血丝虚线（fx.link），血珠沿线一颗颗流回盾上（0.4 s 一颗到达，持续 0.7 s），友军胸前闪一个红色小十字；震屏 1 格。
  - 收招 0.7 s：盾拔起回到身前，圣杯 2 → 1 → 0，杯口余血飘出几颗。
- 移动：大步，每次接触帧 2 颗尘土，披风、盔缨反向摆。
- 受击：金属 + 骨：impact 18 颗 + 4 颗长寿命白火星 + 6 颗骨灰（dust）；白色剪影 1 帧 + 击退 2 格；盔缝眼光熄灭，盔缨、披风向前甩；震屏 1 格。
- 死亡：26 颗火花 + 骨灰 + 震屏 2 格 + 闪白 → 后仰踉跄（盾脱手）→ 盾翻滚 4 档飞出、落地横躺（尘土）→ 身体仰面倒地（离地 3 → 1 → 0，尘土 16 颗 + 震屏 1 格，剑甩到头后方）→ 圣杯熄灭 → 盔缨从立起到倒下 → 1.5 s 起一团血雾（fx.cloud blood）从身上升起，1.6 s 起自上而下消散，血色光点持续上升。
- 音色：盔甲沉稳的铿锵 + 液体逆流的咕嘟声 + 一声低沉的心跳鼓点，重量 0.6。SFX 声明 `{ body: 'armor', how: 'topple', pal: 'blood', style: 'buff', w: 0.6 }`；步态接触帧 step（0.6）、出手帧 swing（thrust）+ hit（flesh）、施放 impact（blood 0.6）+ 血丝回流 impact（blood 0.35）、盾落地 fall（0.3）、身体倒地 fall（0.6）。
