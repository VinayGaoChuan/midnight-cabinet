# 骸骨武士 Warrior

模块：`pcd/chars/Warrior.js`。身体用部件库拼：`rig(giant, leg 11, torso 12, head 7, sw 6, arm 12)`、`cape(tattered, short)`、`arm(plate)`、`legs(greave，骨腿 w 2 + 铁靴)`、`torso(plate + tabard)`、`helm(great)`（加凹痕、竖缝，死亡时用 `at / rot` 滚落）、`sword(great)`（加锯齿刃背）、`hand(big)`、`along`。模块里自画的部件（标了「// 候选部件」）：`jagPauldron` 外翻锯齿骨板肩甲；腰部空心（只剩脊椎 + 骨盆 + 前襟）、甲缝裂纹、肩甲断箭画在各自部件里。
升级线：逃兵 → 骸骨武士是**同一个骷髅**：破锅盔焊上面甲成了桶盔（凹痕留在左后角），逃兵背后那支断箭钉在左肩甲上，蓝军旗布变成罩袍前襟 + 身后破短披风；眼火同样是磷绿。体量是整条线里最大的。

## 角色设定卡

- 名称 / 身份：骸骨武士，唯一穿重甲的骷髅——甲是后穿上的，骨架撑不满（优质：整套黑铁甲 + 门板宽的骨刃大剑）。
- 一句话剪影：**肩上两片外翻的锯齿骨板（肩宽 18 格）+ 身前拄地的锯齿骨刃大剑 + 凹陷桶盔 + 腰间一截空心（只有一根脊椎）**。
- 尺寸：待机 25×34 格（含肩甲断箭羽、披风）；体型 `giant` 巨型重装档（leg 11 · torso 12 · head 7 · sw 6），上重下轻：胸甲厚、腰和小腿只有细骨（腿 2 格宽）。
- 材质色阶（全部来自共享色板；只新增一条特效色阶 `bonebit` [17, 17, 6, 7, 8]，全是已有下标）：
  - 重甲 黑铁 `iron` [0, 27, 28, 29]（远侧臂暗一级）；骨 `bone`（锯齿肩甲、腰椎、小腿、手）
  - 大剑 骨刃 `bone` + `steel` 刃口 + 骨护手（一对肋骨）+ 铁握把
  - 罩袍前襟 `blue` + 金点 `gold`；破短披风 `blue`（band 2）；腰带 `boot` + 金扣
  - 盔缝眼火（发光体）3 档材质：暗 [35, 35, 36, 37] / 亮 [35, 36, 37, 38] / 白热 [37, 38, 21, 21]；熄灭 `ink`
- 部件顺序（从后往前）：破短披风 → 后肩锯齿骨板 → 钉在肩甲上的断箭 → 后臂臂甲 → 两条骨腿（铁靴 + 膝甲）→ 板甲 + 罩袍（同一部件：腰那一截挖空，只留脊椎、骨盆和前襟；甲缝裂纹）→ 凹陷桶盔 → 锯齿骨刃大剑 → 后手（压在剑柄上）→ 前臂臂甲 + 前手 → 前肩锯齿骨板。
- 细节清单：
  - 脸：桶盔（不露脸）——横向眼缝 + 1 格磷绿眼火、面甲竖缝 3 格、T 形面饰；凹痕：左后角塌进去一块（暗格）。眼火随呼吸一亮一暗，蓄力 / 施放白热，死亡熄灭。
  - 头饰：平顶桶盔 + 凹痕 + 竖缝。
  - 躯干：板甲中脊、胸腹分界、腿甲裙分段 + 铆钉、护颈；罩袍前襟下摆两点金；腰椎 2 格宽、椎节亮暗交替 + 骨盆。
  - 手臂：臂甲（肘甲高光）+ 3×3 骨手；锯齿骨板肩甲 3 行扇形 + 下沿 5 颗锯齿 + 外端翘起 + 肋纹。
  - 腿脚：2 格细骨腿、膝甲 3 格、铁靴 2 行。
  - 武器：大剑刃长 17（门板宽 3 格刃、刃口 steel 亮线、刃背隔一格一颗骨齿）、5 格肋骨护手、铁握把、柄头。
- 攻击方式：近战劈——预兆 双手把大剑举过右肩（剑尖朝后上方）→ 出手帧前冲 4 格斜劈到地面（骨刃拖出一道白弧）→ 剑尖砸出一道小地裂 + 尘 → 收回拄剑。
- 差异化：
  - 体型档：巨型重装档，同族唯一重装；和同组骸骨骑士（英武档）、狮锤（桶甲肥壮）、死神（巨型佝偻）比，武士是「上重下轻」——肩宽 18、腰和小腿细骨。
  - 识别特征 4 个（3 个改外轮廓）：外翻锯齿骨板肩甲、锯齿骨刃大剑、肩甲上竖起的断箭羽；轮廓内：腰间空心 + 脊椎。
  - 武器 + 握法 + 攻击类型：双手大剑 × 劈（过右肩斜劈到地）；已通过的影骑士是双手过顶竖劈、魔王卫是单手横扫、黑铁卫是盾砸——武士的斜劈 + 剑尖砸地裂不重复。
  - 待机个性：拄剑（双手压剑柄、剑尖点地，头盔每循环缓缓抬起一次，盔缝绿火像呼吸一亮一暗）。
  - 步态：重装行军（接触帧顿挫、每次落脚 3–4 颗尘）。
  - 死亡方式：跪倒空壳（单膝跪下拄剑不倒，骨头从甲缝里一块块掉出来，最后只剩空盔甲跪着，头盔滚落）。
  - 主色：黑铁重甲 + 骨白肩甲 / 大剑 + 蓝罩袍；和黑铁卫（黑铁 + 银叶 + 铁灰旗）靠骨白和军旗蓝拉开。查重最接近 idleIoU 0.715 / 配色 0.445，未判重。

## 特效设定卡

- 元素色阶：残血再生 · 磷火绿 `FXI.nature`（21 → 38 → 37 → 36 → 35，同线共用）；爆发处加骨白碎片 `bonebit`（17 → 17 → 6 → 7 → 8）；普通攻击的刀光用 `steel`。
- 攻击「斜劈」：预兆 举剑过肩 1 帧（眼火 1 档）→ 出手 前冲 4 格定格，骨刃 steel 白弧（半径 17、3 格宽）2 帧 → 剑尖地裂（earth）+ 6 颗尘 → 命中 14 颗 impact 火花 + 4 格十字，假人大摇，震屏 1 格。
- 技能「骸骨再生」（生命越低回复越快：越残越亮的回血爆发）：
  - 蓄力 1.4 s：单膝跪地拄剑；甲缝一道道裂开透出绿火（胸 → 腹 → 腰带 → 前肩骨板，4 道，第 4 道时全部变白热），甲缝间绿火星冒出；绿火星螺旋收拢到盔缝；轮廓光从盔缝往外扩 1 → 2 → 3 档（rimAll，眼火在剪影内部）；地面映光。
  - 施放 0.5 s：大剑整根插进地里（手下沉 4 格，剑身没进地面）；一圈绿焰冲击环 + 两道贴地绿焰浪从剑脚往两边推开 + 剑身两侧各一根绿焰小火柱 + 两道绿地裂 + 骨白碎片外爆；震屏 2 格 + 天空闪白。
  - 命中（施放后 0.2 s）：盔缝向上喷出一股 2 格宽绿焰柱 + 14 颗火星；甲片「咔」一片片复位（裂纹逐帧合上）；胸前冒一团白蒸汽 + 4 格十字星芒；4 个治疗十字从脚下飘升、脚下绿火星。
  - 收招 0.7 s：拔剑站起，眼火 2 → 1 → 0。
- 受击：金属身体（`body: armor`）——白色剪影 1 帧 + 击退 2 格 + 眼缝熄、披风与罩袍反甩、剑一歪；impact 火花 16 颗；震屏 1 格。
- 死亡：挨打闪白 → 0.45 s 单膝跪倒拄剑（尘 12 颗 + 震屏 + fall）→ 0.7 s 腰椎散落（骨片从腰间掉出来落地）→ 0.95 s 小腿骨掉光，只剩铁靴和膝甲 → 1.2 s 骨手松脱，大剑自己立着 → 盔缝绿火闪几下熄灭 → 1.5 s 头盔滚落、翻滚着落到剑前面（fall）→ 空盔甲跪着 → 2.0 s 起抖动消散，魂光与绿火星交替上升。
- 音色：厚铁甲的沉重铿锵 + 大剑插地的「嗡」一声长震 + 甲缝里绿火的嘶嘶，重量 0.85。
  - `SFX: { body: 'armor', how: 'collapse', pal: 'nature', style: 'heal', w: 0.85 }`；`step`（w 0.85）在步态接触帧、`swing`（slash）+ `hit`（flesh）在斜劈出手帧、`impact`（nature）在插剑和盔缝喷火各一次、骨头掉落各一次 `hit`（stone）、跪地和头盔落地各一次 `fall`。
