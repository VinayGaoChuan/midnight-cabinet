# 糖果女孩 CandyGirl

模块：`pcd/chars/CandyGirl.js`。身体用部件库 `parts.rig`（child 档加高：腿 6、躯干 7、头 8×8、sw 4）+ `parts.legs`（bare 细骨腿）+ `parts.torso`（dress，flare 4.5 / 4 撑成钟形）；颅骨、加长卷发双马尾、糖果发夹、骨臂、漩涡棒棒糖、红白条纹链、尖刺项圈、骨哨是本模块自画的部件（函数前标了「// 候选部件」）。
升级线：召唤师（`Summoner.js`）→ 糖果女孩，同一个骷髅小女孩：保留大圆颅骨 + 大眼窝、两侧长双马尾（更长、发梢卷成大卷，蝴蝶结换成糖果发夹）、狗链 + 项圈（换成糖果条纹链 + 带刺粉项圈）、胸前骨哨；加体量（高 28、钟形裙宽 16）、加武器（比人高的巨型棒棒糖）、加特效层次（地狱火裂缝 + 火焰狼头）。

- 名称 / 身份：糖果女孩，骷髅小女孩召唤师的华丽版，扛着巨型棒棒糖，把地狱犬从地缝里砸出来。脆弱：仍是孩童骨架、细骨腿。

- 尺寸：待机 28×28 格（含棒棒糖顶），裙摆宽 16。史诗、孩童蓬裙档，比召唤师大一圈。

  - 草莓粉蓬裙 [11, 13, 63, #ffc6de]，band 2；糖霜花边 / 糖面白 / 包装纸 / 草莓籽 `white` [7, 18, 17, 21]
  - 骨 `bone` [8, 7, 6, 17]（颅骨、骨臂、骨腿、白骨糖棍、骨哨）；灰白双马尾 `pale` [8, 59, 60, 17]
  - 糖面粉漩涡 / 发夹糖 / 项圈 [11, 13, 63, #ffc6de]；条纹链 `crimson` [11, 12, 13, 26] + `white`；项圈尖刺 `white`
  - 发光体：糖心 [12, 63, #ffc6de, 21]（平涂 5 档）、眼窝粉光 [0, 12, 13, 63]、骨哨孔 [12, 13, 63, #ffc6de]
- 部件顺序（从后往前）：远侧马尾 → 后骨臂 → 细骨腿 → 钟形蓬裙（+ 草莓籽）→ 颅骨 → 近侧马尾 → 两颗糖果发夹 → 骨哨 → 糖棍 → 糖面（糖心同部件）→ 后手（压在糖棍上）→ 条纹链 → 尖刺项圈 → 前骨臂 + 手。
- 细节清单：
  - 脸：同召唤师的骷髅圆颅（2×2 大眼窝 + 1 格粉光、鼻孔、牙排、颧骨暗格、颅顶高光）+ 1 格糖粉腮红；舔糖时下颌掉下 1 格、嘴里一格黑。

  - 服装：窄肩细腰胸衣 + 钟形蓬裙（裙撑、左右外扩 4–4.5 格）、白领、白糖霜花边下摆、裙面隔行点白草莓籽；胸前骨哨。
  - 手臂：骨臂 + 肘节 + 2×2 骨手 + 泡泡短袖；两手一上一下握糖棍（后手压在糖棍上）。
  - 腿脚：两根细骨腿，赤骨脚。
  - 武器：巨型漩涡棒棒糖（1 格白骨糖棍 + 半径 4.5 的糖面：两条粉 / 白螺旋臂按 spin 转、自动明暗、糖心发光）；手腕缠红白逐格交替的糖果条纹链，链尾一只粉色项圈（空心环 + 2 根白尖刺 + 骨牌）。

- 差异化（对照同组分配 + 已通过角色）：

  - 主色：草莓粉 + 糖霜白；同组没有粉色主材质（恐狼只在项圈点缀粉色，和她同源）。

## 特效设定卡

- 元素：糖浆地狱火 · 草莓粉，自建色阶 `candy` = 21 白 → #ffc6de 淡粉 → 63 粉 → #c23a6e 玫红 → 12 深红；裂缝和狼头的火用 `fire`（21 → 47 → 46 → 45 → 44）。
- 攻击「棒棒糖砸」
  - 预兆：棒棒糖抡到头顶身后，身体后仰，双马尾往前甩，糖心亮一档。
  - 出手：前冲 2 格 + 下蹲，粉色斩击弧（`fx.slash`，从身后上方到身前下方）2 帧，糖心亮到 2 档。
  - 命中：糖面砸地崩出糖渣——12 颗 candy 外爆 + 6 颗 impact + 5 颗带重力的 2×2 糖粒落地；假人大摇、震屏 1 格；`swing smash` + `hit wood`（硬糖）。
- 技能「召唤地狱犬」（蓄满法力后召唤恐狼）
  - 蓄力 1.4 s：棒棒糖立起举高，糖面漩涡越转越快（spin 按 3 → 12 圈 / 秒加速）、糖心 1 → 2 档闪；粉色糖粒（1 格 / 2×2 混合）从四周螺旋汇聚进糖心；裙摆被风吹鼓（后扬 2–3）、双马尾吹向后方、最后 0.3 s 抖；轮廓光 2 档、地面映光。
  - 施放 0.5 s：双手把棒棒糖往地上狠砸（糖面压进地里），砸点沿地面裂出两道地狱火裂缝（`fx.crack fire`）向前延伸 12 格、裂缝里火苗往上窜；汇聚糖粒外爆 + 16 颗 candy 外爆 + 6 颗糖粒上抛；震屏 2 格、天空闪白；`impact fire`。
  - 命中（施放 +0.25 → 0.33 s）：一只火焰狼头从裂缝尽头（假人脚下）跃出——先 2 帧深红剪影、再变实体（焦黑头骨 + 暗红火纹、白热眼、白牙、橙黄火鬃逐帧跳动）；成形那一帧 candy + fire 双色外爆 + 火焰冲击环 + 6 颗糖粒，粉色项圈「咔」扣上它的脖子（十字星芒），链子拉直牵着它；假人大摇 + 火边描边 0.7 s；震屏 1 格；`impact fire`。
  - 收招 0.7 s：狼头定 0.2 s 后按抖动消散，项圈落回地上滑回身前；棒棒糖从地上拔起回到肩前；糖心 2 → 1 → 0。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 眯眼，双马尾 / 裙摆反向甩；火花用 dust 骨灰色阶（亡灵）；震屏 1 格。
- 死亡（爆裂成糖）：26 颗骨灰火花 + 震屏 2 格 + 闪白 → 0.15 s 下蹲、身体鼓一下 → 0.4 s「啵」：身体炸成一堆糖果碎屑和小骨头（死亡套件 burst，chunk 3），12 颗 2×2 糖粒四散落地 + candy 外爆 + 闪白 + 震屏 2 格；棒棒糖单独留下，绕糖棍底端向前倒下，0.4 s 后落地裂成两半（两半各往外滑 2 格，扬尘 + `fall`）；双马尾（连着两颗糖果发夹）最后在空中悬一下，再左右晃着飘下来，落地摊成两条波浪长发 → 糖心熄灭 → 1.7 s 起碎屑、糖面、长发按抖动消散，魂光上升。
