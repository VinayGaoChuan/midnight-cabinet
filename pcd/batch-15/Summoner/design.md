# 召唤师 Summoner

模块：`pcd/chars/Summoner.js`。身体用部件库 `parts.rig`（child 档，头改 8×8）+ `parts.legs`（bare，1 格细骨腿）+ `parts.torso`（dress 短蓬裙）+ `parts.apron`（围兜）；骷髅颅骨、双马尾、蝴蝶结、骨臂、狗链、项圈、骨哨、破布狗尾巴是本模块自画的部件（函数前标了「// 候选部件」）。
升级线：召唤师 → 糖果女孩（`CandyGirl.js`），是同一个骷髅小女孩长大、打扮华丽了：保留灰白双马尾、狗链 + 项圈、胸前骨哨、骷髅大圆颅。

## 角色设定卡

- 名称 / 身份：召唤师，骷髅小女孩，牵着一条空狗链的召唤师——链子那头的「狗」要靠骨哨吹出来。脆弱：孩童体、细骨腿、没有甲。
- 一句话剪影：**大圆颅骨两侧一对垂到腰的灰白双马尾（紫蝴蝶结）+ 右手一条伸出身前 6 格、末端落地的空狗链和项圈**，裙后翘着一条破布狗尾巴。
- 尺寸：待机 27×23 格（颅骨 8×8，头身比约 3；双马尾甩出轮廓两侧各 3–4 格）。优质、孩童档。
- 材质色阶（色板下标 [勾线, 暗, 基, 亮]）：
  - 骨 `bone` [8, 7, 6, 17]（颅骨、骨臂、骨腿、骨哨；远侧手臂 / 腿暗一级）
  - 灰紫小裙 [25, 42, 54, 43]，band 2（大面积）；蝴蝶结 / 爪印 `purple` [25, 42, 24, 43]
  - 灰白双马尾 `pale` [8, 59, 60, 17]；围兜 / 裙花边 `white` [7, 18, 17, 21]
  - 铁狗链 [0, 28, 29, 30]；皮项圈 / 哨绳 `leather` [20, 19, 32, 33]；破布狗尾巴 `leather`
  - 发光体：骨哨孔 [39, 40, 23, 22]（平涂 5 档）、眼窝微光 [0, 39, 40, 22]（平涂）
- 部件顺序（从后往前）：远侧马尾 → 后骨臂（+ 泡泡短袖）→ 细骨腿 → 破布狗尾巴 → 短蓬裙 → 围兜（+ 爪印）→ 颅骨 → 近侧马尾 → 两只蝴蝶结 → 骨哨 → 狗链 → 项圈 → 前骨臂（+ 手、泡泡短袖）。
- 细节清单：
  - 脸：骷髅圆颅，2×2 大眼窝（窝里 1 格冰蓝微光，按档亮 / 灭）、鼻孔 1 格、一排亮暗相间的牙、颧骨和太阳穴暗格、颅顶高光；受击 / 死亡眯成一条缝。
  - 发：两条长双马尾，从发结往外甩 4 格再垂到腰，上段 2 格宽带发丝暗格、发梢 1 格亮，随 beard / sway 摆；两只 5×3 紫蝴蝶结（两翼 + 结 + 两条短飘带）。
  - 服装：灰紫短蓬裙（细腰 + 裙撑 + 白花边下摆）、白领、大号白围兜（挂脖带 + 腰后系带）、胸前紫色狗爪印（3 趾 + 掌垫）；裙后缝一条破布狗尾巴，末端两条布须，待机 / 移动时摇。
  - 手臂：1 格骨上臂 + 前臂 + 肘节高光 + 2×2 骨手，肩头套 2×2 泡泡短袖。
  - 腿脚：两根 1 格细骨腿，赤骨脚，前脚尖多 1 格。
  - 武器：空铁狗链（亮 / 暗 / 基逐格循环的链环，下垂成抛物线，碰地就平铺）+ 皮项圈（4×3 空心环 + 铁扣 + 骨牌）；颈上骨哨（3 格骨管 + 哨口 + 发光哨孔）。
  - 发光体：骨哨孔 5 档（待机 / 蓄力 / 蓄满 / 施放 / 熄灭）+ 眼窝微光（死亡熄灭）。
- 攻击方式：近战 **抽**（单手 × 抽 / 流星锤式）：狗链甩到身后头顶（预兆 1 帧）→ 出手帧前冲 2 格、链子横着拉直，项圈砸在假人身上 → 链子垂落到地、项圈落在身前 → 收回。站位 HX 72（链长够到 x 93）。
- 差异化（对照同组分配 + 已通过角色）：

  - 识别特征（≥2 改外轮廓）：①头两侧长双马尾 + 蝴蝶结（轮廓两侧、头顶）②伸出身前 6 格落地的狗链 + 项圈（轮廓前下）③裙后翘起的破布狗尾巴（轮廓后腰）④胸前骨哨、围兜狗爪印（内部）。

  - 动作个性：待机 = 吹骨哨（循环末尾 1.6–2.0 s 双手捧哨吹一下，哨口冒一圈冰蓝小波纹，双马尾一抖）；步态 = 拖链碎步（小碎步，狗链拖在身后、项圈在地上一蹦一蹭扬尘点，双马尾左右甩）；死亡 = 跌坐散骨（死亡套件 parts，power 0.35）。
  - 主色：灰紫小裙 + 骨白 + 灰白发；同组已用的主色是土黄 / 烟褐 / 军旗蓝 / 黑铁 / 墓石灰 / 花岗岩 / 酒红 / 赤红 / 孔雀青 / 紫黑纱 / 墨绿 / 灰白裹尸布。
  - 特效：声纹 + 结霜汇聚 × 甩链落环 + 爪印法阵 × 散骨拼狼 + 仰嚎冲击环，幽霜蓝；死灵法师（魂光蓝紫、骨弹）、死神（冥魂青白、镰弧）的召唤都不是「拼骨头的狼」。

## 特效设定卡

- 元素：猎犬召唤 · 幽霜蓝，色阶 `frost` = 21 白 → 22 冰青 → 23 青 → 40 钢蓝 → 39 深蓝；骨堆 / 散骨用 `bone` 色（8 / 7 / 6 / 17）点缀。
- 攻击「甩链抽」
  - 预兆：狗链甩到身后头顶，双马尾、衣摆往前甩，哨孔亮一档。
  - 出手：前冲 2 格，链子拉直横抽，冰蓝斩击弧（`fx.slash`，半径 15，从身后上方划到身前）2 帧。
  - 命中：项圈砸在假人上——10 颗 impact + 6 颗霜屑 + 小十字星芒，假人小摇；`swing smash` + `hit metal`。
- 技能「召唤猎犬」（蓄满法力后召唤灰狼）
  - 蓄力 1.4 s：双手捧起骨哨、后仰长吹（哨孔 1 → 2 档闪），冰蓝声纹一圈圈小弧从哨口往前扩；霜气定点螺旋汇聚进骨哨；0.3 s 起面前地面结霜（地面线冰青、下一行钢蓝隔点、冰晶尖冒出地面），0.5 s 起 13 块散骨（颅骨、颈椎、两段脊椎、三根肋骨、骨盆、四条腿骨、尾椎）逐块从霜里冒出（每块一小团霜），在霜地里一跳一跳；双马尾被吹向后方、最后 0.3 s 抖动；轮廓光 2 档、地面映光。
