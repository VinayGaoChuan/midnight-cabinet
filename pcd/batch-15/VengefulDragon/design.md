# 复仇之龙 VengefulDragon

## 角色设定卡

- 名称 / 身份：复仇之龙，死灵法师召唤的亡灵飞龙（中型召唤物），远程射手，普通品质。
- 一句话剪影：头戴三尖骨冠、一对破洞膜翼的腐肉翼龙，悬停在离地 8 格处，身后一串裸露的尾椎。
- 尺寸：待机约 49 × 28 格（含翼，身体约 30 格长 × 22 格高），离地悬停 8 格；比骨龙小一大圈。
- 体型档：悬浮 / 飞行（翼龙两足，前肢就是翼）。部件用 parts-beast 的 `B.quad`（dragon 头型，只画两条后腿，飞着时收在腹下往后伸）+ `B.wing` 膜翼。
- 材质色阶（色板下标 [勾线, 暗, 基, 亮]）：
  - 腐肉 skinDark [20, 19, 16, 15]（躯干 band 2，腿 / 头 band 1，远侧暗一级）
  - 翼膜 moss [0, 34, 35, 36]（和死灵法师长袍同色系）
  - 骨 bone [8, 7, 6, 17]（翼骨、肋骨、骨盆、尾椎、骨冠、下颌骨）
  - 眼窝魂光 [0, 0, 23, 22]、口中魂焰 [24, 23, 22, 21]（发光体，平涂）
- 部件顺序（从后往前）：腐肉滩（死亡时）→ 远翼 → 远侧后腿 → 尾椎 → 躯干（腐肉 + 露骨，一个部件）→ 近侧后腿 → 近翼 → 头（+ 露出的下颌骨）→ 骨冠。
- 细节清单：
  - 面部：dragon 头型；魂光眼 1 格 + 眉骨高光；口中常亮魂焰；下颌露骨（逐格骨白）；张嘴见牙。
  - 头饰：三尖骨冠——贴着颅顶一圈骨箍，三根骨尖间隔 2 格以上，中间最高、高出头 3 格（和死灵法师同款）。
  - 躯干：前上半身暗褐腐皮，两个腐肉烂洞（墨色 + 洞里露一点骨）；下半腹一排外露肋骨（肋间暗，蓄力时透魂光）；4 根肋骨尖戳出腹线；臀上露骨盆 + 闭孔；颈背一排椎棘。
  - 翼：B.wing 膜翼（翼展 18、3 根翼指）+ 打洞画笔，三段指间膜各破一个洞，翼骨裸露、拇指爪。
  - 尾：一串裸尾椎（粗节 + 暗关节 + 棘突），末端挂一缕随尾甩的腐皮。
  - 腿：两条后腿，爪脚（骨白爪尖）。
- 攻击方式：远程（射 · 口吐）：扑翼后仰头，吐出一颗魂焰弹直线飞向目标。
- 差异化：
  - 体型档：悬浮翼龙（本组唯一悬停的龙；骨龙是贴地四足，天龙是蛇身驾云、毒龙 / 翡翠龙是地面四足）。
  - 识别特征：①三尖骨冠（改轮廓，头顶三个尖）②破洞膜翼（改轮廓，扑翼时伸出身体上下各 8 格）③戳出腹线的 4 根肋骨尖 + 裸尾椎串（改轮廓）。
  - 武器 + 握法 + 攻击类型：无持械 · 口吐 · 射（单发魂焰弹）；骨龙是光束吐息，同组人形射手用弓 / 徒手法球。
  - 待机个性：滴涎甩头——下颌半张，魂光涎液从嘴角滴落，循环末尾（1.8–2.2 s）甩一下头把涎液甩出去。
  - 步态：扑翼飞行——4 帧沉重扑翼（上扬 → 平展 → 下压 → 回收）+ 上下飘 2 格，身下掉 1 颗腐绿尘粒，地面画影子。
  - 死亡方式：坠落——翼一垂失控坠地（离地 8 → 6 → 4 → 3 → 2 → 1 → 0），落地腐肉溅开成一滩，骨架摊平后魂光离体上升。
  - 主色：腐肉暗褐 skinDark（同组没有别人用），翼膜墓苔绿、骨白、魂光蓝紫点缀。

## 特效设定卡

- 元素色阶：亡灵吞噬 · 魂光蓝紫 FXI.soul = 22 → 23 → 24 → 25 → 3（和死灵法师同一色阶）；回血十字用 blood 第 2、3 级（57、56）；腐绿尘粒 rotMote [37, 36, 35, 34, 0]；落地腐肉块 rotFlesh [15, 16, 19, 20, 0]；受击骨屑 boneDust [21, 17, 6, 7, 8]。
- 攻击「魂焰弹」：
  - 预兆：翼上扬、仰头后引 2 帧（口中魂焰亮一档，轮廓光 1）。
  - 出手：翼下压、头往前一甩、下颌张到 3，定格；口边 3 格喷口光 2 帧 + 6 颗魂光火花。
  - 弹道：3×3 魂火 + 白芯 + 往后上方飘的火尾，150 格/秒，魂光拖尾，地面映光。
  - 命中：12 颗魂光外爆 + 小冲击环，假人小摇。
- 技能「吞噬回血」（desc：击杀敌人时恢复自身生命值）：
  - 蓄力 1.4 s：悬停后退 1 格、下颌逐级张到最大，魂焰粒子在喉口螺旋翻涌（口中发光 2 → 3 档），腹侧外露的肋骨间透出魂光（rib 1 → 2），轮廓光 2 档，地面映光；最后 0.3 s 身体抖动。
  - 施放 0.5 s：收翼俯冲（第 1–2 帧离地 6 → 4，冲出 40% → 80%），第 3 帧扑到目标身上一口咬住：上下两道牙弧往嘴尖合拢的咬合拖影 2 帧，从目标身上撕下一大团魂光（5×5 魂团叼在嘴里抖动），假人染魂光色 + 大摇，冲击环，震屏 2 格 + 天空闪白；之后往回撕扯（后退 2 格）。
  - 命中 / 收招 0.7 s：魂光以胸腔为圆心沿脖子卷进胸口（K_SPIRAL_PT 沿颈），腐肉上的两个烂洞逐帧合拢（3 → 0），胸口浮起暗红治疗十字（blood 第 2 级十字 + 第 3 级尖，旁边一枚小十字）+ 暗红外爆，然后扑翼飞回原位。
- 受击：enemy 来袭 → 白色剪影 1 帧 + 击退 2 格 + 闭眼 + 翼一扬、尾反甩；骨屑（boneDust）火花 + 少量魂光；震屏 1 格。
- 死亡：26 颗骨屑 + 震屏 2 格 + 闪白 → 翼垂落、头前栽，离地 6 → 4 → 3 失控坠落 → 侧躺落地（2 → 1 → 0），腐肉块溅开 16 颗 + 尘土 12 颗 + 震屏 1 格，身下摊开一滩腐肉（带碎骨）→ 0.95 s 一团 3×3 魂火从胸口离体上升，一路魂光粒子 → 1.6–2.4 s 自上而下消散。发光体（口中魂焰、眼光）落地前熄灭。
- 音色：湿漉漉的腐皮扑扇声 + 魂焰喷吐的闷响「噗轰」+ 咬合时骨牙的咔嚓，重量 0.55。
  - SFX 声明：`{ body: 'beast', how: 'collapse', pal: 'shadow', style: 'shadow', w: 0.55, hover: 1 }`
  - 关键帧：移动 `step`（扑翼下压那一拍，w 0.3）；攻击出手帧 `swing`（bite）+ `shoot`（fire）；弹道到达 `hit`（flesh）；施放咬合帧 `hit` + `impact`（shadow）；收招回血 `impact`（blood）；落地 `fall`。
