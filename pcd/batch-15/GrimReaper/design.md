# 死神 GrimReaper

模块：`pcd/chars/GrimReaper.js`。身体用部件库拼：`parts.rig`（giant，leg 14 / torso 16 / head 8 / hunch 4 / arm 17 / sw 6）+ `legs bare`（骨腿）+ `torso robe`（裹尸布）+ `arm loose` + `hand big`。自画部件（函数前标了「// 候选部件」）：`boneWings` 骨翼领、`reaperSkull` 8×8 骷髅头、`dragonCrown` 骨龙冠、`dragonScythe` 巨型龙颅镰（镰头按 90° 换朝向）、`hourglass` 魂光沙漏（正放 / 横放 / 翻过来三态）；死亡用的 `shroudHeap` 塌成堆的裹尸布（三档）、`ribCage` 裹尸布下的脊椎 + 肋骨 + 骨盆、`bonePile` 按落下顺序叠在布堆上的骨头。死亡不用引擎死亡套件，直接画进精灵（动作表和 sprite.json 里都有）。
升级线：死灵法师 → 死神，保留并升级三件识别物：龙颅杖 → 龙颅镰（杖顶的小飞龙头骨长成镰座，刃从龙颅口中伸出）；肋骨立领 → 一对收拢的龙翼骨架；三尖骨冠 → 骨龙冠（多一对后掠龙角）；魂灯换成沙漏；魂光色阶两级共用，死神多一层冥霜白。
