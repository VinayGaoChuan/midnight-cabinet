依据：暗影死神 · 虚空 · 刺客（「该职业擅长爆发攻击，但很脆弱。」）· 史诗 · 近战 304；描述「不再拥有秘密贮藏，但是其属性大幅提升。」；特性 不屈之魂「闪避率增加20%，闪避成功，永久获得10点最大生命值和1点攻击力，从第11关开始，效果翻倍」（一句话「常常闪避，每次闪避都变强」，fx 成长）；由维京海盗进化。

# 角色设定卡

- 名称 / 身份：暗影死神，维京海盗死后被虚空吞掉又爬回来的样子（部队，史诗，刺客）。
- 一句话剪影：弯过头顶的巨大镰刀 + 兜帽外歪戴的锯齿破三角帽 + 往后拖的烟雾下摆（没有腿）。
- 尺寸：待机约 28×37 格（身体约 34 格 + 镰刃），瘦高悬浮档：parts.rig `tall`（torso 10、sw 3 窄肩、arm 11 细长臂），腰以下没有腿，离地 2 格飘着。
- 材质色阶：
  - 斗篷 墨黑褴褛 [0, 52, 8, 9]（band 2；ink 纯黑没有明暗，改用最暗的三级，勾线仍是 0 墨）；内衬、前襟、袖口 [0, 39, 40, 59]（海盗外套的褪色墨蓝）
  - 烟雾下摆 [0, 52, 53, 54]（暗影紫）；兜帽里的脸 [0, 0, 52, 52]（看不见五官的暗）
  - 手骨、颌骨、柄尾 bone；镰柄 iron；镰刃 steel；三角帽 [0, 20, 20, 19]（海盗那顶）；眼罩皮带 [0, 20, 19, 19]
  - 发光体：鬼火独眼 [25, 24, 43, 21]、镰刃紫光 [25, 42, 24, 43]、镰柄鬼火 [25, 24, 43, 21]（都 flat）
- 部件顺序（从后往前）：破边披风（tattered）→ 烟雾下摆（候选部件 smokeHem）→ 后臂 → 长袍（robe，墨蓝前襟）→ 兜帽后层 → 头（暗脸 + 眼罩 + 独眼 + 颌骨，同一部件）→ 兜帽前檐 → 三角帽（往后歪 1 格、挖成锯齿）→ 镰刀（候选部件 scythe：柄 + 鬼火 → 刃）→ 后手骨 → 前臂 + 手骨。
- 细节清单：
  - 脸：兜帽阴影里一只紫色鬼火独眼、推到眉上的眼罩 + 斜皮带、下颌骨两颗牙（骷髅对应物）
  - 头饰：兜帽鸟喙前檐 + 垂布、锯齿破边三角帽
  - 服装：长袍外扩下摆 + 波浪下摆、墨蓝前襟镶边、领口、背后破边披风（3 格缺口）
  - 下摆：烟雾逐行变窄往后偏，边缘缺格、下半截透空成一缕缕，两缕烟尾贴地往后拖，按相位翻卷
  - 手臂：宽袖、墨蓝袖口、骨手
  - 武器：镰刀（铁柄、骨质柄尾、刃背亮 / 刃身 / 刃口紫光、钩尖），柄上鬼火 1 簇（施放后 2 簇 = 成长标记）
  - 发光体：独眼 5 档 + 镰刃紫光按档亮 + 鬼火闪烁；死亡熄灭档
- 攻击方式：近战「劈」：举镰过头 → 残影一闪瞬移 12 格到目标面前（原地留暗紫剪影抖动消散）→ 镰刀过头下劈，镰柄横平、刃垂下砍在目标头顶 → 飘回。
- 差异化（对照同族 / 升级前）：
  - 体型档：瘦高悬浮档（没有腿、烟雾下摆）；海盗是瘦削微驼的步行档。同批人形里没有悬浮体。
  - 识别特征：①镰刃弯过头顶（改变外轮廓）②锯齿破三角帽（改变外轮廓）③往后拖的烟雾尾（改变外轮廓）④鬼火独眼（发光体）。
  - 武器 + 握法 + 攻击类型：双手镰刀，劈（瞬移下劈）。
  - 待机个性：转镰——镰刀在手里慢慢转半圈再转回，独眼鬼火一明一灭，下摆烟雾翻卷。
  - 步态：贴地滑行——不迈步，身体前倾平移，下摆后拖、一路掉暗影烟。
  - 死亡：塌落化烟——失去浮力落地，斗篷像空了一样塌成一堆布，三角帽压在布堆上，镰刀插在旁边地上，独眼在布堆里闪几下熄灭，布堆化成暗影烟升起。
  - 主色：墨黑斗篷 + 暗影紫烟 + 墨蓝内衬 + 紫光。
- 与升级前（维京海盗）的呼应：三角帽、眼罩、墨蓝内衬保留；铁钩长成镰刀（刃形就是放大的钩）；刺客职业从剪影读出：瘦、窄肩、巨大单件兵器、瞬移。

# 特效设定卡

- 元素色阶：暗影紫 shadow = 43 淡紫 → 54 → 53 → 52 → 0 墨；成长时魂光 soul（22 → 23 → 24 → 25 → 3）点缀。
- 攻击：预兆 = 举镰过头、刃光 1 档（2 帧）；出手 = 瞬移：原地留下举镰那一帧的暗紫剪影（0.25 s 抖动消散），暗影拖线，本体闪白 1 帧出现在目标面前；挥砍弧（半径 17，从头后到身前）；命中 = 目标头顶十字星芒 + 暗影外爆 14 颗 + impact 6 颗，目标大摇。
- 技能「不屈之魂」：
  - 蓄力 1.4 s：0.3 s 起身体化影成半透明暗色剪影（隔点透空、逐帧换相位抖动 1 格），暗影烟往上飘；0.62 / 0.9 / 1.16 s 三发敌弹（enemy 色阶）从正面射来直接穿过残影，穿过处溅出暗影碎点。
  - 施放 0.5 s：本体在一旁（后退 8 格）现身并闪白；被穿过的残影留在原地碎掉（剪影抖动消散 + 魂光外爆）；30 颗魂光 / 暗影光点螺旋吸回身体；轮廓光 3 档（从独眼打出来）、镰柄上多点亮一簇鬼火；暗紫冲击环、十字星芒，震屏 2 格，天空闪白。
  - 命中（施放 0.25 s）：随手一挥，假人身上一记十字斩（两道交叉斩光 + 十字星芒 + 暗影外爆 28 颗 + 小冲击环），目标大摇，震屏 1 格。
  - 收招 0.7 s：镰刀转回肩上，飘回原位，两簇鬼火保持亮着，独眼 3 → 2 → 1。
- 受击：impact 10 颗 + 暗影碎点 8 颗 + 白色剪影 1 帧 + 击退 2 格 + 独眼闭上 + 帽子后甩 1 格 + 烟雾下摆大幅后甩。
- 死亡：火花 + 暗影碎点 + 震屏 2 格 + 闪白 → 失去浮力（离地 2 → 1 → 0，身子矮下去）→ 塌成半堆 → 摊平的布堆 + 镰刀插在地上（刃光熄灭、鬼火熄灭）→ 落地尘土 14 颗 → 独眼在布堆里闪几下熄灭 → 自上而下消散，暗影烟 + 魂光上升。
- 音色：破布鼓风的呼呼 + 镰刃刮擦的长鸣 + 一声空洞的叹息，重量 0.4。SFX 声明 `{ body: 'ghost', how: 'collapse', pal: 'shadow', style: 'shadow', w: 0.4, hover: 1 }`（悬浮，不发 step）；swing slash、hit flesh / metal、impact shadow、fall。
