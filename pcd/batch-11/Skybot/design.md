# 角色设定卡 · 天空机器人 Skybot

- 名称 / 身份：天空机器人，脉冲机器人升级后的飞行战斗机甲，虚空一方的近战战士（输出 + 简单防御）。
- 一句话剪影：身体前倾的高大悬停机甲 + 背后一对展开成 V 的后掠三角钢翼（后缘喷口）+ 两根加长的电极天线 + 带散热鳍的活塞拳，腿换成两只向下喷火的推进器。
- 尺寸：约 43 格宽 × 43 格高（含天线与翼尖），神话档；体型档「高大悬停机甲」：悬停基准比骨架再抬 2 格（喷口底离地 6 格）、肩行 18 格宽、身体常态前倾 1 格；比脉冲机器人高 10 格、宽一半。

- 升级线（同一台机器进化了）：保留 两根天线（加长成电极、顶端跳电弧）、活塞拳（加散热鳍 + 拳背火焰喷口）、胸口圆形紫色脉冲核心、钢盔目镜 + 2 格紫眼、肩甲下沿的警示条（金 → 深红）；背包换成钢翼的翼根，腿换成推进器。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 抛光钢蓝装甲 armor = steel [27, 28, 29, 30]（band 2，大块躯干）；抛光高光件 polish = [27, 29, 30, 31]（肩甲、拳指虎、翼前缘）
  - 钢翼 wing = steel；推进器 / 喷口 iron [0, 27, 28, 29]
  - 警示条 crimson [11, 12, 13, 26] 与 ink 交替
  - 发光体：核心 core = purple（flat）、白芯 glow、目镜 eye；喷口蓝焰 jetB = [40, 23, 22, 21]、橙焰 jetO = fire [44, 45, 46, 47]；电极 arc = [40, 22, 22, 21]

- 细节清单：
  - 脸：钢盔、盔顶深红短脊、目镜缝 + 2 格紫眼（受击 / 死亡熄灭）。
  - 「毛发」对应物：两根电极天线（尖端随动作甩、跳电弧时顶端变白）、翼尖（悬停时上下摆 1 格）、推进器火焰（逐帧闪烁 2–4 格）。

# 特效设定卡

- 元素：电磁脉冲 · 电青，主色阶 bolt（FXI.bolt：白 21 → 淡金 51 → 青 22 → 蓝 23 → 深蓝 40）；溅射 / 喷焰用 fire（FXI.fire），爆炸烟用 dust。
- 攻击「俯冲冲撞」
  - 预兆：拉升 3 格、后仰、拳收到肩后；喷口转橙、拳背喷口点火。
  - 出手：整机前冲 3 格 + 下沉；身后 2 帧电青速度线；内杆伸出 3 格。
  - 命中：拳尖火焰小外爆（火焰占卜的溅射，14 颗 fire，两侧各甩出 4 颗落地余火）+ 电青小冲击环 + 十字星芒；假人闪白小摇。
- 技能「火焰占卜 + 电磁脉冲」（每一拳既溅射、又压 3 层防御减益）
  - 蓄力 1.4 s：升高 4 格、拳举到肩后上方；背翼 / 推进器喷口 0.7 s 后由蓝转橙；两根天线之间的电弧越跳越密（fx.bolt，从每 5 帧一道到每 2 帧一道）；拳背喷口点火（2 档）；电青火花螺旋收拢到拳背喷口；轮廓光 2 档。
  - 施放 0.5 s：整机俯冲 2 格、下沉 5 格、直拳砸下，拳头停在假人身前；拳头落点炸开火焰 nova（fire 外爆 36 颗 + 大冲击环 + 十字星芒）；震屏 2 格 + 天空闪白。
  - 命中：3 道电青冲击环依次从目标身上扩散（3 层减益，每层一次 impact）；每层一条短电弧锁住目标（fx.bolt）；假人电青描边 + 摇晃变慢（防御降低）；目标周围地面余火持续燃烧。
  - 收招 0.7 s：喷口回蓝、拳背熄火，拉升回原高度、退回站位。
- 受击：金属：impact 22 颗 + 4 颗长寿命白火星；白剪影 1 帧、击退 2 格并被顶高 1 格、目镜熄灭、电极向后甩、喷口火焰一瞬熄小；震屏 1 格。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 喷口熄火 → 坠落 8 帧：每 2 帧换一次朝向（正 → 镜像 → 正 → 镜像）、每次切换前后倾 ±1 格，两只熄火喷口各拖一串烟（dust）→ 落地那一帧→ 落地爆炸：火焰外爆 + 大冲击环 + 烟团 + 死亡套件 burst 金属碎片四散弹跳 → 抖动消散 + 魂光上升。
