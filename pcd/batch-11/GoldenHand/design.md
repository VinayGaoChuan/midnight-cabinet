# 金手 GoldenHand

模块：`pcd/chars/GoldenHand.js`（身体用部件库拼：`rig(fat) arm(bell / plate + 肩甲 + 钢护腕) legs(shoe) torso(robe) head(round) beard(mustache) hand`；模块里自画的部件：巨金手 `goldHand`（4 种手形 + 铅灰褪色）、腕下金链宝匣 `chainBox`、背后金算盘框 `backAbacus`、升级版瓜皮帽 `skullcap` + 帽后金飘带、倒地后的算盘 / 宝匣，前三个标了「候选部件」）。
升级线：地主 → 金手是**同一个人**进化了：瓜皮帽 + 虚空帽珠（变成拳头大）、八字胡、圆脸双下巴 + 腮红、算盘（改成背在身后的金算盘）都保留；钱袋换成金链宝匣，右臂整条换成鎏金机关手，体量大一圈。

## 角色设定卡

- 名称 / 身份：金手，敢赌的虚空大富商（史诗：拳头大的发光帽珠、金飘带、锦袍团花、鎏金机关手）。
- 一句话剪影：**右侧巨大的鎏金机关手（伸出身体 10 格、比头大）+ 背后高出头顶的金算盘框 + 帽顶拳头大的虚空珠**。
- 尺寸：待机 32×35 格（算盘框顶到脚 33 格）；体型 `fat`（leg 7 · torso 10 · head 7 · headW 7 · sw 6 · belly 4），比地主高 6 格、肚子更大，全程 `lean 1` 被金手压得向右倾。
- 材质色阶（全部取自 64 色共享色板，没有新增颜色；自建特效色阶 `lead` 也只用共享钢色 30 / 29 / 28 / 27 / 0）：
  - 锦袍 酒红 `crimson`（band 2）+ 金前襟 / 金腰带 / 下摆金边 / 立领 `gold` + 暗金团花点；裤 `shadow`；鞋 墨黑
  - 肤 `skin` · 腮红 `pink` · 八字胡 [0, 27, 27, 28]
  - 瓜皮帽 深紫 [0, 25, 42, 24] + 金帽檐 + 金珠座；帽珠（发光体）flat [25, 24, 43, 21]，蓄满 / 施放 flat [24, 43, 21, 21]；帽后两条金飘带
  - 金手 `gold` + 钢关节 `steel`（手腕一列、指节铆钉）；指缝金光（发光体）flat [20, 5, 21, 21]；亏损后的铅灰 [0, 28, 29, 30]
  - 背后金算盘 `gold` + 深红珠 `crimson`；宝匣 `gold` + 红宝石 `blood`
- 部件顺序（从后往前）：背后金算盘框 → 后臂（喇叭袖）→ 腿 → 锦袍（团花、金边、立领）→ 后手（扶肚子）→ 帽后金飘带 → 头（圆脸、腮红、双下巴、八字胡）→ 瓜皮帽 → 帽珠 → 金手臂（圆肩甲 + 鎏金臂甲 + 钢护腕）→ 巨金手 → 腕下金链宝匣 / 抛起的金币。
- 细节清单：
  - 脸：眼（1 格墨，掂金币时往上看）、小鼻尖、嘴（笑时变宽）、腮红、耳、双下巴、八字胡（和地主一样）。
  - 头饰：金帽檐 + 紫缎帽身 3 行（缝线、高光）+ 金珠座 + 3×3 帽珠 + 顶尖；帽后两条金飘带，飘带尖随 `beard` 反甩。
  - 服装：锦袍暗金团花（每 3 行一排、错位）、金前襟、金腰带、下摆金边、立领、后褶。
  - 手臂：左手喇叭袖 + 金袖口；右臂鎏金圆肩甲（钢边）+ 板甲臂 + 钢护腕。
  - 金手：约 11×8 格（手腕一列钢关节、指节钢铆钉、手指分缝、左上高光、指尖暗一级），4 种手形：半握（手指垂下）/ 握拳 / 张开掌心向上（拇指竖起）/ 弹指（食指伸直）。
  - 背后金算盘：9×21 格的竖框，框角外翘，里面是空的（像光环框），每 3 行一道横档、档上两颗深红珠。
- 攻击方式：远程 **射**：金手抬到胸前屈指（预兆）→ 弹指定格（食指伸直、指尖金色十字光）→ 金币 260 格/秒直线高速射出（正面 / 侧边交替 + 两格金色拖影）。
- 差异化：
  - 体型档：高胖富商 + 右侧巨型异形肢体（身体右倾）；和地主（矮胖、左右对称）、屠夫领主（桶腹巨汉、剁骨刀）、奴隶主（宽肩重甲）拉开。
  - 识别特征（≥ 2 个改外轮廓）：①右侧鎏金机关巨手，伸出身体 10 格（轮廓）②背后高出头顶的金算盘框（轮廓）③拳头大的帽珠 + 帽后金飘带（轮廓）④腕下晃荡的金链宝匣（轮廓）。
  - 武器 + 握法 + 攻击类型：**徒手（机关手）弹指** + 射；已通过角色里的射手是长弓 / 发条铳，金手没有武器，弹的是金币。和地主的「甩腕投铜钱」（投）也拉开。
  - 动作个性：待机 = 掂金币（张开金手把一枚大金币抛起 11 格再接住，眼珠跟着往上看，接住时一笑）；步态 = 歪斜踱步（接触 A 重：身子顿一下、金手下沉、3 颗尘、重的脚步声；接触 B 轻：1 颗尘）；死亡 = 前扑碎裂（金手先砸地单膝跪 → 前扑 → 金手从指尖一段段褪成铅灰 → 碎成几块，帽子滚开，金算盘摔平在身后）。
  - 主色：酒红锦袍 + 大块鎏金（已通过角色里奴隶主 / 屠夫领主没有大面积金，维京战士是靛蓝，地主是紫）。
  - 特效：鎏金豪赌（巨币砸地 + 一半熄灭一半飞回），和地主的金币喷泉（从钱袋上抛、落地弹跳、吸回袋里）在蓄力 × 施放 × 命中三段都不同。

## 特效设定卡

- 元素：豪赌 · 鎏金，色阶 `FXI.coin` = 白 21 → 奶油 5 → 金 14 → 暗金 61 → 深木 20；帽珠火星用虚空紫 `curse`；亏损碎块用 `lead`（30 → 29 → 28 → 27 → 0）。
- 攻击「弹指金币」
  - 预兆：金手抬到胸前握拳屈指 1 帧。
  - 出手：弹指定格（食指伸直），指尖金色十字光 2 帧 + 6 颗金星。
  - 弹道：3×3 带孔金币 / 1 格侧边交替 + 2 格拖影，260 格/秒，金色拖尾。
  - 命中：10 颗金币外爆 + 十字星芒，假人闪白小摇。
- 技能「激进投资组合 · 豪赌」
  - 蓄力 1.4 s：金手握拳举到脸边（最后 0.3 s 逐帧抖），指缝里的金光材质按 1 / 2 档亮起、拳前沿漏出几道短光芒；四周金币点螺旋汇聚到拳心；帽珠 1 / 2 档逐帧闪、轮廓光 2 档（光源在金手）、地面映光。
  - 施放 0.5 s：金手张开向前抛（掌心向上），拳心汇聚的金点外爆 + 14 颗金火花 + 十字星芒；一枚 5 格巨型金币（正面带方孔 → 斜 → 侧边 → 斜）划弧线抛到身前 36 格，0.3 s 后旋转砸地——金色大冲击环 + 两道地裂 + 十字星芒 + 金 / 尘外爆，震屏 2 格；施放第一帧天空闪白。
  - 命中：巨币碎成 24 枚小金币——12 枚从色阶第 4 级起步（暗金 → 深木）向上弹飞后熄灭（亏损），12 枚螺旋飞回金手（盈利）；收招开头身后两道金色速度线（「卖空」加速），拉长再断开。
  - 收招 0.7 s：金手收拳，帽珠闪一下（施放档 1 帧）。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼 + 八字胡 / 飘带反甩，金手张开向后甩；impact 16 颗；震屏 1 格。
- 死亡：26 颗 impact + 震屏 2 格 + 闪白 → 踉跄 → 金手先砸地、单膝跪（尘土 + 小地裂 + 金属闷响）→ 前扑倒地（离地 3 → 1 → 0）→ 尘土 16 颗、宝匣摔落、金算盘平摔在身后 → 甩在头前的金手从指尖起每 0.12 s 褪一段铅灰（亏损）→ 1.25 s 碎成 9 块 2×2 的铅灰碎块弹落 + 尘 → 瓜皮帽翻滚着滚到前方 → 帽珠闪 3 次熄灭 → 1.6–2.4 s 自上而下消散 + 魂光上升。
- 音色：沉重金属手指咔嗒 + 巨币旋转嗡鸣后落地一声「铛」，重量 0.6（`SFX: body flesh · how topple · pal coin · style coin · w 0.6`；`step` 在接触帧（重步 0.7 / 轻步 0.35）、`swing throw` + `shoot coin` 在弹指帧、`hit metal` 在金币到达和死亡时金手砸地、`impact coin` 在巨币砸地、`fall` 在前扑落地帧）。
