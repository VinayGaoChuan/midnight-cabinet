# 角色设定卡 · 脉冲机器人 Pulsebot

- 名称 / 身份：脉冲机器人，虚空一方的矮壮步行机甲，前排先锋（防御）。
- 一句话剪影：矮方箱 + 肩上两根竖天线（顶灯）+ 比头还大的液压活塞拳 + 背后方形电池背包冒烟。
- 尺寸：约 27 格宽 × 28 格高（含天线），稀有档；体型档「矮壮方块机甲」：腿只有 6 格、躯干 12 行方箱、宽肩（肩行 15 格宽），头只露出肩上 4 行（头嵌在肩里）。
- 骨架：`parts.rig(P, { body: 'stocky', leg 6, torso 11, head 5, headW 7, sw 7 })` 给出胯行、肩行、步态落脚点；机械部件全部是本模块的候选部件（库里没有机甲部件）。
- 材质色阶（[勾线, 暗, 基, 亮]）：
  - 花岗岩装甲 gran = [0, 9, 10, 18]（stone 色阶提亮一级，band 2；大块躯干）
  - 石质外壳板 shell = [0, 10, 18, 17]（技能时合拢的装甲板）
  - 关节 / 液压 joint = steel [27, 28, 29, 30]；活塞内杆 rod = [27, 29, 30, 31]
  - 警示条 gold [20, 19, 14, 5] 与 ink 交替斜纹
  - 发光体：核心 core = purple [25, 42, 24, 43]（flat）、白芯 glow = [43, 43, 21, 21]、目镜 eye = [25, 42, 43, 21]
- 部件顺序（从后往前）：后天线 → 前天线 → 电池背包（排气管 + 3 格电量灯）→ 后臂 + 后拳（暗一级）→ 远侧腿 → 近侧腿 → 方箱躯干（胸口圆形脉冲核心嵌在同一部件）→ 头盔（目镜缝 + 2 格紫眼）→ 前臂（上臂 + 肘球 + 液压筒 + 伸出的内杆）→ 前肩甲（金黑警示条下沿）→ 活塞拳 → 技能外壳板。
- 细节清单：
  - 脸：钢盔 + 1 行目镜缝 + 2 格发光紫眼（受击时熄灭），盔顶小脊。
  - 「毛发」对应物：两根天线（顶灯按节拍闪，尖端会随动作甩）。
  - 躯干：肩行加宽、竖分缝 + 横分缝、花岗岩斑点、胯下一圈金黑警示斜纹、胸口 5×5 圆核心（钢圈 + 紫芯 5 档）。
  - 手臂：大肩甲（铆钉 2 颗 + 警示条下沿）、肘球关节、液压筒（金色箍）、可伸出 5 格的抛光内杆。
  - 拳：7×6 石拳 + 前 2 列钢指虎（3 道指缝）+ 金黑腕带。
  - 腿脚：液压胯关节 + 石甲小腿 + 宽脚掌、钢包头；远侧腿暗一级。
  - 背负：6×11 电池背包，排气管（喷汽时盖子弹起 1 格）、3 格电量灯跟随核心亮度。
- 攻击方式：近战「冲拳」——后引蓄势（下蹲 1、拳收到胸前）→ 出手帧前冲 2 格、液压筒弹出 5 格直拳（速度线拖影）→ 命中处炸开一圈冲击波。
- 差异化：
  - 体型档：矮壮方块机甲（同组唯一的步行机甲；和虚空的曲速之翼 / 虚空魟的扁平飞行、歼灭者的高瘦反关节鸟腿、爬行投石车的多足都拉开）。
  - 识别特征：①肩上两根竖天线（改外轮廓，升级线保留）②比头还大的活塞拳（改外轮廓）③背后方形电池背包 + 排气管（改外轮廓）④胸口紫色脉冲核心（轮廓内）。
  - 武器 + 握法 + 攻击类型：徒手（机械拳）× 冲拳（前伸直拳）——组内没有别的徒手直拳；北极熊是肩撞、黑熊是人立双掌砸。
  - 待机个性：核心按节拍一亮一灭、天线灯跟着闪；循环末尾（1.6–2.0 s）排气管喷一口蒸汽、盖子弹起、身体一顿。
  - 步态：机械重步——接触帧下沉 1 格、天线一甩、3 颗尘土 + 一小口液压蒸汽。
  - 死亡方式：散架——肩甲、天线先崩掉，头盔弹飞滚到身后，跪地后胸口核心闪三下、一声小爆，剩余部件按部件散落成堆（死亡套件 parts）。
  - 主色：花岗岩灰（偏紫灰的石色），点缀钢蓝关节、紫核心、金黑警示条；同族虚空角色主色分别是天青、品红紫、焦黑枪铁、暗红漆、焦黑旧木、漂白旧木，不重复。
- 音色：液压嘶嘶 + 厚重金属踏步 + 一声低频「嗡——」脉冲，重量 0.85。

# 特效设定卡

- 元素：花岗岩皮肤 · 岩灰钢蓝，主色阶 steel（FXI.steel：白 21 → 31 → 30 → 29 → 28）；碎屑用 earth / dust（灰色石屑），核心闪光借 curse 紫（只点缀核心）。
- 攻击「脉冲冲拳」
  - 预兆：下蹲 1 格、拳收回、核心 1 档。
  - 出手：前冲 2 格 + 液压内杆弹出 5 格；拳后 2 帧速度线（steel 1→3 级）；肘部喷一小口液压汽。
  - 命中：拳尖钢色小冲击环 + 十字星芒 + impact 火花 12 颗 + 两道短地裂（范围伤害）；假人闪白小摇 + 紫色描边 0.7 s（防御减益）。
- 技能「花岗岩皮肤」（被动特性表现为生效的样子）
  - 蓄力 1.4 s：摆出双拳护胸的防守姿（下蹲 1）；从 0.25 s 起每 2 帧翻出一块石质装甲板（盔顶、背板、胸板、胫甲、后腰、后肩共 6 块），每块先外翻 2 格再合拢并迸出钢色火花；灰色石屑螺旋收拢到胸口核心；核心 1→2 档闪、最后 0.4 s 到 3 档；轮廓光 2 档（核心在剪影内部，rimAll）。
  - 施放 0.5 s：装甲锁死一震（下蹲 2 定格）；钢蓝点阵护盾（fx.dome）按角度逐点亮起罩住自己；大冲击环 + 核心十字星芒 + 钢色外爆；震屏 2 格 + 天空闪白。
  - 命中：三发敌弹先后打在护盾上——被打的那一段护盾变白，敌弹碎成灰色石屑（dust 色阶，带重力落地），本体纹丝不动。
  - 收招 0.7 s：装甲板一块块退回，护盾点阵断续熄灭，核心 2→1→0。
- 受击：金属 + 石：impact 22 颗 + 4 颗长寿命白火星 + 灰色石屑落地；白剪影 1 帧、击退 2 格、目镜熄灭、天线向后甩；震屏 1 格。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 踉跄下蹲、肩甲与天线崩落（石屑）→ 头盔弹飞、翻滚到身后 → 双膝砸地（尘土 + fall）→ 核心闪三下 → 小爆（紫 + 钢火花、小冲击环）→ 死亡套件 parts 散架成堆 → 抖动消散 + 魂光上升。
