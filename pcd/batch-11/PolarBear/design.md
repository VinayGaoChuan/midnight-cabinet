# 北极熊 PolarBear

模块：`pcd/chars/PolarBear.js`（`pcd/view.html?c=PolarBear`）。身体全部用 `parts-beast.js` 的 `quad` 骨架（`head bear · foot pad · tail stub · hump 2.5`）；模块自己画树苗（候选部件 `sapling`）、肚下锯齿长毛、缺角的左耳、鼻梁紫裂痕和特效。
升级线：北极熊是两条分支的共同祖先——背上的树苗在黑熊那里结出禁果、在生命树那里长成满冠大树；左耳缺角 + 鼻梁紫裂痕三只熊全程保留。

## 角色设定卡

- 名称 / 身份：北极熊，虚空阵营的优质先锋（防御型前排），刚招募时带着一身「繁茂」加成。
- 一句话剪影：**矮壮低伏、头低于肩线的白熊，肩峰上立着一株三叶小树苗**；肚下、颈下垂着锯齿状长毛。
- 尺寸：待机约 35 × 29 格（含树苗，树苗高出背线 5 格）。体型档「矮壮低伏熊」：体长 14、胸半径 6 / 臀 4.8（前重后轻）、肩峰 2.5、腿长 5、颈 2（颈角 −0.05，头压在肩线以下）。比黑熊矮一截、比生命树小一半。
- 材质色阶（`[勾线, 暗, 基, 亮]`，全部取自共享色板，无专属色）：
  - 冷白熊毛 `[59, 60, 17, 21]`（暗部灰蓝）；远侧腿暗一级 `[59, 60, 60, 17]`
  - 爪 `[0, 0, 27, 28]`、眼 / 鼻 墨 `[0, 0, 0, 0]`
  - 树苗茎 `[34, 35, 36, 37]`、叶 `green`；发光叶 `[35, 37, 38, 21]`；鼻梁裂痕 `[42, 42, 43, 43]`（发光点缀）
- 部件顺序（从后往前）：远侧两腿 → 短尾 → 躯干 + 颈（+ 紧跟着画的锯齿长毛）→ 近侧两腿 → 树苗 → 远侧（左）耳 → 头（+ 紧跟着画的鼻梁裂痕）；侧躺时四条腿挪到最后。
- 细节清单：
  - 脸：墨豆眼 + 亮色眉骨、墨鼻头、圆近耳 + 缺了前上角的平顶左耳、鼻梁 3 格斜紫裂痕（2 级明暗）。
  - 毛：背上毛纹（quad fur）、肚下 / 胸下锯齿长毛（每 3 列一齿，长 0–2 格），甩毛时锯齿相位跟着变。
  - 背负物：树苗茎 5 格（顶端随风摆 1–2 格），3 片叶（左、右、顶，叶尖亮一级）；蓄力时抽高 3 格、长到 5 片叶。
  - 脚：熊掌垫 + 3 根黑爪（近侧亮、远侧暗）。
- 攻击方式：近战 **冲撞**——低头前冲 7 格（预兆：后坐 2 格、低头压身），用肩头和头顶撞假人，不人立、不挥掌。
- 差异化（对照已通过的全部角色 + 同族黑熊、生命树 + 另一台机器上的棕熊「人立挥掌」）：
  - 体型档：矮壮低伏熊（头低于肩、前重后轻），同族里最矮最小。
  - 识别特征：①肩峰上的三叶树苗（改轮廓，高出背线 5 格）②肚下 / 颈下锯齿长毛（改腹线轮廓）③左耳缺角（改耳朵轮廓）④鼻梁紫裂痕（轮廓内）。
  - 武器 + 握法 + 攻击类型：徒手（肩头 / 头顶）+ 冲撞；棕熊人立挥掌、黑熊人立双掌砸、生命树地面根须扫，都不重复。
  - 动作个性：待机 = 每个循环一次从头到尾甩毛（头左右甩、尾甩、锯齿毛抖、树苗乱颤，甩出 3 颗白毛屑）；步态 = 沉重熊步（每步 3 颗尘 + 起伏 1 格）；死亡 = 侧倒伸腿，树苗折断往后弹飞。
  - 主色：冷白熊毛（灰蓝暗部），和黑熊的黑褐、生命树的白桦灰蓝 + 绿冠拉开。
  - 自动查重：`compare.mjs` 退出码 0（对 accepted 与同批两只熊，最高待机 IoU 0.604、施放 IoU 0.713）。

## 特效设定卡

- 元素：成长 · 嫩芽绿，`FXI.nature` = 白 21 → 淡绿白 38 → 嫩绿 37 → 深绿 36 → 墨绿 35。毛屑另用 `polarFur` = 21 → 17 → 18 → 60 → 59（受击、甩毛、消散）。
- 攻击「肩头冲撞」
  - 预兆：后坐 2 格、伏低 1 格、低头（2 帧缓出）。
  - 出手：定格 1 帧前冲 7 格，头压到最低；肩头前两道竖弧（impact 色阶，第 1 帧亮、第 2 帧断续）；脚后 4 颗蹬地尘。
  - 命中：12 颗 impact 外爆 + 6 颗白毛屑，假人闪白小摇。
- 技能「繁茂」（被动特性：刚招募时的加成涌上来，之后一场场减弱）
  - 蓄力 1.4 s：伏低压身、低头；脚下一圈嫩绿光点从 8 格扩到 22 格；地面嫩绿光点定点螺旋汇入树苗；树苗逐帧抽高 3 格、叶片 3 → 5 片，叶子换成发光叶（0.45 s 后 1 / 2 档逐帧闪），树苗顶十字星芒；轮廓光 2 档（光源在树苗顶）、地面映光；最后 0.3 s 树苗发抖。
  - 施放 0.5 s：挺身抬头，身体膨胀 1 格（2 帧）；蓄力粒子外爆 + 20 颗嫩绿外爆 + 身体冲击环；5 片发光叶从树苗弹出，0.12 s 散到身体周围的椭圆轨道上绕身体环绕（前半圈在身前、后半圈在身后，叶心逐帧闪白）= 5 档加成；0.1 s 脚下第二道冲击环 + 14 颗草屑（`impact`）；震屏 2 格、天空闪白。
  - 收招 0.7 s：环绕的叶片一片接一片（间隔 0.1 s）变黄——nature 第 3 → 4 → 5 级——飘落到地面熄灭（加成一场场衰减）；树苗缩回原高，新叶一片片长回 3 片。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼、耳贴后、尾和树苗反甩；impact 16 颗 + 白毛屑 8 颗；震屏 1 格。
- 死亡：26 颗 impact + 震屏 2 格 + 闪白 → 踉跄前腿软下 → 侧倒伸腿（离地 3 → 1 → 0）→ 0.5 s 树苗从背上折断，往后弹飞 14 格落地横躺（落地冒 5 颗嫩绿）→ 落地扬尘 16 颗 + 震屏 1 格 → 静止 → 1.6–2.4 s 身体自上而下消散，化成往后飘的白色毛屑 + 魂光上升。
- 音色：厚毛布的闷扑声 + 树叶沙沙 + 一声低沉的鼻息喷气，重量 0.75（`SFX: body beast · how topple · pal nature · style buff · w 0.75`）。
