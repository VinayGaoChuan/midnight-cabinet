# 生命树 LifeTree

模块：`pcd/chars/LifeTree.js`（`pcd/view.html?c=LifeTree`）。熊身用 `parts-beast.js` 的 `quad`（`head bear · foot pad · tail stub`，腿短粗）；模块自己画背上的树（候选部件 `treeCrown`：树干 + 枝 + 后层暗叶团 + 前层亮叶团 + 发光果）、盘根脚（候选部件 `rootFoot`，紧跟 `quad.leg` 画）、白桦横纹、藤蔓苔须、缺角左耳、鼻梁裂痕里的嫩芽和特效。
升级线：北极熊背上的三叶树苗长成满冠大树；白毛变成白桦树皮；左耳缺角、鼻梁裂痕保留，裂痕里长出一根嫩芽。

## 角色设定卡

- 名称 / 身份：生命树，虚空阵营的史诗圣骑士：背着一棵树的老熊，站在队伍前面，给身后的友军回血。
- 一句话剪影：**又长又平的白桦皮熊身 + 背上一大团圆形树冠**；脚是向外张开的盘根，下巴垂着藤蔓。
- 尺寸：待机 39 × 38 格（树冠占上半：冠宽 21 格、高出背线约 18 格）。体型档「巨型树熊」：体长 18、胸 5.5 / 臀 5（背线肩部高 1 格、臀部低 1 格）、肩峰 1.5、腿长 4（树桩腿）、颈角 −0.3、头低垂。同族最高最宽。
- 材质色阶（全部取自共享色板，无专属色）：
  - 白桦树皮 `pale` `[8, 59, 60, 17]`（躯干暗边 band 3，下半身有明显暗部）+ 墨色横纹（勾线级短横，按列错开）；腹线下沿 3 处 1 格缺口
  - 树干 `[20, 59, 60, 17]`（白桦皮、勾线是木色暗阶）+ 每 2 行一格墨色白桦斑
  - 树冠后层 `moss`、前层 `green`；枯萎时换 `sand`
  - 发光果：暗 `[61, 14, 5, 51]` / 亮 `[5, 51, 21, 21]`；盘根 / 枝 `wood`、远侧盘根暗一级 `[0, 20, 20, 19]`；藤蔓 `moss`；鼻梁嫩芽 `green`；裂痕 `[42, 42, 43, 43]`
- 部件顺序（从后往前）：远侧两腿（+ 盘根）→ 短尾 → 躯干 + 颈（+ 白桦横纹）→ 树干 + 枝 → 近侧两腿（+ 盘根）→ 树冠后层 → 树冠前层（+ 发光果）→ 左耳 → 头（+ 鼻梁裂痕与嫩芽）→ 藤蔓苔须。
- 细节清单：
  - 脸：墨豆眼 + 眉骨、墨鼻头、圆近耳 + 缺角左耳、鼻梁紫裂痕 + 裂痕里一根 3 格嫩芽（伸出头顶轮廓）。
  - 树皮：躯干墨色短横纹、树干每 3 行一道横纹、树干根部往背上摊开。
  - 树冠：椭圆后层（暗绿，零星暗点）+ 7 个亮绿叶团（左上受光、零星暗点）+ 顶上 5 簇伸出的叶尖；随风摆（上半部多摆 1 格）；5 颗淡金果（2×2，暗 / 亮 / 很亮 / 白 4 档）；叶子凋落后露出 4 根枝。
  - 藤蔓：下巴 3 条 + 颈下 1 条，长 3–5 格，尖端亮、随风摆。
  - 脚：树桩腿 + 盘根（候选部件 `rootFoot`）。着地时每只脚 3 根根须占 y −1..0 两行：外侧（前腿朝前、后腿朝后）一根平伸 4 格、一根斜往下贴地 3 格，内侧一根平伸 2 格再落地 2 格，尖端 1 格；待机第 0 帧 y = 0 行每只脚宽 14 格，脚形是向外张开的扇形。抬起的脚上 3 根根须下垂 2 格。
- 攻击方式：**地面发起的施法式横扫**——一只前脚高抬、踏地（预兆 / 出手），地裂往前爬，假人脚下冒出两根根须、横扫过假人、再缩回地下。站位离假人远（HX 66），不前冲。
- 差异化（对照已通过角色 + 同族北极熊、黑熊）：
  - 体型档：巨型树熊（长平身 + 高冠），同族唯一「上半截是树」的轮廓。
  - 识别特征：①满冠圆形树冠（改轮廓，占上半身）②扇形盘根脚（改脚部轮廓）③下巴藤蔓苔须（改下颌轮廓）④鼻梁裂痕嫩芽（伸出头顶）+ 发光淡金果。
  - 武器 + 握法 + 攻击类型：无武器、地下根鞭 + 扫（北极熊冲撞、黑熊人立砸）。
  - 动作个性：待机 = 扎根呼吸（身体不动、树冠随风起伏、孢子从冠顶飘升，每个循环合眼低头一次、果子亮一下、掉一片黄叶）；步态 = 拔根行军（极慢，接触帧扬尘，经过帧拔起的盘根带出土块）；死亡 = 枯萎散架（树冠变黄凋落 → 僵直跪倒成枯木 → 裂成木块落地化灰）。
  - 主色：白桦灰蓝 + 大面积绿冠，和北极熊冷白、黑熊黑褐都拉开。
  - 自动查重：`compare.mjs` 退出码 0（最高待机 IoU 0.525、施放 IoU 0.516）。

## 特效设定卡

- 元素：奉献 · 晨露金绿。主色阶 `FXI.holy` = 白 21 → 淡金 51 → 奶油 5 → 金 14 → 暗金 61；叶片 / 根须冒芽的粒子借 `FXI.nature`（21 → 38 → 37 → 36 → 35）；枯叶、土块用 `FXI.earth`；受击树皮屑 `birchBark` = 21 → 17 → 60 → 59 → 8。
- 攻击「根须横扫」
  - 预兆：近侧前脚抬起 6 格、身体后仰、树冠后摆（1–2 帧）。
  - 出手（2/12 s）：前脚重重踏地，脚下 6 颗尘 + 震屏 1 格，一道地裂（earth 色阶）往假人方向爬；发光果亮一档。
  - 根须（2/12–0.55 s）：假人脚下冒出两根 12 / 9 格高的根（木色 3 级，根部 2–3 格宽，尖端一片嫩叶），往前弯折横扫过假人（扫过处一道 2 格宽的 nature 第 2 级弧形拖影，扫完那一帧转暗一级后消失），再缩回地下。
  - 命中（4/12 s）：12 颗 impact + 6 颗嫩叶外爆 + 5 颗尘，假人闪白小摇。
- 技能「奉献」（持续为身后小范围的友军回血；身后两名友军在蓄力到收招期间出现，`ALLIES: 'skill'`）
  - 蓄力 1.4 s：低头躬身；发光果每 0.25 s 点亮一颗（5 颗），0.45 s 后 1 / 2 档逐帧闪，冠顶十字光；金绿光点（holy / nature 各半）从地面定点螺旋汇入树冠；0.2 s 起一道绿芽地浪从身后贴地往后蔓延 34 格，钻到友军脚下；轮廓光 2 档（光源在冠顶）、地面映光；最后 0.3 s 树冠抖动。
  - 施放 0.5 s：树冠一抖（2 帧），果实全亮到白；26 片花瓣（金 / 绿）向后上方抛洒、飘落；树冠冲击环；藤线（`fx.link`）从树冠连到每个友军；震屏 2 格、天空闪白。
  - 命中：0.15 s / 0.25 s 两名友军依次——脚下小冲击环 + 头顶十字星芒 + 十字形 holy 光点（5 颗一组）整体上升 0.7 s，友军被 holy 描边照亮 1.1 s（各一次 `impact`）。
  - 收招 0.7 s：回到站姿，果实光 2 → 1 → 熄回 1 颗暗果，孢子从冠顶飘升。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼、树冠反摆；impact 16 颗 + 树皮屑 8 颗 + 5 片叶从冠上抖落；震屏 1 格。
