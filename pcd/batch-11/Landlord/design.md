# 地主 Landlord

模块：`pcd/chars/Landlord.js`（身体用部件库拼：`rig(fat) arm(bell) legs(shoe) torso(robe) head(round) beard(mustache) hand`；模块里自画的部件：瓜皮小帽 `skullcap`、算盘 `abacus`、大钱袋 `moneyBag`、腰后铜钱串、倒地后的算盘和撒一地的铜钱，前三个标了「候选部件」）。
升级线：地主 → 金手是**同一个人**：瓜皮帽 + 虚空帽珠、八字胡、圆脸双下巴 + 腮红、算盘都保留；金手体量更大、右臂换成鎏金机关手、算盘背到身后。

## 角色设定卡

- 名称 / 身份：地主，矮胖富态的虚空商人（优质：一颗发光帽珠 + 金边马褂，不打架、只管赚钱）。
- 一句话剪影：**胸前横端的大算盘（11×10，伸出身体约 10 格）+ 瓜皮帽顶的发光帽珠 + 腰间垂到膝下的鼓钱袋**；剪影一眼读成「商人」。
- 尺寸：待机 30×27 格（含帽珠和算盘）；体型 `fat`（leg 5 · torso 7 · head 7 · headW 7 · sw 5 · belly 3），短腿圆肚、头身比约 3.5，宽 16 格（长袍下摆 + 算盘另伸 6 格）。
- 材质色阶（全部取自 64 色共享色板，没有新增颜色）：
  - 马褂 深紫绸缎 `purple` [25, 42, 24, 43]（band 2）+ 金边 / 对襟 / 盘扣 / 立领 `gold`；长袍 暗紫 [0, 25, 42, 24]（band 2，比马褂暗一级，下半身不再碎成灰蓝点）；鞋 墨黑 [0, 0, 27, 28]
  - 肤 `skin` · 腮红 `pink`（脸颊外侧、眼睛下一行）· 八字胡 [0, 27, 27, 28] · 眼 `ink`
  - 瓜皮帽 墨黑 [0, 0, 27, 28] + 金扣；帽珠（发光体）flat [25, 42, 24, 43]，蓄满 / 施放换 flat [42, 24, 43, 21]
  - 算盘 框 `wood`（木框走墨色勾线，和钱袋的 leather 勾线分开）、深木底、浅木档杆、横梁 `gold`、珠 `crimson`；蓄力亮起的珠 flat [20, 14, 5, 21]（发光体）
  - 钱袋 `leather` + 金绳 + 方孔钱印记 `gold`；铜钱串 `gold` + 皮绳
- 部件顺序（从后往前）：后臂（喇叭袖，藏在身后）→ 腿（布鞋）→ 长袍 + 马褂（同一部件：马褂下摆金边、对襟、盘扣、立领）→ 腰后铜钱串 → 头（圆脸、眯眼、腮红、双下巴、八字胡）→ 瓜皮帽 → 帽珠 →（前手托在算盘下沿时：前臂）→ 大钱袋 → 算盘 → 后手（握在算盘左框外侧）→ 前手（托算盘时只画手；举手扔钱 / 拨珠时整条前臂压在算盘前）→ 指间铜钱（攻击预兆）。
- 细节清单：
  - 脸：细长眯眼（2 格墨）、小鼻尖、腮红、耳、双下巴；八字胡压在下巴那一行、和鼻尖隔 1 行肤色，两端各上翘 1 格（笑时再翘 1 格，代替嘴）。
  - 头饰：瓜皮帽 4 行（卷边帽檐暗一级、缝线、左上高光、帽檐小金扣）；帽珠 3 格 + 顶 1 格，5 档亮度（待机 / 蓄力 / 蓄满 / 施放 / 熄灭）。
  - 服装：马褂金下摆 + 对襟金边 + 3 颗盘扣 + 立领 + 背后褶；长袍拖到脚面、波浪下摆随步子摆。
  - 手臂：喇叭宽袖 + 金袖口，2×2 手。
  - 道具：算盘 11×10（木框 + 深木底、4 根浅木档杆每隔 1 列一根、金横梁；每档 1 颗上珠 + 2 颗下珠，珠 1×2 格上亮下深红，下珠按花样拨上拨下，空出的一截档杆露在上或下）；钱袋梨形 7 行（2 格收口褶 → 1 行金绳结 → 袋身 4 → 7 格，中间 2×2 方孔钱印记，蓄力时下半鼓大 2 格），挂在腰前偏后（x 2），和算盘左右错开；腰后一串铜钱。

- 差异化（对照已通过：守夜人 / 寡妇 / 修女 / 屠夫领主 / 钟表匠 / 火葬人 / 蛮兽 / 邪眼王 / 星辉巫师 / 维京战士 / 奴隶主 / 两匹马，以及同组分配的其他角色）：
  - 体型档：矮胖富态（`fat`，短腿、圆肚、头大）；屠夫领主也是胖，但是 32 格巨型桶腹 + 粗臂剁骨刀；地主矮一截、穿长袍马褂、手里是算盘不是刀。
  - 识别特征（≥ 2 个改外轮廓）：①胸前横端的大算盘，伸出身体约 10 格（轮廓）②瓜皮帽 + 帽顶发光珠（轮廓：圆顶加一颗尖珠，不是尖帽也不是宽檐）③垂到膝下的鼓钱袋（轮廓，蓄力时鼓大）④立领金边马褂（内部）。
  - 武器 + 握法 + 攻击类型：**投掷**（单手甩腕扔铜钱）+ 投；寡妇是甩飞牌（牌扇、钢刃），地主扔的是打转的圆铜钱，另一手端算盘。

## 特效设定卡

- 元素：激进投资 · 铜钱金，色阶 `FXI.coin` = 白 21 → 奶油 5 → 金 14 → 暗金 61 → 深木 20；帽珠火星 / 轮廓光用虚空紫 `curse`（43 → 24 → 42 → 25 → 52）。
- 攻击「甩铜钱」
  - 预兆：右手捏铜钱举到耳后 1 帧（指间一枚金币）。
  - 出手：甩腕定格，手边金色十字闪 2 帧 + 5 颗金星。
  - 弹道：打转铜钱（4 帧：3×3 正面带方孔 → 斜 → 1 格侧边 → 斜），170 格/秒，金色短拖尾。
  - 命中：9 颗金币外爆 + 小十字星芒，假人闪白小摇。
- 技能「激进投资组合」（被动特性生效的样子：活过一场战斗，钱收进袋里；外加「卖空」的加速）
  - 蓄力 1.4 s：俯身飞快拨算盘（手每帧换档、珠位每帧换花样），5 档算珠一颗颗亮金（最新亮的那颗白），亮珠上冒金星；地面金币点从四周定点螺旋汇入腰间钱袋，钱袋 0.6 s 鼓大 1 格、1.05 s 鼓大 2 格并开始抖，袋边金光闪点；帽珠 1 / 2 档逐帧闪、轮廓光 2 档、地面映光。
  - 施放 0.5 s：右手一拍钱袋、身子后仰，钱袋一抖——14 枚金币上抛外爆（带重力的喷泉）+ 金色冲击环 + 十字星芒 + 16 颗金火花；帽珠最亮、轮廓光 3 档；震屏 2 格、天空闪白。
  - 命中：每枚金币落回地面弹两下（第一下 42、第二下 22 格/秒）再被螺旋吸回钱袋；身后闪过两道金色速度线（「卖空」加速），往后拉长再断开。
  - 收招 0.7 s：拍两下钱袋，钱袋瘪回去，帽珠闪一下。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 闭眼 + 八字胡上翘 + 钱袋反甩；impact 16 颗；震屏 1 格。
- 死亡：26 颗 impact + 震屏 2 格 + 闪白 → 踉跄（双手捂住钱袋、身子后仰半蹲）→ 后仰倒地（离地 3 → 1 → 0 两帧下落）→ 尘土 14 颗 + 钱袋破开，10 枚铜钱溅出落地、地上撒一排铜钱；算盘摔平在脚边；瓜皮帽从头顶弹开（最高 4 格、0.25 s 落地）、落地后再翻滚 1 次，停在头顶后方（整个死亡状态 bbox 左沿 −26）→ 帽珠闪 3 次熄灭 → 1.6–2.4 s 自上而下消散 + 魂光上升。
- 音色：算盘珠噼啪 + 铜钱串哗啦 + 一声满意的鼻哼，重量 0.45（`SFX: body flesh · how topple · pal coin · style coin · w 0.45`；`step` 在步态接触帧、`swing throw` + `shoot coin` 在甩腕帧、`hit metal` 在铜钱到达、`impact coin` 在喷泉炸开和第一枚金币落地、`fall` 在后仰落地帧）。
