# 黑熊 BlackBear

模块：`pcd/chars/BlackBear.js`（`pcd/view.html?c=BlackBear`）。身体用 `parts-beast.js` 的 `quad`（`head bear · hump 3.5 · mane ruff · foot pad · tail stub`）；人立举掌是改写前腿脚点后用库里的 `quad.leg` 画的（举起的前掌画在头之后）；模块自己画禁果枝（候选部件 `forbiddenBranch`）、禁果（候选部件 `forbiddenFruit`）、背裂纹、胸前月牙、缺角左耳、鼻梁裂痕和特效。
升级线：北极熊背上的三叶树苗 → 扭曲焦黑的枝 + 一颗禁果；左耳缺角、鼻梁紫裂痕保留；体量翻倍、白毛黑化。

## 角色设定卡

- 名称 / 身份：黑熊，虚空阵营的史诗先锋：挨打、出手都在往禁果里攒法力，满了或死了就炸。
- 一句话剪影：**肩峰高耸、臀小收腹的巨型黑熊楔形，背上一根焦黑扭枝挂着一颗发红光的禁果**；攻击时人立、双掌高举（同族唯一人立的熊）。
- 尺寸：待机 40 × 35 格（含枝和果，枝高出背线 7 格）；人立约 36 格高。体型档「巨型肩峰熊」：体长 16、胸 7 / 臀 5、收腹 0.35、肩峰 3.5（北极熊的 1.4 倍）、腿长 6、颈圈毛。
- 材质色阶（全部取自共享色板，无专属色）：
  - 黑褐熊毛 `[0, 52, 20, 19]`（boot 色阶，暗部换成虚空紫黑 52）；颈圈毛 `[0, 20, 19, 32]`
  - 胸前月牙 `bone`；爪 `[0, 27, 29, 30]`；眼 `[0, 0, 57, 58]`（暗红眼）；鼻 墨
  - 禁果枝 `[0, 0, 52, 53]`；禁果 3 档：暗红 `[55, 12, 13, 26]` → 熔红 `[44, 45, 46, 47]` → 亮白 `[45, 47, 21, 21]`
  - 背裂纹：暗熔 `[44, 44, 44, 45]` / 亮熔 `[45, 46, 47, 21]`；鼻梁裂痕 `[42, 42, 43, 43]`
- 部件顺序（从后往前）：远侧后腿 →（远侧前腿，没举起时）→ 短尾 → 禁果枝 → 躯干 + 颈（+ 紧跟着画的背裂纹、胸前月牙）→ 近侧后腿 →（近侧前腿，没举起时）→ 颈圈毛 → 左耳 → 头（+ 鼻梁裂痕）→ 举起的前掌 → 禁果。
- 细节清单：
  - 脸：暗红豆眼 + 眉骨、墨鼻头、张嘴露牙（jaw 0–3）、圆近耳 + 缺角左耳、鼻梁紫裂痕。
  - 毛：颈部蓬起的颈圈毛（6 束尖，随 mane 摆）、背上毛纹、胸前骨白月牙斑（5 格）。
  - 背负物：焦枝 7 格扭两下，顶端往前弯出果柄、后面一根焦刺；禁果 3 档大小（2×2 / 4×3 / 4×4）× 4 档亮度，蓄力时一档档涨大、施放时炸掉、收招重新挂上一颗暗红小果。
  - 背脊 4 道焦裂纹（每道 3 格折线），按法力一条条亮起。
  - 脚：熊掌垫 + 钢灰爪；举起时掌垫朝上成了高举的熊掌。
- 攻击方式：近战 **砸**——人立双掌高举（预兆）→ 前冲 6 格、双掌合拢往下砸（出手定格）→ 伏低收回。
- 差异化（对照已通过角色 + 同族北极熊、生命树 + 另一台机器的棕熊「人立挥掌」）：
  - 体型档：巨型肩峰熊（强楔形），同族最重。
  - 识别特征：①焦黑扭枝 + 发红光的禁果（改轮廓，高出背线 7 格）②人立双掌高举的攻击 / 蓄力姿（改轮廓）③颈圈毛（改颈部轮廓）④胸前骨白月牙 + 背脊熔红裂纹（轮廓内）。
  - 武器 + 握法 + 攻击类型：徒手双掌 + 砸（棕熊是人立单掌挥、北极熊冲撞、生命树根须扫）。
  - 动作个性：待机 = 扭头嗅背上的禁果（张嘴嗅，禁果随之脉动涨一档、背裂纹闪红）；步态 = 蹒跚重步（每步 4 颗尘 + 接触帧低头顿挫）；死亡 = 爆裂（身体膨胀发白后炸成熔红碎块）。
  - 主色：黑褐 + 虚空紫黑暗部，点缀熔红，和北极熊的冷白、生命树的桦白绿冠完全不同。
  - 自动查重：`compare.mjs` 退出码 0（最高待机 IoU 0.697、施放 IoU 0.618）。

## 特效设定卡

- 元素：禁果 · 熔火，`FXI.fire` = 白 21 → 淡黄 47 → 橙 46 → 红 45 → 深红 44。毛屑 `blackBearFur` = 19 → 20 → 52 → 0 → 0。
- 攻击「人立双掌砸」
  - 预兆：人立（pitch 6）、双掌高举过头、张嘴（1–2 帧）。
  - 出手：定格 1 帧前冲 6 格、双掌砸下伏低；假人身上 3 条竖爪痕（impact，第 1 帧亮、第 2 帧断续）；掌落处毛屑 + 5 颗尘，震屏 1 格；禁果亮一档（攒法力）。
  - 命中：14 颗 impact 外爆，假人闪白大摇。
- 技能「禁果」（满法力引爆：对周围所有攻击过它的敌人爆发伤害）
  - 蓄力 1.4 s：0.5 s 内人立、双掌高举；火星从四周螺旋吸入禁果；禁果 0.5 s / 1.0 s 各涨一档（2 → 4 格）；背裂纹每 0.3 s 亮一条；0.5 s 从身体拉出一条断续火线（`fx.link`）连到假人 + 假人身上一个小十字 = 记下仇恨；0.45 s 后禁果 1 / 2 档逐帧闪、十字光；轮廓光 2 档（光源在禁果）、地面映光；最后 0.3 s 发抖。
  - 施放 0.5 s：双掌砸地的同时禁果炸开——蓄力粒子外爆 + 36 颗火焰外爆 + 两道大冲击环（果处 + 掌下）+ 7 格十字 + 前后两道地裂 + 12 颗尘；震屏 2 格、天空闪白（`impact`）。0.08 s 火头顺着连线从身体烧向假人（6 格火团 + 拖尾，0.17 s 到）；0.25 s 在假人身上再炸一团火：30 颗外爆 + 大冲击环 + 十字，假人闪白大摇 + 点燃（`dummyFx tint fire`），震屏 1 格（第二次 `impact`）。
