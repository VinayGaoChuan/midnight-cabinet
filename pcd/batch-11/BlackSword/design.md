# 黑剑（BlackSword）

## 角色设定卡

- 名称 / 身份：黑剑，虚空族刺客狼（部队，普通，近战）。升级线第一级：瘦、矮、贴地的嚎狼，额头长着一支黑剑。
- 一句话剪影：额头一支前指的黑剑独角（伸出吻尖 3 格）+ 细尾末端一片上翘的黑剑刃（带 1 格护手）+ 背脊一排锯齿黑鬃。
- 尺寸：身体约 28×18 格（待机外框 44×20，含尾刃和剑角）；地面线在脚底。
- 体型档：瘦长低伏狼档（quad：len 13 · chest 3.6 · rump 3.1 · waist 0.65 深收腹 · leg 6.5 · lw 1.5 细腿 · neckA 0.12 低颈 · headA 0.22），腿长身细、头压在肩线高度以下，是同族里最瘦最矮的。
- 材质色阶（[勾线, 暗, 基, 亮]，全部取自共享色板）：
  - 蓝黑狼毛 body / limb = shadow [0, 52, 53, 54]（面积最大）
  - 吻部、腹线 muz / belly = [0, 53, 54, 59]（亮部偏钢蓝，让头读得出来）
  - 锯齿黑鬃 mane = [0, 0, 27, 53]
  - 黑剑刃（剑角、尾刃）blade = [0, 0, 27, 43]：墨黑刃身，受光的刃口亮成紫 43
  - 眼 eye = [0, 0, 43, 43]（诅咒紫，平涂）· 发光 glow = [43, 43, 21, 21]
- 部件顺序（从后往前）：远侧两腿 → 刃尾（细尾 + 剑刃 + 护手，同一部件）→ 背脊鬃刺 → 躯干 + 颈 → 近侧两腿 → 头（含耳）+ 额刃角（并进头的部件，头小时不在额头压分界线）→ 断角（死亡时）。
- 细节清单：
  - 脸：诅咒紫豆眼 + 眉、钢蓝吻部、鼻头、张嘴露白牙、嘴线；尖耳（嗅地时一抽一抽）。
  - 毛：背上毛纹、背脊锯齿黑鬃、钢蓝腹线。
  - 剑角：从额头直线前指，根 2 格粗、梢 1 格，刃口紫光，刃尖 1 格高光。
  - 尾：根部 2 格粗的细尾，末端 5 格长的上翘剑刃，刃根一格紫色护手——像一把倒插的小剑。
- 攻击方式：近战 · 咬（低伏蓄势 1 帧 → 前扑 6 格扑咬定格 → 剑角顺势上挑一道短弧 → 回位）。
- 差异化（和已通过角色比较）：
  - 体型档：瘦长低伏四足。已通过的四足只有两匹马（敦实挽马、高挑骏马），人形 / 猿形 / 漂浮都不同。
  - 识别特征：①额头前指黑剑独角（改外轮廓：吻前多 3 格尖）②上翘剑刃尾（改外轮廓：尾端竖起的刃）③背脊锯齿黑鬃（改外轮廓：背线锯齿）。
  - 武器 + 握法 + 攻击类型：天生武器（剑角 + 利齿）· 咬 + 挑。马是冲撞、蛮兵是抡棒砸。
  - 待机个性：低头嗅地（鼻子贴地前后嗅、剑刃尾左右甩、耳朵一抽一抽）。
  - 步态：贴地小跑（压低 1 格、低头，快、轻，接触帧只有 1 颗尘）。
  - 死亡方式：前扑滑倒（塌在地上往前滑 2 格）+ 剑角断裂弹开，自上而下消散。
  - 主色：蓝黑 / 暗紫狼毛，和马的枣褐、血枣红，蛮兵的锈红褐拉开；升级后的暗牙是金毛。

## 特效设定卡

- 元素：狼群 · 诅咒紫，色阶 curse = 43 淡紫 → 24 → 42 → 25 深紫 → 52 墨紫（共享 FXI.curse）。
- 攻击「扑咬」：
  - 预兆：伏低 1 帧（crouch 2、低头、耳贴后）。
  - 出手：前扑 6 格定格，张嘴咬合拖影（上下两道短弧，第 1 帧淡紫 + 白芯、第 2 帧断续深紫），2 帧。
  - 延续：剑角上挑，fx.slash 一道从前下到前上的紫色短弧。
  - 命中：impact 火花 10 颗 + 诅咒紫 4 颗（叠一层破甲），假人闪白小摇。
- 技能「狼群」（每一口叠一层破甲，群狼围咬时层数叠满）：
  - 蓄力 1.4 s：伏低龇牙、鬃毛竖起、眼光 1/2 档逐帧闪、蓄满后身体颤抖甩尾；身后浮出两道单色狼影（copySprite + blitShape，curse 第 4 级 25），先是稀疏抖动的点、逐渐成形；诅咒紫粒子定点汇聚到两道狼影上（成形）并绕嘴环绕；轮廓光 2 档、地面隔点映光。
  - 施放 0.5 s：本体前扑 8 格咬住目标（0.1 s），两道狼影一前一后跃过本体背上扑向目标上半身（0.2 s、0.3 s 到达），各拖一道墨紫扑击残影；蓄力粒子外爆 + 扬尘 + 小冲击环；震屏 2 格、天空闪白；眼光拖尾 3 格。
  - 命中：每一口在目标身上留一道紫色裂痕（fx.crack 叠在身上，下 → 上 → 中三道）+ 紫色火花，前两口假人小摇；第三口叠满：一圈 8 片断续错开的碎盾冲击环 + 大冲击环，目标染诅咒紫 1.4 s、闪白大摇、震屏 1 格。
  - 收招 0.7 s：狼影化成紫尘消散；本体离地一个小弧跳回原位（落地压低 1 格），眼光 2 → 1 → 0。
- 受击：野兽——impact 16 颗 + 蓝黑毛屑 6 颗 + 白色剪影 1 帧 + 击退 2 格 + 闭眼、耳贴后、尾甩起；震屏 1 格。
- 死亡：26 颗火花 + 震屏 2 格 + 闪白 → 缩身 → 踉跄前扑（前低后高）→ 塌倒在地（离地 3 → 1 → 0）并往前滑出 2 格（尘土 14 颗 + 滑行扬尘）→ 剑角齐根断裂，断刃翻着飞出 9 格落地（金属轻响）→ 尾巴最后落下 → 自上而下消散 + 魂光上升。
- 音色：轻爪刨地 + 剑刃般的金属嗡鸣 + 一声短促低吠，重量 0.35。
  - SFX 声明：body beast · how topple · pal curse · style shadow · w 0.35；step（每个接触帧，w 0.2）、swing bite + hit flesh（出手帧）、impact ×3（三口）、fall（落地）、hit metal（断角落地）。
