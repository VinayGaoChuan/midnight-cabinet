# 蟹巫 Crabomancer

模块：`pcd/chars/Crabomancer.js`（查看 `pcd/view.html?c=Crabomancer`）；自检输出 `shots/`。

## 角色设定卡

- 名称 / 身份：蟹巫，虚空族召唤师（传说），蟹术士的进化形态。高腿寄居蟹大巫。
- 一句话剪影：
  - 高耸的尖塔螺，窗里透紫光，塔尖高出眼柄约 6 格。
  - 挂着贝壳铃串的高尖帽。
  - 平时竖举在身前的符文巨螯，比身体还大，单独撑出右侧轮廓。
  - 悬浮在左螯上方的水球。珊瑚杖不见了。
- 尺寸：待机外框 38×33 格（含巨螯和塔螺），属于传说档。腿长约是蟹术士的一倍（离地 6、`knee 1`、`span 14`、`fan 0.8`），身体抬高。
- 骨架：`parts-beast` 的 `bug`（蟹，`legsFront 0`）。尖塔螺、高尖帽 + 贝壳铃、符文巨螯（可朝右 / 朝上 / 朝下三个朝向，90° 换档）、水球是模块里的部件，标了「候选部件」：`spireConch`、`tallCap`、`giantClaw`。
- 材质色阶：
  - 甲壳：fire `[44, 45, 46, 47]`，主材质，比蟹术士更深更艳。
  - 腿：暗一级 `[0, 44, 45, 46]`，让身体读得出来。
  - 甲壳前沿、腕节：gold 镶边。
  - 尖塔螺：sand band 2。窗光：purple 平涂 4 档。
  - 高尖帽：purple。贝壳铃：bone。
  - 巨螯：fire band 1。符文：`[25, 24, 43, 21]` 平涂。
  - 水球：`[39, 40, 22, 21]` 平涂发光体。
- 部件顺序（从后往前）：远螯 → 远侧腿 → 尖塔螺 → 近侧腿 → 头胸甲（+ 口器、金镶边、裂纹）→ 远眼柄 → 高尖帽 → 贝壳铃串 → 近眼柄 → 巨螯臂 → 巨螯 → 水球。
- 细节清单：
  - 脸：两根眼柄，2×2 墨眼 + 高光，能闭眼；口器 3 格。
  - 甲：前沿金镶边。
  - 塔螺：7 层逐级收窄 + 缝合线 + 螺旋沟，3 扇 2×2 窗 + 1 扇圆窗。
  - 帽：金帽带 + 高光、向后折的帽尖、3 颗随摆动的贝壳铃。
  - 巨螯：掌、上下两指、指内齿、7 格符文、金腕节、两节粗臂。
  - 发光体：水球 5 档，带环绕相位 `oa`；符文、窗光各有熄灭档。
- 攻击方式：远程施法。巨螯竖举张到最大，然后一下横过来合拢（隔空一夹）。同一帧，假人身上出现一只水影钳（同一只巨螯的剪影，换成海水青色阶）合拢，然后抖动消散。
- 差异化：
  - 体型档：高腿寄居蟹，比蟹术士高 10 格、宽 10 格。
  - 识别特征：尖塔螺、高尖帽 + 铃、符文巨螯、悬浮水球。前三个改变外轮廓。
  - 武器 + 握法 + 攻击类型：异形肢体巨螯（徒手）× 施法（隔空夹），和蟹术士的「螯夹杖 × 水泡连射」拉开。
  - 待机个性：磨螯。1.6–2.0 s 巨螯一开一合地磨，贝壳铃叮一下，水球一直绕着转。
  - 步态：高腿横移。长腿大步，经过帧身体抬高 2 格，起伏大，每个接触帧 2 颗尘土。
  - 死亡方式：碎裂，死亡套件 chunks。
  - 主色：橙红珊瑚甲。
- 升级线：保留蟹术士的螺壳（→ 尖塔螺）、尖帽（→ 高尖帽）、右螯（→ 巨螯），像同一只蟹长大了。

## 特效设定卡

- 元素色阶：深渊潮涌。主色 `FXI.water` = 21 → 22 → 41 → 40 → 39；只有裂隙描边用 `FXI.magic`（21 → 22 → 23 → 24 → 25）的紫段。
- 攻击「隔空一夹」：
  - 预兆：巨螯竖举、张到 3 档，身体前抬，水球 1 档。
  - 出手：巨螯横过来合拢，定格 1 帧；螯尖画一道咬合弧（2 帧）；轮廓光 2 档。
  - 命中：同一帧假人身上的水影钳从半张到合拢（0.42 s 内抖动消散），12 颗水花，目标闪白小摇。
- 移动：高腿横移，接触帧各 2 颗尘土。
- 技能「召唤蟹钳」：
  - 蓄力 1.4 s：巨螯高举并张开，蓄满后一开一合地颤；贝壳铃被吹响。假人上空（y = HY − 44）撕开一道裂隙：水色螺旋椭圆 + magic 紫描边，逐渐张开。水球里的光点沿抛物线被吸进裂隙，裂隙周围的水色光点螺旋收拢。窗光最亮，水球 1/2 档闪，轮廓光 2 档，地面映光。
  - 施放 0.5 s：巨螯挥下（横过来合拢），水球爆亮、星芒臂长 6。汇聚粒子外爆，裂隙口外爆 + 冲击环，震屏 2 格，天空闪白。0–0.1 s 裂隙里伸出一只巨蟹钳（张开，朝下，带臂，呼应 Pincer），直落到假人身上。
  - 命中（0.1 s）：巨钳合拢一夹。34 颗大水花外爆 + 冲击环 + 地裂 28 格 + 尘土，假人大摇击退 1 格并下陷 1 格，震屏 2 格 + 闪白。
  - 收招 0.7 s：巨钳留在场上往上举起示威，一开一合；0.45 s 后抖动消散。裂隙在 0.5 s 内合拢。水球 2→1→0。
- 受击：白色剪影 1 帧 + 击退 2 格 + 闭眼 + 贝壳铃反甩 + 巨螯后缩半张；impact 16 颗；震屏 1 格。
- 死亡「碎裂」：
  1. 命中火花 26 颗 + 震屏 2 格 + 闪白。
  2. 下蹲、巨螯半张，裂纹从巨螯开始出现（`crk` 1：螯上 5 格 → `crk` 2：螯上 11 格 + 头胸甲 5 格），窗光闪烁后熄灭，水球熄灭。
  3. 0.5 s 整只从巨螯那边碎成 4 格小块炸开（`death.start('chunks')`，冲击点在巨螯掌心，往后推），尖塔螺摔成几截落地弹跳。同时迸出 14 颗紫色碎光 + 尘土，震屏 2 格。
  4. 碎块 1.0 s 后抖动消散；1.6–2.4 s 魂光上升。
- 音色：厚甲壳重咔 + 深海涡流的轰鸣 + 巨钳合拢的一声「咔嚓」，重量 0.7。
  - `SFX: { body: 'armor', how: 'shatter', pal: 'water', style: 'summon', w: 0.7 }`
  - `step` 在步态接触帧；出手帧 `swing` claw + `hit` magic（隔空夹是同帧命中）；巨钳砸落合拢时 `impact` water 0.85。碎裂死亡没有倒地，所以不发 `fall`。
