# 暗牙（DarkFang）

## 角色设定卡

- 名称 / 身份：暗牙，虚空族头狼祭司（部队，稀有，近战）。黑剑进化后的同一个体：身体长壮、金毛取代蓝黑毛，剑角长成后弯弧刃，嚎叫即施法。
- 一句话剪影：金色蓬松颈圈毛把颈部撑宽 + 下颌两支下垂的黑剑牙 + 额头后弯的黑弧刃（角根金环）；剑刃尾保留并加宽。
- 尺寸：身体约 32×22 格，比黑剑高 4 格；待机外框 44×29（弧刃高出头顶 6 格）。
- 体型档：标准健壮狼档（quad：len 13 · chest 4.8 · rump 4 · leg 6.5 · lw 2 · neckA 0.85 抬颈 · 站姿头 -1 昂头），胸厚、颈毛蓬大，和黑剑的瘦长低伏拉开。
- 材质色阶（[勾线, 暗, 基, 亮]，全部取自共享色板）：
  - 金毛 body / limb = gold [20, 19, 14, 5]（面积最大）
  - 颈圈毛 mane = [20, 62, 5, 21]（浅金到奶白，比身体亮一档，蓬松读得出来）
  - 腹线 belly = [20, 62, 5, 5] · 吻部 muz = [20, 14, 5, 5]
  - 黑剑刃（弧刃、剑牙、尾刃）blade = [0, 0, 27, 43]；远侧剑牙 [0, 0, 0, 27]
  - 角根金环 / 尾刃护手 ring = [20, 14, 5, 21]
  - 诅咒纹 mark = [52, 42, 24, 43]（平涂：暗 42 · 亮 24 · 很亮 43）
  - 眼 eye = [0, 0, 43, 43] · 发光 glow = [43, 43, 21, 21]
  - 死亡褪灰：[8, 10, 18, 17]（颈毛 [8, 18, 17, 21]）
- 部件顺序（从后往前）：远侧两腿 → 刃尾（细尾 + 加宽剑刃 + 金护手）→ 躯干 + 颈 + 诅咒纹（同一部件）→ 近侧两腿 → 颈圈毛 → 头（含耳）→ 剑牙 → 额弧刃 + 金环（侧躺时四腿挪到最后）。
- 细节清单：
  - 脸：诅咒紫眼 + 眉、奶金吻部、鼻头、张嘴露牙；尖耳；两支黑剑牙（近侧 2 格粗根、伸出下巴 3 格，远侧暗一级短 1 格）。
  - 毛：浅金颈圈毛一圈尖束（蓄力时竖起变长）、背上毛纹、奶金腹线、身上 4 道紫色折线诅咒纹（待机暗、蓄力逐条亮、施放全亮）。
  - 弧刃：额头起先向前上、再弯向后方的镰形黑刃，根 2 格粗、梢 1 格，受光刃口紫，角根一圈金环。
  - 尾：细尾末端 6 格长、根宽 3 格的剑刃，刃根金色护手（黑剑的尾刃加宽加金）。
- 攻击方式：施法（仰头短嚎，喷出一道紫色声波弧，弧两端点金，打向目标）。站位 HX 58（离假人一段距离，符合 range 272 > 黑剑 240）。
- 差异化：
  - 体型档：标准健壮四足（黑剑是瘦长低伏；两匹马是挽马 / 骏马）。
  - 识别特征：①颈圈毛（外轮廓：颈部宽 4 格）②下垂剑牙（外轮廓：下巴下伸出 3 格）③后弯弧刃（外轮廓：头顶后方的镰刃）④诅咒纹（内部）。
  - 武器 + 握法 + 攻击类型：天生（嚎叫）· 施法 · 声波弹道（黑剑是扑咬近身）。
  - 待机个性：坐姿舔爪——后腿坐下、抬前爪舔一下、剑刃尾拍地两次（扬起小尘），再起身。
  - 步态：昂首阔步（头抬高、步幅 4、抬脚 3，颈毛随步起伏，接触帧 2 颗尘）。
  - 死亡方式：化灰（仰天长嚎 → 倒向一侧 → 金毛从头到尾褪成灰白 → 死亡套件 ash 从上往下化成灰被吹散）。黑剑是前扑滑倒。
  - 主色：金毛，和黑剑的蓝黑、马的枣褐 / 血枣红拉开。
  - 升级线的延续：保留黑剑的剑角（加长弯成弧刃 + 金环）、剑刃尾（加宽 + 金护手）、诅咒紫眼。

## 特效设定卡

- 元素：攻击 / 死亡仍是诅咒紫 curse = 43 → 24 → 42 → 25 → 52（共享 FXI.curse，没改）；技能「领袖光环」单独建色阶 darkFangAura = 21 → 5 → 14 → 42 → 52（白 → 奶金 → 金 → 虚空紫 → 暗紫：金色代表增伤，尾巴落进虚空紫代表代价），用 fxRamp 建，不改动攻击用的色阶。
- 攻击「短嚎」：
  - 预兆：仰头张嘴 1 帧，口中紫光 1 档，颈毛后甩。
  - 出手：张到最大定格，嘴前一小道声波弧（第 1 帧淡紫 + 金边、第 2 帧断续）；发出 ")" 形声波弹道（紫弧 + 金色两端，150 格/秒，稀疏紫尾）。
  - 命中：诅咒紫火花 10 颗 + 小十字星芒，假人闪白小摇。
- 技能「领袖光环」（伤害光环：身边友军伤害提高，但受到的伤害也提高；不打敌人）：
  - 友军占位：ALLIES 'skill'（只在蓄力到收招期间出现），站在头狼身后 ALLY_X = [HX − 36, HX − 50]（不压在刃尾上）。
  - 蓄力 1.4 s：仰头张嘴（口中金光 + 嘴边小十字），脚下一圈金色点阵光环种子，随蓄力从暗紫变金、变宽（半径 12 → 20）；地面浮起的金点（部分 2×2）逆时针螺旋吸进嘴里；4 道诅咒纹每 0.3 s 亮起一道；0.5 s 后颈毛竖起变长；轮廓光 2 档、地面金色映光。
  - 施放 0.5 s：长嚎——头仰到最高、全身颤抖；汇聚的金点不外爆，整股飞向身后近侧友军（releaseOrbit to 友军胸口）；头后方（嘴后 6 格）18 颗小金火花（速度 20–60、寿命 0.2–0.35 s）+ 嘴后 4 格一个小冲击环 + 嘴前十字星芒（5 格）；地面映光中心后移 6 格；震屏 2 格、天空闪白。光环沿地面从脚下向外推开（点阵椭圆，前沿第 1 帧白、之后奶金，后面跟一圈暗一级的内环），前沿扫过的地面溅起金点。所有技能特效停在假人左侧 12 格以外，假人身上没有任何技能像素（技能只强化友军、不打敌人）。
  - 罩住友军（2/12 s 近侧、3/12 s 远侧，各一次 impact）：友军身上 12 颗金火花 + 头顶十字星芒；头狼嘴边连向友军头顶的金色虚线（1.1 s）；头顶一对金色獠牙印（7×5：7 格牙根横梁 + 两支下垂獠牙，根 2 格粗、往下变细、牙尖向内收 1 格，呼应暗牙自己的剑牙：伤害提高），第 1 帧全白、升起 3 格后悬停；脚下紫色断续破绽圈（半径 10，第 1 帧白、之后诅咒紫亮级 EL[1]，内圈半径 7；借攻击的诅咒紫，只读：受到的伤害也提高）+ 被罩住后第 2–3 帧胸口一道紫色裂纹闪（更脆）；两名友军都进光环后整体金色描边（allyFx outline，1.0 s，金 / 奶金隔帧交替）。
  - 收招 0.7 s：低头收声，诅咒纹从很亮暗回亮 1 档，颈毛放下；嘴边和友军身上飘金色余烬；獠牙印、破绽圈、描边末段闪烁褪去。
  - 和同族区分：头狼（PackLeader）是血红鼓声环 + 友军头顶上升箭头 + 暗红裂纹；暗牙是金色地面光环 + 獠牙印 + 紫色破绽圈 + 金色连线。
