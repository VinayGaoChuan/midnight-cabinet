# 蟹术士 CrabWarlock

模块：`pcd/chars/CrabWarlock.js`（查看 `pcd/view.html?c=CrabWarlock`）；自检输出 `shots/`。

## 角色设定卡

- 名称 / 身份：蟹术士，虚空族召唤师（优质）。一只背着符文螺壳、戴歪尖帽、夹着珊瑚杖的寄居蟹小法师。
- 一句话剪影：背上高过身体的螺旋壳（螺尖向后上翘）+ 两根眼柄之间的歪斜小尖帽 + 右螯夹的珊瑚杖和杖顶气泡珠。三样都伸出外轮廓。
- 尺寸：待机外框 28×23 格（含螺壳和杖），矮扁的寄居蟹体型档。身体宽 10、高 6，离地 2 格。螺壳比身体高，腿短。
- 骨架：`parts-beast` 的 `bug`（蟹：`abd null`、`legsFront 0` 腿从壳下伸出、每侧 4 条腿、`knee -1`、螯 `len 5 / size 2.5`）。螺壳、尖帽、眼柄、珊瑚杖、气泡珠是模块里自己画的部件，标了「候选部件」：`conch`、`pointedCap`。
- 材质色阶：
  - 蟹壳：pink `[11, 12, 63, 58]`，主材质。
  - 螺壳：sand `[20, 61, 62, 5]`，band 2。
  - 符文：purple 平涂 `[25, 42, 24, 43]`，按 `rl` 分 4 档亮度。
  - 尖帽：purple。帽带：gold。
  - 珊瑚杖：crimson。
  - 气泡珠：`[39, 40, 22, 21]` 平涂发光体。
  - 眼：墨 + 白高光。
- 部件顺序（从后往前）：远螯 → 远侧腿 → 螺壳 → 近侧腿 → 头胸甲（+ 口器、壳前沿亮边）→ 远眼柄 → 尖帽 → 近眼柄 → 珊瑚杖 → 近螯（夹住杖）→ 气泡珠。
- 细节清单：
  - 脸：两根眼柄，2×2 墨眼 + 1 格高光，能闭眼；口器 2 格。
  - 壳：蟹壳纹 3 点、前沿亮边；螺壳有螺旋沟、螺层缝合线和 4 个 2 格的紫光符文。
  - 帽：帽檐、金帽带 + 高光、向后歪的帽身、折角帽尖（会摆）。
  - 杖：1 格珊瑚主干 + 两根短珊瑚枝。
  - 发光体：气泡珠 5 档（待机小泡 / 蓄力亮 / 变大 5×5 / 施放爆亮 / 熄灭）。
- 攻击方式：远程。举杖后引，再前甩，连射 3 颗水泡弹（出手帧和之后 2 帧各一颗），弹道是空心小泡。
- 差异化（对照已通过角色和同组分配）：
  - 体型档：矮扁寄居蟹，是全库第一个节肢 / 蟹体。和同组的 PolarBear、BlackBear 四足熊、CrawlingCatapult 六足投石车在比例上都拉开。
  - 识别特征：螺壳、尖帽、珊瑚杖 + 气泡珠。三个都改变外轮廓。
  - 武器 + 握法 + 攻击类型：螯夹持杖（单螯夹握）× 施法（水泡连射）。
  - 待机个性：横挪眨眼。1.6–2.0 s 原地横挪两步再挪回来，两根眼柄轮流眨。
  - 步态：横行碎步，多足交替。每个接触帧 1 颗尘土，步子轻。
  - 死亡方式：翻倒缩壳。
  - 主色：珊瑚粉橙，同组没有粉色主材质。
- 升级线（→ 蟹巫）：保留螺壳、尖帽、右螯这三个识别特征。蟹巫把螺壳长成尖塔螺、帽变高、右螯长成巨钳。

## 特效设定卡

- 元素色阶：潮汐召唤 · 海水青 `FXI.water` = 21 白 → 22 青 → 41 蓝 → 40 深蓝 → 39 墨蓝。符文紫光只是材质，不进粒子。
- 攻击「水泡串」：
  - 预兆：杖后引、螯举起、珠 1 档。
  - 出手：前甩定格 1 帧（珠 2 档、轮廓光 2 档），杖顶一圈 8 点泡圈枪口光（2 帧），6 颗小水花。
  - 弹道：3 颗空心水泡（十字 4 格 + 左上白高光），速度 125 / 137 / 149，上下错开。
  - 命中：每颗 7 颗水花外爆，目标闪白小摇。
- 移动：横行碎步，每个接触帧 1 颗尘土。
- 技能「召唤小螃蟹」：
  - 蓄力 1.4 s：杖竖举、身体前抬、帽尖被吹向后。身前地面浮现水纹法阵（`fx.circle` 半径 10×2.5，慢转），水泡从法阵边缘定点螺旋汇入中心，少量汇入杖顶。气泡珠 0.45 s 后在 1/2 档间闪，0.9 s 后变大（5×5）。符文变亮，轮廓光 2 档，地面映光。
  - 施放 0.5 s：杖指向法阵（珠 3 档，十字星芒臂长 6）。法阵中心冒出水柱：第 1 帧 10 格、第 2 帧 22 格，由下往上。汇聚水泡从法阵中心往上溅出，冲击环，震屏 2 格，天空闪白。水柱顶有一只大泡泡，里面是橙色小螃蟹。0.1 s 泡泡破裂（水花 + 小环），小螃蟹蹦出，走抛物线。
  - 命中：0.3 s 小螃蟹落地，砸出一圈水花冲击环、22 颗水花和尘土，震屏 1 格，然后举钳两下。
  - 收招 0.7 s：法阵断续消失，水柱从顶往下塌，小螃蟹横走 4 帧步态到假人身前（x 86），举钳待命。气泡珠 2→1→0。
- 受击：enemy 敌弹 → 白色剪影 1 帧 + 击退 2 格 + 两眼闭上 + 帽尖反甩 + 杖后仰；impact 16 颗；震屏 1 格。
- 死亡：
  1. 命中火花 26 颗 + 震屏 2 格 + 闪白。
  2. 蜷缩（螯举起）→ 腿软摊开 → 翻成腹朝上、腿蜷起（离地 3→1→0）。
  3. 尖帽往前飞出、落在杖头前面；珊瑚杖和气泡珠躺在身前。
  4. 0.66 s 落地：尘土 16 颗 + 震屏 1 格。
  5. 气泡珠闪烁后熄灭；0.95 s 身体缩进螺壳，冒一串气泡，1.1 s 只剩一只空壳（露出暗壳口），符文闪灭。
  6. 1.6–2.4 s 自上而下消散，魂光上升。
- 音色：甲壳咔哒 + 咕噜冒泡 + 珊瑚杖轻敲的清脆声，重量 0.3。
  - `SFX: { body: 'beast', how: 'collapse', pal: 'water', style: 'summon', w: 0.3 }`
  - `step` 在步态接触帧；`swing` staff 在出手帧；每颗水泡发射时 `shoot` water，命中时 `hit` magic；小螃蟹落地时 `impact` water；倒地时 `fall`。
