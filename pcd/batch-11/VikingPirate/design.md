# 角色设定卡

- 名称 / 身份：维京海盗，虚空族的老水手商人（部队，普通）。
- 一句话剪影：背上用铁链捆着的小宝箱（箱顶高出肩 4 格）+ 向前伸出的 J 形铁钩 + 破边三角帽。
- 尺寸：待机约 26×28 格（身体 24 格 + 帽子），瘦削水手档：parts.rig `slim`（leg 9、torso 7、hunch 1 微驼、stride 3），窄肩、头前探。
- 材质色阶：
  - 外套 褪色墨蓝粗呢 [0, 39, 40, 59]（band 2，亮部褪成灰蓝，和维京战士的靛蓝 [0,39,40,41] 拉开）；领口、袖口内衬 [0, 39, 40, 41]
  - 裤 bone（脏帆布白），靴 boot，腰带 leather，扣 / 扣子 gold
  - 肤 [20, 19, 16, 15]（风吹日晒的深肤），髭须 white（灰白），帽 [0, 20, 20, 19]（旧皮三角帽），帽徽 bone
  - 宝箱 wood + iron 包角 + gold 铜锁板；铁钩、弯刀 steel；刀柄 leather，护手 gold
  - 发光体：箱缝金光 coinG [19, 14, 5, 21]（flat），箱里一粒诅咒紫 [25, 42, 24, 43]（flat）
- 部件顺序（从后往前）：宝箱（候选部件 chest）→ 后臂（钩臂，暗一级）→ 腿 → 大衣 coat（斜挎铁链带）→ 头（gaunt 脸、old、鹰钩鼻）+ 八字髭 + 眼罩（同一部件）→ 三角帽（挖掉 3 格成破边）→ 铁钩（候选部件 hook）→ 弯刀 → 前臂 + 手。
- 细节清单：
  - 脸：鹰钩鼻、黑眼罩 + 斜过额头的皮带、灰白八字髭、老人皱纹、耳
  - 头饰：三角帽（上翘两角、帽徽、破边缺口）
  - 服装：大衣前襟开口、竖排金扣、口袋盖、前后开衩、墨蓝领口、皮腰带 + 金扣、胸前斜挎铁链
  - 手臂：宽袖 + 墨蓝袖口，前手 2×2 手握刀，后手皮套 + 铁钩
  - 腿脚：帆布裤 + 翻口高靴，前后脚分色
  - 武器：弯刀（后三分之一弯、金护手、皮缠柄、刃高光），铁钩（J 形，钩尖朝上往回勾，钩与柄之间留空）
  - 背负物：宝箱圆拱盖 + 木板缝 + 铁包角 + 铜锁板锁孔 + 横竖两道铁链（链头在箱顶打结）
  - 发光体：箱缝金光 5 档（合 / 开缝闪 / 开缝亮 / 掀开 / 熄灭）
- 攻击方式：近战「刺」：铁钩先甩出去把目标勾近（目标往海盗这边晃），弯刀往前一捅（前冲 5 格、直线刀光 + 刀尖星芒）。
- 差异化（对照同族虚空 / 同批人形）：
  - 体型档：瘦削微驼水手档（slim + hunch 1），和维京战士（标准偏宽 + 大圆盾 + 姜红辫胡）拉开：瘦、无盾、灰白髭须。
  - 识别特征：①背上宝箱（改变外轮廓，背后鼓出一块、高出肩 4 格）②前伸的铁钩（改变外轮廓）③破边三角帽（改变外轮廓）④眼罩。
  - 武器 + 握法 + 攻击类型：右手弯刀 + 左手铁钩（双持异形），刺；同族没有钩 + 刺组合。
  - 待机个性：偷看宝藏——回头、铁钩伸到肩后掀开箱缝，箱缝漏出金光，赶紧合上。
  - 步态：水手摇摆步——接触帧上身前晃一格、头点一下、背上宝箱颠一下。
  - 死亡：踉跄跪下 → 往前侧倒；宝箱摔在身后、盖子掀开，滚出几枚金币；三角帽飘到头前方落地；自上而下消散。
  - 主色：褪色墨蓝粗呢 + 木箱棕 + 金。
- 与升级线：暗影死神保留三角帽（破成锯齿）、眼罩、墨蓝内衬，铁钩长成镰刀。
