# 网页游戏 · 一键打包（Steam / 安卓）

改完游戏后，把游戏包放进来，双击一下，就能得到可以上传 Steam 的电脑版和可以上架的安卓包。全程只用本地工具，**不调用 AI，不消耗 token**。

## 每次发版：3 步

1. 把导出的游戏包放进 **`放游戏包/`**：可以是 `.zip`，也可以是"分享版" `.html`。有多个时自动用最新的那个。
2. 双击 **`一键打包.command`**（Mac）或 **`一键打包.bat`**（Windows）。
3. 打包完会自动打开 **`输出/打包报告.html`**，里面有试跑截图、帧率和各项检查结果。

同样的游戏包，每次打出来的游戏文件完全一致。**发版前记得在 `配置.jsonc` 里把 `version` 加一点**，应用商店不接受重复的版本号。

## 打出来的东西

| 位置 | 用途 |
|---|---|
| `build/steam-windows/` | Windows 版。整个文件夹上传到 Steam 的 Windows depot |
| `build/steam-mac/` | Mac 版（只能在 Mac 电脑上打）。上传到 Mac depot |
| `build/android/*.apk` | 安卓安装包：直接安装，或上架国内应用商店 |
| `build/android/*.aab` | 上架 Google Play 用 |
| `输出/打包报告.html` | 本次打包的结果报告 |
| `secrets/` | **安卓签名密钥。第一次打安卓包时自动生成，务必马上备份** |

`build/` 和 `输出/` 每次打包都会清空重建，别往里放自己的文件。

## 一键打包自动做的事

1. **导入**：从压缩包里找出"分享版"单文件；没有的话，就找带 `index.html` 的文件夹。
2. **处理**：把窗口标题改成游戏名，把启动底色改成黑色，并对游戏代码做混淆。
3. **电脑版**：套上桌面外壳（Electron），生成 Windows `.exe` 和 Mac `.app`，带图标和版本信息。
4. **加固**：程序和游戏都封进 `app.asar` 并写入完整性校验，改动任何一个字节，程序都会拒绝启动；同时关掉调试入口。
5. **安卓版**：套上安卓外壳（Capacitor），设为横屏全屏、屏幕常亮，换上游戏图标，签名后生成 APK 和 AAB。
6. **检查与试跑**：
   - 电脑版在本机启动、模拟点击、截图，检查存档同步，确认全程不联网。
   - 安卓版装进官方模拟器或 USB 手机里启动、点击、截图，并检查日志里有没有报错。
7. **上传**：配置好以后，电脑版自动上传到 Steam 的测试分支。

## 测试版与日志（给别人测试时用）

- 把 `配置.jsonc` 里的 **`debugLog` 改成 `true`**，然后打包，打出来的就是**测试版**。
- 测试版的画面左下角会显示版本号和构建号。
- **电脑**：测试者按 **Ctrl+Shift+L**（Mac 为 Cmd+Shift+L），或者点左下角的版本号，日志会导出成一个文件放到桌面。让测试者把这个文件发给你。
- **安卓**：点左下角的版本号，会弹出系统分享，可以直接发到微信、QQ 或邮件。
- 你收到后，把文件放进项目的 **`收到的日志/`** 文件夹，双击 **`整理日志`**（或重新打包）。会生成 `输出/日志摘要.md`，里面有测试者的电脑环境、按内容归类的报错及次数、崩溃、卡死、帧率，同时同步一份到技能目录，直接交给 AI 就能查问题。
- 正式版（`debugLog: false`）也会记录报错和崩溃，同样可以按快捷键导出。**上架前记得把 `debugLog` 改回 `false`。**

## 机器人试玩

每次打包后，机器人会在电脑版里自己玩 60 秒。它会：
- 点按钮，优先点"开始、继续、确定"这类推进游戏的按钮，绝不点"重置、删除、退出"；
- 点战场、按住方向键，卡住时换着花样找出路；
- 检查有没有报错、卡死、崩溃，统计帧率和内存。

报告里有它的截图、经过的画面和最后 40 个操作。它能证明游戏可以持续玩下去、不出错，但**不能**证明好不好玩、数值是否平衡。

- 想让它更好地推进游戏：在 `bot.prefer` 里加上关键按钮上的文字。
- 想让它玩得更久：改 `bot.seconds`。
- 同一个 `bot.seed` 每次操作顺序相同，方便复现问题。

## 第一次运行

会自动下载需要的工具：
- 电脑版打包工具约 300 MB；
- 安卓还需要 JDK 21 和 Android SDK，约 2 GB；
- 用模拟器试跑还要再加约 4–5 GB 的安装空间，并且运行时需要约 7.5 GB 空闲磁盘。

安装 Android SDK 前会先问你是否同意 Google 的许可协议。之后打包都可以离线进行。网络慢的话，在配置里填 `electronMirror`。

## 电脑版行为

- 默认全屏，按 F11 或 Alt+Enter 切换窗口和全屏。
- 完全离线运行，任何联网请求都会被拦截。
- 存档会镜像一份到 `save/save.json`，供 Steam 云存档同步。
  - Windows：`%APPDATA%\<程序名>\save\`
  - Mac：`~/Library/Application Support/<程序名>/save/`
- 填了 Steam App ID 之后：不是从 Steam 启动、或者没有买这款游戏，游戏就会拒绝运行。

## 拿到 Steam App ID 以后

1. 在 `配置.jsonc` 里填 `steam.appId`，以及 `steam.depots` 里 Windows 和 Mac 的 depot 编号。
2. 从 Steamworks 官方文档下载 steamcmd，解压到 `tools/steamcmd/`。
3. 把 `steam.upload` 改成 `true`，`steam.buildAccount` 填上传用的账号名。
4. 双击一键打包。第一次上传时，密码和手机令牌需要你在弹出的窗口里自己输入，之后 steamcmd 会记住登录。
5. 新版本只会出现在 `beta` 测试分支，不会直接推给玩家。在 Steam 客户端里切到 beta 分支玩一遍，确认没问题后，再到 Steamworks 后台手动设为正式版本。

报告最后一节列出了 Steamworks 后台要填的启动选项和云存档路径。

## 安卓上架

- **Google Play**：上传 `.aab`。建议开通 Play 应用签名，`secrets/` 里的密钥就是你的上传密钥。
- **国内商店和直接安装**：用 `.apk`。
- **包名**：`android.packageId` 一旦上架就不能再改。

## 常见问题

- **模拟器试跑被跳过**：通常是磁盘空间不够（运行需要约 7.5 GB）。可以清理磁盘；也可以用数据线连上安卓手机，打开 USB 调试，把配置里的 `android.smokeDevice` 改成 `"usb"`。
- **没有 Node.js**：到 https://nodejs.org 安装 22 或更新的 LTS 版本。
- **在 Windows 电脑上打包**：会自动跳过 Mac 版，试跑会直接运行 Windows 版。
- **换图标**：在配置里填 `icon`，指向一张 PNG（建议 512×512 以上）。
