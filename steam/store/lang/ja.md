# Midnight Cabinet · 日本語 (ja)

## Short description
午前零時、古いアパートの屋根裏でスロットマシンが光った。コインを一枚入れたら、地下に基地を掘り進めよう。昼はポータルをくぐって異世界へ遠征し、部隊を集め、三体そろえて進化させ、ボスを倒す。夜は連れ帰った部隊が町を守り、押し寄せる混沌の群れを食い止める。深く進むほど強くなれる——帰ってこられれば、だが。

## Short description · demo
『Midnight Cabinet』の最初の2章を無料でプレイ。霧の町とエルフの森で地下基地を掘り、異世界へ遠征して部隊を集め、三体そろえて進化、10体のボスに挑み、10日目の夜の混沌襲来をしのぎ切ろう。体験版のセーブデータは製品版に引き継がれません。

[h2]コインを一枚、それが始まり[/h2]
午前零時。古いアパートの屋根裏に、悪魔の顔をしたスロットマシンがある。足元に転がってきたコインを投入すると——カメラは画面の中へ飛び込む。あなたのリーダーは地下に基地を築き、夜ごとの混沌襲来を生き延びなければならない。

[img]{STEAM_APP_IMAGE}/extras/02_expedition.gif[/img]

[h2]昼：異世界へ遠征[/h2]
本拠のポータルをくぐり、異世界を一地点ずつ進んでいく。戦闘、夜市、そして奇妙なイベント。もう一歩進めば実入りは増えるが、帰れなくなる危険も増す。勝てないと思ったら撤退して、手に入れたものを持ち帰ろう。戦闘は自動で進み、誰を出すか、いつスキルを使うかはあなたが決める。

[img]{STEAM_APP_IMAGE}/extras/03_merge.gif[/img]

[h2]三体そろえて、進化[/h2]
夜市で部隊を集め、同じ部隊が三体そろえば、その場で同じ系統の次の段階へ進化する。33の進化ライン、6段階のレアリティ、198種の部隊。同じ種族や職業をそろえれば絆が生まれ、編成はどんどん強くなる。

[img]{STEAM_APP_IMAGE}/extras/04_boss.gif[/img]

[h2]ボスごとに違う戦い方[/h2]
大鐘を背負った時計塔の鐘守り、鉄のシャベルを担いだ墓地の墓守、森に踏み込んだ者を土に植えてしまうドルイド……どのボスにも固有の技と第二形態があり、得意な相手と苦手な相手もはっきり示される。読み解いたら、夜市で編成を組もう。

[img]{STEAM_APP_IMAGE}/extras/05_fever.gif[/img]

[h2]FEVER！[/h2]
部隊の戦いぶりが良いほど、FEVERゲージは速くたまる。満タンになった瞬間に爆発：落雷が敵陣を次々と貫き、FEVER TIMEの8秒間は全軍の攻撃速度がアップ。ボス戦では天から光の柱が降り注ぎ、全員を回復する。戦闘は止まらない、アーケードの熱さそのまま。

[img]{STEAM_APP_IMAGE}/extras/06_night.gif[/img]

[h2]夜：混沌襲来[/h2]
毎晩、怪物たちが町の両端から一斉に押し寄せる。その数、人の海。町を守るのは昼に連れ帰った部隊で、リーダーは時計塔の上から撃ちまくる。守り切れば町は栄え、守れなければ本拠は失われる。

[img]{STEAM_APP_IMAGE}/extras/07_base.gif[/img]

[h2]地下基地を掘り進めよう[/h2]
岩盤を掘り、部屋を建てる。生産、鍛冶、医療、訓練、進化。地下に部屋をひとつ建てるたびに、地上には建物がひとつ建ち、町に少しずつ明かりが灯る。49種の建物と17の世界遺産で、毎回ちがう町ができあがる。

[img]{STEAM_APP_IMAGE}/extras/08_event.gif[/img]

[h2]道中のイベント[/h2]
ピンボール、クレーンゲーム、ミッドナイトルーレット、願いの井戸、流しの楽師……異世界の道には妙なものが待ち構えている。27種のイベントは、どれもひとつのミニゲームだ。

[h2]負けても、何かが残る[/h2]
倒れたリーダーは遺影を残す。そこには身につけたタレントがひとつ刻まれ、次のランへ持ち込める。キャビネットにはパーツ、フィギュア、カートリッジもあり、ランを重ねるごとに遊べることが増えていく。
