# Midnight Cabinet · 한국어 (ko)

## Short description
자정, 다락방의 슬롯머신에 불이 들어옵니다. 동전을 넣고 도시 아래에 기지를 파세요. 낮에는 이세계로 원정을 떠나 부대를 모집하고, 셋을 하나로 합쳐 진화시키고, 보스를 쓰러뜨립니다. 밤에는 데려온 부대가 밀려드는 혼돈의 괴물 떼를 막아 냅니다. 깊이 갈수록 더 강해져 돌아옵니다. 돌아올 수만 있다면.

## Short description · demo
Midnight Cabinet의 처음 두 장을 무료로 플레이하세요. 지하 기지를 파고, 안개 마을과 엘프의 숲으로 원정을 떠나 부대를 진화시키고, 보스 10명에 맞서 10번째 밤까지 버텨 내세요. 체험판의 저장 데이터는 정식판으로 이어지지 않습니다.

## About This Game
```

[h2]동전 하나를 넣으면[/h2]
자정. 낡은 아파트 다락방에 악마 얼굴을 한 슬롯머신이 있습니다. 발치로 굴러온 동전을 넣자, 카메라가 화면 속으로 뛰어듭니다. 이제 당신의 리더는 지하에 기지를 세우고, 밤마다 찾아오는 혼돈 습격을 견뎌 내야 합니다.

[img]{STEAM_APP_IMAGE}/extras/02_expedition.gif[/img]

[h2]낮: 이세계로 원정[/h2]
본거지의 포털을 지나 이세계를 한 지점씩 나아갑니다. 전투, 야시장, 기묘한 조우. 한 지점 더 가면 수확은 늘지만, 돌아오지 못할 위험도 커집니다. 버겁다 싶으면 철수해서 얻은 것을 가지고 돌아오세요. 전투는 자동으로 진행되고, 누구를 내보낼지, 언제 스킬을 쓸지는 당신이 정합니다.

[img]{STEAM_APP_IMAGE}/extras/03_merge.gif[/img]

[h2]셋이 모여 하나로[/h2]
야시장에서 부대를 모집하세요. 같은 부대 셋을 모으면 즉시 같은 라인의 다음 단계로 진화합니다. 33개의 진화 라인, 6단계 품질, 198종의 부대. 같은 종족, 같은 직업을 모으면 유대가 생겨 편성이 점점 강해집니다.

[img]{STEAM_APP_IMAGE}/extras/04_boss.gif[/img]

[h2]보스마다 다른 수법[/h2]
큰 종을 등에 진 종탑의 종지기, 쇠삽을 멘 묘지의 묘지기, 숲에 들어온 자를 땅에 심어 버리는 드루이드…… 보스마다 고유한 기술과 2페이즈가 있고, 어떤 편성에 강하고 어떤 편성을 두려워하는지도 알려 줍니다. 그걸 읽어 낸 다음, 야시장에서 편성을 짜세요.

[img]{STEAM_APP_IMAGE}/extras/05_fever.gif[/img]

[h2]FEVER![/h2]
부대가 잘 싸울수록 FEVER 게이지가 빨리 찹니다. 가득 차는 순간 바로 터집니다. 벼락이 적진에 연달아 내리꽂히고, FEVER TIME 8초 동안 전군의 공격 속도가 오릅니다. 보스전에서는 하늘에서 빛기둥이 내려와 모두를 치유합니다. 전투는 멈추지 않습니다.

[img]{STEAM_APP_IMAGE}/extras/06_night.gif[/img]

[h2]밤: 혼돈 습격[/h2]
매일 밤, 몬스터들이 마을 양쪽 끝에서 한꺼번에 몰려옵니다. 그야말로 인산인해. 마을을 지키는 것은 낮에 데려온 부대이고, 리더는 종탑 꼭대기에서 사격합니다. 막아 내면 마을이 번영하고, 무너지면 본거지를 잃습니다.

[img]{STEAM_APP_IMAGE}/extras/07_base.gif[/img]

[h2]지하 기지를 파세요[/h2]
암반을 깨고 방을 지으세요. 생산, 제작, 의무실, 훈련장, 진화실. 지하에 방을 하나 지을 때마다 지상 마을에 건물이 하나 올라가고, 마을에 조금씩 불이 켜집니다. 49종의 건물과 17개의 불가사의로, 판마다 다른 마을이 생깁니다.

[img]{STEAM_APP_IMAGE}/extras/08_event.gif[/img]

[h2]길 위의 기묘한 것들[/h2]
핀볼, 인형 뽑기, 한밤의 룰렛, 소원의 우물, 떠돌이 악사…… 이세계의 길에는 늘 이상한 것들이 기다리고 있습니다. 27종의 조우, 하나하나가 작은 미니게임입니다.

[h2]져도 무언가는 남는다[/h2]
쓰러진 리더는 영정을 남깁니다. 배운 재능 하나가 새겨진 영정은 다음 판으로 가져갈 수 있습니다. 캐비닛에는 부품, 피규어, 카트리지도 있어, 판을 거듭할수록 즐길 거리가 늘어납니다.
```
